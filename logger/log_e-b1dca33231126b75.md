# Configured stream conflicts with an active transient stream

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_e
Log level: error
Documentation ID: log_e-b1dca33231126b75

## Log pattern

```text
transient stream with the same id already exists [%s]
```

## Parameters

- Argument 1 — Identifier: Stream identifier shared by transient and configured entries.

## Log examples

Illustrative examples; these are not captured server logs.

```text
transient stream with the same id already exists [live/camera]
```

## Short description

Configured stream conflicts with an active transient stream.

## Trigger condition

Applying stream settings finds a configured stream identifier already occupied by an active transient stream.

## Explanation

The transient stream is retained and the conflicting configured stream entry is skipped during this update.

## Possible causes

- Applying stream settings finds a configured stream identifier already occupied by an active transient stream.

## What to check

1. Check the active publisher name and configured stream identifier.

## Recommended action

Assign distinct identifiers or remove the conflicting publisher before applying the configured stream.
