# SDI output video parameters changed

Product: Nimble Streamer
Component: SDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-0206096e71589093

## Log pattern

```text
reset sdi output. video params changed [%s/%s]
```

## Parameters

- Argument 1 — Device type: Configured media-device driver type.
- Argument 2 — Device stream: Configured SDI device or stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reset sdi output. video params changed [decklink/SDI output]
```

## Short description

SDI output video parameters changed.

## Trigger condition

An established output receives a different frame duration, width, or height.

## Explanation

Video message processing returns failure rather than reconfiguring the active output device in place.

## Possible causes

- An established output receives a different frame duration, width, or height.

## What to check

1. Check the source video frame rate and dimensions before and after the change.

## Recommended action

Reinitialize output for the new parameters.
