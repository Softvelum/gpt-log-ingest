# IP range list contains no usable items

Product: Nimble Streamer
Component: IP access ranges
Logging function: log_e
Log level: error
Documentation ID: log_e-2461144db4d37f21

## Log pattern

```text
range='%s' is invalid
```

## Parameters

- Argument 1 — Range definition: Text of the configured comma-separated range definition, not its name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
range='' is invalid
```

## Short description

IP range list contains no usable items.

## Trigger condition

Splitting a named range definition by commas produces no range items.

## Explanation

This definition is skipped while other named ranges continue to be processed.

## Possible causes

- The range definition yields no items.

## What to check

1. Check the range definition for an empty list.

## Recommended action

Supply the intended address ranges.
