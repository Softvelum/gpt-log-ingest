# RIST child connection stopped

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-56d132227da27995

## Log pattern

```text
out of process rist %s stopped, id=%s
```

## Parameters

- Argument 1 — Role: sender for output, or player for input.
- Argument 2 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
out of process rist sender stopped, id=rist-output
```

## Short description

RIST child connection stopped.

## Trigger condition

A RIST connection is destroyed after its runtime libraries were successfully loaded.

## Explanation

Peers and transport context are destroyed and parsed address settings released before this message; the RIST libraries are unloaded afterward. The message can also follow failed initialization.

## Possible causes

- A RIST connection is destroyed after its runtime libraries were successfully loaded.

## What to check

1. Check preceding RIST messages if transport setup or operation ended unexpectedly.
