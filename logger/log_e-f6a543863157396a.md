# Origin connection attempt failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-f6a543863157396a

## Log pattern

```text
failed to connect to origin s=%d '%s:%d' errno=%d
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.
- Argument 2 — Origin hostname: Text hostname without the port.
- Argument 3 — Origin port: Integer TCP port.
- Argument 4 — Socket error: Integer error value retained by the socket operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect to origin s=17 'media.example:8080' errno=111
```

## Short description

Origin connection attempt failed.

## Trigger condition

An outgoing origin connection does not return the expected nonblocking in-progress result.

## Explanation

The HTTP client prepares its shutdown response; cache and advertising connection setup return failure.

## Possible causes

- An outgoing origin connection does not return the expected nonblocking in-progress result.

## What to check

1. Interpret the socket error and verify origin hostname, port, reachability, and listener availability.

## Recommended action

Interpret the socket error and verify origin hostname, port, reachability, and listener availability.
