# Quick Sync implementation query failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-a06a174b01bcd251

## Log pattern

```text
failed to get current impl, error=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

Shared by native Quick Sync decoder and encoder setup.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get current impl, error=-3
```

## Short description

Quick Sync implementation query failed.

## Trigger condition

The media runtime returns a nonzero status when queried for the active implementation during decoder or encoder setup.

## Explanation

Setup returns failure before version reporting and hardware binding.

## Possible causes

- The newly created media session cannot report its implementation.

## What to check

1. Use the status to inspect media runtime and session initialization diagnostics.

## Recommended action

Correct the runtime or device initialization failure and restart the affected stream.
