# Audio loader failed during media packaging

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-d8a959918b7ae54d

## Log pattern

```text
BufferTooSmallMP3LoaderException caught while processing file='%s' chunk='%s'
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.
- Argument 2 — Requested resource: Text name of the requested playlist, initialization segment, or media chunk.

## Log examples

Illustrative examples; these are not captured server logs.

```text
BufferTooSmallMP3LoaderException caught while processing file='/media/movie.mp4' chunk='n_0_0_0.ts'
```

## Short description

Audio loader failed during media packaging.

## Trigger condition

A base MPEG-audio-loader exception reaches the general output handler.

## Explanation

The requested output is canceled with a transmuxing-failure reason and released. The fixed text says buffer-too-small MP3, but this catch includes broader audio-loader failures.

## Possible causes

- A base MPEG-audio-loader exception reaches the general output handler.

## What to check

1. Inspect preceding audio parsing and buffer diagnostics; do not infer a buffer-capacity problem from this fixed message alone.

## Recommended action

Inspect preceding audio parsing and buffer diagnostics; do not infer a buffer-capacity problem from this fixed message alone.
