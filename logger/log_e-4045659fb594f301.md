# SRT reporting cannot identify local address

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-4045659fb594f301

## Log pattern

```text
failed to get local IP for SRT s=%d stream='%s' (session will not be reported)
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.
- Argument 2 — Stream: Normalized reporting path with a leading slash.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get local IP for SRT s=101 stream='/live/news' (session will not be reported)
```

## Short description

SRT reporting cannot identify local address.

## Trigger condition

A reporting stream is configured but the local SRT endpoint address is unavailable.

## Explanation

Session registration fails and callers reject this receiver setup.

## Possible causes

- A reporting stream is configured but the local SRT endpoint address is unavailable.

## What to check

1. Inspect preceding local-address lookup errors.
