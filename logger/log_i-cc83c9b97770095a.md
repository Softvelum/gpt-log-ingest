# NVIDIA video decoding falls back to FFmpeg

Product: Nimble Streamer
Component: Video decoding
Logging function: log_i
Log level: info
Documentation ID: log_i-cc83c9b97770095a

## Log pattern

```text
nvidia decoder is unavailable, using default decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

Shared by MPEG-2, H.264, HEVC, VP8, and VP9 decoder selection; the message alone does not identify the codec.

## Log examples

Illustrative examples; these are not captured server logs.

```text
nvidia decoder is unavailable, using default decoder for [live/camera]
```

## Short description

NVIDIA video decoding falls back to FFmpeg.

## Trigger condition

The NVENC decoder option is selected but the native NVIDIA decode libraries are not loaded.

## Explanation

The worker constructs the default FFmpeg decoder for the input codec and continues.

## Possible causes

- The optional NVIDIA decoding libraries were unavailable during loading.

## What to check

1. Check earlier NVIDIA library-loading diagnostics if hardware decoding is required.

## Recommended action

Restore the required libraries or keep the default decoder if its performance is sufficient.
