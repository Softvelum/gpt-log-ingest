# AVC transport header exceeds its buffer

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-b27677d4458762d0

## Log pattern

```text
[VM] cannot allocate memory for mpeg2ts_avc_header [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the affected live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] cannot allocate memory for mpeg2ts_avc_header [live/camera]
```

## Short description

AVC transport header exceeds its buffer.

## Trigger condition

Writing the access-unit delimiter, AVC parameter-set bytes, or their Annex B delimiters into the fixed 16 KiB transport-header buffer fails.

## Explanation

AVC setup returns failure. Parameter-set failures also ensure an empty transport header exists so later processing has a safe header object.

## Possible causes

- Writing the access-unit delimiter, AVC parameter-set bytes, or their Annex B delimiters into the fixed 16 KiB transport-header buffer fails.

## What to check

1. Check AVC parameter-set lengths and memory allocation errors.

## Recommended action

Correct oversized parameter sets or resolve the header-buffer allocation failure.
