# RTSP HTTP POST tunnel is unavailable

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-3b9e6f58f9974320

## Log pattern

```text
failed to open http tunnel, socket=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open http tunnel, socket=25
```

## Short description

RTSP HTTP POST tunnel is unavailable.

## Trigger condition

The client tries to send its tunnel-opening HTTP POST while no tunnel connection is attached.

## Explanation

The input requests shutdown instead of sending the HTTP POST.

## Possible causes

- The client tries to send its tunnel-opening HTTP POST while no tunnel connection is attached.

## What to check

1. Check the preceding HTTP tunnel connection setup.
