# Unrecognized TLS origin event

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-028fe531ff2191e1

## Log pattern

```text
unknown event for ssl origin s=%d ev=0x%x
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the affected local socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown event for ssl origin s=17 ev=0x10
```

## Short description

Unrecognized TLS origin event.

## Trigger condition

The TLS origin socket receives an event combination that is neither input/output readiness nor a handled error or closure.

## Explanation

The event is logged without an immediate state change in this branch.

## Possible causes

- The TLS origin socket receives an event combination that is neither input/output readiness nor a handled error or closure.

## What to check

1. Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.

## Recommended action

Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.
