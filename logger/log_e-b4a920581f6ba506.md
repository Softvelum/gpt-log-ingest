# RTMP createStream command uses a nonzero message stream ID

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-b4a920581f6ba506

## Log pattern

```text
createStream command must be sent via message stream id=0
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
createStream command must be sent via message stream id=0
```

## Short description

RTMP createStream command uses a nonzero message stream ID.

## Trigger condition

The peer sends createStream on a message stream other than 0.

## Explanation

The command is rejected and connection processing fails. These connection-level commands are handled only on message stream 0.

## Possible causes

- The peer sends createStream on a message stream other than 0.

## What to check

1. Inspect the message stream ID in the createStream request.

## Recommended action

Correct the peer to use message stream ID 0 for this command.
