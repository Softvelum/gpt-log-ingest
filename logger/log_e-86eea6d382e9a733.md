# Sent body count exceeds expected bytes

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-86eea6d382e9a733

## Log pattern

```text
origin_resp_body_sent_(%u) <= origin_resp_body_size_(%u)
```

## Parameters

- Argument 1 — Sent bytes: Unsigned 64-bit cumulative sent body bytes, incorrectly printed with %u.
- Argument 2 — Expected bytes: Unsigned 64-bit expected body byte count, incorrectly printed with %u.

Both counters are unsigned 64-bit values passed to %u, so their printed values are unreliable. The fixed comparison text describes the failed invariant, not a true comparison.

## Log examples

Both counters are unsigned 64-bit values passed to %u, so their printed values are unreliable. The fixed comparison text describes the failed invariant, not a true comparison.

## Short description

Sent body count exceeds expected bytes.

## Trigger condition

After an asynchronous write, cumulative sent bytes exceed the expected body count.

## Explanation

The session is marked finished because body accounting is inconsistent.

## Possible causes

- After an asynchronous write, cumulative sent bytes exceed the expected body count.

## What to check

1. Inspect surrounding receive and write counters for the same request; this indicates an internal body-accounting error.

## Recommended action

Inspect surrounding receive and write counters for the same request; this indicates an internal body-accounting error.
