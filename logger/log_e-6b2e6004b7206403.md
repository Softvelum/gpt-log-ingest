# SDI audio converter opening failed

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-6b2e6004b7206403

## Log pattern

```text
failed to open audio converter for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open audio converter for [live/camera]
```

## Short description

SDI audio converter opening failed.

## Trigger condition

Opening the output audio encoder returns a negative result.

## Explanation

The current output frame operation returns failure.

## Possible causes

- The audio encoder rejects the configured output parameters.

## What to check

1. Check the output audio parameters and nearby FFmpeg diagnostics.

## Recommended action

Correct the output parameters and retry.
