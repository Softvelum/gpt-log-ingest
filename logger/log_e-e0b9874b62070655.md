# DVR database cannot be opened for recording

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-e0b9874b62070655

## Log pattern

```text
failed to open dvr segments db file='%s' error='%s'
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.
- Argument 2 — Error message: Text describing the reported filesystem failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open dvr segments db file='/data/dvr/live/camera/nimble-dvr-segments.db' error='Permission denied'
```

## Short description

DVR database cannot be opened for recording.

## Trigger condition

The segment index cannot be opened in the required append or read/write mode.

## Explanation

The pending segment record is not written.

## Possible causes

- The segment index cannot be opened in the required append or read/write mode.

## What to check

1. Check the reported filesystem error and database permissions.

## Recommended action

Check the reported filesystem error and database permissions.
