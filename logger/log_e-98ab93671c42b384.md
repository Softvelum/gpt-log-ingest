# VP9 Quick Sync setup failed and falls back

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-98ab93671c42b384

## Log pattern

```text
failed to create quicksync vp9 decoder, using default decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create quicksync vp9 decoder, using default decoder for [live/camera]
```

## Short description

VP9 Quick Sync setup failed and falls back.

## Trigger condition

Native Quick Sync decoding was requested and its libraries are loaded, but creating the VP9 decoder session returns no decoder.

## Explanation

The worker constructs the default FFmpeg VP9 decoder and continues despite the error severity.

## Possible causes

- Media session creation, implementation or version queries, codec plugin loading, or hardware display binding failed.

## What to check

1. Check preceding Quick Sync and VA device diagnostics for the specific failure.

## Recommended action

Correct the runtime or device setup if Quick Sync is required; otherwise monitor the fallback decoder capacity.
