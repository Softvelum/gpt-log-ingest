# CloudDRM password is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-e72490922503852b

## Log pattern

```text
Password must be provided for Cloud DRM (cloud_drm_password)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Password must be provided for Cloud DRM (cloud_drm_password)
```

## Short description

CloudDRM password is missing.

## Trigger condition

The CloudDRM password is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The CloudDRM password is empty.

## What to check

1. Provide the CloudDRM password.

## Recommended action

Provide the CloudDRM password.
