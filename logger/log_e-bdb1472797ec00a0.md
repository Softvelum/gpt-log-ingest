# External response body buffer is full

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-bdb1472797ec00a0

## Log pattern

```text
[ReqS] url='%s' len='%s' does not fit the buffer capacity=%zu
```

## Parameters

- Argument 1 — URL: Original external request URL, retained even when following a redirect.
- Argument 2 — length: Raw declared Content-Length text.
- Argument 3 — capacity: Body buffer capacity in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[ReqS] url='https://media.example/movie.mp4' len='8192' does not fit the buffer capacity=4096
```

## Short description

External response body buffer is full.

## Trigger condition

A normal body read begins with no unused bytes in its destination buffer.

## Explanation

The message records the declared length and capacity, then the code still attempts the read with zero available space. This path can subsequently be handled as connection closure.

## Possible causes

- The received body has filled the available destination buffer before normal completion.

## What to check

1. Compare the response length with the allocated request buffer or requested range.

## Recommended action

Provide sufficient response capacity or correct the origin response size.
