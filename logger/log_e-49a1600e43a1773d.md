# Fragmented MP4 advertisement has no MP4 loader

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-49a1600e43a1773d

## Log pattern

```text
failed to get mp4 loader while processing content id='%s'
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get mp4 loader while processing content id='ad-01'
```

## Short description

Fragmented MP4 advertisement has no MP4 loader.

## Trigger condition

A fragmented MP4 advertising media or initialization chunk is requested without an MP4 loader.

## Explanation

Generation returns and the pending cache item is canceled during cleanup.

## Possible causes

- A fragmented MP4 advertising media or initialization chunk is requested without an MP4 loader.

## What to check

1. Check that the advertisement is valid MP4 content and has loaded successfully.

## Recommended action

Check that the advertisement is valid MP4 content and has loaded successfully.
