# Disk cache loading started

Product: Nimble Streamer
Component: Media data cache
Logging function: log_i
Log level: info
Documentation ID: log_i-30a3721b8a3bb298

## Log pattern

```text
Loading cache from %s
```

## Parameters

- Argument 1 — directory: Root directory used for disk cache storage.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Loading cache from /var/cache/nimble
```

## Short description

Disk cache loading started.

## Trigger condition

The first cache-loading call creates its directory traversal context.

## Explanation

Stored cache directories are scanned in bounded batches so later calls can resume the work.
