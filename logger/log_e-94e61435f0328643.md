# Unsupported playlist processing type

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-94e61435f0328643

## Log pattern

```text
failed to process playlist type=%d
```

## Parameters

- Argument 1 — Playlist type: Integer protocol value; supported playlist values are 1 HLS, 3 Smooth, 4 HDS, and 7 DASH.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process playlist type=0
```

## Short description

Unsupported playlist processing type.

## Trigger condition

Playlist processing receives a type other than HLS, Smooth, HDS, or DASH.

## Explanation

An HTTP 500 response is prepared.

## Possible causes

- Playlist processing receives a type other than HLS, Smooth, HDS, or DASH.

## What to check

1. Check the preceding playlist classification and response content type; this branch indicates an inconsistent playlist request.

## Recommended action

Check the preceding playlist classification and response content type; this branch indicates an inconsistent playlist request.
