# CEA-708 subtitle queue discards its oldest pending item

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-c41d5ea7dc867320

## Log pattern

```text
max ce708 subtitles queue count exceeded for [%s/%s] service=%d
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Service: Assigned CEA-708 service number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
max ce708 subtitles queue count exceeded for [live/camera] service=1
```

## Short description

CEA-708 subtitle queue discards its oldest pending item.

## Trigger condition

A caption service already has more than ten pending subtitles when another converted WebVTT subtitle arrives.

## Explanation

The oldest pending subtitle is removed before the new subtitle is queued. Because the check is strictly greater than ten, the retained queue can contain eleven items.

## Possible causes

- A caption service already has more than ten pending subtitles when another converted WebVTT subtitle arrives.

## What to check

1. Check caption consumption, subtitle timing, and arrival rate for the named service.

## Recommended action

Reduce caption backlog or correct subtitle timing.
