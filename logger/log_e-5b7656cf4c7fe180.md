# AAC encoder allocation failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-5b7656cf4c7fe180

## Log pattern

```text
failed to open libfdk audio encoder, status=%d
```

## Parameters

- Argument 1 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open libfdk audio encoder, status=1
```

## Short description

AAC encoder allocation failed.

## Trigger condition

In an FDK-enabled build, opening the encoder for the input channel count returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected encoder allocation for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in encoder allocation.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
