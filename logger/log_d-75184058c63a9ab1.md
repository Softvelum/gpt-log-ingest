# Stream-check socket closed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-75184058c63a9ab1

## Log pattern

```text
checker socket s=%d closed
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
checker socket s=12 closed
```

## Short description

Stream-check socket closed.

## Trigger condition

Closing a task socket succeeds after event registration is removed.

## Explanation

The task clears its stored descriptor and releases TLS state; it may later create a replacement connection.
