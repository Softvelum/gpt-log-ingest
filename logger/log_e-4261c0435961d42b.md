# Rules file could not be opened for writing

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-4261c0435961d42b

## Log pattern

```text
failed to open rules file for writing: %s
```

## Parameters

- Argument 1 — File: Requested file path, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open rules file for writing: /var/lib/nimble/example.xml
```

## Short description

Rules file could not be opened for writing.

## Trigger condition

Opening the rules file in write-and-truncate mode fails.

## Explanation

The save operation returns failure before writing the notice or rules.

## Possible causes

- The destination cannot be opened for writing.

## What to check

1. Check the destination path and write access.

## Recommended action

Restore write access to the rules-file destination.
