# SCTE-35 splice section cannot be created

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-9519136b4c42aab2

## Log pattern

```text
[SCTE35] failed to create splice info section for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] failed to create splice info section for [live/camera]
```

## Short description

SCTE-35 splice section cannot be created.

## Trigger condition

Encoding a cue-derived immediate splice marker or an injected splice section returns zero bytes.

## Explanation

Cue processing returns failure; an injected section is discarded while processing of other pending sections continues.

## Possible causes

- Encoding a cue-derived immediate splice marker or an injected splice section returns zero bytes.

## What to check

1. Check injected marker fields and whether the section fits the supported output buffer.

## Recommended action

Correct invalid or oversized injected SCTE-35 content.
