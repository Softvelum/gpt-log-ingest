# VAAPI surface image derivation failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-5924f597cbb666f8

## Log pattern

```text
%p failed to derive image, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to derive image, 0x1
```

## Short description

VAAPI surface image derivation failed.

## Trigger condition

Deriving an image from the input surface returns a non-success status.

## Explanation

The input frame cannot be copied to the surface and frame encoding fails.

## Possible causes

- The VA driver cannot expose a CPU-accessible image for the surface.

## What to check

1. Check the VA status, preceding device errors, and whether the encoder context remains usable.

## Recommended action

Resolve the VA driver or device failure and restart the affected encoder.
