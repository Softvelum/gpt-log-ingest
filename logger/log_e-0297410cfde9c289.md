# Internal media message processing failed

Product: Nimble Streamer
Component: Media subprocess communication
Logging function: log_e
Log level: error
Documentation ID: log_e-0297410cfde9c289

## Log pattern

```text
failed to process msg: type=%d size=%d
```

## Parameters

- Argument 1 — Message type: Unsigned eight-bit internal message type displayed as an integer.
- Argument 2 — Framed size: Message payload size plus its five-byte transport header, in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process msg: type=1 size=105
```

## Short description

Internal media message processing failed.

## Trigger condition

A received framed message reaches the connection-specific handler and that handler returns failure.

## Explanation

The socket session receives a failed-message result. The owning connection marks input failed and switches to discarding input when that result propagates through event processing. This covers any media subprocess using this connection path.

## Possible causes

- A received framed message reaches the connection-specific handler and that handler returns failure.

## What to check

1. Check the message type and preceding component-specific parsing or processing error.
