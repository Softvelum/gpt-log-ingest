# NVIDIA device discovered without a name

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-75c52f8ff05b09e7

## Log pattern

```text
unknown nvenc device %d found
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown nvenc device 0 found
```

## Short description

NVIDIA device discovered without a name.

## Trigger condition

A CUDA device is retrieved, but its name query returns an error.

## Explanation

The device is still added to the available list and may be used by index.

## Possible causes

- The CUDA driver cannot return the device name.

## What to check

1. Check whether subsequent device-context creation succeeds for this index.

## Recommended action

No action is required if the device operates correctly; otherwise inspect CUDA driver access.
