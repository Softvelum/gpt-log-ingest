# Video DVR export header cannot be buffered

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-e5d45b39f33d16e8

## Log pattern

```text
failed to prepare video only mp4 header, stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to prepare video only mp4 header, stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

Video DVR export header cannot be buffered.

## Trigger condition

The video-only HTTP response header cannot be appended to the output buffer.

## Explanation

The export socket is shut down.

## Possible causes

- The video-only HTTP response header cannot be appended to the output buffer.

## What to check

1. Check output-buffer allocation and capacity errors.

## Recommended action

Check output-buffer allocation and capacity errors.
