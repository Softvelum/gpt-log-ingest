# Unhandled Windows exception recorded

Product: Nimble Streamer
Component: Process signals and exception diagnostics
Logging function: log_e
Log level: error
Documentation ID: log_e-6e4899b0902070f1

## Log pattern

```text
Unhandled exception at %#x (code=%#x)
```

## Parameters

- Argument 1 — Address: Process address printed in hexadecimal; the ordinary integer conversion can truncate a pointer on wider targets.
- Argument 2 — Exception code: Windows exception code, printed in hexadecimal.

The exception address is supplied as a pointer but formatted with an ordinary hexadecimal integer conversion; wide addresses may be incomplete.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Unhandled exception at 0x12340000 (code=0xc0000005)
```

## Short description

Unhandled Windows exception recorded.

## Trigger condition

The Windows exception handler receives an unhandled exception.

## Explanation

It logs exception details and register values, builds a stack trace, and continues the normal Windows exception-search behavior.

## Possible causes

- An exception was not handled by the application.

## What to check

1. Check the exception code, address, register report, and following stack trace.

## Recommended action

Diagnose the exception using the associated diagnostics.
