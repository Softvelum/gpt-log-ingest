# Sigma DRM access token is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-7efa4656e9351548

## Log pattern

```text
Access token must be provided for Sigma DRM (sigma_drm_token)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Access token must be provided for Sigma DRM (sigma_drm_token)
```

## Short description

Sigma DRM access token is missing.

## Trigger condition

The Sigma DRM access token is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The Sigma DRM access token is empty.

## What to check

1. Provide the Sigma DRM access token.

## Recommended action

Provide the Sigma DRM access token.
