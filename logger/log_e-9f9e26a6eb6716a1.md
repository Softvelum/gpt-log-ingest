# AVC configuration version is unsupported

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-9f9e26a6eb6716a1

## Log pattern

```text
[VM] not supported AVC configuration %d, [%s/%s]
```

## Parameters

- Argument 1 — Version: First byte of the AVC decoder configuration.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] not supported AVC configuration 2, [live/camera]
```

## Short description

AVC configuration version is unsupported.

## Trigger condition

The first configuration byte is not version 1.

## Explanation

An empty transport header is ensured and AVC setup fails.

## Possible causes

- The first configuration byte is not version 1.

## What to check

1. Check the configuration record version and framing at the input.

## Recommended action

Use a version-1 AVC decoder configuration record.
