# Invalid SRT output stream selection

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-f400c30a42894e9b

## Log pattern

```text
requested stream has invalid streamid s=%d streamid='%s'
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.
- Argument 2 — Stream ID: Requested SRT stream identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
requested stream has invalid streamid s=101 streamid='/news'
```

## Short description

Invalid SRT output stream selection.

## Trigger condition

The receiver stream ID, after removing query parameters and normalizing a leading slash, cannot be split into application and stream.

## Explanation

The regular wildcard output session fails setup before looking up source media.

## Possible causes

- The receiver stream ID, after removing query parameters and normalizing a leading slash, cannot be split into application and stream.

## What to check

1. Check the receiver stream ID.

## Recommended action

Request a valid application/stream identifier.
