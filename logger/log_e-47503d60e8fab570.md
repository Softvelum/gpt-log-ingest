# External request could not start connecting

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-47503d60e8fab570

## Log pattern

```text
failed to connect to peer s=%d '%s:%d' errno=%d
```

## Parameters

- Argument 1 — socket: Peer socket descriptor.
- Argument 2 — host: Target hostname.
- Argument 3 — port: Target TCP port.
- Argument 4 — error: Operating system socket error code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect to peer s=12 'media.example:443' errno=111
```

## Short description

External request could not start connecting.

## Trigger condition

The initial connect does not return the expected in-progress result.

## Explanation

A fatal request exception triggers startup cleanup and a failure callback. The branch also treats an immediate connect success as unexpected.

## Possible causes

- The connect result was outside the expected asynchronous state.

## What to check

1. Check origin reachability and the reported error.

## Recommended action

Investigate connection establishment to the target.
