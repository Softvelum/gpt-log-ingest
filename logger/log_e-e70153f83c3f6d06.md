# DVR export silence sample cannot be buffered

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-e70153f83c3f6d06

## Log pattern

```text
failed to add silence sample=%d/%u period=%u stream=%s utc_start=%llu utc_end=%llu
```

## Parameters

- Argument 1 — Sample index: Zero-based index of the silence sample being appended.
- Argument 2 — Silence count: Unsigned number of silence samples in the gap.
- Argument 3 — Recording period: Integer identifier of the continuous recording period.
- Argument 4 — Stream: Text naming the application and stream.
- Argument 5 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 6 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add silence sample=0/10 period=1 stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

DVR export silence sample cannot be buffered.

## Trigger condition

A silence sample added to align audio with video cannot be written to the output buffer.

## Explanation

The export closes.

## Possible causes

- A silence sample added to align audio with video cannot be written to the output buffer.

## What to check

1. Check buffer capacity and memory errors while filling the audio gap.

## Recommended action

Check buffer capacity and memory errors while filling the audio gap.
