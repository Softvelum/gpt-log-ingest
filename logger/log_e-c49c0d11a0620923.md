# Cannot set accepted SRT connection nonblocking

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-c49c0d11a0620923

## Log pattern

```text
set non blocking failed s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set non blocking failed s=101
```

## Short description

Cannot set accepted SRT connection nonblocking.

## Trigger condition

Configuring an accepted publisher or receiver socket for nonblocking operation fails.

## Explanation

The connection is rejected or the sender enters shutdown; it is not installed for normal media handling.

## Possible causes

- Configuring an accepted publisher or receiver socket for nonblocking operation fails.

## What to check

1. Inspect preceding SRT socket-option diagnostics.
