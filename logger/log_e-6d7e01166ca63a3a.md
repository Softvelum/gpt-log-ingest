# Playlist AC-3 or E-AC-3 packet processing failed

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-6d7e01166ca63a3a

## Log pattern

```text
ServerBlockProcessor: AC3_Reader::processAC3Bitstream failed for vod file [%s], stream=[%s/%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

The original AC-3 parsing message is also used when E-AC-3 output processing fails.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: AC3_Reader::processAC3Bitstream failed for vod file [/media/program.mp4], stream=[live/camera]
```

## Short description

Playlist AC-3 or E-AC-3 packet processing failed.

## Trigger condition

AC-3 parsing fails, produces no complete frames, leaves a partial frame, or output processing rejects an E-AC-3 packet.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- AC-3 parsing fails, produces no complete frames, leaves a partial frame, or output processing rejects an E-AC-3 packet.

## What to check

1. Check AC-3 or E-AC-3 frame boundaries and preceding audio-processing errors.

## Recommended action

Check AC-3 or E-AC-3 frame boundaries and preceding audio-processing errors.
