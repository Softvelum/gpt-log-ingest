# UDP receive buffer size was rejected

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-26350de669903c9e

## Log pattern

```text
failed to set receive buffer size, errno=%d socket=%d buffer_size=%d
```

## Parameters

- Argument 1 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.
- Argument 2 — Socket: Socket descriptor, integer; no unit.
- Argument 3 — Buffer size: Requested operating system UDP socket buffer size in bytes, integer.

Generic UDP receive always attempts its configured value; generic send does so for nonnegative values. HTTP/3 attempts either option only for positive values. All sizes are bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set receive buffer size, errno=5 socket=12 buffer_size=262144
```

## Short description

UDP receive buffer size was rejected.

## Trigger condition

Setting the requested UDP receive buffer size fails. This also occurs while setting HTTP/3 UDP buffers in an HTTP/3-enabled build.

## Explanation

The socket buffer setup returns failure. HTTP/3 setup stops applying further options to the socket list.

## Possible causes

- The operating system rejected the requested socket buffer size.

## What to check

1. Check the requested byte size and socket error.

## Recommended action

Use a supported socket buffer size or resolve the reported socket error.
