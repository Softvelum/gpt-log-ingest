# Socket closure event received

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-bae43850b1a99f53

## Log pattern

```text
connection closed by s=%d (ev=0x%x)
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the local socket.
- Argument 2 — Socket events: Hexadecimal mask of events reported for the socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed by s=17 (ev=0x10)
```

## Short description

Socket closure event received.

## Trigger condition

An advertising download receives a connection-closed event, or an HTTP/1 WebSocket sender receives a hangup or error event.

## Explanation

The download is marked finished, or the WebSocket sender enters shutdown state.

## Possible causes

- An advertising download receives a connection-closed event, or an HTTP/1 WebSocket sender receives a hangup or error event.

## What to check

1. Check the affected peer connection and nearby download or sender errors.

## Recommended action

Check the affected peer connection and nearby download or sender errors.
