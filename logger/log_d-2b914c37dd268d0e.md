# Initial origin body bytes copied to cache

Product: Nimble Streamer
Component: Background origin download
Logging function: log_d
Log level: debug
Documentation ID: log_d-2b914c37dd268d0e

## Log pattern

```text
received %lld of %llu body bytes from %s s=%d
```

## Parameters

- Argument 1 — received: Initial body bytes copied.
- Argument 2 — expected: Declared total body length.
- Argument 3 — peer: Peer role label.
- Argument 4 — socket: Origin socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
received 512 of 4096 body bytes from origin s=12
```

## Short description

Initial origin body bytes copied to cache.

## Trigger condition

The completed origin header already includes some response body bytes.

## Explanation

Those bytes are copied into the allocated cache buffer. If they fill the declared response length, the downloader finishes; otherwise it begins reading the remaining body.
