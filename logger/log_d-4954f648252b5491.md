# Client session finished after download handoff

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-4954f648252b5491

## Log pattern

```text
finishing session p=%p s=%d
```

## Parameters

- Argument 1 — Session address: Pointer identifying this client session within the process.
- Argument 2 — Client socket: Integer client descriptor, nonpositive because the client has gone.

## Log examples

Illustrative examples; these are not captured server logs.

```text
finishing session p=0x1234 s=-1
```

## Short description

Client session finished after download handoff.

## Trigger condition

After a media cache item is completed or handed to a background downloader, the client descriptor is already nonpositive.

## Explanation

The client session is marked finished; the cache item or independent download can serve other clients.

## Possible causes

- After a media cache item is completed or handed to a background downloader, the client descriptor is already nonpositive.

1. Not applicable; this is normal diagnostic progress. Use the socket identifier to follow the same request if troubleshooting.

Not applicable; this is normal diagnostic progress. Use the socket identifier to follow the same request if troubleshooting.
