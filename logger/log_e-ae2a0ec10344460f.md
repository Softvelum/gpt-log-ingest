# Session client address is absent from tracking

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-ae2a0ec10344460f

## Log pattern

```text
failed to find session ip='%s' for session id=%d type=%d
```

## Parameters

- Argument 1 — client: Client IP address.
- Argument 2 — session: Numeric playback session identifier.
- Argument 3 — type: Numeric playback protocol.

The unsigned-long session identifier is passed to a signed-int conversion, so its printed representation is not reliable across platforms.

## Log examples

No portable example is provided for the mismatched session identifier conversion.

## Short description

Session client address is absent from tracking.

## Trigger condition

Deleting a session with a nonempty client address finds no address entry.

## Explanation

The address cleanup returns immediately; the caller continues the session-removal operation.

## Possible causes

- The client-address index lacks the session address.

## What to check

1. Compare earlier registration and deletion messages for the client.

## Recommended action

Investigate the inconsistent client-address index.
