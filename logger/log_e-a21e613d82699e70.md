# Named filter input was not found

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-a21e613d82699e70

## Log pattern

```text
failed to get filter input=%s from filter=%s, stream=%s
```

## Parameters

- Argument 1 — Input name: Configured input label, text.
- Argument 2 — Filter: Complete configured filter expression, text.
- Argument 3 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get filter input=input1 from filter=[in]anull[out], stream=live/camera
```

## Short description

Named filter input was not found.

## Trigger condition

The configured input name is absent from the parsed audio or video filter inputs.

## Explanation

Input setup fails and the frame is not processed.

## Possible causes

- The input label does not match an exposed filter input.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
