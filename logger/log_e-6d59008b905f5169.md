# AV1 live codec initialization failed

Product: Nimble Streamer
Component: MPEG-TS video conversion
Logging function: log_e
Log level: error
Documentation ID: log_e-6d59008b905f5169

## Log pattern

```text
MPEG2TSLiveStream::processAv1VideoMessageInternal, set_video_codec_av1 failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
MPEG2TSLiveStream::processAv1VideoMessageInternal, set_video_codec_av1 failed
```

## Short description

AV1 live codec initialization failed.

## Trigger condition

A changed nonempty AV1 sequence header was stored and converted into a configuration record, but installing that codec configuration in the live stream returned false.

## Explanation

The converter returns false before forwarding this assembled frame. Direct MPEG-TS input processing then resets video initialization and assembly state. Earlier sequence-header parsing or configuration-record construction failures return without this particular message.

## Possible causes

- The live stream rejected the newly built AV1 codec configuration.

## What to check

1. Check earlier AV1 configuration diagnostics and the input sequence header.

## Recommended action

Correct the indicated AV1 codec-configuration problem.
