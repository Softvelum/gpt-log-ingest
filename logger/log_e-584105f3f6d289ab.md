# Audio chunk name has an invalid index

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-584105f3f6d289ab

## Log pattern

```text
invalid audio chunk requested name='%s'
```

## Parameters

- Argument 1 — Audio chunk name: Text requested audio chunk name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid audio chunk requested name='n_bad.ts'
```

## Short description

Audio chunk name has an invalid index.

## Trigger condition

An MP3 or AAC output request is not a playlist and its chunk name fails the n_<number>.ts parser or numeric limit.

## Explanation

The output is canceled and released, and a local input mapping is closed.

## Possible causes

- An MP3 or AAC output request is not a playlist and its chunk name fails the n_<number>.ts parser or numeric limit.

## What to check

1. Use an unmodified n_<number>.ts resource from the generated audio playlist.

## Recommended action

Use an unmodified n_<number>.ts resource from the generated audio playlist.
