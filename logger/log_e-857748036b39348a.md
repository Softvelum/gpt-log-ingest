# Socket address reuse could not be enabled

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-857748036b39348a

## Log pattern

```text
setsockopt SO_REUSEADDR failed for s=%d errno=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
setsockopt SO_REUSEADDR failed for s=12 errno=5
```

## Short description

Socket address reuse could not be enabled.

## Trigger condition

Enabling local address reuse on a socket fails.

## Explanation

The helper logs the error and returns; listener setup is not stopped by this helper.

## Possible causes

- The operating system rejected the address-reuse option.

## What to check

1. Check the socket error.

## Recommended action

Investigate the option failure if listener binding is affected.
