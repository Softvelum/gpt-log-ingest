# Hardware decoder input parameters prepared

Product: Nimble Streamer
Component: FFmpeg video decoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-04bd206e6b7004e7

## Log pattern

```text
set decoder params: decoder=%s, w=%d, h=%d, pix_fmt=%d, framerate=%d/%d for [%s]
```

## Parameters

- Argument 1 — Decoder: Selected hardware decoder name, text.
- Argument 2 — Width: Configured width in pixels, integer.
- Argument 3 — Height: Configured height in pixels, integer.
- Argument 4 — Format: FFmpeg sample or pixel format identifier, integer; an enumeration rather than a bit depth.
- Argument 5 — Frame-rate numerator: Frame-rate rational numerator, integer.
- Argument 6 — Frame-rate denominator: Frame-rate rational denominator, integer.
- Argument 7 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set decoder params: decoder=h264_ama, w=1920, h=1080, pix_fmt=0, framerate=25/1 for [live/camera]
```

## Short description

Hardware decoder input parameters prepared.

## Trigger condition

In an MA35D-enabled build, hardware decoder parameters have been derived from codec configuration or the first VP9 packet.

## Explanation

The dimensions, pixel format, and frame rate are reported before opening the decoder; this is not a success report for opening.
