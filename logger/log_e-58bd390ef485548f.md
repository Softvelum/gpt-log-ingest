# Managed task child process creation failed

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-58bd390ef485548f

## Log pattern

```text
fork() failed for task='%s' errno=%d
```

## Parameters

- Argument 1 — Command: Configured shell command text.
- Argument 2 — System error: Integer operating-system error value; it may be stale unless the preceding operation failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
fork() failed for task='echo ready' errno=11
```

## Short description

Managed task child process creation failed.

## Trigger condition

Both task pipes exist, but creating the child process fails. Available only on Linux builds.

## Explanation

All four pipe ends are closed and task startup returns failure.

## Possible causes

- The operating system rejected child process creation.

## What to check

1. Inspect the reported process-creation error.
