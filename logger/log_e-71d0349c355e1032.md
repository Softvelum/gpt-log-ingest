# MKV source preparation failed

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-71d0349c355e1032

## Log pattern

```text
failed to open and map mkv file='%s'
```

## Parameters

- Argument 1 — MKV filename: Text filesystem path of the requested MKV source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open and map mkv file='/media/movie.mkv'
```

## Short description

MKV source preparation failed.

## Trigger condition

The MKV source preparation helper returns failure before the requested HLS output can be generated.

## Explanation

The output cache item is canceled and released; preceding diagnostics distinguish mapping from media-structure failures.

## Possible causes

- The MKV source preparation helper returns failure before the requested HLS output can be generated.

## What to check

1. Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.

## Recommended action

Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.
