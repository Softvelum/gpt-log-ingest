# Audio frame encoding failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-72d5ae9912c05325

## Log pattern

```text
failed to encode audio frame for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encode audio frame for [live/encoded]
```

## Short description

Audio frame encoding failed.

## Trigger condition

The active audio encoder returns failure when writing a decoded audio frame.

## Explanation

The encoder worker stops processing the output.

## Possible causes

- Audio codec initialization, conversion, allocation, encoding, or encoded-packet delivery failed.

## What to check

1. Check preceding audio codec and destination diagnostics and input sample properties.

## Recommended action

Correct the specific audio failure and restart the affected output.
