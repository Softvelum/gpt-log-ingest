# Quick Sync frame decoding failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-0ca4b89c36582b58

## Log pattern

```text
failed to decode frame, status=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode frame, status=-3
```

## Short description

Quick Sync frame decoding failed.

## Trigger condition

Asynchronous decoding returns a status other than success, changed parameters, more data, more surface, or the device-busy retry status.

## Explanation

The current packet-writing operation returns failure.

## Possible causes

- The media runtime cannot decode the submitted bitstream under the active session.

## What to check

1. Check the reported status and input integrity; device-busy statuses are retried separately.

## Recommended action

Correct the bitstream or media device failure and restart decoding.
