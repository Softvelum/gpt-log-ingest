# MPEG-TS boundary chunk has no usable extension

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-e470b59184900894

## Log pattern

```text
failed to get chunk='%s' extension
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get chunk='/app/stream/ad_1.ts' extension
```

## Short description

MPEG-TS boundary chunk has no usable extension.

## Trigger condition

The source MPEG-TS chunk name does not provide an extension for naming the new section.

## Explanation

The remainder request is marked failed.

## Possible causes

- The source MPEG-TS chunk name does not provide an extension for naming the new section.

## What to check

1. Check the source chunk name and extension.

## Recommended action

Check the source chunk name and extension.
