# URL ciphertext decryption failed

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-855d6b1ef570e1c0

## Log pattern

```text
EVP_DecryptUpdate() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
EVP_DecryptUpdate() failed
```

## Short description

URL ciphertext decryption failed.

## Trigger condition

During encrypted-link validation, processing the decoded ciphertext fails.

## Explanation

Validation returns failure and no URL is assigned.

## Possible causes

- The cryptographic library reports that the cipher rejected the encrypted URL data.

## What to check

1. Check matching encrypted-link data and session key, and available cryptographic library operations.

## Recommended action

Resolve the failed decryption or digest operation before accepting the link.
