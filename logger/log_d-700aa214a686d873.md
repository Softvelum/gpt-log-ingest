# Remote VOD input needs another cache fragment

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-700aa214a686d873

## Log pattern

```text
LoadNextChunkException item key='%s' index=%d
```

## Parameters

- Argument 1 — Source cache key: Text identifying the remote media whose bytes are needed.
- Argument 2 — Required fragment index: Native-size unsigned zero-based source-fragment index, incorrectly printed with %d.

The required fragment index has native-size unsigned type but is passed to %d. The printed index is unreliable on platforms where size_t is wider than int.

## Log examples

The required fragment index has native-size unsigned type but is passed to %d. The printed index is unreliable on platforms where size_t is wider than int.

## Short description

Remote VOD input needs another cache fragment.

## Trigger condition

Media parsing or generation raises a missing-fragment condition for a remote VOD source.

## Explanation

The worker requests that source fragment and registers the output request to resume after a cache update. Failure to queue the fragment or register the observer instead cancels output.

## Possible causes

- Media parsing or generation raises a missing-fragment condition for a remote VOD source.

## What to check

1. A brief wait is normal. If packaging stalls, check the matching remote range download and cache notification.

## Recommended action

A brief wait is normal. If packaging stalls, check the matching remote range download and cache notification.
