# Advertising rule references unknown content

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-05c33eccc60c7632

## Log pattern

```text
failed to find content.id=%s in content list, added empty content to rule.id=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Rule ID: Text identifying the advertising rule.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find content.id=ad-01 in content list, added empty content to rule.id=rule-01
```

## Short description

Advertising rule references unknown content.

## Trigger condition

A content identifier in an advertising rule is absent from the current content registry.

## Explanation

An empty content object is inserted into the rule, retaining its wait and error policy.

## Possible causes

- A content identifier in an advertising rule is absent from the current content registry.

## What to check

1. Include the referenced content identifier and its URI in the advertising content list.

## Recommended action

Include the referenced content identifier and its URI in the advertising content list.
