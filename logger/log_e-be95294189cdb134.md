# RTMP publishing falls behind the retained media buffer

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-be95294189cdb134

## Log pattern

```text
failed to send stream in appropriate rate. s: %d, %s:%d/%s/%s
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Destination host: Publishing destination hostname or address.
- Argument 3 — Destination port: Publishing destination TCP port.
- Argument 4 — Application: Destination application name.
- Argument 5 — Stream: Destination stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send stream in appropriate rate. s: 42, destination.example:1935/live/camera
```

## Short description

RTMP publishing falls behind the retained media buffer.

## Trigger condition

The next required media item is older than the oldest item still retained in the stream buffer.

## Explanation

The publisher cannot continue from its current position, returns failure, and its connection is shut down.

## Possible causes

- The next required media item is older than the oldest item still retained in the stream buffer.

## What to check

1. Check destination receive speed, network throughput, and whether the publishing route is keeping pace with the source.

## Recommended action

Restore enough output capacity for the stream rate before reconnecting.
