# Common-encryption initialization is waiting for a usable key

Product: Nimble Streamer
Component: DRM key management
Logging function: log_v
Log level: verbose
Documentation ID: log_v-bba4c2817680d800

## Log pattern

```text
[drm] Widevine key for '%s/%s' is not available (%s)
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Key availability: Text stating missing when no matching key exists or never updated when its slot has not received a usable key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine key for 'live/camera' is not available (never updated)
```

## Short description

Common-encryption initialization is waiting for a usable key.

## Trigger condition

Initialization is queried without error-level logging and the selected key is missing or has never been updated.

## Explanation

Initialization reports failure for this query. This verbose message can occur while stream codec initialization checks for keys; it also covers CPIX-based providers.

## Possible causes

- Initialization is queried without error-level logging and the selected key is missing or has never been updated.

## What to check

1. Check whether the pending provider request later supplies the required key.

## Recommended action

Check whether the pending provider request later supplies the required key.
