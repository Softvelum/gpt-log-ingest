# External response completed by connection closure

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_d
Log level: debug
Documentation ID: log_d-cf314d5c9a40a990

## Log pattern

```text
processing response size=%u after s=%d closed connection:
%.*s
```

## Parameters

- Argument 1 — size: Bytes accumulated in the initial response buffer.
- Argument 2 — socket: Peer socket descriptor.
- Argument 3 — header length: Maximum number of header bytes requested for printing.
- Argument 4 — headers: Response header text, limited by the supplied precision.

The size and header precision are platform-sized values passed to 32-bit unsigned and int conversions.

## Log examples

No portable example is provided because these byte-count arguments do not match their conversions.

## Short description

External response completed by connection closure.

## Trigger condition

A zero-byte read follows complete headers without Content-Length and with a close connection header.

## Explanation

The available response is passed to the requester according to its status; 200 and 206 are accepted. The printed count is the accumulated header-read buffer size, not necessarily the entire body size.
