# GeoIP archive member read was incomplete

Product: Nimble Streamer
Component: GeoIP database updates
Logging function: log_e
Log level: error
Documentation ID: log_e-d0331578373c8ed1

## Log pattern

```text
failed to read %s from %s
```

## Parameters

- Argument 1 — member: Expected database filename inside the archive.
- Argument 2 — archive: Downloaded GeoIP archive path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read GeoLite2-Country.mmdb from /var/cache/geo/update.jar
```

## Short description

GeoIP archive member read was incomplete.

## Trigger condition

The archive member read returns a count different from its expected size.

## Explanation

The member and archive are closed and extraction fails; the active GeoIP database is not updated by this attempt.

## Possible causes

- The archive database member could not be read completely.

## What to check

1. Check for a damaged or incomplete downloaded archive.

## Recommended action

Obtain a complete valid archive and retry the update.
