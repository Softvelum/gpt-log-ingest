# SRT bonding entry points unavailable

Product: Nimble Streamer
Component: SRT transport
Logging function: log_i
Log level: info

## Log pattern

```text
SRT bonding is not supported (requires SRT 1.5)
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

SRT bonding entry points unavailable.

## Trigger condition

Resolving the optional SRT bonding entry points throws an exception.

## Explanation

Group support is disabled while the ordinary SRT library loading can still succeed. The diagnostic identifies SRT 1.5 as the required generation.

## Possible causes

- Resolving the optional SRT bonding entry points throws an exception.

## What to check

1. Check the loaded SRT library version and whether it contains bonding support.

## Recommended action

Use an SRT library with bonding support if bonded connections are required.
