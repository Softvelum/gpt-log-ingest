# Audio filter output could not be created

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-9f5b71182ead9a75

## Log pattern

```text
failed to create abuffersink, %s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create abuffersink, [in]anull[out]
```

## Short description

Audio filter output could not be created.

## Trigger condition

Creating a sink for a parsed audio output returns a negative result.

## Explanation

Audio filter initialization fails.

## Possible causes

- FFmpeg rejected creation of the audio output sink.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
