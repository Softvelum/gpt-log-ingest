# Limelight authentication description cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-ca8433a298700c14

## Log pattern

```text
cannot get limelight description
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot get limelight description
```

## Short description

Limelight authentication description cannot be decoded.

## Trigger condition

A Limelight authentication error response contains a description field that cannot be read as an AMF string.

## Explanation

Challenge parsing stops without accepting a nonce from this field. The enclosing authentication error-response path ends the connection.

## Possible causes

- A Limelight authentication error response contains a description field that cannot be read as an AMF string.

## What to check

1. Inspect the description field in the destination authentication response.

## Recommended action

Correct the malformed challenge response at the publish destination.
