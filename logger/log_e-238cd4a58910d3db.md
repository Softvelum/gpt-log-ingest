# NVIDIA encoder initialization failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-238cd4a58910d3db

## Log pattern

```text
failed to init encoder=%p, status=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init encoder=0x12340000, status=8
```

## Short description

NVIDIA encoder initialization failed.

## Trigger condition

The driver rejects initialization using the completed codec, preset, dimensions, frame rate and encoding options.

## Explanation

Encoder setup returns failure and the input frame is not encoded.

## Possible causes

- The combined encoding configuration is unsupported or the device cannot allocate the required encoder resources.

## What to check

1. Check the status and the full selected encoding configuration, including GPU capacity.

## Recommended action

Correct unsupported options or restore encoder resources.
