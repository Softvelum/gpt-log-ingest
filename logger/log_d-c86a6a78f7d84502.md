# Client connection accepted

Product: Nimble Streamer
Component: HTTP listener
Logging function: log_d
Log level: debug
Documentation ID: log_d-c86a6a78f7d84502

## Log pattern

```text
accepted s=%d (%s:%d ssl=%d)
```

## Parameters

- Argument 1 — Socket: Integer descriptor of the accepted connection.
- Argument 2 — Client address: Text IP address of the connected peer.
- Argument 3 — Client port: Integer peer port.
- Argument 4 — TLS: Integer flag: 1 for a TLS listening socket, 0 otherwise.

## Log examples

Illustrative examples; these are not captured server logs.

```text
accepted s=12 (192.0.2.10:40000 ssl=1)
```

## Short description

Client connection accepted.

## Trigger condition

A nonblocking accept succeeds and debug logging is enabled.

## Explanation

The new connection is about to be submitted to the worker queue. Queue acceptance and successful request processing have not yet been established.
