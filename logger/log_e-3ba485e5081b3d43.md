# Media reader loop option could not be set

Product: Nimble Streamer
Component: FFmpeg logging and media input
Logging function: log_e
Log level: error
Documentation ID: log_e-3ba485e5081b3d43

## Log pattern

```text
failed to set options
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set options
```

## Short description

Media reader loop option could not be set.

## Trigger condition

Adding the loop option to the FFmpeg option dictionary returns a nonzero result.

## Explanation

Opening the media input stops before the file is opened.

## Possible causes

- The option dictionary update failed.

## What to check

1. Check FFmpeg diagnostics for the option allocation failure.

## Recommended action

Correct the input or requested media setting and retry.
