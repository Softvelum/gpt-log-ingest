# Video codec is unsupported for the requested operation

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-4a25348e0b85697d

## Log pattern

```text
unsupported video codec=%d
```

## Parameters

- Argument 1 — Codec identifier: Integer codec value; scenario media and DVR archive paths use different codec enumerations.

This shared format covers scenario codec setup and DVR video blackout. The numeric identifier cannot be interpreted without its context.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video codec=0
```

## Short description

Video codec is unsupported for the requested operation.

## Trigger condition

Scenario input codec setup receives an unrecognized codec, or DVR blackout is requested for video other than H.264 or H.265.

## Explanation

Scenario setup returns failure before installing that video codec. DVR blackout returns failure before replacing the stored video segment. The accepted codec sets differ between these operations.

## Possible causes

- Scenario input codec setup receives an unrecognized codec, or DVR blackout is requested for video other than H.264 or H.265.

## What to check

1. Identify whether the message concerns scenario input or DVR blackout and check that operation codec support.

## Recommended action

Use a codec supported by the requested operation.
