# Remote fragment request is already active

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-807aa4565f82518c

## Log pattern

```text
request for item key='%s' fi=%u is already active
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — fragment: Zero-based fragment index.

The fragment index is a platform-sized value passed to a 32-bit unsigned conversion.

## Log examples

No portable example is provided for the mismatched fragment-index conversion.

## Short description

Remote fragment request is already active.

## Trigger condition

An active request for the same item has the same byte range.

## Explanation

The duplicate request reports queued status and relies on the existing download; it releases the caller reference when ownership is transferred.
