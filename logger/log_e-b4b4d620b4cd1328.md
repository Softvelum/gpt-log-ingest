# Could not create the geolocation update worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-b4b4d620b4cd1328

## Log pattern

```text
failed to create GeoDB update thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create GeoDB update thread
```

## Short description

Could not create the geolocation update worker.

## Trigger condition

No update worker exists, updates are not disabled, the database is required or updates are enabled, and thread creation fails.

## Explanation

The failed worker object is deleted and the saved pointer is cleared. Server startup or operation continues; a later call can try again.

## Possible causes

- Creation of the database update worker failed.

## What to check

1. Inspect the preceding thread resource error.
