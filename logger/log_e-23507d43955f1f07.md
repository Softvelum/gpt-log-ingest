# Cannot observe required cache updates

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-23507d43955f1f07

## Log pattern

```text
failed to add observer for key=%s
```

## Parameters

- Argument 1 — Reported cache key: Text identifying the affected cache resource. One remote SMIL branch prints the request resource key while attempting to observe its underlying SMIL key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add observer for key=/vod/movie.mp4
```

## Short description

Cannot observe required cache updates.

## Trigger condition

Registering an observer fails for a pending advertising, VOD, SMIL, DVR, restreamed, downloaded, or fragmented response item.

## Explanation

Most request setup branches prepare HTTP 500. Failure during HTTP/2 or HTTP/3 body preparation instead causes an internal-error stream reset; the connection is failed if that reset cannot be queued.

## Possible causes

- Registering an observer fails for a pending advertising, VOD, SMIL, DVR, restreamed, downloaded, or fragmented response item.

## What to check

1. Correlate this key with cache reservation, cancellation, and download messages; the request cannot safely wait for the needed update.

## Recommended action

Correlate this key with cache reservation, cancellation, and download messages; the request cannot safely wait for the needed update.
