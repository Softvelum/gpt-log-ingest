# Remote log settings response has the wrong JSON type

Product: Nimble Streamer
Component: Remote log reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-9b6cd21425ef0d44

## Log pattern

```text
failed to process response: '%s'
```

## Parameters

- Argument 1 — Response body: Complete text of the received response.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process response: '[]'
```

## Short description

Remote log settings response has the wrong JSON type.

## Trigger condition

The response parses successfully as JSON but is not an object.

## Explanation

The parsed value is released and this response is ignored. The loop continues without applying new settings.

## Possible causes

- The response is a JSON value other than an object.

## What to check

1. Check that the response has an object at its top level.

## Recommended action

Return an object containing the remote log reporting settings.
