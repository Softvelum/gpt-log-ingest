# New playback request has an unsupported resource URL

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-ea89fc26349b9e35

## Log pattern

```text
invalid URL '%s' (not a playlist or supported video)
```

## Parameters

- Argument 1 — Request URL: Text of the public resource URL that failed the initial-session resource check.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid URL '/live/camera/segment1.ts' (not a playlist or supported video)
```

## Short description

New playback request has an unsupported resource URL.

## Trigger condition

Session-tracked playback begins with a resource that is not an accepted playlist or supported media file, or a new live HLS session requests a path without the required playlist suffix.

## Explanation

HTTP 404 is prepared even though a media route was found.

## Possible causes

- Session-tracked playback begins with a resource that is not an accepted playlist or supported media file, or a new live HLS session requests a path without the required playlist suffix.

## What to check

1. Start playback from the appropriate playlist or supported media URL and retain its session parameter on later segment requests.

## Recommended action

Start playback from the appropriate playlist or supported media URL and retain its session parameter on later segment requests.
