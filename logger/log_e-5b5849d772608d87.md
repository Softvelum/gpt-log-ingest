# Caption rewrite cannot copy an AVC NAL unit

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-5b5849d772608d87

## Log pattern

```text
failed to write nalu to avcc buffer with cea708 subs for [%s/%s], used_size=%u, nal_size=%d
```

## Parameters

- Argument 1 — First string slot: Actually receives the numeric used-buffer byte count instead of an application string.
- Argument 2 — Second string slot: Actually receives the numeric NAL length instead of a stream string.
- Argument 3 — Unsigned slot: Actually receives the application string pointer instead of used bytes.
- Argument 4 — Integer slot: Actually receives the stream string pointer instead of NAL bytes.

## Log examples

No valid exact example can be supplied: the two %s arguments are integers and the numeric arguments are string pointers.

## Short description

Caption rewrite cannot copy an AVC NAL unit.

## Trigger condition

Writing the NAL length or payload into the caption-rewrite buffer fails.

## Explanation

The intended path abandons caption rewriting and retains the original frame, but this log call supplies numeric byte counts to both string fields and string pointers to both numeric fields, so formatting itself is invalid.

## Possible causes

- Writing the NAL length or payload into the caption-rewrite buffer fails.

## What to check

1. Check caption-rewrite buffer capacity and the malformed logging argument order.

## Recommended action

Resolve the rewrite-buffer failure; reliable output also requires correction of the logging argument order.
