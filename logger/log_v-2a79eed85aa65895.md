## Short description

Panel requested DVR timelines.

## Trigger condition

The successfully received synchronization response produced a nonempty set of requested timeline streams.

## Explanation

Timeline request processing begins next. It can return without posting if there is no DVR status to report, so this message alone does not confirm an upload.
