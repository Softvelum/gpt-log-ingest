# Cannot update SRT event interest

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-f395b62e9fe98999

## Log pattern

```text
srt_epoll_update_usock epfd=%d failed for fd=%d flags=0x%x: %s)
```

## Parameters

- Argument 1 — Poller: SRT event-poller identifier.
- Argument 2 — Socket: SRT socket or group identifier.
- Argument 3 — Events: SRT event-interest bit mask in hexadecimal; input is 0x1, output 0x4, and error 0x8.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_epoll_update_usock epfd=1 failed for fd=100 flags=0x9: Invalid socket ID)
```

## Short description

Cannot update SRT event interest.

## Trigger condition

The SRT library rejects the request to update a socket and its event-interest flags.

## Explanation

The selector operation reports failure to its caller; the requested monitoring change is not confirmed.

## Possible causes

- The SRT library rejects the request to update a socket and its event-interest flags.

## What to check

1. Match the socket and event mask with the expected connection state.
