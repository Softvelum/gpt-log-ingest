# Publisher-control JSON contains an unexpected member

Product: Nimble Streamer
Component: Publisher authorization and management publish denial
Logging function: log_e
Log level: error
Documentation ID: log_e-4e46af45549e15d0

## Log pattern

```text
wrong response. json='%s'
```

## Parameters

- Argument 1 — json\_input: Complete authorization response or management request body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wrong response. json='{"unexpected":[]}'
```

## Short description

Publisher-control JSON contains an unexpected member.

## Trigger condition

Publisher authorization finds a top-level member other than PublishAuthResponse, or the management deny endpoint finds one other than PublishControlDenyRequest.

## Explanation

Authorization response processing discards the result and applies each request default policy. The management endpoint instead releases the JSON value, attempts HTTP 404, and returns without applying the gathered deny list.

## Possible causes

- An unexpected top-level member is present.

## What to check

1. Check the top-level member name against the operation being performed.

## Recommended action

Send only the expected top-level member for this operation.
