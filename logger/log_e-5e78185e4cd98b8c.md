# Registration rules exceed the size limit

Product: Nimble Streamer
Component: Server registration utility
Logging function: log_e
Log level: error
Documentation ID: log_e-5e78185e4cd98b8c

## Log pattern

```text
apply-rules-conf specified but rules.conf is too long ='%d'
```

## Parameters

- Argument 1 — bytes: Loaded rules document length in bytes.

The platform-sized string length is passed to a signed-int conversion.

## Log examples

No portable example is provided for the length argument mismatch.

## Short description

Registration rules exceed the size limit.

## Trigger condition

Registration with rule application loads a rules document larger than 500 KiB.

## Explanation

The utility exits with failure before parsing the rules or sending a registration request.

## Possible causes

- The loaded rules document exceeds 512,000 bytes.

## What to check

1. Check the size of the rules document selected for registration.

## Recommended action

Reduce the document to the supported size before registering with rule application.
