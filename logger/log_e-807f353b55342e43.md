# Cannot buffer generated Icecast metadata

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-807f353b55342e43

## Log pattern

```text
cannot allocate generated_metadata buffer for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name.
- Argument 2 — Stream: Stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot allocate generated_metadata buffer for [live/radio]
```

## Short description

Cannot buffer generated Icecast metadata.

## Trigger condition

Writing the position marker, size byte, or generated metadata payload fails.

## Explanation

Construction of the chunk with generated metadata stops and that chunk is not published.

## Possible causes

- Writing the position marker, size byte, or generated metadata payload fails.

## What to check

1. Check generated metadata sizes and buffer allocation.
