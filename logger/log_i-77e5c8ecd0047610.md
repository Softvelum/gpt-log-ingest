# x264 input needs pixel format conversion

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_i
Log level: info
Documentation ID: log_i-77e5c8ecd0047610

## Log pattern

```text
unsupported frame format=%d, format converter will be used for [%s]
```

## Parameters

- Argument 1 — Format: FFmpeg sample or pixel format identifier, integer; an enumeration rather than a bit depth.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported frame format=0, format converter will be used for [live/camera]
```

## Short description

x264 input needs pixel format conversion.

## Trigger condition

The input format is outside the directly handled planar 4:2:0/4:2:2 or NV12 formats.

## Explanation

Encoder parameters select NV12; frames are converted before encoding.
