# AAC frame encoding failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-d568c76525ca9956

## Log pattern

```text
failed to encoder frame, status=%d
```

## Parameters

- Argument 1 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encoder frame, status=1
```

## Short description

AAC frame encoding failed.

## Trigger condition

FDK returns a non-success status while encoding an input PCM frame.

## Explanation

The current frame write fails before emitting an AAC packet; its input timestamp has already been queued.

## Possible causes

- The AAC library rejected the encoding operation.

## What to check

1. Check the FDK status and current audio parameters.

## Recommended action

Resolve the AAC encoding failure.
