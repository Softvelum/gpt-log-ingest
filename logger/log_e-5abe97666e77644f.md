# AJA output video parameters changed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-5abe97666e77644f

## Log pattern

```text
reset aja output. video params changed [%s]
```

## Parameters

- Argument 1 — Session name: Configured AJA device and channel name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reset aja output. video params changed [0/0]
```

## Short description

AJA output video parameters changed.

## Trigger condition

After video configuration, an incoming frame changes width, height, frame rate, or interlace mode.

## Explanation

Video message processing returns failure; it does not reconfigure the active sender in place.

## Possible causes

- After video configuration, an incoming frame changes width, height, frame rate, or interlace mode.

## What to check

1. Check the source video parameters before and after the change.

## Recommended action

Reinitialize output for the new supported video parameters.
