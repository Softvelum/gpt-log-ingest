# VAAPI cannot write VCL buffering metadata

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-787196d21639c0eb

## Log pattern

```text
vcl hrd parameters not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
vcl hrd parameters not supported
```

## Short description

VAAPI cannot write VCL buffering metadata.

## Trigger condition

The H.264 sequence settings request VCL hypothetical-reference-decoder parameters.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested VCL buffering metadata and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
