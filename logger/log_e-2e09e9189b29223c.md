# Disabled disconnect byte query failed

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-2e09e9189b29223c

## Log pattern

```text
ioctlsocket(s=%d, FIONREAD, bytes_available)
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ioctlsocket(s=12, FIONREAD, bytes_available)
```

## Short description

Disabled disconnect byte query failed.

## Trigger condition

A Windows byte-count query fails in a source branch explicitly disabled at build time.

## Explanation

If enabled, this branch would omit the extra closure flag and continue ordinary input dispatch. It does not run in the current build.

## Possible causes

- The socket byte-count query returned an error.

## Recommended action

No operational action is applicable to this disabled branch.
