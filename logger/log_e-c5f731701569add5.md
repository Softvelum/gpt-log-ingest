# Publisher authorization stopped after an exception

Product: Nimble Streamer
Component: Publisher authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-c5f731701569add5

## Log pattern

```text
std::exception caught what()='%s'
```

## Parameters

- Argument 1 — error: Exception description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
std::exception caught what()='allocation failed'
```

## Short description

Publisher authorization stopped after an exception.

## Trigger condition

A standard exception escapes the authorization request loop.

## Explanation

The exception is logged and the thread stops; this catch does not apply default decisions to remaining requests.

## Possible causes

- An exception escaped request collection or processing.

## What to check

1. Check the exception text and preceding authorization request.

## Recommended action

Investigate the failure that stopped authorization processing.
