# H.264 input frame has no presentation timestamp

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-a6507e7e97d7d25b

## Log pattern

```text
invalid pts
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid pts
```

## Short description

H.264 input frame has no presentation timestamp.

## Trigger condition

The input frame timestamp equals the no-timestamp marker.

## Explanation

The frame is rejected before x264 encoding, even if an override timestamp is supplied.

## Possible causes

- The incoming frame lacks its required presentation timestamp.

## What to check

1. Check timestamp assignment upstream of the encoder.

## Recommended action

Provide frames with valid presentation timestamps.
