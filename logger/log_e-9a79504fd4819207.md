# Video filter input support is unavailable

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-9a79504fd4819207

## Log pattern

```text
failed to get buffer definition, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get buffer definition, filter=[in]null[out], stream=live/camera
```

## Short description

Video filter input support is unavailable.

## Trigger condition

FFmpeg cannot find the video-buffer source filter.

## Explanation

Video input setup fails.

## Possible causes

- The loaded library lacks the required video source filter.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
