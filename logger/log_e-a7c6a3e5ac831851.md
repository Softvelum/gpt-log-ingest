# Origin redirect limit exceeded

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a7c6a3e5ac831851

## Log pattern

```text
reached maximum number of origin redirections (or=%d max=%d)
```

## Parameters

- Argument 1 — Redirect count: Integer incremented number of redirects encountered.
- Argument 2 — Redirect limit: Integer maximum number of allowed redirects.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reached maximum number of origin redirections (or=4 max=3)
```

## Short description

Origin redirect limit exceeded.

## Trigger condition

Following an origin 301 or 302 response would exceed the maximum of three redirections.

## Explanation

The HTTP client prepares HTTP 500 or the cache downloader stops, without connecting to the next location.

## Possible causes

- Following an origin 301 or 302 response would exceed the maximum of three redirections.

## What to check

1. Check origin Location responses for a loop or an unnecessarily long redirect chain.

## Recommended action

Check origin Location responses for a loop or an unnecessarily long redirect chain.
