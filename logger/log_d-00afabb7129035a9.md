# subtitle packet no longer has an accepted type

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-00afabb7129035a9

## Log pattern

```text
updateAvailable subtitle type changed for actual_subtitle_pid_=%d to %d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.
- Argument 2 — stream\_type: Numeric media stream-type code printed in decimal; this is not a packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable subtitle type changed for actual_subtitle_pid_=300 to 27
```

## Short description

subtitle packet no longer has an accepted type.

## Trigger condition

DVB subtitle processing is enabled and the active packet still equals the default, but its advertised type is no longer 89 (DVB subtitle) or 86 (teletext subtitle).

## Explanation

The active identifier is cleared and is not added to the requested packet set by this branch.
