# Managed task output descriptor close failed

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-3368a26a356bba42

## Log pattern

```text
failed to close fd=%d for pid=%d errno=%d
```

## Parameters

- Argument 1 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 2 — Process: Integer task process identifier.
- Argument 3 — System error: Integer operating-system error value; it may be stale unless the preceding operation failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to close fd=12 for pid=1234 errno=9
```

## Short description

Managed task output descriptor close failed.

## Trigger condition

Closing the output descriptor during task stopping or completion returns an error. Available only on Linux builds.

## Explanation

The saved descriptor is invalidated and remaining stop or completion handling continues.

## Possible causes

- The operating system rejected descriptor closure.

## What to check

1. Inspect the returned system error for this output descriptor.
