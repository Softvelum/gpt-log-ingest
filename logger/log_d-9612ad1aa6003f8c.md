# Stored DVR WebVTT segment removal started

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-9612ad1aa6003f8c

## Log pattern

```text
[DvrA::RemWS] p=%u st=%llu f='%s
```

## Parameters

- Argument 1 — Period: Unsigned recording period identifier.
- Argument 2 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 3 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DvrA::RemWS] p=1 st=90000 f='/data/dvr/live/camera/1700000000000.dat
```

## Short description

Stored DVR WebVTT segment removal started.

## Trigger condition

A selected WebVTT entry still has a backing file.

## Explanation

Its database and file references are removed before the language-track entry is erased.

## Possible causes

- A selected WebVTT entry still has a backing file.
