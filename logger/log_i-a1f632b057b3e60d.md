# LAME MP3 encoder library is unavailable

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_i
Log level: info
Documentation ID: log_i-a1f632b057b3e60d

## Log pattern

```text
lame_mp3 encoder is unavailable for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
lame_mp3 encoder is unavailable for live/encoded
```

## Short description

LAME MP3 encoder library is unavailable.

## Trigger condition

The LAME MP3 encoder is requested but its optional library was not loaded successfully.

## Explanation

Audio encoder creation fails; this branch does not use the default encoder even where the message has informational severity.

## Possible causes

- The required optional encoder library is missing or could not load.

## What to check

1. Check the chosen audio backend and preceding library-loading diagnostics.

## Recommended action

Use a compatible available encoder or restore the required library.
