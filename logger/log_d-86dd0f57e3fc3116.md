# RTSP playback request uses an unexpected URI

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-86dd0f57e3fc3116

## Log pattern

```text
Bad uri %s, client %d
```

## Parameters

- Argument 1 — URL: RTSP stream or track URL for the request.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad uri rtsp://192.0.2.1/live/other, client 25
```

## Short description

RTSP playback request uses an unexpected URI.

## Trigger condition

SETUP names neither the advertised video nor audio track, or PLAY names a URI different from the session base URI.

## Explanation

The playback connection requests shutdown. The expected URI depends on whether this is track setup or session playback.

## Possible causes

- SETUP names neither the advertised video nor audio track, or PLAY names a URI different from the session base URI.

## What to check

1. Check that SETUP uses an advertised track URI and PLAY uses the session base URI.

## Recommended action

Use the advertised URI for the requested operation.
