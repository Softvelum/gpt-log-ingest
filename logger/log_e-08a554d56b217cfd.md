# DRMToday merchant identifier is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-08a554d56b217cfd

## Log pattern

```text
Merchant ID must be provided for DRMToday (drmtoday_merchant_id)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Merchant ID must be provided for DRMToday (drmtoday_merchant_id)
```

## Short description

DRMToday merchant identifier is missing.

## Trigger condition

The DRMToday merchant identifier is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The DRMToday merchant identifier is empty.

## What to check

1. Provide the DRMToday merchant identifier.

## Recommended action

Provide the DRMToday merchant identifier.
