# Transport sender settings require reconnection

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_d
Log level: debug
Documentation ID: log_d-fe39f56789b36830

## Log pattern

```text
settings changed for %s:%d
```

## Parameters

- Argument 1 — Destination: Configured destination IP address.
- Argument 2 — Port: Configured destination port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
settings changed for 192.0.2.20:5000
```

## Short description

Transport sender settings require reconnection.

## Trigger condition

Destination, send mode, TTL, local bind settings, protocol parameters, camera ID, or RTP encapsulation differs from current settings.

## Explanation

The sender is marked for shutdown and the settings update returns failure. Printed destination values are the current old values.

## Possible causes

- Destination, send mode, TTL, local bind settings, protocol parameters, camera ID, or RTP encapsulation differs from current settings.

## What to check

1. Compare output connection settings before and after the update.

## Recommended action

No action is needed for intentional connection-setting changes.
