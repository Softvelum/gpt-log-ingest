# Unsupported translation language skipped

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-00f24a9ec965b51e

## Log pattern

```text
unsupported target lang='%s' for [%s]
```

## Parameters

- Argument 1 — Language: Rejected target language code.
- Argument 2 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported target lang='zz' for [live/news]
```

## Short description

Unsupported translation language skipped.

## Trigger condition

A configured target language is absent from the selected service language map.

## Explanation

The target is excluded from the translation request. Other supported targets remain eligible; if none remain, source-language transcription is enabled.

## Possible causes

- A configured target language is absent from the selected service language map.

## What to check

1. Check each configured target language.

## Recommended action

Remove or correct the unsupported target language.
