# Whisper stream limit prevents transcription

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-3d791a47316ac9ae

## Log pattern

```text
failed to transcribe stream=[%s], stream limit (%d) reached
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.
- Argument 2 — stream\_limit: Configured maximum number of Whisper streams, stored as an unsigned 32-bit integer.

The unsigned 32-bit limit is supplied to signed %d. Values within the signed integer range can be represented; larger values have no sound portable signed example.

## Log examples

No example is supplied because the limit type does not match its signed conversion.

## Short description

Whisper stream limit prevents transcription.

## Trigger condition

The number of registered Whisper transcriber streams is at least the configured limit, either before or after loading stream parameters.

## Explanation

The second check covers changes while the parameter loader releases and reacquires a lock. Initialization returns without assigning the Whisper request queue; live stream registration can continue.

## Possible causes

- The Whisper stream count has reached its limit.

## What to check

1. Check the configured limit and active Whisper stream registrations.

## Recommended action

Reduce concurrent Whisper streams or adjust the supported configured limit.
