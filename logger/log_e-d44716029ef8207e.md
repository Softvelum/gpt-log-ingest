# Static HLS encryption key is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-d44716029ef8207e

## Log pattern

```text
key must be provided for 'aes128' protection type
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
key must be provided for 'aes128' protection type
```

## Short description

Static HLS encryption key is missing.

## Trigger condition

An HLS AES-128 group ends with an all-zero key and no external key URL.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- An HLS AES-128 group ends with an all-zero key and no external key URL.

## What to check

1. Provide a valid nonzero AES-128 key.

## Recommended action

Provide a valid nonzero AES-128 key.
