# Unknown returned transcription language

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-4c4590b1c1a81700

## Log pattern

```text
failed to get lang code for lang='%s', stream=[%s]
```

## Parameters

- Argument 1 — Language: Unmapped language returned by the service.
- Argument 2 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get lang code for lang='zz', stream=[live/news]
```

## Short description

Unknown returned transcription language.

## Trigger condition

A KWIKmotion transcript or translation language, or a Speechmatics translation language, has no subtitle language-code mapping.

## Explanation

Processing of the current service result stops without queuing that result as a subtitle. Other later messages can still be processed.

## Possible causes

- A KWIKmotion transcript or translation language, or a Speechmatics translation language, has no subtitle language-code mapping.

## What to check

1. Check the language returned by the service against the selected service language map.
