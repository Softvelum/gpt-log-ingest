# Socket readiness query failed

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-bb1997347756cd08

## Log pattern

```text
select() failed errno=%d max_fd=%d read_fds_.size()=%llu write_fds_.size()=%llu disconnect_fds_.size()=%llu
```

## Parameters

- Argument 1 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.
- Argument 2 — Highest descriptor: Highest descriptor among the monitored sockets, integer.
- Argument 3 — Read count: Number of sockets registered for input, unsigned 64-bit count.
- Argument 4 — Write count: Number of sockets registered for output, unsigned 64-bit count.
- Argument 5 — Disconnect count: Number of sockets registered for disconnect detection, unsigned 64-bit count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
select() failed errno=5 max_fd=12 read_fds_.size()=1 write_fds_.size()=1 disconnect_fds_.size()=0
```

## Short description

Socket readiness query failed.

## Trigger condition

The socket readiness query returns an error.

## Explanation

The current event-processing pass stops before dispatching any events.

## Possible causes

- The operating system rejected the readiness query.

## What to check

1. Check the error code, highest descriptor, and sizes of the read, write, and disconnect sets.

## Recommended action

Resolve the readiness-query error.
