# RTSP H.265 parameter extraction failure branch

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-0d20795601ea832d

## Log pattern

```text
failed to get hevc params, client: %d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

No reachable example is established: the current parameter-extraction operation always reports success.

## Short description

RTSP H.265 parameter extraction failure branch.

## Trigger condition

SDP construction would emit this message if its H.265 parameter extraction reported failure.

## Explanation

The current extraction routine concatenates the available parameter sets and always returns success. This failure branch is present in source, but no ordinary return from the current helper reaches it.
