Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-42cab58845982542

```text
not a GET/POST/HEAD/OPTIONS request
```

Illustrative examples; these are not captured server logs.

## Short description

Unsupported HTTP request method or request form.

## Trigger condition

The request matches none of the supported GET, HEAD, OPTIONS, or enabled WebRTC POST/DELETE forms.

## Explanation

An HTTP 501 response is prepared. The fixed message does not list the conditional DELETE support.

## Possible causes

- The request matches none of the supported GET, HEAD, OPTIONS, or enabled WebRTC POST/DELETE forms.

## What to check

1. Check the request method, WebRTC feature enablement, SDP content type, and WHEP URL where applicable.

## Recommended action

Check the request method, WebRTC feature enablement, SDP content type, and WHEP URL where applicable.
