# NDI no-frame notification could not be forwarded

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-b4292b407a05766b

## Log pattern

```text
failed to write ndi none frame, ndi_name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write ndi none frame, ndi_name=HOST (Camera)
```

## Short description

NDI no-frame notification could not be forwarded.

## Trigger condition

An NDI capture returns no frame and sending the corresponding no-frame message fails.

## Explanation

The receive operation returns failure before updating its inactivity counter. A no-frame capture alone normally continues processing.

## Possible causes

- An NDI capture returns no frame and sending the corresponding no-frame message fails.

## What to check

1. Check the parent-process delivery connection rather than treating the absence of media alone as this error.
