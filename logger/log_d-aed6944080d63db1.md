# TLS shutdown encountered a system error

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-aed6944080d63db1

## Log pattern

```text
failed to SSL_shutdown %s s=%d (SSL_errno=%d errno=%d e='%s')
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Socket: Integer socket descriptor.
- Argument 3 — TLS result: Integer TLS error category returned for the failed operation.
- Argument 4 — System error: Integer operating-system socket error value.
- Argument 5 — TLS detail: Text decoded from the next queued TLS library error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to SSL_shutdown client s=12 (SSL_errno=5 errno=104 e='TLS error')
```

## Short description

TLS shutdown encountered a system error.

## Trigger condition

TLS shutdown returns a system-call error other than the broken-pipe case.

## Explanation

Both the system error and a queued TLS detail are reported, then shutdown returns failure.

## Possible causes

- The underlying TLS shutdown system operation failed.

## What to check

1. Inspect both error categories and the associated TLS detail.
