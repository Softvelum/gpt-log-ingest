# NVIDIA decoded-frame context lock failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-69748c7e858e2ed1

## Log pattern

```text
failed to lock cuda ctx, res=%d
```

## Parameters

- Argument 1 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to lock cuda ctx, res=2
```

## Short description

NVIDIA decoded-frame context lock failed.

## Trigger condition

A shared video context lock is present, but acquiring it before a GPU-to-host frame copy returns an error.

## Explanation

The frame copy fails before either pixel plane is copied.

## Possible causes

- The driver cannot acquire the shared video-context lock.

## What to check

1. Check the CUDA status and shared-context lifecycle.

## Recommended action

Restore a valid shared decoding context before retrying.
