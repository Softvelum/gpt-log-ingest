# Delayed single-stream pull route changed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_i
Log level: info
Documentation ID: log_i-8af89a42668a2788

## Log pattern

```text
live pull task for %s/%s deleted. pull settings changed. app or stream not match
```

## Parameters

- Argument 1 — application: Application of the delayed pull task.
- Argument 2 — stream: Stream of the delayed pull task.

## Log examples

Illustrative examples; these are not captured server logs.

```text
live pull task for live/camera deleted. pull settings changed. app or stream not match
```

## Short description

Delayed single-stream pull route changed.

## Trigger condition

Current single-stream settings have a different application or stream from the task.

## Explanation

The old task is removed and recreation is attempted against current matching settings.
