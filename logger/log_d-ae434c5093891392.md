# Video component settings changed

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_d
Log level: debug
Documentation ID: log_d-ae434c5093891392

## Log pattern

```text
video encoder changed for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

Shared across video-only, combined, waiting-for-audio, and finding-first-audio states; timestamps and keyframe state are reset later in the successful update.

## Log examples

Illustrative examples; these are not captured server logs.

```text
video encoder changed for live/encoded
```

## Short description

Video component settings changed.

## Trigger condition

Video remains enabled and a settings update arrives in a supported existing-video state.

## Explanation

The current video encoder and codec selection are reset, then the updated source or encoder is configured.
