# KeyOS user certificate cannot be read

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-507be0743ca8711c

## Log pattern

```text
failed to load KeyOS user certificate from '%s'
```

## Parameters

- Argument 1 — Credential file: Text naming the KeyOS user certificate file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load KeyOS user certificate from '/data/keyos.pem'
```

## Short description

KeyOS user certificate cannot be read.

## Trigger condition

Reading the configured KeyOS user certificate file fails.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- Reading the configured KeyOS user certificate file fails.

## What to check

1. Correct the KeyOS user certificate path and restore read access.

## Recommended action

Correct the KeyOS user certificate path and restore read access.
