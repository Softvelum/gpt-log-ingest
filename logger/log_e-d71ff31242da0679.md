# Session identifier is missing from its client index

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-d71ff31242da0679

## Log pattern

```text
removed %zu sessions instead of expected 1 for id=%lu ip='%s' type=%u url='%s'
```

## Parameters

- Argument 1 — removed: Number of matching identifiers removed; zero on this path.
- Argument 2 — session: Numeric playback session identifier.
- Argument 3 — client: Client IP address.
- Argument 4 — type: Numeric playback protocol.
- Argument 5 — URL: Requested resource URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed 0 sessions instead of expected 1 for id=42 ip='192.0.2.10' type=1 url='/live/camera/playlist.m3u8'
```

## Short description

Session identifier is missing from its client index.

## Trigger condition

Removing the identifier from a known client-address set removes a count other than one.

## Explanation

The caller continues cleanup and removes the address entry if its set is empty. A set erase can only remove zero or one matching identifier here.

## Possible causes

- The client-address entry did not contain the expected session identifier.

## What to check

1. Compare session registration and prior cleanup for the same identifier.

## Recommended action

Investigate inconsistent session indexing.
