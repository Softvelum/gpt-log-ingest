# Explicit DVR cleanup starts

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-5667a57d4e99fae6

## Log pattern

```text
delete dvr stream='%s/%s' target_depth=%llu older_than=%llu newer_than=%llu
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Target depth: Unsigned retention depth in minutes; zero means no depth bound.
- Argument 4 — Older boundary: Unsigned UTC cutoff in seconds since the Unix epoch; zero means absent.
- Argument 5 — Newer boundary: Unsigned UTC lower bound in seconds since the Unix epoch; zero means absent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
delete dvr stream='live/camera' target_depth=60 older_than=1700000060 newer_than=1700000000
```

## Short description

Explicit DVR cleanup starts.

## Trigger condition

A ready archive accepts a cleanup request with its depth or UTC boundaries.

## Explanation

Cleanup runs under archive locks and updates archive timestamps when content is removed or recording needs a new period.

## Possible causes

- A ready archive accepts a cleanup request with its depth or UTC boundaries.

1. Check the request boundaries and following storage or replacement errors.
