# Streaming body write advanced

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-30f4d929e1be0620

## Log pattern

```text
%u (%llu of %llu) B(b) to cli s=%d avail=%llu
```

## Parameters

- Argument 1 — Written bytes: Native-size signed write result, incorrectly printed with %u.
- Argument 2 — Sent body bytes: Unsigned 64-bit cumulative body bytes sent.
- Argument 3 — Expected body bytes: Unsigned 64-bit total expected body size.
- Argument 4 — Client socket: Integer identifying the local client socket.
- Argument 5 — Remaining available bytes: Unsigned 64-bit bytes still available in the current contiguous block after the write.

The write result is a native-size signed value passed to %u; that count is unreliable on 64-bit builds.

## Log examples

## Short description

Streaming body write advanced.

## Trigger condition

A positive asynchronous body write advances sent-byte progress.

## Explanation

Available bytes are reduced, then counter consistency and response completion are checked.

## Possible causes
