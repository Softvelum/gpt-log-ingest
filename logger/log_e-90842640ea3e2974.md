# Expected a JSON object

Product: Nimble Streamer
Component: JSON message validation
Logging function: log_e
Log level: error
Documentation ID: log_e-90842640ea3e2974

## Log pattern

```text
invalid json object type=%d
%s
```

## Parameters

- Argument 1 — JSON type: JSON library type enumeration, integer.
- Argument 2 — JSON text: Supplied complete JSON input, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid json object type=5
[]
```

## Short description

Expected a JSON object.

## Trigger condition

A guarded JSON operation receives a value whose JSON type is not object.

## Explanation

The complete supplied JSON text is logged and the caller-defined failure action runs; that action varies with the caller. The macro itself does not prescribe a universal session shutdown.

## Possible causes

- The parsed value is another JSON type instead of an object.

## What to check

1. Check the reported type and JSON body against the expected object structure.

## Recommended action

Supply a JSON object where required.
