# Cannot queue decoded DVB subtitle

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-4e27af37fd3a6917

## Log pattern

```text
failed to queue dvb subtitle for [%s]
```

## Parameters

- Argument 1 — Stream: Application and stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to queue dvb subtitle for [live/news]
```

## Short description

Cannot queue decoded DVB subtitle.

## Trigger condition

A decoded subtitle containing rectangles cannot be pushed to the OCR request queue.

## Explanation

The current subtitle decode reports failure; that subtitle is not forwarded for text recognition. The request queue is configured for 1000 items.

## Possible causes

- A decoded subtitle containing rectangles cannot be pushed to the OCR request queue.

## What to check

1. Check whether OCR requests are being consumed and whether the queue has filled.
