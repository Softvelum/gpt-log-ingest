# External request is enabling TLS

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-935d3776e931e44f

## Log pattern

```text
enabling ssl for origin_host='%s' s=%d
```

## Parameters

- Argument 1 — host: Target hostname used for TLS setup.
- Argument 2 — socket: Peer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
enabling ssl for origin_host='media.example' s=12
```

## Short description

External request is enabling TLS.

## Trigger condition

An in-progress peer connection was requested with TLS enabled.

## Explanation

TLS initialization is attempted after this message; failure raises a fatal request exception.
