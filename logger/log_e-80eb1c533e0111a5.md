# Local child listener could not be created

Product: Nimble Streamer
Component: Child process communication
Logging function: log_e

Illustrative examples; these are not captured server logs.

## Short description

Local child listener could not be created.

## Trigger condition

Opening, binding, listening on, or registering a nonblocking loopback listener on an automatically assigned port fails.

## Explanation

The child session cannot start and reports startup failure.

## Possible causes

- A local listener setup operation failed.

## What to check

1. Check the preceding socket error and availability of local socket resources.

## Recommended action

Resolve the reported child communication problem before retrying.
