# Requested playlist video track is absent

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-7584e940acd3749b

## Log pattern

```text
no video stream found, %s stream_id=%d

```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.
- Argument 2 — Track selection: Integer ordinal among supported tracks; minus one selects automatically and minus two disables that media kind.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no video stream found, /media/program.mp4 stream_id=0

```

## Short description

Requested playlist video track is absent.

## Trigger condition

No video track is selected although an explicit nonnegative video track ordinal was requested.

## Explanation

Opening the reader fails.

## Possible causes

- No video track is selected although an explicit nonnegative video track ordinal was requested.

## What to check

1. Choose an existing supported video track or automatic selection.

## Recommended action

Choose an existing supported video track or automatic selection.
