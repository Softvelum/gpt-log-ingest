# Streaming response has sent its selected bytes

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-998f07567fb27b76

## Log pattern

```text
sent=%llu roff=%llu rsz=%llu bsz=%llu to s=%d
```

## Parameters

- Argument 1 — Sent bytes: Unsigned 64-bit cumulative body bytes sent.
- Argument 2 — Response offset: Unsigned 64-bit starting byte offset of the selected response.
- Argument 3 — Response size: Unsigned 64-bit selected response bytes.
- Argument 4 — Origin body size: Unsigned 64-bit expected complete origin body bytes.
- Argument 5 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sent=65536 roff=0 rsz=65536 bsz=65536 to s=18
```

## Short description

Streaming response has sent its selected bytes.

## Trigger condition

The sent count reaches the selected cached response size or the expected origin body size minus the response offset.

## Explanation

The session resets for another request when keep-alive is enabled, otherwise it shuts down the client socket.

## Possible causes

- The sent count reaches the selected cached response size or the expected origin body size minus the response offset.
