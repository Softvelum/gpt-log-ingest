# AJA capture input is unavailable

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-60d7c19391799010

## Log pattern

```text
No such input '%s' on '%s'
```

## Parameters

- Argument 1 — Input label: Channel description in the inferred-input failure, or input-source description in the explicit validation failure.
- Argument 2 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No such input 'Channel 8' on 'AJA device'
```

## Short description

AJA capture input is unavailable.

## Trigger condition

The inferred SDI input for a valid channel is unsupported, or the selected input source is unsupported by the device.

## Explanation

Source selection returns failure. In the inferred-input branch, an HDMI alternative is assigned but the operation still returns failure immediately without validating that alternative.

## Possible causes

- The inferred SDI input for a valid channel is unsupported, or the selected input source is unsupported by the device.

## What to check

1. Check the explicitly selected input source and its device support.

## Recommended action

Select a supported input source explicitly when channel-based inference does not accept it.
