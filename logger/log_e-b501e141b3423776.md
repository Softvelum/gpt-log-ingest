# RTMP AVC decoder configuration is rejected

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-b501e141b3423776

## Log pattern

```text
[VM] set_video_codec_avc
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] set_video_codec_avc
```

## Short description

RTMP AVC decoder configuration is rejected.

## Trigger condition

Installing the AVC decoder configuration from a legacy sequence header fails.

## Explanation

The video handler fails and connection processing stops. A lower-level codec log may explain the specific configuration problem.

## Possible causes

- Installing the AVC decoder configuration from a legacy sequence header fails.

## What to check

1. Inspect the AVC sequence header and preceding codec-configuration errors.

## Recommended action

Provide a valid AVC decoder configuration before media.
