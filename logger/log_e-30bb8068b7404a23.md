# Shared CUDA context binding failed

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-30bb8068b7404a23

## Log pattern

```text
failed to bind shared ctx to thread res=%d
```

## Parameters

- Argument 1 — CUDA status: CUDA driver result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to bind shared ctx to thread res=2
```

## Short description

Shared CUDA context binding failed.

## Trigger condition

Shared-context locking is disabled, and making the shared context current on the calling thread returns an error.

## Explanation

The shared-context request returns failure.

## Possible causes

- The CUDA driver rejects the reported context operation.

## What to check

1. Check the CUDA result, device access, available GPU resources and preceding context diagnostics.

## Recommended action

Correct the driver or resource problem and retry context setup.
