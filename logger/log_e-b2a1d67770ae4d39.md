## Short description

Could not create the transcoder license worker.

## Trigger condition

The transcoder license verification worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the transcoder license worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed transcoder license worker.
