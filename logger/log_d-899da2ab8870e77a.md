# Recognition request prepared

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_d
Log level: debug
Documentation ID: log_d-899da2ab8870e77a

## Log pattern

```text
send msg=%s for stream='%s'
```

## Parameters

- Argument 1 — Message: Complete outgoing recognition-request JSON.
- Argument 2 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
send msg={"message":"StartRecognition","audio_format":{"type":"raw","encoding":"pcm_s16le","sample_rate":16000},"transcription_config":{"language":"en"}} for stream='live/news'
```

## Short description

Recognition request prepared.

## Trigger condition

The initial StartRecognition JSON request is ready to send over the websocket.

## Explanation

The request describes raw signed 16-bit little-endian PCM, sample rate, language, and any translation targets. The message is logged before the write, so it does not confirm acceptance.

## Possible causes

- The initial StartRecognition JSON request is ready to send over the websocket.

## What to check

1. Check the requested sample rate, transcription configuration, and translation targets in the JSON.
