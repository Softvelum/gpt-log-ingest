# DVR audio mute failed

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-6068784f576a0f37

## Log pattern

```text
failed to mute audio segment p=%u vst=%llu st=%llu f='%s of=%llu sz=%u
```

## Parameters

- Argument 1 — Period: Unsigned recording period identifier.
- Argument 2 — UTC time: 64-bit segment UTC time in milliseconds since the Unix epoch.
- Argument 3 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 4 — Storage file: Text naming the recorded media storage file.
- Argument 5 — File offset: Unsigned 64-bit byte offset within the media storage file.
- Argument 6 — Segment bytes: Unsigned media-segment size in bytes.

The field labeled vst is the segment UTC time in milliseconds, not a video media timestamp.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to mute audio segment p=1 vst=1700000000000 st=90000 f='/data/dvr/live/camera/1700000000000.dat of=1024 sz=65536
```

## Short description

DVR audio mute failed.

## Trigger condition

The selected recorded segment could not be processed by the mute operation.

## Explanation

Cleanup logs the failure and continues; this segment is not confirmed replaced.

## Possible causes

- The selected recorded segment could not be processed by the mute operation.

## What to check

1. Check preceding codec, media-read, replacement-size, or storage-write errors.

## Recommended action

Check preceding codec, media-read, replacement-size, or storage-write errors.
