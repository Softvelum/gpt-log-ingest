# SRT password-file authentication expects a user ID

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-559412c58530a714

## Log pattern

```text
[srt_listen_callback] url auth failed,password should be removed from 'srtauth'.streamid=[%s],ip=[%s]
```

## Parameters

- Argument 1 — Stream ID: Requested SRT stream identifier.
- Argument 2 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] url auth failed,password should be removed from 'srtauth'.streamid=[live/news?srtauth=example:password],ip=[192.0.2.20]
```

## Short description

SRT password-file authentication expects a user ID.

## Trigger condition

No publisher ID was obtained from the signature path and the srtauth value contains a colon.

## Explanation

The authenticated listener rejects the connection because this mode expects only a user identifier in srtauth.

## Possible causes

- No publisher ID was obtained from the signature path and the srtauth value contains a colon.

## What to check

1. Check the srtauth value in the stream ID.

## Recommended action

Remove the password from srtauth and supply only the configured user identifier.
