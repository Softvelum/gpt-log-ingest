# Cannot prepare SRT ingest socket

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-25deb4ed09512396

## Log pattern

```text
srt_socket failed: %s
```

## Parameters

- Argument 1 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_socket failed: Invalid parameter
```

## Short description

Cannot prepare SRT ingest socket.

## Trigger condition

Creating and configuring an SRT receive socket fails.

## Explanation

The pull or rendezvous ingest connection cannot proceed. The failure can come from socket allocation, nonblocking setup, timestamp delivery, or configured options.

## Possible causes

- Creating and configuring an SRT receive socket fails.

## What to check

1. Check preceding socket-option diagnostics.
