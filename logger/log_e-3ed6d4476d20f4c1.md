# Requested playlist audio track is absent

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-3ed6d4476d20f4c1

## Log pattern

```text
no audio stream found, %s stream_id=%d

```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.
- Argument 2 — Track selection: Integer ordinal among supported tracks; minus one selects automatically and minus two disables that media kind.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no audio stream found, /media/program.mp4 stream_id=0

```

## Short description

Requested playlist audio track is absent.

## Trigger condition

No audio track is selected although an explicit nonnegative audio track ordinal was requested.

## Explanation

Opening the reader fails.

## Possible causes

- No audio track is selected although an explicit nonnegative audio track ordinal was requested.

## What to check

1. Choose an existing supported audio track or automatic selection.

## Recommended action

Choose an existing supported audio track or automatic selection.
