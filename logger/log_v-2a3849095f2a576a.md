# Cache invalidation pass finished

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-2a3849095f2a576a

## Log pattern

```text
finished invalidating cache ram=%llu disk=%llu items=%llu iterated=%d deleted=%d
```

## Parameters

- Argument 1 — RAM bytes: Total cache capacity currently allocated in memory, in bytes.
- Argument 2 — disk bytes: Total cache capacity currently accounted for on disk, in bytes.
- Argument 3 — items: Remaining items registered by cache key.
- Argument 4 — iterated: Entries examined in this traversal.
- Argument 5 — deleted: Entries or fragments deleted in this traversal.

The item count uses a platform-sized container count with a 64-bit unsigned conversion.

## Log examples

No portable example is provided for the platform-dependent item-count argument.

## Short description

Cache invalidation pass finished.

## Trigger condition

The current bounded traversal of cached items ends.

## Explanation

The totals describe remaining capacity and items. Another pass may still be required when an iteration or deletion limit was reached; this is not a statement that the whole cache is empty.
