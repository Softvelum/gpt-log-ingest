# RTSP UDP connection pair queued

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-8c485dd9833be48f

## Log pattern

```text
rtsp s=%d add rtp s=%d, rtsp s=%d
```

## Parameters

- Argument 1 — RTSP socket: Control-session socket descriptor.
- Argument 2 — RTP socket: UDP media socket descriptor.
- Argument 3 — RTCP socket: UDP control socket descriptor; the original label is rtsp.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtsp s=25 add rtp s=26, rtsp s=27
```

## Short description

RTSP UDP connection pair queued.

## Trigger condition

RTP data and RTCP control sockets have been connected for a media track and are queued for connection-object creation.

## Explanation

The socket pair is added to the pending connection queue. The third value is the RTCP control socket even though its label says rtsp.

## Possible causes

- Normal UDP media-track setup.
