# Inactive session restored

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_d
Log level: debug
Documentation ID: log_d-85352a79b92a43a9

## Log pattern

```text
created inactive session %ld
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.

The format displays an unsigned-long identifier as signed long; the small positive example is within the common representable range.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created inactive session 42
```

## Short description

Inactive session restored.

## Trigger condition

A valid saved inactive-session record is reconstructed by either loader.

## Explanation

The record is inserted in the inactive map, the identifier counter is advanced if needed, and the client-IP index is restored.
