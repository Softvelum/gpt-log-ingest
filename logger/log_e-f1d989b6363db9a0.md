# Downloader received an unsupported plain socket event

Product: Nimble Streamer
Component: Background origin download
Logging function: log_e
Log level: error
Documentation ID: log_e-f1d989b6363db9a0

## Log pattern

```text
downloader session p=%p unknown event for s=%d ev=0x%x
```

## Parameters

- Argument 1 — address: Downloader session memory address.
- Argument 2 — socket: Origin socket descriptor.
- Argument 3 — events: Received event flags in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
downloader session p=0x1000 unknown event for s=12 ev=0x2000
```

## Short description

Downloader received an unsupported plain socket event.

## Trigger condition

A non-TLS downloader event has neither input nor output flags.

## Explanation

The session is marked finished and later cleanup handles the socket and cached data.

## Possible causes

- The downloader received a closure or other event outside its plain input/output handling.

## What to check

1. Compare the event flags and prior origin activity.

## Recommended action

Investigate the origin closure if the download was incomplete.
