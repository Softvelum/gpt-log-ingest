# Video component removed

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_d
Log level: debug
Documentation ID: log_d-d4fdb4782d88663d

## Log pattern

```text
video encoder removed for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

Without timestamp synchronization, removal in the initial state also stops the worker. With audio following video, combined output waits for video. With video following audio, combined output becomes audio-only; removal while waiting for audio stops the worker.

## Log examples

Illustrative examples; these are not captured server logs.

```text
video encoder removed for live/encoded
```

## Short description

Video component removed.

## Trigger condition

New output settings remove video while the worker applies a supported state transition.

## Explanation

A video-only worker stops. A combined worker releases its video encoder and either continues audio alone or waits for video when audio must follow video.
