# DVR transmux request enters its queue

Product: Nimble Streamer
Component: DVR
Logging function: log_d
Log level: debug
Documentation ID: log_d-5e6ddf46726c1062

## Log pattern

```text
[DTRQ::Push] stream='%s' chunk='%s' key='%s' qsize=%zu
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Chunk name: Text naming the requested recorded media chunk.
- Argument 3 — Cache key: Text identifying the requested output in the cache.
- Argument 4 — Queue size: Unsigned number of queued requests before adding this one.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DTRQ::Push] stream='live/camera' chunk='dvr_v_p1_90000.m4s' key='/live/camera/dvr_v_p1_90000.m4s' qsize=2
```

## Short description

DVR transmux request enters its queue.

## Trigger condition

A nonempty request is accepted below the queue limit.

## Explanation

The request is appended after this message.

## Possible causes

- A nonempty request is accepted below the queue limit.
