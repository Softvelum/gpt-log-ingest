# Additional WebVTT language cannot receive a caption track

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-45bc3fc7951bf201

## Log pattern

```text
cea708: dropping WebVTT subtitle lang="%s" for [%s/%s], exceeds max of %zu CC tracks
```

## Parameters

- Argument 1 — Language: WebVTT language that cannot be assigned a service.
- Argument 2 — Application: Application containing the live stream.
- Argument 3 — Stream: Live stream name.
- Argument 4 — Track limit: Supported CEA-708 track count, currently four.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cea708: dropping WebVTT subtitle lang="spa" for [live/camera], exceeds max of 4 CC tracks
```

## Short description

Additional WebVTT language cannot receive a caption track.

## Trigger condition

Multiple WebVTT languages are being converted to CEA-708 and no free caption service remains for this language.

## Explanation

The CEA-708 copy of this subtitle is dropped. WebVTT forwarding and HLS/DASH subtitle packaging continue.

## Possible causes

- Multiple WebVTT languages are being converted to CEA-708 and no free caption service remains for this language.

## What to check

1. Check distinct languages and their assigned caption services.

## Recommended action

Limit caption conversion to the supported number of languages.
