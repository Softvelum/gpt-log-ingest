# VPX constant quality setting was rejected

Product: Nimble Streamer
Component: VP8 and VP9 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f5493e25c7e50830

## Log pattern

```text
failed to set cq_level=%d: %s
```

## Parameters

- Argument 1 — Quality level: Constant-quality level, integer in the range 0 through 63; no physical unit.
- Argument 2 — Codec error: libvpx description of the returned error, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set cq_level=10: Invalid parameter
```

## Short description

VPX constant quality setting was rejected.

## Trigger condition

libvpx rejects the initial cq_level control during encoder setup.

## Explanation

Encoder initialization stops before the remaining common and codec-specific controls are applied.

## Possible causes

- The selected VPX implementation does not accept the requested constant-quality control.

## What to check

1. Check the value and error description; the setting is constrained to 0 through 63 and defaults to 10.

## Recommended action

Choose a supported quality setting or compatible libvpx library.
