# Request delivery to child failed

Product: Nimble Streamer
Component: Child process communication
Logging function: log_e
Log level: error
Documentation ID: log_e-95a960f45392840d

## Log pattern

```text
failed to send request to child process
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send request to child process
```

## Short description

Request delivery to child failed.

## Trigger condition

A connected session cannot queue or flush its next request.

## Explanation

The current attempt fails and the worker resets or exits according to its lifetime.

## Possible causes

- The output buffer rejected the message or the local socket could not send it.

## What to check

1. Check message size and child socket diagnostics.

## Recommended action

Resolve the reported child communication problem before retrying.
