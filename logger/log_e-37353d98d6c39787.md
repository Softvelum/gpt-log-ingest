# Audio decoder fell behind the live buffer

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-37353d98d6c39787

## Log pattern

```text
failed to decode audio in appropriate rate [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode audio in appropriate rate [live/camera]
```

## Short description

Audio decoder fell behind the live buffer.

## Trigger condition

Reading the next live audio item reports that the reader is too slow and its requested item is no longer available.

## Explanation

The read position is reset and the decoder attempts to resume from the current first decodable item.

## Possible causes

- Audio processing has fallen behind retained live-buffer data.

## What to check

1. Check decoder throughput, output backpressure, and host load.

## Recommended action

Remove the processing bottleneck; the worker already attempts to catch up by resetting its read position.
