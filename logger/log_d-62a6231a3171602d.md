# Additional disk cache fragment allocated

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-62a6231a3171602d

## Log pattern

```text
allocated key='%s' fr=%llu sz=%u disk=%llu
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — fragment: Zero-based fragment index.
- Argument 3 — allocated bytes: Mapped fragment size in bytes.
- Argument 4 — disk bytes: Total cache capacity currently accounted for on disk, in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
allocated key='movie' fr=1 sz=1048576 disk=2097152
```

## Short description

Additional disk cache fragment allocated.

## Trigger condition

A missing fragment file is created and mapped successfully within cache limits.

## Explanation

The new fragment enters the cache lists and increases the disk-cache total; content availability is set separately.
