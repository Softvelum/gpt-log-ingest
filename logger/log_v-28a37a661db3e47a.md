# RTMP data frame carries an unexpected metadata command

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_v
Log level: verbose
Documentation ID: log_v-28a37a661db3e47a

## Log pattern

```text
was not able to process setDataFrame(%s). expect onMetaData but got %s
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.
- Argument 2 — Received command: AMF string found after @setDataFrame.

## Log examples

Illustrative examples; these are not captured server logs.

```text
was not able to process setDataFrame(live/camera). expect onMetaData but got onCustomData
```

## Short description

RTMP data frame carries an unexpected metadata command.

## Trigger condition

The string following @setDataFrame is not onMetaData, compared without case sensitivity.

## Explanation

The data frame is ignored and processing continues. Its payload is not installed as the stream metadata.

## Possible causes

- The string following @setDataFrame is not onMetaData, compared without case sensitivity.

## What to check

1. Check the metadata command emitted after @setDataFrame.

## Recommended action

Use onMetaData for supported stream metadata.
