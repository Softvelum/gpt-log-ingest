# Widevine key request is prepared

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-09543a68b894b7ca

## Log pattern

```text
[drm] request Widevine keys for '%s' cpi=%u/%u retry=%hu
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned key rotation period index.
- Argument 3 — Period count: Unsigned number of consecutive crypto periods.
- Argument 4 — Retry index: Unsigned 16-bit retry number; zero means the initial request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] request Widevine keys for 'live/camera' cpi=120/2 retry=0
```

## Short description

Widevine key request is prepared.

## Trigger condition

Requested key slots have been prepared or refreshed and the signed request body is built.

## Explanation

The POST is submitted next; this message does not confirm submission or response success.

## Possible causes

- Requested key slots have been prepared or refreshed and the signed request body is built.
