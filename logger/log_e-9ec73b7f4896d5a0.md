# HEVC decoder sequence parameters could not be read

Product: Nimble Streamer
Component: FFmpeg video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-9ec73b7f4896d5a0

## Log pattern

```text
set_hevc_info function failed, get_h265_sps_info call failed for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set_hevc_info function failed, get_h265_sps_info call failed for [live/camera]
```

## Short description

HEVC decoder sequence parameters could not be read.

## Trigger condition

The first supplied HEVC sequence parameter set is present but cannot be parsed.

## Explanation

The decoder extra data is not updated by this attempt.

## Possible causes

- Malformed or unsupported HEVC sequence parameters.

## What to check

1. Check the HEVC video parameter sets and their sizes.

## Recommended action

Supply valid complete HEVC parameter sets.
