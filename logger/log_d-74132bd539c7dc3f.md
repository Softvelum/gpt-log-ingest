# Remote HLS item URL expanded

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-74132bd539c7dc3f

## Log pattern

```text
l=%s
```

## Parameters

- Argument 1 — Expanded item URL: Text formed by prepending the origin directory URL to the playlist item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
l=http://media.example/live/camera/segment1.ts
```

## Short description

Remote HLS item URL expanded.

## Trigger condition

An absolute-URL request expands a non-comment playlist line using the origin playlist directory.

## Explanation

The expanded line is logged before session-bound URL encryption.

## Possible causes

- An absolute-URL request expands a non-comment playlist line using the origin playlist directory.
