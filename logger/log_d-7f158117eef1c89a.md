# Expired Widevine key found during cleanup

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-7f158117eef1c89a

## Log pattern

```text
[drm] remove expired key for '%s' cpi=%u type='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned key rotation period index.
- Argument 3 — Key type: Text classifying the Widevine media key.

The message is emitted while finding the expired prefix, before the conditional erase.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] remove expired key for 'live/camera' cpi=120 type='HD'
```

## Short description

Expired Widevine key found during cleanup.

## Trigger condition

A key at the beginning of the ordered set belongs to an earlier crypto period.

## Explanation

The expired prefix is removed when a nonexpired key follows. If every key is expired, this cleanup leaves the set in place.

## Possible causes

- A key at the beginning of the ordered set belongs to an earlier crypto period.
