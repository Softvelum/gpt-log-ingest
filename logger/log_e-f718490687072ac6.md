# Publish-denial request is not a JSON object

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-f718490687072ac6

## Log pattern

```text
error processing json='%s'
```

## Parameters

- Argument 1 — request\_body: The complete submitted JSON body printed as a string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
error processing json='[]'
```

## Short description

Publish-denial request is not a JSON object.

## Trigger condition

The publish-control denial endpoint parsed JSON successfully but its top-level value is not an object.

## Explanation

The parsed value is released and an HTTP 500 response is attempted. Publisher denial is not applied from this request.

## Possible causes

- A non-object JSON value was submitted.

## What to check

1. Check the top-level shape of the publish-denial request.

## Recommended action

Send a JSON object containing the expected publisher-denial field.
