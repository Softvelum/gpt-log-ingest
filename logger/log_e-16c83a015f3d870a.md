# Cache metadata file creation failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-16c83a015f3d870a

## Log pattern

```text
failed to create metadata file='%s' (errno=%d)
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.
- Argument 2 — error: Operating system error number reported for the failed operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create metadata file='/var/cache/nimble/movie.meta' (errno=13)
```

## Short description

Cache metadata file creation failed.

## Trigger condition

Opening the metadata file for creation and truncating write fails.

## Explanation

Metadata saving returns failure before serializing the item. The caller decides whether to remove the associated data.

## Possible causes

- The metadata file could not be opened for writing.

## What to check

1. Check the error number and parent directory access.

## Recommended action

Restore writable cache storage.
