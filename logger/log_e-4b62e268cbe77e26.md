# Legacy Quick Sync session creation failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-4b62e268cbe77e26

## Log pattern

```text
failed to init quick sync session, error=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init quick sync session, error=-3
```

## Short description

Legacy Quick Sync session creation failed.

## Trigger condition

Legacy media initialization returns a non-success status other than unsupported, or leaves the session handle null.

## Explanation

The media session is rejected and transcoding initialization cannot continue.

## Possible causes

- The media runtime fails to initialize an automatic implementation, or returns no session handle.

## What to check

1. Check the status and preceding runtime diagnostics; status zero is possible if no session handle was returned.

## Recommended action

Resolve the media runtime or device initialization failure and restart transcoding.
