# Registering a live stream from a publisher

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_v
Log level: verbose
Documentation ID: log_v-707846e708df5b50

## Log pattern

```text
LiveStreamManager::registerStream name='%s' proto=%d publisher='%s'
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.
- Argument 2 — protocol: Input protocol number: 0 RTMP, 1 RTSP, 2 Icecast, 3 MPEG-TS, 4 encoder, 5 NDI, 6 playlist, 7 WebRTC, 8 Dante, 9 OMT, 10 SDI, 11 AJA, 12 none.
- Argument 3 — publisher\_ip: Publisher IP address; no port is included here.

## Log examples

Illustrative examples; these are not captured server logs.

```text
LiveStreamManager::registerStream name='live/camera' proto=0 publisher='192.0.2.20'
```

## Short description

Registering a live stream from a publisher.

## Trigger condition

A stream registration includes a nonempty publisher IP address.

## Explanation

This trace precedes stream-object creation. The publisher address determines which registration message form is used even if a source URL is also supplied.
