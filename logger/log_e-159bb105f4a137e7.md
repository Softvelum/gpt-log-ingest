# Requested audio encoder is unavailable

Product: Nimble Streamer
Component: FFmpeg audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-159bb105f4a137e7

## Log pattern

```text
failed to find %s audio encoder
```

## Parameters

- Argument 1 — Encoder: Requested or selected audio encoder name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find aac audio encoder
```

## Short description

Requested audio encoder is unavailable.

## Trigger condition

FFmpeg cannot find the requested encoder by name, or the default AAC encoder when no name is supplied.

## Explanation

Initialization fails before creating the encoder context.

## Possible causes

- The loaded FFmpeg library does not provide the requested audio encoder.

## What to check

1. Check the selected encoder name and available runtime codecs.

## Recommended action

Select an available encoder or supply the matching FFmpeg build.
