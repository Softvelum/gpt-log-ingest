# Socket close failed

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-76653520061e4197

## Log pattern

```text
failed to close %s socket s=%d (errno=%d)
```

## Parameters

- Argument 1 — Socket label: Caller-supplied descriptive socket label, text.
- Argument 2 — Socket: Socket descriptor, integer; no unit.
- Argument 3 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to close input socket s=12 (errno=5)
```

## Short description

Socket close failed.

## Trigger condition

The platform socket-close call returns an error.

## Explanation

The close helper reports failure to its caller.

## Possible causes

- The operating system rejected the close call.

## What to check

1. Check the socket descriptor and socket error.

## Recommended action

Investigate the close failure.
