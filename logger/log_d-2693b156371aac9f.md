# PES decoding timestamp does not fit its first packet

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-2693b156371aac9f

## Log pattern

```text
DTS MUST be in PUSI PES block pid=%d
```

## Parameters

- Argument 1 — PID: Affected elementary-stream packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DTS MUST be in PUSI PES block pid=256
```

## Short description

PES decoding timestamp does not fit its first packet.

## Trigger condition

The PES flags require both timestamps but fewer than five bytes remain for DTS after PTS is read.

## Explanation

The current transport packet is rejected. Its elementary-stream parser is reset, buffered partial PES data is discarded, and the camera parser searches for another packet boundary.

## Possible causes

- The PES flags require both timestamps but fewer than five bytes remain for DTS after PTS is read.

## What to check

1. Check the complete PTS/DTS fields in the payload-start packet.

## Recommended action

Correct malformed PES framing at the source.
