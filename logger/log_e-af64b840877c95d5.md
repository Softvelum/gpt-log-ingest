# Advertising rules file could not be read

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-af64b840877c95d5

## Log pattern

```text
failed to read main rules from %s
```

## Parameters

- Argument 1 — Rules URI: Text identifying the local rules file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read main rules from file:///data/advertising.json
```

## Short description

Advertising rules file could not be read.

## Trigger condition

The advertising rules location uses a file URI and reading that file fails.

## Explanation

The synchronization-in-progress flag is cleared without processing new rules.

## Possible causes

- The advertising rules location uses a file URI and reading that file fails.

## What to check

1. Check that the local rules file exists and can be read.

## Recommended action

Check that the local rules file exists and can be read.
