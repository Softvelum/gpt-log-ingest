# AJA device cannot capture

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-5742985eb3aca260

## Log pattern

```text
Device '%s' is playback-only
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device 'AJA device' is playback-only
```

## Short description

AJA device cannot capture.

## Trigger condition

Capture capability is absent on the selected card.

## Explanation

The capture-capability check returns failure; receiver initialization reports that the device cannot capture.

## Possible causes

- Capture capability is absent on the selected card.

## What to check

1. Check the card capture capability.

## Recommended action

Use a capture-capable device for input.
