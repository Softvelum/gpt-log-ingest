# WHIP publishing credentials missing

Product: Nimble Streamer
Component: WHIP publishing authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-9c491e20801beb72

## Log pattern

```text
WHIP publish not authorized without auth params stream=[%s/%s] ip=[%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.
- Argument 3 — Client address: Publisher IP address supplied with the request, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WHIP publish not authorized without auth params stream=[live/camera] ip=[192.0.2.10]
```

## Short description

WHIP publishing credentials missing.

## Trigger condition

A WHIP publication supplies neither a publish signature nor application credentials, and signature-free publishing is disabled.

## Explanation

The WHIP session is not created; the caller receives no session.

## Possible causes

- The publisher omitted both supported authorization forms.

## What to check

1. Check the publishing request authorization parameters and whether signature-free publishing is intended.

## Recommended action

Supply the required publishing authorization or enable the intended signature-free policy.
