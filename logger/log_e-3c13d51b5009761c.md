# SRT listen operation failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-3c13d51b5009761c

## Log pattern

```text
srt_listen at %s:%d failed, s=%d: %s
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Socket: SRT socket identifier.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_listen at 0.0.0.0:9000 failed, s=100: Invalid socket state
```

## Short description

SRT listen operation failed.

## Trigger condition

The library rejects placing a bound SRT socket into listening mode.

## Explanation

Listener setup fails. The shared listener helper removes the socket from its event poller and closes it.

## Possible causes

- The library rejects placing a bound SRT socket into listening mode.

## What to check

1. Check the local endpoint and SRT error.
