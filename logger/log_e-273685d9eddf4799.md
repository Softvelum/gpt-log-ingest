# SDI video converter creation failed

Product: Nimble Streamer
Component: SDI video conversion
Logging function: log_e
Log level: error
Documentation ID: log_e-273685d9eddf4799

## Log pattern

```text
failed to create frame converter: %d->uyvy422 for [%s]
```

## Parameters

- Argument 1 — Pixel format: FFmpeg pixel-format identifier, integer; no unit.
- Argument 2 — Output: AJA writer name or SDI output stream name, text.

All occurrences target packed UYVY422. The final field names the AJA writer in AJA output and the stream in either SDI output path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create frame converter: 0->uyvy422 for [live/camera]
```

## Short description

SDI video converter creation failed.

## Trigger condition

A non-UYVY422 frame requires conversion, but creating the converter fails.

## Explanation

The frame is not sent to the AJA or SDI output; the current write returns failure.

## Possible causes

- The pixel conversion cannot process the supplied frame dimensions or pixel format, or lacks resources.

## What to check

1. Check the reported source pixel format, frame dimensions and memory availability.

## Recommended action

Use a supported frame format and restore conversion resources before retrying.
