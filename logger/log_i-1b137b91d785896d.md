# Transcription stream created

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-1b137b91d785896d

## Log pattern

```text
transcriber created for stream='%s'
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
transcriber created for stream='live/news'
```

## Short description

Transcription stream created.

## Trigger condition

A service connection attempt has been initiated successfully and the new transcription stream is installed.

## Explanation

This records local creation and scheduling of the connection, before websocket establishment or recognition acceptance is assured.

## Possible causes

- A service connection attempt has been initiated successfully and the new transcription stream is installed.

## What to check

1. Look for the service recognition response and subsequent sent-audio messages.
