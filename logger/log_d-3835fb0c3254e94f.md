# Stream-check socket event received

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-3835fb0c3254e94f

## Log pattern

```text
StreamCheckerTask::ProcessEvent %p (state=%d s=%d ev=0x%x)
```

## Parameters

- Argument 1 — task address: Memory address of the task object.
- Argument 2 — state: Task state: 0 uninitialized, 1 connecting, 2 preparing request, 3 connected, 4 reading body, 5 shutting down, 6 shut down.
- Argument 3 — socket: Socket descriptor for the stream-check connection.
- Argument 4 — events: Socket event flags printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
StreamCheckerTask::ProcessEvent 0x1000 (state=4 s=12 ev=0x1)
```

## Short description

Stream-check socket event received.

## Trigger condition

The event loop dispatches a socket event to a stream-check task.

## Explanation

The task handles input or output according to its logical operation, then handles peer closure unless the socket changed during processing.
