# Incoming connection could not be accepted

Product: Nimble Streamer
Component: Socket communication
Logging function: log_d
Log level: debug
Documentation ID: log_d-452480ca5007c5c6

## Log pattern

```text
accept fd=%d failed errno=%d
```

## Parameters

- Argument 1 — Listener: Listening socket descriptor, integer.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
accept fd=12 failed errno=5
```

## Short description

Incoming connection could not be accepted.

## Trigger condition

The operating system accept operation returns an invalid socket.

## Explanation

No accepted connection is returned. Linux requests nonblocking acceptance directly; Windows sets nonblocking mode after acceptance.

## Possible causes

- The accept operation returned an error, including a possible transient lack of pending connections.

## What to check

1. Check the listener descriptor and socket error.

## Recommended action

Act on persistent socket errors; a transient unavailable connection can be retried by later listener events.
