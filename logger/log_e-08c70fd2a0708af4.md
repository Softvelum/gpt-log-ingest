# Library unloading is unsupported on this platform

Product: Nimble Streamer
Component: Runtime library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-08c70fd2a0708af4

## Log pattern

```text
DynamicLibrary::Close() is not implemented
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
DynamicLibrary::Close() is not implemented
```

## Short description

Library unloading is unsupported on this platform.

## Trigger condition

A non-null library is closed in a build that supplies neither Linux nor Windows library unloading.

## Explanation

No operating system unload is performed and the retained handle is cleared.

## Possible causes

- This platform has no implementation of dynamic library unloading.

## What to check

1. Check the target operating system supported by this build.

## Recommended action

Use a build with library-loading support for its operating system.
