# Transcoder worker startup failed

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-039526fa66366982

## Log pattern

```text
failed to create transcoder_main_thread thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create transcoder_main_thread thread
```

## Short description

Transcoder worker startup failed.

## Trigger condition

Starting a required Transcoder worker fails during license verification.

## Explanation

The license worker enters its exit state. Shutdown then disables transcoding and stops any already created related workers. The wording can also represent failure of the remote worker.

## Possible causes

- A required worker thread could not be created.

## What to check

1. Check preceding thread resource errors and whether the main or remote worker failed.

## Recommended action

Resolve the thread creation failure and restart the licensing workflow.
