# Closed-caption buffer limit is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-438ad607d164e63b

## Log pattern

```text
invalid parameter value: %s (should be >= 1000 && <= 10000)
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0 (should be >= 1000 && <= 10000)
```

## Short description

Closed-caption buffer limit is invalid.

## Trigger condition

While reading configuration, the video-filter closed-caption size limit is outside 1000 through 10000.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires a caption-data limit from 1000 through 10000.

## Recommended action

Correct the value to a caption-data limit from 1000 through 10000 and reload configuration.
