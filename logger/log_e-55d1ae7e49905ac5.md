# DVR audio indexes point to different segments

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-55d1ae7e49905ac5

## Log pattern

```text
str='%s/%s' period=%u seg p=%p st=%llu does not match A seg p=%p
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Period: Unsigned recording period identifier.
- Argument 4 — Timeline segment: Pointer identifying the segment selected for removal.
- Argument 5 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 6 — Audio-index segment: Pointer identifying the other segment at the same audio timestamp.

## Log examples

Illustrative examples; these are not captured server logs.

```text
str='live/camera' period=1 seg p=0x1234 st=90000 does not match A seg p=0x5678
```

## Short description

DVR audio indexes point to different segments.

## Trigger condition

The combined timeline audio entry and the audio index at the same timestamp hold different segment objects.

## Explanation

Only the combined-timeline segment is removed; the replacement audio-index entry is preserved and audio duration is adjusted.

## Possible causes

- The combined timeline audio entry and the audio index at the same timestamp hold different segment objects.

## What to check

1. Check whether duplicate audio timestamps replaced an earlier index entry.

## Recommended action

Check whether duplicate audio timestamps replaced an earlier index entry.
