# Synchronization response body is empty

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_d
Log level: debug
Documentation ID: log_d-399e05fe83961723

## Log pattern

```text
sync body empty or invalid
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync body empty or invalid
```

## Short description

Synchronization response body is empty.

## Trigger condition

A complete HTTP 200 TLS response has no body pointer or a nonpositive body length. Silent mode is disabled.

## Explanation

The synchronization operation still reports success; it does not replace the caller body with new content.

## Possible causes

- The successful HTTP response contains no usable body.

## What to check

1. Check whether the responding service is expected to supply a body.

## Recommended action

Correct the service response when synchronization requires body content.
