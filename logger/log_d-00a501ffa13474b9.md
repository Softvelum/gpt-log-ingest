# Unrefreshed program map is removed

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-00a501ffa13474b9

## Log pattern

```text
PMT expired and removed pid=%d
```

## Parameters

- Argument 1 — PID: Removed program-map packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
PMT expired and removed pid=100
```

## Short description

Unrefreshed program map is removed.

## Trigger condition

A tracked PMT remains marked unrefreshed during an orphan check, and PAT data has arrived since the previous check.

## Explanation

Its PMT tracker and program mapping are removed and available stream information is updated. No orphan removal is performed by this check when PAT data has not arrived.

## Possible causes

- A tracked PMT remains marked unrefreshed during an orphan check, and PAT data has arrived since the previous check.

## What to check

1. Check ongoing PAT/PMT delivery and whether the program was intentionally removed.

## Recommended action

Restore consistent program-table updates if the program should still be active.
