# Playlist remote media is absent from cache

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-b6a214091c079514

## Log pattern

```text
ServerBlockProcessor: content url=[%s] doesn't exist
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: content url=[/media/program.mp4] doesn't exist
```

## Short description

Playlist remote media is absent from cache.

## Trigger condition

Opening a media URI finds no cache item for its protocol-stripped key.

## Explanation

No reader is created. The caller advances to the next scheduled stream when this source cannot be opened.

## Possible causes

- Opening a media URI finds no cache item for its protocol-stripped key.

## What to check

1. Ensure the remote content download completes before playback.

## Recommended action

Ensure the remote content download completes before playback.
