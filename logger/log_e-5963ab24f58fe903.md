# Fragmented media structure cannot be loaded for audio output

Product: Nimble Streamer
Component: Fragmented media to transport stream packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-5963ab24f58fe903

## Log pattern

```text
cannot load audio_init_segment
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot load audio_init_segment
```

## Short description

Fragmented media structure cannot be loaded for audio output.

## Trigger condition

An MP4-structure error is raised while loading AAC initialization, generating a packed-audio chunk, or reconstructing an audio/video transport chunk.

## Explanation

The current initialization or output-chunk operation returns failure. Despite the message wording, combined-output occurrences can originate while reading video fragments or later audio fragments.

## Possible causes

- An MP4-structure error is raised while loading AAC initialization, generating a packed-audio chunk, or reconstructing an audio/video transport chunk.

## What to check

1. Check complete initialization and media fragments for both selected tracks.

## Recommended action

Replace malformed or mismatched fragmented-media data.
