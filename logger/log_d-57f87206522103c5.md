# RTSP server worker stopped

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug

## Log pattern

RTSPSereverThread stopped

## Short description

RTSP server worker stopped.

## Trigger condition

The RTSP server worker has left its event loop after an exit request.

## Explanation

The worker has cleaned up its active publisher connections or server listeners and returns from its processing routine.

## Possible causes

- The worker received an exit request.
