# Invalid saved state file could not be removed

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-36c4fd6982c3f0c9

## Log pattern

```text
Failed to remove '%s' error=%d message='%s'
```

## Parameters

- Argument 1 — file: Path of the saved session or recovery-statistics data file.
- Argument 2 — error: Filesystem error number.
- Argument 3 — message: Filesystem error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Failed to remove '/var/lib/nimble/sessions.db' error=13 message='Permission denied'
```

## Short description

Invalid saved state file could not be removed.

## Trigger condition

Deleting a session or recovery-statistics file after a JSON parse failure reports failure.

## Explanation

The loader returns and leaves the failed deletion reported for diagnosis; it does not retry deletion here.

## Possible causes

- Removing the invalid state file failed.

## What to check

1. Check the preceding parse failure and filesystem error.

## Recommended action

Correct directory access or remove the invalid state file through normal administration.
