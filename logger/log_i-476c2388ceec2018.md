# Inactive transcription stream removed

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-476c2388ceec2018

## Log pattern

```text
removed transcriber on inactivity stream='%s'
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed transcriber on inactivity stream='live/news'
```

## Short description

Inactive transcription stream removed.

## Trigger condition

The stream reaches three inactivity checks without a successful audio send resetting its counter.

## Explanation

The transcription stream and websocket context are removed. Stored configuration can allow a later audio message to recreate the stream.

## Possible causes

- The stream reaches three inactivity checks without a successful audio send resetting its counter.

## What to check

1. Check whether complete audio chunks are being sent and whether the service connection is progressing.
