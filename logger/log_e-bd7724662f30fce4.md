# HLS advertising playlist is in a failed state

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-bd7724662f30fce4

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu failed to get playlist=%s
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.
- Argument 5 — Playlist ID: Cache identity of the advertising playlist that failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
app=live stream=camera stream_name=live/camera session=123 failed to get playlist=ad-1_6_0
```

## Short description

HLS advertising playlist is in a failed state.

## Trigger condition

A cached advertising playlist is returned during the lookup after obtaining ready content, but its state is neither initializing nor ready.

## Explanation

The advertising playlist update fails. An initializing playlist instead follows a wait path.

## Possible causes

- A cached advertising playlist is returned during the lookup after obtaining ready content, but its state is neither initializing nor ready.

## What to check

1. Check the named advertising playlist generation errors and its source content.

## Recommended action

Correct the failed advertising playlist generation.
