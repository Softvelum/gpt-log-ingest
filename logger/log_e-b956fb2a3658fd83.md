# RTSP pull TLS initialization failed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-b956fb2a3658fd83

## Log pattern

```text
failed to init ssl for rtsp_pull [%s:%d]
```

## Parameters

- Argument 1 — host: Remote stream server hostname.
- Argument 2 — port: Remote TCP port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init ssl for rtsp_pull [media.example:322]
```

## Short description

RTSP pull TLS initialization failed.

## Trigger condition

The RTSP pull connection is being established but TLS initialization fails.

## Explanation

Receiver creation fails. An existing live-stream record is unregistered so the pull manager can recreate the task on a later synchronization.

## Possible causes

- The TLS connection state could not be initialized.

## What to check

1. Check preceding TLS initialization diagnostics for this host.

## Recommended action

Resolve the TLS initialization failure.
