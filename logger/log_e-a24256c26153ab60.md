# Media mapping unmap failed

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-a24256c26153ab60

## Log pattern

```text
munmap_and_close_file munmap failed. errno=%d
```

## Parameters

- Argument 1 — Error: Operating-system error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
munmap_and_close_file munmap failed. errno=22
```

## Short description

Media mapping unmap failed.

## Trigger condition

The operating system rejects releasing a mapped file region on a non-Windows platform.

## Explanation

Cleanup still attempts to close the file descriptor.

## Possible causes

- The operating system rejects releasing a mapped file region on a non-Windows platform.

## What to check

1. Check the error and mapping lifecycle.
