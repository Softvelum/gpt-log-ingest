# DVR media file still contains live segments

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_d
Log level: debug
Documentation ID: log_d-0486cbb298ab17b6

## Log pattern

```text
keeping segment f='%s' dsc=%u
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.
- Argument 2 — Remaining segments: Unsigned count of remaining data segments in the file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
keeping segment f='/data/dvr/live/camera/1700000000000.dat' dsc=4
```

## Short description

DVR media file still contains live segments.

## Trigger condition

Removing one segment leaves other data segments in the same storage file.

## Explanation

The physical file is kept; this diagnostic is suppressed while loading the archive.

## Possible causes

- Removing one segment leaves other data segments in the same storage file.
