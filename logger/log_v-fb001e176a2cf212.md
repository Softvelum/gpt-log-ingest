# TLS server name could not be set

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_v
Log level: verbose
Documentation ID: log_v-fb001e176a2cf212

## Log pattern

```text
SSL_set_tlsext_host_name failed for %s
```

## Parameters

- Argument 1 — Host: Text host name submitted for connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SSL_set_tlsext_host_name failed for origin.example
```

## Short description

TLS server name could not be set.

## Trigger condition

A nonempty host name is available, server-name-extension support is compiled in, and setting the TLS server name fails.

## Explanation

Both ordinary outbound connections and stream-checker connections continue without server-name indication; this error alone does not stop TLS setup.

## Possible causes

- The TLS library rejected the supplied server name.

## What to check

1. Check the host name used for the TLS connection.
