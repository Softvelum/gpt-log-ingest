# Advertising playlist completion is not ready

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-3465c2887e984d3f

## Log pattern

```text
failed to get advertising playlist, playlist_id=%s
```

## Parameters

- Argument 1 — Playlist ID: Text identifier of the advertising playlist reported by the update.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get advertising playlist, playlist_id=ad-playlist-01
```

## Short description

Advertising playlist completion is not ready.

## Trigger condition

An advertising playlist update arrives with a state other than ready.

## Explanation

HTTP/1 rejects the waiting request with HTTP 500. HTTP/2 or HTTP/3 sends HTTP 500 for matching pending live HLS or DASH playlist requests; other pending request types are not completed by that failure loop.

## Possible causes

- An advertising playlist update arrives with a state other than ready.

## What to check

1. Inspect the preceding advertising playlist preparation error and determine which waiting playback requests depend on it.

## Recommended action

Inspect the preceding advertising playlist preparation error and determine which waiting playback requests depend on it.
