# Playlist stream entry is invalid

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-3dc34b02243149ae

## Log pattern

```text
invalid Stream in Block id=[%s]. Ignored
```

## Parameters

- Argument 1 — Block ID: Text identifying the schedule block.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid Stream in Block id=[morning]. Ignored
```

## Short description

Playlist stream entry is invalid.

## Trigger condition

A stream entry has an unknown type, empty source, invalid negative timing or repeat count, or track selection below minus two.

## Explanation

That stream is omitted from the block.

## Possible causes

- A stream entry has an unknown type, empty source, invalid negative timing or repeat count, or track selection below minus two.

## What to check

1. Correct the stream type, source, timing, repeat count, and track selections.

## Recommended action

Correct the stream type, source, timing, repeat count, and track selections.
