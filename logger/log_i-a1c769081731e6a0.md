# File metadata read failed during bus-signal recovery

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_i
Log level: info
Documentation ID: log_i-a1c769081731e6a0

## Log pattern

```text
failed to get f=%d info
```

## Parameters

- Argument 1 — File descriptor: Integer descriptor of the local mapped input.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get f=23 info
```

## Short description

File metadata read failed during bus-signal recovery.

## Trigger condition

After a bus signal, metadata lookup for the local mapped-file descriptor fails.

## Explanation

Recovery continues to log the mapping with zero-initialized size/time values and unmap and close it.

## Possible causes

- After a bus signal, metadata lookup for the local mapped-file descriptor fails.

## What to check

1. Check the prior bus-signal event and whether the mapped file or descriptor changed during processing.

## Recommended action

Check the prior bus-signal event and whether the mapped file or descriptor changed during processing.
