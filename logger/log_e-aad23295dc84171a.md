# NVIDIA AVC configuration creation failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-aad23295dc84171a

## Log pattern

```text
failed to create avc seq header for encoder=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create avc seq header for encoder=0x12340000
```

## Short description

NVIDIA AVC configuration creation failed.

## Trigger condition

The Annex B sequence data returned by NVIDIA cannot be collected into H.264 configuration parameter sets.

## Explanation

Encoder initialization fails before usable codec configuration is supplied to the output.

## Possible causes

- The driver sequence header is not accepted by the codec-configuration builder.

## What to check

1. Check the selected codec, driver compatibility and returned sequence-header diagnostics.

## Recommended action

Use a compatible driver and supported encoding configuration.
