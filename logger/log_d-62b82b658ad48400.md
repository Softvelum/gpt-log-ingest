## Short description

VOD subtitle playlist generation produced text.

## Trigger condition

A default or advertising subtitle playlist has been generated from loaded subtitle data and its requested time range.

## Explanation

The playlist is logged before cache allocation. Successful allocation stores it as an HLS playlist and marks it ready; allocation failure cancels output.

## Possible causes

- A default or advertising subtitle playlist has been generated from loaded subtitle data and its requested time range.
