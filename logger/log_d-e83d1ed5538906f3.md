# SCTE-35 default packet changed

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-e83d1ed5538906f3

## Log pattern

```text
updateAvailable scte35 pid changed from %d to %d
```

## Parameters

- Argument 1 — previous\_packet\_id: Previously active packet identifier.
- Argument 2 — default\_packet\_id: Current default identifier, possibly zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable scte35 pid changed from 300 to 301
```

## Short description

SCTE-35 default packet changed.

## Trigger condition

SCTE-35 processing is enabled and the nonzero active identifier differs from the current default.

## Explanation

A nonzero new default replaces the active identifier and is requested. If the new default is zero, this branch leaves the stored old identifier unchanged but does not request it here.
