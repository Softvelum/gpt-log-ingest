# Scheduled Icecast advertisement is not ready

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-1917e7d24639fdd0

## Log pattern

```text
failed to load cache item for content id=%s uri=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load cache item for content id=ad-01 uri=https://media.example/ad.mp4
```

## Short description

Scheduled Icecast advertisement is not ready.

## Trigger condition

The scheduled advertisement has no active reader and its content is not ready.

## Explanation

Processing next chooses to wait, skip, or finish the session according to content location and the rule error policy.

## Possible causes

- The scheduled advertisement has no active reader and its content is not ready.

## What to check

1. Check the content download and the rule wait and error policy.

## Recommended action

Check the content download and the rule wait and error policy.
