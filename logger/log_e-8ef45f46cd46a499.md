# HTTP/3 traffic-class reporting could not be enabled

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-8ef45f46cd46a499

## Log pattern

```text
failed to set IP_RECVTOS|IPV6_RECVTCLASS, errno=%d socket=%d
```

## Parameters

- Argument 1 — System error: Platform socket-error result.
- Argument 2 — Socket: Integer HTTP/3 UDP socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set IP_RECVTOS|IPV6_RECVTCLASS, errno=22 socket=12
```

## Short description

HTTP/3 traffic-class reporting could not be enabled.

## Trigger condition

HTTP/3 congestion notification is enabled and enabling IPv4 type-of-service or IPv6 traffic-class metadata fails. This path requires HTTP/3 support and a configuration that needs it.

## Explanation

Socket-option setup returns failure and server initialization exits with a failure status.

## Possible causes

- HTTP/3 congestion notification is enabled and enabling IPv4 type-of-service or IPv6 traffic-class metadata fails.

## What to check

1. Inspect the failed option and socket error.
