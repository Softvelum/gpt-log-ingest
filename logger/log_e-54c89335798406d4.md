# Unrecognized socket event

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-54c89335798406d4

## Log pattern

```text
unknown event for s=%d ev=0x%x
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the affected local socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown event for s=17 ev=0x10
```

## Short description

Unrecognized socket event.

## Trigger condition

A socket event does not match the events handled by the current HTTP or advertising session, or by a TLS HLS/HTTP input player.

## Explanation

The general HTTP and advertising branches terminate the session; TLS-specific advertising and input-player branches only log the event. The same text therefore does not always indicate immediate closure.

## Possible causes

- A socket event does not match the events handled by the current HTTP or advertising session, or by a TLS HLS/HTTP input player.

## What to check

1. Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.

## Recommended action

Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.
