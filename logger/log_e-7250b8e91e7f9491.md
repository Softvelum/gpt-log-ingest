# Could not create the RTSP connection worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-7250b8e91e7f9491

## Log pattern

```text
failed to create RTSP server thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create RTSP server thread
```

## Short description

Could not create the RTSP connection worker.

## Trigger condition

The RTSP server worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the RTSP connection worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed RTSP connection worker.
