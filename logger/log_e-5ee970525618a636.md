# VAAPI surface is too small for the input frame

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-5ee970525618a636

## Log pattern

```text
failed to copy frame format=%d %dx%d to fourcc=%x %dx%d
```

## Parameters

- Argument 1 — Pixel format: Input FFmpeg pixel-format identifier, integer enumeration value; no unit.
- Argument 2 — Input width: Input frame width, integer pixels.
- Argument 3 — Input height: Input frame height, integer pixels.
- Argument 4 — Surface format: Derived image FourCC, unsigned integer printed in hexadecimal; NV12 is 3231564e.
- Argument 5 — Surface pitch: Destination first-plane row stride, unsigned integer bytes; this is not image width.
- Argument 6 — Surface height: Destination image height, integer pixels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to copy frame format=0 1920x1080 to fourcc=3231564e 1280x720
```

## Short description

VAAPI surface is too small for the input frame.

## Trigger condition

The derived NV12 image row pitch is less than input width, or its height is less than input height.

## Explanation

Pixel copying is skipped and frame encoding fails.

## Possible causes

- Input dimensions exceed the existing surface layout, including a possible dimension change after initialization.

## What to check

1. Compare input width and height with the reported destination pitch and height.

## Recommended action

Keep input dimensions compatible with the initialized encoder or recreate the encoder after a size change.
