# Stream-check hostname resolved

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-24a640c98f295208

## Log pattern

```text
resolved '%s' -> '%s' task='%s'
```

## Parameters

- Argument 1 — host: Origin host name from the task URL.
- Argument 2 — address: Selected IPv4 address.
- Argument 3 — task: Panel-supplied stream-check task identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
resolved 'media.example' -> '192.0.2.20' task='check-a'
```

## Short description

Stream-check hostname resolved.

## Trigger condition

The task hostname is resolved through the per-batch DNS cache.

## Explanation

One returned address is chosen for the current attempt and the remaining addresses are retained for later connection attempts.
