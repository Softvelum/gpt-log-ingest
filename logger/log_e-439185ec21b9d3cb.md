# Cannot obtain local SRT address

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-439185ec21b9d3cb

## Log pattern

```text
srt_getsockname failed for s=%d: %s
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.
- Argument 2 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_getsockname failed for s=100: Invalid socket ID
```

## Short description

Cannot obtain local SRT address.

## Trigger condition

Reading the local address associated with an SRT socket fails.

## Explanation

The address helper returns an empty address. Callers may consequently omit session reporting or address details.

## Possible causes

- Reading the local address associated with an SRT socket fails.

## What to check

1. Inspect the SRT error and socket state.
