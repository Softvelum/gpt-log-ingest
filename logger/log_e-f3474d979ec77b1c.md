# WHIP application credentials rejected

Product: Nimble Streamer
Component: WHIP publishing authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-f3474d979ec77b1c

## Log pattern

```text
WHIP publish not authorized as login/password incorrect stream=[%s/%s] ip=[%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.
- Argument 3 — Client address: Publisher IP address supplied with the request, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WHIP publish not authorized as login/password incorrect stream=[live/camera] ip=[192.0.2.10]
```

## Short description

WHIP application credentials rejected.

## Trigger condition

A WHIP request uses application credentials without a publish signature and its credential string differs from the configured login followed by a colon and password.

## Explanation

The WHIP session is not created; the caller receives no session.

## Possible causes

- The supplied login/password pair does not match the application settings.

## What to check

1. Compare the publisher credentials with the named application settings.

## Recommended action

Correct the publisher credentials and retry publication.
