# RTMP response transaction ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-c56170a6ec1824ca

## Log pattern

```text
failed to process transaction id for _result command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process transaction id for _result command
```

## Short description

RTMP response transaction ID cannot be decoded.

## Trigger condition

An outbound pull or publish connection receives an _result or onStatus command whose transaction ID cannot be read as an AMF number.

## Explanation

Response processing fails and the connection is stopped. The text names _result even when the malformed response is onStatus.

## Possible causes

- An outbound pull or publish connection receives an _result or onStatus command whose transaction ID cannot be read as an AMF number.

## What to check

1. Check the remote server response for a numeric transaction ID immediately after the command name.

## Recommended action

Correct the malformed AMF response at the remote endpoint.
