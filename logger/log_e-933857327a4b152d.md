# Audio codec is unsupported for the requested operation

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-933857327a4b152d

## Log pattern

```text
unsupported audio codec=%d
```

## Parameters

- Argument 1 — Codec identifier: Integer codec value; scenario audio and DVR archive paths use different codec enumerations.

This shared format covers scenario input configuration and DVR audio muting.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audio codec=0
```

## Short description

Audio codec is unsupported for the requested operation.

## Trigger condition

Scenario input codec setup receives an unrecognized audio codec, or DVR muting is requested for audio other than AAC or MP3.

## Explanation

Scenario setup returns failure without installing the codec. DVR muting returns failure before changing the recorded segment.

## Possible causes

- Scenario input codec setup receives an unrecognized audio codec, or DVR muting is requested for audio other than AAC or MP3.

## What to check

1. Identify whether the message concerns scenario input or DVR muting and check the applicable codec support.

## Recommended action

Use a codec supported by the requested operation.
