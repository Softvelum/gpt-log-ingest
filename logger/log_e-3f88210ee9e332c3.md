# NVIDIA encoded-output lock failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-3f88210ee9e332c3

## Log pattern

```text
failed to lock output bitstream encoder=%p, status=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to lock output bitstream encoder=0x12340000, status=8
```

## Short description

NVIDIA encoded-output lock failed.

## Trigger condition

Locking the oldest pending bitstream buffer to read encoded output returns an error.

## Explanation

The frame write returns failure without completing that queued output.

## Possible causes

- The NVIDIA encoder API rejects this buffer or picture operation.

## What to check

1. Check pending encoder output, driver state and the status code.

## Recommended action

Correct the reported driver/resource or encoder-state problem before retrying.
