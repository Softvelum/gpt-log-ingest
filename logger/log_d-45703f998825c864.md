# Generated media header bytes are being combined

Product: Nimble Streamer
Component: Non-Windows progressive download modules
Logging function: log_d
Log level: debug
Documentation ID: log_d-45703f998825c864

## Log pattern

```text
buffer_content_length=%lu
```

## Parameters

- Argument 1 — bytes: Total in-memory output bytes before the file segment.

The signed platform byte count is displayed with an unsigned-long conversion; the positive example assumes a build with compatible widths.

## Log examples

Illustrative examples; these are not captured server logs.

```text
buffer_content_length=128
```

## Short description

Generated media header bytes are being combined.

## Trigger condition

A valid FLV or MP4 output chain contains a nonzero total of memory-buffer bytes.

## Explanation

The wrapper allocates a combined memory buffer for generated headers and pairs it with the file segment for HTTP output.
