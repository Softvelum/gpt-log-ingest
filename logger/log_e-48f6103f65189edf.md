# Encrypted URL data decodes to no bytes

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-48f6103f65189edf

## Log pattern

```text
BIO_read failed read 0 bytes
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
BIO_read failed read 0 bytes
```

## Short description

Encrypted URL data decodes to no bytes.

## Trigger condition

Base64 decoding the encrypted URL returns exactly zero bytes.

## Explanation

URL validation returns failure without assigning a decrypted URL.

## Possible causes

- No ciphertext bytes were recovered from the supplied encoded URL.

## What to check

1. Check that all encrypted-link fields are complete and correctly encoded.

## Recommended action

Regenerate the complete encrypted link with matching fields.
