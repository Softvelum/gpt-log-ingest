# Internal HTTP request service is unavailable

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-f72518b92b139b13

## Log pattern

```text
requests_processor_ is not assigned
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
requests_processor_ is not assigned
```

## Short description

Internal HTTP request service is unavailable.

## Trigger condition

A component requests access to the internal HTTP request processor before one has been assigned.

## Explanation

An error is logged and a runtime exception is thrown. The processor is normally assigned to the first successfully created HTTP worker.

## Possible causes

- The internal request processor has not been assigned.

## What to check

1. Check whether initial HTTP worker creation completed.
