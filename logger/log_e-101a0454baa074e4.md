# Could not create the advertising license worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-101a0454baa074e4

## Log pattern

```text

```

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Could not create the advertising license worker.

## Trigger condition

The advertising license verification worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the advertising license worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed advertising license worker.
