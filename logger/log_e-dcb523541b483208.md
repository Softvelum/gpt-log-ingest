# Could not create the Whisper transcription worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-dcb523541b483208

## Log pattern

```text
failed to create whisper thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create whisper thread
```

## Short description

Could not create the Whisper transcription worker.

## Trigger condition

Whisper support is compiled in and its transcription worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the Whisper transcription worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed Whisper transcription worker.
