# CUDA decoder context activation failed

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-7767dd3aab7b7233

## Log pattern

```text
failed to push cuda ctx, res=%d
```

## Parameters

- Argument 1 — CUDA status: CUDA driver result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to push cuda ctx, res=2
```

## Short description

CUDA decoder context activation failed.

## Trigger condition

After obtaining a nonshared decoder context, pushing it onto the current thread context stack returns an error.

## Explanation

Decoder context setup returns failure.

## Possible causes

- The CUDA driver rejects the reported context operation.

## What to check

1. Check the CUDA result, device access, available GPU resources and preceding context diagnostics.

## Recommended action

Correct the driver or resource problem and retry context setup.
