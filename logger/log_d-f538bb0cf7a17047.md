# Managed task process wait returned a result

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_d
Log level: debug
Documentation ID: log_d-f538bb0cf7a17047

## Log pattern

```text
CheckFinishedTasks pid=%d errno=%d wifexited=%d wifstopped=%d wifsignaled=%d
```

## Parameters

- Argument 1 — Process: Integer task process identifier.
- Argument 2 — System error: Integer operating-system error value; it may be stale unless the preceding operation failed.
- Argument 3 — Exited: Nonzero when normal process exit was reported.
- Argument 4 — Stopped: Nonzero when a stopped process was reported.
- Argument 5 — Signaled: Nonzero when termination by signal was reported.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CheckFinishedTasks pid=1234 errno=0 wifexited=1 wifstopped=0 wifsignaled=0
```

## Short description

Managed task process wait returned a result.

## Trigger condition

A nonblocking wait for any child process returns a nonzero result, including an error result. Available only on Linux builds.

## Explanation

The process identifier and status flags are reported before looking for a matching managed task. An error result does not identify a completed task.
