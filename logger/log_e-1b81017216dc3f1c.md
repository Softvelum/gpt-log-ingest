# Invalid access-control regular expression skipped

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_e
Log level: error
Documentation ID: log_e-1b81017216dc3f1c

## Log pattern

```text
UserAgentManager: [%s] is wrong regex pattern
```

## Parameters

- Argument 1 — Pattern: Configured regular expression that could not be compiled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
UserAgentManager: [[] is wrong regex pattern
```

## Short description

Invalid access-control regular expression skipped.

## Trigger condition

Compiling a configured user-agent or referrer group pattern throws a regular-expression error.

## Explanation

The invalid pattern is omitted from the compiled group while valid patterns remain. The diagnostic names user-agent management even for the shared referrer-group path.

## Possible causes

- Compiling a configured user-agent or referrer group pattern throws a regular-expression error.

## What to check

1. Check the displayed regular expression.

## Recommended action

Correct the invalid group pattern.
