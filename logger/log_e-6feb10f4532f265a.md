# NVIDIA output codec is unsupported

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_e
Log level: error
Documentation ID: log_e-6feb10f4532f265a

## Log pattern

```text
unsupported nvenc codec: %s
```

## Parameters

- Argument 1 — Codec: Requested output codec option, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported nvenc codec: unsupported_codec
```

## Short description

NVIDIA output codec is unsupported.

## Trigger condition

The selected native NVIDIA backend is available, but its requested codec string is outside the accepted set.

## Explanation

Encoder creation fails and the output worker cannot continue.

## Possible causes

- The configured codec is incompatible with this backend; accepted values are h264 or h265, plus av1 when built with encoder API version 12 or newer.

## What to check

1. Check the backend and exact codec option value.

## Recommended action

Select a supported codec or a backend that provides the required codec.
