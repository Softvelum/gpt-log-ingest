# SRT peer connection attempt failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-876562c585806fab

## Log pattern

```text
failed to connect to %s:%d, s=%d: %s
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Socket: SRT socket identifier.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect to 192.0.2.10:9000, s=100: Connection setup failure
```

## Short description

SRT peer connection attempt failed.

## Trigger condition

The SRT library rejects the peer-connect call for a pull, push, or rendezvous socket.

## Explanation

Connection setup returns failure. The message is shared by ingest and regular or constant-bitrate output.

## Possible causes

- The SRT library rejects the peer-connect call for a pull, push, or rendezvous socket.

## What to check

1. Check the endpoint, connection mode, and library error.
