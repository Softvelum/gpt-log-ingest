# Audio settings update has an invalid state

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_e
Log level: error
Documentation ID: log_e-81eb914851834e51

## Log pattern

```text
failed to update audio encoder, sync_stream=%d state=%d for %s/%s
```

## Parameters

- Argument 1 — Synchronization mode: Integer mode: 0 leaves timestamps unchanged, 1 aligns video to audio, 2 aligns audio to video.
- Argument 2 — Processing state: Integer state: 0 initial, 1 video only, 2 audio only, 3 processing audio after video, 4 processing video with audio paused, 5 waiting for video, 6 waiting for audio, 7 finding first audio, 8 processing audio with video paused.
- Argument 3 — Application: Output application name, text.
- Argument 4 — Stream: Output stream name, text.

Separate occurrences guard each of the three synchronization modes and the default unrecognized-mode branch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to update audio encoder, sync_stream=2 state=0 for live/encoded
```

## Short description

Audio settings update has an invalid state.

## Trigger condition

The audio settings update encounters an unrecognized synchronization mode or a processing state not accepted for that mode.

## Explanation

The update fails and the encoder worker leaves its processing loop.

## Possible causes

- The current lifecycle state is inconsistent with the requested synchronization mode during an input or scenario change.

## What to check

1. Check the printed mode and state against the source changes immediately before the failure.

## Recommended action

Restart the affected output with consistent audio/video settings; investigate a reproducible transition failure.
