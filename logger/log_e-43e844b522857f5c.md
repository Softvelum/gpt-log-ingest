# RTMP listening interface could not be created

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-43e844b522857f5c

## Log pattern

```text
failed to bind rtmp socket %s:%d
```

## Parameters

- Argument 1 — address: Requested listening IP address.
- Argument 2 — port: Requested listening TCP port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to bind rtmp socket 0.0.0.0:1935
```

## Short description

RTMP listening interface could not be created.

## Trigger condition

Adding a new RTMP listener for an updated interface fails.

## Explanation

Other interfaces continue to be processed. The configuration marker is not advanced, allowing a later synchronization attempt to retry.

## Possible causes

- The listener could not be created or bound.

## What to check

1. Check adjacent socket errors, address availability, and port use.

## Recommended action

Correct the listening address or socket resource problem.
