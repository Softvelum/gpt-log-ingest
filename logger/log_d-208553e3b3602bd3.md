# RTCP connection destroyed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-208553e3b3602bd3

## Log pattern

```text
rtcp close, s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtcp close, s=25
```

## Short description

RTCP connection destroyed.

## Trigger condition

The RTCP connection is being destroyed.

## Explanation

Its parent RTSP input is asked to shut down when still attached. The message marks cleanup rather than explaining the original reason for disconnection.

## Possible causes

- The connection lifetime has ended.

## What to check

1. If the disconnection was unexpected, check preceding messages for the same socket.
