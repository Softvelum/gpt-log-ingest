# External response is ready for status handling

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_d
Log level: debug
Documentation ID: log_d-28dd018f880bb570

## Log pattern

```text
response is ready:
%.*s
```

## Parameters

- Argument 1 — header length: Maximum number of header bytes requested for printing.
- Argument 2 — headers: Response header text, limited by the supplied precision.

The header precision is a platform-sized byte count passed where the format requires an int.

## Log examples

No portable example is provided because the precision argument has the wrong type.

## Short description

External response is ready for status handling.

## Trigger condition

The parser completes a normal response, completes HEAD headers, or recognizes a supported redirect.

## Explanation

Only the response headers are printed. Status handling, redirection, and success or failure callbacks follow, so ready does not itself mean success.
