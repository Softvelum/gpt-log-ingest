# Cannot set SRT retransmission algorithm

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-985188f3bfc748f9

## Log pattern

```text
failed to set retransmitalgo=%s, s=%d
```

## Parameters

- Argument 1 — Value: Original configuration string before conversion to flag zero or one.
- Argument 2 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set retransmitalgo=1, s=100
```

## Short description

Cannot set SRT retransmission algorithm.

## Trigger condition

The SRT library rejects the selected retransmission-algorithm flag.

## Explanation

The text value 1 selects flag one; every other configured value selects zero. Settings application fails.

## Possible causes

- The SRT library rejects the selected retransmission-algorithm flag.

## What to check

1. Check library support and the requested retransmission algorithm.
