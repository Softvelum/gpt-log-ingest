# Quick Sync crop offset is unsupported

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-617df136e9c27b9e

## Log pattern

```text
unsupported crop: %d,%d,%d,%d
```

## Parameters

- Argument 1 — X: Crop horizontal origin, integer pixels.
- Argument 2 — Y: Crop vertical origin, integer pixels.
- Argument 3 — Width: Crop width, integer pixels.
- Argument 4 — Height: Crop height, integer pixels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported crop: 8,0,1920,1080
```

## Short description

Quick Sync crop offset is unsupported.

## Trigger condition

The parsed video header specifies a nonzero horizontal or vertical crop origin.

## Explanation

Decoder initialization stops; the width and height are reported along with the rejected origin.

## Possible causes

- The video sequence requires a crop that starts away from the top-left corner.

## What to check

1. Check the input sequence crop origin and dimensions.

## Recommended action

Supply video with a zero crop origin or select another decoder.
