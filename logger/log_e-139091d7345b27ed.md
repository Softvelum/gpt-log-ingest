# Video filter input could not be connected

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-139091d7345b27ed

## Log pattern

```text
failed to link buffer='%s', filter=%s, stream=%s
```

## Parameters

- Argument 1 — Input settings: Generated video-source settings containing dimensions, format, time base, pixel aspect ratio, and optionally frame rate; text.
- Argument 2 — Filter: Complete configured video filter expression, text.
- Argument 3 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to link buffer='video_size=1920x1080:pix_fmt=0:time_base=1/1000:pixel_aspect=1/1', filter=[in]null[out], stream=live/camera
```

## Short description

Video filter input could not be connected.

## Trigger condition

FFmpeg cannot connect the video-buffer input with the reported input settings.

## Explanation

Video input setup fails and the frame is not processed.

## Possible causes

- The generated video input parameters or graph connection were rejected.

## What to check

1. Compare the generated input settings with the configured filter.

## Recommended action

Correct the input format or filter connection.
