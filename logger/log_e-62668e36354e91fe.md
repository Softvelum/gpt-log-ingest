# CUDA cache context allocation failed

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-62668e36354e91fe

## Log pattern

```text
failed to create cuda context, gpu=%d, flag=%d
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 2 — Flags: CUDA context creation flags, integer bit mask printed in decimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create cuda context, gpu=0, flag=0
```

## Short description

CUDA cache context allocation failed.

## Trigger condition

The context creation helper fails during a cache fill batch.

## Explanation

This context is not added to the cache; the batch continues with its remaining attempts.

## Possible causes

- The GPU index is unavailable, CUDA context creation fails, or detaching the context from the thread fails.

## What to check

1. Check the preceding GPU, creation or detach error for this attempt.

## Recommended action

Correct that error if the requested cache capacity is needed.
