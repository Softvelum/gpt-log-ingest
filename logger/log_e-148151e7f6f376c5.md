# Could not create the pay-per-view authorization worker

Product: Nimble Streamer

## Short description

Could not create the pay-per-view authorization worker.

## Trigger condition

The pay-per-view authorization worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the pay-per-view authorization worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed pay-per-view authorization worker.
