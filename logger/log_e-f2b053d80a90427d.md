# Socket event registration could not remove

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-f2b053d80a90427d

## Log pattern

```text
epoll_ctl epfd=%d DEL failed fd=%d (errno=%d)
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Socket: Socket descriptor, integer; no unit.
- Argument 3 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
epoll_ctl epfd=10 DEL failed fd=12 (errno=5)
```

## Short description

Socket event registration could not remove.

## Trigger condition

Linux rejects an attempt to remove a descriptor in the event monitor.

## Explanation

The kernel removal fails. Pending events already held by the current dispatch loop are suppressed for this descriptor. The operation reports failure.

## Possible causes

- The operating system rejected the requested monitor operation.

## What to check

1. Check the monitor descriptor, socket descriptor, requested events, and operating system error.

## Recommended action

Correct the reported monitor operation failure.
