# Transcription subtitle queued

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_d
Log level: debug
Documentation ID: log_d-2a839782d0ef6f56

## Log pattern

```text
queue_subtitle t0=%lld t1=%lld text=%s lang=%s for stream='%s'
```

## Parameters

- Argument 1 — Start: Subtitle start timestamp in milliseconds, converted from a 90 kHz timestamp.
- Argument 2 — End: Subtitle end timestamp in milliseconds, converted from a 90 kHz timestamp.
- Argument 3 — Text: Subtitle text.
- Argument 4 — Language: Three-letter subtitle language code.
- Argument 5 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
queue_subtitle t0=1000 t1=3500 text=Good morning. lang=eng for stream='live/news'
```

## Short description

Transcription subtitle queued.

## Trigger condition

A transcript or translation segment is packaged for delivery to the parent media process.

## Explanation

The subtitle includes start and end timestamps, text, and a three-letter language code. This debug message records queuing, before delivery to the parent.

## Possible causes

- A transcript or translation segment is packaged for delivery to the parent media process.

## What to check

1. Compare the subtitle timing, text, and language with the requested stream.
