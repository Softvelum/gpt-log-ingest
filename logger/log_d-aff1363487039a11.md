# TLS shutdown returned without an error

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-aff1363487039a11

## Log pattern

```text
SSL_shutdown %s ssl=%p s=%d
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — TLS session: TLS session address used for diagnostic correlation.
- Argument 3 — Socket: Integer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SSL_shutdown client ssl=0x1000 s=12
```

## Short description

TLS shutdown returned without an error.

## Trigger condition

TLS shutdown returns a nonnegative result.

## Explanation

The helper returns true for both complete shutdown and the non-error intermediate return. This message does not distinguish those two outcomes.
