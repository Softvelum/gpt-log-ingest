# Quick Sync encoder parameter sets could not be retrieved

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-bb916af45df02280

## Log pattern

```text
%p quick sync failed to get sps/pps, ret=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 quick sync failed to get sps/pps, ret=-3
```

## Short description

Quick Sync encoder parameter sets could not be retrieved.

## Trigger condition

Retrieving initialized encoder parameters, including SPS/PPS and HEVC VPS where applicable, returns a negative status.

## Explanation

Encoder initialization fails before output configuration is built.

## Possible causes

- The runtime cannot provide the initialized codec parameter sets.

## What to check

1. Check the status, codec, and preceding encoder initialization messages.

## Recommended action

Correct the runtime or codec configuration issue and restart encoding.
