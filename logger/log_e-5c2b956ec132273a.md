# Cannot accept constant-bitrate SRT receiver

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-5c2b956ec132273a

## Log pattern

```text
failed to accept srt cbr sender, s=%d
```

## Parameters

- Argument 1 — Listener: SRT listening socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to accept srt cbr sender, s=100
```

## Short description

Cannot accept constant-bitrate SRT receiver.

## Trigger condition

Accepting or initializing a receiver through the constant-bitrate listener fails.

## Explanation

No new sender is registered for that receiver. This path is available on non-Windows builds.

## Possible causes

- Accepting or initializing a receiver through the constant-bitrate listener fails.

## What to check

1. Inspect earlier accept, stream-selection, or session-registration errors.
