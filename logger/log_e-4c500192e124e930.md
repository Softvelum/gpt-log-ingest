# RTSP video encoding is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-4c500192e124e930

## Log pattern

```text
unsupported video codec='%s' stream url='%s'
```

## Parameters

- Argument 1 — Encoding: SDP video encoding name.
- Argument 2 — Stream URL: RTSP input base URL identifying the affected source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video codec='unsupported-video' stream url='rtsp://192.0.2.1/live'
```

## Short description

RTSP video encoding is unsupported.

## Trigger condition

The SDP video encoding is neither H264, H265, VP8, nor VP9.

## Explanation

RTSP codec selection returns failure and leaves the media type unselected.

## Possible causes

- The SDP video encoding is neither H264, H265, VP8, nor VP9.

## What to check

1. Check the video encoding advertised by the source.

## Recommended action

Use H.264, H.265, VP8, or VP9 for this RTSP input.
