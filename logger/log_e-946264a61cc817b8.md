# DVB subtitle bitmap plane is truncated

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_e
Log level: error
Documentation ID: log_e-946264a61cc817b8

## Log pattern

```text
wrong main plane size
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
wrong main plane size
```

## Short description

DVB subtitle bitmap plane is truncated.

## Trigger condition

The declared rectangle line size multiplied by height exceeds the remaining message bytes.

## Explanation

The subtitle message is rejected before text recognition.

## Possible causes

- The declared rectangle line size multiplied by height exceeds the remaining message bytes.

## What to check

1. Check the rectangle dimensions, line size, and transmitted bitmap payload.
