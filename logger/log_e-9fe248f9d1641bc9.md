# VCAS settings disappeared after key creation

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-9fe248f9d1641bc9

## Log pattern

```text
key server not found after processing VCAS CreateKey response keys_for='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
key server not found after processing VCAS CreateKey response keys_for='live/camera'
```

## Short description

VCAS settings disappeared after key creation.

## Trigger condition

A successful create-key response no longer has matching application key-server settings.

## Explanation

The returned key is not installed.

## Possible causes

- A successful create-key response no longer has matching application key-server settings.

## What to check

1. Check DRM settings changes while the key request was pending.

## Recommended action

Check DRM settings changes while the key request was pending.
