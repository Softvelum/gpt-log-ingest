# Invalid KWIKmotion metadata item skipped

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-f73280a13f1d491b

## Log pattern

```text
invalid metadata_type type=%d
```

## Parameters

- Argument 1 — Type: Numeric JSON value type of the rejected item; the log does not name that type.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid metadata_type type=3
```

## Short description

Invalid KWIKmotion metadata item skipped.

## Trigger condition

A transcript or translation metadata array item is not a JSON object.

## Explanation

That metadata item is skipped while the remaining items are examined. It cannot provide subtitle text or timestamps.

## Possible causes

- A transcript or translation metadata array item is not a JSON object.

## What to check

1. Check that service metadata entries are JSON objects.
