# Socket event has no owning session

Product: Nimble Streamer
Component: Socket event handling
Logging function: log_e
Log level: error
Documentation ID: log_e-dd604e13a3e694b6

## Log pattern

```text
unknown socket fd=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.

All four occurrences close the unrecognized descriptor; the eligible owning connection types differ by worker.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown socket fd=12
```

## Short description

Socket event has no owning session.

## Trigger condition

A socket event reaches the scenario manager, WHIP worker, WHEP control worker or WHEP media worker, but no listener, pending connection, control connection or active session owns that descriptor in the relevant worker.

## Explanation

The worker removes the descriptor from event monitoring and closes it.

## Possible causes

- The descriptor has no corresponding connection or session in the worker handling the event.

## What to check

1. Correlate the descriptor with preceding connection creation, handoff and cleanup messages.

## Recommended action

If this repeats, investigate the connection lifecycle for the affected worker; the orphan socket is already closed.
