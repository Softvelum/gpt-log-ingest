# Cannot load SRT password-settings file

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-73bb7886b60b1967

## Log pattern

```text
[srt_listen_callback] failed to open [%s] for streamid=[%s],ip=[%s]
```

## Parameters

- Argument 1 — File: Configured SRT password-settings file path.
- Argument 2 — Stream ID: Requested SRT stream identifier.
- Argument 3 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] failed to open [/data/srt-users.json] for streamid=[live/news?srtauth=example],ip=[192.0.2.20]
```

## Short description

Cannot load SRT password-settings file.

## Trigger condition

Reading the configured password-settings file fails during publisher handshake authentication.

## Explanation

The incoming connection is rejected before user settings can be applied.

## Possible causes

- Reading the configured password-settings file fails during publisher handshake authentication.

## What to check

1. Check the configured file path and readability.

## Recommended action

Restore access to the intended password-settings file.
