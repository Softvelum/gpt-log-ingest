# HLS advertising content is missing

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-49367b829fe3a245

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu failed to get content=%s
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.
- Argument 5 — Content ID: Identifier of the selected advertising item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
app=live stream=camera stream_name=live/camera session=123 failed to get content=ad-1
```

## Short description

HLS advertising content is missing.

## Trigger condition

The advertising content manager cannot find the selected content identifier.

## Explanation

The session playlist update fails before an advertising playlist can be requested for this item.

## Possible causes

- The advertising content manager cannot find the selected content identifier.

## What to check

1. Check whether the selected content still exists in the advertising configuration/cache.

## Recommended action

Restore the referenced content or correct the rule selecting it.
