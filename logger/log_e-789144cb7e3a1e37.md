# OMT sender creation failed

Product: Nimble Streamer
Component: OMT media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-789144cb7e3a1e37

## Log pattern

```text
failed to create omt sender for [%s]
```

## Parameters

- Argument 1 — OMT name: Requested output name or resolved full input source name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create omt sender for [Output]
```

## Short description

OMT sender creation failed.

## Trigger condition

The first outgoing message requires a sender and the OMT library returns no sender instance.

## Explanation

Message processing fails before media or timecode dispatch.

## Possible causes

- The first outgoing message requires a sender and the OMT library returns no sender instance.

## What to check

1. Check whether an OMT sender can be created for the requested name and quality.
