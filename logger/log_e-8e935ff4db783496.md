# HLS advertising reaches an unexpected phase

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-8e935ff4db783496

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu, wrong advertiser state=%d
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.
- Argument 5 — State: Numeric advertising phase not handled at this point in chunk insertion.

## Log examples

No normal-flow illustrative state is established: initial phases are handled before this loop and its normal transitions use the supported insertion phases.

## Short description

HLS advertising reaches an unexpected phase.

## Trigger condition

Chunk insertion encounters a state outside the phases handled by its processing loop.

## Explanation

The advertising playlist update fails; the log reports the numeric phase reached.

## Possible causes

- Chunk insertion encounters a state outside the phases handled by its processing loop.

## What to check

1. Check preceding rule, content, playlist, and remainder transitions.

## Recommended action

Report the unexpected advertising phase to support.
