# Cannot apply selected stream to SRT output

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-5d90e99f35a973ea

## Log pattern

```text
failed to patch stream settings s=%d, streamid=%s
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.
- Argument 2 — Stream ID: Requested SRT stream identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to patch stream settings s=101, streamid=/live/news
```

## Short description

Cannot apply selected stream to SRT output.

## Trigger condition

After resolving a wildcard receiver request, synchronizing the sender with that stream and its buffer fails.

## Explanation

Session setup fails before output starts.

## Possible causes

- After resolving a wildcard receiver request, synchronizing the sender with that stream and its buffer fails.

## What to check

1. Check source-stream availability and current output settings.
