# Initial buffer offset is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-5a4ce8e75119f885

## Log pattern

```text
invalid parameter value: %s. should be >= 0 && <= 1024
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 0 && <= 1024
```

## Short description

Initial buffer offset is invalid.

## Trigger condition

While reading configuration, the RTMP, decoder, or DVR initial buffer offset is outside 0 through 1024.

## Explanation

Configuration processing reports failure and the file loader stops at this line. The parsed value is assigned before the failure is returned; this message does not mean it was clamped to a valid range.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires an offset from 0 through 1024 items.

## Recommended action

Correct the value to an offset from 0 through 1024 items and reload configuration.
