# SMIL document has no body child

Product: Nimble Streamer
Component: SMIL media playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-352b1223acebc242

## Log pattern

```text
invalid SMIL(first root child not body) file=%s
```

## Parameters

- Argument 1 — SMIL filename: Text filename passed to the XML reader. It is a local SMIL path or the local cache-fragment filename for a downloaded SMIL document.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid SMIL(first root child not body) file=/media/movie.smil
```

## Short description

SMIL document has no body child.

## Trigger condition

The smil root has no direct child element named body. The search checks every direct element child; body does not have to be the first child despite the fixed log wording.

## Explanation

HLS playlist generation, including fragmented-MP4 HLS, returns failure and the HTTP caller prepares HTTP 500. DASH input discovery returns an empty item list, so its HTTP caller prepares HTTP 404. No requested playlist or manifest is generated from this document.

## Possible causes

- The smil root has no direct child element named body. The search checks every direct element child; body does not have to be the first child despite the fixed log wording.

## What to check

1. Place a lowercase body element directly under the smil root. A body nested inside another child does not satisfy this check.

## Recommended action

Place a lowercase body element directly under the smil root. A body nested inside another child does not satisfy this check.
