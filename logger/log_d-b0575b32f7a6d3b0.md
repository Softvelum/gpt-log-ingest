# DVR recording context created

Product: Nimble Streamer
Component: DVR recording
Logging function: log_d
Log level: debug
Documentation ID: log_d-b0575b32f7a6d3b0

## Log pattern

```text
creating dvr context for stream='%s' path='%s' video_timescale=%u audio_timescale=%u
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Archive directory: Text giving the recording directory.
- Argument 3 — Video timescale: Unsigned video ticks per second.
- Argument 4 — Audio timescale: Unsigned audio ticks per second.

## Log examples

Illustrative examples; these are not captured server logs.

```text
creating dvr context for stream='live/camera' path='/data/dvr/live/camera' video_timescale=90000 audio_timescale=48000
```

## Short description

DVR recording context created.

## Trigger condition

A recording context is constructed for a stream and archive.

## Explanation

Audio/video segment state is initialized and the live buffer is asked to retain decoding data.

## Possible causes

- A recording context is constructed for a stream and archive.
