# AJA card does not support the output frame-buffer format

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-c10ccd4296355189

## Log pattern

```text
Device '%s' doesn't support output framebuffer format '%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Pixel format: Runtime description of the requested device frame-buffer format.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device 'AJA device' doesn't support output framebuffer format 'Unsupported format'
```

## Short description

AJA card does not support the output frame-buffer format.

## Trigger condition

The card capability check rejects the requested frame-buffer pixel format.

## Explanation

Output video setup returns failure before creating its format description or configuring the card.

## Possible causes

- The card capability check rejects the requested frame-buffer pixel format.

## What to check

1. Check device support for the selected frame-buffer pixel format.

## Recommended action

Use a frame-buffer format supported by the card.
