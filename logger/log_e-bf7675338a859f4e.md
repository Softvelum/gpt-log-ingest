# MPEG-4 generic RTSP audio mode is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-bf7675338a859f4e

## Log pattern

```text
unsupported audio codec='%s %s' stream url='%s'
```

## Parameters

- Argument 1 — Encoding: SDP audio encoding name.
- Argument 2 — Mode: SDP audio mode string.
- Argument 3 — Stream URL: RTSP input base URL identifying the affected source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audio codec='mpeg4-generic AAC-lbr' stream url='rtsp://192.0.2.1/live'
```

## Short description

MPEG-4 generic RTSP audio mode is unsupported.

## Trigger condition

The audio encoding is mpeg4-generic but its mode is not AAC-hbr.

## Explanation

RTSP audio codec selection returns failure before AAC configuration is parsed.

## Possible causes

- The audio encoding is mpeg4-generic but its mode is not AAC-hbr.

## What to check

1. Check the mode associated with the mpeg4-generic SDP encoding.

## Recommended action

Use AAC-hbr for MPEG-4 generic AAC input.
