# VAAPI rate-control buffer unmapping failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-34ae3b104db7e594

## Log pattern

```text
%p failed to unmap rate control params buffer, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to unmap rate control params buffer, 0x1
```

## Short description

VAAPI rate-control buffer unmapping failed.

## Trigger condition

Constant or variable bitrate control parameters have been written. The driver returns a non-success status when asked to unmap the corresponding parameter buffer.

## Explanation

Encoder initialization fails. The buffer is destroyed.

## Possible causes

- The VA driver cannot unmap this encoding parameter buffer.

## What to check

1. Check the status, the corresponding encoding options, and device resource availability.

## Recommended action

Correct incompatible encoding options or restore the VA driver and device, then restart encoding.
