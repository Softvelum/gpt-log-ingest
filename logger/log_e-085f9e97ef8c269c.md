# Protected absolute URL could not be decrypted

Product: Nimble Streamer
Component: Request routing
Logging function: log_e
Log level: error
Documentation ID: log_e-085f9e97ef8c269c

## Log pattern

```text
failed to decrypt absolute url='%s' key='%s'
```

## Parameters

- Argument 1 — Request URL: Full original request URL including its encoded absolute-URL parameters.
- Argument 2 — Session key: Session-key bytes rendered as concatenated decimal values with at least two digits per byte.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decrypt absolute url='/nimble-absolute-url-/part.ts?nimbleabsoluteurl=bad&nimbleurlhash=bad&nimbleurliv=bad' key='00000000000000000000000000000000'
```

## Short description

Protected absolute URL could not be decrypted.

## Trigger condition

An absolute-URL request includes its encrypted path, hash and initialization-vector parameters, but decryption fails.

## Explanation

The request is classified as unable to process. The message includes the request URL and a textual session-key representation.

## Possible causes

- The protected URL could not be decoded or validated using the session key.

## What to check

1. Check the complete protected-URL parameter set and its associated session.
