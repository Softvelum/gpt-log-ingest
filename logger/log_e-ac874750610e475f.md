# AJA capture worker received no frames for five seconds

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-ac874750610e475f

## Log pattern

```text
Frame receive timeout for %s/%d
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Frame receive timeout for 0/0
```

## Short description

AJA capture worker received no frames for five seconds.

## Trigger condition

Polling yields no valid audio or video frame and more than five seconds have elapsed since the last received frame.

## Explanation

Polling returns failure, causing the worker to leave its processing loop and clean up the capture connection.

## Possible causes

- Polling yields no valid audio or video frame and more than five seconds have elapsed since the last received frame.

## What to check

1. Check the card input signal, capture state, and preceding capture errors.
