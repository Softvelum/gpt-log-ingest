# AJA sender parameters failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-d58c0f260e5528fb

## Log pattern

```text
sender init failed device=%s/%d reason='invalid params'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender init failed device=0/0 reason='invalid params'
```

## Short description

AJA sender parameters failed.

## Trigger condition

Starting the sender fails because output parameter validation fails.

## Explanation

Hardware setup is not attempted.

## Possible causes

- Starting the sender fails because output parameter validation fails.

## What to check

1. Check the preceding parameters diagnostics and the selected device/channel.
