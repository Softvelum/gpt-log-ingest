# Stream-check redirect URL is malformed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-94144055546cb608

## Log pattern

```text
location url = %s is invalid for %s task.
```

## Parameters

- Argument 1 — location: Invalid redirect location.
- Argument 2 — task: Panel-supplied stream-check task identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
location url = invalid is invalid for check-a task.
```

## Short description

Stream-check redirect URL is malformed.

## Trigger condition

A nonrelative redirect location lacks the required URL parts.

## Explanation

The task records an invalid-URL result and starts shutdown.

## Possible causes

- The origin returned a malformed absolute redirect URL.

## What to check

1. Check the redirect location header.

## Recommended action

Correct the origin redirect target.
