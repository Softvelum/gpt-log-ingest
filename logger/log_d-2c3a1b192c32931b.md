# Origin closed after the expected body

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-2c3a1b192c32931b

## Log pattern

```text
origin closed connection (%u of %u bytes received)
```

## Parameters

- Argument 1 — Received bytes: Unsigned 64-bit received body bytes, incorrectly printed with %u.
- Argument 2 — Expected bytes: Unsigned 64-bit expected body length, incorrectly printed with %u.

Both byte counts are unsigned 64-bit values supplied to %u conversions, so their printed values are not reliable.

## Log examples

Both byte counts are unsigned 64-bit values supplied to %u conversions, so their printed values are not reliable.

## Short description

Origin closed after the expected body.

## Trigger condition

An origin closure event arrives with at least the expected body byte count received.

## Explanation

The origin socket is closed and buffered client output may continue; the session finishes if the client has already gone.

## Possible causes

- An origin closure event arrives with at least the expected body byte count received.
