# Panel synchronization transport result

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-61eda71213a11260

## Log pattern

```text
sync status=%d
```

## Parameters

- Argument 1 — sync\_status: Transport result number: 0 success, 1 send failure, 2 receive failure, 3 invalid HTTP response, 4 TLS context creation failure, 5 TLS object creation failure, 6 TLS socket assignment failure, 7 partial TLS send, 8 TLS request-send failure, 9 TLS read failure, 10 internal error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync status=0
```

## Short description

Panel synchronization transport result.

## Trigger condition

A connected panel socket has completed a request attempt and has been shut down.

## Explanation

Success enters response processing, recovery reporting, and requested uploads. Other transport results continue to the retry delay; the value is a local transport classification, not the JSON status returned by the panel.
