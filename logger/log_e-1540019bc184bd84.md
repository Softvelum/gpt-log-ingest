# Cannot close tagged SRT socket

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-1540019bc184bd84

## Log pattern

```text
failed to close %s socket s=%d: %s
```

## Parameters

- Argument 1 — Role: Caller-provided socket role label.
- Argument 2 — Socket: SRT socket or group identifier.
- Argument 3 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to close mpeg2ts_srt_camera socket s=100: Invalid socket ID
```

## Short description

Cannot close tagged SRT socket.

## Trigger condition

The SRT library returns failure while closing a socket whose caller supplied a role label.

## Explanation

The close helper returns failure; this message does not prove the socket was closed.

## Possible causes

- The SRT library returns failure while closing a socket whose caller supplied a role label.

## What to check

1. Inspect the error and earlier socket lifecycle messages.
