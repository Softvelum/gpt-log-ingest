# WHEP media item send failed

Product: Nimble Streamer
Component: WHEP media delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-950a3b463f104ff5

## Log pattern

```text
failed to send item for whep session=%s
```

## Parameters

- Argument 1 — Playback session URL: Relative WHEP session deletion URL including its session signature, text; identifies this playback session.

Four occurrences cover zero-byte and hard negative sends for media payload and for metadata. Metadata can describe a media item or adaptive-bitrate choices; would-block keeps the pending item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send item for whep session=/live/camera/whep.stream?whepsign=example-session
```

## Short description

WHEP media item send failed.

## Trigger condition

Sending media payload or its length/JSON metadata returns zero, or a negative error other than would-block.

## Explanation

The worker removes the session from active playback, marks it aborted, stops socket monitoring, and releases its helper media connection.

## Possible causes

- The helper session connection closes or encounters a hard send error.

## What to check

1. Check the helper process and session connection near this event.

## Recommended action

Restore the helper connection and reconnect playback.
