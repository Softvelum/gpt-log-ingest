# Icecast advertisement insertion begins

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-9b1f52b514a065c3

## Log pattern

```text
insert advertising content id=%s uri=%s to stream %s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.
- Argument 3 — Icecast stream: Text identifying the target Icecast stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
insert advertising content id=ad-01 uri=https://media.example/ad.mp4 to stream live/radio
```

## Short description

Icecast advertisement insertion begins.

## Trigger condition

A reader has been created for a scheduled advertisement whose insertion time has arrived.

## Explanation

The next operation reads an audio sample for insertion into the named stream.

## Possible causes

- A reader has been created for a scheduled advertisement whose insertion time has arrived.
