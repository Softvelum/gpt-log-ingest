# Host text is not an IPv6 literal

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-b13973ce71df9a11

## Log pattern

```text
inet_pton failed for host='%s' ret=%d errno=%d
```

## Parameters

- Argument 1 — Host: Text host name submitted for connection.
- Argument 2 — Conversion result: Integer result from IPv6 literal parsing; zero means the text is not a valid literal.
- Argument 3 — System error: System error value at this point; it need not identify a failure when conversion returns zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
inet_pton failed for host='origin.example' ret=0 errno=0
```

## Short description

Host text is not an IPv6 literal.

## Trigger condition

IPv6-capable connection handling has rejected an IPv4 literal interpretation and the IPv6 literal conversion does not succeed.

## Explanation

Name resolution is attempted next. An ordinary DNS host name can produce this message without a connection failure.
