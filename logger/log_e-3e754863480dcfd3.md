# Audio encoder requires reset after channel count change

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_e
Log level: error
Documentation ID: log_e-3e754863480dcfd3

## Log pattern

```text
audio encoder reset for stream='%s' as channel count changed (%d -> %d)
```

## Parameters

- Argument 1 — Stream: Output stream name, text.
- Argument 2 — Previous value: Previous channel count, integer channels.
- Argument 3 — New value: Current input channel count, integer channels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio encoder reset for stream='live/camera' as channel count changed (2 -> 1)
```

## Short description

Audio encoder requires reset after channel count change.

## Trigger condition

The current input channel count differs from the retained encoder-frame channel count.

## Explanation

Frame preparation returns failure so the existing encoder is no longer used for this frame. The log does not itself recreate an encoder.

## Possible causes

- The audio input changed channel count after initialization.

## What to check

1. Compare the old and new channel count and the upstream audio changes.

## Recommended action

Recreate the encoder with the new audio parameters or keep the input parameters stable.
