# OCR decoder added for subtitle language

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_d
Log level: debug
Documentation ID: log_d-ede5408203498cd4

## Log pattern

```text
tesseract decoder added, lang=%s
```

## Parameters

- Argument 1 — Language: Lowercase DVB subtitle language code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
tesseract decoder added, lang=eng
```

## Short description

OCR decoder added for subtitle language.

## Trigger condition

A new language-specific Tesseract instance has been initialized and stored.

## Explanation

The instance is reused for later DVB subtitle rectangles of the same language. This does not itself confirm recognized text.

## Possible causes

- A new language-specific Tesseract instance has been initialized and stored.

## What to check

1. Check subsequent subtitle output for the indicated language.
