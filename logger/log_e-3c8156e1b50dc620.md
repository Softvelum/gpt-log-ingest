# AAC configuration could not be extracted from LATM

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-3c8156e1b50dc620

## Log pattern

```text
mp4a-latm: failed to get aac config
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
mp4a-latm: failed to get aac config
```

## Short description

AAC configuration could not be extracted from LATM.

## Trigger condition

The SDP LATM stream-multiplex configuration was processed, but an AAC audio configuration cannot be obtained.

## Explanation

LATM initialization returns failure before the live stream receives an AAC codec configuration.

## Possible causes

- The SDP LATM stream-multiplex configuration was processed, but an AAC audio configuration cannot be obtained.

## What to check

1. Check the LATM configuration for an extractable AAC audio configuration.
