# UDP input cannot join a source-specific multicast group

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-d2019eaa39280710

## Log pattern

```text
failed to configure multicast(add_source_membership) s=%d '%s:%d@%s on %s' [%d]
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Group: Multicast IPv4 address.
- Argument 3 — Port: Input UDP port.
- Argument 4 — Source: Allowed multicast sender IPv4 address.
- Argument 5 — Interface: Selected receive interface IPv4 address; empty selects the default.
- Argument 6 — Error: Operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to configure multicast(add_source_membership) s=42 '239.1.1.1:5000@192.0.2.20 on 192.0.2.10' [19]
```

## Short description

UDP input cannot join a source-specific multicast group.

## Trigger condition

Binding succeeds but joining the multicast group with its configured source filter fails.

## Explanation

UDP input connection setup returns failure.

## Possible causes

- Binding succeeds but joining the multicast group with its configured source filter fails.

## What to check

1. Check multicast group, sender source address, receiving interface, and socket error.

## Recommended action

Correct the source-specific membership settings.
