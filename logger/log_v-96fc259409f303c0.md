# No SLDP WebSocket route matches

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-96fc259409f303c0

## Log pattern

```text
no websocket route for url '%s':'%s'
```

## Parameters

- Argument 1 — Request host: Text authority or Host value used for routing.
- Argument 2 — Request URL: Text request path and query being routed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no websocket route for url 'media.example':'/live/camera'
```

## Short description

No SLDP WebSocket route matches.

## Trigger condition

A WebSocket request has no matching SLDP route.

## Explanation

HTTP 404 is prepared before playback starts.

## Possible causes

- A WebSocket request has no matching SLDP route.

## What to check

1. Check the requested host and stream path against the intended SLDP routing.

## Recommended action

Check the requested host and stream path against the intended SLDP routing.
