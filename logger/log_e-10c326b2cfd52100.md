# AJA capture frame range is not valid

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-10c326b2cfd52100

## Log pattern

```text
Bad frames spec for device '%s',  Expected '%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Expected syntax: Constant description of the accepted frame-range forms.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad frames spec for device '0',  Expected '{frameCount}, {frameCount}[@{firstFrameNum}] or {firstFrameNum}-{lastFrameNum}'
```

## Short description

AJA capture frame range is not valid.

## Trigger condition

The stored frame range fails validation while validating the capture parameters.

## Explanation

Parameter validation returns failure. The printed syntax describes supported specification forms rather than the rejected value.

## Possible causes

- The stored frame range fails validation while validating the capture parameters.

## What to check

1. Check the configured frame count and optional frame range.

## Recommended action

Use a valid frame count or supported range specification.
