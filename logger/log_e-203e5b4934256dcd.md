# VCAS asset response has the wrong JSON type

Product: Nimble Streamer
Component: VCAS DRM
Logging function: log_e
Log level: error
Documentation ID: log_e-203e5b4934256dcd

## Log pattern

```text
error processing createAssetResponse json='%s'
```

## Parameters

- Argument 1 — Response body: Text containing the VCAS response.

## Log examples

Illustrative examples; these are not captured server logs.

```text
error processing createAssetResponse json='[]'
```

## Short description

VCAS asset response has the wrong JSON type.

## Trigger condition

The VCAS create-asset response parses as a JSON value other than an object.

## Explanation

Response parsing returns failure.

## Possible causes

- The VCAS create-asset response parses as a JSON value other than an object.

## What to check

1. Return a JSON object from the VCAS create-asset endpoint.

## Recommended action

Return a JSON object from the VCAS create-asset endpoint.
