# RTSP media socket connection failed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-2bd7b9593a83482a

## Log pattern

```text
failed to connect s=%d to '%s:%d' errno=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.
- Argument 2 — Host: Remote destination host.
- Argument 3 — Remote port: Decimal destination port.
- Argument 4 — Error number: Integer error value reported by the socket operation; its meaning depends on the operating system.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect s=26 to '192.0.2.1:5000' errno=111
```

## Short description

RTSP media socket connection failed.

## Trigger condition

Connecting a media or control socket fails with an error other than connection in progress.

## Explanation

The failing socket is closed; the connection operation eventually reports failure when it has no successful address attempt.

## Possible causes

- Connecting a media or control socket fails with an error other than connection in progress.

## What to check

1. Check the destination host, port, and reported socket error.
