# Next remote fragment request selected

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-28fa819008704a6a

## Log pattern

```text
processing pending request for item key='%s' from=%llu to=%llu queue_size=%u
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — from: Inclusive starting byte offset.
- Argument 3 — to: Exclusive ending byte offset.
- Argument 4 — queue size: Pending requests remaining for this URL.

The queue size is a platform-sized container count passed to a 32-bit unsigned conversion.

## Log examples

No portable example is provided for the mismatched queue-size conversion.

## Short description

Next remote fragment request selected.

## Trigger condition

A successful GET completion removes the first pending request from its queue.

## Explanation

The next external request is submitted after this message; submission can still fail. The queue size excludes the selected request.
