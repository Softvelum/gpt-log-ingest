# SDI output audio parameters changed

Product: Nimble Streamer
Component: SDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-c69463bf5772c6f4

## Log pattern

```text
reset sdi output. audio params changed [%s/%s]
```

## Parameters

- Argument 1 — Device type: Configured media-device driver type.
- Argument 2 — Device stream: Configured SDI device or stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reset sdi output. audio params changed [decklink/SDI output]
```

## Short description

SDI output audio parameters changed.

## Trigger condition

An already configured audio output receives a different sample format, channel layout, or sample rate.

## Explanation

Audio message processing returns failure. This differs from the supported first-late-audio case, which recreates the output device.

## Possible causes

- An already configured audio output receives a different sample format, channel layout, or sample rate.

## What to check

1. Check sample format, channel layout, and rate before and after the change.

## Recommended action

Reinitialize output for the new audio parameters.
