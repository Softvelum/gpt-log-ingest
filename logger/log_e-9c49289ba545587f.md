# Successful origin response lacks Content-Length

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-9c49289ba545587f

## Log pattern

```text
missing Content-Length from origin url='%s%s'
```

## Parameters

- Argument 1 — Origin host: Text containing the origin hostname and optional port.
- Argument 2 — Origin URL: Text giving the origin request path and query string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
missing Content-Length from origin url='media.example:8080/live/camera/playlist.m3u8'
```

## Short description

Successful origin response lacks Content-Length.

## Trigger condition

A parsed origin response with status 200 or 206 has no usable Content-Length field.

## Explanation

The HTTP client prepares HTTP 500 or the cache download finishes unsuccessfully; a bounded body cannot be allocated from this response.

## Possible causes

- A parsed origin response with status 200 or 206 has no usable Content-Length field.

## What to check

1. Configure the origin to return a valid Content-Length for this response and verify the requested route reaches the intended HTTP service.

## Recommended action

Configure the origin to return a valid Content-Length for this response and verify the requested route reaches the intended HTTP service.
