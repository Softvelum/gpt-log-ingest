# Panel synchronization sleep returned early

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-8c42117c77b9b4ea

## Log pattern

```text
syncThreadSleep livetime_delta=%ld remained_sleep_time=%d
```

## Parameters

- Argument 1 — elapsed\_seconds: Elapsed UTC seconds since the start of the delay.
- Argument 2 — remaining\_seconds: Requested duration minus elapsed seconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
syncThreadSleep livetime_delta=5 remained_sleep_time=25
```

## Short description

Panel synchronization sleep returned early.

## Trigger condition

On Windows, a sleep returns before the requested elapsed duration without shutdown or an explicit settings interruption.

## Explanation

The remaining duration is recomputed from elapsed UTC seconds and another sleep is attempted. Clock movement backward or reaching the requested duration ends the loop without this message.
