# Cannot send synchronized media message

Product: Nimble Streamer
Component: WebVTT timing synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-6b8d92b3d52cc871

## Log pattern

```text
failed to send webvtt sync queue message for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name.
- Argument 2 — Stream: Stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send webvtt sync queue message for [live/news]
```

## Short description

Cannot send synchronized media message.

## Trigger condition

Sending the next buffered media or subtitle message to the live-stream path returns failure.

## Explanation

That front item has already been removed from the queue and duration accounting updated; the send loop returns failure. Attached subtitles are attempted before the media message.

## Possible causes

- Sending the next buffered media or subtitle message to the live-stream path returns failure.

## What to check

1. Check the downstream live-stream state and preceding media processing diagnostics.
