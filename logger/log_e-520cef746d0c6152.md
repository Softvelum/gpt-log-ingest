# Quick Sync HEVC plugin could not load

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-520cef746d0c6152

## Log pattern

```text
failed to load quicksync hevc plugin, error=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

The decoder selects software or hardware HEVC decoding automatically. The encoder selects the matching encoding plugin unless its plugin option overrides that choice. This path is used without the newer VPL loader.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load quicksync hevc plugin, error=-3
```

## Short description

Quick Sync HEVC plugin could not load.

## Trigger condition

A legacy media runtime returns a nonzero status while loading the HEVC plugin for decoding or encoding.

## Explanation

The corresponding decoder or encoder setup fails.

## Possible causes

- The selected HEVC plugin is unavailable or incompatible with the media implementation.

## What to check

1. Check whether software or hardware implementation was selected; for encoding, also check the optional plugin override.

## Recommended action

Install or select a compatible HEVC plugin and restart the stream.
