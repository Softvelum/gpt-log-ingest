# DVR pending KLV metadata could not be packaged

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-d4d1631da53317b4

## Log pattern

```text
failed to process KLV metadata for stream='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process KLV metadata for stream='live/camera'
```

## Short description

DVR pending KLV metadata could not be packaged.

## Trigger condition

While processing AVC video, pending metadata has a wrong item category, cannot be buffered, or cannot fit in MPEG-TS output.

## Explanation

Pending KLV items and metadata buffers are cleared; video processing continues.

## Possible causes

- While processing AVC video, pending metadata has a wrong item category, cannot be buffered, or cannot fit in MPEG-TS output.

## What to check

1. Check incoming KLV data and the configured live transmuxing buffer capacity.

## Recommended action

Check incoming KLV data and the configured live transmuxing buffer capacity.
