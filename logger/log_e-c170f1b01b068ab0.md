# RIST sender peer creation failed

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-c170f1b01b068ab0

## Log pattern

```text
failed to add rist sender peer, id=%s
```

## Parameters

- Argument 1 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add rist sender peer, id=rist-sender
```

## Short description

RIST sender peer creation failed.

## Trigger condition

The RIST library returns a nonzero result from peer creation.

## Explanation

The sender context exists, but transport startup is not attempted and initialization fails.

## Possible causes

- The RIST library returns a nonzero result from peer creation.

## What to check

1. Check the RIST runtime diagnostics for peer creation using this connection ID.
