# Parsed stream-check JSON array length printed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-bdca7642411f94d1

## Log pattern

```text
stream_response_obj.array_length() = %d
```

## Parameters

- Argument 1 — length: Top-level array length, or zero when the parsed response is not an array.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream_response_obj.array_length() = 0
```

## Short description

Parsed stream-check JSON array length printed.

## Trigger condition

The successfully parsed response is passed to the array-length helper.

## Explanation

This is diagnostic metadata before response fields are processed; the normal panel response is an object, so this count is not the number of stream-check tasks.
