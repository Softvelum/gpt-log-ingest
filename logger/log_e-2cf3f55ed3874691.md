# Statistics slice pattern is invalid

Product: Nimble Streamer
Component: Statistics data slices
Logging function: log_e
Log level: error
Documentation ID: log_e-2cf3f55ed3874691

## Log pattern

```text
[%s] is wrong regex pattern
```

## Parameters

- Argument 1 — pattern: Regular expression supplied for application or stream matching.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[[] is wrong regex pattern
```

## Short description

Statistics slice pattern is invalid.

## Trigger condition

Compiling an application or stream matching expression raises a runtime error.

## Explanation

The invalid expression is not added to the cached pattern set. Later matching cannot use that expression; other patterns continue to be processed.

## Possible causes

- The matching expression cannot be compiled.

## What to check

1. Check the syntax of the reported expression.

## Recommended action

Correct the expression used for the statistics slice.
