# PES frame buffer cannot accept more payload

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_e
Log level: error
Documentation ID: log_e-62e03a23194b6dda

## Log pattern

```text
mpeg2ts_transport_stream: cannot allocate appropriate buffer
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
mpeg2ts_transport_stream: cannot allocate appropriate buffer
```

## Short description

PES frame buffer cannot accept more payload.

## Trigger condition

Appending transport payload to the elementary-stream frame buffer fails.

## Explanation

The packet is rejected, the stream parser resets and discards its partial frame, and input searches for a new packet boundary. The frame buffer is capped at 10 MiB.

## Possible causes

- Appending transport payload to the elementary-stream frame buffer fails.

## What to check

1. Check accumulated PES size, missing PES boundaries, and memory availability.

## Recommended action

Correct oversized or unterminated PES input, or resolve allocation pressure.
