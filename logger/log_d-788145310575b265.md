# Unsupported WebSocket subprotocol

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-788145310575b265

## Log pattern

```text
invalid websocket subprotocol [%s]
```

## Parameters

- Argument 1 — Requested subprotocol: Text of the Sec-WebSocket-Protocol request header.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid websocket subprotocol [chat]
```

## Short description

Unsupported WebSocket subprotocol.

## Trigger condition

A WebSocket upgrade request does not specify exactly sldp.softvelum.com as its subprotocol.

## Explanation

HTTP 501 is prepared and the connection is not upgraded.

## Possible causes

- A WebSocket upgrade request does not specify exactly sldp.softvelum.com as its subprotocol.

## What to check

1. Use an SLDP client that requests the supported sldp.softvelum.com subprotocol.

## Recommended action

Use an SLDP client that requests the supported sldp.softvelum.com subprotocol.
