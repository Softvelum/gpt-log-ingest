# HEVC sequence header has no parsed parameters

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-6c7a5316b869572f

## Log pattern

```text
failed to get hevc codec params from [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

The names identify the input stream. Forwarding treats the failure as fatal; decoder update and reset call sites currently discard the helper result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get hevc codec params from [live/camera]
```

## Short description

HEVC sequence header has no parsed parameters.

## Trigger condition

The input HEVC sequence-header item has no attached parsed decoder information.

## Explanation

Compressed forwarding rejects the configuration. The video decoder helper also returns failure, although its current callers ignore that return and continue without applying new HEVC parameters.

## Possible causes

- The sequence-header item lacks its expected parsed VPS/SPS/PPS information.

## What to check

1. Check upstream HEVC sequence-header parsing and whether the item was created with decoded parameter information.

## Recommended action

Restore complete HEVC sequence headers and restart the affected path.
