# Transcoder drop limit is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-b24862f62b75994d

## Log pattern

```text
invalid parameter value: %s. should be from 0 to 100
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be from 0 to 100
```

## Short description

Transcoder drop limit is invalid.

## Trigger condition

While reading configuration, the transcoder drop limit is outside 0 through 100.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires a drop limit from 0 through 100.

## Recommended action

Correct the value to a drop limit from 0 through 100 and reload configuration.
