# Audio output codec is unsupported

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-e4bb85294b541d5e

## Log pattern

```text
failed to write audio pkt, unsupported audio codec %d for [%s/%s]
```

## Parameters

- Argument 1 — Audio codec: Internal audio stream codec enumeration value, integer; no unit.
- Argument 2 — Application: Output application name, text.
- Argument 3 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write audio pkt, unsupported audio codec 0 for [live/encoded]
```

## Short description

Audio output codec is unsupported.

## Trigger condition

After synchronization, the audio stream codec is outside AAC, MP3, Speex, AC3, EAC3, and Opus.

## Explanation

The packet is rejected and output processing fails.

## Possible causes

- The internal audio codec was not initialized to a supported packet-delivery type.

## What to check

1. Check codec selection and preceding audio configuration messages.

## Recommended action

Use a supported output audio codec and restart the stream.
