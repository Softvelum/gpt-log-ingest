# Plain socket shutdown failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_e
Log level: error
Documentation ID: log_e-738d6240c3432cd2

## Log pattern

```text
failed to shutdown %s s=%d (errno=%d)
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Socket: Integer socket descriptor.
- Argument 3 — System error: Integer operating-system socket error value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to shutdown client s=12 (errno=9)
```

## Short description

Plain socket shutdown failed.

## Trigger condition

Shutting down both directions of a non-TLS socket returns an error other than a not-connected result.

## Explanation

The system error is saved and the shutdown helper returns failure. The socket is not closed by this helper.

## Possible causes

- The operating system rejected socket shutdown.

## What to check

1. Inspect the socket and system error.
