# HLS chunk encryption has no key server

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-8b45e833b6a50a35

## Log pattern

```text
[drm] key server is empty for '%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

The provider type is accessed before this guard, so this message is not a reliable diagnostic for every missing-server state.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] key server is empty for 'live/camera'
```

## Short description

HLS chunk encryption has no key server.

## Trigger condition

The VCAS protection path reaches its missing-key-server guard.

## Explanation

The crypto-parameter or chunk-preparation operation returns failure.

## Possible causes

- The VCAS protection path reaches its missing-key-server guard.

## What to check

1. Reload a consistent VCAS protection configuration; retain surrounding messages if the condition repeats.

## Recommended action

Reload a consistent VCAS protection configuration; retain surrounding messages if the condition repeats.
