# NVIDIA hardware decoder created

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-374ccfb06b967e22

## Log pattern

```text
nvidia decoder created for [%s], w:%d h:%d fmt:%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — Width: Display width used for decoded output, integer pixels.
- Argument 3 — Height: Display height used for decoded output, integer pixels.
- Argument 4 — Chroma format: NVIDIA chroma-format identifier, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
nvidia decoder created for [live/camera], w:1920 h:1080 fmt:1
```

## Short description

NVIDIA hardware decoder created.

## Trigger condition

Creating the hardware decoder for the incoming sequence succeeds.

## Explanation

The decoder is ready with NV12 output and the reported display dimensions and source chroma format.
