# Listening port is not an integer

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-fb1161396f688a60

## Log pattern

```text
failed to convert port='%s' to integer
```

## Parameters

- Argument 1 — Port: Configured port token as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to convert port='abc' to integer
```

## Short description

Listening port is not an integer.

## Trigger condition

Converting a configured port token to an integer raises a conversion error.

## Explanation

The process exits with a failure status during listener setup.

## Possible causes

- A configured listening-port token cannot be converted to an integer.

## What to check

1. Inspect the named port token.

## Recommended action

Use an integer listening-port value.
