# SDI audio converter is unavailable

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-97f738dbe48935e4

## Log pattern

```text
failed to find audio converter for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find audio converter for [live/camera]
```

## Short description

SDI audio converter is unavailable.

## Trigger condition

FFmpeg cannot find its signed 16-bit PCM encoder.

## Explanation

The current output frame operation returns failure.

## Possible causes

- The loaded FFmpeg libraries do not provide the signed 16-bit PCM encoder.

## What to check

1. Check encoder support in the installed FFmpeg libraries.

## Recommended action

Provide the required FFmpeg encoder.
