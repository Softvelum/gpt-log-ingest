# Remote cache initialization is already active

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_e
Log level: error
Documentation ID: log_e-4b50d074d124c59d

## Log pattern

```text
cache item key='%s' is already being processed
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item key='https://media.example/movie.mp4' is already being processed
```

## Short description

Remote cache initialization is already active.

## Trigger condition

An empty item is being initialized while an active request already exists for its URL.

## Explanation

The duplicate initialization returns failure without submitting another HEAD request.

## Possible causes

- The cache key already has an active request.

## What to check

1. Look for the earlier request and its completion or failure.

## Recommended action

Investigate duplicate item initialization if it prevents caching.
