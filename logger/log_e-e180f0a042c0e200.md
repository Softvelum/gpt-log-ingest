# RTMP createStream transaction ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-e180f0a042c0e200

## Log pattern

```text
failed to process transaction id for createStream command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process transaction id for createStream command
```

## Short description

RTMP createStream transaction ID cannot be decoded.

## Trigger condition

The createStream request cannot supply its transaction ID as an AMF number.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The createStream request cannot supply its transaction ID as an AMF number.

## What to check

1. Inspect the transaction ID field and AMF framing in the incoming createStream command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
