# RTMP client-handshake digest processing fails

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-1103067d7bf16634

## Log pattern

```text
cannot parse c0 from client: %d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot parse c0 from client: 42
```

## Short description

RTMP client-handshake digest processing fails.

## Trigger condition

Digest-enabled handshake processing cannot calculate the client-handshake digest.

## Explanation

The incoming connection is shut down. A simple digest mismatch can fall back to the old handshake without this message; the checked failure here comes from the digest operation itself.

## Possible causes

- Digest-enabled handshake processing cannot calculate the client-handshake digest.

## What to check

1. Check accompanying HMAC allocation errors and local cryptographic resources.

## Recommended action

Resolve the cryptographic resource failure before retrying the handshake.
