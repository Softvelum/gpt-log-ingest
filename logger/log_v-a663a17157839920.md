# TCP connection started or UDP input bound

Product: Nimble Streamer
Component: Socket communication
Logging function: log_v
Log level: verbose
Documentation ID: log_v-a663a17157839920

## Log pattern

```text
connecting to s=%d '%s:%d'
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Host: Requested host or address text.
- Argument 3 — Port: TCP port number, integer.

The host and port identify the remote TCP destination in one occurrence and the bound UDP input address in the other.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connecting to s=12 '192.0.2.10:1935'
```

## Short description

An outbound TCP connection is in progress or a UDP media input has bound its address.

## Trigger condition

Nonblocking TCP connect returns connection-in-progress, or the MPEG-TS UDP receiver successfully binds its configured input address.

## Explanation

The TCP helper returns the socket for asynchronous completion. The UDP receiver next joins multicast membership when applicable; its message does not describe a TCP connection.
