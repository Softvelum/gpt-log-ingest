# Socket creation failed

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-3535d868dee15fa0

## Log pattern

```text
socket creation failed (errno=%d)
```

## Parameters

- Argument 1 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

Most callers report the platform socket error; RTSP directly reports errno. The SRT occurrence also reads the operating system socket error rather than the SRT library error, so its value may not explain the SRT failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
socket creation failed (errno=5)
```

## Short description

A requested network socket could not be created.

## Trigger condition

A socket creation call returns an invalid handle for outgoing TCP, MPEG-TS UDP input/output, RTSP transport, or SRT.

## Explanation

The affected connection or sender setup fails before binding or connecting. The constant-rate MPEG-TS sender occurrence is compiled only on non-Windows builds.

## Possible causes

- The operating system rejected socket creation.

## What to check

1. Check the socket error and available socket resources.

## Recommended action

Resolve the reported socket creation failure.
