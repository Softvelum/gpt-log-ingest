# Enhanced RTMP audio codec is unsupported or changes

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-2a8c1e38d814b107

## Log pattern

```text
[AM] codec changed for (%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] codec changed for (live/camera)
```

## Short description

Enhanced RTMP audio codec is unsupported or changes.

## Trigger condition

The enhanced audio four-character code is unsupported, or differs from the supported enhanced codec already selected for this message stream.

## Explanation

The audio message is rejected and connection processing fails. The text says codec changed even for the first unsupported codec. Accepted codes are ac-3, ec-3, Opus, fLaC, and mp4a.

## Possible causes

- The enhanced audio four-character code is unsupported, or differs from the supported enhanced codec already selected for this message stream.

## What to check

1. Check both the first and current enhanced audio codec identifiers.

## Recommended action

Use a supported enhanced audio codec and keep it consistent during the connection.
