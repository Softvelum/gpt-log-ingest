# Buffered NDI video sender started

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-6c97d41a08157713

## Log pattern

```text
ndi video sender started, ndi_name="%s"
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ndi video sender started, ndi_name="HOST (Output)"
```

## Short description

Buffered NDI video sender started.

## Trigger condition

The dedicated buffered video sender enters its worker routine.

## Explanation

It begins reading and pacing video frames until exit is requested or an unsupported video format stops its loop.

## Possible causes

- Normal startup of the buffered NDI video worker.
