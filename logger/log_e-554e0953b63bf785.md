# SRT event wait failed

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-554e0953b63bf785

## Log pattern

```text
srt_epoll_wait failed for fd=%d: %s
```

## Parameters

- Argument 1 — Poller: SRT event-poller identifier.
- Argument 2 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_epoll_wait failed for fd=1: Invalid poll ID
```

## Short description

SRT event wait failed.

## Trigger condition

Waiting for socket events returns an error other than the normal timeout.

## Explanation

This wait cycle dispatches no socket events. A caller can continue its event loop. The value labeled fd identifies the event poller.

## Possible causes

- Waiting for socket events returns an error other than the normal timeout.

## What to check

1. Inspect the error and whether it repeats across event-loop iterations.
