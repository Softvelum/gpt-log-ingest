# Remote HLS absolute URL prefix created

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-f058035cc2b5b666

## Log pattern

```text
url_prefix=%s
```

## Parameters

- Argument 1 — URL prefix: Text consisting of http://, the origin host, and the playlist directory.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url_prefix=http://media.example/live/camera/
```

## Short description

Remote HLS absolute URL prefix created.

## Trigger condition

An absolute-URL request encounters its first non-comment playlist line without an http:// prefix.

## Explanation

An HTTP prefix is built from the origin host and playlist directory and is used to expand that line.

## Possible causes

- An absolute-URL request encounters its first non-comment playlist line without an http:// prefix.
