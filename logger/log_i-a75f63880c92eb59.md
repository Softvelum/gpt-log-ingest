# Disk cache loading finished

Product: Nimble Streamer
Component: Media data cache
Logging function: log_i
Log level: info
Documentation ID: log_i-a75f63880c92eb59

## Log pattern

```text
Finished loading cache, %llu item(s) disk cache size is %llu bytes, items_list.size()=%llu lru_list.size()=%llu
```

## Parameters

- Argument 1 — items: Number of registered cache items.
- Argument 2 — disk bytes: Total cache capacity currently accounted for on disk, in bytes.
- Argument 3 — expiration entries: Number of entries in the cache expiration list.
- Argument 4 — reuse entries: Number of entries in the reuse-order list.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Finished loading cache, 2 item(s) disk cache size is 2097152 bytes, items_list.size()=2 lru_list.size()=2
```

## Short description

Disk cache loading finished.

## Trigger condition

All directory batches and cache list sorting are complete.

## Explanation

The message reports loaded items, disk accounting, and two internal list lengths. Those lists can contain individual fragments, so their counts need not equal the number of cache keys.
