# Origin playlist exceeds the response-size limit

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-7133a7d31bd176df

## Log pattern

```text
origin response length is too big l=%d max=%u
```

## Parameters

- Argument 1 — Response bytes: Integer calculated bytes for headers plus declared body.
- Argument 2 — Maximum bytes: Unsigned configured maximum origin playlist response size.

## Log examples

Illustrative examples; these are not captured server logs.

```text
origin response length is too big l=2097152 max=1048576
```

## Short description

Origin playlist exceeds the response-size limit.

## Trigger condition

A playlist response needs a larger buffer and its calculated header-plus-body length exceeds the configured maximum.

## Explanation

Buffer growth is refused and HTTP 500 is prepared.

## Possible causes

- A playlist response needs a larger buffer and its calculated header-plus-body length exceeds the configured maximum.

## What to check

1. Inspect whether the origin returned an unexpectedly large playlist; adjust the maximum only if that response size is intentional.

## Recommended action

Inspect whether the origin returned an unexpectedly large playlist; adjust the maximum only if that response size is intentional.
