# Runtime library loaded on Linux

Product: Nimble Streamer
Component: Runtime library loading
Logging function: log_d
Log level: debug
Documentation ID: log_d-1bb7e344ab000237

## Log pattern

```text
loaded lib_name_='%s' dl_=%p
```

## Parameters

- Argument 1 — Library: Requested library name or path, text.
- Argument 2 — Library handle: Loaded library handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
loaded lib_name_='libexample.so' dl_=0x12340000
```

## Short description

Runtime library loaded on Linux.

## Trigger condition

The main library or its configured alternative loads successfully on Linux.

## Explanation

The retained handle is used to find the library functions. The reported name is changed to the alternative when that alternative succeeds.
