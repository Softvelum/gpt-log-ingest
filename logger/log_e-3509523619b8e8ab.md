# AAC raw AAC transport failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-3509523619b8e8ab

## Log pattern

```text
failed to set transport type, status=%d
```

## Parameters

- Argument 1 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set transport type, status=1
```

## Short description

AAC raw AAC transport failed.

## Trigger condition

In an FDK-enabled build, selecting raw AAC output without ADTS headers returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected raw AAC transport for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in raw AAC transport.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
