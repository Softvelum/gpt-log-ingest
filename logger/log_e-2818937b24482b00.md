# VAAPI capability query failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-2818937b24482b00

## Log pattern

```text
%p failed to get config attributes, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

Three occurrences query rate-control modes, reference-frame counts, and quality range respectively; the message does not identify which query failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to get config attributes, 0x1
```

## Short description

VAAPI capability query failed.

## Trigger condition

A VA attribute query for rate-control modes, maximum reference-frame counts, or quality range returns a non-success status.

## Explanation

That capability result is discarded. Encoder initialization continues: rate-control reporting is skipped, default quality handling remains, or reference-count reporting is skipped.

## Possible causes

- The selected VA profile, encoding entry point, or driver cannot answer the requested capability query.

## What to check

1. Check the status and subsequent configuration creation result.

## Recommended action

If initialization or encoding fails, select settings supported by the VA driver or restore the driver.
