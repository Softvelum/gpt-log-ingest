# Scenario input item could not be read

Product: Nimble Streamer
Component: Scenario input forwarding
Logging function: log_e
Log level: error
Documentation ID: log_e-5e16a273b4be241c

## Log pattern

```text
failed to read item [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read item [live/camera]
```

## Short description

Scenario input item could not be read.

## Trigger condition

Obtaining the first or next input item returns neither a successful nonempty item nor the normal wait-for-new-items result.

## Explanation

Forwarding returns failure to scenario connection handling, which can remove and recreate the affected scenario.

## Possible causes

- The live buffer cannot provide the requested item or returns an empty item.

## What to check

1. Check the source stream and preceding slow-consumer or buffer diagnostics.

## Recommended action

Restore valid source-buffer delivery and allow the scenario to reconnect.
