# HLS playlist parsing failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-882377d98ad68775

## Log pattern

```text
failed to parse M3U8 playlist:
%s
```

## Parameters

- Argument 1 — Playlist text: Text of the playlist that could not be parsed.

## Log examples

Illustrative examples; these are not captured server logs.

```text

<html>Not found</html>
```

## Short description

HLS playlist parsing failed.

## Trigger condition

An origin, cached, or local prepackaged HLS playlist is rejected during playlist processing.

## Explanation

The request is rejected: direct HTTP/1 origin processing uses HTTP 406, while the local, cache-update, and HTTP/2 or HTTP/3 branches use HTTP 500.

## Possible causes

- An origin, cached, or local prepackaged HLS playlist is rejected during playlist processing.

## What to check

1. Inspect the displayed playlist for malformed HLS or an error page returned as media; repair the source playlist or its origin response.

## Recommended action

Inspect the displayed playlist for malformed HLS or an error page returned as media; repair the source playlist or its origin response.
