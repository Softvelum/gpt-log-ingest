# RTSP interleaved frame processing failed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-1c57af851128f6e1

## Log pattern

```text
rtp_parse_interleaved returns %d, stream=[%s]
```

## Parameters

- Argument 1 — Status: Integer parser status: one means parse failure; two means stream processing failure.
- Argument 2 — Stream identity: Application and stream label used by the RTSP parser.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtp_parse_interleaved returns 1, stream=[live/camera]
```

## Short description

RTSP interleaved frame processing failed.

## Trigger condition

The interleaved-frame parser returns a nonzero status.

## Explanation

Pull-client mode advances one byte and searches for another frame boundary. Server mode immediately propagates the failure instead.

## Possible causes

- The interleaved-frame parser returns a nonzero status.

## What to check

1. Check the preceding RTP or RTCP error and whether this is a pulled input or an incoming publisher.
