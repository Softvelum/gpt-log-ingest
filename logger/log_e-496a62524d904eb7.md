# Audio source file could not be mapped

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-496a62524d904eb7

## Log pattern

```text
failed to open and map audio file='%s'
```

## Parameters

- Argument 1 — Audio filename: Text filesystem path of the local audio source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open and map audio file='/media/audio.mp3'
```

## Short description

Audio source file could not be mapped.

## Trigger condition

Opening and mapping a local MP3 or AAC source returns an invalid mapping.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- Opening and mapping a local MP3 or AAC source returns an invalid mapping.

## What to check

1. Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.

## Recommended action

Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.
