# Icecast socket error received

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_d
Log level: debug
Documentation ID: log_d-4c1ec5c7714480e1

## Log pattern

```text
kEventError received from client: %d
```

## Parameters

- Argument 1 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
kEventError received from client: 42
```

## Short description

Icecast socket error received.

## Trigger condition

The event loop reports a socket error event for the session.

## Explanation

The session is marked shut down and event processing returns failure.

## Possible causes

- The event loop reports a socket error event for the session.

## What to check

1. Check peer connection state and nearby transport diagnostics.
