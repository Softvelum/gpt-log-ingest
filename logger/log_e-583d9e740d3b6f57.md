# Intel media loader creation failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-583d9e740d3b6f57

## Log pattern

```text
MFXLoad failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
MFXLoad failed
```

## Short description

Intel media loader creation failed.

## Trigger condition

The VPL media loader returns a null loader handle.

## Explanation

Session creation fails before implementations can be enumerated.

## Possible causes

- The installed VPL loader cannot create a loader instance.

## What to check

1. Check Intel media runtime loading and availability.

## Recommended action

Restore a working VPL runtime and restart the affected transcoding operation.
