# Obsolete fragmented-MP4 HLS hard reset setting

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-9237338ce8e88274

## Log pattern

```text
'hls_fmp4_hard_reset_enabled' option is deprecated and always enabled, please remove it from nimble.conf
```

## Log examples

## Short description

Obsolete fragmented-MP4 HLS hard reset setting.

## Trigger condition

Configuration includes the obsolete fragmented-MP4 HLS hard reset option.

## Explanation

The option is accepted with a diagnostic; the feature is always enabled and the supplied value does not disable it.

## Possible causes

- The configuration retains an obsolete feature switch.

## What to check

1. Check whether this obsolete switch is still present.

## Recommended action

Remove the obsolete option; the feature remains enabled.
