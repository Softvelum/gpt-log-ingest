# NVIDIA context created without allocation lock

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-21c70693c81d9aef

## Log pattern

```text
created nvenc ctx=%p gpu=%d flag=%d time=%ld(ms)
```

## Parameters

- Argument 1 — Context: CUDA context handle, pointer printed in hexadecimal.
- Argument 2 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 3 — Flags: CUDA context creation flags, integer bit mask printed in decimal; no unit.
- Argument 4 — Duration: Elapsed wall-clock duration, signed long milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created nvenc ctx=0x12340000 gpu=0 flag=0 time=12(ms)
```

## Short description

NVIDIA context created without allocation lock.

## Trigger condition

No cached context is available and serialized context creation is disabled; creation succeeds.

## Explanation

The new context is returned and, when reuse is enabled, recorded as in use. The logged duration includes the creation path, including time waiting for the allocation lock where applicable.
