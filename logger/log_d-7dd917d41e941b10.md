# Cache parent directory created

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-7dd917d41e941b10

## Log pattern

```text
create_directories created dir='%s'
```

## Parameters

- Argument 1 — directory: Directory created for cache storage.

## Log examples

Illustrative examples; these are not captured server logs.

```text
create_directories created dir='/var/cache/nimble/app'
```

## Short description

Cache parent directory created.

## Trigger condition

Creating the missing parent directory for a normal disk cache file succeeds.

## Explanation

The cache proceeds to create and map the data file.
