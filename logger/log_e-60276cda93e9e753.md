# Writable cache file could not be opened

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-60276cda93e9e753

## Log pattern

```text
open failed to create file='%s' errno=%d
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.
- Argument 2 — error: Operating system error number reported for the failed operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
open failed to create file='/var/cache/nimble/movie' errno=13
```

## Short description

Writable cache file could not be opened.

## Trigger condition

A non-Windows file creation call for cache storage or the shared mapping helper fails.

## Explanation

No mapping is created. The direct cache path returns allocation failure; the helper returns a failed mapping result.

## Possible causes

- File creation or read/write access was denied or otherwise failed.

## What to check

1. Use the error number to check directory permissions and filesystem availability.

## Recommended action

Correct access or storage problems before retrying.
