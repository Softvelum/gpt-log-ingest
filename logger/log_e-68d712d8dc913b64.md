# Encoded MP3 header could not be parsed

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-68d712d8dc913b64

## Log pattern

```text
failed to parse mpa frame
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse mpa frame
```

## Short description

Encoded MP3 header could not be parsed.

## Trigger condition

At least three encoded bytes are buffered but MPEG audio header parsing fails.

## Explanation

The frame write fails before emitting a packet.

## Possible causes

- The encoded output does not contain an accepted MPEG audio header.

## What to check

1. Check the encoder output format and preceding encoder failures.

## Recommended action

Resolve the indicated MP3 encoding or frame-accounting failure.
