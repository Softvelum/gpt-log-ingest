# Stream chunk decryption failed before advertisement insertion

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-e35c835348f3e082

## Log pattern

```text
failed to decrypt chunk='%s'
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decrypt chunk='/app/stream/ad_1.ts'
```

## Short description

Stream chunk decryption failed before advertisement insertion.

## Trigger condition

Decrypting the source chunk fails while creating an audio or MPEG-TS section around an advertisement.

## Explanation

The remainder request is marked failed and returns.

## Possible causes

- Decrypting the source chunk fails while creating an audio or MPEG-TS section around an advertisement.

## What to check

1. Check the application DRM settings and the encryption key for this source chunk.

## Recommended action

Check the application DRM settings and the encryption key for this source chunk.
