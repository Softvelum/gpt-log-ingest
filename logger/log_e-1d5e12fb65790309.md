# Could not create the MPEG-TS over UDP output worker

Product: Nimble Streamer

## Short description

Could not create the MPEG-TS over UDP output worker.

## Trigger condition

The MPEG-TS UDP output worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the MPEG-TS over UDP output worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed MPEG-TS over UDP output worker.
