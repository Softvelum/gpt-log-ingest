# Required video acceleration library is unavailable

Product: Nimble Streamer
Component: Linux video acceleration initialization
Logging function: log_i
Log level: info
Documentation ID: log_i-41986b4c7dd3f049

## Log pattern

```text
failed to load libva
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load libva
```

## Short description

Required video acceleration library is unavailable.

## Trigger condition

In a Linux Quick Sync or VA-API build, a required video acceleration library function pointer is unavailable.

## Explanation

Video acceleration display opening returns failure without probing devices.

## Possible causes

- The required runtime library was not loaded successfully.

## What to check

1. Check availability of the video acceleration library.

## Recommended action

Install or load compatible video acceleration libraries.
