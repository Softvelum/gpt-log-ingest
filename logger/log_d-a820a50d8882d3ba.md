# Cannot format Windows performance value

Product: Nimble Streamer
Component: Windows system statistics
Logging function: log_d
Log level: debug
Documentation ID: log_d-a820a50d8882d3ba

## Log pattern

```text
PdhGetFormattedCounterValue failed status=%#x
```

## Parameters

- Argument 1 — Status: Windows performance-counter status code in hexadecimal.

The Windows status type is unsigned long; the hexadecimal conversion uses unsigned int. These have the same 32-bit width on Windows.

## Log examples

Illustrative examples; these are not captured server logs.

```text
PdhGetFormattedCounterValue failed status=0xc0000bc6
```

## Short description

Cannot format Windows performance value.

## Trigger condition

Reading a collected CPU-load or paging-file-usage counter as a double fails.

## Explanation

The current metric call returns zero instead of a measured value. The existing query remains available for later sampling. This diagnostic is Windows-only.

## Possible causes

- Reading a collected CPU-load or paging-file-usage counter as a double fails.

## What to check

1. Inspect the Windows performance-counter status and whether system metrics remain zero.
