# RTSP HTTP tunnel GET was rejected

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-4ea77705067f5e2d

## Log pattern

```text
bad http status=%d on socket %d
```

## Parameters

- Argument 1 — HTTP status: Decimal status code parsed from the tunnel response.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
bad http status=403 on socket 25
```

## Short description

RTSP HTTP tunnel GET was rejected.

## Trigger condition

The initial HTTP GET used to open an RTSP tunnel receives a status other than 200.

## Explanation

The RTSP input begins shutdown before opening its POST tunnel.

## Possible causes

- The initial HTTP GET used to open an RTSP tunnel receives a status other than 200.

## What to check

1. Check the reported HTTP status and the source or proxy tunnel endpoint.
