# Media-file read ended before requested length

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-659a4cfd166f12b2

## Log pattern

```text
failed to read %llu bytes from f=%s offset=%llu errno=%d read=%llu
```

## Parameters

- Argument 1 — Size: Requested byte count.
- Argument 2 — File: Requested runtime data-file path.
- Argument 3 — Offset: Requested starting byte offset.
- Argument 4 — Error: Operating-system error number.
- Argument 5 — Read: Actual accumulated bytes read.

Unsigned 64-bit sizes and offsets are printed with long-long conversions; exact typedef compatibility is platform dependent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read 4096 bytes from f=/data/media/segment.m4s offset=8192 errno=0 read=1024
```

## Short description

Media-file read ended before requested length.

## Trigger condition

Reading reaches end of file before accumulating the requested number of bytes.

## Explanation

The incomplete reader is rejected. The printed error number is not set specifically for this short read and may be stale.

## Possible causes

- Reading reaches end of file before accumulating the requested number of bytes.

## What to check

1. Compare the file size with the requested offset and length; check whether the file changed during reading.
