# VAAPI cannot write multiple slice groups

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-6e4161ad196f61ba

## Log pattern

```text
slice groups not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
slice groups not supported
```

## Short description

VAAPI cannot write multiple slice groups.

## Trigger condition

The H.264 picture settings request more than one slice group.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested multiple slice groups and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
