# Fragmented response body write progress

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-426f044c9f3983d2

## Log pattern

```text
%llu of %llu (rem %llu) B(b-f) to cli s=%d
```

## Parameters

- Argument 1 — Sent fragment bytes: Unsigned 64-bit bytes sent from the current response fragment.
- Argument 2 — Fragment bytes: Unsigned 64-bit selected bytes in the current fragment.
- Argument 3 — Remaining response bytes: Unsigned 64-bit remaining response bytes including the current fragment until completion.
- Argument 4 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
8192 of 65536 (rem 131072) B(b-f) to cli s=18
```

## Short description

Fragmented response body write progress.

## Trigger condition

A body write succeeds while a fragmented response still has a nonzero remaining response count.

## Explanation

The current fragment progress is logged; the remaining response count still includes this fragment until it is fully sent.

## Possible causes

- A body write succeeds while a fragmented response still has a nonzero remaining response count.
