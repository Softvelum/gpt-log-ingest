# DVR video replacement parsing failed

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-3a0b1a5826ade732

## Log pattern

```text
unknown exception caught while blackout video segment utc_time=%lld start_time=%lld duration=%lld period=%d
```

## Parameters

- Argument 1 — UTC time: 64-bit segment UTC time in milliseconds since the Unix epoch.
- Argument 2 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 3 — Media duration: 64-bit duration in the segment track timescale.
- Argument 4 — Period: Unsigned recording period identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown exception caught while blackout video segment utc_time=1700000000000 start_time=90000 duration=540000 period=1
```

## Short description

DVR video replacement parsing failed.

## Trigger condition

Reading the original video sample layout raises an unclassified exception.

The segment replacement returns failure and cleanup may continue with other segments.

## Possible causes
