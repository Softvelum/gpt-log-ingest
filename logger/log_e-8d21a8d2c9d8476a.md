# DRMToday password is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-8d21a8d2c9d8476a

## Log pattern

```text
password must be provided for DRMToday (drmtoday_password)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
password must be provided for DRMToday (drmtoday_password)
```

## Short description

DRMToday password is missing.

## Trigger condition

The DRMToday password is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The DRMToday password is empty.

## What to check

1. Provide the DRMToday password.

## Recommended action

Provide the DRMToday password.
