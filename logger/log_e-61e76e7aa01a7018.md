# AVC parameter sets exceed the transport-header buffer

Product: Nimble Streamer
Component: Fragmented media to transport stream packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-61e76e7aa01a7018

## Log pattern

```text
cannot load video_init_segment(avc header too long)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot load video_init_segment(avc header too long)
```

## Short description

AVC parameter sets exceed the transport-header buffer.

## Trigger condition

Appending a sequence or picture parameter set and its four-byte delimiter would reach or exceed the transport-header capacity.

## Explanation

AVC header construction returns failure. The buffer is 188 bytes for video-only reconstruction and 4136 bytes for combined audio/video reconstruction.

## Possible causes

- Appending a sequence or picture parameter set and its four-byte delimiter would reach or exceed the transport-header capacity.

## What to check

1. Compare parameter-set sizes and accumulated delimiters with the applicable header limit.

## Recommended action

Use parameter sets within the supported header size.
