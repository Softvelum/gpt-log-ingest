# Minimum queue or segment value is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-4b482435ae59ead0

## Log pattern

```text
invalid parameter value: %s. should be >= 1
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1
```

## Short description

Minimum queue or segment value is invalid.

## Trigger condition

While reading configuration, the external-transcoder message queue or subtitle chunk duration is below one, or the unsigned HLS/DASH ready-segment count is zero.

## Explanation

Configuration processing reports failure and the file loader stops at this line. HLS/DASH ready-segment checks test for zero after conversion to an unsigned count.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires at least one message, ready segment, or second of subtitle duration as applicable.

## Recommended action

Correct the value to at least one message, ready segment, or second of subtitle duration as applicable and reload configuration.
