# Timed-out Icecast advertising group is skipped

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a269d60632dc5a3a

## Log pattern

```text
timer expired, skip advertising content id=%s uri=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
timer expired, skip advertising content id=ad-01 uri=https://media.example/ad.mp4
```

## Short description

Timed-out Icecast advertising group is skipped.

## Trigger condition

An Icecast session waiting for advertising content reaches its timer and the configured error action is skip.

## Explanation

The pending observer is removed, the current advertising group is discarded, and live output is resumed.

## Possible causes

- An Icecast session waiting for advertising content reaches its timer and the configured error action is skip.

## What to check

1. Check download/preparation time for the named advertisement and the configured wait timeout if advertisements are being skipped.

## Recommended action

Check download/preparation time for the named advertisement and the configured wait timeout if advertisements are being skipped.
