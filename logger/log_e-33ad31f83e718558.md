# RTMP connect or publish command is rejected

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-33ad31f83e718558

## Log pattern

```text
'%s' command failed for s: %d, %s:%d/%s/%s
```

## Parameters

- Argument 1 — Command: connect for transaction ID 1 or publish for transaction ID 0.
- Argument 2 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 3 — Destination host: Publishing destination hostname or address.
- Argument 4 — Destination port: Publishing destination TCP port.
- Argument 5 — Application: Destination application name.
- Argument 6 — Stream: Destination stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
'publish' command failed for s: 42, destination.example:1935/live/camera
```

## Short description

RTMP connect or publish command is rejected.

## Trigger condition

The outbound publisher receives a failed command response with transaction ID 1 or 0.

## Explanation

The log names connect for ID 1 and publish for ID 0; the response handler controls subsequent connection termination.

## Possible causes

- The outbound publisher receives a failed command response with transaction ID 1 or 0.

## What to check

1. Check the destination response and the publishing credentials or stream target.

## Recommended action

Resolve the destination command rejection.
