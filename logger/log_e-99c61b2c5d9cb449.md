# DVR recording fell behind the live buffer

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-99c61b2c5d9cb449

## Log pattern

```text
dvr archive reader for stream='%s' is too slow
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dvr archive reader for stream='live/camera' is too slow
```

## Short description

DVR recording fell behind the live buffer.

## Trigger condition

The requested next buffered media item has already fallen outside the retained live buffer.

## Explanation

The read position is reset and recording resumes from the first available DVR item.

## Possible causes

- The requested next buffered media item has already fallen outside the retained live buffer.

## What to check

1. Check recording throughput, disk performance, and the live-buffer retention interval.

## Recommended action

Check recording throughput, disk performance, and the live-buffer retention interval.
