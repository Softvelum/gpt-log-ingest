# Whisper process connected

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-b4b665778f8c455b

## Log pattern

```text
whisper transcriber connected for [%s] lang=%s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Language: Configured language identifier for this transcription process; it may differ from the effective detected language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whisper transcriber connected for [live/news] lang=en
```

## Short description

Whisper process connected.

## Trigger condition

The child sends a valid connection message identifying an expected stream and language, and the accepted socket is attached successfully.

## Explanation

Queued configuration and audio can now be sent to that process. This does not establish that model loading has completed.

## Possible causes

- The child sends a valid connection message identifying an expected stream and language, and the accepted socket is attached successfully.

## What to check

1. Match the stream and language with the requested transcription.
