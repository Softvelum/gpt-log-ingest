# DVR database record position is unavailable

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-73484da3d4512a59

## Log pattern

```text
failed to seek to offset=%u in segment db='%s'
```

## Parameters

- Argument 1 — Database offset: Unsigned byte offset of the segment record in its database.
- Argument 2 — Segment database: Text naming the recording segment-index database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to seek to offset=512 in segment db='/data/dvr/live/camera/nimble-dvr-segments.db'
```

## Short description

DVR database record position is unavailable.

## Trigger condition

Shared-file recording cannot seek to the next database-record offset.

## Explanation

The pending segment record is not written.

## Possible causes

- Shared-file recording cannot seek to the next database-record offset.

## What to check

1. Check the database offset and filesystem I/O errors.

## Recommended action

Check the database offset and filesystem I/O errors.
