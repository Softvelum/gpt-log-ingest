# Current Widevine crypto period has no matching key

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-bae1be7029b42415

## Log pattern

```text
[drm] Widevine key for '%s' cpi=%u is not available
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned key rotation period index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine key for 'live/camera' cpi=120 is not available
```

## Short description

Current Widevine crypto period has no matching key.

## Trigger condition

Rotation selects a period and media-key type for which no key object is found.

## Explanation

Missing keys are requested as needed, but this lookup returns no key.

## Possible causes

- Rotation selects a period and media-key type for which no key object is found.

## What to check

1. Check key request and response messages for the current crypto period.

## Recommended action

Check key request and response messages for the current crypto period.
