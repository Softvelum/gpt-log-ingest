# DVR JPEG thumbnail could not be stored

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-36229d96314f80a6

## Log pattern

```text
failed to save thumbnail segment to file='%s'
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to save thumbnail segment to file='/data/dvr/live/camera/1700000000000.dat'
```

## Short description

DVR JPEG thumbnail could not be stored.

## Trigger condition

Appending a completed JPEG thumbnail to its storage file fails.

## Explanation

That thumbnail result is skipped and other results continue.

## Possible causes

- Appending a completed JPEG thumbnail to its storage file fails.

## What to check

1. Check disk space, permissions, and storage-write errors.

## Recommended action

Check disk space, permissions, and storage-write errors.
