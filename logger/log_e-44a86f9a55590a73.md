# Subtitle file could not be read

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-44a86f9a55590a73

## Log pattern

```text
failed to load subtitles from file='%s'
```

## Parameters

- Argument 1 — Subtitle filename: Text actual filesystem path being read, including a cache-fragment path for remote subtitles.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load subtitles from file='/media/movie.srt'
```

## Short description

Subtitle file could not be read.

## Trigger condition

A selected local subtitle file or the local fragment backing a cached remote subtitle item fails to load.

## Explanation

Subtitle preparation returns failure. Direct subtitle requests are canceled; optional subtitle discovery for a main playlist can continue without subtitles.

## Possible causes

- A selected local subtitle file or the local fragment backing a cached remote subtitle item fails to load.

## What to check

1. Check that this subtitle file is readable and complete; use adjacent messages to distinguish a failed subtitle request from optional subtitle omission.

## Recommended action

Check that this subtitle file is readable and complete; use adjacent messages to distinguish a failed subtitle request from optional subtitle omission.
