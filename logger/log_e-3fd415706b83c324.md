# RTMP AAC media arrives before its sequence header

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-3fd415706b83c324

## Log pattern

```text
[AM] aac data MUST follow aac sequence header
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] aac data MUST follow aac sequence header
```

## Short description

RTMP AAC media arrives before its sequence header.

## Trigger condition

A legacy AAC packet is not a sequence header and AAC initialization has not occurred.

## Explanation

The AAC packet is rejected and connection processing fails before decoding media.

## Possible causes

- A legacy AAC packet is not a sequence header and AAC initialization has not occurred.

## What to check

1. Check that a nonempty AAC sequence header precedes audio frames.

## Recommended action

Send the AAC decoder configuration before AAC media packets.
