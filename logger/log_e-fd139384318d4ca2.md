# Transport output send fails

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-fd139384318d4ca2

## Log pattern

```text
failed to send s=%d '%s:%d' errno=%d
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Destination: Configured destination IP address.
- Argument 3 — Port: Configured destination port.
- Argument 4 — Error: Operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send s=42 '192.0.2.20:5000' errno=101
```

## Short description

Transport output send fails.

## Trigger condition

The CBR sender receives a failed send, or a regular UDP/Zixi transport sender receives a socket error other than would-block.

## Explanation

The CBR sending worker stops; regular sender paths return failure and the send loop enters shutdown. The destination fields describe configured output settings, including the Zixi destination even when bytes are sent over a local bridge socket.

## Possible causes

- The CBR sender receives a failed send, or a regular UDP/Zixi transport sender receives a socket error other than would-block.

## What to check

1. Check the socket error, output peer, and network availability.

## Recommended action

Resolve the reported transport send error.
