# Audio sample storage allocation failed

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_e
Log level: error
Documentation ID: log_e-00287d232612cf76

## Log pattern

```text
failed to alloc audio buffer, %d
```

## Parameters

- Argument 1 — FFmpeg error: FFmpeg operation result, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc audio buffer, -12
```

## Short description

Audio sample storage allocation failed.

## Trigger condition

Allocating sample buffers for the new audio frame returns a negative result.

## Explanation

The frame object is freed and audio frame creation fails.

## Possible causes

- The stated frame allocation, layout copy, or sample conversion operation failed.

## What to check

1. Check the input audio format, channel layout, and accompanying FFmpeg diagnostics.

## Recommended action

Resolve the reported frame-preparation failure.
