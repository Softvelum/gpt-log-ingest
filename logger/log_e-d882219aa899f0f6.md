# Origin socket is already registered

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-d882219aa899f0f6

## Log pattern

```text
s=%d is already in active clients map
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=17 is already in active clients map
```

## Short description

Origin socket is already registered.

## Trigger condition

A new origin connection descriptor is already present in the active-session map.

## Explanation

Registration is refused; the HTTP client prepares HTTP 500 or the cache downloader reports setup failure.

## Possible causes

- A new origin connection descriptor is already present in the active-session map.

## What to check

1. Check earlier creation and closure events for the descriptor; repeated collisions indicate inconsistent socket ownership.

## Recommended action

Check earlier creation and closure events for the descriptor; repeated collisions indicate inconsistent socket ownership.
