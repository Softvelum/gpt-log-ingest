# WHEP pending control send failed

Product: Nimble Streamer
Component: WHEP playback helper
Logging function: log_e
Log level: error
Documentation ID: log_e-98131c3ec9c6b1d6

## Log pattern

```text
whep control socket failed to send session request from ProcessEvent
```

## Parameters

Separate occurrences handle zero-byte and hard negative sends. The pending buffer can contain either a session request or the control welcome.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whep control socket failed to send session request from ProcessEvent
```

## Short description

WHEP pending control send failed.

## Trigger condition

A writable event attempts to send buffered control data and the result is zero or a negative error other than would-block.

## Explanation

The helper control socket and pending output are cleared, pending starts are marked finished, and unclassified accepted sockets are removed. Playback sockets already assigned to media workers are not directly closed by this cleanup.

## Possible causes

- The WHEP helper control connection closes or encounters a hard send error.

## What to check

1. Check helper availability and surrounding connection diagnostics.

## Recommended action

Restore the control connection and retry affected playback starts.
