# WHIP stream name already registered

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-a1047678659fd37e

## Log pattern

```text
cannot start whip session with id=%d. stream=[%s/%s] already registered
```

## Parameters

- Argument 1 — Session identifier: WebRTC helper session identifier, unsigned 32-bit integer displayed in decimal; no unit.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot start whip session with id=7. stream=[live/camera] already registered
```

## Short description

WHIP stream name already registered.

## Trigger condition

A returned WHIP session is found, but registering its application and stream as a live source returns no stream object.

## Explanation

The returned socket is closed, the pending session is marked finished, and its publishing authorization record and request entry are removed.

## Possible causes

- Another live source already owns the same application and stream name.

## What to check

1. Check existing publishers for the named application and stream.

## Recommended action

Stop the conflicting publisher or assign a distinct stream name before retrying.
