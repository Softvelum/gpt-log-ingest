# DASH subtitle segment is cached

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_d
Log level: debug
Documentation ID: log_d-b4ae7626913b239f

## Log pattern

```text
add_dash_subtitle_segment key='%s' duration=%llu size=%u
```

## Parameters

- Argument 1 — Cache key: Application/stream path and generated segment or part name used as the cache identity.
- Argument 2 — Duration: Subtitle segment duration converted from 90 kHz ticks to whole milliseconds.
- Argument 3 — Size: WebVTT text size in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
add_dash_subtitle_segment key='/live/camera/s_100_0_eng.vtt' duration=2000 size=128
```

## Short description

DASH subtitle segment is cached.

## Trigger condition

A WebVTT subtitle segment has been stored and marked ready.

## Explanation

The subtitle bandwidth estimate and retained segment list are updated, and time-based timelines are refreshed when enabled.

## Possible causes

- A WebVTT subtitle segment has been stored and marked ready.

## What to check

1. Check the subtitle language in the key, duration, and payload size.

## Recommended action

No action is required for expected subtitle output.
