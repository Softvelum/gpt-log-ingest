# Stream-check request send failed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-06ab727f581bf3a2

## Log pattern

```text
failed to send to s=%d (errno=%d) task='%s'
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — error: Operating system error number.
- Argument 3 — task: Panel-supplied stream-check task identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send to s=12 (errno=32) task='check-a'
```

## Short description

Stream-check request send failed.

## Trigger condition

The plain socket send returns a negative failure result.

## Explanation

The task starts shutdown and returns from request sending. This path does not give temporary would-block errors a separate retry branch.

## Possible causes

- The socket send failed.

## What to check

1. Interpret the error and check the origin connection.

## Recommended action

Investigate the failed request transmission.
