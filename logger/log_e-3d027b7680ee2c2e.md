# Cannot set SRT encryption key length

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-3d027b7680ee2c2e

## Log pattern

```text
failed to set pbkeylen=%d, s=%d
```

## Parameters

- Argument 1 — Length: Configured encryption key length passed to SRT.
- Argument 2 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set pbkeylen=15, s=100
```

## Short description

Cannot set SRT encryption key length.

## Trigger condition

A passphrase is configured and the SRT library rejects its key-length setting.

## Explanation

Socket settings application stops before applying the passphrase. The default attempted length is 16 when none is configured.

## Possible causes

- A passphrase is configured and the SRT library rejects its key-length setting.

## What to check

1. Check the configured encryption key length.
