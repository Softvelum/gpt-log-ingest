# RTMP connect command is repeated

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-f293590032f77723

## Log pattern

```text
connect command sent twice for one rtmp session
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
connect command sent twice for one rtmp session
```

## Short description

RTMP connect command is repeated.

## Trigger condition

A second connect command arrives on an RTMP session that has already processed a connect command.

## Explanation

The repeated command is rejected and the connection processing fails. A new connect request requires a new session.

## Possible causes

- A second connect command arrives on an RTMP session that has already processed a connect command.

## What to check

1. Check whether the peer sends connect twice on the same connection.

## Recommended action

Correct the peer command sequence or reconnect before starting another connection handshake.
