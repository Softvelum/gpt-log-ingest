# Raw DRM key response is invalid

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-0457a2d8cc950613

## Log pattern

```text
failed to update key url='%s' status_code=%hu body_len=%d
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — HTTP status: Unsigned 16-bit HTTP status.
- Argument 3 — Body bytes: Integer response-body length in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to update key url='https://keys.example/key' status_code=503 body_len=0
```

## Short description

Raw DRM key response is invalid.

## Trigger condition

A raw-key response has a status other than HTTP 200 or a body length other than 16 bytes.

## Explanation

The key is marked failed and its previous bytes are retained.

## Possible causes

- A raw-key response has a status other than HTTP 200 or a body length other than 16 bytes.

## What to check

1. Restore an HTTP 200 response containing exactly 16 key bytes.

## Recommended action

Restore an HTTP 200 response containing exactly 16 key bytes.
