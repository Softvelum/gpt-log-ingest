# Server worker thread could not start

Product: Nimble Streamer
Component: Server worker threads
Logging function: log_e
Log level: error
Documentation ID: log_e-7e7eeb5817c6f070

## Log pattern

```text
failed to create thread [%s] message='%s' code=%d
```

## Parameters

- Argument 1 — Thread: Worker thread name, text.
- Argument 2 — Error text: Diagnostic description supplied by the operating system or library, text.
- Argument 3 — Resource error: Thread-library error code, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create thread [worker] message='operation failed' code=11
```

## Short description

Server worker thread could not start.

## Trigger condition

Creating a worker thread throws a thread-resource exception.

## Explanation

The creation request returns failure and no worker thread starts.

## Possible causes

- The thread library reports a resource error while creating the thread.

## What to check

1. Check the exception description and numeric resource error.

## Recommended action

Resolve the thread resource failure before retrying.
