# Enhanced RTMP FLAC media precedes its sequence header

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-8f6a88d9172a0f8a

## Log pattern

```text
[AM] flac data MUST follow flac sequence header for (%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] flac data MUST follow flac sequence header for (live/camera)
```

## Short description

Enhanced RTMP FLAC media precedes its sequence header.

## Trigger condition

A FLAC coded-audio packet arrives before enhanced audio initialization.

## Explanation

The packet is rejected and connection processing fails before audio delivery.

## Possible causes

- A FLAC coded-audio packet arrives before enhanced audio initialization.

## What to check

1. Check whether a FLAC sequence-start packet was sent and accepted before coded frames.

## Recommended action

Send the FLAC sequence header before coded audio packets.
