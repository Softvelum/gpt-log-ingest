# Encrypted SCTE-35 sections are unsupported

Product: Nimble Streamer
Component: SCTE-35 advertisement markers
Logging function: log_e
Log level: error
Documentation ID: log_e-ce8263f9e0645001

## Log pattern

```text
[SCTE35] encryption is currently unsupported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] encryption is currently unsupported
```

## Short description

Encrypted SCTE-35 sections are unsupported.

## Trigger condition

The encrypted-packet flag is set.

## Explanation

Splice-information section parsing stops and reports failure.

## Possible causes

- The incoming SCTE-35 marker is encrypted.

## What to check

1. Check the relevant field in the upstream SCTE-35 marker.

## Recommended action

Supply an unencrypted valid version-zero splice-information section.
