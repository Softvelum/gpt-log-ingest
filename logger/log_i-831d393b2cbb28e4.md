# DVR database uses line-by-line recovery

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_i
Log level: info
Documentation ID: log_i-831d393b2cbb28e4

## Log pattern

```text
Loading segments db='%s' line by line, parsed %d lines
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.
- Argument 2 — Recovered records: Number of individually accepted JSON records.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Loading segments db='/data/dvr/live/camera/nimble-dvr-segments.db' line by line, parsed 12 lines
```

## Short description

DVR database uses line-by-line recovery.

## Trigger condition

Whole-database loading returns no parsed array.

## Explanation

A fallback pass collects individually parseable records; the count is the accepted records, not every physical line.

## Possible causes

- Whole-database loading returns no parsed array.

## What to check

1. Check preceding database parse errors and whether expected recordings were recovered.

## Recommended action

Check preceding database parse errors and whether expected recordings were recovered.
