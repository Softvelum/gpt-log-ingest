# DVR initialization record could not be deleted

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-a419b717c7ea36f7

## Log pattern

```text
failed to remove init segment from segment db file='%s'
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove init segment from segment db file='/data/dvr/live/camera/nimble-dvr-segments.db'
```

## Short description

DVR initialization record could not be deleted.

## Trigger condition

Marking a deferred initialization record deleted in the segment database fails.

## Explanation

Storage-file removal stops before deleting the media file.

## Possible causes

- Marking a deferred initialization record deleted in the segment database fails.

## What to check

1. Check the preceding database open or seek error.

## Recommended action

Check the preceding database open or seek error.
