# Cannot configure SRT blocking behavior

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-5ae908264ac99a09

## Log pattern

```text
srt_setsockopt failed s=%d: %s
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.
- Argument 2 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_setsockopt failed s=100: Invalid socket ID
```

## Short description

Cannot configure SRT blocking behavior.

## Trigger condition

SRT rejects a send/receive synchronous-mode option or, for blocking mode, a send/receive timeout option.

## Explanation

The blocking-mode helper returns failure immediately. The message does not identify which of these settings failed.

## Possible causes

- SRT rejects a send/receive synchronous-mode option or, for blocking mode, a send/receive timeout option.

## What to check

1. Inspect the SRT error and whether the socket is being initialized for blocking or nonblocking operation.
