# Playlist default stream is invalid

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-a97bd0760692b62e

## Log pattern

```text
invalid DefaultStream in Block id=[%s]. Ignored
```

## Parameters

- Argument 1 — Block ID: Text identifying the schedule block.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid DefaultStream in Block id=[morning]. Ignored
```

## Short description

Playlist default stream is invalid.

## Trigger condition

The default stream has an unknown type, empty source, negative start, or audio/video selection below minus two.

## Explanation

The invalid default stream is ignored.

## Possible causes

- The default stream has an unknown type, empty source, negative start, or audio/video selection below minus two.

## What to check

1. Correct the default stream type, source, start offset, and track selections.

## Recommended action

Correct the default stream type, source, start offset, and track selections.
