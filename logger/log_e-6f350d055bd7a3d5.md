# Encoder Annex B configuration is invalid

Product: Nimble Streamer
Component: FFmpeg video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-6f350d055bd7a3d5

## Log pattern

```text
failed to parse annexb sps/pps/vps for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

The HEVC occurrence collects VPS/SPS/PPS; the H.264 occurrence collects SPS/PPS despite also mentioning VPS.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse annexb sps/pps/vps for [live/camera]
```

## Short description

Encoder Annex B configuration is invalid.

## Trigger condition

Parsing H.264 or HEVC Annex B configuration encounters fewer than three bytes or an empty NAL unit.

## Explanation

The output codec configuration is rejected and initialization or packet delivery returns failure.

## Possible causes

- The encoder supplies truncated Annex B data or an empty NAL unit.

## What to check

1. Check the encoder sequence header and codec selection.

## Recommended action

Provide valid Annex B codec configuration.
