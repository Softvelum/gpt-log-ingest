# RTMP authentication challenge session ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-875c012c63834010

## Log pattern

```text
failed to read session-id for setChallenge
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read session-id for setChallenge
```

## Short description

RTMP authentication challenge session ID cannot be decoded.

## Trigger condition

The setChallenge command cannot supply its session ID as an AMF number.

## Explanation

The command response is marked failed and connection processing stops before sending the calculated client login.

## Possible causes

- The setChallenge command cannot supply its session ID as an AMF number.

## What to check

1. Inspect the session ID in the destination challenge and its AMF type.

## Recommended action

Correct the malformed challenge at the authentication endpoint.
