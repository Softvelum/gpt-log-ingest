# RTMP publishing authorization reaches an invalid handler

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error

## Short description

RTMP publishing authorization reaches an invalid handler.

## Trigger condition

Publishing authorization is requested on a connection that has no specific authorization handler.

## Explanation

The connection publishing state is set to not authorized. This is an internal control-flow error rather than a normal credential rejection.

## Possible causes

- Publishing authorization is requested on a connection that has no specific authorization handler.

## What to check

1. Check the surrounding connection setup and publishing logs.

## Recommended action

Contact support with the connection sequence and this message.
