# RTMP connect transaction ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-25cf124763f5dfc5

## Log pattern

```text
failed to process transaction id for connect command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process transaction id for connect command
```

## Short description

RTMP connect transaction ID cannot be decoded.

## Trigger condition

The connect request cannot supply its transaction ID as an AMF number.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The connect request cannot supply its transaction ID as an AMF number.

## What to check

1. Inspect the transaction ID field and AMF framing in the incoming connect command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
