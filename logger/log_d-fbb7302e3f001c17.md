# DVR WebVTT entry without storage is removed

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-fbb7302e3f001c17

## Log pattern

```text
[DvrA::RemWS] p=%u st=%llu
```

## Parameters

- Argument 1 — Period: Unsigned recording period identifier.
- Argument 2 — Media start: 64-bit media start timestamp in the segment track timescale.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DvrA::RemWS] p=1 st=90000
```

## Short description

DVR WebVTT entry without storage is removed.

## Trigger condition

A selected WebVTT entry has no backing file reference.

## Explanation

The entry is erased from its language-track index without a file operation.

## Possible causes

- A selected WebVTT entry has no backing file reference.
