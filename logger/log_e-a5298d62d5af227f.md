# DVR export segment lookup failed

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-a5298d62d5af227f

## Log pattern

```text
failed to get dvr segments for stream='%s' utc_start=%llu utc_end=%llu
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get dvr segments for stream='live/camera' utc_start=1700000000 utc_end=1700000060
```

## Short description

DVR export segment lookup failed.

## Trigger condition

The archive manager cannot supply the requested recording range to MP4 or subtitle export.

## Explanation

The export returns HTTP 404.

## Possible causes

- The archive manager cannot supply the requested recording range to MP4 or subtitle export.

## What to check

1. Check archive registration, loading state, and the requested stream.

## Recommended action

Check archive registration, loading state, and the requested stream.
