# Existing connection assigned to a cache downloader

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-4d82b7012cc914ab

## Log pattern

```text
created downloader session=%p(s=%d key='%s' offset=%llu size=%llu)
```

## Parameters

- Argument 1 — Session: Connection-session address used for diagnostic correlation.
- Argument 2 — Socket: Integer socket descriptor.
- Argument 3 — Cache key: Destination cache-item identifier as text.
- Argument 4 — Offset: Unsigned 64-bit starting byte offset.
- Argument 5 — Size: Unsigned 64-bit requested byte length.

The 64-bit range values use unsigned-long-long conversions; exact underlying type compatibility depends on the build.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created downloader session=0x1000(s=12 key='example-item' offset=0 size=4096)
```

## Short description

Existing connection assigned to a cache downloader.

## Trigger condition

A nonempty cache item and positive socket descriptor have been used to construct a downloader session.

## Explanation

The caller receives success after construction; the requested cache range still needs to download.
