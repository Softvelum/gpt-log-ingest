# Socket receive failed

Product: Nimble Streamer
Component: Socket communication
Logging function: log_d
Log level: debug
Documentation ID: log_d-6e584a0b1559a6a3

## Log pattern

```text
failed to recv from s=%d (errno=%d)
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv from s=12 (errno=5)
```

## Short description

Socket receive failed.

## Trigger condition

Reading into the socket buffer returns an error other than would-block or try-again.

## Explanation

The receive helper reports an error without adding bytes to the buffer.

## Possible causes

- The operating system reported a receive failure.

## What to check

1. Check the socket error and connection state.

## Recommended action

Resolve the reported receive failure.
