# MP3 or Speex packet decoding failed

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-b6e12c538e154f5e

## Log pattern

```text
failed to decode mp3 packet from [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

The same literal message is used by MP3 and Speex decoding; its mp3 wording does not identify the codec reliably.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode mp3 packet from [live/camera]
```

## Short description

MP3 or Speex packet decoding failed.

## Trigger condition

The selected decoder returns failure while processing a MP3 or Speex packet from the live input buffer.

## Explanation

The audio item fails and the decoder worker leaves its processing loop.

## Possible causes

- The decoder rejects the payload, cannot initialize or allocate output, or its output delivery fails.

## What to check

1. Check preceding codec or output-queue diagnostics and the input packet or codec configuration.

## Recommended action

Correct the specific decoder or output failure and restart the affected audio pipeline.
