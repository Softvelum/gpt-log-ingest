# Cannot write Ogg frame into Icecast chunk

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-8868cdbb46653d51

## Log pattern

```text
icecast stream failed to write OGG chunk %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream failed to write OGG chunk http://radio.example.net/live
```

## Short description

Cannot write Ogg frame into Icecast chunk.

## Trigger condition

Writing the assembled Ogg frame to the Icecast output chunk fails.

## Explanation

Frame processing fails and the ingest session is shut down.

## Possible causes

- Writing the assembled Ogg frame to the Icecast output chunk fails.

## What to check

1. Check accumulated output chunk size and allocation.
