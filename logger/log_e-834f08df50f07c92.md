# SCTE-35 declared length exceeds available data

Product: Nimble Streamer
Component: SCTE-35 advertisement markers
Logging function: log_e
Log level: error
Documentation ID: log_e-834f08df50f07c92

## Log pattern

```text
[SCTE35] invalid section_length=%u buffer=%u
```

## Parameters

- Argument 1 — Declared length: Declared section length in bytes, unsigned integer.
- Argument 2 — Remaining bytes: Whole unread bytes following the section-length field, unsigned integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] invalid section_length=100 buffer=20
```

## Short description

SCTE-35 declared length exceeds available data.

## Trigger condition

The declared section length is greater than the remaining complete bytes after the length field.

## Explanation

Splice-information section parsing stops and reports failure.

## Possible causes

- The section is truncated or its declared length is incorrect.

## What to check

1. Check the relevant field in the upstream SCTE-35 marker.

## Recommended action

Supply an unencrypted valid version-zero splice-information section.
