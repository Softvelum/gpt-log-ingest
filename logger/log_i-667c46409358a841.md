# NVIDIA context destruction was issued

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-667c46409358a841

## Log pattern

```text
destroyed nvenc ctx=%p
```

## Parameters

- Argument 1 — Context: CUDA context handle, pointer printed in hexadecimal.

The in-use occurrence follows a warning that the context was still checked out.

## Log examples

Illustrative examples; these are not captured server logs.

```text
destroyed nvenc ctx=0x12340000
```

## Short description

NVIDIA context destruction was issued.

## Trigger condition

Manager release has called CUDA context destruction for a free cached context or a context still recorded as in use.

## Explanation

The corresponding cache or in-use record is removed. The driver destruction result is not checked by this message.
