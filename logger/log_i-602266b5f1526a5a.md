# NDI buffer delay statistics reached their reporting interval

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-602266b5f1526a5a

## Log pattern

```text
delay: min/avg/max=%d/%d/%d
```

## Parameters

- Argument 1 — Minimum delay: Intended minimum buffered delay in milliseconds, stored as an unsigned 64-bit integer.
- Argument 2 — Average delay: Intended integer mean of 101 delay samples in milliseconds, stored as an unsigned 64-bit integer.
- Argument 3 — Maximum delay: Intended maximum buffered delay in milliseconds, stored as an unsigned 64-bit integer.

All three values are unsigned 64-bit counters, but the original format uses %d conversions. The argument widths do not match.

## Log examples

No portable sound example is supplied because the logging call formats unsigned 64-bit counters using %d.

## Short description

NDI buffer delay statistics reached their reporting interval.

## Trigger condition

The sender pacing routine has collected 101 buffer-delay measurements since its previous report.

## Explanation

It computes minimum, integer average, and maximum delay in milliseconds, then clears the accumulation count and sum. The original call uses three narrow integer conversions for unsigned 64-bit counters, so its formatted values cannot be treated as portable reliable statistics.

## Possible causes

- The sender pacing routine has collected 101 buffer-delay measurements since its previous report.

## What to check

1. Check sender buffering behavior, taking the format mismatch into account.
