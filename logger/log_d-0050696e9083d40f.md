# HTTP/2 live stream request started

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_d
Log level: debug
Documentation ID: log_d-0050696e9083d40f

## Log pattern

```text
[H2C::PLSR] id=%lu o_url='%s' a_url='%s' f_name='%s'
```

## Parameters

- Argument 1 — Request stream identifier: HTTP request stream identifier, unsigned 64-bit integer displayed in decimal; no unit.
- Argument 2 — Origin URL: Origin resource URL after request routing, text; may include query parameters.
- Argument 3 — Aliased URL: Aliased request URL retained for this request, text; can be empty when no alias applies.
- Argument 4 — Decoded origin path: Origin URL with query parameters removed and percent escapes decoded, text; a logical resource path, not necessarily a disk filename.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[H2C::PLSR] id=4 o_url='/live/camera/playlist.m3u8' a_url='/public/camera/playlist.m3u8' f_name='/live/camera/playlist.m3u8'
```

## Short description

HTTP/2 live stream request started.

## Trigger condition

A live-stream request enters processing with its routed origin URL and decoded path.

## Explanation

Nimble splits the application, stream, and resource, then handles HLS, DASH, MPEG-TS over HTTP, or Icecast delivery. It may wait for media or return an error; this entry message does not indicate response success.
