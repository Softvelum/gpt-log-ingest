# AV1 CENC output for fragmented MP4 HLS is unsupported

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-29e1b669c909b84c

## Log pattern

```text
av1 cenc fmp4 hls currently unsupported [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the affected live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
av1 cenc fmp4 hls currently unsupported [live/camera]
```

## Short description

AV1 CENC output for fragmented MP4 HLS is unsupported.

## Trigger condition

CENC is required while initializing AV1 fragmented MP4 HLS, either initially or while retrying postponed video initialization.

## Explanation

The unsupported combination is logged without generating AV1 CENC HLS initialization in that branch. Other setup continues; this message is not an immediate whole-stream shutdown.

## Possible causes

- CENC is required while initializing AV1 fragmented MP4 HLS, either initially or while retrying postponed video initialization.

## What to check

1. Check whether the AV1 HLS route requires CENC encryption.

## Recommended action

Use a supported codec/encryption output combination.
