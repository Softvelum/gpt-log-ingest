# Whisper decoder reset for changed settings

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-91c0e81da9f529e3

## Log pattern

```text
reset transcriber on audio config change for [%s] lang=%s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Language: Configured language identifier for this transcription process; it may differ from the effective detected language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reset transcriber on audio config change for [live/news] lang=en
```

## Short description

Whisper decoder reset for changed settings.

## Trigger condition

A new valid configuration differs from the active decoder in audio format, model, GPU selection, or supported recognition options.

## Explanation

The existing decoder is destroyed. The new configuration is retained for a replacement on later audio.

## Possible causes

- A new valid configuration differs from the active decoder in audio format, model, GPU selection, or supported recognition options.

## What to check

1. Check which audio or transcription settings changed.
