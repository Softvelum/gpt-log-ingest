# SVT HEVC stream header is invalid

Product: Nimble Streamer
Component: SVT HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f906c16868729d51

## Log pattern

```text
failed to parse annexb sps/pps/vps
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse annexb sps/pps/vps
```

## Short description

SVT HEVC stream header is invalid.

## Trigger condition

Parsing the returned Annex B stream header into HEVC parameter sets fails.

## Explanation

The header buffer is released and encoder initialization returns failure before passing codec information to the output.

## Possible causes

- The encoder header is not accepted as HEVC Annex B parameter-set data.

## What to check

1. Check the SVT HEVC installation and preceding header diagnostics.

## Recommended action

Use a compatible encoder library that supplies valid HEVC headers.
