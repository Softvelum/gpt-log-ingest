# RTMP connect result lacks a success code

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-f82829dd566ff951

## Log pattern

```text
connect failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
connect failed
```

## Short description

RTMP connect result lacks a success code.

## Trigger condition

A connect result reaches the end of its response object without accepting NetConnection.Connect.Success.

## Explanation

The pending connection command is marked failed and connection processing stops. A different explicit code can fail earlier without this particular message.

## Possible causes

- A connect result reaches the end of its response object without accepting NetConnection.Connect.Success.

## What to check

1. Check whether the result contains a string code field with the connection-success value.

## Recommended action

Resolve the remote connection rejection or malformed success response.
