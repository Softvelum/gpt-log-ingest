# NVIDIA H.264 parameter setup failed

Product: Nimble Streamer

Log level: error

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

NVIDIA H.264 parameter setup failed.

## Trigger condition

The H.264-specific parameter configuration helper returns failure.

## Explanation

Encoder initialization stops before the NVIDIA initialization call.

## Possible causes

- A constrained-encoding, adaptive-transform, flexible-macroblock-ordering, B-direct or entropy-coding capability query fails.

## What to check

1. Check the preceding capability-query message.

## Recommended action

Correct that query failure before retrying H.264 encoding.
