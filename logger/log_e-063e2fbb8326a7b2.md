# Addenda license file cannot be updated

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-063e2fbb8326a7b2

## Log pattern

```text
cannot update addenda license file! Fix this ASAP
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot update addenda license file! Fix this ASAP
```

## Short description

Addenda license file cannot be updated.

## Trigger condition

Opening the Addenda license file for output fails after receiving a changed expiration date.

## Explanation

The updated license cannot be saved to disk; the in-memory expiration has already been changed.

## Possible causes

- Opening the Addenda license file for output fails after receiving a changed expiration date.

## What to check

1. Restore write access to the Addenda license file and its directory.

## Recommended action

Restore write access to the Addenda license file and its directory.
