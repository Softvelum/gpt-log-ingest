# AJA output requires an explicit frame rate

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-a7d7a373c26c932d

## Log pattern

```text
aja requires fps to be explicitly set. use fps filter to set fps. for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
aja requires fps to be explicitly set. use fps filter to set fps. for [live/encoded]
```

## Short description

AJA output requires an explicit frame rate.

## Trigger condition

The first video frame for the AJA writer has a frame-rate rational with a zero numerator or denominator.

## Explanation

The frame is rejected before the output time base is established.

## Possible causes

- The upstream video pipeline did not provide a valid explicit frame rate.

## What to check

1. Check the frame-rate setting on the input filter chain.

## Recommended action

Add an fps filter with the required output frame rate and restart the output.
