# Cache notification refers to another item

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-242625414295acae

## Log pattern

```text
ClientSession(%p) item (key='%s') is not observed
```

## Parameters

- Argument 1 — Session address: Pointer identifying this client session within the process.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ClientSession(0x1234) item (key='/live/camera/segment1.ts') is not observed
```

## Short description

Cache notification refers to another item.

## Trigger condition

A cache update key differs from the key of the item currently held by the session.

## Explanation

The notification is logged and ignored.

## Possible causes

- A cache update key differs from the key of the item currently held by the session.

## What to check

1. Correlate observer registration and cleanup for the reported key and session.

## Recommended action

Correlate observer registration and cleanup for the reported key and session.
