# Cannot assemble Ogg audio around metadata

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-7695caf609dd213f

## Log pattern

```text
icecast frame buffer not enough %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast frame buffer not enough http://radio.example.net/live
```

## Short description

Cannot assemble Ogg audio around metadata.

## Trigger condition

Writing audio bytes into the frame buffer fails while removing interleaved Icecast metadata from Ogg input.

## Explanation

The session is shut down.

## Possible causes

- Writing audio bytes into the frame buffer fails while removing interleaved Icecast metadata from Ogg input.

## What to check

1. Check buffer allocation and the size of buffered Ogg audio.
