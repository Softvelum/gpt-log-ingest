# VCAS asset creation could not be submitted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-16db67d20c0e6901

## Log pattern

```text
[drm] failed to POST VCAS CreateAsset to url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] failed to POST VCAS CreateAsset to url='https://keys.example/key'
```

## Short description

VCAS asset creation could not be submitted.

## Trigger condition

The HTTP processor refuses the VCAS CEI create-asset POST request.

## Explanation

The application key set is removed so registration can be attempted again.

## Possible causes

- The HTTP processor refuses the VCAS CEI create-asset POST request.

## What to check

1. Check the VCAS endpoint and HTTP request-processor errors.

## Recommended action

Check the VCAS endpoint and HTTP request-processor errors.
