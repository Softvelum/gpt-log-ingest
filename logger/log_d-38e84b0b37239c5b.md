# Remote media response callback started

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_d
Log level: debug
Documentation ID: log_d-38e84b0b37239c5b

## Log pattern

```text
MediaCacheManager::OnRequestProcessed url='%s' status=%d body_len=%lld
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — status: HTTP response status code.
- Argument 3 — body bytes: Parsed response body length in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
MediaCacheManager::OnRequestProcessed url='https://media.example/movie.mp4' status=206 body_len=1048576
```

## Short description

Remote media response callback started.

## Trigger condition

An external request reports a parsed response to the cache manager.

## Explanation

The manager logs status and body length before verifying the URL, cache state, status, range, and body size. This alone does not establish successful caching.
