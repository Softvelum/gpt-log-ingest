# Decoded publishing signature is too long

Product: Nimble Streamer
Component: Publisher authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-8a4a566ae4730252

## Log pattern

```text
publishsign length > 512 for [%s][%s]
```

## Parameters

- Argument 1 — stream: Application and stream path being published, beginning with a slash.
- Argument 2 — client: Publishing client IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
publishsign length > 512 for [/live/camera][192.0.2.10]
```

## Short description

Decoded publishing signature is too long.

## Trigger condition

Percent and Base64 decoding yields more than 512 bytes of publishing signature data.

## Explanation

Publishing signature validation fails before parsing its fields.

## Possible causes

- The decoded signature exceeds the supported size.

## What to check

1. Check how the publishing client creates the authorization value.

## Recommended action

Provide a correctly encoded signature within the allowed length.
