# SCTE-35 protocol version is unsupported

Product: Nimble Streamer
Component: SCTE-35 advertisement markers
Logging function: log_e
Log level: error
Documentation ID: log_e-6d00617e22a04a1c

## Log pattern

```text
[SCTE35] invalid protocol_version=%d
```

## Parameters

- Argument 1 — Version: Received protocol version byte, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] invalid protocol_version=1
```

## Short description

SCTE-35 protocol version is unsupported.

## Trigger condition

The protocol version byte is nonzero.

## Explanation

Splice-information section parsing stops and reports failure.

## Possible causes

- The section uses a version other than the supported version zero.

## What to check

1. Check the relevant field in the upstream SCTE-35 marker.

## Recommended action

Supply an unencrypted valid version-zero splice-information section.
