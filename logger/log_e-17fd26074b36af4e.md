Product: Nimble Streamer
Component: Fragmented media to transport stream packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-17fd26074b36af4e

```text
[AM] audio_buffer too small: failed to write id3 info
```

## Log examples

The reviewed path first reserves exactly the same 73-byte prefix plus ID3 payload capacity later requested by this append; no ordinary input-driven failure at this second check is established.

## Short description

Packed-audio ID3 metadata cannot be appended.

## Trigger condition

Appending supplied ID3 metadata to the packed-audio chunk fails after its timestamp metadata prefix has been created.

## Explanation

Audio-only output chunk reconstruction returns failure.

## Possible causes

- Appending supplied ID3 metadata to the packed-audio chunk fails after its timestamp metadata prefix has been created.

## What to check

1. Check ID3 byte count and output-buffer capacity.

## Recommended action

Investigate unexpected metadata append failure.
