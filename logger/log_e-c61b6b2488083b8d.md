# AAC decoder configuration was rejected

Product: Nimble Streamer
Component: FDK AAC audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-c61b6b2488083b8d

## Log pattern

```text
failed to set aac config, %x
```

## Parameters

- Argument 1 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set aac config, 1
```

## Short description

AAC decoder configuration was rejected.

## Trigger condition

The decoder has explicit AAC configuration and the library rejects it.

## Explanation

Decoder initialization fails before packets can be decoded.

## Possible causes

- The supplied AAC configuration is not accepted by FDK.

## What to check

1. Check the AAC configuration and hexadecimal library status.

## Recommended action

Provide valid configuration matching the incoming AAC.
