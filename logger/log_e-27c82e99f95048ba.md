# SLDP playback command is unknown

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-27c82e99f95048ba

## Log pattern

```text
unknown command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown command
```

## Short description

SLDP playback command is unknown.

## Trigger condition

A subsequent command is not recognized as Play, Cancel, or Time, including JSON without a recognized command field.

## Explanation

Command handling fails and the caller closes the playback connection.

## Possible causes

- A subsequent command is not recognized as Play, Cancel, or Time, including JSON without a recognized command field.

## What to check

1. Check command spelling, case, and the top-level command field.

## Recommended action

Send one of the supported command names.
