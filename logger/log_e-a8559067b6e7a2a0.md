# AJA playback circulation stopped unexpectedly

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-a8559067b6e7a2a0

## Log pattern

```text
playback stopped device=%s/%d reason='AutoCirculate stopped'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback stopped device=0/0 reason='AutoCirculate stopped'
```

## Short description

AJA playback circulation stopped unexpectedly.

## Trigger condition

After circulation was started, an output wait observes a stopped or stopping state.

## Explanation

The frame wait returns failure and pending frame transfer stops.

## Possible causes

- After circulation was started, an output wait observes a stopped or stopping state.

## What to check

1. Check what stopped the card playback engine.
