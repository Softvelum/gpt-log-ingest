# Origin request prepared for transmission

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-a900a7e94d196de0

## Log pattern

```text
origin s=%d request (%dB):
%s
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.
- Argument 2 — Request bytes: Native-size unsigned HTTP request length in bytes, incorrectly printed with %d.
- Argument 3 — Request text: Text of the HTTP request being sent.

The request length is a native-size unsigned value passed to a %d conversion; its output is not reliable on platforms where that type is wider than int.

## Log examples

The request length is a native-size unsigned value passed to a %d conversion; its output is not reliable on platforms where that type is wider than int.

## Short description

Origin request prepared for transmission.

## Trigger condition

An origin connection succeeds and its HTTP request is ready to send.

## Explanation

The request text is logged before transmission begins; it does not prove the origin received the request.

## Possible causes

- An origin connection succeeds and its HTTP request is ready to send.
