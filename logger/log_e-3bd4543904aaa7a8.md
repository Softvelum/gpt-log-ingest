# RTSP header line is malformed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-3bd4543904aaa7a8

## Log pattern

```text
unable to parse header line for [%s]: %s
```

## Parameters

- Argument 1 — Stream identity: Application and stream label used by the RTSP parser.
- Argument 2 — Header line: Received header text without its terminating newline.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unable to parse header line for [live/camera]: invalid-header
```

## Short description

RTSP header line is malformed.

## Trigger condition

A nonempty complete header line cannot be parsed as a header name and value, or its authorization field cannot be parsed.

## Explanation

The parser resets to its interleaved-data state and returns parse failure.

## Possible causes

- A nonempty complete header line cannot be parsed as a header name and value, or its authorization field cannot be parsed.

## What to check

1. Check the displayed header syntax and any authorization value.

## Recommended action

Supply a correctly formed header field.
