# Child process launch raised an exception

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-e53266004649222d

## Log pattern

```text
failed to start process '%s' error='%s'
```

## Parameters

- Argument 1 — Command: Command supplied for launching the child, text.
- Argument 2 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start process 'nimble_transcoder' error='operation failed'
```

## Short description

Child process launch raised an exception.

## Trigger condition

Creating a child with restricted inherited handles raises a standard exception.

## Explanation

No child handle is returned. Child standard output and error are redirected away from the parent.

## Possible causes

- The child-process library reports the included launch failure.

## What to check

1. Check the requested command and exception text.

## Recommended action

Resolve the reported executable or process-creation failure.
