# License server response exceeded receive capacity

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-371172884af6f6c3

## Log pattern

```text
Transcoder validation procedure failed to read server response
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Transcoder validation procedure failed to read server response
```

## Short description

License server response exceeded receive capacity.

## Trigger condition

The license-validation response exceeds the available receive capacity.

## Explanation

This license-validation attempt did not complete. The server can retry the license service; this message alone does not establish that the license was rejected.

## Possible causes

- The license response exceeds the bounded response storage.

## What to check

1. Check the response size and whether a proxy returned unexpected content.

## Recommended action

Resolve the specific synchronization failure so license validation can succeed.
