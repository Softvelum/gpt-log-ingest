# HTTP/2 socket removal from event monitor failed

Product: Nimble Streamer
Component: HTTP/2 connection
Logging function: log_e
Log level: error
Documentation ID: log_e-0e92575a5e826934

## Log pattern

```text
Http2Connection(%p) failed to delete %s s=%d from selector fd=%d
```

## Parameters

- Argument 1 — Connection identity: In-process connection object address, pointer displayed in hexadecimal; useful only for correlating this process lifetime.
- Argument 2 — Socket label: Diagnostic name assigned to the client socket, text.
- Argument 3 — Socket: Socket descriptor, integer; no unit.
- Argument 4 — Event monitor descriptor: Underlying event-monitor descriptor, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Http2Connection(0x12340000) failed to delete client s=12 from selector fd=5
```

## Short description

HTTP/2 socket removal from event monitor failed.

## Trigger condition

During destruction of an HTTP/2 connection with an open positive descriptor, removing its client socket from the event monitor returns failure.

## Explanation

Cleanup continues: the connection is removed from active clients and the socket is closed.

## Possible causes

- The event monitor rejects removal of the socket, including an inconsistent registration state.

## What to check

1. Check nearby socket cleanup and monitor diagnostics for the descriptor.

## Recommended action

Investigate repeated cleanup failures; no retry is performed here.
