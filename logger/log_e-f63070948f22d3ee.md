# NVIDIA AV1 configuration creation failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f63070948f22d3ee

## Log pattern

```text
failed to create av1 config record for encoder=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create av1 config record for encoder=0x12340000
```

## Short description

NVIDIA AV1 configuration creation failed.

## Trigger condition

Building an AV1 configuration record from the returned encoder sequence header fails.

## Explanation

Encoder initialization fails before usable codec configuration is supplied to the output.

## Possible causes

- The driver sequence header is not accepted by the codec-configuration builder.

## What to check

1. Check the selected codec, driver compatibility and returned sequence-header diagnostics.

## Recommended action

Use a compatible driver and supported encoding configuration.
