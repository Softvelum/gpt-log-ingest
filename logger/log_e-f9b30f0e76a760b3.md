# Awaited cache fragment is marked failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-f9b30f0e76a760b3

## Log pattern

```text
cache item key='%s' fragment=%u is failed
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Fragment index: Unsigned zero-based index of the requested cache fragment.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item key='/live/camera/segment1.ts' fragment=1 is failed
```

## Short description

Awaited cache fragment is marked failed.

## Trigger condition

A fragmented response resumes and finds its awaited fragment marked failed.

## Explanation

HTTP/1 shuts down the client socket. HTTP/2 or HTTP/3 fails body preparation and attempts an internal-error stream reset.

## Possible causes

- A fragmented response resumes and finds its awaited fragment marked failed.

## What to check

1. Check the source-range download and cache errors that marked this fragment failed.

## Recommended action

Check the source-range download and cache errors that marked this fragment failed.
