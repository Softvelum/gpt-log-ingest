# Origin playlist response received

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-8c074ed77a469ba0

## Log pattern

```text
origin s=%d response playlist url='%s%s':
%.*s
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.
- Argument 2 — Origin host: Text containing the origin hostname and optional port.
- Argument 3 — Playlist path: Origin URL text with query parameters removed.
- Argument 4 — Response bytes: Integer byte limit applied to the response text.
- Argument 5 — Response text: Raw HTTP response text limited by the preceding byte count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
origin s=17 response playlist url='media.example:8080/live/camera/playlist.m3u8':
HTTP/1.0 200 OK
Content-Length: 8

#EXTM3U

```

## Short description

Origin playlist response received.

## Trigger condition

A complete nonempty origin response with status 200 or 206 enters playlist processing.

## Explanation

The origin connection has been closed; the response is logged before its playlist type is checked.

## Possible causes

- A complete nonempty origin response with status 200 or 206 enters playlist processing.
