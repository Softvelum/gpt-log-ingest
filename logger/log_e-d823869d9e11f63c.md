# DVR segment removal could not update storage

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-d823869d9e11f63c

## Log pattern

```text
failed to remove segment='%s'
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove segment='/data/dvr/live/camera/1700000000000.dat'
```

## Short description

DVR segment removal could not update storage.

## Trigger condition

Removing an audio, extra-data, WebVTT, or general nonaudio segment fails while marking its database record deleted.

## Explanation

The corresponding removal path returns failure; archive cleanup may continue with later segments.

## Possible causes

- Removing an audio, extra-data, WebVTT, or general nonaudio segment fails while marking its database record deleted.

## What to check

1. Check the preceding segment-database open or seek failure.

## Recommended action

Check the preceding segment-database open or seek failure.
