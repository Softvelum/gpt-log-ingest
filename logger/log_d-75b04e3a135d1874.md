# Management connection event received

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_d
Log level: debug
Documentation ID: log_d-75b04e3a135d1874

## Log pattern

```text
[HMC::PE] p=%p st=%d s=%d ev=0x%x
```

## Parameters

- Argument 1 — client\_address: Pointer identifying the client object; not a network address.
- Argument 2 — state: State number: 0 invalid, 1 waiting for a request, 2 receiving, 3 replying, 4 shut down, 5 shutting down.
- Argument 3 — socket: Client socket descriptor.
- Argument 4 — event\_mask: Event flags printed in hexadecimal; no flag-number mapping is inferred here.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[HMC::PE] p=0x123400 st=2 s=42 ev=0x1
```

## Short description

Management connection event received.

## Trigger condition

A management client receives a selector event.

## Explanation

The trace records the client identity and current state before updating activity time or handling close, error, input, or output events.
