# WHIP blocked session request cannot await output

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e

## Short description

WHIP blocked session request cannot await output.

## Trigger condition

The first send would block, output monitoring is not already enabled, and enabling writable events fails.

## Explanation

The control socket is closed, pending starts are marked finished, pending data is cleared, and active WHIP publications are removed and their stream registrations released. The new session is marked finished and its authorization record is removed.

## Possible causes

- The event monitor cannot register the control socket for pending output.

## What to check

1. Check nearby control-connection and event-monitor errors.

## Recommended action

Restore the helper connection and retry the publication.
