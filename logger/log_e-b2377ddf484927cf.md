# MP4 response has data after its file segment

Product: Nimble Streamer
Component: Non-Windows progressive download modules
Logging function: log_e
Log level: error
Documentation ID: log_e-b2377ddf484927cf

## Log pattern

```text
Mp4Module::HandleRequest data after file buffer
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Mp4Module::HandleRequest data after file buffer
```

## Short description

MP4 response has data after its file segment.

## Trigger condition

A file-backed output buffer has another chain entry after it.

## Explanation

The MP4 wrapper marks the chain invalid, clears response content length, and changes status 200 to 500. Other existing status values are retained.

## Possible causes

- A file-backed output buffer has another chain entry after it.

## What to check

1. Check the module return result and selected local media file.

## Recommended action

Investigate the module output that violates the wrapper buffer requirements.
