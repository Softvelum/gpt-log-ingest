# Cannot load TLS private key

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_e
Log level: error
Documentation ID: log_e-81f97c3908016229

## Log pattern

```text
failed to use SSL cert key file='%s' e='%s'
```

## Parameters

- Argument 1 — File: Configured private key file path.
- Argument 2 — Error: Error text reported by the TLS library.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to use SSL cert key file='/data/certs/key.pem' e='error loading PEM data'
```

## Short description

Cannot load TLS private key.

## Trigger condition

The TLS library rejects loading the configured private key file.

## Explanation

Creating this certificate context fails, so the pending certificate reload cannot replace the active context set. HTTP/3 uses the same diagnostic when supported.

## Possible causes

- The TLS library rejects loading the configured private key file.

## What to check

1. Check the indicated file and TLS error text for path, readability, encoding, or key-password problems.

## Recommended action

Provide a valid readable private key file.
