# Stream-check protocol is unsupported

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-0ea013096afe29a9

## Log pattern

```text
task is invalid protocol not supported %s
```

## Parameters

- Argument 1 — URL: Task URL including its unsupported protocol.

## Log examples

Illustrative examples; these are not captured server logs.

```text
task is invalid protocol not supported ftp://media.example/movie
```

## Short description

Stream-check protocol is unsupported.

## Trigger condition

The task URL scheme is outside HTTP, HTTPS, RTSP, RTSPS, RTMP, and RTMPS.

## Explanation

The task records an unsupported-protocol result and is not connected.

## Possible causes

- The monitoring task uses an unsupported URL scheme.

## What to check

1. Check the task protocol.

## Recommended action

Use a supported stream-check protocol.
