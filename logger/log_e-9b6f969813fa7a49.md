# MP4 parsing failed during thumbnail creation

Product: Nimble Streamer
Component: JPEG thumbnails
Logging function: log_e
Log level: error
Documentation ID: log_e-9b6f969813fa7a49

## Log pattern

```text
BaseMP4LoaderException caught while creating jpg thumbnail for stream='%s/%s'
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
BaseMP4LoaderException caught while creating jpg thumbnail for stream='live/camera'
```

## Short description

MP4 parsing failed during thumbnail creation.

## Trigger condition

Loading or reading the initialization or video fragment structure raises an MP4 loader exception.

## Explanation

The recorded-media thumbnail request returns failure, and the worker also logs its segment details.

## Possible causes

- The requested MP4 initialization or fragment data cannot be parsed as required.

## What to check

1. Check the following segment-detail message and whether the initialization and media bytes form valid matching MP4 fragments.

## Recommended action

Repair or regenerate invalid recorded content.
