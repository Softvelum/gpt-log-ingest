# CPIX DRM signaling cannot be parsed

Product: Nimble Streamer
Component: KeyOS DRM
Logging function: log_e
Log level: error
Documentation ID: log_e-3073a30159dbdb01

## Log pattern

```text
failed to parse DRMSystemList
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse DRMSystemList
```

## Short description

CPIX DRM signaling cannot be parsed.

## Trigger condition

After key decryption, the XML root is missing or is not CPIX, or the DRM system list cannot be processed.

## Explanation

The response is rejected even though key bytes were already decoded.

## Possible causes

- After key decryption, the XML root is missing or is not CPIX, or the DRM system list cannot be processed.

## What to check

1. Check the CPIX root and supported DRM system signaling fields.

## Recommended action

Check the CPIX root and supported DRM system signaling fields.
