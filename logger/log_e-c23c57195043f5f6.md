# HTTP/3 destination-address reporting could not be enabled

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-c23c57195043f5f6

## Log pattern

```text
failed to set IPPROTO_IP|IPPROTO_IPV6, errno=%d socket=%d
```

## Parameters

- Argument 1 — System error: Platform socket-error result.
- Argument 2 — Socket: Integer HTTP/3 UDP socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set IPPROTO_IP|IPPROTO_IPV6, errno=22 socket=12
```

## Short description

HTTP/3 destination-address reporting could not be enabled.

## Trigger condition

Enabling destination-address metadata on an IPv4 or IPv6 HTTP/3 UDP socket fails. This path requires HTTP/3 support and a configuration that needs it.

## Explanation

Socket-option setup returns failure and server initialization exits with a failure status.

## Possible causes

- Enabling destination-address metadata on an IPv4 or IPv6 HTTP/3 UDP socket fails.

## What to check

1. Inspect the failed option and socket error.
