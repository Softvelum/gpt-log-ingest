# Statistics name filtering raised an exception

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_e
Log level: error
Documentation ID: log_e-10a4587e7f924ca5

## Log pattern

```text
std::exception caught re='%s' s='%s' what='%s'
```

## Parameters

- Argument 1 — Expression: Regular-expression text used for filtering.
- Argument 2 — Name: Host, application or stream name being matched.
- Argument 3 — Error detail: Exception diagnostic text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
std::exception caught re='(a+)+' s='camera' what='matching failed'
```

## Short description

Statistics name filtering raised an exception.

## Trigger condition

Evaluating a regular-expression match against a host, application or stream name throws an exception.

## Explanation

The attempted match is treated as false, so that name is excluded from the filtered statistics result.

## Possible causes

- The expression matcher raised an exception.

## What to check

1. Inspect the filter expression, name and reported exception.
