# SCTE-35 packet automatically selected

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-236ba179f86a6ca0

## Log pattern

```text
updateAvailable scte35 type implicitly set found pid=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable scte35 type implicitly set found pid=300
```

## Short description

SCTE-35 packet automatically selected.

## Trigger condition

SCTE-35 processing is enabled and the active SCTE-35 identifier is zero while the input default is nonzero.

## Explanation

The default identifier becomes active and is added to the set of packets requested from the input.
