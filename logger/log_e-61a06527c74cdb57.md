# VAAPI parameter set is not byte aligned

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-61a06527c74cdb57

## Log pattern

```text
bad bit offset
```

## Parameters

Shared by sequence and picture parameter sets. No ordinary input-triggered path to this check is established because trailing-bit writing loops until the bit offset is zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
bad bit offset
```

## Short description

VAAPI parameter set is not byte aligned.

## Trigger condition

The H.264 sequence or picture writer observes a nonzero bit offset after writing trailing alignment bits.

## Explanation

Parameter-set creation returns failure and encoder initialization stops.

## Possible causes

- The parameter-set writer has an inconsistent alignment state; the normal trailing-bit loop is intended to finish at a zero offset.

## What to check

1. Retain the encoding settings and preceding diagnostics for investigation if this defensive check is reached.

## Recommended action

Restart the affected encoder and investigate the reproducible parameter-set writing failure.
