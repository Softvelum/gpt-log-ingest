# WHEP media send count inconsistent

Product: Nimble Streamer
Component: WHEP media delivery
Logging function: log_e
Log level: error
Documentation ID: log_e-37732ed399680a95

## Log pattern

```text
whep socket sent more that requested. impossible
```

## Parameters

One occurrence validates the media payload total; the other validates a header/JSON metadata total.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whep socket sent more that requested. impossible
```

## Short description

WHEP media send count inconsistent.

## Trigger condition

A reported socket send advances either the payload offset or header/metadata offset beyond the corresponding buffer length.

## Explanation

The worker removes the session from active playback, marks it aborted, stops socket monitoring, and releases its helper media connection.

## Possible causes

- The returned byte count violates the socket send contract.

## What to check

1. Capture surrounding session diagnostics and identify whether payload or metadata was being sent.

## Recommended action

Investigate repeated inconsistent send counts as an internal transport defect.
