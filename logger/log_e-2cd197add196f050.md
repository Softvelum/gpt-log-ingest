# Could not create the Speechmatics transcription worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e

Documentation ID: log_e-2cd197add196f050

## Short description

Could not create the Speechmatics transcription worker.

## Trigger condition

Speechmatics support is compiled in and its transcription worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the Speechmatics transcription worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed Speechmatics transcription worker.
