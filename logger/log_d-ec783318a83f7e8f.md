# Child forced-kill request started

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_d
Log level: debug
Documentation ID: log_d-ec783318a83f7e8f

## Log pattern

```text
sending SIGKILL to child pid=%d
```

## Parameters

- Argument 1 — Process: Child process identifier, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sending SIGKILL to child pid=1234
```

## Short description

Child forced-kill request started.

## Trigger condition

The non-Windows polling loop did not establish that the child stopped before the allotted iterations ended, or a wait error ended polling.

## Explanation

A forced-kill signal is sent, followed by a blocking child wait and final process-library wait.

## Possible causes

- The child did not stop within the available polling period, or polling failed.

## What to check

1. Check preceding wait errors and child shutdown behavior.

## Recommended action

Resolve unexpected shutdown delays or wait failures.
