# DVR archive discovered in an application directory

Product: Nimble Streamer
Component: DVR
Logging function: log_d
Log level: debug
Documentation ID: log_d-4f69dd4a0515a5e5

## Log pattern

```text
loading dvr archive='%s' from path='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Archive directory: Text giving the DVR storage directory.

## Log examples

Illustrative examples; these are not captured server logs.

```text
loading dvr archive='live/camera' from path='/data/dvr/live/camera'
```

## Short description

DVR archive discovered in an application directory.

## Trigger condition

A stream directory is found without a current archive object.

## Explanation

A new archive is created and loaded immediately or added to the deferred loading list.

## Possible causes

- A stream directory is found without a current archive object.
