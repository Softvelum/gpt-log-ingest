# SRT receiver session started

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_d
Log level: debug
Documentation ID: log_d-95a048befa73354a

## Log pattern

```text
srt session started s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt session started s=101
```

## Short description

SRT receiver session started.

## Trigger condition

A multipoint receiver completes stream selection, nonblocking/event setup, and required session registration.

## Explanation

The sender enters its connected/start state and can begin delivering available output.

## Possible causes

- A multipoint receiver completes stream selection, nonblocking/event setup, and required session registration.

## What to check

1. Check the corresponding receiver and stream statistics.
