# MP3 channel count was rejected

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-688742e618d722f0

## Log pattern

```text
failed to set num channels=%d, status=%d
```

## Parameters

- Argument 1 — Channels: Number of audio channels, integer.
- Argument 2 — Status: LAME return status, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set num channels=2, status=-1
```

## Short description

MP3 channel count was rejected.

## Trigger condition

In a LAME-enabled build, applying channel count returns a nonzero status.

## Explanation

Encoder initialization stops and the audio-frame write reports failure.

## Possible causes

- LAME rejected channel count.

## What to check

1. Check the input channel count and the returned LAME status.

## Recommended action

Correct the rejected MP3 encoder setting.
