# CUDA context cache fill finished

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-fd1321224b261a3d

## Log pattern

```text
cached %zd cuda ctx, gpu=%d, flag=%d
```

## Parameters

- Argument 1 — Added contexts: Intended count of newly cached contexts. An ordinary int is passed to a signed-size conversion; its printed value has a type mismatch.
- Argument 2 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 3 — Flags: CUDA context creation flags, integer bit mask printed in decimal; no unit.

## Log examples

No portable runtime example can be asserted: the first conversion expects signed size-width data but receives an int.

## Short description

CUDA context cache fill finished.

## Trigger condition

All requested creation attempts in a cache batch have completed.

## Explanation

The first field is intended to report the increase in free cached contexts for this GPU and flags. The format uses a size-width conversion for an ordinary integer argument, so the printed count is not reliable on all platforms.
