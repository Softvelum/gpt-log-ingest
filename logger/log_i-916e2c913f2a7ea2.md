# Advertising content definition removed

Product: Nimble Streamer
Component: Advertising
Logging function: log_i
Log level: info
Documentation ID: log_i-916e2c913f2a7ea2

## Log pattern

```text
removed advertising content id='%s'
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed advertising content id='ad-01'
```

## Short description

Advertising content definition removed.

## Trigger condition

A full content synchronization omits an existing content identifier.

## Explanation

Its entry is removed from the advertising content registry.

## Possible causes

- A full content synchronization omits an existing content identifier.
