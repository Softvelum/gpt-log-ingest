# VAAPI input pixel format is unsupported

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-5819f16f144a2cf1

## Log pattern

```text
unsupported input frame format=%d

```

## Parameters

- Argument 1 — Pixel format: Input FFmpeg pixel-format identifier, integer enumeration value; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported input frame format=0

```

## Short description

VAAPI input pixel format is unsupported.

## Trigger condition

The derived surface image is NV12 but the input frame is not NV12.

## Explanation

Frame encoding returns failure before copying pixels, despite this message having debug severity.

## Possible causes

- The upstream pipeline supplied a pixel format other than NV12.

## What to check

1. Check the input FFmpeg pixel format and preceding video conversion settings.

## Recommended action

Convert input frames to NV12 before using this encoder.
