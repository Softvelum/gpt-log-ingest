# Cannot set SRT packet-reordering tolerance

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-3dab28a133a08a18

## Log pattern

```text
failed to set lossmaxttl=%s s=%d
```

## Parameters

- Argument 1 — Value: Original configured maximum packet-reordering tolerance string, passed numerically without unit conversion.
- Argument 2 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set lossmaxttl=20 s=100
```

## Short description

Cannot set SRT packet-reordering tolerance.

## Trigger condition

The SRT library rejects the configured maximum packet-reordering tolerance.

## Explanation

Applying socket settings stops with failure. The logged value is the original text converted to an integer before it is passed to SRT.

## Possible causes

- The SRT library rejects the configured maximum packet-reordering tolerance.

## What to check

1. Check the configured maximum packet-reordering tolerance and library compatibility.
