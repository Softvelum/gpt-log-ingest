# Filter stream wildcard could not be resolved

Product: Nimble Streamer
Component: Video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-edf9f17596546932

## Log pattern

```text
failed to resolve wildcard filter_expression="%s" stream='%s'
```

## Parameters

- Argument 1 — Expression: Original video filter expression, text.
- Argument 2 — Main stream: Main stream name supplied to wildcard resolution, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to resolve wildcard filter_expression="drawtext=textfile='/tmp/{STREAM}.txt'" stream='camera'
```

## Short description

Filter stream wildcard could not be resolved.

## Trigger condition

A quoted textfile option contains {STREAM}, but the main stream name does not split into exactly an application and stream.

## Explanation

The original filter expression is retained and construction continues with its unresolved placeholder.

## Possible causes

- The supplied main stream name does not have the required two-part form.

## What to check

1. Check the main stream name and textfile placeholder expression.

## Recommended action

Use an application/stream name with exactly two parts or replace the placeholder with an explicit value.
