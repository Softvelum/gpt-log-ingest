# Geolocation lookup returned an error

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_d
Log level: debug
Documentation ID: log_d-b09740924002c7a7

## Log pattern

```text
MMDB_lookup_string ip='%s' gai_error=%d mmdb_error=%d
```

## Parameters

- Argument 1 — IP address: Address text submitted for lookup.
- Argument 2 — Address error: Integer address-resolution error; zero indicates no error in this part.
- Argument 3 — Database error: Integer database-library result; a non-success value indicates lookup failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
MMDB_lookup_string ip='invalid-address' gai_error=-2 mmdb_error=0
```

## Short description

Geolocation lookup returned an error.

## Trigger condition

Address lookup reports a nonzero address-resolution error or a database-library error.

## Explanation

Country lookup returns empty text, so callers cannot use this result as an identified country.

## Possible causes

- The address-resolution or database lookup step returned an error.

## What to check

1. Inspect the address and both result values.
