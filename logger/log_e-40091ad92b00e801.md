# NVIDIA decoded-frame context unlock failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-40091ad92b00e801

## Log pattern

```text
failed to unlock cuda ctx, res=%d
```

## Parameters

- Argument 1 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

Two occurrences are cleanup after a failed plane copy; one is the normal post-copy unlock.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to unlock cuda ctx, res=2
```

## Short description

NVIDIA decoded-frame context unlock failed.

## Trigger condition

Releasing the shared video-context lock after a frame copy returns a driver error.

## Explanation

The frame copy fails. This can follow an already failed luma/chroma copy or occur after both planes were copied successfully.

## Possible causes

- The driver cannot release the shared context lock.

## What to check

1. Check the CUDA status and any preceding plane-copy error.

## Recommended action

Restore a valid shared context and investigate repeated locking failures.
