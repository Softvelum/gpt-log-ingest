# VAAPI cannot write bitstream restriction metadata

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-639b4c08dfe48e61

## Log pattern

```text
bitstream restrictions not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
bitstream restrictions not supported
```

## Short description

VAAPI cannot write bitstream restriction metadata.

## Trigger condition

The H.264 sequence parameters mark bitstream restrictions as present.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested bitstream restriction metadata and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
