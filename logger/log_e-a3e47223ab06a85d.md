# Advertising playlist is in an unusable state

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a3e47223ab06a85d

## Log pattern

```text
failed to get playlist id=%s
```

## Parameters

- Argument 1 — Playlist ID: Text identifying the advertising playlist that was retrieved.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get playlist id=ad-playlist-01
```

## Short description

Advertising playlist is in an unusable state.

## Trigger condition

An existing advertising playlist is neither being initialized nor ready when a chunk request needs it.

## Explanation

The chunk request is rejected with HTTP 500.

## Possible causes

- An existing advertising playlist is neither being initialized nor ready when a chunk request needs it.

## What to check

1. Inspect earlier generation failures for this playlist; the chunk request needs a ready playlist or an active initialization.

## Recommended action

Inspect earlier generation failures for this playlist; the chunk request needs a ready playlist or an active initialization.
