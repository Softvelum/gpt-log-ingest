# H.264 headers could not be generated

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-4976e865b68eb092

## Log pattern

```text
failed to get sps/pps
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get sps/pps
```

## Short description

H.264 headers could not be generated.

## Trigger condition

x264 header generation returns zero or a negative result.

## Explanation

H.264 encoder initialization fails.

## Possible causes

- The encoder could not produce its initial parameter-set headers.

## What to check

1. Check the video format and selected x264 profile, preset, tuning, and codec options.

## Recommended action

Correct the rejected encoder configuration.
