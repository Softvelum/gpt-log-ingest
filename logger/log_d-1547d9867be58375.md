# Remote VOD source is not ready for transmuxing

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-1547d9867be58375

## Log pattern

```text
cache item='%s' state=%d is not ready for transmuxing session_state=%d
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.
- Argument 3 — Session state: Integer identifying the HTTP client session phase: 0 reading a request, 1 sending a response, 2 connecting to origin, 3 sending to origin, 4 reading origin headers, 5 reading an origin playlist, 6 reading origin media, 29 shutting down, or 30 finished; intermediate values identify pending asynchronous work.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item='/live/camera/segment1.ts' state=1 is not ready for transmuxing session_state=4
```

## Short description

Remote VOD source is not ready for transmuxing.

## Trigger condition

The remote source cache item already exists but is neither fragmented nor ready.

## Explanation

An observer is registered and the state is checked again; the request waits unless the source has become usable.

## Possible causes

- The remote source cache item already exists but is neither fragmented nor ready.

## What to check

1. If the wait persists, check the remote source download and cache initialization errors.

## Recommended action

If the wait persists, check the remote source download and cache initialization errors.
