# MP3 encoder could not be created

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-c06e21f1c195f88d

## Log pattern

```text
failed to init lame audio encoder
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init lame audio encoder
```

## Short description

MP3 encoder could not be created.

## Trigger condition

LAME encoder allocation returns no context in a build with LAME support.

## Explanation

The first-frame initialization fails and audio is not encoded.

## Possible causes

- LAME could not create its encoder context.

## What to check

1. Check whether runtime encoder initialization is available and inspect preceding library diagnostics.

## Recommended action

Resolve the encoder initialization failure.
