# Live video item could not be read

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-48ac4393b11a4c6d

## Log pattern

```text
failed to read video item [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

Shared by the live video decoder and compressed-video forwarding worker. Both reset slow readers and wait for a keyframe before this failure check.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read video item [live/camera]
```

## Short description

Live video item could not be read.

## Trigger condition

The live buffer read returns neither success nor wait-for-new-items, including after a slow-reader reset.

## Explanation

The current decoding or compressed-forwarding operation fails.

## Possible causes

- The input buffer cannot provide a usable item at the requested position.

## What to check

1. Check source availability, recent buffer resets, and preceding slow-reader diagnostics.

## Recommended action

Restore the live source and restart the dependent pipeline if needed.
