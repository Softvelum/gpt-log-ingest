# Assigned local control port could not be read

Product: Nimble Streamer
Component: Child process communication
Logging function: log_e
Log level: error
Documentation ID: log_e-c06d3db1154719bc

## Log pattern

```text
failed to get assigned ephemeral port for s=%d errno=%d '%s'
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

This pattern covers generic child listeners and WHIP/WHEP control listeners.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get assigned ephemeral port for s=12 errno=5 'operation failed'
```

## Short description

The local child or WebRTC control listener address could not be read.

## Trigger condition

A local listener was created and bound, but querying its assigned address and port fails.

## Explanation

Child listener setup reports failure. WHIP and WHEP control listener setup also closes the socket and returns failure before launching the associated process.

## Possible causes

- The operating system rejected the local socket address query.

## What to check

1. Check the socket descriptor and operating system error.

## Recommended action

Resolve the address-query error and retry child startup.
