# Local NDI timecode queue is full

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-2184a9d00790a1ac

## Log pattern

```text
failed to queue NDI timecode message for [%s]
```

## Parameters

- Argument 1 — Output: Local output stream or AJA writer name, text.

The queued message contains the requested system-clock timecode. The queue also rejects empty messages, but these call sites construct a populated message before submission.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to queue NDI timecode message for [camera]
```

## Short description

Local NDI timecode queue is full.

## Trigger condition

The accepted writer cannot append the NDI timecode message to its bounded outgoing message queue.

## Explanation

The message is not queued and this write operation returns failure.

## Possible causes

- The shared outgoing queue already holds 1024 messages because the helper process or socket consumer is not draining it fast enough.

## What to check

1. Check helper-process health, socket progress, and the rate of outgoing audio, video, and control messages.

## Recommended action

Restore consumer throughput or reduce output load and restart the affected writer.
