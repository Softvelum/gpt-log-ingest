# Delayed pull task settings were removed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_i
Log level: info
Documentation ID: log_i-9aece459464db018

## Log pattern

```text
live pull task for %s/%s deleted.pull settings removed
```

## Parameters

- Argument 1 — application: Application of the delayed pull task.
- Argument 2 — stream: Stream of the delayed pull task.

## Log examples

Illustrative examples; these are not captured server logs.

```text
live pull task for live/camera deleted.pull settings removed
```

## Short description

Delayed pull task settings were removed.

## Trigger condition

A task no longer has its associated delayed pull settings.

## Explanation

The old task is removed from all task indexes. A new matching request is attempted afterward and can succeed only if current settings provide a route.
