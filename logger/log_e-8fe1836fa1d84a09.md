# RTMP metadata object field cannot be decoded

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-8fe1836fa1d84a09

## Log pattern

```text
cannot process AMF object(%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process AMF object(live/camera)
```

## Short description

RTMP metadata object field cannot be decoded.

## Trigger condition

Reading the next field name in the metadata AMF object or ECMA array fails.

## Explanation

The failure is logged without immediately leaving the field loop. Subsequent field parsing determines where decoding stops; metadata already received has already been stored.

## Possible causes

- Reading the next field name in the metadata AMF object or ECMA array fails.

## What to check

1. Check object field boundaries and termination in the incoming metadata.

## Recommended action

Correct the malformed metadata object at the encoder.
