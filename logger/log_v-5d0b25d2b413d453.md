# No HTTP media route matches

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-5d0b25d2b413d453

## Log pattern

```text
no route for url '%s':'%s'
```

## Parameters

- Argument 1 — Request host: Text authority or Host value used for routing.
- Argument 2 — Request URL: Text request path and query being routed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no route for url 'media.example':'/live/camera'
```

## Short description

No HTTP media route matches.

## Trigger condition

HTTP media routing finds no route for the request host and URL.

## Explanation

HTTP 404 is prepared before playback starts.

## Possible causes

- HTTP media routing finds no route for the request host and URL.

## What to check

1. Check the public host and path against the configured media route and any alias.

## Recommended action

Check the public host and path against the configured media route and any alias.
