# Peer hostname resolution failed

Product: Nimble Streamer
Component: Host address resolution
Logging function: log_e
Log level: error
Documentation ID: log_e-28195e90a2a209ed

## Log pattern

```text
failed to resolve ip address from %s ret=%d err='%s'
```

## Parameters

- Argument 1 — Host: Requested hostname or address text.
- Argument 2 — Resolver result: Address-resolution return code, signed integer.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to resolve ip address from example.invalid ret=-2 err='operation failed'
```

## Short description

Peer hostname resolution failed.

## Trigger condition

IPv6 support is enabled, the supplied name is not an IP literal, name lookup is permitted, and address resolution fails.

## Explanation

Peer address preparation reports failure.

## Possible causes

- The system resolver rejected the hostname lookup.

## What to check

1. Check the name, resolver code, and resolver description.

## Recommended action

Correct the name or its resolution.
