# Management request needs more input

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_d
Log level: debug
Documentation ID: log_d-45807e102810f68c

## Log pattern

```text
request is not ready size=%u
```

## Parameters

- Argument 1 — buffered\_bytes: Current input-buffer usage in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
request is not ready size=128
```

## Short description

Management request needs more input.

## Trigger condition

HTTP parsing succeeds so far but the parser has not marked the request complete.

## Explanation

The connection remains in request reception and waits for more bytes; this is not itself a parse error.
