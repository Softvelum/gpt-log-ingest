# MP3 input sample rate was rejected

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-5ec20c138ed66b15

## Log pattern

```text
failed to set input sample_rate=%d, status=%d
```

## Parameters

- Argument 1 — Sample rate: Audio sample rate in samples per second, integer.
- Argument 2 — Status: LAME return status, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set input sample_rate=48000, status=-1
```

## Short description

MP3 input sample rate was rejected.

## Trigger condition

In a LAME-enabled build, applying input sample rate returns a nonzero status.

## Explanation

Encoder initialization stops and the audio-frame write reports failure.

## Possible causes

- LAME rejected input sample rate.

## What to check

1. Check the input sample rate and the returned LAME status.

## Recommended action

Correct the rejected MP3 encoder setting.
