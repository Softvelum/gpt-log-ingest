# SLDP cannot parse a SCTE-35 splice point

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-2b3476831cc75041

## Log pattern

```text
[SCTE35] failed to read splice point, s=%d ip='%s' stream='%s/%s'
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Client IP: Connected playback client address.
- Argument 3 — Application: Effective application name after alias mapping when present.
- Argument 4 — Stream: Playback URL stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] failed to read splice point, s=42 ip='192.0.2.30' stream='live/camera'
```

## Short description

SLDP cannot parse a SCTE-35 splice point.

## Trigger condition

A SCTE-35 media item fails splice-point decoding.

## Explanation

The metadata item is treated as handled and no advertisement is scheduled from it; playback continues.

## Possible causes

- A SCTE-35 media item fails splice-point decoding.

## What to check

1. Check the SCTE-35 section completeness and encoding from the source.

## Recommended action

Correct malformed splice metadata at the source.
