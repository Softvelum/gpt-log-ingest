# KLV metadata packet assigned a forwarding index

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-091b8753dfe8e195

## Log pattern

```text
updateAvailable klv metadata type implicitly set found pid=%d, stream=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.
- Argument 2 — metadata\_index: Assigned zero-based KLV metadata stream index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable klv metadata type implicitly set found pid=400, stream=0
```

## Short description

KLV metadata packet assigned a forwarding index.

## Trigger condition

KLV forwarding is enabled, a newly available KLV packet remains unmapped, and an unused metadata stream index exists.

## Explanation

The packet receives that index and is added to the requested input set. Assignment stops once the configured pool of metadata indexes is exhausted.
