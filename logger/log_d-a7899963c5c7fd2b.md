# Media mapping file opened for creation

Product: Nimble Streamer
Component: Media file access
Logging function: log_d
Log level: debug
Documentation ID: log_d-a7899963c5c7fd2b

## Log pattern

```text
created file fd=%d path='%s'
```

## Parameters

- Argument 1 — Descriptor: Open file descriptor.
- Argument 2 — File: Requested runtime data-file path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created file fd=42 path='/data/media/output.bin'
```

## Short description

Media mapping file opened for creation.

## Trigger condition

The non-Windows create-or-open operation returns a valid writable descriptor.

## Explanation

Truncating the file to its requested size and creating the mapping happen next, so the log does not confirm those later operations. The file may already have existed.

## Possible causes

- The non-Windows create-or-open operation returns a valid writable descriptor.

## What to check

1. Check subsequent truncation or mapping diagnostics.
