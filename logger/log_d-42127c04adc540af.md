# Scenario transcoder connection setup began

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_d
Log level: debug
Documentation ID: log_d-42127c04adc540af

## Log pattern

```text
connected scenario transcoder process, scenario=%s
```

## Parameters

- Argument 1 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connected scenario transcoder process, scenario=scenario1
```

## Short description

Scenario transcoder connection setup began.

## Trigger condition

An accepted child connection has supplied a known scenario identifier and is handed to that scenario controller.

## Explanation

The controller records the socket, processes already received messages, allocates its output buffer and enables input/output events. Those later steps can still fail.
