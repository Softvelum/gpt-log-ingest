# SRT pull event has no registered camera

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_d
Log level: debug
Documentation ID: log_d-8d4c1a718376a14f

## Log pattern

```text
invalid fd in selector: %d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid fd in selector: 101
```

## Short description

SRT pull event has no registered camera.

## Trigger condition

An event arrives for a socket absent from the pull-thread camera map.

## Explanation

The descriptor is removed from the SRT event poller.

## Possible causes

- An event arrives for a socket absent from the pull-thread camera map.

## What to check

1. Check whether the camera was removed or replaced shortly before the event.
