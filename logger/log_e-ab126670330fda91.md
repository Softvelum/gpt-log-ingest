# RTMP metadata command cannot be decoded

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-ab126670330fda91

## Log pattern

```text
was not able to process setDataFrame(%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
was not able to process setDataFrame(live/camera)
```

## Short description

RTMP metadata command cannot be decoded.

## Trigger condition

An AMF0 data message does not begin with a readable AMF string command.

## Explanation

The unrecognized data message is ignored. This branch reports success and does not close the connection.

## Possible causes

- An AMF0 data message does not begin with a readable AMF string command.

## What to check

1. Inspect the first AMF field and message length of the encoder metadata.

## Recommended action

Correct the metadata command encoding.
