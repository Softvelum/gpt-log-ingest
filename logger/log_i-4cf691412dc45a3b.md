# Panel synchronization thread stopped

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_i
Log level: info
Documentation ID: log_i-4cf691412dc45a3b

## Log pattern

```text
wmspanelSyncThread stopped
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
wmspanelSyncThread stopped
```

## Short description

Panel synchronization thread stopped.

## Trigger condition

Startup finds an empty panel identity or disabled synchronization, or the running synchronization loop reaches its exit path.

## Explanation

Stopping panel synchronization can disable statistics reporting or invalidate the server license.
