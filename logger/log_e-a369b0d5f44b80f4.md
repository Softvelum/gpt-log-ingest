# Authentication digest context allocation failed

Product: Nimble Streamer
Component: RTMP and HTTP authentication digests
Logging function: log_e
Log level: error
Documentation ID: log_e-a369b0d5f44b80f4

## Log pattern

```text
HMAC_CTX_new() failed
```

## Parameters

The same format applies to RTMP handshake SHA-256, S3 request SHA-1, and HTTP SHA-256 digest creation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
HMAC_CTX_new() failed
```

## Short description

Authentication digest context allocation failed.

## Trigger condition

In builds using the newer OpenSSL heap-allocated HMAC context API, creating that context returns no object.

## Explanation

RTMP handshake digest generation returns failure. HTTP S3 SHA-1 or SHA-256 signing helpers return empty text rather than a computed digest.

## Possible causes

- The cryptographic library could not allocate the digest context.

## What to check

1. Check cryptographic-library allocation failures and which handshake or signing operation requested the digest.

## Recommended action

Resolve the digest-context allocation failure.
