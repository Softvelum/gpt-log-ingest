# UDP sender TTL option fails

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-b09d680000f62771

## Log pattern

```text
set ttl failed.s=%d, ttl=%d, (errno=%d)
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — TTL: Requested IP hop limit.
- Argument 3 — Error: Operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set ttl failed.s=42, ttl=300, (errno=22)
```

## Short description

UDP sender TTL option fails.

## Trigger condition

Applying the unicast TTL or multicast TTL socket option fails.

## Explanation

Sender setup continues with the socket remaining at its prior/default option value.

## Possible causes

- Applying the unicast TTL or multicast TTL socket option fails.

## What to check

1. Check requested TTL, destination type, and socket error.

## Recommended action

Correct the TTL value or resolve the option failure.
