# NVIDIA decoded frame transfer failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-79157f773bb28fbe

## Log pattern

```text
failed to copy video frame w:%d h:%d for [%s]
```

## Parameters

- Argument 1 — Width: Display width used for decoded output, integer pixels.
- Argument 2 — Height: Display height used for decoded output, integer pixels.
- Argument 3 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to copy video frame w:1920 h:1080 for [live/camera]
```

## Short description

NVIDIA decoded frame transfer failed.

## Trigger condition

Copying a mapped NV12 frame into its host output frame returns failure.

## Explanation

The GPU mapping is released and frame-queue processing returns failure without writing this frame.

## Possible causes

- The shared-context lock/unlock or a luma/chroma GPU-to-host copy fails.

## What to check

1. Check the preceding lock or plane-copy diagnostic for the detailed driver status.

## Recommended action

Correct that underlying transfer failure.
