# DVR media file removal completed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_d
Log level: debug
Documentation ID: log_d-12a7b63b3ad83e28

## Log pattern

```text
dvr segment file='%s' removed
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

This message can also mean the file was already absent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dvr segment file='/data/dvr/live/camera/1700000000000.dat' removed
```

## Short description

DVR media file removal completed.

## Trigger condition

Filesystem removal succeeds or reports that the file is already absent without an error.

## Explanation

The file-removal operation returns success.

## Possible causes

- Filesystem removal succeeds or reports that the file is already absent without an error.
