# H.264 profile was rejected

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e9c840056dd66720

## Log pattern

```text
failed to set profile=%s
```

## Parameters

- Argument 1 — Profile: Requested H.264 profile, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set profile=baseline
```

## Short description

H.264 profile was rejected.

## Trigger condition

Applying a nonempty requested H.264 profile returns a nonzero result.

## Explanation

H.264 encoder initialization fails.

## Possible causes

- The requested profile is incompatible or unrecognized.

## What to check

1. Check the video format and selected x264 profile, preset, tuning, and codec options.

## Recommended action

Correct the rejected encoder configuration.
