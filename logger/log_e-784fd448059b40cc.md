# IPv6 listener address could not be resolved

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-784fd448059b40cc

## Log pattern

```text
getaddrinfo failed for ip='%s'
```

## Parameters

- Argument 1 — Host: Requested host or address text.

Used by both generic IPv6 listener creation and main server listener creation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
getaddrinfo failed for ip='192.0.2.10'
```

## Short description

IPv6 listener address could not be resolved.

## Trigger condition

Resolving a specific IPv6 listener address fails.

## Explanation

The generic listener helper closes the new socket and returns failure. Main server listener setup exits the process with failure.

## Possible causes

- The supplied IPv6 listener address could not be resolved.

## What to check

1. Check the requested listener address.

## Recommended action

Correct the listener address or its resolution.
