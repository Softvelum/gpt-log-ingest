# Session begins waiting for advertising repackaging

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-09d80c771bb4d3b6

## Log pattern

```text
[WrkT::AddAdsTmxRO] request_id='%d' session=%p
```

## Parameters

- Argument 1 — Request identifier: Unsigned 32-bit advertising repackaging request identifier displayed with a signed conversion.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

The request identifier is unsigned; values outside the signed range may appear negative.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::AddAdsTmxRO] request_id='42' session=0x1000
```

## Short description

Session begins waiting for advertising repackaging.

## Trigger condition

A session asks to observe completion of an advertising repackaging request.

## Explanation

The request is inserted into the waiting map and gets the worker as observer only if insertion succeeds.
