# Cannot accumulate Ogg FLAC headers

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-23c176e703191af8

## Log pattern

```text
icecast stream cannot write FLAC header %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream cannot write FLAC header http://radio.example.net/live
```

## Short description

Cannot accumulate Ogg FLAC headers.

## Trigger condition

Adding a pre-audio Ogg frame to the saved FLAC header fails.

## Explanation

Ogg frame processing fails and the session is shut down by the caller.

## Possible causes

- Adding a pre-audio Ogg frame to the saved FLAC header fails.

## What to check

1. Check header sizes and buffer allocation.
