# Cache cancellation rejected

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-957ac322188cb89f

## Log pattern

```text
CacheItem::SetCanceled failed for item key='%s' state=%d
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — state: Numeric cache state: 0 empty, 1 downloading, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CacheItem::SetCanceled failed for item key='movie' state=3
```

## Short description

Cache cancellation rejected.

## Trigger condition

Cancellation is requested for an item that is neither empty nor downloading.

## Explanation

The cache throws a state error before marking the item for removal.

## Possible causes

- An internal cache state transition was requested at an invalid time.

## What to check

1. Compare nearby messages for the same cache key and its state changes.

## Recommended action

Use the surrounding cache lifecycle messages to identify the conflicting operation.
