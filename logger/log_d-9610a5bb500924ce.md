# NDI audio waits for a video timecode reference

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-9610a5bb500924ce

## Log pattern

```text
skip audio frame till first video frame with sei timecode, ndi_name="%s"
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip audio frame till first video frame with sei timecode, ndi_name="HOST (Output)"
```

## Short description

NDI audio waits for a video timecode reference.

## Trigger condition

SEI-timecode output receives audio before both a valid SEI system-time reference and a corresponding video timestamp are available.

## Explanation

The frame is skipped and processing reports success so later frames can establish or use the reference.

## Possible causes

- SEI-timecode output receives audio before both a valid SEI system-time reference and a corresponding video timestamp are available.

## What to check

1. Check that incoming video carries a usable SEI timecode and establishes its timestamp.

## Recommended action

Provide the video timecode reference before expecting scheduled audio output.
