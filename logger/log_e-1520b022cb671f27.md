# Initial NDI no-frame notification could not be sent

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-1520b022cb671f27

## Log pattern

```text
failed to write initial ndi none frame, name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write initial ndi none frame, name=Camera
```

## Short description

Initial NDI no-frame notification could not be sent.

## Trigger condition

NDI receiver initialization cannot send its initial no-frame message to the parent process.

## Explanation

Initialization fails before creating the discovery finder. This is an internal delivery failure rather than proof that an NDI source is missing.

## Possible causes

- NDI receiver initialization cannot send its initial no-frame message to the parent process.

## What to check

1. Check the parent-process connection used for NDI frame delivery.
