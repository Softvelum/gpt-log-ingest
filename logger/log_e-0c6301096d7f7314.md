# Scenario connection attachment failed

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-0c6301096d7f7314

## Log pattern

```text
failed to connect remote transcoder sock=%d scenario=%s
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect remote transcoder sock=12 scenario=scenario1
```

## Short description

Scenario connection attachment failed.

## Trigger condition

A known scenario cannot process buffered messages or enable socket events while attaching the child connection.

## Explanation

The accepted socket entry and scenario controller are removed; audio and video synchronization is invalidated for recreation.

## Possible causes

- An already received child message is invalid or rejected, or updating event monitoring fails.

## What to check

1. Check preceding codec/message and event-monitor errors for this socket and scenario.

## Recommended action

Correct the protocol or event-monitor failure and let the scenario restart.
