# Stream checks exceeded the final cleanup deadline

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-282057c0d1958ecf

## Log pattern

```text
checker was not able to process all tasks even in wipe interval
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Stream checks exceeded the final cleanup deadline.

## Trigger condition

Tasks remain after the final batch deadline, or the wall clock moves before the batch start.

## Explanation

The checker records current results, removes remaining sockets, deletes tasks, and clears the batch. Deadlines are 240 seconds for regular checks and 60 seconds for immediate checks.

## Possible causes

- Tasks did not complete cleanup before the deadline, or the wall clock moved backward.

## What to check

1. Check earlier timeout, socket, and task result messages.

## Recommended action

Investigate slow or stuck checks and clock changes.
