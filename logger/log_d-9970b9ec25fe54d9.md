# Scenario stream-override settings received

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-9970b9ec25fe54d9

## Log pattern

```text
sync_settings: %s
```

## Parameters

- Argument 1 — Settings payload: Complete received settings text, before JSON parsing.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync_settings: {}
```

## Short description

Scenario stream-override settings received.

## Trigger condition

The scenario encoder receives a stream-override settings payload.

## Explanation

The payload is logged before JSON parsing. Valid imported settings are applied; this message alone does not establish valid JSON or successful settings import.

## Possible causes

- A settings synchronization message arrives.

## What to check

1. Check the supplied stream-override settings if the expected override is not applied.
