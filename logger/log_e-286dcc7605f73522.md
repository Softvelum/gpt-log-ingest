# Playlist H.265 configuration was rejected

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-286dcc7605f73522

## Log pattern

```text
ServerBlockProcessor: failed to set hevc video header for vod file url=[%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: failed to set hevc video header for vod file url=[/media/program.mp4]
```

## Short description

Playlist H.265 configuration was rejected.

## Trigger condition

Parsed H.265 parameter sets cannot initialize the output stream.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- Parsed H.265 parameter sets cannot initialize the output stream.

## What to check

1. Check the source H.265 video, sequence, and picture parameter sets.

## Recommended action

Check the source H.265 video, sequence, and picture parameter sets.
