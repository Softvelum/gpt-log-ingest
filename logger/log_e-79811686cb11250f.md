# Teletext decoder initialization failed

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-79811686cb11250f

## Log pattern

```text
failed to init DVB Teletext decoder for '%s/%s'
```

## Parameters

- Argument 1 — Application: Stream application name.
- Argument 2 — Stream: Stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init DVB Teletext decoder for 'live/news'
```

## Short description

Teletext decoder initialization failed.

## Trigger condition

Lazy teletext decoder initialization fails while decoding a selected subtitle page.

## Explanation

The current teletext decode returns failure. Initialization includes decoder discovery, allocation, setting text/page/region options, and opening the decoder.

## Possible causes

- Lazy teletext decoder initialization fails while decoding a selected subtitle page.

## What to check

1. Check earlier decoder availability diagnostics and teletext page settings.
