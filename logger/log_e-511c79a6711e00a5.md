# VP9 live-stream codec setup failed

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error

## Log pattern

```text
vp9: unable to set codec params
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

VP9 live-stream codec setup failed.

## Trigger condition

The VP9 configuration operation returns failure because the attached live stream is already ended.

## Explanation

RTSP codec setup fails before selecting VP9 as the RTP stream type.

## Possible causes

- The VP9 configuration operation returns failure because the attached live stream is already ended.

## What to check

1. Check whether the live stream ended during RTSP codec initialization.
