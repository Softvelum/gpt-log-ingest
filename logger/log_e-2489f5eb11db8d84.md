# Scenario encoder missed three heartbeat checks

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-2489f5eb11db8d84

## Log pattern

```text
encoder for stream [%s/%s] hangs and scenario will be restarted
```

## Parameters

- Argument 1 — Application: Live-stream application name.
- Argument 2 — Stream: Live-stream name within its application.

## Log examples

Illustrative examples; these are not captured server logs.

```text
encoder for stream [live/camera] hangs and scenario will be restarted
```

## Short description

Scenario encoder missed three heartbeat checks.

## Trigger condition

A non-device stream has no encoder heartbeat for three consecutive inactivity checks.

## Explanation

The inactivity check requests scenario termination; the main loop closes its connection and stops encoding so the supervising side can restart it. NDI, OMT, and SDI signaling streams are excluded from this check. The main loop checks approximately every two seconds.

## Possible causes

- A non-device stream has no encoder heartbeat for three consecutive inactivity checks.

## What to check

1. Check whether the encoder has stopped producing heartbeat updates and inspect preceding encoding errors.
