# RTSP SDP could not obtain AAC configuration

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-829699629398f8f2

## Log pattern

```text
failed to get aac params, client: %d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get aac params, client: 25
```

## Short description

RTSP SDP could not obtain AAC configuration.

## Trigger condition

Building an SDP description fails while extracting AAC configuration, sample rate, and channel count.

## Explanation

SDP construction returns failure. The extraction checks for a complete sequence header and a usable sample-frequency index.

## Possible causes

- Building an SDP description fails while extracting AAC configuration, sample rate, and channel count.

## What to check

1. Check the stored AAC sequence header and its sampling-frequency index.
