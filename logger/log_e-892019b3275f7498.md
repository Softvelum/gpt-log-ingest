# Cannot assemble Icecast audio frame

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-892019b3275f7498

## Log pattern

```text
icecast stream aac.buffer not enough %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream aac.buffer not enough http://radio.example.net/live
```

## Short description

Cannot assemble Icecast audio frame.

## Trigger condition

Writing a saved header fragment or further audio bytes into the frame buffer fails.

## Explanation

The ingest session is shut down. Although the text names AAC, the shared assembly path also handles MP3.

## Possible causes

- Writing a saved header fragment or further audio bytes into the frame buffer fails.

## What to check

1. Check audio frame sizes and buffer allocation.
