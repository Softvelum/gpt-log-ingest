# Waiting for child shutdown failed

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-1318af7d497fe353

## Log pattern

```text
waitpid failed for pid=%d errno=%d
```

## Parameters

- Argument 1 — Process: Child process identifier, integer.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waitpid failed for pid=1234 errno=5
```

## Short description

Waiting for child shutdown failed.

## Trigger condition

A nonblocking child-status wait returns -1 during the timed shutdown loop.

## Explanation

The polling loop ends and, since successful stopping was not observed, the helper proceeds to its forced-kill path.

## Possible causes

- The operating system rejected the child wait.

## What to check

1. Check the child identifier and wait error.

## Recommended action

Investigate child ownership or wait-state errors.
