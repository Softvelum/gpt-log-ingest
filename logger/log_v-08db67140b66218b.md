# HTTP/2 concurrent stream limit reached

Product: Nimble Streamer
Component: HTTP/2 connection
Logging function: log_v
Log level: verbose
Documentation ID: log_v-08db67140b66218b

## Log pattern

```text
max stream count reached for s=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
max stream count reached for s=12
```

## Short description

HTTP/2 concurrent stream limit reached.

## Trigger condition

A new complete request header arrives when active replies, pending resets, and pending POST requests together meet or exceed the connection’s concurrent-stream limit.

## Explanation

The frame is reset locally and a protocol-error GOAWAY is sent or queued, ending normal connection processing.

## Possible causes

- The client exceeds the tracked per-connection request capacity; pending resets and POST bodies also count.

## What to check

1. Check simultaneous requests, unfinished POST bodies, pending resets, and the negotiated limit.

## Recommended action

Reduce client concurrency or clear stalled requests before reconnecting.
