# DVR video blackout starts

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-48fb194fd22f055b

## Log pattern

```text
blackout video segment utc_time=%lld start_time=%lld duration=%lld period=%d
```

## Parameters

- Argument 1 — UTC time: 64-bit segment UTC time in milliseconds since the Unix epoch.
- Argument 2 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 3 — Media duration: 64-bit duration in the segment track timescale.
- Argument 4 — Period: Unsigned recording period identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
blackout video segment utc_time=1700000000000 start_time=90000 duration=540000 period=1
```

## Short description

DVR video blackout starts.

## Trigger condition

A supported AVC or HEVC segment has a usable black-frame generator.

## Explanation

The original segment is loaded and replacement samples are prepared; success is not yet established.

## Possible causes

- A supported AVC or HEVC segment has a usable black-frame generator.
