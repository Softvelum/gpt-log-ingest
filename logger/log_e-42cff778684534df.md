# Library log level setting is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-42cff778684534df

## Log pattern

```text
invalid %s parameter value: %s
```

## Parameters

- Argument 1 — Setting: Configuration setting name, text.
- Argument 2 — Value: Original log-level text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid ffmpeg_log_level parameter value: trace
```

## Short description

Library log level setting is invalid.

## Trigger condition

The FFmpeg log level, or the Whisper log level in a Whisper-enabled build, is not one of none, error, info, verbose, or debug.

## Explanation

Configuration processing fails and loading stops at the affected line.

## Possible causes

- An unrecognized log-level word was supplied.

## What to check

1. Check the setting name and exact lowercase log-level value.

## Recommended action

Use none, error, info, verbose, or debug.
