# Quick Sync VP9 decoder plugin could not load

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-f0cd5979228e12da

## Log pattern

```text
failed to load quicksync vp9 decoder plugin, error=%d

```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load quicksync vp9 decoder plugin, error=-3

```

## Short description

Quick Sync VP9 decoder plugin could not load.

## Trigger condition

The legacy media runtime returns a nonzero status while loading the hardware VP9 decoder plugin.

## Explanation

Decoder setup fails before the media API version is checked.

## Possible causes

- The hardware VP9 plugin cannot be loaded for the current runtime or device.

## What to check

1. Check availability and compatibility of the VP9 decoder plugin and Intel media runtime.

## Recommended action

Restore a compatible decoder plugin or select another supported decoder.
