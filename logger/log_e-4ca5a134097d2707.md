# AJA capture host buffers failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-4ca5a134097d2707

## Log pattern

```text
init failed device=%s/%d reason='host buffer setup failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
init failed device=0/0 reason='host buffer setup failed'
```

## Short description

AJA capture host buffers failed.

## Trigger condition

Receiver initialization fails because allocation, circular-buffer registration, or locking of host frame buffers fails.

## Explanation

Capture initialization stops before input signal routing.

## Possible causes

- Receiver initialization fails because allocation, circular-buffer registration, or locking of host frame buffers fails.

## What to check

1. Check the preceding device or capture host buffers error details.
