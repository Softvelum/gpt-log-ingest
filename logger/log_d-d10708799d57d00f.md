# Client response body write progress

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-d10708799d57d00f

## Log pattern

```text
%llu of %llu B(b) to cli s=%d
```

## Parameters

- Argument 1 — Sent body bytes: Unsigned 64-bit body bytes sent so far.
- Argument 2 — Body bytes: Unsigned 64-bit size of this response body or current live chunk.
- Argument 3 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
8192 of 65536 B(b) to cli s=18
```

## Short description

Client response body write progress.

## Trigger condition

A positive response-body write succeeds without a fragmented-response remainder.

## Explanation

Body and access statistics advance; a completed response continues live streaming, waits for a new request, or closes according to the session.

## Possible causes

- A positive response-body write succeeds without a fragmented-response remainder.

1. Not applicable; this is normal diagnostic progress. Use the socket identifier to follow the same request if troubleshooting.
