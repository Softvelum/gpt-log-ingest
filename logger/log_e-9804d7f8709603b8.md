# Quick Sync encoder initialization failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-9804d7f8709603b8

## Log pattern

```text
%p failed to init quick sync encoder, error=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to init quick sync encoder, error=-3
```

## Short description

Quick Sync encoder initialization failed.

## Trigger condition

Encoder initialization returns a negative status.

## Explanation

Initialization stops before output parameter sets and buffers are obtained.

## Possible causes

- The media runtime rejects the selected encoding parameters or cannot initialize the device.

## What to check

1. Check the status and any preceding parameter-query message.

## Recommended action

Correct unsupported encoding settings or the media device failure and restart encoding.
