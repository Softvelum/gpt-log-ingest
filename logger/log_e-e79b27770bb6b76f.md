# Video filter graph allocation failed

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-e79b27770bb6b76f

## Log pattern

```text
failed to create filter graph: %s, out of memory
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create filter graph: [in]null[out], out of memory
```

## Short description

Video filter graph allocation failed.

## Trigger condition

Allocating the video filter graph returns no graph.

## Explanation

Video filter initialization fails.

## Possible causes

- Video filter graph allocation could not obtain storage.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
