# RTSP publishing worker stopped

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-68c5344fa1b09bf0

## Log pattern

```text
RtspPublisherThread stopped
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
RtspPublisherThread stopped
```

## Short description

RTSP publishing worker stopped.

## Trigger condition

The RTSP publishing worker has left its event loop after an exit request.

## Explanation

The worker has cleaned up its active publisher connections or server listeners and returns from its processing routine.

## Possible causes

- The worker received an exit request.
