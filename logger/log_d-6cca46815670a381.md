# Cached response preparation started

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-6cca46815670a381

## Log pattern

```text
sending cached key='%s' sz=%u st=%u
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Stored bytes: Unsigned 64-bit amount of cached data in bytes.
- Argument 3 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.

The cache size is unsigned 64-bit data supplied to %u, so the printed size is unreliable.

## Log examples

The cache size is unsigned 64-bit data supplied to %u, so the printed size is unreliable.

## Short description

Cached response preparation started.

## Trigger condition

Cached-item sending has a valid retained item and begins preparing its response.

## Explanation

The key and state are logged before range and conditional checks; the message alone does not establish that the response was sent.

## Possible causes

- Cached-item sending has a valid retained item and begins preparing its response.
