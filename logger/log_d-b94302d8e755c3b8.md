# Existing shared origin session reused

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_d
Log level: debug
Documentation ID: log_d-b94302d8e755c3b8

## Log pattern

```text
reusing shared session=%lu shared_url='%s'
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.
- Argument 2 — shared URL: Application-level URL used to combine origin traffic.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reusing shared session=42 shared_url='/live/http_origin_common'
```

## Short description

Existing shared origin session reused.

## Trigger condition

Registration finds a shared session with the same application-level shared URL.

## Explanation

The existing identifier is returned instead of creating another session. Access checking has already succeeded before the shared-session search.
