# Origin parameters stored for a session

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_v
Log level: verbose
Documentation ID: log_v-766c3b4942a248e3

## Log pattern

```text
set origin params for session=%lu params='%s'
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.
- Argument 2 — parameters: Origin request parameters stored for the session.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set origin params for session=42 params='token=example'
```

## Short description

Origin parameters stored for a session.

## Trigger condition

A known session has no origin parameters yet, or updating them is enabled.

## Explanation

The supplied origin parameters replace the stored value. Manifest parameters are updated separately regardless of whether this message appears.
