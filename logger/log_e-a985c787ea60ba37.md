# Speechmatics transcription is missing its API URL

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-a985c787ea60ba37

## Log pattern

```text
speechmatics url is empty for [%s/%s]
```

## Parameters

- Argument 1 — application: Application name.
- Argument 2 — stream: Stream name within the application.

## Log examples

Illustrative examples; these are not captured server logs.

```text
speechmatics url is empty for [live/camera]
```

## Short description

Speechmatics transcription is missing its API URL.

## Trigger condition

The Speechmatics provider was selected but its API URL is empty after loading stream parameters.

## Explanation

Transcriber initialization returns without assigning the provider request queue. This diagnostic is available only in builds with the corresponding transcription support; live stream registration still continues.

## Possible causes

- The effective Speechmatics API URL is empty.

## What to check

1. Check the provider settings applied to this application and stream.

## Recommended action

Supply the required API URL.
