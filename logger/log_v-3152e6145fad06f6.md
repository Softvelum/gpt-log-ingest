# DVR archive load was aborted

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_v
Log level: verbose
Documentation ID: log_v-3152e6145fad06f6

## Log pattern

```text
aborted loading dvr archive='%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
aborted loading dvr archive='live/camera'
```

## Short description

DVR archive load was aborted.

## Trigger condition

The coordinating worker requests exit after a time bucket was processed.

## Explanation

The archive is marked not ready, loaded metadata is cleared, and loading returns failure.

## Possible causes

- The coordinating worker requests exit after a time bucket was processed.

## What to check

1. Check shutdown activity if the load was expected to finish.

## Recommended action

Check shutdown activity if the load was expected to finish.
