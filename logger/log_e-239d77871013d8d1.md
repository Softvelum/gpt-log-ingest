# WebVTT synchronization duration is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-239d77871013d8d1

## Log pattern

```text
invalid parameter value: %s (should be >=0 && <= 30000)
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0 (should be >=0 && <= 30000)
```

## Short description

WebVTT synchronization duration is invalid.

## Trigger condition

While reading configuration, the WebVTT synchronization queue duration is outside 0 through 30000 milliseconds.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 0 through 30000 milliseconds.

## Recommended action

Correct the value to 0 through 30000 milliseconds and reload configuration.
