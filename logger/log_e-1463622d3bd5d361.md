# H.264 packetization mode is outside modes zero and one

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-1463622d3bd5d361

## Log pattern

```text
H264: unsupported packetization-mode=%d
```

## Parameters

- Argument 1 — Packetization mode: Integer parsed from the SDP packetization-mode field; it is dimensionless.

## Log examples

Illustrative examples; these are not captured server logs.

```text
H264: unsupported packetization-mode=2
```

## Short description

H.264 packetization mode is outside modes zero and one.

## Trigger condition

The SDP packetization mode parses to a value other than zero or one.

## Explanation

Mode two is rejected because interleaved packetization is unsupported. Other out-of-range values produce this message but setup continues using the default handling.

## Possible causes

- The SDP packetization mode parses to a value other than zero or one.

## What to check

1. Check the H.264 packetization mode advertised in SDP.

## Recommended action

Use packetization mode zero or one.
