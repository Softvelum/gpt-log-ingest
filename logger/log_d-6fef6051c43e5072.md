# Live-stream notification removal processed

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-6fef6051c43e5072

## Log pattern

```text
WorkerThread::RemoveStreamObserver stream='%s' removed session=%p
```

## Parameters

- Argument 1 — Stream name: Text identifying the observed resource.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WorkerThread::RemoveStreamObserver stream='example-item' removed session=0x1000
```

## Short description

Live-stream notification removal processed.

## Trigger condition

A stream subscription set exists and removal of the requested session has been attempted.

## Explanation

If no sessions remain, upstream MPEG-TS or Icecast observation and the empty set are removed.
