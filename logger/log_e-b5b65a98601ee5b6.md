# DVR database JSON could not be parsed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-b5b65a98601ee5b6

## Log pattern

```text
Failed to parse json from file='%s'
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Failed to parse json from file='/data/dvr/live/camera/nimble-dvr-segments.db'
```

## Short description

DVR database JSON could not be parsed.

## Trigger condition

The collected database records cannot be parsed as a JSON array.

## Explanation

Whole-database loading fails and the caller attempts individual-record recovery.

## Possible causes

- The collected database records cannot be parsed as a JSON array.

## What to check

1. Check malformed database entries and the following recovery count.

## Recommended action

Check malformed database entries and the following recovery count.
