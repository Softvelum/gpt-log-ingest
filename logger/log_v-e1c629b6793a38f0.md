# GeoIP archive response size recorded

Product: Nimble Streamer
Component: GeoIP database updates
Logging function: log_v
Log level: verbose
Documentation ID: log_v-e1c629b6793a38f0

## Log pattern

```text
response length=%u
```

## Parameters

- Argument 1 — bytes: Collected response body size in bytes.

A platform-sized string length is passed to a 32-bit unsigned conversion.

## Log examples

No portable example is provided for the response-size argument mismatch.

## Short description

GeoIP archive response size recorded.

## Trigger condition

The archive exchange returns and the collected response length is logged.

## Explanation

A nonempty response proceeds to temporary storage and extraction regardless of the returned exchange status; the length does not confirm a valid archive.
