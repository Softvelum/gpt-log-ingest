# PallyCon protection selected

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-9761d8f9434c61ec

## Log pattern

```text
[drm] app='%s' stream='%s' is protected with PallyCon
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] app='live' stream='camera' is protected with PallyCon
```

## Short description

PallyCon protection selected.

## Trigger condition

The application uses PallyCon and stream registration includes MPEG-DASH or fragmented-MP4 HLS.

## Explanation

Key registration continues; this message alone does not confirm that usable keys have arrived.

## Possible causes

- The application uses PallyCon and stream registration includes MPEG-DASH or fragmented-MP4 HLS.
