# Whole-file memory mapping failed

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-934b996c2f37e22a

## Log pattern

```text
open_and_map_read_only_file mmap() failed errno=%d fd=%d mmap_prot=%d st_size=%lld
```

## Parameters

- Argument 1 — Error: Operating-system error number.
- Argument 2 — Descriptor: Open file descriptor.
- Argument 3 — Protection: Numeric memory-protection mask.
- Argument 4 — Length: Complete file size in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
open_and_map_read_only_file mmap() failed errno=22 fd=42 mmap_prot=1 st_size=0
```

## Short description

Whole-file memory mapping failed.

## Trigger condition

The operating system rejects mapping the complete file with the requested read/write protection.

## Explanation

The descriptor is closed and no mapping is returned.

## Possible causes

- The operating system rejects mapping the complete file with the requested read/write protection.

## What to check

1. Check the error, file length, protection flags, and available address space.
