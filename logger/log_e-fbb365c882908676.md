# Live video packet decoding failed

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-fbb365c882908676

## Log pattern

```text
failed to decode packet from [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

Five occurrences cover these codecs after their packet framing has been removed. HEVC timecodes may already have been forwarded before decoding fails.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode packet from [live/camera]
```

## Short description

Live video packet decoding failed.

## Trigger condition

The selected decoder returns failure while processing a live H.264, HEVC, VP8, VP9, or AV1 payload.

## Explanation

The video item fails and the decoder worker leaves its processing loop.

## Possible causes

- The packet or codec configuration is rejected, decoder setup or allocation fails, or decoded output delivery fails.

## What to check

1. Check the preceding codec, hardware, and output-queue diagnostics and the input configuration.

## Recommended action

Correct the specific decoder or downstream failure and restart the affected pipeline.
