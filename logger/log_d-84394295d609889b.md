# HTTP/3 transport initialization failed

Product: Nimble Streamer
Component: HTTP/3 delivery
Logging function: log_d

Illustrative examples; these are not captured server logs.

## Short description

HTTP/3 transport initialization failed.

## Trigger condition

Creating a QUIC engine for a configured listening socket returns no engine during HTTP/3 worker initialization.

## Explanation

The temporary engine holder is destroyed and initialization returns failure. This path is available only when HTTP/3 support is included.

## Possible causes

- The transport engine could not be created.

## What to check

1. Check the preceding transport-engine initialization messages.
