# Advertising content definition added

Product: Nimble Streamer
Component: Advertising
Logging function: log_i
Log level: info
Documentation ID: log_i-e4354657483268b0

## Log pattern

```text
added advertising content id='%s'
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.

## Log examples

Illustrative examples; these are not captured server logs.

```text
added advertising content id='ad-01'
```

## Short description

Advertising content definition added.

## Trigger condition

Synchronization provides a content identifier absent from the registry.

## Explanation

The content is inserted and loading is attempted; this message alone does not establish that loading succeeded.

## Possible causes

- Synchronization provides a content identifier absent from the registry.

## What to check

1. Check the subsequent content-loading message when verifying media readiness.

## Recommended action

Check the subsequent content-loading message when verifying media readiness.
