# Empty cache object allocation failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-0be726c7dc2d3518

## Log pattern

```text
failed to allocate cache item (key='%s')
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to allocate cache item (key='movie')
```

## Short description

Empty cache object allocation failed.

## Trigger condition

Creating the object for a new cache reservation returns no object.

## Explanation

Reservation fails before the key is inserted in the cache.

## Possible causes

- The process could not allocate the cache item object.

## What to check

1. Check memory availability and the preceding reservation activity.

## Recommended action

Address the allocation failure before retrying.
