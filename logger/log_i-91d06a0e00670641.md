# Shared hardware-device context created

Product: Nimble Streamer
Component: Shared hardware devices
Logging function: log_i
Log level: info
Documentation ID: log_i-91d06a0e00670641

## Log pattern

```text
created shared hw device ctx=%p type=%d dev=%s
```

## Parameters

- Argument 1 — Context: FFmpeg hardware device reference address, pointer printed in hexadecimal.
- Argument 2 — Device type: FFmpeg hardware-device type identifier, integer; no unit.
- Argument 3 — Device: Hardware device name or device node, text; VAAPI with no explicit name first attempts Intel render-device discovery.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created shared hw device ctx=0x12340000 type=3 dev=/dev/dri/renderD128
```

## Short description

Shared hardware-device context created.

## Trigger condition

FFmpeg successfully creates a new context for the device type/name.

## Explanation

The context is cached and a separate reference is returned to the caller.
