# Playlist block GET request could not be queued

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-38086e099574901f

## Log pattern

```text
failed to request server playlist blocks url='%s'
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to request server playlist blocks url='https://api.example/playlist'
```

## Short description

Playlist block GET request could not be queued.

## Trigger condition

Submitting an HTTP GET for external block definitions fails.

## Explanation

The URL is not added to the set of outstanding block requests.

## Possible causes

- Submitting an HTTP GET for external block definitions fails.

## What to check

1. Check the block destination and the request-processing service.

## Recommended action

Check the block destination and the request-processing service.
