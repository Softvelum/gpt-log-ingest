# CloudDRM SPEKE endpoint is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-23e6f384abd05507

## Log pattern

```text
Key server SPEKE 2 must be provided for Cloud DRM (keyserver)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Key server SPEKE 2 must be provided for Cloud DRM (keyserver)
```

## Short description

CloudDRM SPEKE endpoint is missing.

## Trigger condition

The CloudDRM key-server URL is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The CloudDRM key-server URL is empty.

## What to check

1. Provide the CloudDRM SPEKE 2 endpoint.

## Recommended action

Provide the CloudDRM SPEKE 2 endpoint.
