# Cache update state is incompatible with the request

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-7ab6dc89041b5162

## Log pattern

```text
OnCacheItemUpdated invalid item key='%s' state=%d
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
OnCacheItemUpdated invalid item key='/live/camera/segment1.ts' state=4
```

## Short description

Cache update state is incompatible with the request.

## Trigger condition

A cache update has an unexpected state for HTTP/1 cached-header or body waiting, or an unrecognized state reaches the HTTP/2 or HTTP/3 update dispatcher.

## Explanation

HTTP/1 cached-header waiting prepares its default shutdown response, while cached-body waiting prepares HTTP 500. The HTTP/2 or HTTP/3 branch shuts down the connection.

## Possible causes

- A cache update has an unexpected state for HTTP/1 cached-header or body waiting, or an unrecognized state reaches the HTTP/2 or HTTP/3 update dispatcher.

## What to check

1. Correlate cache cancellation and observer events with the waiting request phase; this indicates an incompatible internal cache transition.

## Recommended action

Correlate cache cancellation and observer events with the waiting request phase; this indicates an incompatible internal cache transition.
