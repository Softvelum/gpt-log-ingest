# Audio filter input write failed

Product: Nimble Streamer
Component: Audio filtering worker
Logging function: log_e
Log level: error
Documentation ID: log_e-1345d03f0e6be3c5

## Log pattern

```text
failed to filter audio id=%s, stream=%s
```

## Parameters

- Argument 1 — Filter identifier: Configured filter identifier, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to filter audio id=audio-main, stream=live/camera
```

## Short description

Audio filter input write failed.

## Trigger condition

Submitting the current frame to its audio filter input returns failure.

## Explanation

The audio filter worker exits its processing loop.

## Possible causes

- Filter input initialization, filtering, or downstream frame writing failed.

## What to check

1. Check preceding filter-specific errors for this filter and stream.

## Recommended action

Resolve the reported filter or output writer failure.
