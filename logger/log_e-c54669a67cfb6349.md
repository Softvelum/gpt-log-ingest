# Encoder pixel converter creation failed

Product: Nimble Streamer
Component: Encoder pixel-format selection
Logging function: log_e
Log level: error
Documentation ID: log_e-c54669a67cfb6349

## Log pattern

```text
failed to create frame converter: %d->%d for [%s]
```

## Parameters

- Argument 1 — Input format: FFmpeg input pixel-format identifier, integer.
- Argument 2 — Output format: Chosen FFmpeg destination pixel-format identifier, integer.
- Argument 3 — Stream: Output stream name, text.

Both FFmpeg and native NVIDIA encoder initialization can emit this message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create frame converter: 0->23 for [live/camera]
```

## Short description

Encoder pixel converter creation failed.

## Trigger condition

A suitable destination pixel format is selected, but creating the same-size software converter returns no conversion context.

## Explanation

Encoder initialization fails.

## Possible causes

- FFmpeg cannot construct conversion for the supplied dimensions and source/destination formats.

## What to check

1. Check the two format identifiers, input dimensions and memory availability.

## Recommended action

Use supported conversion parameters or supply the encoder format directly.
