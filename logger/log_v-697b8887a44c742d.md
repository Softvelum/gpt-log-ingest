# Log-upload HTTP request prepared

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_v
Log level: verbose
Documentation ID: log_v-697b8887a44c742d

## Log pattern

```text
prepared log packet size=%llu
```

## Parameters

- Argument 1 — request\_bytes: Complete request length in bytes, cast to an unsigned 64-bit integer.

The argument is uint64_t while %llu expects unsigned long long; the underlying type differs on some targets.

## Log examples

No target-independent example is given because the length conversion depends on the platform integer type.

## Short description

Log-upload HTTP request prepared.

## Trigger condition

The multipart log-upload body and HTTP headers have been assembled.

## Explanation

This reports the complete prepared HTTP request length, including headers and multipart fields. It does not confirm a connection or successful upload.
