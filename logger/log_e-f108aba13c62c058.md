# MPEG-2 picture decoding failed

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f108aba13c62c058

## Log pattern

```text
failed to decode mpeg2video packet for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

One occurrence decodes a picture when the next picture start is found; the other decodes the final packet after optional caption forwarding.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode mpeg2video packet for [live/camera]
```

## Short description

MPEG-2 picture decoding failed.

## Trigger condition

The selected MPEG-2 decoder rejects either an intermediate picture segment or the final message remainder.

## Explanation

The current message fails and the video decoder worker stops.

## Possible causes

- MPEG-2 payload or decoder configuration is rejected, device processing fails, or decoded output delivery fails.

## What to check

1. Check the earlier decoder diagnostics and picture boundaries in the live MPEG-2 input.

## Recommended action

Correct the decoder or downstream failure and restart the affected pipeline.
