# LATM alternate mux version unsupported

Product: Nimble Streamer
Component: AAC LATM parsing
Logging function: log_e
Log level: error
Documentation ID: log_e-9a01fb13146f046a

## Log pattern

```text
unsupported audioMuxVersionA=%d
```

## Parameters

- Argument 1 — Version: One-bit alternate audio mux version.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audioMuxVersionA=1
```

## Short description

LATM alternate mux version unsupported.

## Trigger condition

The LATM alternate audio mux version is nonzero.

## Explanation

Stream configuration parsing fails; only alternate version zero is accepted.

## Possible causes

- The LATM alternate audio mux version is nonzero.

## What to check

1. Check the input LATM mux version.

## Recommended action

Use the supported LATM mux configuration.
