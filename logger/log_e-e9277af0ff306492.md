# Advertising chunk cache allocation failed

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-e9277af0ff306492

## Log pattern

```text
failed to allocate cache item key=%s
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to allocate cache item key=/app/stream/ad_1.ts
```

## Short description

Advertising chunk cache allocation failed.

## Trigger condition

Allocating cache storage for the completed advertising media or initialization chunk fails.

## Explanation

The request records insufficient memory as its cancellation reason and returns; cleanup cancels the pending item.

## Possible causes

- Allocating cache storage for the completed advertising media or initialization chunk fails.

## What to check

1. Check available cache capacity and the requested advertising chunk size.

## Recommended action

Check available cache capacity and the requested advertising chunk size.
