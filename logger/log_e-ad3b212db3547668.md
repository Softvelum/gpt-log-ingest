# External request connection ended before completion

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-ad3b212db3547668

## Log pattern

```text
requestor session p=%p %s event for s=%d ev=0x%x url='%s' r=%d '%llu-%llu'
```

## Parameters

- Argument 1 — address: Request session memory address.
- Argument 2 — kind: error for the exact error event; otherwise disconnect.
- Argument 3 — socket: Peer socket descriptor.
- Argument 4 — events: Socket event flags in hexadecimal.
- Argument 5 — URL: Current peer URL, which can differ after redirection.
- Argument 6 — method: Numeric request method.
- Argument 7 — from: Inclusive starting byte offset.
- Argument 8 — to: Exclusive ending byte offset, or zero for no ending bound.

## Log examples

Illustrative examples; these are not captured server logs.

```text
requestor session p=0x1000 disconnect event for s=12 ev=0x2000 url='https://media.example/movie.mp4' r=0 '0-1024'
```

## Short description

External request connection ended before completion.

## Trigger condition

A recognized closure or error event arrives outside the keep-alive resume retry case.

## Explanation

The session is marked finished. A remaining requester is notified of failure during cleanup.

## Possible causes

- The connection closed or reported an error before normal completion.

## What to check

1. Check request progress and peer closure diagnostics.

## Recommended action

Resolve the connection failure or origin response problem.
