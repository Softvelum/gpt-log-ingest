# Managed task output could not be monitored

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-8b268ef5b75257fc

## Log pattern

```text
failed to add fd=%d to selector epfd=%d
```

## Parameters

- Argument 1 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 2 — Selector: Integer event-selector descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add fd=12 to selector epfd=7
```

## Short description

Managed task output could not be monitored.

## Trigger condition

Adding the newly created task output descriptor to the event selector fails. Available only on Linux builds.

## Explanation

The output descriptor is closed and task startup returns failure. This branch does not explicitly stop the subprocess it just created.

## Possible causes

- The event selector rejected the task output descriptor.

## What to check

1. Check the output and selector descriptors and associated selector errors.
