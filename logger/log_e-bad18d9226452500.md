# Caption preservation buffer is full

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-bad18d9226452500

## Log pattern

```text
failed to alloc subtitles buffer f='%s', size=%d, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.
- Argument 2 — Required bytes: Existing caption bytes plus incoming caption side-data bytes, integer.
- Argument 3 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc subtitles buffer f='[in]null[out]', size=10001, stream=live/camera
```

## Short description

Caption preservation buffer is full.

## Trigger condition

Adding the frame captions would exceed an output caption buffer capacity.

## Explanation

That output does not retain these captions; processing continues for other outputs and video.

## Possible causes

- Accumulated caption data exceeds the configured caption buffer maximum.

## What to check

1. Check caption preservation settings, accumulated caption size, and allocation diagnostics.

## Recommended action

Resolve the caption storage failure if caption preservation is required.
