# AJA capture frame-range text is invalid

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-e162c67aa9859c80

## Log pattern

```text
Bad frames spec for device %s, '%s', '%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Frame specification: Requested device frame-count/range text.
- Argument 3 — Parse detail: Error text returned by the AJA frame-range parser.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad frames spec for device 0, 'invalid', 'invalid frame range'
```

## Short description

AJA capture frame-range text is invalid.

## Trigger condition

Parsing a nonempty device frame-range specification returns an error string.

## Explanation

The frame-range setter returns failure without accepting that specification.

## Possible causes

- Parsing a nonempty device frame-range specification returns an error string.

## What to check

1. Check the supplied frame-count or frame-range text and parser detail.

## Recommended action

Use a frame count, count with first-frame number, or first-to-last frame range.
