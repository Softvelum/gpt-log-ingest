# SRT multipoint receiver accept failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-749d17b990148ba6

## Log pattern

```text
failed to accept srt socket s=%d
```

## Parameters

- Argument 1 — Listener: SRT listener socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to accept srt socket s=100
```

## Short description

SRT multipoint receiver accept failed.

## Trigger condition

The sender object cannot accept a receiver from its listening socket.

## Explanation

No sender session is started or handed to a worker for this attempt.

## Possible causes

- The sender object cannot accept a receiver from its listening socket.

## What to check

1. Inspect preceding SRT accept errors.
