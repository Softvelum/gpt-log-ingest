# H.264 sequence parameter set is too short

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-5188d8b08873bff1

## Log pattern

```text
sps must be at least 4 bytes long
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
sps must be at least 4 bytes long
```

## Short description

H.264 sequence parameter set is too short.

## Trigger condition

The decoded H.264 sequence parameter set contains fewer than four bytes.

## Explanation

AVC configuration construction stops before reading profile, compatibility, and level bytes. No codec configuration is installed.

## Possible causes

- The decoded H.264 sequence parameter set contains fewer than four bytes.

## What to check

1. Check the decoded sequence parameter set length.

## Recommended action

Provide an H.264 sequence parameter set containing at least four bytes.
