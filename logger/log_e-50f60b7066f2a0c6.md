# HEVC sequence parameter set cannot be decoded

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-50f60b7066f2a0c6

## Log pattern

```text
[VM] set_video_codec_hevc function, get_h265_sps_info call failed for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the affected live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] set_video_codec_hevc function, get_h265_sps_info call failed for [live/camera]
```

## Short description

HEVC sequence parameter set cannot be decoded.

## Trigger condition

The first HEVC sequence parameter set cannot be parsed for its codec information.

## Explanation

HEVC setup fails before creating the decoder configuration record.

## Possible causes

- The first HEVC sequence parameter set cannot be parsed for its codec information.

## What to check

1. Inspect the first SPS and its declared length.

## Recommended action

Provide a valid HEVC sequence parameter set.
