# No WHEP playback route matches

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-17642ccc546f9905

## Log pattern

```text
no WebRTC WHEP route for url '%s':'%s'
```

## Parameters

- Argument 1 — Request host: Text authority or Host value used for routing.
- Argument 2 — Request URL: Text request path and query being routed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no WebRTC WHEP route for url 'media.example':'/live/camera'
```

## Short description

No WHEP playback route matches.

## Trigger condition

A WebRTC WHEP playback request has no matching route.

## Explanation

HTTP 404 is prepared before playback starts.

## Possible causes

- A WebRTC WHEP playback request has no matching route.

## What to check

1. Check WHEP playback enablement and the host/application/stream route used by the client.

## Recommended action

Check WHEP playback enablement and the host/application/stream route used by the client.
