# RTSP media socket connection accepted or in progress

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_v
Log level: verbose
Documentation ID: log_v-39cb5abc53166739

## Log pattern

```text
connecting s=%d to '%s:%d'
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.
- Argument 2 — Host: Remote media or control host.
- Argument 3 — Remote port: Decimal destination port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connecting s=26 to '192.0.2.1:5000'
```

## Short description

RTSP media socket connection accepted or in progress.

## Trigger condition

The socket connection completes immediately or reports the operating-system connection-in-progress condition.

## Explanation

The socket is returned as usable for continued asynchronous setup. This message covers both immediate success and an unfinished asynchronous connection.

## Possible causes

- Normal acceptance of a media socket connection attempt.
