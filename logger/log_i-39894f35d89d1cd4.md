# Panel identity is empty

## Log pattern

```text
panel_uuid is empty, stopping thread
```

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Panel identity is empty.

## Trigger condition

A panel-related thread starts with an empty configured panel UUID.

## Explanation

The panel log-upload thread and both stream-checker threads return before running their normal loops. The synchronization thread also disables statistics and logs its stopped message before returning. This does not stop the entire server.
