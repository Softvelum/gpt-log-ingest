# Invalid decoded DVB subtitle rectangle

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-db1a9bc58922555c

## Log pattern

```text
invalid dvb sub rect for [%s]
```

## Parameters

- Argument 1 — Stream: Application and stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid dvb sub rect for [live/news]
```

## Short description

Invalid decoded DVB subtitle rectangle.

## Trigger condition

A rectangle is missing, has nonpositive width, height, line size, or color count, or lacks bitmap or palette data.

## Explanation

The subtitle request is classified as empty, preventing valid serialization of that request.

## Possible causes

- A rectangle is missing, has nonpositive width, height, line size, or color count, or lacks bitmap or palette data.

## What to check

1. Check the decoded rectangle metadata and bitmap/palette availability.
