# RTMP publishing TLS initialization failed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-44671df8eda06e00

## Log pattern

```text
failed to init ssl for rtmp_publisher [%s:%d]
```

## Parameters

- Argument 1 — host: Remote stream server hostname.
- Argument 2 — port: Remote TCP port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init ssl for rtmp_publisher [publish.example:443]
```

## Short description

RTMP publishing TLS initialization failed.

## Trigger condition

TLS initialization fails while creating an RTMP publisher or reconnecting for the final Adobe authorization stage.

## Explanation

The publisher is not installed for that connection. Synchronization records failure or requests another synchronization attempt.

## Possible causes

- TLS state could not be initialized for the publishing destination.

## What to check

1. Check preceding TLS and connection diagnostics.

## Recommended action

Resolve the TLS setup problem at the publishing connection.
