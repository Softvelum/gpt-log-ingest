# Pay-per-view API response received

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_v
Log level: verbose
Documentation ID: log_v-786b98ab7288ddb5

## Log pattern

```text
received PPV Api response:
%s
```

## Parameters

- Argument 1 — response: Handler response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
received PPV Api response:

```

## Short description

Pay-per-view API response received.

## Trigger condition

The handler HTTP exchange succeeds.

## Explanation

The body is logged before JSON or XML parsing and mutual authorization checks; successful exchange does not prove the deny list is accepted.
