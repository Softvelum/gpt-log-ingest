# Cannot expand ICY response header

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-8a31d6db4735c706

## Log pattern

```text
failed to shift header %s 
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

Three additional integer arguments are supplied after the URL but the format has no conversions for them; they do not appear in the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to shift header http://radio.example.net/live 
```

## Short description

Cannot expand ICY response header.

## Trigger condition

The receive buffer cannot shift its contents by five bytes to convert ICY response syntax to HTTP syntax.

## Explanation

The pulled Icecast session is shut down before header parsing.

## Possible causes

- The receive buffer cannot shift its contents by five bytes to convert ICY response syntax to HTTP syntax.

## What to check

1. Check receive-buffer capacity and the response header size.
