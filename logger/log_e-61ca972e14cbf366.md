# SLDP advertising wait expires and stops playback

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-61ca972e14cbf366

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d timer expired, stop on advertising content error %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — Content URI: Configured URI of the advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 timer expired, stop on advertising content error https://media.example/ad.mp4
```

## Short description

SLDP advertising wait expires and stops playback.

## Trigger condition

The matching cache-wait timer expires and the item is not configured to skip errors.

## Explanation

The observer and timer are removed and the playback connection is shut down.

## Possible causes

- The matching cache-wait timer expires and the item is not configured to skip errors.

## What to check

1. Check media availability, the wait timeout, and error policy.

## Recommended action

Restore content loading or correct the intended timeout policy.
