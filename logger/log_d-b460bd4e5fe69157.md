# File response send result

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-b460bd4e5fe69157

## Log pattern

```text
sendf s=%d f=%d off=%ld sz=%lld wr=%d
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — File descriptor: Integer descriptor of the response file.
- Argument 3 — Current file offset: Signed file byte offset after the send operation, printed as long.
- Argument 4 — Remaining requested bytes: Native-size unsigned bytes requested before this write is subtracted.
- Argument 5 — Written bytes: Signed write result explicitly cast to int; negative values indicate failure or suspension.

The remaining-size value is unsigned native-size data printed with %lld; only values representable in the signed output type are meaningful. The offset conversion assumes a platform where the file offset fits long.

## Log examples

The file offset uses %ld and a native-size unsigned remaining count uses %lld. These arguments are not portably matched to the format, so an exact cross-platform example is omitted.

## Short description

File response send result.

## Trigger condition

A response file send operation returns.

## Explanation

The offset reflects the send operation; the remaining-size field is captured before subtracting this write. Positive writes advance progress; suspension waits, and other nonpositive results finish the session.

## Possible causes

- A response file send operation returns.
