# Encrypted URL initialization vector text is too long

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-a9668b4113b9f3e2

## Log pattern

```text
iv_len=%d is too long
```

## Parameters

- Argument 1 — Required vector length: Cipher-required initialization vector length in bytes, integer; this is not the supplied length despite the wording.

## Log examples

Illustrative examples; these are not captured server logs.

```text
iv_len=16 is too long
```

## Short description

Encrypted URL initialization vector text is too long.

## Trigger condition

The encoded vector length fails the preliminary bound for the selected cipher initialization vector.

## Explanation

URL validation returns failure without assigning a decrypted URL.

## Possible causes

- The supplied encoded initialization vector is too long.

## What to check

1. Check that all encrypted-link fields are complete and correctly encoded.

## Recommended action

Regenerate the complete encrypted link with matching fields.
