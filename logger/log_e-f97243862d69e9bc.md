# AAC variable bitrate mode failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f97243862d69e9bc

## Log pattern

```text
failed to set vbr=%d, status=%d
```

## Parameters

- Argument 1 — Mode: Requested FDK variable-bitrate mode, integer 1 through 5.
- Argument 2 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set vbr=3, status=1
```

## Short description

AAC variable bitrate mode failed.

## Trigger condition

In an FDK-enabled build, applying the selected variable-bitrate mode returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected variable bitrate mode for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in variable bitrate mode.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
