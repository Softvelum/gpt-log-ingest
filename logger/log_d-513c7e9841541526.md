# Management listener thread stopped

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_d
Log level: debug
Documentation ID: log_d-513c7e9841541526

## Log pattern

```text
ServerManagementThread stopped
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerManagementThread stopped
```

## Short description

Management listener thread stopped.

## Trigger condition

No management listening socket was created, or the active event loop has ended after an exit request.

## Explanation

Startup with no sockets returns immediately. After an active loop, the thread logs this message before closing its listening and accepted sockets and deleting client objects.
