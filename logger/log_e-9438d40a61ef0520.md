# Newly reserved origin cache item has the wrong state

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-9438d40a61ef0520

## Log pattern

```text
invalid cache item state=%u
```

## Parameters

- Argument 1 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid cache item state=1
```

## Short description

Newly reserved origin cache item has the wrong state.

## Trigger condition

A cache reservation reports that this session owns a new item, but its state is not newly reserved.

## Explanation

The client session is marked finished before origin connection.

## Possible causes

- A cache reservation reports that this session owns a new item, but its state is not newly reserved.

## What to check

1. Check cache reservation and update messages for this key; a newly reserved item should not already be in another lifecycle state.

## Recommended action

Check cache reservation and update messages for this key; a newly reserved item should not already be in another lifecycle state.
