# Memory cache buffer allocated

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-0b896fd558115470

## Log pattern

```text
allocated key='%s' sz=%llu ram=%llu
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — allocated bytes: New buffer capacity in bytes.
- Argument 3 — RAM bytes: Total cache capacity currently allocated in memory, in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
allocated key='movie' sz=4096 ram=8192
```

## Short description

Memory cache buffer allocated.

## Trigger condition

Allocating an item buffer in memory succeeds.

## Explanation

The item capacity and memory-cache total are updated; the item data size remains zero until content is filled.
