# Proxy tunnel response could not be read

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_e
Log level: error
Documentation ID: log_e-2d73f98558dcf7d3

## Log pattern

```text
failed to read response from proxy '%s:%d' r=%d errno=%d
```

## Parameters

- Argument 1 — Host: Destination host or proxy host, text.
- Argument 2 — Port: TCP destination port number, integer.
- Argument 3 — Read result: Bytes received; zero means peer closure, a negative result is an error.
- Argument 4 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read response from proxy 'panel.example:443' r=0 errno=5
```

## Short description

Proxy tunnel response could not be read.

## Trigger condition

Reading the proxy response returns zero or a negative result.

## Explanation

Tunnel setup fails.

## Possible causes

- The proxy exchange failed at the stated send, read, or parse step.

## What to check

1. Check the proxy address and response, and the socket error where reported.

## Recommended action

Restore a valid reachable HTTP CONNECT proxy.
