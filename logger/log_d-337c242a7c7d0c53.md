# Scenario input buffer creation requested

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-337c242a7c7d0c53

## Log pattern

```text
register input stream [%s/%s]
```

## Parameters

- Argument 1 — Application: Live-stream application name.
- Argument 2 — Stream: Live-stream name within its application.

## Log examples

Illustrative examples; these are not captured server logs.

```text
register input stream [live/camera]
```

## Short description

Scenario input buffer creation requested.

## Trigger condition

A codec or frame operation needs an input buffer and none currently exists for the application/stream pair.

## Explanation

The buffer manager is asked to create the input stream. This message precedes creation and does not guarantee a nonempty result.

## Possible causes

- First use of an unregistered scenario input.

## What to check

1. Check later codec or frame-processing messages if input creation fails.
