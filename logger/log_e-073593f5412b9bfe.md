# SRT publisher handshake too old for stream-ID authentication

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-073593f5412b9bfe

## Log pattern

```text
[srt_listen_callback] old client(< 1.3.x) with ip=[%s] tries to publish stream into [%s:%d] configured for streamid processing
```

## Parameters

- Argument 1 — Peer: Publisher IP address.
- Argument 2 — Address: Configured endpoint address.
- Argument 3 — Port: Configured endpoint port number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] old client(< 1.3.x) with ip=[192.0.2.20] tries to publish stream into [0.0.0.0:9000] configured for streamid processing
```

## Short description

SRT publisher handshake too old for stream-ID authentication.

## Trigger condition

An authenticated listener receives a handshake version below five.

## Explanation

The incoming connection is rejected. The diagnostic identifies this as an SRT client older than the 1.3 generation.

## Possible causes

- An authenticated listener receives a handshake version below five.

## What to check

1. Check the publisher SRT version.

## Recommended action

Use a publisher supporting the required stream-ID handshake.
