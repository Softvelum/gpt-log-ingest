# Loading persisted recovery statistics

Product: Nimble Streamer
Component: Statistics recovery
Logging function: log_i
Log level: info
Documentation ID: log_i-c695984a32e86fd0

## Log pattern

```text
Loading Recovery stats from '%s'
```

## Parameters

- Argument 1 — Statistics file: Path of the accumulated or ready-to-report statistics file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Loading Recovery stats from '/var/cache/nimble/stats.json'
```

## Short description

Loading persisted recovery statistics.

## Trigger condition

A persisted statistics file is found and loading is about to begin.

## Explanation

The file must still open, parse and supply valid dated items. A later completion message marks the end of processing.
