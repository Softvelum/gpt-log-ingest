# OCR vertical-bar exclusion could not be set

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_e
Log level: error
Documentation ID: log_e-a71a6aa950ee3706

## Log pattern

```text
failed to set tessedit_char_blacklist, lang=%s
```

## Parameters

- Argument 1 — Language: Lowercase DVB subtitle language code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set tessedit_char_blacklist, lang=eng
```

## Short description

OCR vertical-bar exclusion could not be set.

## Trigger condition

Tesseract rejects the setting that excludes the vertical-bar character from recognition.

## Explanation

The decoder is still installed and used. The intended exclusion helps avoid recognizing the letter I as a vertical bar.

## Possible causes

- Tesseract rejects the setting that excludes the vertical-bar character from recognition.

## What to check

1. Check whether recognized subtitle text contains unwanted vertical bars.
