# RIST sender could not consume the MPEG-TS payload

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-dcd1447f4c553b74

## Log pattern

```text
failed to send mpegts packet over rist, id=%s
```

## Parameters

- Argument 1 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send mpegts packet over rist, id=rist-output
```

## Short description

RIST sender could not consume the MPEG-TS payload.

## Trigger condition

A RIST write returns zero, a negative count, or a count greater than the remaining message payload.

## Explanation

Message processing returns failure. Partial positive writes are retried by advancing through the payload; this message covers a result that cannot continue that loop.

## Possible causes

- A RIST write returns zero, a negative count, or a count greater than the remaining message payload.

## What to check

1. Check the RIST sender state and any transport diagnostics for this connection.
