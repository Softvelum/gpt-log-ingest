# Advertising playlist contains no chunks

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-d36fa08254796e32

## Log pattern

```text
empty chunklist generated for content id='%s' uri='%s'
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
empty chunklist generated for content id='ad-01' uri='https://media.example/ad.mp4'
```

## Short description

Advertising playlist contains no chunks.

## Trigger condition

Playlist generation from an MP4 or an audio advertisement produces an empty chunk list.

## Explanation

The condition is logged, but processing continues and the playlist is ultimately marked ready unless a later exception occurs.

## Possible causes

- Playlist generation from an MP4 or an audio advertisement produces an empty chunk list.

## What to check

1. Check media duration and selected tracks; an empty list cannot supply advertising chunks.

## Recommended action

Check media duration and selected tracks; an empty list cannot supply advertising chunks.
