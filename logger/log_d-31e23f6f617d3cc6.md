# Cache reservation found an existing item

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-31e23f6f617d3cc6

## Log pattern

```text
key='%s' sz=%llu st=%u already exists
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — size: Stored data size in bytes.
- Argument 3 — state: Numeric cache state: 0 empty, 1 downloading, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
key='movie' sz=4096 st=3 already exists
```

## Short description

Cache reservation found an existing item.

## Trigger condition

An existing item cannot be removed or replaced under the reservation rules.

## Explanation

The reservation reports that the key already exists; it does not create or return a new empty item.
