# SDI audio packet resubmission failed

Product: Nimble Streamer
Component: SDI device input
Logging function: log_e
Log level: error
Documentation ID: log_e-563bd75004e6d202

## Log pattern

```text
failed to send again audio pkt to decoder [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send again audio pkt to decoder [live/camera]
```

## Short description

SDI audio packet resubmission failed.

## Trigger condition

After draining decoder output, resubmitting the pending device audio packet returns a nonzero result.

## Explanation

The current device decoding operation returns failure.

## Possible causes

- The decoder still cannot accept the pending device audio packet.

## What to check

1. Check preceding decoder diagnostics and whether the device audio input remains valid.

## Recommended action

Correct or restart the failing device input.
