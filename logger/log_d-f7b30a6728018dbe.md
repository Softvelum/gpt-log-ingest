# Direct panel connection started

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_d
Log level: debug
Documentation ID: log_d-f7b30a6728018dbe

## Log pattern

```text
connecting to %s (%s:%d)
```

## Parameters

- Argument 1 — Host: Destination host or proxy host, text.
- Argument 2 — Address: Selected resolved IPv4 address, text.
- Argument 3 — Port: TCP destination port number, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connecting to panel.example (192.0.2.10:443)
```

## Short description

Direct panel connection started.

## Trigger condition

A resolved destination address is selected for a direct connection attempt while silent mode is disabled.

## Explanation

The TCP socket is created and connected next; the message does not confirm connection success.
