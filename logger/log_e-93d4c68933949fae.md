# HLS publishing request cannot continue

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_e
Log level: error
Documentation ID: log_e-93d4c68933949fae

## Log pattern

```text
hls publisher failed to push item=%s from stream='%s/%s'

```

## Parameters

- Argument 1 — Item: URL of the failed playlist or chunk upload.
- Argument 2 — Application: Source application name.
- Argument 3 — Stream: Source stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
hls publisher failed to push item=https://upload.example.net/live/playlist.m3u8 from stream='live/news'

```

## Short description

HLS publishing request cannot continue.

## Trigger condition

A failed upload cannot be retried by the publisher, exceeds three retries, or cannot resend the pending item.

## Explanation

The publisher is removed and settings resynchronization is requested. The current publisher retries HTTP 500 responses only.

## Possible causes

- A failed upload cannot be retried by the publisher, exceeds three retries, or cannot resend the pending item.

## What to check

1. Check the item URL, destination response, and whether the source chunk remains available.
