# DVR database record and offset counts disagree

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-fd7487b12c68c0f7

## Log pattern

```text
invalid segments db='%s' array_len=%u offsets.size()=%u
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.
- Argument 2 — Record count: Unsigned parsed array or recovered-record count.
- Argument 3 — Offset count: Unsigned native-size count of recorded offsets.

The offset count is a native-size value supplied to a 32-bit unsigned conversion; it is incompatible on 64-bit native-size builds.

## Log examples

No portable sound example is given because the native-size offset count may not match its printf conversion.

## Short description

DVR database record and offset counts disagree.

## Trigger condition

The parsed record count differs from the collected database-offset count.

## Explanation

The entire affected time bucket is skipped and other buckets continue loading.

## Possible causes

- The parsed record count differs from the collected database-offset count.

## What to check

1. Check database damage and preceding recovery messages.

## Recommended action

Check database damage and preceding recovery messages.
