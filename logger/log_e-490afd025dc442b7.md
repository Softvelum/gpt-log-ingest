# HTTP media input receive failed

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-490afd025dc442b7

## Log pattern

```text
failed to receive data from url='%s' s=%d errno=%d
```

## Parameters

- Argument 1 — url: Current origin URL.
- Argument 2 — socket: Origin connection socket descriptor.
- Argument 3 — socket\_error: Stored error code reported by the peer socket; its meaning depends on the connection and platform.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to receive data from url='https://origin.example/live.ts' s=42 errno=104
```

## Short description

HTTP media input receive failed.

## Trigger condition

The socket read helper reports a receive error for an HLS or MPEG-TS HTTP origin.

## Explanation

The input enters its completed shutdown state and returns. An orderly peer close uses a separate branch and does not produce this message.

## Possible causes

- The origin read operation reported failure.

## What to check

1. Check the current URL, descriptor, and preceding socket or TLS diagnostics.

## Recommended action

Resolve the indicated origin connection failure.
