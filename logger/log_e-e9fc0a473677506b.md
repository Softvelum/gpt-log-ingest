# Signal stack trace recorded

Product: Nimble Streamer
Component: Process signals and exception diagnostics
Logging function: log_e
Log level: error
Documentation ID: log_e-e9fc0a473677506b

## Log pattern

```text
backtrace:
%s
```

## Parameters

- Argument 1 — Stack trace: Tab-indented stack descriptions with trailing newlines, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
backtrace:
	[0x12340000]

```

## Short description

Signal stack trace recorded.

## Trigger condition

The non-Windows default signal branch successfully obtains printable stack descriptions.

## Explanation

The assembled stack trace is logged and the handler returns.

## Possible causes

- An unexpected signal reached the default branch.

## What to check

1. Read the preceding signal and the recorded stack trace.

## Recommended action

Use the signal and stack trace to diagnose the triggering failure.
