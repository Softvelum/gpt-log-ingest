## Log examples

Illustrative examples; these are not captured server logs.

## Short description

HTTP/3 worker initialization failed.

## Trigger condition

An HTTP/3-enabled worker fails to initialize its transport engine.

## Explanation

The worker returns before entering its event loop. This branch does not set the global server exit flag.
