# Child log level update failed

Product: Nimble Streamer
Component: Child process communication
Logging function: log_e
Log level: error
Documentation ID: log_e-dc563bb63e29b118

## Log pattern

```text
failed to update log level
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to update log level
```

## Short description

Child log level update failed.

## Trigger condition

During the periodic log-level check, a changed log level cannot be queued or flushed to the child.

## Explanation

The child communication attempt is treated as failed and reset or ended.

## Possible causes

- The bounded output buffer or the socket rejected the log-level update.

## What to check

1. Check child connection health and preceding output failures.

## Recommended action

Resolve the reported child communication problem before retrying.
