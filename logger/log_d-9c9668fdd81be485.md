# Origin body buffer status

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-9c9668fdd81be485

## Log pattern

```text
OnOriginResp total=%llu capacity=%llu received=%llu sent=%llu remained_space=%u
```

## Parameters

- Argument 1 — Expected body bytes: Unsigned 64-bit total body size taken from the origin response.
- Argument 2 — Buffer capacity: Unsigned 64-bit allocated buffer size in bytes.
- Argument 3 — Received bytes: Unsigned 64-bit cumulative body bytes received.
- Argument 4 — Sent bytes: Unsigned 64-bit cumulative body bytes sent to the client.
- Argument 5 — Contiguous free bytes: Unsigned amount of contiguous buffer space available for the next read.

## Log examples

Illustrative examples; these are not captured server logs.

```text
OnOriginResp total=1048576 capacity=524288 received=65536 sent=32768 remained_space=458752
```

## Short description

Origin body buffer status.

## Trigger condition

Before reading origin media, the session calculates the contiguous free space in its full-body or circular buffer.

## Explanation

This records receiving and sending progress; a full circular buffer temporarily pauses origin input until client output frees space.

## Possible causes

- Before reading origin media, the session calculates the contiguous free space in its full-body or circular buffer.
