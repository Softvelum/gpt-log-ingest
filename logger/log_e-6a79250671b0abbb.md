# SLDP skips unavailable advertising content

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-6a79250671b0abbb

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d skip advertising content error %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — Content URI: Configured URI of the advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 skip advertising content error https://media.example/ad.mp4
```

## Short description

SLDP skips unavailable advertising content.

## Trigger condition

Unready advertising content cannot use the wait path and its error action is skip.

## Explanation

The sender advances to the next scheduled content item and continues playback if possible.

## Possible causes

- Unready advertising content cannot use the wait path and its error action is skip.

## What to check

1. Check content readiness and the configured skip policy.

## Recommended action

Restore the media if it must be shown.
