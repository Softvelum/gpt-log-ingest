# Advertising download redirect accepted

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-f07538547251c570

## Log pattern

```text
redirect to %s requested, uri=%s
```

## Parameters

- Argument 1 — Redirect destination: Text from the redirect location.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
redirect to https://cdn.example/ad.mp4 requested, uri=https://media.example/ad.mp4
```

## Short description

Advertising download redirect accepted.

## Trigger condition

A redirect has a nonempty destination and remains within the three-redirect limit.

## Explanation

The current socket is removed and closed; the download worker will connect to the new destination.

## Possible causes

- A redirect has a nonempty destination and remains within the three-redirect limit.
