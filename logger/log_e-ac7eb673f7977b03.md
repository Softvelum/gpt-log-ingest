# Cannot discard received websocket client data

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_e
Log level: error
Documentation ID: log_e-ac7eb673f7977b03

## Log pattern

```text
failed to recv buffer on skip from client: %d
```

## Parameters

- Argument 1 — Socket: Client socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv buffer on skip from client: 42
```

## Short description

Cannot discard received websocket client data.

## Trigger condition

An HTTP/1 websocket sender fails while reading unwanted client data and the error is not would-block.

## Explanation

The sender is marked shut down. This discard path is specific to HTTP/1 transport.

## Possible causes

- An HTTP/1 websocket sender fails while reading unwanted client data and the error is not would-block.

## What to check

1. Check the client connection and preceding socket diagnostics.
