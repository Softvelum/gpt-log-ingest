# DVR segment header seek failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-b15c283413137658

## Log pattern

```text
failed to seek to offset=%llu for fd=%d errno=%d
```

## Parameters

- Argument 1 — Segment offset: Unsigned 64-bit byte offset within the archive file.
- Argument 2 — File descriptor: Integer open archive-file descriptor.
- Argument 3 — File error: Integer operating-system error number after the failed seek.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to seek to offset=1048576 for fd=23 errno=5
```

## Short description

DVR segment header seek failed.

## Trigger condition

Seeking to a DVR subtitle or audio/video segment offset returns a different offset or an error.

## Explanation

The segment header cannot be inspected and an HTTP 500 response is prepared.

## Possible causes

- Seeking to a DVR subtitle or audio/video segment offset returns a different offset or an error.

## What to check

1. Check the archive file and filesystem I/O errors; the recorded segment offset must be seekable.

## Recommended action

Check the archive file and filesystem I/O errors; the recorded segment offset must be seekable.
