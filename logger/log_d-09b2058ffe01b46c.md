# Debug text forwarded from several subsystems

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-09b2058ffe01b46c

## Log pattern

```text
%s
```

## Parameters

- Argument 1 — text: Complete prepared diagnostic text; it can include multiple lines.

There is no single fixed message body for this shared string conversion.

## Log examples

Illustrative examples; these are not captured server logs.

```text
user [192.0.2.10] is in deny list
```

## Short description

Debug text forwarded from several subsystems.

## Trigger condition

A cache-list dump, access-control result, or RIST debug callback supplies a prepared text message.

## Explanation

Cache dumps list at most 1,000 entries and their state, references, and timestamps. Access-control successes use debug logging; failures use it when that error level is selected, and may also enter access-control log storage. RIST debug callbacks remove a trailing newline before forwarding the library text. The shared format alone does not identify the subsystem.
