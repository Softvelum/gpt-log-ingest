# Audio format converter could not be created

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_e
Log level: error
Documentation ID: log_e-687c098dbea2f012

## Log pattern

```text
failed to create audio format conv ctx
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create audio format conv ctx
```

## Short description

Audio format converter could not be created.

## Trigger condition

The input sample format differs from the encoder format, and allocating or configuring the audio converter fails.

## Explanation

The input frame write fails before format conversion or encoding.

## Possible causes

- The stated frame allocation, layout copy, or sample conversion operation failed.

## What to check

1. Check the input audio format, channel layout, and accompanying FFmpeg diagnostics.

## Recommended action

Resolve the reported frame-preparation failure.
