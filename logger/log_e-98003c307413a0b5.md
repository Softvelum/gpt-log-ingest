# Unexpected playlist HTTP response

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-98003c307413a0b5

## Log pattern

```text
ServerPlaylistSyncThread::OnRequestProcessed unexpected url='%s' status=%d body_len=%d
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.
- Argument 2 — HTTP status: Integer HTTP response status.
- Argument 3 — Body bytes: Integer response body length in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerPlaylistSyncThread::OnRequestProcessed unexpected url='https://api.example/playlist' status=200 body_len=1024
```

## Short description

Unexpected playlist HTTP response.

## Trigger condition

A response URL is neither a currently requested block nor the configured main playlist destination.

## Explanation

The response body is ignored. A block response arriving after its request tracking was cleared can cause this.

## Possible causes

- A response URL is neither a currently requested block nor the configured main playlist destination.

## What to check

1. Compare the URL and timing with current playlist and block requests.

## Recommended action

Compare the URL and timing with current playlist and block requests.
