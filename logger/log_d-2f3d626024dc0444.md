# DASH manifest is waiting for DRM initialization data

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-2f3d626024dc0444

## Log pattern

```text
wait for DRM key for Pallycon stream='%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the VOD application.
- Argument 2 — Stream: Text naming the protected media stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wait for DRM key for Pallycon stream='vod/movie.mp4'
```

## Short description

DASH manifest is waiting for DRM initialization data.

## Trigger condition

A DASH manifest needs DRM PSSH data and its CENC keys have not yet been initialized.

## Explanation

The request is queued pending a key notification, unless the 2000-request wait limit forces cancellation. The fixed Pallycon label does not limit this branch to that provider.

## Possible causes

- A DASH manifest needs DRM PSSH data and its CENC keys have not yet been initialized.

## What to check

1. Check key acquisition for this stream and whether PSSH inclusion is enabled; a short wait is expected on first use.

## Recommended action

Check key acquisition for this stream and whether PSSH inclusion is enabled; a short wait is expected on first use.
