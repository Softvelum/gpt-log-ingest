# Cannot load TLS certificate chain

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_e
Log level: error
Documentation ID: log_e-8935e125a7062b8a

## Log pattern

```text
failed to use SSL cert file='%s' e='%s'
```

## Parameters

- Argument 1 — File: Configured certificate chain file path.
- Argument 2 — Error: Error text reported by the TLS library.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to use SSL cert file='/data/certs/chain.pem' e='error loading PEM data'
```

## Short description

Cannot load TLS certificate chain.

## Trigger condition

The TLS library rejects loading the configured certificate chain file.

## Explanation

Creating this certificate context fails, so the pending certificate reload cannot replace the active context set. HTTP/3 uses the same diagnostic when supported.

## Possible causes

- The TLS library rejects loading the configured certificate chain file.

## What to check

1. Check the indicated file and TLS error text for path, readability, encoding, or key-password problems.

## Recommended action

Provide a valid readable certificate chain file.
