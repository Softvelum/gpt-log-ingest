# VCAS key creation could not be submitted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-3d5a0242a3334722

## Log pattern

```text
failed to POST VCAS CreateKey request to url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to POST VCAS CreateKey request to url='https://keys.example/key'
```

## Short description

VCAS key creation could not be submitted.

## Trigger condition

The HTTP request processor refuses a create-key POST after successful asset creation.

## Explanation

That key is not recorded as requested by this attempt.

## Possible causes

- The HTTP request processor refuses a create-key POST after successful asset creation.

## What to check

1. Check the VCAS endpoint and accompanying HTTP request-processor errors.

## Recommended action

Check the VCAS endpoint and accompanying HTTP request-processor errors.
