# Cannot initialize pulled Icecast chunk

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-5a418140f48c1704

## Log pattern

```text
icecast stream failed to init chunk.url=%s, ct=%s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.
- Argument 2 — Content type: Accepted source response content type.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream failed to init chunk.url=http://radio.example.net/live, ct=audio/aac
```

## Short description

Cannot initialize pulled Icecast chunk.

## Trigger condition

After accepting the source headers, initializing the first audio chunk fails.

## Explanation

The pull session is shut down, typically after a metadata or chunk-buffer write failure.

## Possible causes

- After accepting the source headers, initializing the first audio chunk fails.

## What to check

1. Inspect preceding metadata and chunk-buffer diagnostics.
