# RTSP input has no usable media tracks

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-f5f37665de480ac8

## Log pattern

```text
No media streams found, socket %d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No media streams found, socket 25
```

## Short description

RTSP input has no usable media tracks.

## Trigger condition

The SDP contains media descriptions, but every track fails codec setup.

## Explanation

The client requests shutdown before issuing SETUP for a track. Earlier codec-specific messages identify individual rejected descriptions.

## Possible causes

- The SDP contains media descriptions, but every track fails codec setup.

## What to check

1. Check codec-specific errors for all advertised tracks.

## Recommended action

Supply at least one supported, valid media track.
