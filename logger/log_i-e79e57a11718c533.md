# Whisper model context created

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-e79e57a11718c533

## Log pattern

```text
whisper ctx created model='%s' use_gpu=%d gpu_device=%d
```

## Parameters

- Argument 1 — Model: Configured Whisper model file path.
- Argument 2 — GPU enabled: Boolean GPU preference, printed as 0 or 1.
- Argument 3 — GPU device: Configured GPU device number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whisper ctx created model='/data/models/speech.bin' use_gpu=1 gpu_device=0
```

## Short description

Whisper model context created.

## Trigger condition

Whisper model initialization returns a valid context.

## Explanation

Audio decoding and transcription setup continue using the displayed model and requested device settings. The log does not independently verify actual GPU execution.

## Possible causes

- Whisper model initialization returns a valid context.

## What to check

1. Confirm the model and requested device settings.
