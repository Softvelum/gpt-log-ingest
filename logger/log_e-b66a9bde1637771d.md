# Requested mapping exceeds media file size

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-b66a9bde1637771d

## Log pattern

```text
open_and_map_read_only_file failed file_name='%s' expected file_size=%llu but actual file_size=%lld
```

## Parameters

- Argument 1 — File: Requested runtime data-file path.
- Argument 2 — Required size: Minimum file length required to cover the requested region, in bytes.
- Argument 3 — Actual size: File length reported by the operating system, in bytes.

The required size is unsigned 64-bit and actual size is the operating-system file-size type; long-long conversion compatibility is platform dependent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
open_and_map_read_only_file failed file_name='/data/media/segment.m4s' expected file_size=8192 but actual file_size=4096
```

## Short description

Requested mapping exceeds media file size.

## Trigger condition

The requested starting offset plus requested length exceeds the actual file size.

## Explanation

No memory mapping is created.

## Possible causes

- The requested starting offset plus requested length exceeds the actual file size.

## What to check

1. Compare the requested end position with the current file length and check for concurrent truncation.
