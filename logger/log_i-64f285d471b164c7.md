# Quick Sync encoder hardware binding failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_i
Log level: info
Documentation ID: log_i-64f285d471b164c7

## Log pattern

```text
%p failed to set hw handle, err=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to set hw handle, err=-3
```

## Short description

Quick Sync encoder hardware binding failed.

## Trigger condition

Binding the opened VA display to the Linux encoder session returns a nonzero status.

## Explanation

The VA display is closed and encoder setup fails despite this message having informational severity.

## Possible causes

- The media session rejects the selected VA display.

## What to check

1. Check the status and compatibility between the render device, VA driver, and media runtime.

## Recommended action

Use a compatible device and driver combination, then restart encoding.
