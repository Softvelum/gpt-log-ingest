# NVIDIA H.264 timecode forwarding cannot initialize

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-1ee8d064000d8e80

## Log pattern

```text
failed to add sei timecodes for nvenc encoder=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add sei timecodes for nvenc encoder=0x12340000
```

## Short description

NVIDIA H.264 timecode forwarding cannot initialize.

## Trigger condition

SEI timecode forwarding is enabled, but the generated AVC configuration cannot be parsed for sequence information or does not signal picture-structure information.

## Explanation

Encoder initialization returns failure after setting output codec data; requested timecode forwarding is not ready.

## Possible causes

- The generated sequence header does not provide the information required for picture-timing timecodes.

## What to check

1. Check timecode-forwarding settings and the NVIDIA-generated H.264 sequence configuration.

## Recommended action

Use compatible H.264 settings or disable timecode forwarding when it is not required.
