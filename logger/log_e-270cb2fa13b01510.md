# NVIDIA B-direct capability query failed

Product: Nimble Streamer

Logging function: log_e
Log level: error

Illustrative examples; these are not captured server logs.

## Short description

NVIDIA B-direct capability query failed.

## Trigger condition

The encoder cannot complete the B-direct capability check while configuring H.264.

## Explanation

H.264 parameter setup returns failure, preventing encoder initialization.

## Possible causes

- The encoder capability query fails; an unsupported codec identifier can also prevent preparing that query.

## What to check

1. Check driver compatibility and preceding codec or session errors.

## Recommended action

Restore valid NVIDIA H.264 capability queries before retrying encoding.
