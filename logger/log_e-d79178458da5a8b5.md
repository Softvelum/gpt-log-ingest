# Audio framing buffer is too small

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-d79178458da5a8b5

## Log pattern

```text
[AM] audio_buffer too small. %s/%s
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] audio_buffer too small. live/camera
```

## Short description

Audio framing buffer is too small.

## Trigger condition

Writing the seven-byte AAC ADTS header or the audio payload into the selected audio buffer fails.

## Explanation

Audio framing returns failure. Live transport grouping propagates the failure; Icecast packaging discards its current chunk and resumes with a reset chunk.

## Possible causes

- Writing the seven-byte AAC ADTS header or the audio payload into the selected audio buffer fails.

## What to check

1. Check the audio payload size and buffer allocation limits.

## Recommended action

Resolve oversized audio frames or insufficient framing-buffer capacity.
