# DVR subtitle segment has no file

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-237c4d397c006705

## Log pattern

```text
failed to get .vtt segment file, stream=%s period=%d start_time=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Period: Integer identifying a continuous recording period.
- Argument 3 — Segment start: 64-bit media timestamp in 90000-Hz ticks.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get .vtt segment file, stream=live/camera period=1 start_time=90000
```

## Short description

DVR subtitle segment has no file.

## Trigger condition

The located subtitle segment has no backing file reference.

## Explanation

This segment contributes no subtitle text; export continues with subsequent segments.

## Possible causes

- The located subtitle segment has no backing file reference.

## What to check

1. Check the affected recorded subtitle segment and its language metadata.

## Recommended action

Check the affected recorded subtitle segment and its language metadata.
