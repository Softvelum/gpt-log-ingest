# KeyOS user credentials are missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-c5e0e24923f75e2a

## Log pattern

```text
keyos_user_certificate_file and keyos_user_key_file must be provided for KeyOS
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
keyos_user_certificate_file and keyos_user_key_file must be provided for KeyOS
```

## Short description

KeyOS user credentials are missing.

## Trigger condition

The loaded KeyOS user certificate or private key is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The loaded KeyOS user certificate or private key is empty.

## What to check

1. Provide readable nonempty KeyOS user certificate and key files.

## Recommended action

Provide readable nonempty KeyOS user certificate and key files.
