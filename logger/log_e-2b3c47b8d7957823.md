# Interleaved RTSP channel type is unknown

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-2b3c47b8d7957823

## Log pattern

```text
unknown stream type=%d stream=[%s]
```

## Parameters

- Argument 1 — Channel type: Integer data/control classification, outside the recognized choices.
- Argument 2 — Stream identity: Application and stream label used by the RTSP parser.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown stream type=99 stream=[live/camera]
```

## Short description

Interleaved RTSP channel type is unknown.

## Trigger condition

The registered channel type is neither RTP data nor RTCP control.

## Explanation

The frame is logged and consumed without dispatching its payload; the parser returns success.

## Possible causes

- The registered channel type is neither RTP data nor RTCP control.

## What to check

1. Check the interleaved channel type registered during transport setup.
