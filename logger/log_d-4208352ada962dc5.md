# Subtitle chunk name is invalid

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-4208352ada962dc5

## Log pattern

```text
invalid subtitles chunk requested name='%s'
```

## Parameters

- Argument 1 — Subtitle resource: Text requested WebVTT chunk name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid subtitles chunk requested name='subtitle_bad.webvtt'
```

## Short description

Subtitle chunk name is invalid.

## Trigger condition

A requested WebVTT resource fails extraction of its chunk index, optional language prefix, or advertising suffix.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- A requested WebVTT resource fails extraction of its chunk index, optional language prefix, or advertising suffix.

## What to check

1. Use the resource name from its subtitle playlist, including the n_ prefix, numeric index, and any language or advertising suffix.

## Recommended action

Use the resource name from its subtitle playlist, including the n_ prefix, numeric index, and any language or advertising suffix.
