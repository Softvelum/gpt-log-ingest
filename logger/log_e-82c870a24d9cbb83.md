# Shared CUDA context lock creation failed

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-82c870a24d9cbb83

## Log pattern

```text
failed to create lock for shared ctx, gpu=%d, res=%d
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 2 — CUDA status: CUDA driver result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create lock for shared ctx, gpu=0, res=2
```

## Short description

Shared CUDA context lock creation failed.

## Trigger condition

Shared-context locking is enabled, but creating the video-context lock returns an error.

## Explanation

The newly created CUDA context is destroyed and the request fails.

## Possible causes

- The CUDA driver rejects the reported context operation.

## What to check

1. Check the CUDA result, device access, available GPU resources and preceding context diagnostics.

## Recommended action

Correct the driver or resource problem and retry context setup.
