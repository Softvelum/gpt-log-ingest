# Enhanced RTMP video codec is unsupported

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-078822b8f5c5998e

## Log pattern

```text
[VM] unsupported codec %s.
```

## Parameters

- Argument 1 — Codec: Four-character codec identifier copied from the enhanced video tag.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] unsupported codec zzzz.
```

## Short description

Enhanced RTMP video codec is unsupported.

## Trigger condition

An enhanced video tag carries a four-character codec identifier other than hvc1, av01, vp09, or vp08.

## Explanation

The video message is rejected and connection processing fails.

## Possible causes

- An enhanced video tag carries a four-character codec identifier other than hvc1, av01, vp09, or vp08.

## What to check

1. Inspect the enhanced video codec identifier and destination compatibility.

## Recommended action

Use one of the supported enhanced video codec identifiers.
