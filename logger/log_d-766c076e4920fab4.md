# Icecast session waiting for advertisement content

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-766c076e4920fab4

## Log pattern

```text
waiting for content %s, timeout=%d
```

## Parameters

- Argument 1 — Content ID: Text identifier of the pending advertisement.
- Argument 2 — Wait timeout: Integer advertising-content wait timeout in seconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waiting for content ad-01, timeout=5
```

## Short description

Icecast session waiting for advertisement content.

## Trigger condition

An Icecast advertisement is not yet ready and observer registration succeeds.

## Explanation

A timeout timer is installed and output waits for readiness or the configured timeout action.

## Possible causes

- An Icecast advertisement is not yet ready and observer registration succeeds.

## What to check

1. If waits are frequent, check the advertisement download and the configured wait and error action.

## Recommended action

If waits are frequent, check the advertisement download and the configured wait and error action.
