# Renewed Transcoder license could not be saved

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-658f5a7f6e809429

## Log pattern

```text
cannot update transcoder license file! Fix this ASAP
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot update transcoder license file! Fix this ASAP
```

## Short description

Renewed Transcoder license could not be saved.

## Trigger condition

After updating the in-memory expiration and signature, opening the license file for output fails.

## Explanation

The updated expiration remains in memory, but the new license is not persisted and the remembered file modification time is not refreshed.

## Possible causes

- The license file cannot be opened for writing.

## What to check

1. Check write access to the license file and its parent directory.

## Recommended action

Restore write access so renewed license information can be persisted.
