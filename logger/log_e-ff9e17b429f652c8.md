# TLS protocol name is unrecognized

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-ff9e17b429f652c8

## Log pattern

```text
unknown SSL protocol '%s'
```

## Parameters

- Argument 1 — Protocol: Unrecognized protocol-list item, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown SSL protocol 'TLSv9'
```

## Short description

TLS protocol name is unrecognized.

## Trigger condition

A space-separated protocol-list item does not match SSLv2, SSLv3, TLSv1, TLSv1.1, TLSv1.2, or TLSv1.3 when that version is compiled in.

## Explanation

Protocol-list processing stops and configuration loading fails. The partially constructed protocol mask is still stored.

## Possible causes

- The list includes an unknown or unavailable protocol name.

## What to check

1. Check spelling and whether the build includes the requested protocol option.

## Recommended action

Use protocol names supported by the build.
