# DRMToday CAS ticket received

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-a8677f36b2a0bc82

## Log pattern

```text
[drm] response for='%s' from DRMToday (get cas ticket) server: %s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — HTTP response details: Text containing the HTTP status and optional response body; empty when no response parser exists.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] response for='live/camera' from DRMToday (get cas ticket) server: status=503 body='unavailable'
```

## Short description

DRMToday CAS ticket received.

## Trigger condition

The ticket response body is nonempty and current application DRM settings exist.

## Explanation

The ticket is cached for the asset and the DRM key request begins.

## Possible causes

- The ticket response body is nonempty and current application DRM settings exist.
