# Connection session deletion begins

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-38060ef446ed66f2

## Log pattern

```text
delete session=%p
```

## Parameters

- Argument 1 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
delete session=0x1000
```

## Short description

Connection session deletion begins.

## Trigger condition

An HTTP worker is deleting a session, or the advertising download worker is deleting a finished or inactive session.

## Explanation

The HTTP worker removes any custom timeout before deletion. Advertising cleanup removes its descriptor mapping. This message precedes destruction and does not prove it succeeded.
