# HLS audio part is ready for publication

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_d
Log level: debug
Documentation ID: log_d-84a61d978a50ec76

## Log pattern

```text
add HLS part app='%s' stream='%s' duration=%llu.%llu start=%llu key='%s'
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Duration seconds: Whole seconds of the chunk or part duration.
- Argument 4 — Duration remainder: Remaining milliseconds, printed without zero padding; the dot-separated pair is not necessarily a decimal fraction.
- Argument 5 — Start time: Part start timestamp in 90 kHz ticks.
- Argument 6 — Key URL: Encryption-key URL returned by preparation, possibly empty.

## Log examples

Illustrative examples; these are not captured server logs.

```text
add HLS part app='live' stream='camera' duration=2.500 start=900000 key=''
```

## Short description

HLS audio part is ready for publication.

## Trigger condition

Encryption preparation succeeds and a completed audio part is about to be added to the HLS output.

## Explanation

The output receives the clear or encrypted bytes according to the encryption result. An empty key URL is possible for clear output.

## Possible causes

- Encryption preparation succeeds and a completed audio part is about to be added to the HLS output.

## What to check

1. Use the stream, start time, duration, and key URL to correlate output segment production.

## Recommended action

No action is needed for expected segment production.
