# Remote log reporting cannot open its connection

Product: Nimble Streamer
Component: Remote log reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-1da4f51e45c7368d

## Log pattern

```text
cannot open socket to api handler
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot open socket to api handler
```

## Short description

Remote log reporting cannot open its connection.

## Trigger condition

Remote reporting is enabled and opening the connection to the configured panel host and port returns an invalid socket.

## Explanation

Reporting settings are reset to disabled and queued records are cleared. The thread remains alive. The underlying connection failure is not identified by this message.

## Possible causes

- The connection helper could not open a socket to the configured panel endpoint.

## What to check

1. Check the panel host and port used by remote reporting.
