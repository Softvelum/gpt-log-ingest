# Internal HTTP request submission received

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-c4c98fc49998b84f

## Log pattern

```text
WorkerThread::SendHttpRequest url='%s' requestor=%p
```

## Parameters

- Argument 1 — URL: Requested resource URL as text.
- Argument 2 — Request recipient: Address of the component waiting for the HTTP request result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WorkerThread::SendHttpRequest url='https://origin.example/media' requestor=0x2000
```

## Short description

Internal HTTP request submission received.

## Trigger condition

An HTTP request object and its result recipient are submitted to the worker.

## Explanation

After validating request-processing setup, URL and recipient, the request is queued for later session creation. This message precedes that validation.
