# Scenario video codec is unsupported

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-90da833dff45978f

## Log pattern

```text
unsupported video codec=%d stream=%s/%s scenario=%s
```

## Parameters

- Argument 1 — Codec: Numeric video codec identifier, integer; no unit.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.
- Argument 4 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video codec=999 stream=live/camera scenario=scenario1
```

## Short description

Scenario video codec is unsupported.

## Trigger condition

The child sends video codec information with an identifier outside the supported set.

## Explanation

The codec message is rejected, connection processing fails and the scenario controller is removed. Supported video codecs on this message path are H.264, HEVC, MPEG-2 video, VP6, VP8, VP9 and AV1.

## Possible causes

- The child announces an unsupported or invalid video codec identifier.

## What to check

1. Check the reported codec and consistency of the parent and scenario transcoder installations.

## Recommended action

Select a supported output codec and use matching parent and child versions.
