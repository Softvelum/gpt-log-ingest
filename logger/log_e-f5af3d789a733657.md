# File audio codec is unsupported

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f5af3d789a733657

## Log pattern

```text
unsupported audio format: %d [%s]
```

## Parameters

- Argument 1 — Codec: FFmpeg codec identifier, integer enumeration value; no unit.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audio format: 86019 [live/camera]
```

## Short description

File audio codec is unsupported.

## Trigger condition

File-stream decoder selection receives a codec other than AAC or MP3.

## Explanation

No decoder is configured for the file track and the audio worker stops processing.

## Possible causes

- The selected file audio track uses a codec outside this file-decoder selection path.

## What to check

1. Check the selected track and reported FFmpeg codec identifier.

## Recommended action

Use an AAC or MP3 file audio track or another supported input path.
