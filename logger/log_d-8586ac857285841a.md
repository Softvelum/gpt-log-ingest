# Advertising repackaging subscription removal requested

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-8586ac857285841a

## Log pattern

```text
[WrkT::RemAdsTmxRO] request_id='%d' session=%p
```

## Parameters

- Argument 1 — Request identifier: Unsigned 32-bit advertising repackaging request identifier displayed with a signed conversion.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

The request identifier is unsigned; values outside the signed range may appear negative.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::RemAdsTmxRO] request_id='42' session=0x1000
```

## Short description

Advertising repackaging subscription removal requested.

## Trigger condition

The worker is asked to stop observing an advertising repackaging request.

## Explanation

The upstream observer is cleared first, then the request entry is removed from the waiting map if found.
