# VPX default configuration could not be obtained

Product: Nimble Streamer
Component: VP8 and VP9 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-525d6d10ecf4c164

## Log pattern

```text
failed to get default enc config: %s
```

## Parameters

- Argument 1 — Codec error: libvpx description of the returned error, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get default enc config: Invalid parameter
```

## Short description

VPX default configuration could not be obtained.

## Trigger condition

libvpx returns a non-success status while requesting default settings for the selected VP8 or VP9 encoder.

## Explanation

Initialization fails before frame dimensions and user settings are applied.

## Possible causes

- The loaded library cannot supply the selected codec default configuration.

## What to check

1. Check the error description and codec-library compatibility.

## Recommended action

Restore a working compatible libvpx library and restart encoding.
