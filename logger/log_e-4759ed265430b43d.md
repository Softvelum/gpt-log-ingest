# HTTP authorization request identifier already pending

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_e
Log level: error
Documentation ID: log_e-4759ed265430b43d

## Log pattern

```text
failed to add pending auth request with request_id=%lu for s=%d
```

## Parameters

- Argument 1 — Authorization request identifier: External authorization request identifier, unsigned 64-bit integer displayed in decimal; no unit.
- Argument 2 — Connection identifier: HTTP/2 socket descriptor or HTTP/3 session index, integer; no unit.

Occurrences cover SLDP CONNECT authorization, ordinary new playback-session authorization, and WHEP playback authorization.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add pending auth request with request_id=42 for s=12
```

## Short description

HTTP authorization request identifier already pending.

## Trigger condition

An external authorization request returns a nonzero identifier that cannot be inserted because the connection already tracks that identifier.

## Explanation

The authorization request is discarded, the new request stream entry is erased, and request handling reports failure.

## Possible causes

- An authorization request identifier is reused while still pending on this connection.

## What to check

1. Correlate the request identifier with nearby authorization starts and completions.

## Recommended action

Investigate repeated identifier collisions in authorization processing; clients may need to retry.
