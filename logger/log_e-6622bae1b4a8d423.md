# Configuration parameter was not accepted

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-6622bae1b4a8d423

## Log pattern

```text
invalid parameter name: %s
```

## Parameters

- Argument 1 — Setting: Configuration setting name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter name: ffmpeg_log_level
```

## Short description

Configuration parameter was not accepted.

## Trigger condition

A parameter is unmatched by a nested parameter handler, or that handler rejects its value.

## Explanation

The outer handler reports failure and the loader stops. A recognized setting with an invalid value can therefore also produce this parameter-name diagnostic.

## Possible causes

- The parameter is unknown in this build, or its value failed validation.

## What to check

1. Check earlier value-specific messages as well as the setting name and build support.

## Recommended action

Correct the setting name or rejected value.
