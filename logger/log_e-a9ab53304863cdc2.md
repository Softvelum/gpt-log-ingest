# Postponed VOD output lost its required input

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-a9ab53304863cdc2

## Log pattern

```text
dropped VOD transmuxer request key='%s' as item key='%s' fragment=%u request is failed
```

## Parameters

- Argument 1 — Output cache key: Text cache key reserved for the requested generated output.
- Argument 2 — Dependency key: Text key of the failed or missing input item.
- Argument 3 — Required fragment: Unsigned 32-bit zero-based fragment index; 4294967295 means a whole-item dependency with no fragment index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dropped VOD transmuxer request key='/vod/movie.mp4/n_0_0_0.ts' as item key='/vod/movie.mp4' fragment=1 request is failed
```

## Short description

Postponed VOD output lost its required input.

## Trigger condition

A dependency cache notification is processed but the input item is missing or the awaited fragment is marked failed.

## Explanation

The request is dropped from further processing; if its output item still exists, the worker attempts to mark it canceled with a transmuxing-failure reason.

## Possible causes

- A dependency cache notification is processed but the input item is missing or the awaited fragment is marked failed.

## What to check

1. Inspect the dependency download or initialization failure and cache eviction before the notification.

## Recommended action

Inspect the dependency download or initialization failure and cache eviction before the notification.
