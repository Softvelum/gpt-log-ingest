# RTMP advertising content is not ready

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-701c9bc76b6e4d84

## Log pattern

```text
s=%d, failed to load cache item for content %s
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Content URI: Configured URI of the selected advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, failed to load cache item for content https://media.example/ad.mp4
```

## Short description

RTMP advertising content is not ready.

## Trigger condition

A selected advertising item is not ready when playback reaches its loading phase.

## Explanation

The sender next either waits for eligible remote content, skips the item under its error policy, or stops playback. This message alone does not distinguish those outcomes.

## Possible causes

- A selected advertising item is not ready when playback reaches its loading phase.

## What to check

1. Check subsequent wait/skip/stop messages, content availability, and its loading status.

## Recommended action

Make the advertising media available and valid before its scheduled insertion.
