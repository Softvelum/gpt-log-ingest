# AAC packet could not be fed to decoder

Product: Nimble Streamer
Component: FDK AAC audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-093a6cb7628094ce

## Log pattern

```text
failed to feed libfdk decoder [%s] e=%x
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to feed libfdk decoder [live/camera] e=1
```

## Short description

AAC packet could not be fed to decoder.

## Trigger condition

In an FDK-enabled build, the library refuses to consume packet bytes.

## Explanation

The packet write reports failure.

## Possible causes

- The decoder or sample-handling operation described by the message failed.

## What to check

1. Check the AAC input parameters and accompanying decoder diagnostics.

## Recommended action

Resolve the indicated AAC decode or output-frame failure.
