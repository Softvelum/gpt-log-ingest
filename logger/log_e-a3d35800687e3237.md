# Could not create the remote log reporting worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-a3d35800687e3237

## Log pattern

```text
failed to create LOGGER thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Could not create the remote log reporting worker.

## Trigger condition

The remote log reporting worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the remote log reporting worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed remote log reporting worker.
