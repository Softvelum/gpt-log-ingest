# File media packet decoding failed

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-02817956e2a8d074

## Log pattern

```text
failed to decode packet for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

Shared by audio and video file decoding. The video path refreshes APNG or GIF decoder settings before decoding the packet.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode packet for [live/camera]
```

## Short description

File media packet decoding failed.

## Trigger condition

The selected audio or video decoder returns failure for a packet read from its file stream.

## Explanation

The corresponding decoder worker stops processing.

## Possible causes

- The decoder rejects the packet, fails setup or allocation, or cannot deliver its output.

## What to check

1. Check the preceding codec and output diagnostics and verify file integrity.

## Recommended action

Correct the reported decoder or downstream failure and restart the file pipeline.
