# AV1 forwarding configuration failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-15e61d661975bb1a

## Log pattern

```text
failed to set av1 codec params for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

In the separate transcoder process, this codec setter queues its configuration and returns success unconditionally, so this guard ordinarily applies to in-process output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set av1 codec params for [live/encoded]
```

## Short description

AV1 forwarding configuration failed.

## Trigger condition

Applying AV1 parameters from the live input sequence header to the output stream returns failure.

## Explanation

Compressed video forwarding cannot continue with this sequence header.

## Possible causes

- The destination is closed, the AV1 configuration cannot be parsed, or output header buffers cannot be prepared.

## What to check

1. Check preceding codec-configuration diagnostics and the publisher sequence header.

## Recommended action

Correct the input codec configuration or destination setup and restart forwarding.
