# Cache fragment failure status updated

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-5ca68f5b3728d933

## Log pattern

```text
SetFragmentFailed key='%s' from=%llu to=%llu f=%d
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — from: First byte offset, used to select the fragment.
- Argument 3 — to: Ending byte offset recorded for diagnostics.
- Argument 4 — failed: 1 marks failure; 0 clears failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SetFragmentFailed key='movie' from=0 to=1048576 f=1
```

## Short description

Cache fragment failure status updated.

## Trigger condition

A byte range is submitted to change its fragment failure flag.

## Explanation

The starting offset selects the fragment. A true failure flag also notifies cache observers; clearing it does not.
