# Windows service is entering its running state

Product: Nimble Streamer
Component: Windows service
Logging function: log_i
Log level: info
Documentation ID: log_i-e76e988b31b112eb

## Log pattern

```text
service running
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
service running
```

## Short description

Windows service is entering its running state.

## Trigger condition

The service control handler was registered successfully on Windows.

## Explanation

A running state is submitted to the operating system and the server is then initialized and run. The message precedes server initialization, so it does not establish that all services are ready.
