# Transcription settings file content unavailable

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-274888af08c4732a

## Log pattern

```text
failed to load transcriber config '%s'
```

## Parameters

- Argument 1 — File: Configured transcription settings path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load transcriber config '/data/transcription.json'
```

## Short description

Transcription settings file content unavailable.

## Trigger condition

Reading the settings file fails, or the caller receives empty content from the file-loading step.

## Explanation

File-based settings are unavailable. Parameter loading can still proceed with WMSPanel settings when supplied; otherwise it fails. The same failure may be logged at both reading and caller stages.

## Possible causes

- Reading the settings file fails, or the caller receives empty content from the file-loading step.

## What to check

1. Check file existence, readability, and whether it contains nonempty JSON settings.

## Recommended action

Restore the intended readable settings content.
