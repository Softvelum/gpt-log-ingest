# MP3 variable bitrate quality was rejected

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-140b1805fe38bad6

## Log pattern

```text
failed to set vbr_quality=%d, status=%d
```

## Parameters

- Argument 1 — Quality: Variable-bitrate quality value, integer; the local parser accepts 0 through 10.
- Argument 2 — Status: LAME return status, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set vbr_quality=4, status=-1
```

## Short description

MP3 variable bitrate quality was rejected.

## Trigger condition

In a LAME-enabled build, applying variable bitrate quality returns a nonzero status.

## Explanation

Encoder initialization stops and the audio-frame write reports failure.

## Possible causes

- LAME rejected variable bitrate quality.

## What to check

1. Check the variable-bitrate quality setting and the returned LAME status.

## Recommended action

Correct the rejected MP3 encoder setting.
