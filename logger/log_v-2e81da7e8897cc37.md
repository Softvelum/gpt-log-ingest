# HTTP session exceeded its inactivity limit

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_v
Log level: verbose
Documentation ID: log_v-2e81da7e8897cc37

## Log pattern

```text
closing inactive session=%p last activity time=%llu current time=%llu
```

## Parameters

- Argument 1 — Session: Connection-session address used for diagnostic correlation.
- Argument 2 — Last activity: Last activity time in seconds since the system epoch, converted to unsigned 64-bit.
- Argument 3 — Current time: Current wall-clock time in the same units, converted to unsigned 64-bit.

The 64-bit arguments are formatted as unsigned long long; the underlying integer type depends on the build.

## Log examples

Illustrative examples; these are not captured server logs.

```text
closing inactive session=0x1000 last activity time=100 current time=160
```

## Short description

HTTP session exceeded its inactivity limit.

## Trigger condition

At a periodic inactivity check, elapsed wall-clock time since the session activity reaches the configured client inactivity timeout.

## Explanation

The session is deleted. Checks occur after at least five seconds have elapsed since the previous inactivity scan.

## Possible causes

- No qualifying session activity occurred within the configured timeout.

## What to check

1. Compare the displayed times with the configured inactivity timeout.
