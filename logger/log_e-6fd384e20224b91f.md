# URL decryption initialization failed

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-6fd384e20224b91f

## Log pattern

```text
EVP_DecryptInit_ex() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
EVP_DecryptInit_ex() failed
```

## Short description

URL decryption initialization failed.

## Trigger condition

During encrypted-link validation, initializing AES-128-CBC with the session key and decoded vector fails.

## Explanation

Validation returns failure and no URL is assigned.

## Possible causes

- The cryptographic library reports that the cipher setup rejected the key or vector context.

## What to check

1. Check matching encrypted-link data and session key, and available cryptographic library operations.

## Recommended action

Resolve the failed decryption or digest operation before accepting the link.
