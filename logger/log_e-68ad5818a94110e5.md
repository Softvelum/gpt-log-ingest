# URL decryption context allocation failed

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-68ad5818a94110e5

## Log pattern

```text
EVP_CIPHER_CTX_new() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
EVP_CIPHER_CTX_new() failed
```

## Short description

URL decryption context allocation failed.

## Trigger condition

During encrypted-link validation, allocating the cipher context returns no context.

## Explanation

Validation returns failure and no URL is assigned.

## Possible causes

- The cryptographic library reports that the cipher context could not be allocated.

## What to check

1. Check matching encrypted-link data and session key, and available cryptographic library operations.

## Recommended action

Resolve the failed decryption or digest operation before accepting the link.
