# DASH or fragmented MP4 HLS cache reservation fails

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-f881c33c4884b1c4

## Log pattern

```text
failed to reserve item key='%s'
```

## Parameters

- Argument 1 — Cache key: Application/stream path and generated segment or part name used as the cache identity.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to reserve item key='/live/camera/v_100_0.m4s'
```

## Short description

DASH or fragmented MP4 HLS cache reservation fails.

## Trigger condition

The cache cannot reserve the generated DASH media/subtitle segment or fragmented MP4 HLS segment/part key.

## Explanation

This item is not published. DASH media finalizes timing and resets its segment builder before returning; DASH subtitles and HLS return without attaching the item. Reservation can fail because the key already exists or a cache-item allocation fails.

## Possible causes

- The cache cannot reserve the generated DASH media/subtitle segment or fragmented MP4 HLS segment/part key.

## What to check

1. Check the key for a collision and accompanying cache allocation messages.

## Recommended action

Resolve the cache-key conflict or allocation failure.
