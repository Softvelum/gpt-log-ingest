# Cannot add Windows performance counter

Product: Nimble Streamer
Component: Windows system statistics
Logging function: log_d
Log level: debug
Documentation ID: log_d-6e3fb7840f8d0f31

## Log pattern

```text
PdhAddEnglishCounter failed status=%#x
```

## Parameters

- Argument 1 — Status: Windows performance-counter status code in hexadecimal.

The Windows status type is unsigned long; the hexadecimal conversion uses unsigned int. These have the same 32-bit width on Windows.

## Log examples

Illustrative examples; these are not captured server logs.

```text
PdhAddEnglishCounter failed status=0xc0000bc6
```

## Short description

Cannot add Windows performance counter.

## Trigger condition

Adding the total CPU-time or paging-file-usage counter to a new query fails.

## Explanation

The current metric call returns zero instead of a measured value. The query is closed and a later call can retry initialization. This diagnostic is Windows-only.

## Possible causes

- Adding the total CPU-time or paging-file-usage counter to a new query fails.

## What to check

1. Inspect the Windows performance-counter status and whether system metrics remain zero.
