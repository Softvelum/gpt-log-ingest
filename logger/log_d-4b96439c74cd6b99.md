# Zixi API request prepared

Product: Nimble Streamer
Component: Zixi integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-4b96439c74cd6b99

## Log pattern

```text
send zixi request: url=%s
```

## Parameters

- Argument 1 — URL: Complete local Zixi API request URL, including query parameters when present.

## Log examples

Illustrative examples; these are not captured server logs.

```text
send zixi request: url=http://localhost:4444/zixi/streams.json
```

## Short description

Zixi API request prepared.

## Trigger condition

A local Zixi API GET URL has been constructed, immediately before request submission.

## Explanation

The request uses configured API credentials and a two-second timeout. The log precedes submission and does not confirm that the API received it.

## Possible causes

- A local Zixi API GET URL has been constructed, immediately before request submission.

## What to check

1. Check the local API port, path, and query parameters.
