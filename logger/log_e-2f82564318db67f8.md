# No supported transcription provider selected

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-2f82564318db67f8

## Log pattern

```text
failed to transcribe stream=[%s/%s], invalid params
```

## Parameters

- Argument 1 — application: Application name.
- Argument 2 — stream: Stream name within the application.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to transcribe stream=[live/camera], invalid params
```

## Short description

No supported transcription provider selected.

## Trigger condition

Transcriber initialization reaches the end without entering a provider branch supported by this build.

## Explanation

No transcriber request queue is assigned. This can indicate a provider selection incompatible with the compiled transcription support; ordinary live stream registration continues.

## Possible causes

- The selected provider has no matching enabled provider branch.

## What to check

1. Check the provider selection and compiled transcription support.

## Recommended action

Select a provider supported by this build.
