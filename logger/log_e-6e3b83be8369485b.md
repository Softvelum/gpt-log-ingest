# DVR AAC silence sample is unavailable

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-6e3b83be8369485b

## Log pattern

```text
failed to get aac silence sample, channels=%d
```

## Parameters

- Argument 1 — Channels: Integer recorded AAC channel configuration.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get aac silence sample, channels=8
```

## Short description

DVR AAC silence sample is unavailable.

## Trigger condition

No prebuilt AAC silence sample can be obtained for the recorded channel configuration.

## Explanation

The mute operation returns failure.

## Possible causes

- No prebuilt AAC silence sample can be obtained for the recorded channel configuration.

## What to check

1. Check whether the recorded channel configuration has a supported silence sample.

## Recommended action

Check whether the recorded channel configuration has a supported silence sample.
