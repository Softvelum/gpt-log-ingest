# Unexpected Icecast state after sending response

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-9e99013ca6475602

## Log pattern

```text
invalid state=%d for client: %d
```

## Parameters

- Argument 1 — State: Numeric internal session-state value.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid state=0 for client: 42
```

## Short description

Unexpected Icecast state after sending response.

## Trigger condition

A complete response or request is sent while the session state is outside the expected publishing, authentication, pull-request, or metadata-response states.

## Explanation

The session is shut down.

## Possible causes

- A complete response or request is sent while the session state is outside the expected publishing, authentication, pull-request, or metadata-response states.

## What to check

1. Check preceding connection events and state transitions.
