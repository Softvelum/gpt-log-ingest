# WHEP playback fell behind retained media

Product: Nimble Streamer
Component: WHEP media delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-8795a9c0cdd20568

## Log pattern

```text
failed to send buffer in appropriate rate for whep session=%s
```

## Parameters

- Argument 1 — Playback session URL: Relative WHEP session deletion URL including its session signature, text; identifies this playback session.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer in appropriate rate for whep session=/live/camera/whep.stream?whepsign=example-session
```

## Short description

WHEP playback fell behind retained media.

## Trigger condition

The next requested media item is older than the oldest item retained in the source stream buffer.

## Explanation

The worker removes the session from active playback, marks it aborted, stops socket monitoring, and releases its helper media connection.

## Possible causes

- The playback delivery path has fallen behind enough for unread media to be overwritten.

## What to check

1. Check helper delivery throughput and whether processing stalls or stream bitrate exceed the playback path capacity.

## Recommended action

Restore delivery capacity or reduce the selected stream bitrate before reconnecting.
