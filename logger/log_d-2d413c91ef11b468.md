# RTMP advertising state is invalid

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-2d413c91ef11b468

## Log pattern

```text
s=%d, unknown ad_state=%d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — State: Numeric internal advertising-state value that did not match a supported phase.

## Log examples

No reachable illustrative value is established: all declared advertising phases are handled, and normal transitions only assign those phases.

## Short description

RTMP advertising state is invalid.

## Trigger condition

Playback encounters an advertising state outside all defined phases.

## Explanation

The sender returns failure and the connection is shut down. The current normal transitions only assign handled phases.

## Possible causes

- Playback encounters an advertising state outside all defined phases.

## What to check

1. Check the preceding advertising transitions and content events.

## Recommended action

Report the unexpected internal advertising state to support.
