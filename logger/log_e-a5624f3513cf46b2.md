# AVC NAL length field width is unsupported

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-a5624f3513cf46b2

## Log pattern

```text
[VM] NALU unit size not supported %d, [%s/%s]
```

## Parameters

- Argument 1 — Length width: NAL-unit length field width in bytes; this branch prints 3.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] NALU unit size not supported 3, [live/camera]
```

## Short description

AVC NAL length field width is unsupported.

## Trigger condition

The AVC configuration selects a three-byte NAL-unit length field.

## Explanation

An empty transport header is ensured and AVC setup fails; one-, two-, and four-byte lengths are not rejected by this check.

## Possible causes

- The AVC configuration selects a three-byte NAL-unit length field.

## What to check

1. Check the configured NAL length field width in the AVC sequence header.

## Recommended action

Use a supported NAL length field width.
