# Encoder keyframe submission counter reported

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-7a834902f2285fa9

## Log pattern

```text
debugWriteVideoKeyFrame for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
debugWriteVideoKeyFrame for [live/encoded]
```

## Short description

Encoder keyframe submission counter reported.

## Trigger condition

Encoder debug logging is enabled and keyframe-write attempts since the last report exceed 25.

## Explanation

The counter resets and the requested keyframe is then submitted; this message does not prove submission success.
