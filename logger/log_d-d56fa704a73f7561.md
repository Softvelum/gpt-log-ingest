# Transport restreaming buffer is destroyed

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-d56fa704a73f7561

## Log pattern

```text
restreaming buffer removed for cam=%s
```

## Parameters

- Argument 1 — Camera ID: Transport input camera identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
restreaming buffer removed for cam=camera1
```

## Short description

Transport restreaming buffer is destroyed.

## Trigger condition

The restreaming buffer for this camera is being destroyed.

## Explanation

Its retained packet storage is released with the object.

## Possible causes

- The restreaming buffer for this camera is being destroyed.

## What to check

1. Check whether the camera or restreaming consumer was removed.

## Recommended action

No action is needed for expected cleanup.
