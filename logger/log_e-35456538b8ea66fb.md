# Advertising redirect connection failed

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-35456538b8ea66fb

## Log pattern

```text
redirect failed, delete session=%p
```

## Parameters

- Argument 1 — Session address: Pointer identifying the session in this process.

## Log examples

Illustrative examples; these are not captured server logs.

```text
redirect failed, delete session=0x1234
```

## Short description

Advertising redirect connection failed.

## Trigger condition

The download worker attempts a requested redirect and receives an invalid connection descriptor.

## Explanation

The failed download session is deleted.

## Possible causes

- The download worker attempts a requested redirect and receives an invalid connection descriptor.

## What to check

1. Check the redirect destination and the preceding connection failure.

## Recommended action

Check the redirect destination and the preceding connection failure.
