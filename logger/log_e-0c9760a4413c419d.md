# Cache loading raised an exception

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-0c9760a4413c419d

## Log pattern

```text
std::exception caught while loading cache what()='%s'
```

## Parameters

- Argument 1 — Exception detail: Text supplied by the caught exception.

## Log examples

Illustrative examples; these are not captured server logs.

```text
std::exception caught while loading cache what()='cache read failed'
```

## Short description

Cache loading raised an exception.

## Trigger condition

A standard exception escapes cache compatibility checking or initial loading at startup, or a later background cache-loading step.

## Explanation

The diagnostic is reported and execution continues. Startup proceeds to create services; the background loader rechecks whether loading is complete and can continue on later iterations.

## Possible causes

- Cache compatibility checking or loading raised an exception.

## What to check

1. Inspect the exception text and surrounding cache diagnostics.
