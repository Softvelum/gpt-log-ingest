# AAC decoder falls back to FFmpeg

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_i
Log level: info
Documentation ID: log_i-447e9195cf3c2e8b

## Log pattern

```text
libfdk_aac decoder is unavailable, using default audio decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
libfdk_aac decoder is unavailable, using default audio decoder for [live/camera]
```

## Short description

AAC decoder falls back to FFmpeg.

## Trigger condition

The audio decoder option requests libfdk_aac, but the FDK library is unavailable in a build containing that integration.

## Explanation

The worker selects the default FFmpeg AAC decoder and continues.

## Possible causes

- The requested optional FDK library was not loaded.

## What to check

1. Check earlier FDK library-loading messages if that decoder is required.

## Recommended action

Restore the optional library if needed; otherwise the fallback requires no action.
