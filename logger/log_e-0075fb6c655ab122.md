# Icecast metadata update mode unsupported

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-0075fb6c655ab122

## Log pattern

```text
invalid icecast metadata mode, url=%s, client=%d
```

## Parameters

- Argument 1 — URL: Received metadata-update URL.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid icecast metadata mode, url=/admin/metadata?mount=live/radio&mode=other, client=42
```

## Short description

Icecast metadata update mode unsupported.

## Trigger condition

The metadata-update URL mode is not updinfo.

## Explanation

The connection is shut down without updating stream metadata.

## Possible causes

- The metadata-update URL mode is not updinfo.

## What to check

1. Check the mode query parameter.

## Recommended action

Use mode=updinfo for this update endpoint.
