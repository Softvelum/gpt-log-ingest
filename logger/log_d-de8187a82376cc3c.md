# Automatic audio packet selected

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-de8187a82376cc3c

## Log pattern

```text
updateAvailable audio type implicitly set found pid=%d type=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.
- Argument 2 — stream\_type: Numeric media stream-type code printed in decimal; this is not a packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable audio type implicitly set found pid=256 type=15
```

## Short description

Automatic audio packet selected.

## Trigger condition

No explicit audio packet is configured, no active identifier is selected, and the effective default identifier is nonzero.

## Explanation

The default identifier is selected, added to the requested input set, and its advertised media type is stored. A configured zero-based media index can replace the input default before this branch. For LATM audio with probing enabled, the actual audio type is left unset until payload probing.
