# Remote media fragment request failed

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_e
Log level: error
Documentation ID: log_e-cb00c8bd0823f095

## Log pattern

```text
key='%s' f=%llu-%llu request failed
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — from: Inclusive starting byte offset.
- Argument 3 — to: Exclusive ending byte offset.

## Log examples

Illustrative examples; these are not captured server logs.

```text
key='https://media.example/movie.mp4' f=0-1048576 request failed
```

## Short description

Remote media fragment request failed.

## Trigger condition

The external request failure callback refers to an established item rather than an initial HEAD or initial download.

## Explanation

The requested fragment is marked failed, the item reference is released, and the active request is deleted. A pending next request is not started here.

## Possible causes

- The external resource request reported failure.

## What to check

1. Check earlier network or response parsing messages for this URL.

## Recommended action

Resolve the origin request failure.
