# Segment remains clear because its rotating key is unavailable

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-baa5f79111a23830

## Log pattern

```text
[drm] Widevine key for '%s/%s' is not available (%s) - keeping unencrypted
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Key availability: Text stating missing when no matching key exists or never updated when its slot has not received a usable key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine key for 'live/camera' is not available (never updated) - keeping unencrypted
```

## Short description

Segment remains clear because its rotating key is unavailable.

## Trigger condition

A common-encryption key is missing or unpopulated while rotation is enabled and clear fallback is allowed.

## Explanation

Segment parameters succeed with no encryption key so the segment can remain unencrypted.

## Possible causes

- A common-encryption key is missing or unpopulated while rotation is enabled and clear fallback is allowed.

## What to check

1. Check provider key delivery and the explicit setting permitting unencrypted output.

## Recommended action

Check provider key delivery and the explicit setting permitting unencrypted output.
