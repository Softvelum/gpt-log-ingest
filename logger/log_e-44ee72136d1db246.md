# Encoded video stream configuration failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-44ee72136d1db246

## Log pattern

```text
failed to set video codec params for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

Five occurrences cover H.264, HEVC, VP8, VP9, and AV1 initialization. Separate-process H.264, VP8, VP9, and AV1 setters queue configuration and return success; HEVC additionally parses and builds its configuration.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set video codec params for [live/encoded]
```

## Short description

Encoded video stream configuration failed.

## Trigger condition

Applying codec parameters when the first encoded H.264, HEVC, VP8, VP9, or AV1 packet initializes its output returns failure.

## Explanation

The encoded packet is not delivered and output processing fails.

## Possible causes

- The output is closed, codec headers are malformed or incomplete, or header and transport-buffer preparation fails. For VP8/VP9 in-process output, the explicit failure condition is a closed destination.

## What to check

1. Check preceding codec-specific header diagnostics and output lifecycle changes.

## Recommended action

Restore valid codec headers and an active destination, then restart encoding.
