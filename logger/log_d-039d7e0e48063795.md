# TLS socket receive failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-039d7e0e48063795

## Log pattern

```text
failed to read from %s ssl=%p s=%d (errno=%d e='%s')
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — TLS session: TLS session address used for diagnostic correlation.
- Argument 3 — Socket: Integer socket descriptor.
- Argument 4 — TLS result: Integer TLS error category returned for the failed operation.
- Argument 5 — TLS detail: Text decoded from the next queued TLS library error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read from origin ssl=0x1000 s=12 (errno=1 e='TLS read error')
```

## Short description

TLS socket receive failed.

## Trigger condition

A TLS read returns a negative result with an error category other than waiting for read or write readiness.

## Explanation

The TLS error is saved and the read result is returned to the caller.

## Possible causes

- The TLS read failed without a retry-for-readiness result.

## What to check

1. Inspect the TLS error category and detail for this socket.
