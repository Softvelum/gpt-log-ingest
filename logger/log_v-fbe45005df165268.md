# Client socket error

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-fbe45005df165268

## Log pattern

```text
kEventError for client s=%d ev=0x%x error=%d
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.
- Argument 3 — Socket error: Integer operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
kEventError for client s=18 ev=0x10 error=111
```

## Short description

Client socket error.

## Trigger condition

A non-TLS client socket reports an error event without a higher-priority input, output, or closure event.

## Explanation

The socket error status is recorded and the session is marked finished.

## Possible causes

- A non-TLS client socket reports an error event without a higher-priority input, output, or closure event.

## What to check

1. Interpret the platform socket error and check whether the client disconnected or the network failed.

## Recommended action

Interpret the platform socket error and check whether the client disconnected or the network failed.
