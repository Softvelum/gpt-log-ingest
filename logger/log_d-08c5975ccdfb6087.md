# Plain socket receive returned an error

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-08c5975ccdfb6087

## Log pattern

```text
failed to recv from %s s=%d (errno=%d)
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Socket: Integer socket descriptor.
- Argument 3 — System error: Integer operating-system socket error value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv from origin s=12 (errno=11)
```

## Short description

Plain socket receive returned an error.

## Trigger condition

A non-TLS receive returns a negative result.

## Explanation

The socket error is saved and the result is returned to the caller. The error can indicate temporary unavailability; this message alone does not establish that the connection is unusable.

## Possible causes

- The socket receive operation returned an error.

## What to check

1. Distinguish a would-block result from a fatal socket error.
