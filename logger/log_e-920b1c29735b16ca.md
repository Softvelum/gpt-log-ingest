# Legacy RTMP video codec is unsupported

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-920b1c29735b16ca

## Log pattern

```text
[VM] wrong codec %d.
```

## Parameters

- Argument 1 — Video codec: Numeric legacy video codec identifier; accepted values are 4 for VP6, 7 for AVC, and 12 for HEVC.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] wrong codec 2.
```

## Short description

Legacy RTMP video codec is unsupported.

## Trigger condition

A legacy video tag uses a codec identifier other than AVC, VP6, or the supported legacy HEVC extension.

## Explanation

The video message is rejected and connection processing fails.

## Possible causes

- A legacy video tag uses a codec identifier other than AVC, VP6, or the supported legacy HEVC extension.

## What to check

1. Check the low four bits of the video tag header and the encoder video codec.

## Recommended action

Use a supported legacy codec or supported enhanced RTMP framing.
