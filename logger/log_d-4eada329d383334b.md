# DVR request resumes after DRM key arrival

Product: Nimble Streamer
Component: DVR playback conversion
Logging function: log_d
Log level: debug
Documentation ID: log_d-4eada329d383334b

## Log pattern

```text
ready to process postponed request for '%s' chunk='%s' key='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Chunk name: Text naming the requested recording resource.
- Argument 3 — Cache key: Text identifying the requested cache output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ready to process postponed request for 'live/camera' chunk='dvr_v_p1_90000.fmp4' key='/live/camera/dvr_v_p1_90000.fmp4'
```

## Short description

DVR request resumes after DRM key arrival.

## Trigger condition

A successful DRM notification matches requests waiting for that stream.

## Explanation

Each postponed request is moved to the ready queue for another processing attempt.

## Possible causes

- A successful DRM notification matches requests waiting for that stream.
