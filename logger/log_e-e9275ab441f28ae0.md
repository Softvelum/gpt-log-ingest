# RTSP SDP found no supported media codec

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-e9275ab441f28ae0

## Log pattern

```text
No Supported Codecs Found, client: %d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No Supported Codecs Found, client: 25
```

## Short description

RTSP SDP found no supported media codec.

## Trigger condition

Media properties exist, but no supported codec branch contributes a media description.

## Explanation

SDP construction returns failure. The separate case with no codec properties available returns an empty description so the sender can wait for media.

## Possible causes

- Media properties exist, but no supported codec branch contributes a media description.

## What to check

1. Check whether the live stream provides a supported RTSP video or audio codec.

## Recommended action

Provide media with a codec accepted by the RTSP output.
