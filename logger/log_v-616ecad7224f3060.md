# HTTP client session created

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-616ecad7224f3060

## Log pattern

```text
cli s=%d ssl=%d
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — TLS enabled: Boolean rendered as 1 when TLS is enabled and 0 otherwise.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cli s=18 ssl=1
```

## Short description

HTTP client session created.

## Trigger condition

A new accepted HTTP connection is assigned a client session.

## Explanation

Request and origin-response buffers are initialized; TLS acceptance is initialized next when enabled.

## Possible causes

- A new accepted HTTP connection is assigned a client session.
