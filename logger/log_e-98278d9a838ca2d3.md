# DVR AAC data arrived before initialization

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-98278d9a838ca2d3

## Log pattern

```text
[AM] aac data MUST follow aac sequence header stream='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] aac data MUST follow aac sequence header stream='live/camera'
```

## Short description

DVR AAC data arrived before initialization.

## Trigger condition

An AAC packet is not a sequence header and the recording context has not initialized AAC.

## Explanation

Audio processing returns failure.

## Possible causes

- An AAC packet is not a sequence header and the recording context has not initialized AAC.

## What to check

1. Ensure the publisher supplies an AAC sequence header before raw audio.

## Recommended action

Ensure the publisher supplies an AAC sequence header before raw audio.
