# TCP socket created

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-5df73467a711276c

## Log pattern

```text
created %s socket s=%d
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Socket: Integer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created origin socket s=12
```

## Short description

TCP socket created.

## Trigger condition

Creating an IPv4 or IPv6 stream socket succeeds.

## Explanation

Nonblocking setup follows; the socket has not yet completed an outbound connection.
