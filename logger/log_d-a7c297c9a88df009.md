# Video encoder timing selected

Product: Nimble Streamer
Component: Video encoder timing
Logging function: log_d
Log level: debug
Documentation ID: log_d-a7c297c9a88df009

## Log pattern

```text
time_base=%d/%d, framerate=%d/%d for [%s]
```

## Parameters

- Argument 1 — Time-base numerator: Timestamp time-base numerator, integer; numerator/denominator is seconds per tick.
- Argument 2 — Time-base denominator: Timestamp time-base denominator, integer; numerator/denominator is seconds per tick.
- Argument 3 — Frame-rate numerator: Frame-rate numerator, integer; numerator/denominator is frames per second.
- Argument 4 — Frame-rate denominator: Frame-rate denominator, integer; numerator/denominator is frames per second.
- Argument 5 — Stream: Output stream name, text.

The values come from the FFmpeg codec context in one occurrence and the x264 encoder parameters in the other.

## Log examples

Illustrative examples; these are not captured server logs.

```text
time_base=1/90000, framerate=25/1 for [live/camera]
```

## Short description

Video encoder timing selected.

## Trigger condition

FFmpeg encoder initialization or x264 parameter setup has selected its timestamp time base and frame rate.

## Explanation

The reported fractions describe the timing supplied to the encoder; codec opening can still fail later.
