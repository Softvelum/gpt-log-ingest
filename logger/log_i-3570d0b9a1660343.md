## Short description

Timecode output needs timestamp-wrap handling.

## Trigger condition

A local output has a positive SEI timecode delay configured while MPEG-TS timestamp-wrap processing is disabled.

## Explanation

The recommendation is logged and timecode sending is still enabled; this is not a startup failure.

## Possible causes

- Delayed timecode output is configured without the timestamp-wrap handling expected to prevent missing audio after a MPEG-TS timestamp wrap.

## What to check

1. Check the MPEG-TS timestamp-wrap processing setting and the configured timecode delay.

## Recommended action

Enable mpeg2ts_timestamp_overrun_processing_enabled when using this delayed timecode output.
