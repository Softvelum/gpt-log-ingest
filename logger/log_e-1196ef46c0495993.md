# VAAPI cannot write overscan metadata

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-1196ef46c0495993

## Log pattern

```text
overscan info not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
overscan info not supported
```

## Short description

VAAPI cannot write overscan metadata.

## Trigger condition

The H.264 sequence settings mark overscan information as present.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested overscan metadata and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
