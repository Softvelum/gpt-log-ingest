# WHEP control interface is not IPv4

Product: Nimble Streamer
Component: WHEP playback helper
Logging function: log_e
Log level: error
Documentation ID: log_e-8c561a54b36b23dc

## Log pattern

```text
invalid parameter webrtc_whep_control_interface value: %s
```

## Parameters

- Argument 1 — Configured interface: Configured helper-listener address text that failed IPv4 parsing.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter webrtc_whep_control_interface value: invalid-address
```

## Short description

WHEP control interface is not IPv4.

## Trigger condition

The configured WHEP control-interface text cannot be converted to an IPv4 address.

## Explanation

The helper listener socket is closed and initialization fails.

## Possible causes

- The configured interface is malformed or is not an IPv4 address.

## What to check

1. Check the webrtc_whep_control_interface value.

## Recommended action

Set a valid local IPv4 address for the WHEP helper listener.
