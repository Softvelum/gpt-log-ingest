## Short description

Scenario main encoding worker failed to start.

## Trigger condition

The main transcoding thread creation operation returns false.

## Explanation

Media and x264 libraries are unloaded, pending logs are given a chance to reach the parent, logging closes, and the process returns failure.

## Possible causes

- The main transcoding thread creation operation returns false.

## What to check

1. Check the encoding worker startup and preceding library diagnostics.
