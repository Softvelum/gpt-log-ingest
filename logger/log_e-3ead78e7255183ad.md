# GPU management mapping disabled automatic assignment

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-3ead78e7255183ad

## Log pattern

```text
failed to get nvml device by uuid, gpu_id=%d, gpu_uuid=%s, err=%d, nvenc gpu auto assigning disabled
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 2 — GPU UUID: CUDA device UUID in canonical hexadecimal text without the GPU- prefix.
- Argument 3 — Management status: NVIDIA management-library result code, integer; no unit.

The status can be success when the fallback search completes but finds no matching device; the absent match still causes this failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get nvml device by uuid, gpu_id=0, gpu_uuid=12345678-1234-1234-1234-123456789abc, err=3, nvenc gpu auto assigning disabled
```

## Short description

GPU management mapping disabled automatic assignment.

## Trigger condition

A CUDA GPU cannot be matched to a management-library device by UUID, including the fallback device search.

## Explanation

The temporary mapping is cleared and automatic load-based GPU assignment is not enabled.

## Possible causes

- The management library cannot enumerate or identify the CUDA device, or no matching UUID is found.

## What to check

1. Compare the GPU UUID with available management-library devices and inspect the result code.

## Recommended action

Restore consistent CUDA and management-device visibility or explicitly select a GPU.
