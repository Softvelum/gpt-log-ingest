# Cannot create SRT output listener

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-136ce4c37dc933a1

## Log pattern

```text
failed to add srt server socket ip=%s port=%d
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add srt server socket ip=0.0.0.0 port=9000
```

## Short description

Cannot create SRT output listener.

## Trigger condition

A new or changed nonempty output listener cannot complete its listen setup.

## Explanation

The listener is not installed and settings synchronization is invalidated so a later pass retries.

## Possible causes

- A new or changed nonempty output listener cannot complete its listen setup.

## What to check

1. Check the local endpoint and preceding bind/listen errors.
