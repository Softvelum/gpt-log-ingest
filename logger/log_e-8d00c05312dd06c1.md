# Waiting for socket events failed

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-8d00c05312dd06c1

## Log pattern

```text
epoll_wait failed for fd=%d errno=%d
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
epoll_wait failed for fd=10 errno=5
```

## Short description

Waiting for socket events failed.

## Trigger condition

Linux event waiting returns an error other than an interrupted system call.

## Explanation

No events are dispatched during this wait invocation.

## Possible causes

- The operating system rejected event waiting.

## What to check

1. Check the monitor descriptor and operating system error.

## Recommended action

Resolve the reported wait failure.
