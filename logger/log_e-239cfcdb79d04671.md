# SRT local bind failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-239cfcdb79d04671

## Log pattern

```text
srt_bind for %s:%d failed, s=%d: %s
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Socket: SRT socket identifier.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_bind for 192.0.2.1:9000 failed, s=100: Cannot bind to the requested address
```

## Short description

SRT local bind failed.

## Trigger condition

The library rejects binding a sender/listener socket or an explicitly configured local endpoint.

## Explanation

Socket connection or listening setup returns failure. The address denotes the local bind endpoint, including a rendezvous/local-interface setting where applicable.

## Possible causes

- The library rejects binding a sender/listener socket or an explicitly configured local endpoint.

## What to check

1. Check whether the local address is available and the port can be bound.
