# Client-IP routing selected a redirect

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-1c02f9468869d9be

## Log pattern

```text
redirecting to '%s'
```

## Parameters

- Argument 1 — Redirect URL: Text absolute destination URL built from the selected target and request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
redirecting to 'http://edge2.example/live/camera/playlist.m3u8'
```

## Short description

Client-IP routing selected a redirect.

## Trigger condition

The client address matches a redirect rule and a new target URL is constructed.

## Explanation

HTTP 302 with this Location is prepared; the media is expected to be requested from the selected target.

## Possible causes

- The client address matches a redirect rule and a new target URL is constructed.

## What to check

1. If the target is unexpected, check the client address used for routing and the matching redirect rule.

## Recommended action

If the target is unexpected, check the client address used for routing and the matching redirect rule.
