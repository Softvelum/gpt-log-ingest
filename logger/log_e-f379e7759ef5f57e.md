# Socket event monitor close failed

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-f379e7759ef5f57e

## Log pattern

```text
close epoll epfd=%d failed (errno=%d)
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
close epoll epfd=10 failed (errno=5)
```

## Short description

Socket event monitor close failed.

## Trigger condition

Closing a positive Linux event-monitor descriptor returns an error.

## Explanation

The stored descriptor is set to an invalid value despite the close error.

## Possible causes

- The operating system rejected the close request.

## What to check

1. Check the monitor descriptor and operating system error.

## Recommended action

Investigate the close error.
