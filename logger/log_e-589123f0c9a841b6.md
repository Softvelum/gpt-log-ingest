# HLS body exceeds its remaining declared length

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-589123f0c9a841b6

## Log pattern

```text
remained_chunk_body_size_=%u received=%u
```

## Parameters

- Argument 1 — remaining\_bytes: Remaining declared body length in bytes, stored as an unsigned 32-bit count.
- Argument 2 — received\_bytes: Current input-buffer usage in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remained_chunk_body_size_=100 received=120
```

## Short description

HLS body exceeds its remaining declared length.

## Trigger condition

Fixed-length body handling sees more buffered bytes than the remaining body count.

## Explanation

The input requests shutdown before subtracting the size or requesting the next item. Media processing may already have seen the buffered data because this length check follows the processing branch.

## Possible causes

- The received buffer contains more bytes than the tracked remaining body length.

## What to check

1. Check the origin Content-Length and actual response body boundaries.

## Recommended action

Correct inconsistent HTTP body lengths.
