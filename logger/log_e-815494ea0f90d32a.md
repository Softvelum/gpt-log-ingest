# MPEG-TS HTTP chunk framing rejected

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-815494ea0f90d32a

## Log pattern

```text
failed to parse chunked buffer from s=%d
```

## Parameters

- Argument 1 — socket: Origin connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse chunked buffer from s=42
```

## Short description

MPEG-TS HTTP chunk framing rejected.

## Trigger condition

The HTTP parser rejects input while receiving a chunked response body.

## Explanation

The input immediately enters the completed shutdown state and returns. This error occurs before decoded HTTP body bytes are passed to MPEG-TS processing.

## Possible causes

- The chunked HTTP response could not be parsed.

## What to check

1. Check chunk-size lines, chunk boundaries, and origin response framing.

## Recommended action

Correct the HTTP chunked response.
