# HTTP response text prepared

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-1d3801eb18387f1b

## Log pattern

```text
client s=%d response:
%s%s
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Header buffer: Text of the response header buffer, sometimes followed by an embedded small body.
- Argument 3 — Separate body: Text of a separate response-body buffer, empty when unused.

## Log examples

Illustrative examples; these are not captured server logs.

```text
client s=18 response:
HTTP/1.1 200 OK
Date: Mon, 28 Sep 2026 12:00:00 GMT
Server: Nimble/3.7.0
Content-Length: 0
Allow: OPTIONS, GET, HEAD
Access-Control-Allow-Methods: OPTIONS, GET, HEAD
Connection: close


```

## Short description

HTTP response text prepared.

## Trigger condition

A playlist, OPTIONS reply, generated MPEG-TS playlist, WebSocket upgrade, shutdown reply, or copied origin reply has been assembled.

## Explanation

The response buffers are logged before sending. A small body can be inside the first buffer; the second buffer can be empty.

## Possible causes

- A playlist, OPTIONS reply, generated MPEG-TS playlist, WebSocket upgrade, shutdown reply, or copied origin reply has been assembled.
