# Hardware frame limit is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-13393342cc9d4a08

## Log pattern

```text
invalid parameter value: %s. should be >= 1 && <=20480
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1 && <=20480
```

## Short description

Hardware frame limit is invalid.

## Trigger condition

While reading configuration, the CUDA, Quick Sync, or Xilinx transcoder frame limit is outside 1 through 20480.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires a frame count from 1 through 20480.

## Recommended action

Correct the value to a frame count from 1 through 20480 and reload configuration.
