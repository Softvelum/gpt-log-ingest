# AJA output circulation status could not be read

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-b68f49fa604c8a62

## Log pattern

```text
playback failed device=%s/%d reason='AutoCirculate status failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback failed device=0/0 reason='AutoCirculate status failed'
```

## Short description

AJA output circulation status could not be read.

## Trigger condition

Waiting for an available output frame cannot obtain device circulation status.

## Explanation

The wait returns failure, preventing transfer of the pending video frame.

## Possible causes

- Waiting for an available output frame cannot obtain device circulation status.

## What to check

1. Check device access and output circulation state.
