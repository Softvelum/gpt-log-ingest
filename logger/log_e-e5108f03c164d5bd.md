# AAC sequence header is too short

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e5108f03c164d5bd

## Log pattern

```text
wrong aac seq header %d, [%s/%s]
```

## Parameters

- Argument 1 — Header size: Total AAC sequence-header message size, unsigned byte count printed in decimal.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wrong aac seq header 1, [live/camera]
```

## Short description

AAC sequence header is too short.

## Trigger condition

The live AAC sequence header contains fewer than two bytes.

## Explanation

The header is rejected before extracting the AAC configuration and updating decoder outputs.

## Possible causes

- The input AAC configuration message is truncated.

## What to check

1. Check the publisher sequence header and RTMP audio framing.

## Recommended action

Provide a complete AAC configuration message and restart the input.
