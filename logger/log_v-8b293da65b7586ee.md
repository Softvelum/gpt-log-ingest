# External HTTP request prepared

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-8b293da65b7586ee

## Log pattern

```text
peer s=%d request:
%s
```

## Parameters

- Argument 1 — socket: Peer socket descriptor.
- Argument 2 — request: Prepared request headers and, when enabled, request body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
peer s=12 request:
GET /movie.mp4 HTTP/1.1
Host: media.example
User-Agent: Nimble


```

## Short description

External HTTP request prepared.

## Trigger condition

A newly connected or resumed peer has its HTTP request assembled.

## Explanation

The request has not yet been sent. The body is included in this diagnostic only when body logging is enabled; otherwise it is appended after the message.
