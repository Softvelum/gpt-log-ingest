# Automatic GPU selection cannot read encoder load

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-de7849f913b58290

## Log pattern

```text
failed to get encoder utilization for gpu=%d, err=%d
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 2 — Management status: NVIDIA management-library result code, integer; no unit.

Encoder load is queried for encoder selection and FFmpeg decoder selection. Decoder load is queried for native and FFmpeg decoder selection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get encoder utilization for gpu=0, err=3
```

## Short description

Automatic GPU selection cannot read encoder load.

## Trigger condition

An automatic GPU selection pass fails to query encoder utilization for one of its mapped devices.

## Explanation

Selection returns GPU zero immediately instead of completing load comparison; this message does not itself disable future selection attempts.

## Possible causes

- The management library cannot retrieve current encoder utilization.

## What to check

1. Check the reported GPU and management status, and preceding driver/device messages.

## Recommended action

Restore utilization queries or select a GPU explicitly.
