# SLDP command is not valid JSON

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-d4b88f7641591c57

## Log pattern

```text
error parsing json'%s'
```

## Parameters

- Argument 1 — Received text: Full text submitted to the JSON parser.

## Log examples

Illustrative examples; these are not captured server logs.

```text
error parsing json'{"command":'
```

## Short description

SLDP command is not valid JSON.

## Trigger condition

JSON parsing fails during initial Play, Cancel, or subsequent command dispatch.

## Explanation

Command handling fails and the playback connection is closed through the caller.

## Possible causes

- JSON parsing fails during initial Play, Cancel, or subsequent command dispatch.

## What to check

1. Check JSON syntax and completeness in the supplied message.

## Recommended action

Send valid JSON commands from the player.
