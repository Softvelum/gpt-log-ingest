# Caption SEI rendering fails

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-6a8216f28e9a179e

## Log pattern

```text
failed render sei nalu for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed render sei nalu for [live/camera]
```

## Short description

Caption SEI rendering fails.

## Trigger condition

The caption SEI renderer returns zero after output space has been reserved.

## Explanation

Caption rewriting fails and the calling AVC path retains the original video frame.

## Possible causes

- The caption SEI renderer returns zero after output space has been reserved.

## What to check

1. Check caption payload generation and the size calculated for the SEI message.

## Recommended action

Correct the caption payload or rendering failure.
