## Short description

SRT wildcard output requires Addenda.

## Trigger condition

A receiver connects to a wildcard output listener while the Addenda package is unavailable.

## Explanation

The requested per-stream output session fails setup. Both regular and non-Windows constant-bitrate paths enforce this requirement.

## Possible causes

- A receiver connects to a wildcard output listener while the Addenda package is unavailable.

## What to check

1. Check the Addenda license and whether wildcard stream selection is intended.

## Recommended action

Enable the required package to use SRT listen stream selection.
