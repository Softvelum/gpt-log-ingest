# License validation response lacks required fields

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-44229e10585536d6

## Log pattern

```text
License server response [%s]
```

## Parameters

- Argument 1 — Status: Status text returned by the license server; may be empty.

## Log examples

Illustrative examples; these are not captured server logs.

```text
License server response [license unavailable]
```

## Short description

License validation response lacks required fields.

## Trigger condition

The license-validation response lacks required information.

## Explanation

Validation returns failure. The license worker stops the corresponding feature and waits for a changed license file.

## Possible causes

- The license server returned an incomplete or rejecting response.

## What to check

1. Read the server status text and check the registered license and server credentials.

## Recommended action

Resolve the license-server status before retrying registration or validation.
