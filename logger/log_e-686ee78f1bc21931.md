# DVR extra-data index contains an unsupported type

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-686ee78f1bc21931

## Log pattern

```text
[DvrA::RemES] invalid segment type=%u file='%s'
```

## Parameters

- Argument 1 — Segment type: Integer recorded-segment category: 2 video, 3 audio, 6 DVB subtitle, 7 KLV, 8 WebVTT.
- Argument 2 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DvrA::RemES] invalid segment type=3 file='/data/dvr/live/camera/1700000000000.dat'
```

## Short description

DVR extra-data index contains an unsupported type.

## Trigger condition

The extra-data removal path receives neither a DVB subtitle nor KLV segment.

## Explanation

The removal operation returns failure without deleting this entry.

## Possible causes

- The extra-data removal path receives neither a DVB subtitle nor KLV segment.

## What to check

1. Check archive index consistency and preceding loading errors.

## Recommended action

Check archive index consistency and preceding loading errors.
