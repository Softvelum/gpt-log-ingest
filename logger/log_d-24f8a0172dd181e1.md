# Automatic video packet selection changed

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-24f8a0172dd181e1

## Log pattern

```text
updateAvailable explicitly set video pid changed from %d to %d
```

## Parameters

- Argument 1 — previous\_packet\_id: Previously active packet identifier.
- Argument 2 — default\_packet\_id: New effective default packet identifier, or zero if unavailable.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable explicitly set video pid changed from 256 to 300
```

## Short description

Automatic video packet selection changed.

## Trigger condition

No explicit packet is configured and the active video identifier differs from the effective default.

## Explanation

Despite the word explicitly in the pattern, this occurs in automatic selection. Video codec initialization, timestamps, parameter sets, and frame assembly buffers are reset. The old selection is cleared, then the new default and its type are selected if the default is nonzero; zero leaves video unselected.
