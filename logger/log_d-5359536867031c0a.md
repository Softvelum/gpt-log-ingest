# Socket event registration updated

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_d
Log level: debug
Documentation ID: log_d-5359536867031c0a

## Log pattern

```text
epoll_ctl epfd=%d DEL fd=%d
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Socket: Socket descriptor, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
epoll_ctl epfd=10 DEL fd=12
```

## Short description

Socket event registration updated.

## Trigger condition

Linux successfully completes the request to remove a descriptor in the event monitor.

## Explanation

Future event monitoring uses the updated registration.
