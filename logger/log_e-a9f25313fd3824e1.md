# Quick Sync decoder hardware binding failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-a9f25313fd3824e1

## Log pattern

```text
%p failed to set hw handle, error=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to set hw handle, error=-3
```

## Short description

Quick Sync decoder hardware binding failed.

## Trigger condition

Binding the opened VA display to the Linux decoder session returns a nonzero status.

## Explanation

The VA display is closed and decoder session setup fails.

## Possible causes

- The media session rejects the selected VA display.

## What to check

1. Check the status and compatibility between the selected render device, VA driver, and Intel media runtime.

## Recommended action

Use a compatible device and driver combination, then restart decoding.
