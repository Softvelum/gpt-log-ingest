# Entire saved-session file loading started

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_i
Log level: info
Documentation ID: log_i-f637f6de8d4a6519

## Log pattern

```text
Loading sessions from '%s'
```

## Parameters

- Argument 1 — file: Path of the saved session or recovery-statistics data file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Loading sessions from '/var/lib/nimble/sessions.db'
```

## Short description

Entire saved-session file loading started.

## Trigger condition

The whole-file loader is selected.

## Explanation

The complete file is read and parsed as JSON. Automatic selection uses this mode for files up to 10 MiB and when size inspection fails.
