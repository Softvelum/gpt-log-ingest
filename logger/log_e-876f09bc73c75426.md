# Cache download transition rejected

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-876f09bc73c75426

## Log pattern

```text
CacheItem::SetBeingDownloaded failed for item key='%s' state=%d
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — state: Numeric cache state: 0 empty, 1 downloading, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CacheItem::SetBeingDownloaded failed for item key='movie' state=3
```

## Short description

Cache download transition rejected.

## Trigger condition

An atomic transition from an empty item to downloading fails.

## Explanation

The cache throws a state error instead of starting the download. The logged state is read after the failed transition.

## Possible causes

- An internal cache state transition was requested at an invalid time.

## What to check

1. Compare nearby messages for the same cache key and its state changes.

## Recommended action

Use the surrounding cache lifecycle messages to identify the conflicting operation.
