# NVIDIA encoded packet delivery failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-1471d926e2aba3f9

## Log pattern

```text
failed to write output bitstream encoder=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write output bitstream encoder=0x12340000
```

## Short description

NVIDIA encoded packet delivery failed.

## Trigger condition

After reading and unlocking an encoded packet, the downstream video packet writer returns failure.

## Explanation

The frame write returns failure; the completed encoder buffer slot has already been released.

## Possible causes

- The output writer cannot accept or publish the encoded packet.

## What to check

1. Check the output stream/writer diagnostics immediately before this message.

## Recommended action

Correct the downstream output failure.
