# Expired shared session link is missing

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-e6fa6c1718066955

## Log pattern

```text
InvalidateSessions failed to find shared session url='%s' id=%lu
```

## Parameters

- Argument 1 — URL: Requested resource URL.
- Argument 2 — session: Numeric playback session identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
InvalidateSessions failed to find shared session url='/live/http_origin_common' id=42
```

## Short description

Expired shared session link is missing.

## Trigger condition

Removing an inactive shared session cannot find a shared-list entry with both its URL and identifier.

## Explanation

The session record is still deleted; this reports an inconsistency in the shared-session tracking list.

## Possible causes

- Shared-session tracking no longer contains the matching URL and identifier.

## What to check

1. Compare shared registration, reuse, and expiration messages.

## Recommended action

Investigate inconsistent shared-session lifetime tracking.
