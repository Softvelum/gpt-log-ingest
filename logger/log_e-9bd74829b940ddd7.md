# SMIL body has no switch child

Product: Nimble Streamer
Component: SMIL media playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-9bd74829b940ddd7

## Log pattern

```text
invalid SMIL(switch node absent) file=%s
```

## Parameters

- Argument 1 — SMIL filename: Text filename passed to the XML reader. It is a local SMIL path or the local cache-fragment filename for a downloaded SMIL document.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid SMIL(switch node absent) file=/media/movie.smil
```

## Short description

SMIL body has no switch child.

## Trigger condition

The body element found under the smil root has no direct child element named switch.

## Explanation

HLS playlist generation, including fragmented-MP4 HLS, returns failure and the HTTP caller prepares HTTP 500. DASH input discovery returns an empty item list, so its HTTP caller prepares HTTP 404. No requested playlist or manifest is generated from this document.

## Possible causes

- The body element found under the smil root has no direct child element named switch.

## What to check

1. Place a lowercase switch element directly under the selected body element; this parser does not search deeper descendants for it.

## Recommended action

Place a lowercase switch element directly under the selected body element; this parser does not search deeper descendants for it.
