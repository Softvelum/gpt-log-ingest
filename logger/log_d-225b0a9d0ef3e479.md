# SCTE-35 command does not produce a supported splice point

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_d
Log level: debug
Documentation ID: log_d-225b0a9d0ef3e479

## Log pattern

```text
[SCTE35] unsupported splice command type=%d for [%s/%s]
```

## Parameters

- Argument 1 — Command type: SCTE-35 command type byte.
- Argument 2 — Application: Application containing the live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] unsupported splice command type=0 for [live/camera]
```

## Short description

SCTE-35 command does not produce a supported splice point.

## Trigger condition

A section is parsed but its command or segmentation descriptor does not map to a supported splice event.

## Explanation

Ad-marker list processing ignores it successfully. Live processing continues forwarding the raw section to stream output and, when enabled, MPEG-TS packaging.

## Possible causes

- A section is parsed but its command or segmentation descriptor does not map to a supported splice event.

## What to check

1. Check the command type and enabled time-signal interpretation.

## Recommended action

Use supported splice signaling if ad-boundary recognition is required.
