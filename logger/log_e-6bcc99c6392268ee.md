# MPEG audio RTP reserved field is nonzero

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-6bcc99c6392268ee

## Log pattern

```text
mbz must be zero %d

```

## Parameters

- Argument 1 — Reserved field: Unsigned sixteen-bit field displayed in decimal; it must be zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
mbz must be zero 1

```

## Short description

MPEG audio RTP reserved field is nonzero.

## Trigger condition

The first sixteen bits of the MPEG audio RTP payload header contain a nonzero reserved value.

## Explanation

Parsing stops before reading the fragment offset or submitting MPEG audio data.

## Possible causes

- The first sixteen bits of the MPEG audio RTP payload header contain a nonzero reserved value.

## What to check

1. Check that the MPEG audio RTP reserved header field is zero.

## Recommended action

Send zero in the reserved header field.
