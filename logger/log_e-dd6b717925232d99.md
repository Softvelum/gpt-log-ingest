# AAC configuration is shorter than two bytes

Product: Nimble Streamer
Component: Fragmented media to transport stream packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-dd6b717925232d99

## Log pattern

```text
[AM] wrong codec_info_size %d
```

## Parameters

- Argument 1 — Configuration size: AAC decoder-configuration length in bytes; this branch prints 0 or 1.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] wrong codec_info_size 1
```

## Short description

AAC configuration is shorter than two bytes.

## Trigger condition

The extracted AAC decoder configuration has fewer than two bytes.

## Explanation

AAC configuration extraction fails before reading sample rate or channel configuration.

## Possible causes

- The extracted AAC decoder configuration has fewer than two bytes.

## What to check

1. Check the AAC configuration length in the audio initialization segment.

## Recommended action

Provide a complete AAC decoder configuration.
