# AAC LATM configuration has no registered live stream

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-49e494a1ce27e7a7

## Log pattern

```text
mp4a-latm: unregistered stream
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
mp4a-latm: unregistered stream
```

## Short description

AAC LATM configuration has no registered live stream.

## Trigger condition

The RTSP AAC LATM configuration is being applied while no live stream is attached.

## Explanation

Codec setup returns failure before registering the AAC LATM configuration. The message identifies missing stream registration rather than malformed media.

## Possible causes

- The RTSP AAC LATM configuration is being applied while no live stream is attached.

## What to check

1. Check whether the RTSP input has a registered live stream before codec setup.
