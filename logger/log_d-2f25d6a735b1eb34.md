# PES timestamp flag combination is unsupported

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-2f25d6a735b1eb34

## Log pattern

```text
not supported PTS flag pid=%d
```

## Parameters

- Argument 1 — PID: Affected elementary-stream packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
not supported PTS flag pid=256
```

## Short description

PES timestamp flag combination is unsupported.

## Trigger condition

The two-bit PTS/DTS flag field equals the reserved value 1.

## Explanation

The current transport packet is rejected. Its elementary-stream parser is reset, buffered partial PES data is discarded, and the camera parser searches for another packet boundary.

## Possible causes

- The two-bit PTS/DTS flag field equals the reserved value 1.

## What to check

1. Check the PES timestamp flags in the source transport stream.

## Recommended action

Correct malformed PES framing at the source.
