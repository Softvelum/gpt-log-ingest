# TCP listening could not start

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-ce6a18535b684619

## Log pattern

```text
failed to listen socket s=%d errno=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

The pattern covers generic TCP listeners, WHIP/WHEP control listeners, and main server TCP listeners.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to listen socket s=12 errno=5
```

## Short description

TCP listening could not start.

## Trigger condition

The operating system rejects the listen operation after binding and nonblocking setup.

## Explanation

Generic and WebRTC control listeners close the socket and return failure. Main server listener startup exits the process with failure.

## Possible causes

- The listen operation failed.

## What to check

1. Check the socket error and listener descriptor.

## Recommended action

Resolve the reported listen error.
