# Audio filter output could not be connected

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-027b150190fade4d

## Log pattern

```text
failed to link abuffersink, %s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to link abuffersink, [in]anull[out]
```

## Short description

Audio filter output could not be connected.

## Trigger condition

Connecting a parsed audio output to its new sink returns a negative result.

## Explanation

Audio filter initialization fails.

## Possible causes

- The audio filter output cannot be linked to its sink.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
