# Panel reports server as unknown

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_e
Log level: error

## Short description

Panel reports server as unknown.

## Trigger condition

The ordinary synchronization response status is unknown.

## Explanation

The response handler returns false. The sync thread stops immediately if every response so far has been unknown, or on the twelfth unknown retry after a previously accepted response. Earlier retries wait one hour, then two hours, while saving statistics. Other callers receive the false result.

## Possible causes

- The panel response does not recognize this server.

## What to check

1. Check the server registration, identity, and selected panel endpoint.

## Recommended action

Correct the server registration or panel identity.
