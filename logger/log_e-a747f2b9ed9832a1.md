# NVIDIA codec configuration parsing failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-a747f2b9ed9832a1

## Log pattern

```text
failed to parse extra data for [%s], res=%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse extra data for [live/camera], res=2
```

## Short description

NVIDIA codec configuration parsing failed.

## Trigger condition

The newly created parser rejects the initial Annex B codec configuration data.

## Explanation

Decoder initialization returns failure before normal packets are processed.

## Possible causes

- The initial codec configuration is invalid or unsupported by the parser.

## What to check

1. Check the source H.264 or HEVC parameter sets and the driver status.

## Recommended action

Provide valid supported codec configuration.
