# License TLS request was only partially sent

Component: Transcoder and Addenda licensing

## Log pattern

```text
Transcoder validation procedure failed. SSL request send partially
```

Illustrative examples; these are not captured server logs.

## Short description

License TLS request was only partially sent.

## Trigger condition

The license-validation TLS request was only partly sent.

## Explanation

This license-validation attempt did not complete. The server can retry the license service; this message alone does not establish that the license was rejected.

## Possible causes

- The request could not be sent completely in the single write used by this helper.

## What to check

1. Check TLS and transport behavior at the time of the partial write.

## Recommended action

Resolve the specific synchronization failure so license validation can succeed.
