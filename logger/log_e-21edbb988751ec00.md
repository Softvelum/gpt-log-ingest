# Scenario transcoder process could not start

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-21edbb988751ec00

## Log pattern

```text
failed to create transcoder, scenario=%s
```

## Parameters

- Argument 1 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create transcoder, scenario=scenario1
```

## Short description

Scenario transcoder process could not start.

## Trigger condition

Creating the child process for a newly required scenario returns no process.

## Explanation

The scenario is skipped in this settings synchronization; no controller is installed for it.

## Possible causes

- The scenario executable cannot be launched.

## What to check

1. Check earlier process-launch diagnostics, executable availability and operating-system process resources.

## Recommended action

Correct the child launch failure and reapply or refresh the scenario settings.
