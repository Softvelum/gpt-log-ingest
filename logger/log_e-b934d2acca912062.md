# HLS playlist encryption method is unsupported

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-b934d2acca912062

## Log pattern

```text
unsupported encryption METHOD=%s, playlist url='%s'
```

## Parameters

- Argument 1 — method: Exact encryption method value parsed from the tag.
- Argument 2 — playlist\_url: Current playlist URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported encryption METHOD=SAMPLE-AES, playlist url='https://origin.example/live.m3u8'
```

## Short description

HLS playlist encryption method is unsupported.

## Trigger condition

A playlist encryption tag specifies a method other than NONE or AES-128.

## Explanation

Playlist processing requests input shutdown and returns before queuing further segments from that playlist.

## Possible causes

- The playlist declares an unsupported encryption method.

## What to check

1. Check the encryption method in the origin playlist.

## Recommended action

Use an unencrypted or AES-128 playlist supported by this input path.
