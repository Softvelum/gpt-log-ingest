## Short description

WHIP publishing worker stopped.

## Trigger condition

The WHIP run loop has handled an exit request and completed its shutdown sequence.

## Explanation

Pending new sessions are finished, the managed helper is stopped, control and active media connections are cleared, and the listener is closed.
