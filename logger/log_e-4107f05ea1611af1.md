# Invalid Zixi interface item skipped

Product: Nimble Streamer
Component: Zixi integration
Logging function: log_e
Log level: error
Documentation ID: log_e-4107f05ea1611af1

## Log pattern

```text
invalid private_interface type=%d
```

## Parameters

- Argument 1 — Type: Numeric JSON type of the rejected interface item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid private_interface type=3
```

## Short description

Invalid Zixi interface item skipped.

## Trigger condition

An element of a private, public, or server-interface array is not a JSON object.

## Explanation

Only that interface item is skipped; other items are still examined. The diagnostic names private_interface even for the other interface arrays.

## Possible causes

- An element of a private, public, or server-interface array is not a JSON object.

## What to check

1. Check the Zixi configuration response interface-array elements.
