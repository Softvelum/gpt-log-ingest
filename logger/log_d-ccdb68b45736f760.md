# Client socket removed from processing

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-ccdb68b45736f760

## Log pattern

```text
removed client s=%d from processing (active=%d)
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Remaining map entries: Native-size unsigned number of registered socket/session entries after removal, incorrectly printed with %d.

The active-map size is a native-size unsigned count supplied to %d, so that field is unreliable on platforms where size_t is wider than int.

## Log examples

The active-map size is a native-size unsigned count supplied to %d, so that field is unreliable on platforms where size_t is wider than int.

## Short description

Client socket removed from processing.

## Trigger condition

The client socket is removed from the event selector and active-session map during cleanup.

## Explanation

The remaining map size is logged before closing the client socket.

## Possible causes

- The client socket is removed from the event selector and active-session map during cleanup.
