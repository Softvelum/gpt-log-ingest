# Quick Sync surface memory allocation failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-88f1763b5891ec1c

## Log pattern

```text
%p failed to alloc surface buffer
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

The decoder allocates storage for 17 NV12 surfaces. The encoder sizes its NV12 surface pool from lookahead, the runtime recommendation, and asynchronous depth. This log covers the explicit null check; an allocation exception does not take this branch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to alloc surface buffer
```

## Short description

Quick Sync surface memory allocation failed.

## Trigger condition

The decoder or encoder surface-buffer allocation returns a null pointer.

## Explanation

Initialization fails before surfaces can be used.

## Possible causes

- The requested contiguous system-memory surface buffer cannot be allocated.

## What to check

1. Check memory availability and the video dimensions; for encoding include lookahead and asynchronous depth when assessing surface memory.

## Recommended action

Reduce memory demand or restore available memory and restart the stream.
