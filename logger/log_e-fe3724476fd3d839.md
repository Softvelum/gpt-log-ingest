# DVR KLV metadata segment could not be stored

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-fe3724476fd3d839

## Log pattern

```text
failed to save KLV metadata segment for stream='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to save KLV metadata segment for stream='live/camera'
```

## Short description

DVR KLV metadata segment could not be stored.

## Trigger condition

Appending KLV segment index data or adding the metadata segment to the archive fails.

## Explanation

The metadata buffers are cleared and video recording continues.

## Possible causes

- Appending KLV segment index data or adding the metadata segment to the archive fails.

## What to check

1. Check metadata buffer capacity and archive storage errors.

## Recommended action

Check metadata buffer capacity and archive storage errors.
