# Could not create the server management worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-33b35ed4551c82c9

## Log pattern

```text
failed to create server management thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create server management thread
```

## Short description

Could not create the server management worker.

## Trigger condition

The server management API worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the server management worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed server management worker.
