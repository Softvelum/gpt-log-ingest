# Pay-per-view response authentication failed

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-01007132a82226d0

## Log pattern

```text
deny list rejected since solution != BASE64(MD5(PUZZLE+TOKEN)), solution=%s, puzzle=%s, token=%s
```

## Parameters

- Argument 1 — solution: Solution returned by the handler.
- Argument 2 — puzzle: Most recent challenge sent to the handler.
- Argument 3 — token: Configured shared token used to verify the response.

## Log examples

Illustrative examples; these are not captured server logs.

```text
deny list rejected since solution != BASE64(MD5(PUZZLE+TOKEN)), solution=invalid, puzzle=example-puzzle, token=example-token
```

## Short description

Pay-per-view response authentication failed.

## Trigger condition

Mutual authorization is enabled and the received solution differs from Base64 of the MD5 digest of the last puzzle followed by the shared token.

## Explanation

The returned deny list is rejected and the current deny list is cleared.

## Possible causes

- The handler response does not match the current challenge and shared token.

## What to check

1. Check that both sides use the same token and that the response matches the latest challenge.

## Recommended action

Correct handler mutual authorization.
