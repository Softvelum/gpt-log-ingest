# TLS origin error treated as disconnection

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-f975b945369662aa

## Log pattern

```text
error event for ssl origin s=%d (ev=0x%x)
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the affected local socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.

## Log examples

Illustrative examples; these are not captured server logs.

```text
error event for ssl origin s=17 (ev=0x10)
```

## Short description

TLS origin error treated as disconnection.

## Trigger condition

The TLS origin socket reports an error event, alone or combined with hang-up, without a readable or writable event.

## Explanation

The origin connection is handled as closed; further cleanup follows the current request phase.

## Possible causes

- The TLS origin socket reports an error event, alone or combined with hang-up, without a readable or writable event.

## What to check

1. Check the peer connection and nearby TLS or transport errors when the response was interrupted.

## Recommended action

Check the peer connection and nearby TLS or transport errors when the response was interrupted.
