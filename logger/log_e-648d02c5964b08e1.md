# DRM protection requires the Addenda license

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-648d02c5964b08e1

## Log pattern

```text
DRM protection failed for '%s/%s' type=%d (requires Addenda package license)
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Provider type: Integer provider identifier: 0 VCAS, 1 VCAS CEI 2, 2 VCAS CPIX, 3 Widevine, 4 EzDRM, 5 EzDRM V2, 6 PallyCon, 7 KeyOS, 8 SigmaDRM, 9 static HLS AES, 10 DRMToday, 11 Axinom, 12 CloudDRM, 13 ExpressPlay.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DRM protection failed for 'live/camera' type=3 (requires Addenda package license)
```

## Short description

DRM protection requires the Addenda license.

## Trigger condition

Common encryption registration, initialization, or segment preparation, or static HLS chunk encryption, is attempted while Addenda is disabled.

## Explanation

The affected key registration or encryption operation fails. The application and stream identify the affected output.

## Possible causes

- Common encryption registration, initialization, or segment preparation, or static HLS chunk encryption, is attempted while Addenda is disabled.

## What to check

1. Enable a valid Addenda license before using the requested DRM mode.

## Recommended action

Enable a valid Addenda license before using the requested DRM mode.
