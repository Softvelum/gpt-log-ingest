# Buffered NDI video sender stopped

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-493e497c7a6f3212

## Log pattern

```text
ndi video sender stoped, ndi_name="%s"
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ndi video sender stoped, ndi_name="HOST (Output)"
```

## Short description

Buffered NDI video sender stopped.

## Trigger condition

The dedicated video worker leaves its send loop.

## Explanation

For video output, this follows an exit request or an unsupported video format.

## Possible causes

- An exit request or unsupported video format.

## What to check

1. Check the preceding messages if the worker stopped unexpectedly.
