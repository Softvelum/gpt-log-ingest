# Playlist synchronization location does not exist

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-e1e6f504e5c5587e

## Log pattern

```text
server_playlist_sync_url is neither file nor url. url=[%s]
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
server_playlist_sync_url is neither file nor url. url=[https://api.example/playlist]
```

## Short description

Playlist synchronization location does not exist.

## Trigger condition

The configured synchronization location is neither HTTP nor HTTPS and is not an existing file.

## Explanation

Synchronization returns failure.

## Possible causes

- The configured synchronization location is neither HTTP nor HTTPS and is not an existing file.

## What to check

1. Set an existing readable playlist file or an HTTP or HTTPS destination.

## Recommended action

Set an existing readable playlist file or an HTTP or HTTPS destination.
