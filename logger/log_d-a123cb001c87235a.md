# Outbound TCP socket created

Product: Nimble Streamer
Component: Socket communication
Logging function: log_d
Log level: debug
Documentation ID: log_d-a123cb001c87235a

## Log pattern

```text
created socket s=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Outbound TCP socket created.

## Trigger condition

An IPv4 TCP socket is successfully created before setting nonblocking mode and connecting.

## Explanation

This confirms allocation only; later setup operations can still fail.
