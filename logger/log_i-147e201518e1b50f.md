# Transcription removed after configuration change

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-147e201518e1b50f

## Log pattern

```text
removed transcriber on audio config change, stream='%s'
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed transcriber on audio config change, stream='live/news'
```

## Short description

Transcription removed after configuration change.

## Trigger condition

New audio configuration differs from the active stream in audio format or relevant transcription settings.

## Explanation

The active stream and its websocket context are removed. The new configuration is retained so later audio can create a replacement.

## Possible causes

- New audio configuration differs from the active stream in audio format or relevant transcription settings.

## What to check

1. Check for changes to codec, audio timing, rate, channels, language, service URL, key, or custom transcription options.
