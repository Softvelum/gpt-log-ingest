# External request ended without a result

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-6e85e9a7f37aa201

## Log pattern

```text
~RequestorSession url='%s' request failed
```

## Parameters

- Argument 1 — URL: Original external request URL, retained even when following a redirect.

## Log examples

Illustrative examples; these are not captured server logs.

```text
~RequestorSession url='https://media.example/movie.mp4' request failed
```

## Short description

External request ended without a result.

## Trigger condition

The request session is destroyed while its requester still awaits completion.

## Explanation

Cleanup invokes the failure callback without a response parser. This can follow timeout, input failure, incomplete response, or another path that ended the session.

## Possible causes

- The session ended before delivering a success or failure response callback.

## What to check

1. Use preceding network, timeout, parsing, or buffer messages to identify the cause.

## Recommended action

Resolve the earlier request failure before retrying.
