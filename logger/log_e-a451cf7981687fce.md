# HEVC decoder configuration could not be built

Product: Nimble Streamer
Component: FFmpeg video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-a451cf7981687fce

## Log pattern

```text
set_hevc_info function failed, buildHEVCDecoderConfigurationRecord call failed for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set_hevc_info function failed, buildHEVCDecoderConfigurationRecord call failed for [live/camera]
```

## Short description

HEVC decoder configuration could not be built.

## Trigger condition

Assembling decoder configuration from the supplied HEVC parameter sets fails.

## Explanation

The decoder extra data is not updated by this attempt.

## Possible causes

- The parameter sets cannot form an accepted configuration within the bounded buffer.

## What to check

1. Check the HEVC video parameter sets and their sizes.

## Recommended action

Supply valid complete HEVC parameter sets.
