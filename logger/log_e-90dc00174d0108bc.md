# Failure reported for an unexpected playlist URL

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-90dc00174d0108bc

## Log pattern

```text
ServerPlaylistSyncThread::OnRequestFailed unexpected url='%s'
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerPlaylistSyncThread::OnRequestFailed unexpected url='https://api.example/playlist'
```

## Short description

Failure reported for an unexpected playlist URL.

## Trigger condition

Failure handling receives a URL absent from pending block requests and different from the main destination.

## Explanation

The failure is logged without changing a tracked request.

## Possible causes

- Failure handling receives a URL absent from pending block requests and different from the main destination.

## What to check

1. Compare the URL with the current synchronization destinations and recently completed requests.

## Recommended action

Compare the URL with the current synchronization destinations and recently completed requests.
