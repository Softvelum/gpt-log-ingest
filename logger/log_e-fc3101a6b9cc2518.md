# RTMP createStream precedes an accepted connection

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-fc3101a6b9cc2518

## Log pattern

```text
createStream command MUST be sent after connect
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
createStream command MUST be sent after connect
```

## Short description

RTMP createStream precedes an accepted connection.

## Trigger condition

The peer sends createStream before connect has been processed or while the accepted application name is still empty.

## Explanation

The stream command is rejected and connection processing fails. This can also occur when connection authorization has not yet established an application.

## Possible causes

- The peer sends createStream before connect has been processed or while the accepted application name is still empty.

## What to check

1. Check the connect response and authentication exchange preceding the stream command.

## Recommended action

Complete the connect and authorization exchange before creating or initializing streams.
