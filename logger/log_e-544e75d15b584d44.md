# RTMP AMF3 command has no leading byte

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-544e75d15b584d44

## Log pattern

```text
failed to parse AMF3 command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse AMF3 command
```

## Short description

RTMP AMF3 command has no leading byte.

## Trigger condition

An AMF3 command message has a payload size below one byte.

## Explanation

The command cannot skip its leading byte before AMF0 command decoding, so connection processing fails.

## Possible causes

- An AMF3 command message has a payload size below one byte.

## What to check

1. Check the declared payload size and actual contents of the AMF3 command.

## Recommended action

Correct the empty command payload at the peer.
