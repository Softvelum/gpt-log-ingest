# AJA frame transfer to the output device failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-90857504bd75f019

## Log pattern

```text
playback failed device=%s/%d reason='AutoCirculate transfer failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback failed device=0/0 reason='AutoCirculate transfer failed'
```

## Short description

AJA frame transfer to the output device failed.

## Trigger condition

Transferring the prepared host video/audio buffers to the card returns failure.

## Explanation

The sender attempts to read circulation status for an additional diagnostic, then returns failure.

## Possible causes

- Transferring the prepared host video/audio buffers to the card returns failure.

## What to check

1. Check the following circulation-status message when available.
