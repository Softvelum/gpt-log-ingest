# Axinom tenant identifier is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-79c2d9c096692ba3

## Log pattern

```text
Tenant Id must be provided for Axinom DRM (axinom_tenant_id)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Tenant Id must be provided for Axinom DRM (axinom_tenant_id)
```

## Short description

Axinom tenant identifier is missing.

## Trigger condition

The Axinom tenant identifier is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The Axinom tenant identifier is empty.

## What to check

1. Provide the Axinom tenant identifier.

## Recommended action

Provide the Axinom tenant identifier.
