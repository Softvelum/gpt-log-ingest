# Remote log response received

Product: Nimble Streamer
Component: Remote log reporting
Logging function: log_v
Log level: verbose
Documentation ID: log_v-12298e1205567192

## Log pattern

```text
received response:
%s
```

## Parameters

- Argument 1 — Response body: Response body text from remote log synchronization.

## Log examples

Illustrative examples; these are not captured server logs.

```text
received response:
{"LogLevel":"error","LogKind":"wmsauth","LogInterval":30,"LogMaxLines":100}
```

## Short description

Remote log response received.

## Trigger condition

HTTP or HTTPS log synchronization completes successfully.

## Explanation

Shows the response body before JSON validation. A valid object can update the reporting level, kind, interval and maximum stored line count.
