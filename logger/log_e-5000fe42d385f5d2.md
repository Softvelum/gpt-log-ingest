# RTMP value has the wrong type

Product: Nimble Streamer
Component: RTMP data parsing
Logging function: log_e
Log level: error
Documentation ID: log_e-5000fe42d385f5d2

## Log pattern

```text
rtmp_read_number buffer not bool[%d]
```

## Parameters

- Argument 1 — Received type: Received one-byte RTMP data-type marker, integer.

Despite the number-reader wording in the pattern, this check validates a boolean.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtmp_read_number buffer not bool[5]
```

## Short description

RTMP value has the wrong type.

## Trigger condition

The next RTMP data-type marker is not the expected boolean type.

## Explanation

The value parser returns failure without consuming this value.

## Possible causes

- The payload has another data type where a boolean is expected.

## What to check

1. Check the data-type marker and RTMP message structure.

## Recommended action

Send the expected boolean value.
