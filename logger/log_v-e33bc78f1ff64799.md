# DVR conversion request started

Product: Nimble Streamer
Component: DVR playback conversion
Logging function: log_v
Log level: verbose
Documentation ID: log_v-e33bc78f1ff64799

## Log pattern

```text
[DTT::PR] stream='%s' chunk='%s' key='%s' t=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Chunk name: Text naming the requested recording resource.
- Argument 3 — Cache key: Text identifying the requested cache output.
- Argument 4 — Start time: 64-bit wall-clock timestamp in microseconds since the Unix epoch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DTT::PR] stream='live/camera' chunk='dvr_v_p1_90000.fmp4' key='/live/camera/dvr_v_p1_90000.fmp4' t=1700000000000000
```

## Short description

DVR conversion request started.

## Trigger condition

A playback resource request enters processing while verbose logging is enabled.

## Explanation

The timestamp marks the beginning of this processing attempt.

## Possible causes

- A playback resource request enters processing while verbose logging is enabled.
