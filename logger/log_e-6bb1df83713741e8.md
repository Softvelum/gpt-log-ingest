# Video frame could not be copied for caption preservation

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-6bb1df83713741e8

## Log pattern

```text
failed to clone frame f='%s', stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to clone frame f='[in]null[out]', stream=live/camera
```

## Short description

Video frame could not be copied for caption preservation.

## Trigger condition

Caption preservation is enabled and cloning a frame that carries captions fails.

## Explanation

Filtering continues with the original frame, as if caption preservation were disabled for this frame.

## Possible causes

- The frame clone could not be allocated.

## What to check

1. Check caption preservation settings, accumulated caption size, and allocation diagnostics.

## Recommended action

Resolve the caption storage failure if caption preservation is required.
