# HTTP/3 requested header buffer exceeds library limit

Product: Nimble Streamer
Component: HTTP/3 header decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-20d66886e2e110b4

## Log pattern

```text
requested space for header is too large: %zu bytes
```

## Parameters

- Argument 1 — Requested space: Requested header-buffer capacity after applying the minimum allocation, size-based unsigned integer in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
requested space for header is too large: 1048576 bytes
```

## Short description

HTTP/3 requested header buffer exceeds library limit.

## Trigger condition

The decoder asks for header storage larger than the header library’s maximum supported string length, after a minimum 32-byte allocation size is applied.

## Explanation

The allocation callback returns no header, preventing decoding into an unsupported buffer.

## Possible causes

- The decoder requests an oversized header allocation.

## What to check

1. Check the size of the incoming header and the matching HTTP/3 library/server build.

## Recommended action

Reduce oversized headers; investigate repeated impossible allocation requests.
