# Audio filter input support is unavailable

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-8bd027fbd9d46739

## Log pattern

```text
failed to get abuffer definition, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get abuffer definition, filter=[in]anull[out], stream=live/camera
```

## Short description

Audio filter input support is unavailable.

## Trigger condition

FFmpeg cannot find the audio-buffer source filter.

## Explanation

Input setup fails.

## Possible causes

- The loaded library lacks the required audio source filter.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
