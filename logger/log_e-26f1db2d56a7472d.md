# AJA output video format is missing

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-26f1db2d56a7472d

## Log pattern

```text
Output video format is required for device '%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Output video format is required for device 'AJA device'
```

## Short description

AJA output video format is missing.

## Trigger condition

Output video setup receives the unknown-format value.

## Explanation

Output setup returns failure before channel and device-format checks.

## Possible causes

- Output video setup receives the unknown-format value.

## What to check

1. Check whether the output video format was supplied or inferred.

## Recommended action

Provide a recognized output video format.
