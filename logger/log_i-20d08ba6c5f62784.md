# TCP listener started

Product: Nimble Streamer
Component: Socket communication
Logging function: log_i
Log level: info
Documentation ID: log_i-20d08ba6c5f62784

## Log pattern

```text
listening '%s:%d'
```

## Parameters

- Argument 1 — Host: Requested host or address text.
- Argument 2 — Port: TCP port number, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
listening '192.0.2.10:1935'
```

## Short description

TCP listener started.

## Trigger condition

The listen operation succeeds; an automatically assigned port is queried when the requested port was zero.

## Explanation

The listener is ready at the socket level. It is registered for input events immediately afterward, which can still fail.
