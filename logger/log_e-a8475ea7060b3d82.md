# EzDRM key request could not be submitted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-a8475ea7060b3d82

## Log pattern

```text
failed to request key for '%s' from EzDRM url='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to request key for 'live/camera' from EzDRM url='https://keys.example/key'
```

## Short description

EzDRM key request could not be submitted.

## Trigger condition

The HTTP request processor refuses an initial or repeated EzDRM CPIX key request.

## Explanation

No pending request is registered for this attempt.

## Possible causes

- The HTTP request processor refuses an initial or repeated EzDRM CPIX key request.

## What to check

1. Check the configured EzDRM endpoint and accompanying HTTP request-processor errors.

## Recommended action

Check the configured EzDRM endpoint and accompanying HTTP request-processor errors.
