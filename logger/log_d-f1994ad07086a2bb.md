# Failed task output is being reported

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_d
Log level: debug
Documentation ID: log_d-f1994ad07086a2bb

## Log pattern

```text
report pid=%d failed out_buf.size()=%zd
```

## Parameters

- Argument 1 — Process: Integer task process identifier.
- Argument 2 — Buffered output: Size of the stored recent output in bytes.

The source passes an unsigned container size to a signed size conversion; small nonnegative values illustrate the intended byte count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
report pid=1234 failed out_buf.size()=32
```

## Short description

Failed task output is being reported.

## Trigger condition

A status report is being built for a task marked failed. Available only on Linux builds.

## Explanation

Buffered output and any recorded failure time are included in the report. A failed task without a restart interval is removed after reporting.
