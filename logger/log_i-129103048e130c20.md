# Quick Sync decoding falls back to FFmpeg

Product: Nimble Streamer
Component: Video decoding
Logging function: log_i
Log level: info
Documentation ID: log_i-129103048e130c20

## Log pattern

```text
quicksync decoder is unavailable, using default decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

Shared by H.264, HEVC, VP8, and VP9 decoder selection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
quicksync decoder is unavailable, using default decoder for [live/camera]
```

## Short description

Quick Sync decoding falls back to FFmpeg.

## Trigger condition

Native quicksync decoding is requested but the Quick Sync libraries are not loaded.

## Explanation

A default FFmpeg decoder is constructed and processing continues.

## Possible causes

- The optional Intel media runtime was unavailable during library loading.

## What to check

1. Check preceding Intel media library-loading messages and the decoder option.

## Recommended action

Restore a compatible media runtime if hardware decoding is required, or use the default decoder.
