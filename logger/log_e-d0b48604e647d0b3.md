# HTTP media source returned an error status

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-d0b48604e647d0b3

## Log pattern

```text
http error code=%d for url='%s' s=%d
```

## Parameters

- Argument 1 — Status: HTTP response status code.
- Argument 2 — URL: Configured source URL; it can be empty for an incoming publisher.
- Argument 3 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
http error code=404 for url='http://radio.example.net/live' s=42
```

## Short description

HTTP media source returned an error status.

## Trigger condition

A pulled Icecast or MPEG-TS response status is neither 200 nor a handled 301/302 redirect.

## Explanation

The current source connection is shut down.

## Possible causes

- A pulled Icecast or MPEG-TS response status is neither 200 nor a handled 301/302 redirect.

## What to check

1. Check the status code and source endpoint availability.
