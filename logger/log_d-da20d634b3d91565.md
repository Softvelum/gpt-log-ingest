# Disk cache file opened for allocation

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-da20d634b3d91565

## Log pattern

```text
created cache fd=%d f='%s'
```

## Parameters

- Argument 1 — descriptor: Open file descriptor used for the operation.
- Argument 2 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created cache fd=12 f='/var/cache/nimble/movie'
```

## Short description

Disk cache file opened for allocation.

## Trigger condition

Opening or creating a non-Windows cache file succeeds.

## Explanation

The file still needs resizing and memory mapping before cache allocation can succeed.
