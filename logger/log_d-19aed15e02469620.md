## Short description

HTTP host contains a disallowed character.

## Trigger condition

Host validation encounters a character outside printable ASCII or a forbidden host punctuation character.

## Explanation

HTTP 400 is prepared before ordinary or WHEP routing.

## Possible causes

- Host validation encounters a character outside printable ASCII or a forbidden host punctuation character.

## What to check

1. Correct the client Host or authority value and check proxy rewriting. Whitespace, slashes, question marks, quotes, braces, and several other punctuation characters are rejected.

## Recommended action

Correct the client Host or authority value and check proxy rewriting. Whitespace, slashes, question marks, quotes, braces, and several other punctuation characters are rejected.
