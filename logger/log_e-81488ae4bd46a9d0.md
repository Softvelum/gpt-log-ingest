# Several playlist subtitle tracks share one language

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-81488ae4bd46a9d0

## Log pattern

```text
file '%s': %zd subtitles for language code '%s' found
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.
- Argument 2 — Matching tracks: Number of matching subtitle entries.
- Argument 3 — Language code: Text naming the requested subtitle language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
file '/media/program.mp4': 2 subtitles for language code 'en' found
```

## Short description

Several playlist subtitle tracks share one language.

## Trigger condition

More than one configured subtitle entry matches the requested language code.

## Explanation

The first matching subtitle index is used and the lookup still succeeds.

## Possible causes

- More than one configured subtitle entry matches the requested language code.

## What to check

1. Use distinct language codes when each subtitle track must be selected separately.

## Recommended action

Use distinct language codes when each subtitle track must be selected separately.
