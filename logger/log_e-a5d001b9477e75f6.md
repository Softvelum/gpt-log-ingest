# RTMP initStream requested stream ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-a5d001b9477e75f6

## Log pattern

```text
failed to process stream id for InitStream command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process stream id for InitStream command
```

## Short description

RTMP initStream requested stream ID cannot be decoded.

## Trigger condition

The initStream request cannot supply its requested stream ID as an AMF number.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The initStream request cannot supply its requested stream ID as an AMF number.

## What to check

1. Inspect the requested stream ID field and AMF framing in the incoming initStream command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
