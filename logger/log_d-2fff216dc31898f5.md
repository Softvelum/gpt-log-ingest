# Saved cache fragment loaded

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-2fff216dc31898f5

## Log pattern

```text
loaded key='%s' fragment=%u size=%llu
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — fragment: Zero-based fragment index.
- Argument 3 — file bytes: Size of the fragment file on disk.

The fragment index is a platform-sized value passed to a 32-bit unsigned conversion.

## Log examples

No portable example is provided for the mismatched fragment-index type.

## Short description

Saved cache fragment loaded.

## Trigger condition

An available fragment file exists and a tracking object is created while loading stored cache metadata.

## Explanation

The fragment enters the cache ordering lists without being mapped yet; its file size contributes to the loaded item total.
