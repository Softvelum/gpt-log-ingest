# DVR cleanup request accepted for processing

Product: Nimble Streamer
Component: DVR
Logging function: log_v
Log level: verbose
Documentation ID: log_v-ecc712d7a063668a

## Log pattern

```text
url='%s' target_depth=%llu older_than=%llu newer_than=%llu video=%s audio=%s
```

## Parameters

- Argument 1 — Request URL: Text giving the management cleanup URL.
- Argument 2 — Target depth: Unsigned retention depth in minutes; zero means no depth bound.
- Argument 3 — Older boundary: Unsigned UTC cutoff in seconds since the Unix epoch; zero means unspecified.
- Argument 4 — Newer boundary: Unsigned UTC lower bound in seconds since the Unix epoch; zero means unspecified.
- Argument 5 — Video action: Text giving delete, keep, or blackout; empty text means the default delete action.
- Argument 6 — Audio action: Text giving delete, keep, or mute; empty text means the default delete action.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url='/manage/dvr/cleanup/live/camera?target_depth=3600' target_depth=3600 older_than=0 newer_than=0 video=delete audio=delete
```
