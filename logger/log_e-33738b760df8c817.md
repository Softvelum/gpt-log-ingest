# Scenario output item type is unsupported

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-33738b760df8c817

## Log pattern

```text
unsupported item, type=%d app=%s stream=%s scenario=%s
```

## Parameters

- Argument 1 — Item type: Numeric media-buffer item identifier, integer; no unit.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.
- Argument 4 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported item, type=999 app=live stream=camera scenario=scenario1
```

## Short description

Scenario output item type is unsupported.

## Trigger condition

A child frame message has an item type that the parent output dispatcher does not handle.

## Explanation

The item is rejected, connection processing fails and the scenario controller is removed.

## Possible causes

- The child supplies an unsupported or invalid media item type.

## What to check

1. Check the item type and consistency of parent and scenario transcoder versions.

## Recommended action

Use matching installations and supported output media.
