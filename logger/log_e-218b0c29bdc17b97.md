# AAC output configuration failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-218b0c29bdc17b97

## Log pattern

```text
failed to set aac codec params for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

The separate transcoder-process setter queues its AAC configuration and returns success, so that implementation does not normally trigger this guard.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set aac codec params for [live/encoded]
```

## Short description

AAC output configuration failed.

## Trigger condition

Applying the encoder-provided AAC configuration to the output stream returns failure.

## Explanation

The first AAC packet cannot initialize its output and audio writing fails.

## Possible causes

- The in-process destination is closed, the configuration is shorter than two bytes, or it requests an unsupported explicit sampling-frequency index.

## What to check

1. Check the AAC configuration and preceding destination or audio-header diagnostics.

## Recommended action

Provide valid AAC configuration and an active destination, then restart encoding.
