# Transport input stream choices are being refreshed

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-a288a58f0873fb18

## Log pattern

```text
update UDPCameraInfo for camera=%s
```

## Parameters

- Argument 1 — Camera ID: Transport input camera identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
update UDPCameraInfo for camera=camera1
```

## Short description

Transport input stream choices are being refreshed.

## Trigger condition

A camera with associated live streams supplies an updated available PID/type map.

## Explanation

Available tracks are inspected, default choices are selected, and each associated live stream receives the update.

## Possible causes

- A camera with associated live streams supplies an updated available PID/type map.

## What to check

1. Compare the following PID/type records with the desired input tracks.

## Recommended action

No action is needed for expected stream discovery.
