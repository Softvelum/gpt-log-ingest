# MP3 output buffer limit reached

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-7299233b984061e0

## Log pattern

```text
failed to alloc encode buffer, size=%d
```

## Parameters

- Argument 1 — Required bytes: Existing buffered bytes plus the new encode allowance, integer bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc encode buffer, size=1049600
```

## Short description

MP3 output buffer limit reached.

## Trigger condition

Growing the encoded-audio buffer to the required size fails.

## Explanation

The frame write fails before encoding.

## Possible causes

- The required buffer exceeds its bounded capacity.

## What to check

1. Check output accumulation and the reported required byte size.

## Recommended action

Resolve the indicated MP3 encoding or frame-accounting failure.
