# Access rule expression failed

Product: Nimble Streamer
Component: Playback access control
Logging function: log_e
Log level: error
Documentation ID: log_e-9474a8acb118f879

## Log pattern

```text
std::exception caught while processing WMSAuth rule regexp='%s' value='%s' what()='%s'
```

## Parameters

- Argument 1 — expression: Regular expression being checked.
- Argument 2 — value: Input value tested against that expression.
- Argument 3 — error: Exception description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
std::exception caught while processing WMSAuth rule regexp='[' value='viewer' what()='Invalid regular expression'
```

## Short description

Access rule expression failed.

## Trigger condition

Compiling or evaluating a nonempty access-rule regular expression raises a standard exception.

## Explanation

The match reports false, so this rule is treated as not matching. Other access rules and their ordering determine the overall access decision.

## Possible causes

- The rule expression is invalid or expression evaluation raises an exception.

## What to check

1. Compare the expression and tested value in the message.

## Recommended action

Correct the failing rule expression.
