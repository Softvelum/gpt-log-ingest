# WHIP pending control request send failed

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-5488fdc4e7a85d19

## Log pattern

```text
whip control socket failed to send session request from ProcessEvent
```

## Parameters

One occurrence handles a zero-byte send and the other a hard negative send; would-block waits without this message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whip control socket failed to send session request from ProcessEvent
```

## Short description

WHIP pending control request send failed.

## Trigger condition

Sending buffered control data on a writable event returns zero, or a negative result with an error other than would-block.

## Explanation

The control socket is closed, pending starts are marked finished, pending data is cleared, and active WHIP publications are removed and their stream registrations released.

## Possible causes

- The WHIP helper control connection is closed or has a socket send error.

## What to check

1. Check WHIP helper availability and nearby control-connection failures.

## Recommended action

Restore the helper connection and retry affected publications.
