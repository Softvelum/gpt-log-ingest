# G.711 mu-law configuration has no registered live stream

Product: Nimble Streamer
Component: RTSP input and RTP media

Log level: error

```text
pcmu: unregistered stream
```

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

G.711 mu-law configuration has no registered live stream.

## Trigger condition

The RTSP G.711 mu-law configuration is being applied while no live stream is attached.

## Explanation

Codec setup returns failure before registering the G.711 mu-law configuration. The message identifies missing stream registration rather than malformed media.

## Possible causes

- The RTSP G.711 mu-law configuration is being applied while no live stream is attached.

## What to check

1. Check whether the RTSP input has a registered live stream before codec setup.
