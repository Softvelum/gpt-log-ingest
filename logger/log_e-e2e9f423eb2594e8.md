# VPX encoder control was rejected

Product: Nimble Streamer
Component: VP8 and VP9 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e2e9f423eb2594e8

## Log pattern

```text
failed to set %s=%d: %s
```

## Parameters

- Argument 1 — Option: Encoder option key, text.
- Argument 2 — Value: Integer control value; tuning controls use enumeration values and other units depend on the named option.
- Argument 3 — Codec error: libvpx description of the returned error, text.

The tuning occurrence applies psnr/ssim, the content occurrence applies default/screen, and the integer occurrence covers codec-specific controls such as speed, quantization, reference windows, and tiling. The printed key identifies the setting.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set speed=4: Invalid parameter
```

## Short description

VPX encoder control was rejected.

## Trigger condition

libvpx returns a non-success status while applying a tuning mode, content-tuning mode, or range-checked integer control.

## Explanation

Control setup fails and encoder initialization returns failure.

## Possible causes

- The loaded VPX codec does not accept the requested control or value.

## What to check

1. Check the option name, numeric value, error description, and VP8 versus VP9 selection.

## Recommended action

Select a supported value or compatible libvpx library and restart encoding.
