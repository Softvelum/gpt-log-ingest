# RTSP sender fell behind the live buffer

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-6669922a06ac225b

## Log pattern

```text
failed to send stream in appropriate rate. s=%d ip=%s stream='%s/%s'
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.
- Argument 2 — Peer address: Remote client IP address.
- Argument 3 — Application: Live-stream application name.
- Argument 4 — Stream: Live-stream name within its application.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send stream in appropriate rate. s=25 ip=192.0.2.2 stream='live/camera'
```

## Short description

RTSP sender fell behind the live buffer.

## Trigger condition

The next requested media item is no longer available because the consumer is too slow.

## Explanation

The sender resets its media position, waits for new messages, and requires a video keyframe before continuing video. This path attempts resynchronization rather than immediately closing the socket.

## Possible causes

- The next requested media item is no longer available because the consumer is too slow.

## What to check

1. Check whether the receiver is consuming media fast enough to remain within the live buffer.
