# Codec option value is invalid

Product: Nimble Streamer
Component: FFmpeg logging and media input
Logging function: log_e
Log level: error
Documentation ID: log_e-47911d99fe9cd1a2

## Log pattern

```text
invalid param value: %s=%s for [%s]
```

## Parameters

- Argument 1 — Option: Requested codec option name, text.
- Argument 2 — Value: Requested codec option value, text.
- Argument 3 — Stream: Stream name associated with the encoder or decoder being configured, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid param value: example_option=invalid for [live/camera]
```

## Short description

Codec option value is invalid.

## Trigger condition

While applying encoder or decoder options, the library rejects the value as invalid.

## Explanation

The rejected option is logged and processing continues with subsequent options; this helper does not abort codec initialization.

## Possible causes

- The supplied value is not accepted for the selected codec option.

## What to check

1. Check the option value syntax and allowed values for the selected codec.

## Recommended action

Use a supported option and value.
