# RIST runtime loading failed

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-87c9d6e06b44850a

## Log pattern

```text
failed load rist libs, id=%s
```

## Parameters

- Argument 1 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

## Short description

RIST runtime loading failed.

## Trigger condition

The RIST shared-library and symbol loader returns failure.

## Explanation

Connection initialization stops before URL parsing or creation of a sender/receiver context.

## Possible causes

- The RIST shared-library and symbol loader returns failure.

## What to check

1. Check whether the required RIST runtime library and symbols can be loaded.
