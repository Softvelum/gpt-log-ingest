# Playlist downloaded content retained

Product: Nimble Streamer
Component: Server playlists
Logging function: log_i
Log level: info
Documentation ID: log_i-e66a4692d3d14e5a

## Log pattern

```text
locked downloaded content url=%s
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
locked downloaded content url=/media/program.mp4
```

## Short description

Playlist downloaded content retained.

## Trigger condition

A notified content download reaches the ready cache state.

## Explanation

The cache item is retained for playlist use and the pending request is removed.

## Possible causes

- A notified content download reaches the ready cache state.
