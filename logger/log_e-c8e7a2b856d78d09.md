# First video frame could not initialize its codec

## Short description

First video frame could not initialize its codec.

## Trigger condition

Video configuration is incomplete when buffered H.264 data is processed, or when an H.265 timestamp change causes the previous buffered frame to be processed, and codec setup fails.

## Explanation

The RTP parser reports a stream failure before delivering that frame. The same text covers H.264 sequence/picture parameter sets and H.265 video/sequence/picture parameter sets.

## Possible causes

- Video configuration is incomplete when buffered H.264 data is processed, or when an H.265 timestamp change causes the previous buffered frame to be processed, and codec setup fails.

## What to check

1. Check that the first video data supplies usable codec parameter sets.
