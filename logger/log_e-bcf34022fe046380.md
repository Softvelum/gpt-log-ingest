# Unexpected exception during disk cache loading

Product: Nimble Streamer
Component: Background maintenance
Logging function: log_e
Log level: error

## Log pattern

```text
unknown exception caught while loading data cache
```

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Unexpected exception during disk cache loading.

## Trigger condition

A cache loading batch throws an exception that is not caught as a standard exception.

## Explanation

The utility loop catches it, checks whether loading finished, and continues its maintenance loop. Later iterations can attempt further loading.

## Possible causes

- Cache loading raised an exception without a standard exception description.

## What to check

1. Check adjacent cache loading and filesystem messages.

## Recommended action

Investigate the cache loading failure using the surrounding diagnostics.
