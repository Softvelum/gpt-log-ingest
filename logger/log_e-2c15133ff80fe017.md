# Runtime library could not be unloaded on Windows

Product: Nimble Streamer
Component: Runtime library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-2c15133ff80fe017

## Log pattern

```text
FreeLibrary failed for lib='%s' dl_=%p errno=%d
```

## Parameters

- Argument 1 — Library: Requested library name or path, text.
- Argument 2 — Library handle: Loaded library handle, pointer printed in hexadecimal.
- Argument 3 — Windows error: Windows last-error code, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
FreeLibrary failed for lib='libexample.so' dl_=0x12340000 errno=6
```

## Short description

Runtime library could not be unloaded on Windows.

## Trigger condition

Releasing a non-null library handle fails on Windows.

## Explanation

The stored handle is cleared even though release failed.

## Possible causes

- The Windows library release operation failed.

## What to check

1. Check the Windows error and library handle.

## Recommended action

Investigate the reported Windows loader error.
