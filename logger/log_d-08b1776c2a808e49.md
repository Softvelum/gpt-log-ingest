# VAAPI coded buffer size selected

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-08b1776c2a808e49

## Log pattern

```text
codedbuf_size=%d

```

## Parameters

- Argument 1 — Buffer capacity: Encoded-output buffer capacity, 32-bit unsigned byte count printed in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
codedbuf_size=3264000

```

## Short description

VAAPI coded buffer size selected.

## Trigger condition

Encoder setup calculates output-buffer capacity from the aligned picture area at 400 bytes per 16-by-16 block.

## Explanation

The capacity is reported immediately before the buffer allocation attempt.
