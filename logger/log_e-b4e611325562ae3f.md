# SVT HEVC frame submission failed

Product: Nimble Streamer
Component: SVT HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-b4e611325562ae3f

## Log pattern

```text
failed to encode frame, err=%d
```

## Parameters

- Argument 1 — Encoder status: SVT HEVC result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encode frame, err=-1
```

## Short description

SVT HEVC frame submission failed.

## Trigger condition

Submitting a YUV420P picture to the initialized encoder returns an error.

## Explanation

The current frame write returns failure before retrieving encoded packets.

## Possible causes

- SVT HEVC rejects the input picture.

## What to check

1. Check the SVT status and input frame validity.

## Recommended action

Correct the input or encoder state and retry.
