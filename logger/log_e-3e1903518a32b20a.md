# Playlist E-AC-3 frame parsing failed

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-3e1903518a32b20a

## Log pattern

```text
ServerBlockProcessor: EAC3_Reader::processEAC3Bitstream failed for vod file [%s], stream=[%s/%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: EAC3_Reader::processEAC3Bitstream failed for vod file [/media/program.mp4], stream=[live/camera]
```

## Short description

Playlist E-AC-3 frame parsing failed.

## Trigger condition

E-AC-3 parsing returns failure or produces no frame buffer.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- E-AC-3 parsing returns failure or produces no frame buffer.

## What to check

1. Check the source E-AC-3 bitstream for complete valid frames.

## Recommended action

Check the source E-AC-3 bitstream for complete valid frames.
