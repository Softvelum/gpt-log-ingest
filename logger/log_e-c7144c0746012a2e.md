# Playlist H.265 configuration cannot be parsed

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-c7144c0746012a2e

## Log pattern

```text
ServerBlockProcessor: failed to parse hevc video extradata for vod file url=[%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: failed to parse hevc video extradata for vod file url=[/media/program.mp4]
```

## Short description

Playlist H.265 configuration cannot be parsed.

## Trigger condition

Parsing either start-code H.265 parameter sets or an H.265 decoder configuration record fails.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- Parsing either start-code H.265 parameter sets or an H.265 decoder configuration record fails.

## What to check

1. Check the structure of the source H.265 codec configuration.

## Recommended action

Check the structure of the source H.265 codec configuration.
