# Video output codec is invalid

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-a934042e3e6b3350

## Log pattern

```text
failed to write video pkt, invalid video codec %d [%s/%s]
```

## Parameters

- Argument 1 — Video codec: Internal stream video-codec identifier, integer; zero means no codec was selected.
- Argument 2 — Application: Output application name, text.
- Argument 3 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write video pkt, invalid video codec 0 [live/encoded]
```

## Short description

Video output codec is invalid.

## Trigger condition

After codec selection and timestamp synchronization, the video packet dispatch value is outside H.264, HEVC, MPEG-2, VP8, VP9, and AV1.

## Explanation

The packet is rejected and output processing fails.

## Possible causes

- The selected encoder codec is unsupported by the output packet path or codec setup left the value unset.

## What to check

1. Check the reported stream codec value and preceding encoder-name or configuration messages.

## Recommended action

Use a supported output codec and restart the affected stream.
