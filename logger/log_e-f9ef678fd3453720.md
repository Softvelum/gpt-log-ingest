# SDI audio frame conversion failed

Product: Nimble Streamer
Component: SDI audio conversion
Logging function: log_e
Log level: error
Documentation ID: log_e-f9ef678fd3453720

## Log pattern

```text
failed to rescale audio for [%s]
```

## Parameters

- Argument 1 — Stream: Device input or output stream name, text; the direction follows the emitting audio operation.

The stream identifies the input or output according to the emitting device operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to rescale audio for [live/camera]
```

## Short description

SDI audio frame conversion failed.

## Trigger condition

Converting an audio frame returns a nonzero result.

## Explanation

The current audio operation returns failure. Device input converts samples to planar float without changing the sample rate or channel layout. Device output converts samples to signed 16-bit interleaved audio at 48000 samples per second.

## Possible causes

- FFmpeg cannot convert the supplied audio frame with the current configuration.

## What to check

1. Check the input sample format, sample rate and channel layout, and nearby FFmpeg diagnostics.

## Recommended action

Use supported audio parameters and retry the device operation.
