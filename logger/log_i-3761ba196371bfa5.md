# Cached geolocation database opened

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_i
Log level: info
Documentation ID: log_i-3761ba196371bfa5

## Log pattern

```text
opened GeoIP database='%s' version='%s'
```

## Parameters

- Argument 1 — Database path: Text path of the cached country database.
- Argument 2 — Version: Trimmed version text; it may be empty or retain an earlier value if reading the version file fails.

## Log examples

Illustrative examples; these are not captured server logs.

```text
opened GeoIP database='/var/cache/nimble/GeoLite2-Country.mmdb' version='20260928'
```

## Short description

Cached geolocation database opened.

## Trigger condition

The cached country database and version file exist, and database opening succeeds.

## Explanation

The version is read and trimmed when possible, then reported with the opened path. The log does not prove that reading the version file succeeded.
