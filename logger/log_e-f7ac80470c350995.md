# Playlist AV1 configuration was rejected

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-f7ac80470c350995

## Log pattern

```text
ServerBlockProcessor: failed to set av1 video header for vod file url=[%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: failed to set av1 video header for vod file url=[/media/program.mp4]
```

## Short description

Playlist AV1 configuration was rejected.

## Trigger condition

A changed AV1 configuration cannot initialize the output stream.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- A changed AV1 configuration cannot initialize the output stream.

## What to check

1. Check the source AV1 configuration record.

## Recommended action

Check the source AV1 configuration record.
