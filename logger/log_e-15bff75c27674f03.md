# No Quick Sync encoded packet slot is free

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-15bff75c27674f03

## Log pattern

```text
%p failed to get free packet
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to get free packet
```

## Short description

No Quick Sync encoded packet slot is free.

## Trigger condition

The next packet slot is already past the end of the packet pool when another input frame is submitted.

## Explanation

The frame-writing operation fails before submitting an asynchronous encode request.

## Possible causes

- All configured packet slots remain occupied by pending encoding work.

## What to check

1. Check preceding encode or synchronization results and asynchronous depth.

## Recommended action

Resolve the blocked encoder state and restart the affected stream.
