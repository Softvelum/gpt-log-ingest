# Waiting for another origin download

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-34385ec8e2766b34

## Log pattern

```text
waiting for updates for item key='%s'
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waiting for updates for item key='/live/camera/segment1.ts'
```

## Short description

Waiting for another origin download.

## Trigger condition

A restreaming cache item remains newly reserved or downloading after observer registration.

## Explanation

The request waits for a cached playlist or for media response headers instead of starting another download.

## Possible causes

- A restreaming cache item remains newly reserved or downloading after observer registration.
