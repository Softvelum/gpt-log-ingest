# RTMP PROXY protocol header is invalid

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-42ddf70ac8d27907

## Log pattern

```text
failed to parse proxy protocol header '%s'
```

## Parameters

- Argument 1 — Encoded header: Base64 representation of the rejected complete PROXY header including its line ending.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse proxy protocol header 'UFJPWFkgSU5WQUxJRA0K'
```

## Short description

RTMP PROXY protocol header is invalid.

## Trigger condition

PROXY support is enabled, a complete header ending in CRLF is found within the allowed prefix, and the v1 header parser rejects it.

## Explanation

The incoming connection is shut down before RTMP handshake processing. The displayed text is Base64, not the literal header.

## Possible causes

- PROXY support is enabled, a complete header ending in CRLF is found within the allowed prefix, and the v1 header parser rejects it.

## What to check

1. Decode the Base64 header and check its PROXY version, transport, addresses, and ports.

## Recommended action

Send a valid PROXY protocol v1 header matching the configured listener.
