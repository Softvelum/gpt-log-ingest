# Client disconnected during origin setup

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-b0c0024956332f37

## Log pattern

```text
client s=%d closed connection while connecting to origin s=%d
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Origin socket: Integer identifying the local origin socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
client s=18 closed connection while connecting to origin s=17
```

## Short description

Client disconnected during origin setup.

## Trigger condition

The client closes while the session is connecting to or sending its request to the origin.

## Explanation

The origin socket is closed and the client session is marked finished.

## Possible causes

- The client closes while the session is connecting to or sending its request to the origin.

## What to check

1. Check whether the player canceled or timed out while the origin connection was being established.

## Recommended action

Check whether the player canceled or timed out while the origin connection was being established.
