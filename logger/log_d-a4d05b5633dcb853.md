# Unrecognized managed task event

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_d
Log level: debug
Documentation ID: log_d-a4d05b5633dcb853

## Log pattern

```text
unknown event for fd=%d ev=0x%x
```

## Parameters

- Argument 1 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 2 — Event mask: Hexadecimal socket-event bit mask.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown event for fd=12 ev=0x8
```

## Short description

Unrecognized managed task event.

## Trigger condition

An event for a known task indicates neither output-channel closure nor readable output. Available only on Linux builds.

## Explanation

The activity time is updated, but no output is read and no task state transition occurs.

## Possible causes

- The event mask contains no recognized read or hang-up condition.

## What to check

1. Inspect the event mask and the task output descriptor.
