# Plain socket shutdown failed

Product: Nimble Streamer
Component: Stream checks, RTMP, and RTSP
Logging function: log_e
Log level: error
Documentation ID: log_e-ce6440c74a201961

## Log pattern

```text
failed to shutdown s=%d (errno=%d)
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — error: Platform socket error code; operating system errno on non-Windows builds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to shutdown s=12 (errno=9)
```

## Short description

Plain socket shutdown failed.

## Trigger condition

The operating system rejects a bidirectional shutdown request.

## Explanation

The owning object moves directly to its shut-down state. Plain RTMP uses a separate verbose message for its specifically recognized not-connected error; other RTMP failures and the checker/RTSP failures use this error entry.

## Possible causes

- The socket shutdown operation failed.

## What to check

1. Check the error and previous connection closure messages.

## Recommended action

Investigate repeated shutdown errors and socket lifetime tracking.
