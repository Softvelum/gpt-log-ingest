# Peer host name resolution failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_e
Log level: error
Documentation ID: log_e-c1c81135250f4a14

## Log pattern

```text
failed to resolve host='%s' ret=%d err='%s'
```

## Parameters

- Argument 1 — Host: Text host name submitted for connection.
- Argument 2 — Resolver result: Integer host name resolver error.
- Argument 3 — Resolver detail: Text associated with the resolver error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to resolve host='origin.example' ret=-2 err='Name or service not known'
```

## Short description

Peer host name resolution failed.

## Trigger condition

IPv6-capable connection handling attempts host name resolution and receives a nonzero resolver result.

## Explanation

Connection setup returns failure before creating the replacement socket.

## Possible causes

- The host name resolver did not return an address.

## What to check

1. Inspect the host and resolver error text.
