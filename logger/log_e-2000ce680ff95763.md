# WHIP session request exceeds control buffer

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-2000ce680ff95763

## Log pattern

```text
too big sdp for whip session=%s/%s
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
too big sdp for whip session=live/camera
```

## Short description

WHIP session request exceeds control buffer.

## Trigger condition

Writing the length-prefixed session-start JSON into the 65,536-byte control buffer fails. The body includes base64 SDP and helper parameters.

## Explanation

The affected session is marked finished and its publishing authorization record is removed; the helper start request is not successfully queued.

## Possible causes

- The encoded SDP plus other start parameters exceed the available control buffer.

## What to check

1. Check SDP size and the complete encoded session-start request size.

## Recommended action

Reduce the oversized negotiation data or correct the unexpectedly large helper parameters.
