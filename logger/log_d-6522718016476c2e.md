# Stream checks exceeded their normal time allowance

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-6522718016476c2e

## Log pattern

```text
checker was not able to process all tasks in appropriate interval
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
checker was not able to process all tasks in appropriate interval
```

## Short description

Stream checks exceeded their normal time allowance.

## Trigger condition

Tasks remain after the normal batch limit, or the wall clock moves before the batch start.

## Explanation

The checker requests shutdown for remaining tasks. The limits are 180 seconds for regular checks and 30 seconds for immediate checks; cleanup can continue until the longer removal deadline.
