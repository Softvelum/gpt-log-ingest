# Audio filter rebuilt for changed input parameters

Product: Nimble Streamer
Component: Audio filtering worker
Logging function: log_d
Log level: debug
Documentation ID: log_d-5a9fc2468025c816

## Log pattern

```text
audio filter frame params changed, id=%s stream=%s
```

## Parameters

- Argument 1 — Filter identifier: Configured filter identifier, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio filter frame params changed, id=audio-main stream=live/camera
```

## Short description

Audio filter rebuilt for changed input parameters.

## Trigger condition

Changing parameters during operation is enabled and the sample rate, sample format, or channel layout differs from the initialized input.

## Explanation

The filter graph and all its inputs are recreated and output writers are reattached before processing the current frame; the old graph is not flushed.
