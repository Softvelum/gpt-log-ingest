# Short NDI source name resolved to a full name

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-141a6d4e818f694a

## Log pattern

```text
found ndi full name: %s
```

## Parameters

- Argument 1 — Resolved name: Full discovered NDI source name selected for the requested short name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
found ndi full name: HOST (Camera)
```

## Short description

Short NDI source name resolved to a full name.

## Trigger condition

Discovery matches the requested name to a full source name with a matching parenthesized suffix.

## Explanation

The receiver uses the resolved full name for creation. An exact name match does not produce this message.

## Possible causes

- Successful short-name matching during NDI discovery.
