# Transmuxing buffer is below its minimum

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-0e591b66ff602ab7

## Log pattern

```text
invalid parameter value: %s. 5M is a minimum value
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. 5M is a minimum value
```

## Short description

Transmuxing buffer is below its minimum.

## Trigger condition

While reading configuration, the live or VOD transmuxing buffer value is below five megabytes.

## Explanation

Configuration processing reports failure and the file loader stops at this line. The parsed value is assigned before the failure is returned; this message does not mean it was clamped to a valid range.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires at least five megabytes.

## Recommended action

Correct the value to at least five megabytes and reload configuration.
