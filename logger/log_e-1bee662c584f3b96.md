# Video decoder fell behind the live buffer

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-1bee662c584f3b96

## Log pattern

```text
failed to decode video in appropriate rate from [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decode video in appropriate rate from [live/camera]
```

## Short description

Video decoder fell behind the live buffer.

## Trigger condition

Reading the next video item reports that the requested item has expired because the reader is too slow.

## Explanation

The read index is reset, non-keyframes are skipped, and the worker attempts to restart from the first available decodable item.

## Possible causes

- Video decoding or downstream processing is slower than the retained live stream.

## What to check

1. Check decoder throughput, output backpressure, and host or GPU load.

## Recommended action

Remove the processing bottleneck; the worker already attempts to resume at a usable keyframe.
