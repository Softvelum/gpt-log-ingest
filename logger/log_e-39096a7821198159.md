# Codec option could not be applied

Product: Nimble Streamer
Component: FFmpeg logging and media input
Logging function: log_e
Log level: error
Documentation ID: log_e-39096a7821198159

## Log pattern

```text
invalid param: %s=%s for [%s]
```

## Parameters

- Argument 1 — Option: Requested codec option name, text.
- Argument 2 — Value: Requested codec option value, text.
- Argument 3 — Stream: Stream name associated with the encoder or decoder being configured, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid param: example_option=invalid for [live/camera]
```

## Short description

Codec option could not be applied.

## Trigger condition

While applying encoder or decoder options, the library reports another nonzero option-setting error.

## Explanation

The rejected option is logged and processing continues with subsequent options; this helper does not abort codec initialization.

## Possible causes

- The codec library reports an option-setting error outside the separately handled unknown-name, range, and invalid-value cases.

## What to check

1. Check the selected codec and nearby library diagnostics for the option-setting failure.

## Recommended action

Use a supported option and value.
