# Widevine response processing failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-871446ea3a494ab9

## Log pattern

```text
[drm] Widevine response processing failed for='%s' cpi=%u/%u status='%s':
%.*s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned index of the requested or selected key rotation period.
- Argument 3 — Period count: Unsigned number of consecutive crypto periods requested.
- Argument 4 — Provider status: Text containing the provider status code.
- Argument 5 — Response length: Integer limit in bytes for the response text that follows.
- Argument 6 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine response processing failed for='live/camera' cpi=120/2 status='ERROR':
{}
```

## Short description

Widevine response processing failed.

## Trigger condition

The response cannot be parsed or its provider status is not OK.

## Explanation

Keys in the requested period range are marked failed and waiting consumers are notified.

## Possible causes

- The response cannot be parsed or its provider status is not OK.

## What to check

1. Check the response status and preceding Widevine parsing errors.

## Recommended action

Check the response status and preceding Widevine parsing errors.
