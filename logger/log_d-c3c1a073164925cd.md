# PES packet length is shorter than its header

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-c3c1a073164925cd

## Log pattern

```text
wrong-negative pes size pid=%d
```

## Parameters

- Argument 1 — PID: Affected elementary-stream packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wrong-negative pes size pid=256
```

## Short description

PES packet length is shorter than its header.

## Trigger condition

Subtracting parsed timestamp bytes and remaining header overhead makes the nonzero declared PES packet length negative.

## Explanation

The current transport packet is rejected. Its elementary-stream parser is reset, buffered partial PES data is discarded, and the camera parser searches for another packet boundary.

## Possible causes

- Subtracting parsed timestamp bytes and remaining header overhead makes the nonzero declared PES packet length negative.

## What to check

1. Compare the PES packet length with the full header size.

## Recommended action

Correct malformed PES framing at the source.
