# AAC LATM configuration text is too short

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-4c400a432df1440c

## Log pattern

```text
mp4a-latm: unable to parse config=%s

```

## Parameters

- Argument 1 — LATM configuration: Original SDP configuration text before hexadecimal decoding.

## Log examples

Illustrative examples; these are not captured server logs.

```text
mp4a-latm: unable to parse config=12

```

## Short description

AAC LATM configuration text is too short.

## Trigger condition

An SDP LATM configuration is present but contains fewer than four hexadecimal characters.

## Explanation

LATM initialization returns failure. An absent configuration field follows a separate supported path that reads configuration from media packets.

## Possible causes

- An SDP LATM configuration is present but contains fewer than four hexadecimal characters.

## What to check

1. Check the LATM configuration advertised in SDP.

## Recommended action

Supply complete LATM configuration, or use supported in-band configuration.
