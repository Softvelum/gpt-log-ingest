# Transport restreaming retention starts

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-b91316a969e81e9a

## Log pattern

```text
restreaming started for cam=%s
```

## Parameters

- Argument 1 — Camera ID: Transport input camera identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
restreaming started for cam=camera1
```

## Short description

Transport restreaming retention starts.

## Trigger condition

A live restreaming buffer has no active item storage when start is requested.

## Explanation

The packet ring is allocated, the partial item is cleared, and the write index resets to zero.

## Possible causes

- A live restreaming buffer has no active item storage when start is requested.

## What to check

1. Correlate with the camera and output restreaming settings.

## Recommended action

No action is needed for intended restreaming.
