# Unused OCR decoder removed

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_d
Log level: debug
Documentation ID: log_d-68901f89b0c02b4b

## Log pattern

```text
tesseract decoder removed on inactivity, lang=%s
```

## Parameters

- Argument 1 — Language: Lowercase DVB subtitle language code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
tesseract decoder removed on inactivity, lang=eng
```

## Short description

Unused OCR decoder removed.

## Trigger condition

A language decoder reaches three inactivity checks without being accessed for recognition.

## Explanation

The cached decoder is destroyed. A later subtitle in that language can initialize a new one.

## Possible causes

- A language decoder reaches three inactivity checks without being accessed for recognition.

## What to check

1. Check whether subtitles for the indicated language have stopped arriving.
