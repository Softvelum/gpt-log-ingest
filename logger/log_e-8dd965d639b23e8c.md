# Existing protected live stream blocks registration

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-8dd965d639b23e8c

## Log pattern

```text
stream already registered and not removable[%s]. failed to register
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream already registered and not removable[live/camera]. failed to register
```

## Short description

Existing protected live stream blocks registration.

## Trigger condition

A stream with the requested name already exists and is marked as not removable.

## Explanation

Registration returns no stream object. The previous stream remains registered.

## Possible causes

- The requested name belongs to a protected existing stream.

## What to check

1. Check which input already owns the same application and stream name.

## Recommended action

Use a distinct stream name or remove the conflict through the owning input lifecycle.
