# VCAS CPIX endpoint is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-1767c946ab1967cc

## Log pattern

```text
keyserver URL must be provided for vcas_cpix protection type
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
keyserver URL must be provided for vcas_cpix protection type
```

## Short description

VCAS CPIX endpoint is missing.

## Trigger condition

The VCAS CPIX key-server URL is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The VCAS CPIX key-server URL is empty.

## What to check

1. Provide the VCAS CPIX key-server URL.

## Recommended action

Provide the VCAS CPIX key-server URL.
