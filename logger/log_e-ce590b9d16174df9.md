# AJA stream acquisition failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-ce590b9d16174df9

## Log pattern

```text
Unable to acquire device '%s' because another app(%d) owns it
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Owner process ID: Integer process identifier reported by the device ownership query.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Unable to acquire device 'AJA device' because another app(1234) owns it
```

## Short description

AJA stream acquisition failed.

## Trigger condition

The card cannot acquire the device stream for this process after querying its current owner.

## Explanation

Initialization fails before changing device services. The reported process ID is the owner returned by the earlier ownership query.

## Possible causes

- The card cannot acquire the device stream for this process after querying its current owner.

## What to check

1. Check the application currently owning the device stream.

## Recommended action

Release the device stream from the other application before retrying.
