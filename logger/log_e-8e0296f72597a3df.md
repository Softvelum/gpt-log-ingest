# Icecast metadata cannot be encoded for injection

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-8e0296f72597a3df

## Log pattern

```text
failed to fill icecast metadata for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to fill icecast metadata for [live/camera]
```

## Short description

Icecast metadata cannot be encoded for injection.

## Trigger condition

The RTMP metadata representation of the supplied Icecast title and URL cannot be written into an 8192-byte temporary buffer.

## Explanation

This metadata update is not queued for stream injection.

## Possible causes

- The RTMP metadata representation of the supplied Icecast title and URL cannot be written into an 8192-byte temporary buffer.

## What to check

1. Check the combined title and URL length.

## Recommended action

Shorten oversized metadata fields.
