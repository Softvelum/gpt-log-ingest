# RTSP RTP connection reported open

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-84619ffcf399b40b

## Log pattern

```text
rtsp s=%d added rtp s=%d
```

## Parameters

- Argument 1 — RTSP socket: Parent control-session socket descriptor.
- Argument 2 — RTP socket: Newly opened RTP socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtsp s=25 added rtp s=26
```

## Short description

RTSP RTP connection reported open.

## Trigger condition

The new RTP connection reports its socket to the parent RTSP input.

## Explanation

The parent looks up the media-track association and stores the connection when found. A missing association instead requests shutdown, so this message alone does not prove registration succeeded.

## Possible causes

- Normal callback during UDP RTP connection creation.

## What to check

1. If setup stops afterward, check whether the socket has a media-track association.
