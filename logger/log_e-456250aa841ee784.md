# Advertising chunk cache state is unusable

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-456250aa841ee784

## Log pattern

```text
invalid cache item state=%d for ads item key='%s'
```

## Parameters

- Argument 1 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid cache item state=4 for ads item key='/live/camera/segment1.ts'
```

## Short description

Advertising chunk cache state is unusable.

## Trigger condition

An existing advertising chunk cache item is neither newly reserved, receiving data, nor ready.

## Explanation

HTTP 500 is prepared; a fragmented or removed item cannot be used by this chunk path.

## Possible causes

- An existing advertising chunk cache item is neither newly reserved, receiving data, nor ready.

## What to check

1. Inspect cancellation or cache state changes for this chunk and the advertising request that created it.

## Recommended action

Inspect cancellation or cache state changes for this chunk and the advertising request that created it.
