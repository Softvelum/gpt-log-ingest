# Cannot allocate DVB subtitle decoder

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-3fda9e74cb327525

## Log pattern

```text
failed to alloc dvb subtitle decoder context for [%s]
```

## Parameters

- Argument 1 — Stream: Application and stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc dvb subtitle decoder context for [live/news]
```

## Short description

Cannot allocate DVB subtitle decoder.

## Trigger condition

The media library cannot allocate a decoder context.

## Explanation

Decoder initialization fails; the current subtitle decode returns failure.

## Possible causes

- The media library cannot allocate a decoder context.

## What to check

1. Check memory availability and nearby media-library diagnostics.
