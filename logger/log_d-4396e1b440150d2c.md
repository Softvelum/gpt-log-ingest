# VAAPI surface pixel format is unsupported

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-4396e1b440150d2c

## Log pattern

```text
unsupported output frame fourcc=%x

```

## Parameters

- Argument 1 — Surface format: Derived image FourCC, unsigned integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported output frame fourcc=32315659

```

## Short description

VAAPI surface pixel format is unsupported.

## Trigger condition

The derived surface image has a FourCC other than NV12.

## Explanation

Frame encoding fails before pixel copying, despite this message having debug severity.

## Possible causes

- The driver exposed a surface layout this encoder cannot populate.

## What to check

1. Check the reported surface FourCC and VA driver format support.

## Recommended action

Use a driver that exposes NV12 surfaces or select another encoder backend.
