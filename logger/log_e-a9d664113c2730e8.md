# Icecast socket receive failed

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-a9d664113c2730e8

## Log pattern

```text
failed to recv buffer from client s=%d errno=%d
```

## Parameters

- Argument 1 — Socket: Numeric connection socket descriptor.
- Argument 2 — Error: Operating-system error number captured after the failed read.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv buffer from client s=42 errno=104
```

## Short description

Icecast socket receive failed.

## Trigger condition

Reading from the peer returns a receive error.

## Explanation

The session is marked shut down; no further audio is processed in this callback.

## Possible causes

- Reading from the peer returns a receive error.

## What to check

1. Inspect the operating-system error number and source connection state.
