# Application has no external DRM settings

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-2ab1e28f8b02b891

## Log pattern

```text
[drm] app='%s' stream='%s' is not protected with external key server
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] app='live' stream='camera' is not protected with external key server
```

## Short description

Application has no external DRM settings.

## Trigger condition

A stream registers without DRM settings for its application.

## Explanation

External key registration is skipped; this does not describe separate default HLS encryption settings.

## Possible causes

- A stream registers without DRM settings for its application.

## What to check

1. Check application DRM settings if external protection was intended.

## Recommended action

Check application DRM settings if external protection was intended.
