# Cached file size disagrees with capacity

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-55c71f912c983556

## Log pattern

```text
cache item key='%s' file='%s' error: item capacity=%llu but file size=%lld
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — file: Filesystem path of the cache data or metadata file being handled.
- Argument 3 — capacity: Allocated capacity of the item in bytes.
- Argument 4 — file size: End offset returned by the file seek, or a negative failure result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item key='movie' file='/var/cache/nimble/movie' error: item capacity=4096 but file size=1024
```

## Short description

Cached file size disagrees with capacity.

## Trigger condition

Seeking to the end of a reopened cache file does not return its recorded capacity.

## Explanation

The descriptor is closed, the acquired reference is released, and the cache item is removed. A failed seek can also produce this message.

## Possible causes

- The stored file size changed or the seek failed.

## What to check

1. Compare the file length with the recorded capacity and check filesystem access.

## Recommended action

Investigate the changed or unreadable cache file; it will need to be cached again.
