# Registering a live stream from a source URL

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_v
Log level: verbose
Documentation ID: log_v-af5563dd688bb567

## Log pattern

```text
LiveStreamManager::registerStream name='%s' proto=%d source_url=%s
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.
- Argument 2 — protocol: Input protocol number: 0 RTMP, 1 RTSP, 2 Icecast, 3 MPEG-TS, 4 encoder, 5 NDI, 6 playlist, 7 WebRTC, 8 Dante, 9 OMT, 10 SDI, 11 AJA, 12 none.
- Argument 3 — source\_url: Source URL supplied during stream registration.

## Log examples

Illustrative examples; these are not captured server logs.

```text
LiveStreamManager::registerStream name='live/camera' proto=1 source_url=rtsp://192.0.2.20/camera
```

## Short description

Registering a live stream from a source URL.

## Trigger condition

A stream registration has no publisher IP address but has a nonempty source URL.

## Explanation

The trace precedes stream-object creation and registration; it does not establish that media data has arrived.
