# Fragmented MP4 HLS audio initialization exceeds its buffer

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-27d6c1785dc886c0

## Log pattern

```text
Fmp4LiveSegmentList::generate_audio_initialization_segment failed to generate init segment for [%s/%s] aac_codec_info_size=%d
```

## Parameters

- Argument 1 — Application: Application containing the affected live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Configuration size: Supplied decoder-configuration size in bytes; total initialization size also includes MP4 overhead.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Fmp4LiveSegmentList::generate_audio_initialization_segment failed to generate init segment for [live/camera] aac_codec_info_size=2048
```

## Short description

Fragmented MP4 HLS audio initialization exceeds its buffer.

## Trigger condition

The calculated audio initialization-segment size exceeds the fixed 1,024-byte buffer. This shared message covers plain and CENC audio initialization.

## Explanation

A fallback unencrypted initialization segment with zero codec-configuration bytes is generated and queued for the HLS track. This fallback does not preserve requested CENC initialization.

## Possible causes

- The calculated audio initialization-segment size exceeds the fixed 1,024-byte buffer. This shared message covers plain and CENC audio initialization.

## What to check

1. Check decoder-configuration size and any encryption initialization overhead.

## Recommended action

Correct oversized or malformed initialization data before packaging.
