# Could not create the RTMP publishing worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-356d2e17f4f3e652

## Log pattern

```text
failed to create RTMPPUBLISHER thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create RTMPPUBLISHER thread
```

## Short description

Could not create the RTMP publishing worker.

## Trigger condition

One of the configured RTMP publishing workers is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the RTMP publishing worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed RTMP publishing worker.
