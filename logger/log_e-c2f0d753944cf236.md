# Audio filter input could not be connected

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-c2f0d753944cf236

## Log pattern

```text
failed to link abuffer to filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to link abuffer to filter=[in]anull[out], stream=live/camera
```

## Short description

Audio filter input could not be connected.

## Trigger condition

Linking the audio source to the named filter input returns a negative result.

## Explanation

Input setup fails.

## Possible causes

- The input cannot be linked to the configured audio filter.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
