# Icecast metadata history limit is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-ed21a6394ad35296

## Log pattern

```text
invalid parameter value: %s. should be <= 1024 and >= 10
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be <= 1024 and >= 10
```

## Short description

Icecast metadata history limit is invalid.

## Trigger condition

While reading configuration, the Icecast metadata list count is outside 10 through 1024.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 10 through 1024 metadata entries.

## Recommended action

Correct the value to 10 through 1024 metadata entries and reload configuration.
