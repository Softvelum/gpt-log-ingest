# Ogg FLAC sequence header invalid

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-193b6816b2dd3a3c

## Log pattern

```text
invalid FLAC seq header format for '%s/%s'
```

## Parameters

- Argument 1 — Application: Application name.
- Argument 2 — Stream: Stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid FLAC seq header format for 'live/radio'
```

## Short description

Ogg FLAC sequence header invalid.

## Trigger condition

The accumulated Ogg FLAC header is shorter than 51 bytes or lacks the native FLAC marker at the expected offset.

## Explanation

Audio codec initialization fails and the ingest session is shut down by its caller.

## Possible causes

- The accumulated Ogg FLAC header is shorter than 51 bytes or lacks the native FLAC marker at the expected offset.

## What to check

1. Check the Ogg FLAC mapping header and STREAMINFO block.
