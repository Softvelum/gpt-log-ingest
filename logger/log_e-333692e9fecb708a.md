# Traffic statistics lack application or stream

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_e
Log level: error
Documentation ID: log_e-333692e9fecb708a

## Log pattern

```text
Statistics::UpdateSessionStatistics invalid app='%s' stream='%s'
```

## Parameters

- Argument 1 — Application: Application name as text.
- Argument 2 — Stream: Stream name as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Statistics::UpdateSessionStatistics invalid app='' stream='camera'
```

## Short description

Traffic statistics lack application or stream.

## Trigger condition

A traffic update notification has an empty application name or stream name.

## Explanation

Received, sent and lost byte counters are not updated.

## Possible causes

- At least one required application or stream name is empty.

## What to check

1. Inspect both reported names.

## Recommended action

Provide nonempty application and stream names for the statistics notification.
