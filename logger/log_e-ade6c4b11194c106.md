# Authorization request could not be submitted

Product: Nimble Streamer
Component: Client authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-ade6c4b11194c106

## Log pattern

```text
failed to POST auth request to url='%s'
```

## Parameters

- Argument 1 — Handler URL: Text containing the authorization service URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to POST auth request to url='https://auth.example/authorize'
```

## Short description

Authorization request could not be submitted.

## Trigger condition

Submitting the JSON authorization POST request to the HTTP request processor fails.

## Explanation

For an immediate request, no active request is registered and an invalid request identifier is returned. For a queued request, its client receives a request-failure notification and processing continues with other queued requests. The message does not itself establish whether playback is allowed or denied.

## Possible causes

- The HTTP request processor could not accept the authorization POST request.

## What to check

1. Check the configured authorization handler URL and the associated request-processor error.
