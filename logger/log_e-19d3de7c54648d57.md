# Widevine response structure is invalid

Product: Nimble Streamer
Component: Widevine DRM
Logging function: log_e
Log level: error
Documentation ID: log_e-19d3de7c54648d57

## Log pattern

```text
[Widevine] unexpected response json='%s'
```

## Parameters

- Argument 1 — Response body: Text containing the original outer response.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[Widevine] unexpected response json='{}'
```

## Short description

Widevine response structure is invalid.

## Trigger condition

The response has an unexpected object type, missing encoded payload, invalid tracks array, missing key fields, invalid crypto-period type, or invalid protection-header data.

## Explanation

Key response parsing returns failure at the first rejected field.

## Possible causes

- The response has an unexpected object type, missing encoded payload, invalid tracks array, missing key fields, invalid crypto-period type, or invalid protection-header data.

## What to check

1. Check the Widevine response object, encoded payload, tracks, keys, and protection headers.

## Recommended action

Check the Widevine response object, encoded payload, tracks, keys, and protection headers.
