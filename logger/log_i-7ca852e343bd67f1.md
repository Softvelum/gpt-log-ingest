# Playlist reused an existing cache item

Product: Nimble Streamer
Component: Server playlists
Logging function: log_i
Log level: info
Documentation ID: log_i-7ca852e343bd67f1

## Log pattern

```text
lock existed cache_item key=%s
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
lock existed cache_item key=/media/program.mp4
```

## Short description

Playlist reused an existing cache item.

## Trigger condition

Reserving remote content finds an existing cache item.

## Explanation

A reference is retained and no new download is initiated.

## Possible causes

- Reserving remote content finds an existing cache item.
