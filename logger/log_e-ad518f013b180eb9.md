# AJA output circulation initialization failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-ad518f013b180eb9

## Log pattern

```text
playback failed device=%s/%d reason='AutoCirculate output init failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback failed device=0/0 reason='AutoCirculate output init failed'
```

## Short description

AJA output circulation initialization failed.

## Trigger condition

Hardware setup and routing complete, but initializing the output frame circulation returns failure.

## Explanation

Sender startup returns failure and does not mark the sender started.

## Possible causes

- Hardware setup and routing complete, but initializing the output frame circulation returns failure.

## What to check

1. Check the output channel and configured device frame range.
