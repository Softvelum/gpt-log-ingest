# AJA capture input format is not accepted

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-107b6e133715ba33

## Log pattern

```text
Device/channel '%s'/%u cannot handle %s
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.
- Argument 3 — Video format: Runtime description of the normalized input video format.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device/channel 'AJA device'/0 cannot handle 3840x2160p25
```

## Short description

AJA capture input format is not accepted.

## Trigger condition

The normalized detected format is unsupported by the card, or is classified as 4K or quad-quad video.

## Explanation

Capture video setup returns failure. This path rejects those large-format categories even if a device advertises support.

## Possible causes

- The normalized detected format is unsupported by the card, or is classified as 4K or quad-quad video.

## What to check

1. Check the detected format and the capture path format restrictions.

## Recommended action

Use an input format accepted by both the card and this capture path.
