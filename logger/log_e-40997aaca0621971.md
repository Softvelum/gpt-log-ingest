# NVIDIA codec identifier has no encoder mapping

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-40997aaca0621971

## Log pattern

```text
failed to get nvenc encode GUID for codec=%d
```

## Parameters

- Argument 1 — Codec: FFmpeg codec identifier, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get nvenc encode GUID for codec=999
```

## Short description

NVIDIA codec identifier has no encoder mapping.

## Trigger condition

The requested codec is not H.264 or HEVC, nor AV1 in a build with NVIDIA API version 12 or newer.

## Explanation

Encoder initialization or capability lookup fails before requesting that codec from NVIDIA.

## Possible causes

- An unsupported codec identifier was selected.

## What to check

1. Check the requested output codec and build support for AV1.

## Recommended action

Select a supported NVIDIA output codec.
