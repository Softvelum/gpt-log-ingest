# MPEG-TS advertising boundary buffer allocation failed

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-6ffc71d84541b88e

## Log pattern

```text
failed to alloc chunk buffer, size=%d
```

## Parameters

- Argument 1 — Buffer bytes: Integer size of the requested buffer in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc chunk buffer, size=1048576
```

## Short description

MPEG-TS advertising boundary buffer allocation failed.

## Trigger condition

Growing the buffer for transport tables and the retained audio/video frames fails.

## Explanation

The remainder request is marked failed before the output chunk is assembled.

## Possible causes

- Growing the buffer for transport tables and the retained audio/video frames fails.

## What to check

1. Check the transmuxing buffer limit and available memory for this chunk.

## Recommended action

Check the transmuxing buffer limit and available memory for this chunk.
