# Session advertising context belongs to a different stream

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-b1276cc4f429ad74

## Log pattern

```text
failed to get ads hls context, session=%d app=%s stream=%s
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.
- Argument 2 — application: Requested application name.
- Argument 3 — stream: Requested stream name.

The unsigned-long session identifier is passed to a signed-int conversion, so its printed representation is not reliable across platforms.

## Log examples

No portable example is provided for the mismatched session identifier conversion.

## Short description

Session advertising context belongs to a different stream.

## Trigger condition

A known session already has an HLS advertising context whose application or stream differs from the requested pair.

## Explanation

No advertising context is returned for the request; the existing context remains attached to the session.

## Possible causes

- The session advertising context was created for a different application or stream.

## What to check

1. Compare the session and requested playback stream.

## Recommended action

Use the matching playback session or investigate unexpected stream reuse.
