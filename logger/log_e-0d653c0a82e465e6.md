# DVR export movie metadata send failed

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-0d653c0a82e465e6

## Log pattern

```text
failed to send mixed moov stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

Illustrative examples; these are not captured server logs.

## Short description

DVR export movie metadata send failed.

## Trigger condition

Sending a produced block of MP4 movie metadata fails.

## Explanation

The export closes. The helper serves combined and single-track exports.

## Possible causes

- Sending a produced block of MP4 movie metadata fails.
