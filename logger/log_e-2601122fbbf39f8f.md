# NDI source-list finder could not be created

## Short description

NDI source-list finder could not be created.

## Trigger condition

The NDI runtime returns no finder while building the source-list response.

## Explanation

Source enumeration returns failure before discovery waiting or JSON list construction. Local sources were requested as part of discovery.

## Possible causes

- The NDI runtime returns no finder while building the source-list response.

## What to check

1. Check whether the NDI runtime can initialize source discovery.
