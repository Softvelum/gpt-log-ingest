# UDP input address cannot be bound

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-009bff45d992de30

## Log pattern

```text
failed to connect s=%d '%s:%d' [%d]
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Address: Configured UDP input address; Windows binds the wildcard address while still printing this value.
- Argument 3 — Port: Configured receive port.
- Argument 4 — Error: Operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect s=42 '192.0.2.10:5000' [98]
```

## Short description

UDP input address cannot be bound.

## Trigger condition

Binding the receive socket to the configured port and platform-selected local address fails.

## Explanation

UDP input setup returns failure; despite the wording, this is a bind failure, not a UDP peer connection attempt.

## Possible causes

- Binding the receive socket to the configured port and platform-selected local address fails.

## What to check

1. Check local address availability, port conflicts, and socket error.

## Recommended action

Correct the bind address or resolve the port conflict.
