# Cross-domain policy file could not be loaded

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-534e9c12479f1417

## Log pattern

```text
failed to load crossdomain.xml content from '%s'
```

## Parameters

- Argument 1 — File: Requested file path, text.

At startup this rejects configuration; during periodic or forced reload it preserves the cached policy.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load crossdomain.xml content from '/var/lib/nimble/example.xml'
```

## Short description

Cross-domain policy file could not be loaded.

## Trigger condition

Opening the configured cross-domain policy file fails during initial configuration or a subsequent reload.

## Explanation

Initial configuration fails. During a later reload, the previously cached policy is returned and its remembered write time is not advanced.

## Possible causes

- The policy file cannot be opened for reading.

## What to check

1. Check that the requested file exists and is readable by the server.

## Recommended action

Restore access to the policy file.
