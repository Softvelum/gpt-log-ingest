# Automatic video packet selected

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-311bb5f58fa3d747

## Log pattern

```text
updateAvailable video type implicitly set found pid=%d type=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.
- Argument 2 — stream\_type: Numeric media stream-type code printed in decimal; this is not a packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable video type implicitly set found pid=256 type=27
```

## Short description

Automatic video packet selected.

## Trigger condition

No explicit video packet is configured, no active identifier is selected, and the effective default identifier is nonzero.

## Explanation

The default identifier is selected, added to the requested input set, and its advertised media type is stored. A configured zero-based media index can replace the input default before this branch.
