# DVR storage format is unsupported

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-dc838b1619e46062

## Log pattern

```text
unsupported dvr archive storage format='%d'
```

## Parameters

- Argument 1 — Storage format: Integer configured archive-storage version.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported dvr archive storage format='3'
```

## Short description

DVR storage format is unsupported.

## Trigger condition

Recording reaches a storage mode other than version 1 or version 2.

## Explanation

Adding the segment returns failure.

## Possible causes

- Recording reaches a storage mode other than version 1 or version 2.

## What to check

1. Select a supported DVR storage version.

## Recommended action

Select a supported DVR storage version.
