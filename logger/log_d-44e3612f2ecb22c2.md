# DVR combined timeline entry removal started

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-44e3612f2ecb22c2

## Log pattern

```text
[DvrA::RemS] p=%u vst=%llu st=%llu f='%s of=%llu sz=%u t=%d
```

## Parameters

- Argument 1 — Period: Unsigned recording period identifier.
- Argument 2 — Timeline start: Unsigned start timestamp normalized to the video timescale.
- Argument 3 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 4 — Storage file: Text naming the recorded media storage file.
- Argument 5 — File offset: Unsigned 64-bit byte offset within the media storage file.
- Argument 6 — Segment bytes: Unsigned media-segment size in bytes.
- Argument 7 — Segment type: Integer recorded-segment category: 2 video, 3 audio, 6 DVB subtitle, 7 KLV, 8 WebVTT.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DvrA::RemS] p=1 vst=90000 st=90000 f='/data/dvr/live/camera/1700000000000.dat of=1024 sz=65536 t=3
```

## Short description

DVR combined timeline entry removal started.

## Trigger condition

An entry is selected from the period's combined audio/video timeline.

## Explanation

Audio entries are reconciled with the audio index; video entries also remove matching thumbnails before storage removal.

## Possible causes

- An entry is selected from the period's combined audio/video timeline.
