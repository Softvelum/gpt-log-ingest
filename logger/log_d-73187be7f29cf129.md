# HTTP/2 peer requested connection shutdown

Product: Nimble Streamer
Component: HTTP/2 connection
Logging function: log_d
Log level: debug
Documentation ID: log_d-73187be7f29cf129

## Log pattern

```text
[H2C::GA] p=%p st=%d s=%d laststrm=%lu err=%lu
```

## Parameters

- Argument 1 — Connection identity: In-process connection object address, pointer displayed in hexadecimal; useful only for correlating this process lifetime.
- Argument 2 — Connection state: Connection state code, integer: 0 awaiting preface, 1 awaiting settings, 2 sending settings/acknowledgment, 3 main processing, 4 sending GOAWAY, 5 shutting down, 6 stopped.
- Argument 3 — Socket: Socket descriptor, integer; no unit.
- Argument 4 — Peer last stream identifier: Peer-reported last stream identifier with its reserved high bit removed, unsigned 32-bit value supplied to an unsigned-long decimal conversion.
- Argument 5 — Peer error code: Peer-supplied GOAWAY error code, unsigned 32-bit value supplied to an unsigned-long decimal conversion; no unit.

The peer error value and last-stream identifier are diagnostic here; the response uses no-error status regardless of the received code. The two final conversions require unsigned long values, but both supplied values are unsigned 32-bit integers without a matching cast. This is not a portable printf argument match.

## Log examples

No reliable portable example can be asserted: both final unsigned-long conversions receive unsigned 32-bit arguments without the required matching type.

## Short description

HTTP/2 peer requested connection shutdown.

## Trigger condition

A complete GOAWAY frame has stream identifier zero and at least eight payload bytes.

## Explanation

Nimble records the peer’s last-stream identifier and error code, consumes the frame, then sends or queues its own GOAWAY with no-error status and stops normal connection processing.
