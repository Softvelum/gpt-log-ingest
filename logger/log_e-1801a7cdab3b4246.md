# RIST receiver peer creation failed

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-1801a7cdab3b4246

## Log pattern

```text
failed to add rist receiver peer, id=%s
```

## Parameters

- Argument 1 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add rist receiver peer, id=rist-receiver
```

## Short description

RIST receiver peer creation failed.

## Trigger condition

The RIST library returns a nonzero result from peer creation.

## Explanation

The receiver context exists, but data callback installation and startup are not attempted.

## Possible causes

- The RIST library returns a nonzero result from peer creation.

## What to check

1. Check the RIST runtime diagnostics for peer creation using this connection ID.
