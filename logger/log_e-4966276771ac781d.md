# HLS advertising cannot retrieve the source chunk

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-4966276771ac781d

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu failed to get cache item, key=%s
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.
- Argument 5 — Cache key: Application/stream path and generated segment or part name used as the cache identity.

## Log examples

Illustrative examples; these are not captured server logs.

```text
app=live stream=camera stream_name=live/camera session=123 failed to get cache item, key=/live/camera/l_100_60000_10.ts
```

## Short description

HLS advertising cannot retrieve the source chunk.

## Trigger condition

The source cache item cannot be requested while preparing a leading or trailing live-chunk remainder around an advertisement.

## Explanation

The advertising playlist update fails before submitting the remainder work.

## Possible causes

- The source cache item cannot be requested while preparing a leading or trailing live-chunk remainder around an advertisement.

## What to check

1. Check the named cache item availability and cache eviction or removal messages.

## Recommended action

Restore availability of source chunks needed during advertising insertion.
