# RTMP play command refers to an unknown stream

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-b936f49ca317f460

## Log pattern

```text
unknown message stream id for play command, msg_id=%d
```

## Parameters

- Argument 1 — Message stream ID: Numeric RTMP message stream identifier carried by the received message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown message stream id for play command, msg_id=2
```

## Short description

RTMP play command refers to an unknown stream.

## Trigger condition

The play command message stream ID does not identify an allocated stream on this connection.

## Explanation

The message is rejected and connection processing fails before the requested operation can proceed.

## Possible causes

- The play command message stream ID does not identify an allocated stream on this connection.

## What to check

1. Check the stream-creation response and the message stream ID used by this peer.

## Recommended action

Create the message stream successfully before sending commands or media on its ID.
