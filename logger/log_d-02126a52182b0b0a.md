## Short description

JSON message ready for parsing.

## Trigger condition

A publisher-authorization response, selected management POST body, or settings-sync body reaches its parser.

## Explanation

The full input is logged before syntax or shape checks. Management occurrences cover publish denial, RTMP republish creation, Icecast metadata, session deletion, and cache deletion. Panel processing also prints this before its empty-input branch, which clears routing and IP ranges. The trace alone says nothing about parse success or authorization outcome.
