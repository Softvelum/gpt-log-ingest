# MP3 message is shorter than its inspected header

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-94fa7433eb748606

## Log pattern

```text
[AM] wrong mp3 message size %d
```

## Parameters

- Argument 1 — Message size: Received audio message size in bytes; this branch accepts only values below 3.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] wrong mp3 message size 2
```

## Short description

MP3 message is shorter than its inspected header.

## Trigger condition

A live MPEG audio message has fewer than three bytes.

## Explanation

Audio processing returns failure before header inspection and normal audio output delivery.

## Possible causes

- A live MPEG audio message has fewer than three bytes.

## What to check

1. Check input MP3 frame boundaries and byte counts.

## Recommended action

Send complete MPEG audio messages.
