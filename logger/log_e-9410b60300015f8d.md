# SDI output channel count is unsupported

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-9410b60300015f8d

## Log pattern

```text
audio channel count is invalid for [%s/%s], channels=%d
```

## Parameters

- Argument 1 — Device type: FFmpeg output device type, text.
- Argument 2 — Stream: Output stream name, text.
- Argument 3 — Channels: Requested channel count, integer channels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio channel count is invalid for [decklink/live/camera], channels=6
```

## Short description

SDI output channel count is unsupported.

## Trigger condition

Output audio setup receives a channel count other than 2, 8 or 16.

## Explanation

The audio setup request returns failure.

## Possible causes

- The requested audio layout has an unsupported number of channels.

## What to check

1. Check the channel count reported in this message.

## Recommended action

Use 2, 8 or 16 audio channels for this output.
