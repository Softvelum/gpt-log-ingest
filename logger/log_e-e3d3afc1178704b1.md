# VAAPI encoding context creation failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e3d3afc1178704b1

## Log pattern

```text
%p failed to create context, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to create context, 0x1
```

## Short description

VAAPI encoding context creation failed.

## Trigger condition

The VA driver returns a non-success status while creating a progressive encoding context using the allocated surfaces.

## Explanation

Encoder initialization returns failure at this stage.

## Possible causes

- The driver cannot create an encoding context for the selected configuration or surfaces.

## What to check

1. Check the VA status, selected profile and dimensions, and device resource availability.

## Recommended action

Correct unsupported settings or restore device resources, then restart encoding.
