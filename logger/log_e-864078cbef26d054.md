# RTCP packet is not a sender report

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-864078cbef26d054

## Log pattern

```text
unhandled rtcp packet type=%d
```

## Parameters

- Argument 1 — Packet type: Unsigned eight-bit RTCP packet type displayed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unhandled rtcp packet type=201
```

## Short description

RTCP packet is not a sender report.

## Trigger condition

An RTCP packet with a complete header and sender identifier has a type other than sender report.

## Explanation

The packet is logged without updating timing from a sender report. This branch still returns successful parsing status.

## Possible causes

- An RTCP packet with a complete header and sender identifier has a type other than sender report.

## What to check

1. Check whether the received RTCP packet is a sender report or another control-packet type.
