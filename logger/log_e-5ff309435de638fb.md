# Socket event registration could not modify

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-5ff309435de638fb

## Log pattern

```text
epoll_ctl epfd=%d MOD failed fd=%d f=0x%x (errno=%d)
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Socket: Socket descriptor, integer; no unit.
- Argument 3 — Event flags: Requested event-interest bit mask, hexadecimal integer.
- Argument 4 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
epoll_ctl epfd=10 MOD failed fd=12 f=0x1 (errno=5)
```

## Short description

Socket event registration could not modify.

## Trigger condition

Linux rejects an attempt to modify a descriptor in the event monitor.

## Explanation

The requested interest change is not applied by this attempt. The operation reports failure.

## Possible causes

- The operating system rejected the requested monitor operation.

## What to check

1. Check the monitor descriptor, socket descriptor, requested events, and operating system error.

## Recommended action

Correct the reported monitor operation failure.
