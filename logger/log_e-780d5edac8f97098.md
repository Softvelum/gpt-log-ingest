# Playlist AC-3 audio packet was rejected

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-780d5edac8f97098

## Log pattern

```text
ServerBlockProcessor: processAC3AudioMessage failed for vod file [%s], stream=[%s/%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: processAC3AudioMessage failed for vod file [/media/program.mp4], stream=[live/camera]
```

## Short description

Playlist AC-3 audio packet was rejected.

## Trigger condition

Forwarding the parsed AC-3 packet to the output stream fails.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- Forwarding the parsed AC-3 packet to the output stream fails.

## What to check

1. Check the AC-3 audio packet and preceding output audio errors.

## Recommended action

Check the AC-3 audio packet and preceding output audio errors.
