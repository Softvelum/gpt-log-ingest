# Playlist AAC sample rate is unsupported

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-6400b70690b6b185

## Log pattern

```text
unsupported aac sample_rate=%d, file=%s
```

## Parameters

- Argument 1 — Sample rate: Integer audio sample rate in hertz.
- Argument 2 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported aac sample_rate=12345, file=/media/program.mp4
```

## Short description

Playlist AAC sample rate is unsupported.

## Trigger condition

The MPEG-TS AAC sample rate is absent from the supported sampling-rate table.

## Explanation

Building AAC configuration data returns failure.

## Possible causes

- The MPEG-TS AAC sample rate is absent from the supported sampling-rate table.

## What to check

1. Use a sample rate supported by the AAC configuration table.

## Recommended action

Use a sample rate supported by the AAC configuration table.
