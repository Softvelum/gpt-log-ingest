# Audio arrived for video synchronization

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_d
Log level: debug
Documentation ID: log_d-65754323886cd60d

## Log pattern

```text
audio encoder added, sync video to audio for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio encoder added, sync video to audio for live/encoded
```

## Short description

Audio arrived for video synchronization.

## Trigger condition

Video-to-audio synchronization is selected and audio is added while the worker was waiting for audio.

## Explanation

If a decoded-video buffer exists its read index advances to the current write position, then the worker seeks the first audio timestamp before resuming video.
