# Remote log synchronization failed

Product: Nimble Streamer
Component: Remote log reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-af35d0514f1d0617

## Log pattern

```text
log sync failed (%d)
```

## Parameters

- Argument 1 — Result: Integer synchronization result: 1 send failure; 2 receive failure; 3 invalid HTTP response; 4 TLS context creation; 5 TLS session creation; 6 TLS socket binding; 7 partial TLS send; 8 TLS request send; 9 TLS response read; 10 internal error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
log sync failed (2)
```

## Short description

Remote log synchronization failed.

## Trigger condition

Sending the log batch over HTTP or HTTPS returns a non-success synchronization result.

## Explanation

The socket is closed, remote reporting settings are reset to disabled, and queued records are cleared. The loop remains alive.

## Possible causes

- A request, response, TLS setup, or internal synchronization step failed, as identified by the result.

## What to check

1. Match the numeric result to the failed synchronization step.
