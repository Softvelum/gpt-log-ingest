# Selected VCAS key has never been populated

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-806a3773f4cd55c3

## Log pattern

```text
key pos=%d for '%s' was never updated
```

## Parameters

- Argument 1 — Key position: Integer index of the selected key in the rotating key set.
- Argument 2 — Application: Text naming the application owning the key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
key pos=0 for 'live' was never updated
```

## Short description

Selected VCAS key has never been populated.

## Trigger condition

The selected HLS key slot has no successful update timestamp.

## Explanation

The HLS operation fails unless fallback to the configured default key is permitted; with fallback permitted, default-key selection is attempted.

## Possible causes

- The selected HLS key slot has no successful update timestamp.

## What to check

1. Check the initial VCAS key request and its response.

## Recommended action

Check the initial VCAS key request and its response.
