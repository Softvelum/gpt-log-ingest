# AAC decoder configuration is too short

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-1b28a4c652b754e1

## Log pattern

```text
[AM] wrong codec_info_size %d for [%s/%s]
```

## Parameters

- Argument 1 — Configuration size: Received AAC decoder-configuration byte count.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] wrong codec_info_size 1 for [live/camera]
```

## Short description

AAC decoder configuration is too short.

## Trigger condition

The AAC decoder configuration contains fewer than two bytes.

## Explanation

AAC codec setup fails before its object type, sample rate index, and channel configuration can be read.

## Possible causes

- The AAC decoder configuration contains fewer than two bytes.

## What to check

1. Check the decoder-configuration byte count in the input sequence header.

## Recommended action

Send a complete AAC decoder configuration.
