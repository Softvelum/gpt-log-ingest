# AAC profile signaling mode failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-0a97d1705f8d281c

## Log pattern

```text
failed to set signaling_mode=%d, status=%d
```

## Parameters

- Argument 1 — Mode: Requested AAC signaling mode, integer 0 through 2.
- Argument 2 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set signaling_mode=0, status=1
```

## Short description

AAC profile signaling mode failed.

## Trigger condition

In an FDK-enabled build, setting profile signaling returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected profile signaling mode for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in profile signaling mode.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
