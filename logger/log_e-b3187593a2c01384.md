# Stream-check sent-byte count exceeds the request

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-b3187593a2c01384

## Log pattern

```text
StreamCheckerTask::OnSockOut s=%d assertion failed (%d < %d)
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — request bytes: Prepared request length.
- Argument 3 — sent bytes: Accumulated bytes recorded as sent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
StreamCheckerTask::OnSockOut s=12 assertion failed (100 < 101)
```

## Short description

Stream-check sent-byte count exceeds the request.

## Trigger condition

The accumulated sent count becomes larger than the prepared request length.

## Explanation

The task starts shutdown and abandons request transmission.

## Possible causes

- Internal request byte accounting exceeded its expected limit.

## What to check

1. Compare earlier write-progress messages for the task.

## Recommended action

Investigate inconsistent request byte accounting.
