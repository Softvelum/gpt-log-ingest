# Ogg page version unsupported

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-3a0e19f7373d38da

## Log pattern

```text
unsupported ogg version=%d %s
```

## Parameters

- Argument 1 — Version: Ogg page version byte.
- Argument 2 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported ogg version=1 http://radio.example.net/live
```

## Short description

Ogg page version unsupported.

## Trigger condition

An Ogg page header contains a version other than zero.

## Explanation

The session is shut down and Ogg parsing stops.

## Possible causes

- An Ogg page header contains a version other than zero.

## What to check

1. Check the Ogg page version.

## Recommended action

Supply an Ogg stream using supported version zero.
