# Cannot create SRT ingest listener

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-f38fcb78b7376c49

## Log pattern

```text
failed to bind srt socket %s:%d
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to bind srt socket 0.0.0.0:9000
```

## Short description

Cannot create SRT ingest listener.

## Trigger condition

Creating the primary SRT ingest listener or an additional bonding listener fails.

## Explanation

The listening setup is rejected and settings synchronization is invalidated to permit a later retry.

## Possible causes

- Creating the primary SRT ingest listener or an additional bonding listener fails.

## What to check

1. Check the local address, port, and preceding listener diagnostics.
