# SRT publisher does not match IP allow rules

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-f84d9e839d5b959b

## Log pattern

```text
[srt_listen_callback] publisher not allowed by ip. password path=[%s], ip=[%s]
```

## Parameters

- Argument 1 — File: Configured SRT password-settings file path.
- Argument 2 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] publisher not allowed by ip. password path=[/data/srt-users.json], ip=[192.0.2.20]
```

## Short description

SRT publisher does not match IP allow rules.

## Trigger condition

A nonempty global or stream-specific allow list does not contain the publisher IP.

## Explanation

Authentication settings processing fails and the publisher connection is rejected.

## Possible causes

- A nonempty global or stream-specific allow list does not contain the publisher IP.

## What to check

1. Check the publisher address against the applicable allow rules.
