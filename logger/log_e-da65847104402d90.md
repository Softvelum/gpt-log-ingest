# Encrypted URL verification hash does not match

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-da65847104402d90

## Log pattern

```text
digest length=%u expected=%u
```

## Parameters

- Argument 1 — Calculated length: Calculated digest length in bytes, unsigned integer.
- Argument 2 — Supplied length: Supplied decoded digest length in bytes, unsigned integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
digest length=16 expected=16
```

## Short description

Encrypted URL verification hash does not match.

## Trigger condition

The calculated digest length differs from the supplied decoded digest length, or the bytes differ even when lengths are equal.

## Explanation

Decrypted data is discarded and URL validation fails.

## Possible causes

- The link data, vector, key, or verification digest does not match the expected combination.

## What to check

1. Check the complete encrypted link and session key; equal displayed lengths do not imply matching hash bytes.

## Recommended action

Regenerate a matching encrypted link.
