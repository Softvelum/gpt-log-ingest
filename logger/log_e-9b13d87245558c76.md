# Live audio item could not be read

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-9b13d87245558c76

## Log pattern

```text
failed to read audio item [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

Shared by the audio decoder and the encoder worker forwarding compressed audio; both attempt to reset a slow reader first.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read audio item [live/camera]
```

## Short description

Live audio item could not be read.

## Trigger condition

Reading the first or next live audio item returns neither success nor wait-for-new-items, including failure after a slow-reader reset.

## Explanation

The audio decoding or encoded-audio forwarding operation returns failure.

## Possible causes

- The stream buffer cannot supply a usable item at the requested position.

## What to check

1. Check input availability, buffer resets, and preceding slow-reader messages.

## Recommended action

Restore the live source and restart the affected pipeline if it does not recover.
