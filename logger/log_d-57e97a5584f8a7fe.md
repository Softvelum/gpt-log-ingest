# VAAPI group length selected

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-57e97a5584f8a7fe

## Log pattern

```text
gop_length=%d
```

## Parameters

- Argument 1 — Group length: Configured group-of-pictures length, integer frames.

## Log examples

Illustrative examples; these are not captured server logs.

```text
gop_length=120
```

## Short description

VAAPI group length selected.

## Trigger condition

H.264 setup reads keyint or its g alias, with a default of 120 and a minimum of one.

## Explanation

The group length is reported and used for the intra and IDR periods.
