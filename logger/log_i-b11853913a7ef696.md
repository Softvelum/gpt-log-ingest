# Shared NVIDIA context destruction was issued

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-b11853913a7ef696

## Log pattern

```text
destroyed shared ctx=%p
```

## Parameters

- Argument 1 — Context: CUDA context handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
destroyed shared ctx=0x12340000
```

## Short description

Shared NVIDIA context destruction was issued.

## Trigger condition

Manager release has called CUDA destruction for a shared context.

## Explanation

The shared context record is removed; the destruction result is not checked.
