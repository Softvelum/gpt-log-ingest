# Advertising download socket removed

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-16025bc440bd2a8b

## Log pattern

```text
removed origin s=%d from processing
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the local socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed origin s=17 from processing
```

## Short description

Advertising download socket removed.

## Trigger condition

A download session is destroyed while its socket descriptor is positive.

## Explanation

The socket has been removed from event monitoring and is then closed.

## Possible causes

- A download session is destroyed while its socket descriptor is positive.
