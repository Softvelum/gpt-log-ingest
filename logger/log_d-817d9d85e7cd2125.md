# SLDP Cancel message is received

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-817d9d85e7cd2125

## Log pattern

```text
s=%d, cancel: %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Command JSON: Complete received Cancel request text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, cancel: {"command":"Cancel","streams":[1]}
```

## Short description

SLDP Cancel message is received.

## Trigger condition

A received message is passed to cancellation processing.

## Explanation

The JSON text is logged before parsing. Matching stream numbers disable the selected audio or video; an in-progress media item is cancelled immediately or after its started frame is completed.

## Possible causes

- A received message is passed to cancellation processing.

## What to check

1. Check the requested stream numbers against active selections.

## Recommended action

No action is required for intended cancellation.
