# File audio time base changed

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-83a20870df4215cb

## Log pattern

```text
audio stream time base changed for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio stream time base changed for [live/camera]
```

## Short description

File audio time base changed.

## Trigger condition

The current file-stream time base differs from the value captured when its audio decoder was configured.

## Explanation

The decoder operation fails and the worker stops instead of continuing with mismatched timestamp units.

## Possible causes

- The stream reader now reports a different timestamp scale while the same decoder remains active.

## What to check

1. Check file replacement or stream property changes and the configured input track.

## Recommended action

Restart the audio pipeline with consistent input timestamp properties.
