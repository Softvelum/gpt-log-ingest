# WebRTC helper control event invalid

Product: Nimble Streamer
Component: WebRTC helper connection
Logging function: log_d
Log level: debug
Documentation ID: log_d-a67680d1bc43ac14

## Log pattern

```text
invalid control socket event for fd=%d error event=0x%x
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Event mask: Socket readiness/error event bitmask, integer displayed in hexadecimal.

Both occurrences require exactly the writable event, so combined masks also enter this failure path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid control socket event for fd=12 error event=0x4
```

## Short description

WebRTC helper control event invalid.

## Trigger condition

An established WHIP or WHEP control socket receives an event mask other than exactly the writable-event value.

## Explanation

The control connection and pending output are cleared. Pending session starts and unclassified accepted sockets are discarded. WHIP additionally stops its active publishing sessions; WHEP playback sockets already handed to workers are not closed here.

## Possible causes

- The helper control connection closes, fails, becomes readable unexpectedly, or receives a combined event mask.

## What to check

1. Check the event mask and nearby helper-process or socket errors to identify the control-connection event.

## Recommended action

Restore the helper connection; investigate repeated unexpected events if session starts continue failing.
