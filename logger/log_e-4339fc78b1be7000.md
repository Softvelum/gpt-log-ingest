# Xilinx media initialization failed

Product: Nimble Streamer
Component: Transcoder orchestration
Logging function: log_e
Log level: error
Documentation ID: log_e-4339fc78b1be7000

## Log pattern

```text
xma_initialize failed, status=%d
```

## Parameters

- Argument 1 — Status: Xilinx media initialization result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
xma_initialize failed, status=-1
```

## Short description

Xilinx media initialization failed.

## Trigger condition

Initializing the enumerated Xilinx devices with the transcoding hardware image returns a status other than success.

## Explanation

The error is logged and main transcoder orchestration continues; the devices have not successfully completed this initialization.

## Possible causes

- The Xilinx media runtime cannot initialize the devices and transcoding image.

## What to check

1. Check the Xilinx status, device availability and installed transcoding image.

## Recommended action

Repair the Xilinx runtime or device/image installation before relying on Xilinx transcoding.
