# Audio filter output frame allocation failed

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-043f5ba6f68e82f7

## Log pattern

```text
failed to create audio frame, out of memory, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create audio frame, out of memory, filter=[in]anull[out], stream=live/camera
```

## Short description

Audio filter output frame allocation failed.

## Trigger condition

Allocating an audio frame to receive filter output returns no frame.

## Explanation

Output processing fails.

## Possible causes

- The output frame allocation could not obtain storage.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
