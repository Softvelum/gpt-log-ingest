# Local Zixi connection accepted

Product: Nimble Streamer
Component: Zixi integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-717554c072a58f42

## Log pattern

```text
zixi connection accepted s=%d
```

## Parameters

- Argument 1 — Socket: Newly accepted local TCP socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
zixi connection accepted s=42
```

## Short description

Local Zixi connection accepted.

## Trigger condition

The local TCP listener for a Zixi ingest or output bridge accepts a connection.

## Explanation

The listener is replaced with the accepted socket. Ingest waits for media; output first waits for the HTTP request before sending its response and media. This does not confirm a remote Zixi link is healthy.

## Possible causes

- The local TCP listener for a Zixi ingest or output bridge accepts a connection.

## What to check

1. Check the corresponding local bridge and subsequent media flow.
