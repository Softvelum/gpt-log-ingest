# Origin TLS initialization failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-57c84aa629036f37

## Log pattern

```text
failed to init ssl for origin s=%d
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init ssl for origin s=17
```

## Short description

Origin TLS initialization failed.

## Trigger condition

TLS state cannot be initialized for an outgoing origin or request-service connection.

## Explanation

Connection setup aborts; an HTTP client prepares HTTP 500, download setup fails, or the request-service session raises its fatal failure.

## Possible causes

- TLS state cannot be initialized for an outgoing origin or request-service connection.

## What to check

1. Check accompanying TLS initialization diagnostics and memory or TLS-context availability.

## Recommended action

Check accompanying TLS initialization diagnostics and memory or TLS-context availability.
