# Requested RTSP playback stream is unavailable

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-de1038f42c805683

## Log pattern

```text
Stream Not Found %s
```

## Parameters

- Argument 1 — URL: RTSP stream or track URL for the request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Stream Not Found rtsp://192.0.2.1/live/missing
```

## Short description

Requested RTSP playback stream is unavailable.

## Trigger condition

A DESCRIBE request names no current live buffer and no configured delayed-pull task after application alias resolution.

## Explanation

The server requests shutdown instead of passing the session to the playback sender.

## Possible causes

- A DESCRIBE request names no current live buffer and no configured delayed-pull task after application alias resolution.

## What to check

1. Check the requested stream name and whether an active input or delayed pull supplies it.

## Recommended action

Make the requested stream available before requesting its description.
