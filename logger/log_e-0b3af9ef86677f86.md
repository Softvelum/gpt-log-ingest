# Video packet category is unsupported

Product: Nimble Streamer
Component: Video input
Logging function: log_e
Log level: error
Documentation ID: log_e-0b3af9ef86677f86

## Log pattern

```text
[VM] avc packet type not supported %d
```

## Parameters

- Argument 1 — Packet category: Integer packet-type byte from the video tag.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] avc packet type not supported 3
```

## Short description

Video packet category is unsupported.

## Trigger condition

A legacy AVC-style packet is neither sequence header, coded NAL units, nor end of sequence. This guard is used by DVR AVC recording and RTMP AVC/HEVC input.

## Explanation

The affected video operation returns failure.

## Possible causes

- A legacy AVC-style packet is neither sequence header, coded NAL units, nor end of sequence. This guard is used by DVR AVC recording and RTMP AVC/HEVC input.

## What to check

1. Send a supported video packet type with a correct packet header.

## Recommended action

Send a supported video packet type with a correct packet header.
