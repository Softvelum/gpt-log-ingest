# Inactive SRT ingest connection removed

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_d
Log level: debug
Documentation ID: log_d-7acd8f2281d1f262

## Log pattern

```text
remove srt camera on inactivity s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remove srt camera on inactivity s=101
```

## Short description

Inactive SRT ingest connection removed.

## Trigger condition

The camera inactivity interval reaches its configured timeout; invalid or absent settings use a 30-second limit measured from inactivity tracking.

## Explanation

The camera is removed and its statistics finalized. A single-source listener is recreated to accept a replacement; a stream-ID listener remains available.

## Possible causes

- The camera inactivity interval reaches its configured timeout; invalid or absent settings use a 30-second limit measured from inactivity tracking.

## What to check

1. Check source traffic and the configured inactivity timeout.
