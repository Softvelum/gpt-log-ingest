# Initial advertising session rules requested

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-7efe1e31865707a7

## Log pattern

```text
request inital session rules for app=%s stream=%s session=%lld protocol=%s stream_time=%lld
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Session ID: Signed 64-bit viewer session identifier.
- Argument 4 — Protocol: Text naming hls, icecast, rtmp, sldp, or unknown.
- Argument 5 — Stream time: Playback position in seconds; initial requests may use zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
request inital session rules for app=live stream=camera session=12345 protocol=hls stream_time=0
```

## Short description

Initial advertising session rules requested.

## Trigger condition

A new viewer session has a configured advertising session handler.

## Explanation

The session waits for its first rules response and the request is queued for the handler.

## Possible causes

- A new viewer session has a configured advertising session handler.
