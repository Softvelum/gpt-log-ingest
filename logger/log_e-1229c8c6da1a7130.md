# DVR operation received an unrelated socket event

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-1229c8c6da1a7130

## Log pattern

```text
event=%d for unknown s=%d
```

## Parameters

- Argument 1 — Event mask: Integer socket-event bitmask.
- Argument 2 — Socket descriptor: Integer identifying the local socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
event=4 for unknown s=17
```

## Short description

DVR operation received an unrelated socket event.

## Trigger condition

An archive-operation, MP4-export, or subtitle-export event names a socket other than that operation's peer.

## Explanation

The event is logged and ignored.

## Possible causes

- An archive-operation, MP4-export, or subtitle-export event names a socket other than that operation's peer.

## What to check

1. Check socket lifecycle and surrounding disconnect messages.

## Recommended action

Check socket lifecycle and surrounding disconnect messages.
