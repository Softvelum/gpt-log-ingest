# Connection recorded in the statistics hierarchy

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_d
Log level: debug
Documentation ID: log_d-9859299dfd9886ab

## Log pattern

```text
[Stat] ip='%s' connected to %s:%s:%s (%s) cisz=%llu
```

## Parameters

- Argument 1 — Client address: Client IP address as text; an empty value can represent a request to create statistics records only.
- Argument 2 — Host: Text identifying the statistics host.
- Argument 3 — Application: Application name as text.
- Argument 4 — Stream: Stream name as text.
- Argument 5 — Recent connections: Semicolon-separated client addresses accumulated for reporting; this is not necessarily the current active-client list.
- Argument 6 — Changed streams: Number of stream statistics records awaiting reporting, supplied as a container size.

The final argument is a container size although the conversion expects unsigned long long; exact type compatibility depends on the build.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[Stat] ip='192.0.2.10' connected to media.example:live:camera (192.0.2.10) cisz=1
```

## Short description

Connection recorded in the statistics hierarchy.

## Trigger condition

Connection statistics are enabled, application and stream names are nonempty, and a new or existing stream record has received the connection update.

## Explanation

The four occurrences cover creating a host, application or stream, or updating an existing stream. Ordinary sessions enter the changed-record set; shared sessions enter the origin-record set. The global ordinary-session count is updated after this message.
