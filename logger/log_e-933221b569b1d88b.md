# NVIDIA decoded frame unmapping failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-933221b569b1d88b

## Log pattern

```text
failed to unmap video frame for [%s], res=%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to unmap video frame for [live/camera], res=2
```

## Short description

NVIDIA decoded frame unmapping failed.

## Trigger condition

After copying a decoded frame to host memory, releasing the GPU frame mapping returns an error.

## Explanation

Frame-queue processing returns failure before writing the host frame downstream.

## Possible causes

- The driver cannot release the mapped decoded frame.

## What to check

1. Check the driver status and decoder lifecycle.

## Recommended action

Restore valid decoder state before retrying.
