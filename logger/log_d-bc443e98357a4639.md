# Client disconnection added to statistics

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_d
Log level: debug
Documentation ID: log_d-bc443e98357a4639

## Log pattern

```text
Disconnect removed ip='%s' from '%s' ('%s'/'%s')
```

## Parameters

- Argument 1 — Client address: Client IP address as text; an empty value can represent a request to create statistics records only.
- Argument 2 — Stream: Stream name as text.
- Argument 3 — Recent connections: Semicolon-separated client addresses accumulated for reporting; this is not necessarily the current active-client list.
- Argument 4 — Recent disconnections: Semicolon-separated records containing address, protocol, user-agent code, duration, and optionally a user-agent hash separated by hash signs.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Disconnect removed ip='192.0.2.10' from 'camera' ('192.0.2.10'/'192.0.2.10#HLS#other#30')
```

## Short description

Client disconnection added to statistics.

## Trigger condition

A disconnection record has been appended to the report list.

## Explanation

The active address is removed next, then stream and parent counts decrease when nonzero. Despite the wording, this message precedes removal from the active-address collection.
