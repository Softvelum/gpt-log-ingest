# Output-chain buffer write completed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-e03148209b39ee81

## Log pattern

```text
sent=%d obuf rem=%d
```

## Parameters

- Argument 1 — Written bytes: Native-size signed bytes written, incorrectly printed with %d.
- Argument 2 — Remaining buffer bytes: Native-size remaining buffer byte count, incorrectly printed with %d.

The positive write result and remaining output-buffer size are native-size values passed to %d conversions; their output is unreliable on 64-bit builds.

## Log examples

The positive write result and remaining output-buffer size are native-size values passed to %d conversions; their output is unreliable on 64-bit builds.

## Short description

Output-chain buffer write completed.

## Trigger condition

A file or memory output-chain buffer writes a positive number of bytes.

## Explanation

The remaining count is updated; a fully sent buffer is released, and the next buffer or request can proceed.

## Possible causes

- A file or memory output-chain buffer writes a positive number of bytes.
