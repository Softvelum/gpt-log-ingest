# Client country was found for a routing rule

Product: Nimble Streamer
Component: Request routing
Logging function: log_d
Log level: debug
Documentation ID: log_d-b364fa89de98f590

## Log pattern

```text
country code for IP '%s' is '%s'
```

## Parameters

- Argument 1 — Client address: Text IP address used for country lookup.
- Argument 2 — Country: Country-code text returned by the geolocation database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
country code for IP '8.8.8.8' is 'US'
```

## Short description

Client country was found for a routing rule.

## Trigger condition

A matching host/path rule uses country routing and the client address lookup returns a nonempty country code.

## Explanation

The result is compared with the rule country. A matching country selects a redirect destination; a different country allows later rules to be examined.
