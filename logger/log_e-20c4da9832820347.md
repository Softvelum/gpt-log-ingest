# Cannot release SRT event poller

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-20c4da9832820347

## Log pattern

```text
srt_epoll_release epfd=%d failed: %s
```

## Parameters

- Argument 1 — Poller: SRT event-poller identifier.
- Argument 2 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_epoll_release epfd=1 failed: Invalid poll ID
```

## Short description

Cannot release SRT event poller.

## Trigger condition

Releasing the event poller returns an SRT error.

## Explanation

The local poller identifier is still cleared, so this selector no longer attempts to use it.

## Possible causes

- Releasing the event poller returns an SRT error.

## What to check

1. Check the SRT error description during selector cleanup.
