# Windows service control request received

Product: Nimble Streamer
Component: Windows service
Logging function: log_d
Log level: debug
Documentation ID: log_d-2d3948474ff2ddd0

## Log pattern

```text
service_ctrl_handler reguest=%d
```

## Parameters

- Argument 1 — Request: Numeric Windows service control request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
service_ctrl_handler reguest=1
```

## Short description

Windows service control request received.

## Trigger condition

The Windows service control handler receives a request.

## Explanation

Stop and shutdown requests ask the server to exit and report that stopping is pending. Other requests leave the server running. This message exists only in Windows builds.
