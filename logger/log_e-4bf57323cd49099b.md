# External response status is not accepted

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-4bf57323cd49099b

## Log pattern

```text
url='%s' request failed status=%hu
```

## Parameters

- Argument 1 — URL: Original external request URL, retained even when following a redirect.
- Argument 2 — status: HTTP response status code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url='https://media.example/movie.mp4' request failed status=404
```

## Short description

External response status is not accepted.

## Trigger condition

A completed response has a status outside the success statuses accepted by its completion path.

## Explanation

The requester receives a failure callback and the session finishes. Most paths accept 200 or 206; the immediate header-completion path also accepts 201. Header-stage redirects have separate handling.

## Possible causes

- The remote server returned an unaccepted HTTP status.

## What to check

1. Check response status, target URL, and response completion path.

## Recommended action

Correct the remote response or request parameters.
