# Advertising API response is not an object

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-b59d01c353758856

## Log pattern

```text
invalid Advertising API response='%s'
```

## Parameters

- Argument 1 — Response body: Text containing the received non-object JSON body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid Advertising API response='[]'
```

## Short description

Advertising API response is not an object.

## Trigger condition

The main or session advertising response parses as JSON but its top-level value is not an object.

## Explanation

The response is rejected; pending session rules requests receive failure handling.

## Possible causes

- The main or session advertising response parses as JSON but its top-level value is not an object.

## What to check

1. Return a JSON object at the top level of the advertising response.

## Recommended action

Return a JSON object at the top level of the advertising response.
