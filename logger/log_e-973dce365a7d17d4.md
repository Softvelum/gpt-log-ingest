# AAC quality improvement setting failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-973dce365a7d17d4

## Log pattern

```text
failed to set afterburner=%d, status=%d
```

## Parameters

- Argument 1 — Enabled: Requested quality-improvement enable value, 0 or 1.
- Argument 2 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set afterburner=1, status=1
```

## Short description

AAC quality improvement setting failed.

## Trigger condition

In an FDK-enabled build, applying the quality-improvement switch returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected quality improvement setting for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in quality improvement setting.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
