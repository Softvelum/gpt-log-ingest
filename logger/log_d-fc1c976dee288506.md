# Video decoder worker stopped

Product: Nimble Streamer
Component: Video decoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-fc1c976dee288506

## Log pattern

```text
VideoDecoderThread(%s) stopped
```

## Parameters

- Argument 1 — Input: Input display name captured when the worker started, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VideoDecoderThread(live/camera) stopped
```

## Short description

Video decoder worker stopped.

## Trigger condition

The worker leaves its loop after a stop request or failed source update or decoding operation.

## Explanation

The decoder and local input reader are released before this message and the worker returns.
