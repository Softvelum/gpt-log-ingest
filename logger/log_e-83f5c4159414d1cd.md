# Cannot submit stream notification POST

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_e
Log level: error
Documentation ID: log_e-83f5c4159414d1cd

## Log pattern

```text
failed to POST publish/unpublish request to url='%s'
```

## Parameters

- Argument 1 — URL: Configured publish/unpublish notification endpoint.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to POST publish/unpublish request to url='https://notify.example.net/events'
```

## Short description

Cannot submit stream notification POST.

## Trigger condition

The HTTP request processor rejects submission of the publish/unpublish notification request.

## Explanation

The batch has already been removed from the pending queues to build the JSON body and is not requeued here.

## Possible causes

- The HTTP request processor rejects submission of the publish/unpublish notification request.

## What to check

1. Check the notification URL and HTTP request-processor availability.
