# SLDP audio is already selected

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-ce3b494f153994a9

## Log pattern

```text
audio is already requested, sn=%d
```

## Parameters

- Argument 1 — Existing audio number: Client stream number already assigned to this audio selection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio is already requested, sn=1
```

## Short description

SLDP audio is already selected.

## Trigger condition

A duration-free Play request merges with an existing selection for the same source buffer and offset, but audio is already enabled there.

## Explanation

The duplicate selection is logged and processing continues. The existing stream number is retained rather than adding another copy.

## Possible causes

- A duration-free Play request merges with an existing selection for the same source buffer and offset, but audio is already enabled there.

## What to check

1. Check duplicate audio requests for the same stream and offset.

## Recommended action

Avoid requesting the same media selection twice.
