# TCP listener started

Product: Nimble Streamer
Component: Socket communication
Logging function: log_i
Log level: info
Documentation ID: log_i-fd527d211f2b9f53

## Log pattern

```text
listening '%s:%d' (%s)
```

## Parameters

- Argument 1 — Host: Requested host or address text.
- Argument 2 — Port: TCP port number, integer.
- Argument 3 — Listener label: Optional descriptive label supplied by the caller, text.

The optional label is supplied by the generic listener caller; main server listeners use SSL or plain to describe transport security.

## Log examples

Illustrative examples; these are not captured server logs.

```text
listening '192.0.2.10:1935' (input)
```

## Short description

TCP listener started.

## Trigger condition

The listen operation succeeds; an automatically assigned port is queried when the requested port was zero.

## Explanation

The TCP socket is listening and is registered for input events afterward. Generic listener setup checks that registration and can close the socket on failure; the main server path does not check that add result.
