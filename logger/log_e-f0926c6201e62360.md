# Cannot bind SRT bonding node to interface

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-f0926c6201e62360

## Log pattern

```text
srt_config_add failed for %s:%d%%%s s='%s'
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Interface: Requested network-interface name.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_config_add failed for 192.0.2.10:9000%eth0 s='Invalid parameter'
```

## Short description

Cannot bind SRT bonding node to interface.

## Trigger condition

Adding the requested network-interface binding to a bonded endpoint configuration fails.

## Explanation

The endpoint is still added to the group configuration and connection setup continues; the requested interface binding is not confirmed.

## Possible causes

- Adding the requested network-interface binding to a bonded endpoint configuration fails.

## What to check

1. Check the network-interface name and SRT error.
