# Outgoing SCTE-35 section exceeds the transport limit

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-8cb032f59886a129

## Log pattern

```text
[SCTE35] max splice info size exceeded for [%s/%s] sending to %s:%d frame_size=%u
```

## Parameters

- Argument 1 — Application: Source application.
- Argument 2 — Stream: Source stream.
- Argument 3 — Destination: Configured destination IP address.
- Argument 4 — Port: Configured destination port.
- Argument 5 — Section size: SCTE-35 section size in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SCTE35] max splice info size exceeded for [live/camera] sending to 192.0.2.20:5000 frame_size=184
```

## Short description

Outgoing SCTE-35 section exceeds the transport limit.

## Trigger condition

A queued SCTE-35 section is larger than the supported 183-byte single-packet payload.

## Explanation

The sender enters shutdown and the current media packaging operation fails.

## Possible causes

- A queued SCTE-35 section is larger than the supported 183-byte single-packet payload.

## What to check

1. Check the full section size and outgoing SCTE-35 source.

## Recommended action

Reduce the splice section to the supported size.
