# Library function lookup is unsupported

Product: Nimble Streamer
Component: Runtime library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-e272545a51e3108b

## Log pattern

```text
DynamicLibrary::GetSymbol() is not implemented
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
DynamicLibrary::GetSymbol() is not implemented
```

## Short description

Library function lookup is unsupported.

## Trigger condition

Function lookup is requested on a target other than the supported Linux and Windows branches.

## Explanation

The lookup logs the failure and throws an exception.

## Possible causes

- The platform has no implementation of runtime function lookup.

## What to check

1. Check the operating system support of the build.

## Recommended action

Use a supported build for the target platform.
