# Transport sender falls behind the live buffer

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-e245918b2f48e93a

## Log pattern

```text
failed to send buffer in appropriate rate for [%s:%d]
```

## Parameters

- Argument 1 — Destination: Configured destination IP address.
- Argument 2 — Port: Configured destination port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer in appropriate rate for [192.0.2.20:5000]
```

## Short description

Transport sender falls behind the live buffer.

## Trigger condition

The next requested media item is no longer retained because this sender consumed data too slowly.

## Explanation

Its read position is reset and the sender requests the newest retained item, skipping older unavailable media.

## Possible causes

- The next requested media item is no longer retained because this sender consumed data too slowly.

## What to check

1. Check output throughput and how far the sender trails live input.

## Recommended action

Resolve the sending bottleneck to avoid repeated media skips.
