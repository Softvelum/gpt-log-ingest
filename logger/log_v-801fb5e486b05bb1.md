# HTTP streaming session denied by payment policy

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_v
Log level: verbose
Documentation ID: log_v-801fb5e486b05bb1

## Log pattern

```text
disconnecting denied client ip='%s' ppv_id='%s'
```

## Parameters

- Argument 1 — Client address: Client IP address attached to the request, text.
- Argument 2 — Payment client identifier: Payment authorization client identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
disconnecting denied client ip='192.0.2.10' ppv_id='viewer-42'
```

## Short description

HTTP streaming session denied by payment policy.

## Trigger condition

A periodic authorization check finds a nonempty payment client identifier marked denied by the payment authorization manager.

## Explanation

The denial check returns true; the SLDP reply path marks the affected request stream for an internal reset.

## Possible causes

- The payment authorization policy has denied the client identifier.

## What to check

1. Check the named payment client and the applicable playback authorization decision.

## Recommended action

Resolve the authorization decision before the client reconnects.
