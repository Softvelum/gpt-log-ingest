# MP3 encoding preset was rejected

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e9938f014d463a23

## Log pattern

```text
failed to set preset=%d, status=%d
```

## Parameters

- Argument 1 — Preset: Numeric LAME preset code or bitrate preset, integer.
- Argument 2 — Status: LAME return status, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set preset=128, status=-1
```

## Short description

MP3 encoding preset was rejected.

## Trigger condition

In a LAME-enabled build, applying encoding preset returns -1.

## Explanation

Encoder initialization stops and the audio-frame write reports failure.

## Possible causes

- LAME rejected encoding preset.

## What to check

1. Check the selected named or numeric preset and the returned LAME status.

## Recommended action

Correct the rejected MP3 encoder setting.
