# PES presentation timestamp does not fit its first packet

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-92b726fd79441910

## Log pattern

```text
PTS MUST be in PUSI PES block pid=%d
```

## Parameters

- Argument 1 — PID: Affected elementary-stream packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
PTS MUST be in PUSI PES block pid=256
```

## Short description

PES presentation timestamp does not fit its first packet.

## Trigger condition

The PES flags require a PTS but fewer than five bytes remain in the payload-start transport packet.

## Explanation

The current transport packet is rejected. Its elementary-stream parser is reset, buffered partial PES data is discarded, and the camera parser searches for another packet boundary.

## Possible causes

- The PES flags require a PTS but fewer than five bytes remain in the payload-start transport packet.

## What to check

1. Check adaptation-field size and timestamp placement.

## Recommended action

Correct malformed PES framing at the source.
