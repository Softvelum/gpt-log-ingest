# Panel does not recognize this stream-check server

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-06363aff0ff0381f

## Log pattern

```text
this server is 'unknown' to the panel. stream thread will be stopped.
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
this server is 'unknown' to the panel. stream thread will be stopped.
```

## Short description

Panel does not recognize this stream-check server.

## Trigger condition

The panel stream response reports the server as unknown.

## Explanation

The response parser requests termination of the regular or immediate checker thread instead of further polling.

## Possible causes

- The panel returned an unknown-server status for this server identity.

## What to check

1. Check the server registration and selected panel.

## Recommended action

Correct the panel registration or server identity before restarting checks.
