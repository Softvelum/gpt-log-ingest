# Widevine retry has no remaining key slots

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-075710e5b2f3a98d

## Log pattern

```text
dropped retry request for Widevine keys for '%s' cpi=%u/%u (no keys to update)
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned key rotation period index.
- Argument 3 — Period count: Unsigned number of consecutive crypto periods.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dropped retry request for Widevine keys for 'live/camera' cpi=120/2 (no keys to update)
```

## Short description

Widevine retry has no remaining key slots.

## Trigger condition

A noninitial request finds no key objects in its requested crypto-period range.

## Explanation

The retry is dropped because its keys may already have expired and been removed.

## Possible causes

- A noninitial request finds no key objects in its requested crypto-period range.

## What to check

1. Compare the retried period with current rotation and key-cleanup messages.

## Recommended action

Compare the retried period with current rotation and key-cleanup messages.
