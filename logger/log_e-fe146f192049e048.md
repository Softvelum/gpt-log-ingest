# Scenario media libraries failed to initialize

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-fe146f192049e048

## Log pattern

```text
failed to load transcoder libs, scenario_id=%s
```

## Parameters

- Argument 1 — Scenario ID: Configured identifier of the scenario encoder process.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load transcoder libs, scenario_id=scenario-1
```

## Short description

Scenario media libraries failed to initialize.

## Trigger condition

Media-processing library initialization fails after the scenario has connected to its parent and loaded configuration.

## Explanation

Libraries are unloaded, queued log messages are given a chance to reach the parent, logging closes, and the process returns failure.

## Possible causes

- Media-processing library initialization fails after the scenario has connected to its parent and loaded configuration.

## What to check

1. Check media-library loading diagnostics for this scenario.
