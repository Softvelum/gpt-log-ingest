# VAAPI encoded output mapping failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-ca3b52276f37f96a

## Log pattern

```text
%p failed to map output buffer, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to map output buffer, 0x1
```

## Short description

VAAPI encoded output mapping failed.

## Trigger condition

Mapping the coded-output buffer after encoding and synchronization returns a non-success status.

## Explanation

No output packet is assembled or delivered for this frame.

## Possible causes

- The driver cannot expose the encoded packet buffer.

## What to check

1. Check the VA status, preceding device errors, and whether the encoder context remains usable.

## Recommended action

Resolve the VA driver or device failure and restart the affected encoder.
