# SDI output rejects interlaced frames

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-075262c09da0c759

## Log pattern

```text
don't supports interlaced frames. Please de-interlace.sdi_stream=%s
```

## Parameters

- Argument 1 — Output: Local output stream or AJA writer name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
don't supports interlaced frames. Please de-interlace.sdi_stream=camera
```

## Short description

SDI output rejects interlaced frames.

## Trigger condition

The input video frame is marked interlaced.

## Explanation

The frame is rejected before pixel conversion or queueing to the SDI helper.

## Possible causes

- The upstream video pipeline still contains interlaced frames.

## What to check

1. Check whether deinterlacing is applied before the SDI output.

## Recommended action

Deinterlace video before sending it to this SDI writer.
