# VP8 live-stream codec setup failed

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error

## Log pattern

vp8: unable to set codec params
```

## Log examples

Illustrative examples; these are not captured server logs.

```

## Short description

VP8 live-stream codec setup failed.

## Trigger condition

The VP8 configuration operation returns failure because the attached live stream is already ended.

## Explanation

RTSP codec setup fails before selecting VP8 as the RTP stream type.

## Possible causes

- The VP8 configuration operation returns failure because the attached live stream is already ended.

## What to check

1. Check whether the live stream ended during RTSP codec initialization.
