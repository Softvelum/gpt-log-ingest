# SMIL playlist generation failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-e86ce78b4e392467

## Log pattern

```text
failed to process smil file='%s'
```

## Parameters

- Argument 1 — SMIL filename: Text filesystem path of the SMIL document.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process smil file='/media/movie.smil'
```

## Short description

SMIL playlist generation failed.

## Trigger condition

Generating an HLS or fragmented-MP4 playlist from a local SMIL document returns failure.

## Explanation

HTTP 500 is prepared instead of the generated playlist.

## Possible causes

- Generating an HLS or fragmented-MP4 playlist from a local SMIL document returns failure.

## What to check

1. Check the SMIL document and referenced media or track selections, together with adjacent parsing and playlist-generation errors.

## Recommended action

Check the SMIL document and referenced media or track selections, together with adjacent parsing and playlist-generation errors.
