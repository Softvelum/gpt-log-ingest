# RTSP playback client requested unsupported transport

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-432d8551c8d57757

## Log pattern

```text
Unsupported transport %s, client %d
```

## Parameters

- Argument 1 — Transport: Requested Transport header protocol value.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Unsupported transport RTP/AVP/UDP, client 25
```

## Short description

RTSP playback client requested unsupported transport.

## Trigger condition

A playback SETUP request specifies a transport other than RTP/AVP/TCP.

## Explanation

The server sends an unsupported-transport response and keeps processing the session.

## Possible causes

- A playback SETUP request specifies a transport other than RTP/AVP/TCP.

## What to check

1. Check the transport in the playback SETUP request.

## Recommended action

Request interleaved RTP over TCP.
