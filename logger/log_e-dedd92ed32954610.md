# NVIDIA video packet parsing failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-dedd92ed32954610

## Log pattern

```text
failed to parse pkt for [%s], res=%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse pkt for [live/camera], res=2
```

## Short description

NVIDIA video packet parsing failed.

## Trigger condition

Passing an input packet to the NVIDIA parser returns a driver error. H.264 and HEVC packets have first been converted to Annex B.

## Explanation

The current packet returns failure before delivering queued decoded frames.

## Possible causes

- The parser or a decoding callback rejects the packet.

## What to check

1. Check the driver status, source packet validity and any preceding sequence or decode error.

## Recommended action

Correct invalid input or the reported decoder failure.
