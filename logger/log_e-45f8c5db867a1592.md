# SVT HEVC stream header could not be read

Product: Nimble Streamer
Component: SVT HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-45f8c5db867a1592

## Log pattern

```text
failed to get encode header, err=%d
```

## Parameters

- Argument 1 — Encoder status: SVT HEVC result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get encode header, err=-1
```

## Short description

SVT HEVC stream header could not be read.

## Trigger condition

Requesting the initialized encoder stream header returns an error.

## Explanation

The returned header buffer is released and encoder initialization fails before publishing HEVC configuration.

## Possible causes

- The encoder cannot supply its stream header.

## What to check

1. Check the SVT status and preceding encoder initialization diagnostics.

## Recommended action

Correct the encoder failure before retrying.
