# Cannot set SRT latency

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-df051f5b16d046e7

## Log pattern

```text
failed to set latency s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set latency s=100
```

## Short description

Cannot set SRT latency.

## Trigger condition

The SRT library rejects the configured latency value.

## Explanation

Applying the socket settings stops with failure; callers creating a socket or group then close it.

## Possible causes

- The SRT library rejects the configured latency value.

## What to check

1. Check the configured latency and nearby SRT diagnostics.
