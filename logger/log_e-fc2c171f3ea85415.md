# AJA capture capability failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-fc2c171f3ea85415

## Log pattern

```text
init failed device=%s/%d reason='device is not capture-capable'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
init failed device=0/0 reason='device is not capture-capable'
```

## Short description

AJA capture capability failed.

## Trigger condition

Receiver initialization fails because the card lacks capture capability.

## Explanation

No video or audio setup is attempted.

## Possible causes

- Receiver initialization fails because the card lacks capture capability.

## What to check

1. Check the preceding device or capture capability error details.
