# Advertising UTC start time cannot be parsed

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-b93aa37936634c1a

## Log pattern

```text
failed to parse time_offset=%s rule.id=%s
```

## Parameters

- Argument 1 — UTC time: Text supplied as the rule start time.
- Argument 2 — Rule ID: Text identifying the advertising rule.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse time_offset=invalid-date rule.id=rule-01
```

## Short description

Advertising UTC start time cannot be parsed.

## Trigger condition

An advertising rule using UTC time has a start time that cannot be parsed as year-month-day and time.

## Explanation

The invalid rule is skipped. A valid timestamp is interpreted as UTC.

## Possible causes

- An advertising rule using UTC time has a start time that cannot be parsed as year-month-day and time.

## What to check

1. Use a UTC timestamp in YYYY-MM-DD HH:MM:SS form.

## Recommended action

Use a UTC timestamp in YYYY-MM-DD HH:MM:SS form.
