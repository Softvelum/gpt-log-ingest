# HLS fragmented MP4 part buffer cannot be allocated

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-4c67906ebc761497

## Log pattern

```text
failed to allocate fmp4 part buffer size=%u, key=%s
```

## Parameters

- Argument 1 — Size: Required serialization-buffer capacity in bytes.
- Argument 2 — Cache key: Application/stream path and generated segment or part name used as the cache identity.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to allocate fmp4 part buffer size=1048576, key=/live/camera/v_100_90000_10_0.fmp4
```

## Short description

HLS fragmented MP4 part buffer cannot be allocated.

## Trigger condition

The temporary serialization buffer cannot grow to the required part size after its cache key has been reserved.

## Explanation

The reserved cache item is cancelled and released, and this item is not attached to the output list.

## Possible causes

- The temporary serialization buffer cannot grow to the required part size after its cache key has been reserved.

## What to check

1. Check the requested size and available memory or buffer limits.

## Recommended action

Resolve the serialization-buffer capacity failure.
