# Icecast authorization scheme unsupported

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-610b2bb07115cc35

## Log pattern

```text
unsupported icecast auth scheme=%s, client=%d
```

## Parameters

- Argument 1 — Scheme: Received authorization scheme token.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported icecast auth scheme=Digest, client=42
```

## Short description

Icecast authorization scheme unsupported.

## Trigger condition

An authenticated metadata-update or publishing request uses a scheme other than Basic.

## Explanation

The connection is shut down.

## Possible causes

- An authenticated metadata-update or publishing request uses a scheme other than Basic.

## What to check

1. Check the authorization scheme.

## Recommended action

Use Basic authorization for this endpoint.
