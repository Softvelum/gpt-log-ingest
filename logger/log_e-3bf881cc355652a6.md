# HLS HTTP response parsing failed

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-3bf881cc355652a6

## Log pattern

```text
failed to parse buffer from %s s=%d url='%s'
```

## Parameters

- Argument 1 — socket\_tag: The source supplies the HLS input tag hlscam.
- Argument 2 — socket: Origin connection socket descriptor.
- Argument 3 — url: Current origin URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse buffer from hlscam s=42 url='https://origin.example/live.m3u8'
```

## Short description

HLS HTTP response parsing failed.

## Trigger condition

The HTTP parser rejects data while receiving the response header or while processing chunked transfer input.

## Explanation

The HLS input is marked shut down and returns. This concerns HTTP framing, not HLS playlist syntax.

## Possible causes

- The HTTP parser rejected the received response data.

## What to check

1. Check the origin HTTP header or chunked transfer framing for the failing phase.

## Recommended action

Correct the origin response framing.
