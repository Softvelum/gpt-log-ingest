# MKV source format is invalid during output generation

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-910d88ecc4a492e5

## Log pattern

```text
InvalidFileformatMKVLoaderException caught while processing file='%s' chunk='%s'
```

## Parameters

- Argument 1 — MKV filename: Text filesystem path of the source MKV file.
- Argument 2 — Requested resource: Text name of the requested playlist, initialization segment, or media chunk.

## Log examples

Illustrative examples; these are not captured server logs.

```text
InvalidFileformatMKVLoaderException caught while processing file='/media/movie.mkv' chunk='n_0_0_0.ts'
```

## Short description

MKV source format is invalid during output generation.

## Trigger condition

An invalid-MKV-format exception reaches the local MKV output-generation handler.

## Explanation

The requested output cache item is canceled with a transmuxing-failure reason and released.

## Possible causes

- An invalid-MKV-format exception reaches the local MKV output-generation handler.

## What to check

1. Check that the file is valid MKV media and has not been incompletely written or changed during playback.

## Recommended action

Check that the file is valid MKV media and has not been incompletely written or changed during playback.
