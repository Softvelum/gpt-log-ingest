# Pay-per-view response JSON is malformed

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-05a4d1c8f823c714

## Log pattern

```text
failed to parse PPV API response='%s'
```

## Parameters

- Argument 1 — response: Raw API response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse PPV API response='{invalid}'
```

## Short description

Pay-per-view response JSON is malformed.

## Trigger condition

JSON mode is enabled and the response cannot be parsed.

## Explanation

The current deny list is cleared and the response is not applied.

## Possible causes

- The API returned invalid JSON.

## What to check

1. Check response syntax and whether JSON mode matches the handler output.

## Recommended action

Return a valid JSON response from the handler.
