# Cannot install SRT connection-accept callback

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-a659758625c1d9f6

## Log pattern

```text
srt_listen_callback failed, s=%d: %s
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.
- Argument 2 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_listen_callback failed, s=100: Invalid socket ID
```

## Short description

Cannot install SRT connection-accept callback.

## Trigger condition

The SRT library rejects registering the listener callback.

## Explanation

The new listening socket is closed and listener creation fails.

## Possible causes

- The SRT library rejects registering the listener callback.

## What to check

1. Inspect the SRT error and listener callback support.
