# RTMP metadata refers to an unknown stream

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-5abd140ed1a31893

## Log pattern

```text
unknown message stream id for DataMessageAMF0, msg_id=%d
```

## Parameters

- Argument 1 — Message stream ID: Numeric RTMP message stream identifier carried by the received message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown message stream id for DataMessageAMF0, msg_id=2
```

## Short description

RTMP metadata refers to an unknown stream.

## Trigger condition

An AMF0 data message uses a message stream ID that is not allocated on the connection.

## Explanation

This data message is discarded, but the handler reports success so this event alone does not stop the connection.

## Possible causes

- An AMF0 data message uses a message stream ID that is not allocated on the connection.

## What to check

1. Compare the metadata message stream ID with the allocated media stream ID.

## Recommended action

Send metadata on the allocated message stream.
