# PES optional header length is shorter than its timestamps

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_d
Log level: debug
Documentation ID: log_d-fb7f21d5555687b5

## Log pattern

```text
wrong-negative pes header size pid=%d
```

## Parameters

- Argument 1 — PID: Affected elementary-stream packet identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wrong-negative pes header size pid=256
```

## Short description

PES optional header length is shorter than its timestamps.

## Trigger condition

Subtracting required five-byte PTS and optional five-byte DTS fields makes the declared optional-header length negative.

## Explanation

The current transport packet is rejected. Its elementary-stream parser is reset, buffered partial PES data is discarded, and the camera parser searches for another packet boundary.

## Possible causes

- Subtracting required five-byte PTS and optional five-byte DTS fields makes the declared optional-header length negative.

## What to check

1. Compare the declared optional-header length with the timestamp flags.

## Recommended action

Correct malformed PES framing at the source.
