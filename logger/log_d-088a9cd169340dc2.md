# TLS client server name received

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_d
Log level: debug
Documentation ID: log_d-088a9cd169340dc2

## Log pattern

```text
SNICb sni='%s'
```

## Parameters

- Argument 1 — Server name: Client SNI hostname, or NULL when no hostname was supplied.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SNICb sni='media.example.net'
```

## Short description

TLS client server name received.

## Trigger condition

The TLS server-name callback reads the hostname supplied by the client.

## Explanation

The server tries to switch to the matching certificate context; absent names or failed matching return without acknowledging SNI. The log is available when server-name extension support is compiled in.

## Possible causes

- The TLS server-name callback reads the hostname supplied by the client.

## What to check

1. Compare the client hostname with the configured certificate hostname mappings.
