# Windows cached file could not be reopened

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-3f1c697542be87ed

## Log pattern

```text
failed to open and map file='%s'
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open and map file='/cache/movie'
```

## Short description

Windows cached file could not be reopened.

## Trigger condition

A Windows cache lookup cannot open and map the stored file.

## Explanation

The newly added reference is removed and the cache item is deleted before returning a miss.

## Possible causes

- Opening or mapping the disk cache file failed.

## What to check

1. Check nearby Windows file errors and the availability of the cache file.

## Recommended action

Correct the file-access problem; the failed item must be cached again.
