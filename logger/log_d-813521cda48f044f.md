# Configured video packet is unavailable

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-813521cda48f044f

## Log pattern

```text
updateAvailable failed to find video_pid=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable failed to find video_pid=256
```

## Short description

Configured video packet is unavailable.

## Trigger condition

The matching input availability map does not contain the explicitly configured video packet identifier.

## Explanation

Video codec initialization, timestamps, parameter sets, and frame assembly buffers are reset. The selected identifier and type are cleared. Availability processing continues for other media.
