# Geolocation verification found no country

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_e
Log level: error
Documentation ID: log_e-328ef208f64472cf

## Log pattern

```text
failed to detect country code for '%s'
```

## Parameters

- Argument 1 — Verification address: Either the IPv4 address 8.8.8.8 or the IPv6 address 8.8.8.8.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to detect country code for '8.8.8.8'
```

## Short description

Geolocation verification found no country.

## Trigger condition

A country lookup for one of the two built-in verification addresses returns no country code.

## Explanation

Failure for the IPv4 verification address rejects the proposed database and reloads the cached database. Failure for the IPv6 verification address is reported but does not change the verification result.

## Possible causes

- The opened database did not provide a country value for the verification address.

## What to check

1. Distinguish the IPv4 verification failure from the diagnostic-only IPv6 failure.
