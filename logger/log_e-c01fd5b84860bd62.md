# Encrypted stream-check read failed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-c01fd5b84860bd62

## Log pattern

```text
failed to read from s=%d (sslerr=%d)
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — TLS error: TLS error category associated with the read result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read from s=12 (sslerr=6)
```

## Short description

Encrypted stream-check read failed.

## Trigger condition

A TLS read returns zero or a negative result other than the supported retry conditions.

## Explanation

The task starts shutdown. A zero return is logged here even when it represents orderly TLS closure.

## Possible causes

- TLS input ended or failed.

## What to check

1. Interpret the TLS category and previous response progress.

## Recommended action

Investigate the encrypted origin response if the check did not complete.
