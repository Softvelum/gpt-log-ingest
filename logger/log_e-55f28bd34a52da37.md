# VAAPI input image release failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-55f28bd34a52da37

## Log pattern

```text
%p failed to destroy image, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to destroy image, 0x1
```

## Short description

VAAPI input image release failed.

## Trigger condition

Destroying the derived image after unmapping returns a non-success status.

## Explanation

Frame encoding fails before the input surface is synchronized.

## Possible causes

- The driver cannot release the derived image.

## What to check

1. Check the VA status, preceding device errors, and whether the encoder context remains usable.

## Recommended action

Resolve the VA driver or device failure and restart the affected encoder.
