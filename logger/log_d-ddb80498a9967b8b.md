# DVR export sends movie metadata

Product: Nimble Streamer
Component: DVR export
Logging function: log_d
Log level: debug
Documentation ID: log_d-ddb80498a9967b8b

## Log pattern

```text
sending moov atom: size=%d stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Metadata bytes: Number of movie-metadata bytes produced.
- Argument 2 — Stream: Text naming the application and stream.
- Argument 3 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 4 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sending moov atom: size=4096 stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

DVR export sends movie metadata.

## Trigger condition

The movie builder produces a nonempty block of final MP4 metadata.

## Explanation

The metadata is buffered and its send is attempted.

## Possible causes

- The movie builder produces a nonempty block of final MP4 metadata.
