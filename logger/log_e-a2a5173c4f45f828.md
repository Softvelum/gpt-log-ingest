# AAC high bit rate size length is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-a2a5173c4f45f828

## Log pattern

```text
AAC-hbr: unsupported sizelength=%s

```

## Parameters

- Argument 1 — Advertised length: Original SDP field text; the expected numeric value is a bit count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
AAC-hbr: unsupported sizelength=12

```

## Short description

AAC high bit rate size length is unsupported.

## Trigger condition

The SDP AAC size length does not parse to 13.

## Explanation

The AAC high bit rate configuration is rejected before audio codec initialization.

## Possible causes

- The SDP AAC size length does not parse to 13.

## What to check

1. Check the AAC size length field in SDP.

## Recommended action

Use 13 bits for the AAC size length.
