# NVIDIA bitstream-buffer destruction failed

Product: Nimble Streamer

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

NVIDIA bitstream-buffer destruction failed.

## Trigger condition

Destroying an initialized encoded-output buffer during cleanup returns an error.

## Explanation

Cleanup continues with remaining buffers and the encoder session.

## Possible causes

- The NVIDIA driver rejects the requested cleanup operation.

## What to check

1. Check preceding encoding failures and NVIDIA device/driver state.

## Recommended action

If cleanup failures recur, restore the device/driver state before restarting encoding.
