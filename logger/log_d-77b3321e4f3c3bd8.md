# DASH initialization receives a fixed key identifier

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-77b3321e4f3c3bd8

## Log pattern

```text
[drm] GetCencInitParams returned key/key_id/pssh for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

The original wording includes key; this initialization path supplies the key identifier and signaling rather than copying the secret key itself.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] GetCencInitParams returned key/key_id/pssh for 'live/camera'
```

## Short description

DASH initialization receives a fixed key identifier.

## Trigger condition

A usable common-encryption key is available for DASH with key rotation disabled.

## Explanation

The initialization data receives the protection header, key identifier, and scheme-specific constant IV.

## Possible causes

- A usable common-encryption key is available for DASH with key rotation disabled.
