# UDP input address reuse cannot be enabled

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-7d039f19e10eb046

## Log pattern

```text
set socket reuseaddr failed s=%d (errno=%d)
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Error: Operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set socket reuseaddr failed s=42 (errno=22)
```

## Short description

UDP input address reuse cannot be enabled.

## Trigger condition

Address reuse is requested but the socket option fails.

## Explanation

Setup logs the failure and continues to selector registration and binding; this failure alone does not abort the input.

## Possible causes

- Address reuse is requested but the socket option fails.

## What to check

1. Check the socket error and whether sharing the configured bind address is required.

## Recommended action

Resolve the reuse option failure if shared binding is needed.
