# Origin socket error

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-1a8856509caf383a

## Log pattern

```text
kEventError for origin s=%d ev=0x%x error=%d
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.
- Argument 3 — Socket error: Integer operating-system socket error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
kEventError for origin s=17 ev=0x10 error=111
```

## Short description

Origin socket error.

## Trigger condition

A plain origin socket reports an error event in an HTTP client or advertising download session.

## Explanation

The socket error status is logged. This branch itself does not finish the session; later connection events or timeout handling determine cleanup.

## Possible causes

- A plain origin socket reports an error event in an HTTP client or advertising download session.

## What to check

1. Check the origin connection and interpret the platform socket error; correlate with later closure or timeout messages.

## Recommended action

Check the origin connection and interpret the platform socket error; correlate with later closure or timeout messages.
