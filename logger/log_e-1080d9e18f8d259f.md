# Synchronization response exceeds its buffer

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_e
Log level: error
Documentation ID: log_e-1080d9e18f8d259f

## Log pattern

```text
buffer for sync request is too small
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
buffer for sync request is too small
```

## Short description

Synchronization response exceeds its buffer.

## Trigger condition

The accumulated response byte count reaches the configured or caller-supplied response-buffer capacity.

## Explanation

The synchronization request reports a receive failure.

## Possible causes

- The response cannot fit within the allocated response buffer.

## What to check

1. Check the response size and HTTP requestor buffer limit.

## Recommended action

Use a sufficient response buffer or reduce the response size.
