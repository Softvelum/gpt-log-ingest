# DRM initialization data contains an unexpected box

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-047cf9b53d4e6f89

## Log pattern

```text
invalid pssh atom. type=%u
```

## Parameters

- Argument 1 — Type: Unexpected four-byte box type interpreted as an unsigned integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid pssh atom. type=1836019574
```

## Short description

DRM initialization data contains an unexpected box.

## Trigger condition

Validation of supplied DRM initialization bytes encounters a box whose type is not pssh.

## Explanation

Validation fails and supplied initialization bytes are not copied into the output container.

## Possible causes

- Validation of supplied DRM initialization bytes encounters a box whose type is not pssh.

## What to check

1. Check the DRM provider initialization data contains only protection-system-specific-header boxes.
