# Registration proxy URL is invalid

Product: Nimble Streamer
Component: Server registration utility
Logging function: log_e
Log level: error
Documentation ID: log_e-be69702594ca9952

## Log pattern

```text
failed to parse proxy '%s'
```

## Parameters

- Argument 1 — proxy: Proxy URL supplied on the command line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse proxy 'invalid'
```

## Short description

Registration proxy URL is invalid.

## Trigger condition

The explicit proxy argument cannot be parsed during registration or rule application to an existing server.

## Explanation

The utility exits with failure before opening the panel connection.

## Possible causes

- The supplied proxy address cannot be interpreted by the proxy parser.

## What to check

1. Check the proxy argument syntax.

## Recommended action

Supply a correctly formed proxy address.
