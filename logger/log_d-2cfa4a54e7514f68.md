## Short description

Zixi cleanup request queued.

## Trigger condition

Shutdown cleanup begins when the Zixi request queue is empty.

## Explanation

Active ingest/output stream lists are cleared, a cleanup request is queued, and retrieval of the current Zixi stream list begins. Cleanup completion is not yet confirmed.

## Possible causes

- Shutdown cleanup begins when the Zixi request queue is empty.

## What to check

1. Check subsequent API request and response messages during shutdown.
