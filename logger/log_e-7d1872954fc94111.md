# Audio transport writer exceeds its buffer

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-7d1872954fc94111

## Log pattern

```text
[AM] cannot write mpeg2ts body for [%s/%s], used_size=%u, frame_size=%u
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Used size: Bytes already used in the affected output buffer.
- Argument 4 — Frame size: Media payload size in bytes, including any prepared transport header.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] cannot write mpeg2ts body for [live/camera], used_size=1048576, frame_size=4096
```

## Short description

Audio transport writer exceeds its buffer.

## Trigger condition

The transport packet writer reports insufficient capacity while writing audio for HLS or MPEG-TS over HTTP.

## Explanation

Audio transport packaging returns failure.

## Possible causes

- The transport packet writer reports insufficient capacity while writing audio for HLS or MPEG-TS over HTTP.

## What to check

1. Check transport overhead against remaining buffer capacity.

## Recommended action

Resolve the output-buffer sizing problem.
