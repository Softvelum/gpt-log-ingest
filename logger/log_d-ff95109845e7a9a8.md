# Waiting media operation requests missing DRM keys

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-ff95109845e7a9a8

## Log pattern

```text
[drm] request missing keys for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] request missing keys for 'live/camera'
```

## Short description

Waiting media operation requests missing DRM keys.

## Trigger condition

A protected operation must wait and no key set exists for its application and stream.

## Explanation

Key registration is attempted and the consumer is registered for notification.

## Possible causes

- A protected operation must wait and no key set exists for its application and stream.

## What to check

1. Check subsequent provider request and key response messages.

## Recommended action

Check subsequent provider request and key response messages.
