# Managed task output descriptor closed

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_v
Log level: verbose
Documentation ID: log_v-c588fb99f0f81391

## Log pattern

```text
closed fd=%d for pid=%d
```

## Parameters

- Argument 1 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 2 — Process: Integer task process identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
closed fd=12 for pid=1234
```

## Short description

Managed task output descriptor closed.

## Trigger condition

The output descriptor closes successfully during task stopping or completion. Available only on Linux builds.

## Explanation

The saved descriptor is invalidated; process stop or completion handling continues.
