# SLDP advertising wait expires and skips the item

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-dd4b427d3471995e

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d timer expired, skip advertising content %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — Content URI: Configured URI of the advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 timer expired, skip advertising content https://media.example/ad.mp4
```

## Short description

SLDP advertising wait expires and skips the item.

## Trigger condition

The matching cache-wait timer expires and the item error action is skip.

## Explanation

The observer and timer are removed; the sender selects the next scheduled content and attempts to continue.

## Possible causes

- The matching cache-wait timer expires and the item error action is skip.

## What to check

1. Check download time and the configured wait and skip policy.

## Recommended action

Prepare the media earlier if the item must play.
