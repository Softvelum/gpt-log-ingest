# Windows interface discovery failed

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-e8313e955589d07a

## Log pattern

```text
getaddrinfo failed error=%d
```

## Parameters

- Argument 1 — lookup\_error: Integer result returned by the Windows address lookup; not a socket descriptor.

## Log examples

The inspected source does not define the platform address-lookup error numbers.

## Short description

Windows interface discovery failed.

## Trigger condition

Windows address lookup for the local machine returns a nonzero error.

## Explanation

The error is logged and interface discovery returns an empty address-list string. The surrounding panel request can still be prepared.

## Possible causes

- The local address lookup returned an error.

## What to check

1. Check local address-resolution configuration and the reported lookup result.
