# Audio frame is early

Product: Nimble Streamer
Component: Timed local media sending
Logging function: log_e
Log level: error
Documentation ID: log_e-19185a6fa153c9bb

## Log pattern

```text
audio frame too early, delta=%lld, name=%s
```

## Parameters

- Argument 1 — Time difference: Frame timecode minus sender current system time, signed 64-bit milliseconds.
- Argument 2 — Stream: Timecode sender stream name, text.

The millisecond count is the duration representation type, passed without a cast to a signed long-long conversion. On platforms using signed long for that representation, the argument and conversion types differ.

## Short description

Audio frame is early.

## Trigger condition

The frame system timecode is more than ten seconds ahead of the sender current system-clock sample.

## Explanation

The incoming audio frame is discarded and is not added to the timed send queue.

## Possible causes

- The timecode or configured delay places the frame too far into the future.

## What to check

1. Check clock alignment and the configured timecode delay.

## Recommended action

Correct timecode order, delay, or clock alignment before resuming timed output.
