# DVR application directory is being scanned

Product: Nimble Streamer
Component: DVR
Logging function: log_v
Log level: verbose
Documentation ID: log_v-da71b9937a563dc9

## Log pattern

```text
loading dvr archives for app='%s' from path='%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Archive directory: Text giving the DVR storage directory.

## Log examples

Illustrative examples; these are not captured server logs.

```text
loading dvr archives for app='live' from path='/data/dvr/live/camera'
```

## Short description

DVR application directory is being scanned.

## Trigger condition

Application-wide DVR settings are applied.

## Explanation

Subdirectories are examined for per-stream archives.

## Possible causes

- Application-wide DVR settings are applied.
