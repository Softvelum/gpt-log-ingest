# VOD packaging request dispatched

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-b194719143985039

## Log pattern

```text
[TmxT::PR] f='%s' ck=%d chunk='%s' key='%s'
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.
- Argument 2 — Source is cached: Boolean rendered as 1 when the source text is a cache key and 0 when it is a local path.
- Argument 3 — Requested resource: Text name of the requested playlist, initialization segment, or media chunk.
- Argument 4 — Output cache key: Text cache key reserved for the requested generated output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[TmxT::PR] f='/media/movie.mp4' ck=0 chunk='n_0_0_0.ts' key='/vod/movie.mp4/n_0_0_0.ts'
```

## Short description

VOD packaging request dispatched.

## Trigger condition

The transmuxer starts handling a queued output request.

## Explanation

The source interpretation, requested resource, and reserved output key are logged before retrieving the output cache item and selecting a media handler.

## Possible causes

- The transmuxer starts handling a queued output request.
