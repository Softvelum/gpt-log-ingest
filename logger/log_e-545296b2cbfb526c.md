# SRT handshake publishing authorization failed

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-545296b2cbfb526c

## Log pattern

```text
[srt_listen_callback] url auth failed,streamid=[%s],ip=[%s]
```

## Parameters

- Argument 1 — Stream ID: Requested SRT stream identifier.
- Argument 2 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] url auth failed,streamid=[live/news?publishsign=example-invalid],ip=[192.0.2.20]
```

## Short description

SRT handshake publishing authorization failed.

## Trigger condition

The preliminary publishing-signature or authentication check rejects the publisher.

## Explanation

The handshake callback rejects the connection before applying password-file settings.

## Possible causes

- The preliminary publishing-signature or authentication check rejects the publisher.

## What to check

1. Check the stream-ID authentication parameters and publishing authorization.
