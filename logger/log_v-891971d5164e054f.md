# HTTP response requests a missing cache fragment

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_v
Log level: verbose
Documentation ID: log_v-891971d5164e054f

## Log pattern

```text
req2 fr=%u key='%s'
```

## Parameters

- Argument 1 — Fragment index: Zero-based cache fragment index, unsigned 32-bit integer; the first index is the range start divided by fragment granularity.
- Argument 2 — Cache key: Requested cache-item key, text; identifies the origin resource.

The first occurrence requests the fragment containing the requested range start; the second requests the next missing fragment after the previous fragment is released.

## Log examples

Illustrative examples; these are not captured server logs.

```text
req2 fr=2 key='https://origin.example/movie.mp4'
```

## Short description

HTTP response requests a missing cache fragment.

## Trigger condition

A required fragment is missing, requesting additional fragments is enabled, and observation of the cache item has been registered.

## Explanation

Nimble requests the fragment from the media cache manager. It can continue immediately if available, wait for a queued fetch, or fail if the fetch is rejected.
