# Pay-per-view response JSON has the wrong structure

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-01ba04a901c7c549

## Log pattern

```text
invalid PPV API response='%s'
```

## Parameters

- Argument 1 — response: Raw API response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid PPV API response='[]'
```

## Short description

Pay-per-view response JSON has the wrong structure.

## Trigger condition

The parsed top level is not an object, the deny list is not an object, or its identifier member is not an array.

## Explanation

The current deny list is cleared and the response is rejected.

## Possible causes

- The JSON does not follow the expected deny-list structure.

## What to check

1. Check the top-level object, deny-list object, and identifier array.

## Recommended action

Correct the handler response structure.
