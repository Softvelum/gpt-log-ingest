# Advertising download connection requested

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-69a2c5813d6f1842

## Log pattern

```text
downloading content=%s
```

## Parameters

- Argument 1 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
downloading content=https://media.example/ad.mp4
```

## Short description

Advertising download connection requested.

## Trigger condition

A content download or redirected download begins a connection attempt.

## Explanation

The URI is logged before validating HTTP or HTTPS and opening the connection; this is not a completion message.

## Possible causes

- A content download or redirected download begins a connection attempt.
