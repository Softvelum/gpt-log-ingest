# Management request receive failed

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-23e7663acd99e609

## Log pattern

```text
failed to recv buffer from s=%d
```

## Parameters

- Argument 1 — socket: Client socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv buffer from s=42
```

## Short description

Management request receive failed.

## Trigger condition

The receive helper returns an error for a non-TLS management connection.

## Explanation

The client enters its completed shutdown state and is removed by the management thread. TLS read errors take the same state transition without this particular message.

## Possible causes

- The plain socket read reported an error.

## What to check

1. Check connection diagnostics for the same descriptor.

## Recommended action

Resolve the connection failure before retrying the management request.
