# Stream-check socket close failed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-7f34520733aaac2b

## Log pattern

```text
failed to close checker socket s=%d (errno=%d)
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — error: Operating system error number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to close checker socket s=12 (errno=9)
```

## Short description

Stream-check socket close failed.

## Trigger condition

Closing a task socket returns an error after its event registration is removed.

## Explanation

The stored descriptor is cleared and TLS state is released despite the close error.

## Possible causes

- The operating system rejected socket closure.

## What to check

1. Check the error and preceding socket lifetime events.

## Recommended action

Investigate inconsistent socket cleanup.
