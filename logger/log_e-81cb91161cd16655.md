# Time-aligned keyframe copy failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-81cb91161cd16655

## Log pattern

```text
failed to make time aligned key frame for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to make time aligned key frame for [live/encoded]
```

## Short description

Time-aligned keyframe copy failed.

## Trigger condition

A new time boundary falls between frames and cloning the previous frame for the boundary keyframe fails.

## Explanation

The required boundary frame cannot be produced and video processing fails.

## Possible causes

- FFmpeg cannot allocate a reference-counted clone of the previous frame.

## What to check

1. Check memory pressure and preceding allocation errors.

## Recommended action

Restore memory availability and restart the affected encoder.
