# DVR media append failed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-c687c2788b5413c5

## Log pattern

```text
failed to save dvr segment to file='%s'
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to save dvr segment to file='/data/dvr/live/camera/1700000000000.dat'
```

## Short description

DVR media append failed.

## Trigger condition

Appending a normal segment or copying initialization data into a new shared storage file fails.

## Explanation

The affected segment-add operation returns failure; no new database record is written for this append.

## Possible causes

- Appending a normal segment or copying initialization data into a new shared storage file fails.

## What to check

1. Check disk space, file permissions, and preceding storage-write errors.

## Recommended action

Check disk space, file permissions, and preceding storage-write errors.
