# Worker exit condition reached

Product: Nimble Streamer
Component: Worker shutdown
Logging function: log_d
Log level: debug
Documentation ID: log_d-b59a4363ff491488

## Log pattern

```text
exit requested
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
exit requested
```

## Short description

Worker exit condition reached.

## Trigger condition

A worker observes a server exit request, an applicable local stop request, or its configured exit handler. The TCP and QUIC listeners also emit this when the Nimble license is invalid; publishing authorization emits it when its thread is interrupted. DVR workers can emit it when their interruptible sleep detects exit.

## Explanation

The emitting worker leaves its processing loop. Cleanup depends on the worker: scenario management closes connections and child controllers; transcoder management stops media workers and releases device contexts; live pull removes receivers and tasks; RTMP input removes cameras and listeners and joins workers; Icecast and RTSP input clear sessions and listeners; RTMP, RTSP and HLS publishers release publishers; HTTP workers delete sessions and close event monitoring; MPEG-TS and SRT input apply empty rules; management closes sockets; DVR management stops processing, DVR main joins writers, and DVR writers clear contexts; advertising rule handling releases rules and contents. Thumbnail, geographic update, logging, task, transmuxing, utility, advertising download, transport-sender and Zixi loops stop their current work. This event precedes completion of any remaining cleanup.

## Possible causes

- A server or local worker shutdown was requested.
- A TCP or QUIC listener detected an invalid Nimble license.
- The publishing authorization worker was interrupted.

## What to check

1. Use the emitting thread name and surrounding shutdown or licensing messages to identify which exit condition applied.

## Recommended action

No action is required for an intended shutdown. If a listener stopped unexpectedly, check Nimble licensing; otherwise inspect the preceding request that stopped the worker.
