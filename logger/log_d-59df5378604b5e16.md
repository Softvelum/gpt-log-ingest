# Remote VOD origin address normalized

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-59df5378604b5e16

## Log pattern

```text
o_host='%s' o_url='%s'
```

## Parameters

- Argument 1 — Origin host: Text containing the origin hostname and optional port.
- Argument 2 — Origin URL: Text giving the origin request path and query string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
o_host='media.example:8080' o_url='/live/camera/playlist.m3u8'
```

## Short description

Remote VOD origin address normalized.

## Trigger condition

A file_http or file_https route has been converted into an origin hostname and full remote path.

## Explanation

The request proceeds to remote VOD cache and transmuxing handling.

## Possible causes

- A file_http or file_https route has been converted into an origin hostname and full remote path.
