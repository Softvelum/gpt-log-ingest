# Inactive VOD playlist structure removed from cache

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-92849a18624e2b67

## Log pattern

```text
removing cached playlist structure for file='%s'
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removing cached playlist structure for file='/media/movie.mp4'
```

## Short description

Inactive VOD playlist structure removed from cache.

## Trigger condition

Periodic playlist-cache cleanup finds a structure unused for more than 60 seconds.

## Explanation

The in-memory playlist structure is deleted; a future request may rebuild it. This does not delete the source media file.

## Possible causes

- Periodic playlist-cache cleanup finds a structure unused for more than 60 seconds.

## What to check

1. Not applicable; this is normal processing progress. Follow the same source and output cache key if troubleshooting.

## Recommended action

Not applicable; this is normal processing progress. Follow the same source and output cache key if troubleshooting.
