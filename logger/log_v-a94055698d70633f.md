# No DRM key consumers need notification

Product: Nimble Streamer
Component: DRM key management
Logging function: log_v
Log level: verbose
Documentation ID: log_v-a94055698d70633f

## Log pattern

```text
[drm] not found key observers to notify for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] not found key observers to notify for 'live/camera'
```

## Short description

No DRM key consumers need notification.

## Trigger condition

Key completion tries to notify an owner with no registered listeners.

## Explanation

The notification operation returns; this is explicitly an expected condition.

## Possible causes

- Key completion tries to notify an owner with no registered listeners.
