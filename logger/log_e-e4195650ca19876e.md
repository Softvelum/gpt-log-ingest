# Origin body no longer fits its buffer

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-e4195650ca19876e

## Log pattern

```text
origin body buffer is too small to fit the response (received=%llu capacity=%llu) oh='%s' ou='%s'
```

## Parameters

- Argument 1 — Received bytes: Unsigned 64-bit cumulative origin-body bytes received.
- Argument 2 — Buffer capacity: Unsigned 64-bit response-buffer capacity in bytes.
- Argument 3 — Origin host: Text containing the origin hostname and optional port.
- Argument 4 — Origin URL: Text giving the origin request path and query string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
origin body buffer is too small to fit the response (received=65536 capacity=65536) oh='media.example:8080' ou='/live/camera/playlist.m3u8'
```

## Short description

Origin body no longer fits its buffer.

## Trigger condition

A non-circular response buffer has already received at least its capacity when another origin read is attempted.

## Explanation

Origin downloading stops and the client shutdown response is prepared.

## Possible causes

- A non-circular response buffer has already received at least its capacity when another origin read is attempted.

## What to check

1. Compare the origin Content-Length, body size, and cache allocation; the response cannot accept additional data.

## Recommended action

Compare the origin Content-Length, body size, and cache allocation; the response cannot accept additional data.
