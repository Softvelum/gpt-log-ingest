# Quick Sync hardware encoder selected

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_d
Log level: debug
Documentation ID: log_d-26fb4214b9e6f40a

## Log pattern

```text
%p quick sync %d.%d hw
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Major version: Selected media API major version, integer.
- Argument 3 — Minor version: Selected media API minor version, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 quick sync 1.17 hw
```

## Short description

Quick Sync hardware encoder selected.

## Trigger condition

Encoder session setup identifies a recognized hardware implementation.

## Explanation

The selected API version is reported. On Linux, opening and binding the VA display still follows this message.
