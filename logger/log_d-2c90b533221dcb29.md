# Recovered-statistics response status is unsuccessful

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-2c90b533221dcb29

## Log pattern

```text
sync status is not success ("%s"), discarding rules[recovered]
```

## Parameters

- Argument 1 — status: Panel-provided status string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync status is not success ("error"), discarding rules[recovered]
```

## Short description

Recovered-statistics response status is unsuccessful.

## Trigger condition

The recovered-statistics status is neither success nor unknown.

## Explanation

The response handler returns permission to continue synchronization. The successful-transport caller can then clear the pending recovered statistics even though the status was not success.
