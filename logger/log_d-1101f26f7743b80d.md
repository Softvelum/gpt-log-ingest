# Traffic update refers to an unknown session

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_d
Log level: debug
Documentation ID: log_d-1101f26f7743b80d

## Log pattern

```text
no session=%lu to update statistics for
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no session=42 to update statistics for
```

## Short description

Traffic update refers to an unknown session.

## Trigger condition

A traffic update finds the identifier in neither active nor inactive sessions.

## Explanation

No session counters or per-session statistics are updated.
