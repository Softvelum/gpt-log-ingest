## Short description

License server HTTP response is invalid.

## Trigger condition

The license service returned an invalid or incomplete HTTP response, or an unsuccessful HTTP status.

## Explanation

This license-validation attempt did not complete. The server can retry the license service; this message alone does not establish that the license was rejected.

## Possible causes

- The response is malformed, incomplete, or has a non-success status.

## What to check

1. Check the license server response and proxy behavior.

## Recommended action

Resolve the specific synchronization failure so license validation can succeed.
