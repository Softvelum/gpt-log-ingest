# AJA sender playback capability failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-27bd2a2392848d65

## Log pattern

```text
sender init failed device=%s/%d reason='device is not playback-capable'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender init failed device=0/0 reason='device is not playback-capable'
```

## Short description

AJA sender playback capability failed.

## Trigger condition

Starting the sender fails because the card does not support playback.

## Explanation

Video and audio output setup are not attempted.

## Possible causes

- Starting the sender fails because the card does not support playback.

## What to check

1. Check the preceding playback capability diagnostics and the selected device/channel.
