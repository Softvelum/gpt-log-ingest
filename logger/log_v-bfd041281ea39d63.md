# Legacy NVIDIA preset lookup is falling back

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_v
Log level: verbose
Documentation ID: log_v-bfd041281ea39d63

## Log pattern

```text
failed to get NVENC preset config session=%p nvStatus=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get NVENC preset config session=0x12340000 nvStatus=8
```

## Short description

Legacy NVIDIA preset lookup is falling back.

## Trigger condition

A legacy preset query fails in a build supporting NVIDIA API version 12 or newer.

## Explanation

Setup retries with the modern preset API, using the modern default preset if no supported preset is specified. This message does not by itself mean initialization fails.

## Possible causes

- The installed driver rejects the legacy preset query.

## What to check

1. Check whether modern preset retrieval or encoder initialization subsequently succeeds.

## Recommended action

No action is needed if fallback succeeds; otherwise choose a supported modern preset or compatible driver.
