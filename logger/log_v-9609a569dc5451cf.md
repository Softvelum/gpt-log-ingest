# Requested fragment is still unavailable

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-9609a569dc5451cf

## Log pattern

```text
continue waiting cache item key='%s' fragment=%u
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Fragment index: Unsigned zero-based cache fragment index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
continue waiting cache item key='/live/camera/segment1.ts' fragment=1
```

## Short description

Requested fragment is still unavailable.

## Trigger condition

A resumed fragmented response checks its awaited fragment without requesting it again, and no data is available yet.

## Explanation

The session continues waiting for another cache update.

## Possible causes

- A resumed fragmented response checks its awaited fragment without requesting it again, and no data is available yet.
