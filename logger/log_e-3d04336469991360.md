# New session identifier is already in use

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-3d04336469991360

## Log pattern

```text
session=%d already exists
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.

The unsigned-long session identifier is passed to a signed-int conversion, so its printed representation is not reliable across platforms.

## Log examples

No portable example is provided for the mismatched session identifier conversion.

## Short description

New session identifier is already in use.

## Trigger condition

A newly selected identifier exists in the active or inactive session map.

## Explanation

The counter advances and registration tries another identifier, up to the bounded collision limit.

## Possible causes

- The next identifier collides with a recorded session.

## What to check

1. Check nearby identifier-collision and registration messages.

## Recommended action

Investigate repeated collisions if they prevent new sessions.
