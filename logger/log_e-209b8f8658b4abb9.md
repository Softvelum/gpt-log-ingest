# URL verification digest allocation failed

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-209b8f8658b4abb9

## Log pattern

```text
EVP_MD_CTX_create() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
EVP_MD_CTX_create() failed
```

## Short description

URL verification digest allocation failed.

## Trigger condition

During encrypted-link validation, allocating the digest context returns no context.

## Explanation

Validation returns failure and no URL is assigned.

## Possible causes

- The cryptographic library reports that the verification context could not be allocated.

## What to check

1. Check matching encrypted-link data and session key, and available cryptographic library operations.

## Recommended action

Resolve the failed decryption or digest operation before accepting the link.
