# NVIDIA constrained encoding option is unsupported

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-0159ce7725aa3ea4

## Log pattern

```text
No HW support for Constrained Encoding mode, nvenc=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No HW support for Constrained Encoding mode, nvenc=0x12340000
```

## Short description

NVIDIA constrained encoding option is unsupported.

## Trigger condition

The constrained-encoding parameter is present, but the driver capability query reports no hardware support.

## Explanation

The requested option is not applied; encoder setup continues with its existing preset value. Presence of the option triggers this message even when its requested value would disable the feature.

## Possible causes

- The selected GPU/codec does not report support for constrained encoding.

## What to check

1. Check whether this option is needed and whether the GPU supports it for the selected codec.

## Recommended action

Remove the unsupported option or select hardware that supports it.
