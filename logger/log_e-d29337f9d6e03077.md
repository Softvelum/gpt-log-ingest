# Buffered socket send failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_e
Log level: error
Documentation ID: log_e-d29337f9d6e03077

## Log pattern

```text
failed to send buffer to %s s=%d
```

## Parameters

- Argument 1 — Peer role: Text identifying the socket role.
- Argument 2 — Socket: Integer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer to origin s=13
```

## Short description

Buffered socket send failed.

## Trigger condition

Sending buffered data returns a fatal operation result.

## Explanation

The buffer-send helper returns failure without advancing its sent-byte count. A TLS request to wait for read or write readiness is handled separately and does not produce this message.

## Possible causes

- A non-TLS send failed, or a TLS send failed without requesting another readiness event.

## What to check

1. Check the preceding socket or TLS error for the same connection.
