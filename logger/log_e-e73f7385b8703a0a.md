# Advertising session handler is not an object

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-e73f7385b8703a0a

## Log pattern

```text
invalid session_handler type=%d
```

## Parameters

- Argument 1 — JSON type: Integer JSON type code of the unexpected value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid session_handler type=6
```

## Short description

Advertising session handler is not an object.

## Trigger condition

The session handler field in the main rules response has a non-object JSON type.

## Explanation

Handler parsing stops. The resulting handler URL is empty and its default settings are applied.

## Possible causes

- The session handler field in the main rules response has a non-object JSON type.

## What to check

1. Return a JSON object for the session handler settings.

## Recommended action

Return a JSON object for the session handler settings.
