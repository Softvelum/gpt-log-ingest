# Task event has no matching task

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-219b63daa6386484

## Log pattern

```text
fd=%d ev=0x%x not found in tasks list
```

## Parameters

- Argument 1 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 2 — Event mask: Hexadecimal socket-event bit mask.

## Log examples

Illustrative examples; these are not captured server logs.

```text
fd=12 ev=0x1 not found in tasks list
```

## Short description

Task event has no matching task.

## Trigger condition

An event arrives for a descriptor that is absent from the managed task table. Available only on Linux builds.

## Explanation

The event is ignored without updating any task activity or output.

## Possible causes

- No task currently owns the event descriptor.

## What to check

1. Compare the descriptor with preceding task-start and task-completion events.
