# RTSP HTTP tunnel connection destroyed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-db3025662a2ff00c

## Log pattern

```text
rtsp tunnel close, s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtsp tunnel close, s=25
```

## Short description

RTSP HTTP tunnel connection destroyed.

## Trigger condition

The RTSP HTTP tunnel connection is being destroyed.

## Explanation

Its parent RTSP input is asked to shut down when still attached. The message marks cleanup rather than explaining the original reason for disconnection.

## Possible causes

- The connection lifetime has ended.

## What to check

1. If the disconnection was unexpected, check preceding messages for the same socket.
