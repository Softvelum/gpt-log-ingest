# Widevine returned an unregistered key

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-8a60a75f33886ff6

## Log pattern

```text
[drm] not found Widevine key to update for '%s' cpi=%u type='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned index of the requested or selected key rotation period.
- Argument 3 — Key type: Text classifying the Widevine media key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] not found Widevine key to update for 'live/camera' cpi=120 type='HD'
```

## Short description

Widevine returned an unregistered key.

## Trigger condition

A successful Widevine response includes a period/type combination absent from the stored placeholders.

## Explanation

That key is not installed; waiting consumers are notified that at least one returned key could not be matched.

## Possible causes

- A successful Widevine response includes a period/type combination absent from the stored placeholders.

## What to check

1. Compare the requested crypto periods and media-key types with the response.

## Recommended action

Compare the requested crypto periods and media-key types with the response.
