# Waiting before panel synchronization

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_v
Log level: verbose
Documentation ID: log_v-7fd330a593bc669f

## Log pattern

```text
sleeping for %d seconds before the next sync
```

## Parameters

- Argument 1 — delay\_seconds: Requested wait in seconds; 0 through 30 in these paths.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sleeping for 30 seconds before the next sync
```

## Short description

Waiting before panel synchronization.

## Trigger condition

The loop reaches the delay after a successful exchange, or after a failed request attempt.

## Explanation

After success, the delay is the remaining time in the 30-second interval from the last complete sync, or zero if overdue or the clock moved backward. Failed attempts use 30 seconds. A settings-sync request can interrupt the wait.
