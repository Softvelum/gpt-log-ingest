# NDI input discovery finder could not be created

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-8b99489ec045dbc6

## Log pattern

```text
failed to create ndi finder, name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create ndi finder, name=Camera
```

## Short description

NDI input discovery finder could not be created.

## Trigger condition

The NDI library returns no finder while initializing the requested input.

## Explanation

Receiver initialization returns failure before searching for sources.

## Possible causes

- The NDI library returns no finder while initializing the requested input.

## What to check

1. Check whether the NDI runtime can create a discovery finder.
