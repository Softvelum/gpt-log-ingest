# MP3 mono or stereo mode was rejected

Product: Nimble Streamer
Component: MP3 audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-b41f7785c84b777e

## Log pattern

```text
failed to set mode, status=%d
```

## Parameters

- Argument 1 — Status: LAME return status, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set mode, status=-1
```

## Short description

MP3 mono or stereo mode was rejected.

## Trigger condition

In a LAME-enabled build, applying mono or stereo mode returns a nonzero status.

## Explanation

Encoder initialization stops and the audio-frame write reports failure.

## Possible causes

- LAME rejected mono or stereo mode.

## What to check

1. Check the input channels and joint-stereo setting and the returned LAME status.

## Recommended action

Correct the rejected MP3 encoder setting.
