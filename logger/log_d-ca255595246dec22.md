# CPIX provider response received

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-ca255595246dec22

## Log pattern

```text
[drm] GetKeyRequest response for='%s' from %s server:
%.*s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Provider: Text naming the DRM provider.
- Argument 3 — Response length: Integer limit in bytes for the response text that follows.
- Argument 4 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] GetKeyRequest response for='live/camera' from Widevine server:
{}
```

## Short description

CPIX provider response received.

## Trigger condition

A managed key request for a CPIX-based provider completes.

## Explanation

The response is logged before checking its destination key slot and provider-specific payload.

## Possible causes

- A managed key request for a CPIX-based provider completes.
