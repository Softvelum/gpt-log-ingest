# DVR segment record is being removed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_d
Log level: debug
Documentation ID: log_d-b00679dfc90416b0

## Log pattern

```text
remove dvr str='%s/%s' f='%s' p=%u st=%llu of=%llu dbof=%u t=%u
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Storage file: Text naming the recorded media storage file.
- Argument 4 — Period: Unsigned recording period identifier.
- Argument 5 — Media start: Unsigned 64-bit media start timestamp in the segment track timescale.
- Argument 6 — File offset: Unsigned 64-bit byte offset within the media storage file.
- Argument 7 — Database offset: Unsigned byte offset of the segment record in its database.
- Argument 8 — Segment type: Integer category: 0 video initialization, 1 audio initialization, 2 video, 3 audio, 4 shared data file, 5 JPEG, 6 DVB subtitles, 7 KLV metadata, 8 WebVTT.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remove dvr str='live/camera' f='/data/dvr/live/camera/1700000000000.dat' p=1 st=90000 of=1024 dbof=512 t=2
```

## Short description

DVR segment record is being removed.

## Trigger condition

A noninitialization segment is selected for deletion.

## Explanation

Its database entry is marked deleted before releasing its file reference; physical file removal depends on remaining data and users.

## Possible causes

- A noninitialization segment is selected for deletion.
