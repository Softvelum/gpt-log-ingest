# RTSP HTTP tunnel connection created

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-2400a8a457fe5a22

## Log pattern

```text
rtsp tunnel open, s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtsp tunnel open, s=25
```

## Short description

RTSP HTTP tunnel connection created.

## Trigger condition

The RTSP HTTP tunnel connection object is constructed.

## Explanation

The connection reports itself to its parent RTSP input and reports the tunnel connection to its RTSP client. This records creation, not proof that remote media has arrived.

## Possible causes

- Normal creation of a RTSP HTTP tunnel connection.
