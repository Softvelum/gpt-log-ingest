# NDI sender speeds up to reduce buffering

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-5873cc0b101a21d3

## Log pattern

```text
buffer delay=%lld, correction=%lld, speed up
```

## Parameters

- Argument 1 — Buffer delay: Current buffered stream duration in milliseconds.
- Argument 2 — Correction: Positive amount subtracted from the pacing origin in milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
buffer delay=700, correction=8, speed up
```

## Short description

NDI sender speeds up to reduce buffering.

## Trigger condition

Buffered delay is above the 500-millisecond target and the pacing correction rounds to a positive value.

## Explanation

The sender moves its pacing start time earlier, reducing the output wait to consume excess buffered media.

## Possible causes

- Buffered delay is above the 500-millisecond target and the pacing correction rounds to a positive value.

## What to check

1. Check the reported buffer delay relative to the 500-millisecond target.
