# Management client construction failed

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-71d5d20755805a34

## Log pattern

```text
failed to create client s=%d
```

## Parameters

- Argument 1 — socket: Newly accepted socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create client s=42
```

## Short description

Management client construction failed.

## Trigger condition

An exception occurs while constructing a client for a newly accepted management socket.

## Explanation

The accept handler logs the failure and returns before adding the socket to its active client tables. The message does not identify the exception.

## Possible causes

- Client construction raised an exception.

## What to check

1. Check surrounding resource and selector diagnostics.
