# Playlist media has no selected audio or video

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-9e39397b54cf2be5

## Log pattern

```text
no video/audio stream found, %s a_stream_id=%d, v_stream_id=%d

```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.
- Argument 2 — Track selection: Integer ordinal among supported tracks; minus one selects automatically and minus two disables that media kind.
- Argument 3 — Track selection: Integer ordinal among supported tracks; minus one selects automatically and minus two disables that media kind.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no video/audio stream found, /media/program.mp4 a_stream_id=0, v_stream_id=0

```

## Short description

Playlist media has no selected audio or video.

## Trigger condition

No supported audio or video track is selected after scanning the input.

## Explanation

Opening the reader fails.

## Possible causes

- No supported audio or video track is selected after scanning the input.

## What to check

1. Check the media codecs and audio/video track selections.

## Recommended action

Check the media codecs and audio/video track selections.
