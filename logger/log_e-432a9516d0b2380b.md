# AJA writer session information is invalid

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-432a9516d0b2380b

## Log pattern

```text
failed to parse AJA writer info
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse AJA writer info
```

## Short description

AJA writer session information is invalid.

## Trigger condition

The session message is missing, not a JSON object, or lacks a positive ID, nonempty IP address and name, or positive port.

## Explanation

The control message is ignored before replacing an existing session or creating a new worker.

## Possible causes

- The session message is missing, not a JSON object, or lacks a positive ID, nonempty IP address and name, or positive port.

## What to check

1. Check the internal writer session description and required fields.

## Recommended action

Supply a complete valid session description.
