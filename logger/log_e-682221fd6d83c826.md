# Internal HTTP request session creation raised an exception

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-682221fd6d83c826

## Log pattern

```text
failed to create requestor session for url='%s'
```

## Parameters

- Argument 1 — URL: Requested resource URL as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create requestor session for url='https://origin.example/media'
```

## Short description

Internal HTTP request session creation raised an exception.

## Trigger condition

An exception occurs while creating a session for a queued internal request or registering its timeout.

## Explanation

The exception is caught and processing continues with other requests. This catch does not explicitly notify the waiting request recipient.

## Possible causes

- Session construction or timeout registration raised an exception.

## What to check

1. Inspect the URL and preceding request-session diagnostics.
