# License endpoint does not permit required TLS

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-7b5838411068e1f5

## Log pattern

```text
wrong domain server settings
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

License endpoint does not permit required TLS.

## Trigger condition

The selected license endpoint does not have the required TLS transport enabled.

## Explanation

The endpoint iterator advances and this validation attempt returns a recoverable result without sending a request.

## Possible causes

- The chosen endpoint has incompatible transport settings.

## What to check

1. Check the license-server endpoint TLS setting.

## Recommended action

Use an endpoint configured for TLS license validation.
