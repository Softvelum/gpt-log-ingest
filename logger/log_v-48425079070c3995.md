# HTTP byte-range syntax rejected

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-48425079070c3995

## Log pattern

```text
invalid Range field format: '%s'
```

## Parameters

- Argument 1 — Range field: Text of the client Range request header.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid Range field format: 'items=0-10'
```

## Short description

HTTP byte-range syntax rejected.

## Trigger condition

An origin, cached restream, or local file response receives a Range field that fails the supported byte-range parser.

## Explanation

HTTP 416 is prepared before sending the requested media range.

## Possible causes

- An origin, cached restream, or local file response receives a Range field that fails the supported byte-range parser.

## What to check

1. Send a supported bytes= range with a dash and numeric bounds; inspect the literal field shown here. This message reports parsing failure rather than a valid range extending beyond the file.

## Recommended action

Send a supported bytes= range with a dash and numeric bounds; inspect the literal field shown here. This message reports parsing failure rather than a valid range extending beyond the file.
