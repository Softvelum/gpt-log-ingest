# FLV module command inspected

Product: Nimble Streamer
Component: Non-Windows progressive download modules
Logging function: log_d
Log level: debug
Documentation ID: log_d-3398569d906d4ea8

## Log pattern

```text
flv module command %.*s

```

## Parameters

- Argument 1 — length: Number of command-name characters printed.
- Argument 2 — command: Command name from the module command table.

## Log examples

Illustrative examples; these are not captured server logs.

```text
flv module command flv

```

## Short description

FLV module command inspected.

## Trigger condition

The FLV module initialization loop examines a command entry.

## Explanation

The command name is logged before testing whether it selects the FLV request handler. This message does not prove module initialization completed.
