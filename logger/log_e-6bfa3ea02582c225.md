# SDI video converter opening failed

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-6bfa3ea02582c225

## Log pattern

```text
failed to open video converter for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open video converter for [live/camera]
```

## Short description

SDI video converter opening failed.

## Trigger condition

Opening the output video encoder returns a negative result.

## Explanation

The current output frame operation returns failure.

## Possible causes

- The video encoder rejects the configured output parameters.

## What to check

1. Check the output video parameters and nearby FFmpeg diagnostics.

## Recommended action

Correct the output parameters and retry.
