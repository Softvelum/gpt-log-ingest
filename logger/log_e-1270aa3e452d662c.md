# Widevine response JSON cannot be parsed

Product: Nimble Streamer
Component: Widevine DRM
Logging function: log_e
Log level: error
Documentation ID: log_e-1270aa3e452d662c

## Log pattern

```text
[Widevine] error parsing json='%s'
```

## Parameters

- Argument 1 — Response body: Text containing the original outer response.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[Widevine] error parsing json='invalid JSON'
```

## Short description

Widevine response JSON cannot be parsed.

## Trigger condition

Either the outer response or the base64-decoded response cannot be parsed as JSON.

## Explanation

Key response parsing returns failure. The original outer body is logged in either case.

## Possible causes

- Either the outer response or the base64-decoded response cannot be parsed as JSON.

## What to check

1. Check the outer JSON response and its base64-encoded payload.

## Recommended action

Check the outer JSON response and its base64-encoded payload.
