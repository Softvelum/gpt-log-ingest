# Invalid closed-caption language setting skipped

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-d14993a4be2488d7

## Log pattern

```text
invalid parameter value: %s (%s)
```

## Parameters

- Argument 1 — Settings: Complete caption-language settings string.
- Argument 2 — Item: Rejected assignment or application/stream item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 608.x=eng (608.x=eng)
```

## Short description

Invalid closed-caption language setting skipped.

## Trigger condition

A caption-language setting cannot be parsed as a channel-to-language assignment, uses a caption family other than 608 or 708, or has a channel number outside the accepted numeric type.

## Explanation

The invalid item is skipped while other valid assignments can be retained. Prefix parsing also contains this diagnostic for invalid application/stream syntax.

## Possible causes

- A caption-language setting cannot be parsed as a channel-to-language assignment, uses a caption family other than 608 or 708, or has a channel number outside the accepted numeric type.

## What to check

1. Check the displayed item within the complete settings string.

## Recommended action

Use valid channel-to-language assignments and supported caption-family prefixes.
