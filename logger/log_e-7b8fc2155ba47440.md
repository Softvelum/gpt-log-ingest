# IPv4 hostname resolution failed

Product: Nimble Streamer
Component: Host address resolution
Logging function: log_e
Log level: error
Documentation ID: log_e-7b8fc2155ba47440

## Log pattern

```text
failed to resolve '%s' h_errnop=%d
```

## Parameters

- Argument 1 — Host: Requested hostname or address text.
- Argument 2 — Resolver result: Address-resolution result code, integer; despite its label this is not an operating system errno.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to resolve 'example.invalid' h_errnop=-2
```

## Short description

IPv4 hostname resolution failed.

## Trigger condition

IPv4 TCP address resolution returns a nonzero resolver result or no result list.

## Explanation

No addresses are appended and the lookup reports failure.

## Possible causes

- The resolver cannot supply an IPv4 address for the host.

## What to check

1. Check the hostname and resolver return code.

## Recommended action

Correct the hostname or resolve the address-lookup error.
