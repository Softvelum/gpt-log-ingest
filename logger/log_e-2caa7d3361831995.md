# Cache fragment creation or mapping failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-2caa7d3361831995

## Log pattern

```text
failed to create and map fragment file='%s'
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create and map fragment file='/var/cache/nimble/movie.fr/1'
```

## Short description

Cache fragment creation or mapping failed.

## Trigger condition

The file creation and mapping helper cannot allocate an additional fragment.

## Explanation

The temporary fragment object is deleted and allocation returns failure without adding it to the cache.

## Possible causes

- Creating or mapping the fragment file failed.

## What to check

1. Check nearby file creation or mapping errors for the concrete cause.

## Recommended action

Correct the filesystem or mapping failure before retrying.
