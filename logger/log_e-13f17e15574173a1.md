# OMT requires top-field-first interlacing

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-13f17e15574173a1

## Log pattern

```text
omt only supports tff interlaced frames, add fieldorder=tff into video pipeline for omt_stream=%s
```

## Parameters

- Argument 1 — Output: Local output stream or AJA writer name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
omt only supports tff interlaced frames, add fieldorder=tff into video pipeline for omt_stream=camera
```

## Short description

OMT requires top-field-first interlacing.

## Trigger condition

The input video frame is interlaced and its top-field-first flag is false.

## Explanation

The frame is rejected before common local-output validation and queueing.

## Possible causes

- The upstream pipeline supplied bottom-field-first interlaced video.

## What to check

1. Check the input field order and OMT output filter chain.

## Recommended action

Add fieldorder=tff for this interlaced output.
