# WebVTT queue duration has no queued message

Product: Nimble Streamer
Component: WebVTT timing synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-89d48538653b7fcc

## Log pattern

```text
empty webvtt sync queue has nonzero duration for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name.
- Argument 2 — Stream: Stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
empty webvtt sync queue has nonzero duration for [live/news]
```

## Short description

WebVTT queue duration has no queued message.

## Trigger condition

The send loop still meets its duration threshold while the message queue is empty.

## Explanation

Last audio/video references are cleared and the send operation returns success. A zero duration threshold can also reach this branch despite the wording.

## Possible causes

- The send loop still meets its duration threshold while the message queue is empty.

## What to check

1. Check the configured queue duration and timing state.
