# Decoded AAC output frame allocation failed

Product: Nimble Streamer
Component: FDK AAC audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-d98e65a5fbf16712

## Log pattern

```text
failed to alloc output frame [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc output frame [live/camera]
```

## Short description

Decoded AAC output frame allocation failed.

## Trigger condition

In an FDK-enabled build, creating the signed 16-bit output frame with the decoded sample count, channel layout, and sample rate fails.

## Explanation

The decoded frame is not forwarded and packet processing fails.

## Possible causes

- The decoder or sample-handling operation described by the message failed.

## What to check

1. Check the AAC input parameters and accompanying decoder diagnostics.

## Recommended action

Resolve the indicated AAC decode or output-frame failure.
