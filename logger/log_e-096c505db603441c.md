# DVR export media padding send failed

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-096c505db603441c

## Log pattern

```text
failed to send mixed mdat remainder stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send mixed mdat remainder stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

DVR export media padding send failed.

## Trigger condition

Sending a buffer of media-data padding fails.

## Explanation

The export closes. This helper also serves single-track exports despite the mixed wording.

## Possible causes

- Sending a buffer of media-data padding fails.

## What to check

1. Check the client connection and transport errors.

## Recommended action

Check the client connection and transport errors.
