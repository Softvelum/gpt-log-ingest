# RTMP publish status status object opening cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-0913ef2b4242d152

## Log pattern

```text
failed to read object start for publish/onStatus
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read object start for publish/onStatus
```

## Short description

RTMP publish status status object opening cannot be decoded.

## Trigger condition

The remote publish onStatus response lacks a readable AMF object start at its status object opening.

## Explanation

The pending command response is marked failed and connection processing stops.

## Possible causes

- The remote publish onStatus response lacks a readable AMF object start at its status object opening.

## What to check

1. Inspect the publish status response field order and AMF types.

## Recommended action

Correct the malformed status response at the remote endpoint.
