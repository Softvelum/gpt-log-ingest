# Whisper audio decoder wrapper created

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-bc503f685cd2e030

## Log pattern

```text
whisper decoder created for stream='%s' lang=%s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Language: Configured language identifier for this transcription process; it may differ from the effective detected language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whisper decoder created for stream='live/news' lang=en
```

## Short description

Whisper audio decoder wrapper created.

## Trigger condition

The first audio payload finds a valid stored configuration and a new transcription decoder is allocated.

## Explanation

The model context is initialized later while processing this audio. This log alone does not confirm that model initialization succeeds.

## Possible causes

- The first audio payload finds a valid stored configuration and a new transcription decoder is allocated.

1. Check the following model-context and transcription messages.
