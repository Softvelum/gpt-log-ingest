# Live video format is unsupported

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-a79636cb027b58c0

## Log pattern

```text
unsupported video format [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

Compressed forwarding accepts MPEG-2, H.264, HEVC, and AV1. Decoder setup additionally handles VP8 and VP9 before sequence-header dispatch. The names identify the input.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video format [live/camera]
```

## Short description

Live video format is unsupported.

## Trigger condition

A live sequence-header update reaches a codec outside the accepted dispatch cases.

## Explanation

The encoder forwarding update or video decoder update returns failure.

## Possible causes

- The source codec is unsupported by the selected processing path.

## What to check

1. Check the live input codec and whether the operation decodes or forwards compressed video.

## Recommended action

Choose a supported codec or a different input/output path.
