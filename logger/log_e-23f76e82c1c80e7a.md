# Cache fragment allocation is duplicated

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-23f76e82c1c80e7a

## Log pattern

```text
fragment=%llu is already allocated for item key='%s'
```

## Parameters

- Argument 1 — fragment: Zero-based fragment index.
- Argument 2 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
fragment=1 is already allocated for item key='movie'
```

## Short description

Cache fragment allocation is duplicated.

## Trigger condition

The requested fragment is already available or already has an allocated fragment object.

## Explanation

Allocation returns failure without replacing the existing fragment.

## Possible causes

- The same fragment allocation was requested again.

## What to check

1. Look for the earlier allocation or availability message for this fragment.

## Recommended action

Investigate duplicate allocation of the fragment.
