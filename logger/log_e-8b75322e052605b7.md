# File video codec is unsupported

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-8b75322e052605b7

## Log pattern

```text
unsupported video format: %d [%s]
```

## Parameters

- Argument 1 — Codec: FFmpeg codec identifier, integer enumeration value; no unit.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video format: 173 [live/camera]
```

## Short description

File video codec is unsupported.

## Trigger condition

The selected file video track is neither MPEG-2, H.264, MJPEG, BMP, TIFF, GIF, PNG, nor APNG.

## Explanation

The file decoder cannot be selected and the video worker stops.

## Possible causes

- The input file track uses a codec outside this file-reading path.

## What to check

1. Check the selected track and reported FFmpeg codec identifier.

## Recommended action

Convert the file to a supported codec or use another input path.
