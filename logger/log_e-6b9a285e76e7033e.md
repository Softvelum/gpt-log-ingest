# Could not create the DVR control worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e

## Short description

Could not create the DVR control worker.

## Trigger condition

The main DVR control worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the DVR control worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed DVR control worker.
