# Invalid SRT stream users section

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-a1c246e54873bb72

## Log pattern

```text
[srt_listen_callback] failed to parse 'users' section from password file [%s] for [%s] stream
```

## Parameters

- Argument 1 — File: Configured SRT password-settings file path.
- Argument 2 — Stream: Requested application/stream identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] failed to parse 'users' section from password file [/data/srt-users.json] for [live/news] stream
```

## Short description

Invalid SRT stream users section.

## Trigger condition

The matching stream contains a users section whose value is not a JSON object.

## Explanation

Per-user SRT settings cannot be selected and the publisher is rejected.

## Possible causes

- The matching stream contains a users section whose value is not a JSON object.

## What to check

1. Check the users object for the requested stream.

## Recommended action

Use a JSON object mapping user identifiers to their settings.
