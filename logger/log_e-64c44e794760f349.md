# AJA capture audio setup failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-64c44e794760f349

## Log pattern

```text
init failed device=%s/%d reason='audio setup failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
init failed device=0/0 reason='audio setup failed'
```

## Short description

AJA capture audio setup failed.

## Trigger condition

Receiver initialization fails because audio capture is enabled and device audio setup fails.

## Explanation

Capture initialization stops before host-buffer setup.

## Possible causes

- Receiver initialization fails because audio capture is enabled and device audio setup fails.

## What to check

1. Check the preceding device or capture audio setup error details.
