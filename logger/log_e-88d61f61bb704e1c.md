# Legacy NVIDIA preset retrieval failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-88d61f61bb704e1c

## Log pattern

```text
failed to get NVENC preset config session=%p nvStatus=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get NVENC preset config session=0x12340000 nvStatus=8
```

## Short description

Legacy NVIDIA preset retrieval failed.

## Trigger condition

A legacy preset query fails in a build using an NVIDIA API older than version 12.

## Explanation

Encoder initialization returns failure; this build has no modern preset fallback on this path.

## Possible causes

- The driver rejects the requested legacy codec/preset query.

## What to check

1. Check the result and compatibility of the installed driver, codec and preset.

## Recommended action

Select a supported preset or use a compatible build and driver.
