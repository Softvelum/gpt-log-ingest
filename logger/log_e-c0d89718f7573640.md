# DVR audio codec is unsupported

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-c0d89718f7573640

## Log pattern

```text
[AM] format is not supported stream='%s' codec=%d
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Codec: Integer internal audio codec identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] format is not supported stream='live/camera' codec=0
```

## Short description

DVR audio codec is unsupported.

## Trigger condition

The recording buffer audio codec is neither AAC, MP3, AC3, nor EAC3.

## Explanation

Audio processing fails for this recording pass.

## Possible causes

- The recording buffer audio codec is neither AAC, MP3, AC3, nor EAC3.

## What to check

1. Record a supported audio codec.

## Recommended action

Record a supported audio codec.
