# Plain socket send returned an error

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-ba74329e3cd9d449

## Log pattern

```text
failed to send to %s s=%d (errno=%d)
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Socket: Integer socket descriptor.
- Argument 3 — System error: Integer operating-system socket error value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send to client s=12 (errno=32)
```

## Short description

Plain socket send returned an error.

## Trigger condition

A non-TLS send fails on either the Windows or non-Windows socket path.

## Explanation

The relevant platform socket error is saved and the negative result is returned to the caller.

## Possible causes

- The operating-system send operation returned an error.

## What to check

1. Inspect the peer role, socket and system error.
