# Error event from an unowned socket

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-e572af26383e002e

## Log pattern

```text
kEventError for unknown s=%d ev=0x%x
```

## Parameters

- Argument 1 — Socket descriptor: Integer identifying the affected local socket.
- Argument 2 — Event mask: Hexadecimal integer mask of reported socket events.

## Log examples

Illustrative examples; these are not captured server logs.

```text
kEventError for unknown s=17 ev=0x10
```

## Short description

Error event from an unowned socket.

## Trigger condition

An error event carries a descriptor that matches neither the HTTP client nor origin socket, or does not match the advertising download socket.

## Explanation

The ownership inconsistency is logged; this branch does not itself close a socket.

## Possible causes

- An error event carries a descriptor that matches neither the HTTP client nor origin socket, or does not match the advertising download socket.

## What to check

1. Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.

## Recommended action

Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.
