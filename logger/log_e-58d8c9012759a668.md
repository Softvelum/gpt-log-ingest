# SRT publisher matches IP deny rule

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-58d8c9012759a668

## Log pattern

```text
[srt_listen_callback] publisher denied by ip. password path=[%s], ip=[%s]
```

## Parameters

- Argument 1 — File: Configured SRT password-settings file path.
- Argument 2 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] publisher denied by ip. password path=[/data/srt-users.json], ip=[192.0.2.20]
```

## Short description

SRT publisher matches IP deny rule.

## Trigger condition

The publisher address matches a global or stream-specific deny rule in the password settings.

## Explanation

Authentication settings processing returns failure and the publisher connection is rejected.

## Possible causes

- The publisher address matches a global or stream-specific deny rule in the password settings.

## What to check

1. Check the publisher address against the applicable deny rules.
