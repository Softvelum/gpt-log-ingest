# Configured caption language is duplicated

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-5409d56cb2563435

## Log pattern

```text
cea708_langs: duplicate lang "%s" for [%s/%s], ignored
```

## Parameters

- Argument 1 — Language: Repeated configured caption language.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cea708_langs: duplicate lang "eng" for [live/camera], ignored
```

## Short description

Configured caption language is duplicated.

## Trigger condition

CEA-708 generation from WebVTT sees a repeated language in its explicit language order.

## Explanation

The duplicate entry is ignored and setup continues with the original language-to-service assignment.

## Possible causes

- CEA-708 generation from WebVTT sees a repeated language in its explicit language order.

## What to check

1. Check repeated entries in the caption language order.

## Recommended action

Remove duplicate language entries.
