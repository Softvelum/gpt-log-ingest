# FLAC decoder is unavailable

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f1028c032a16f8b7

## Log pattern

```text
failed to find FLAC decoder for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find FLAC decoder for [live/camera]
```

## Short description

FLAC decoder is unavailable.

## Trigger condition

The first availability lookup finds no registered FFmpeg FLAC decoder.

## Explanation

The missing-decoder result is cached, the update returns success, and subsequent FLAC frames are skipped by this worker.

## Possible causes

- The loaded FFmpeg codec library does not provide this decoder.

## What to check

1. Check the loaded codec library and required FLAC support.

## Recommended action

Use a codec library with FLAC decoding support or change the input codec.
