# RIST child connection entered transport initialization

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-66b0f0cc7975ea01

## Log pattern

```text
out of process rist %s started, id=%s
```

## Parameters

- Argument 1 — Role: sender for output, or player for input.
- Argument 2 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
out of process rist player started, id=rist-input
```

## Short description

RIST child connection entered transport initialization.

## Trigger condition

The RIST runtime is loaded and its address has been parsed.

## Explanation

The selected sender or player initialization is called after this message. The word started does not establish that context creation, peer creation, or transport startup has succeeded.

## Possible causes

- Normal entry into RIST sender or receiver initialization.

## What to check

1. Check subsequent initialization messages to determine whether transport startup succeeded.
