# Unused DRM key removed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-2902704964f455c7

## Log pattern

```text
[drm] remove %s key for '%s' cpi=%u type='%s' url='%s'
```

## Parameters

- Argument 1 — Removal reason: Text describing cleanup; this path supplies unused.
- Argument 2 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 3 — Crypto-period index: Unsigned index of the requested or selected key rotation period.
- Argument 4 — Key type: Text classifying the Widevine media key.
- Argument 5 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] remove unused key for 'live/camera' cpi=120 type='HD' url='https://keys.example/key'
```

## Short description

Unused DRM key removed.

## Trigger condition

All keys for an inactive owner have been unused for over 30 minutes and the removed key has no remaining references.

## Explanation

Its URL lookup and inactive key set are removed.

## Possible causes

- All keys for an inactive owner have been unused for over 30 minutes and the removed key has no remaining references.
