# Managed task did not confirm forced termination

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-113a1a61201081d2

## Log pattern

```text
failed to stop task with SIGKILL pid=%d cmd='%s' errno=%d
```

## Parameters

- Argument 1 — Process: Integer task process identifier.
- Argument 2 — Command: Configured shell command text.
- Argument 3 — System error: Integer operating-system error value; it may be stale unless the preceding operation failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to stop task with SIGKILL pid=1234 cmd='echo ready' errno=10
```

## Short description

Managed task did not confirm forced termination.

## Trigger condition

After a termination request and then forced termination, no qualifying process state is returned within the final two-second wait. Available only on Linux builds.

## Explanation

The task is nevertheless marked as being stopped and the stop helper returns success. This message does not prove the process is still running.

## Possible causes

- No matching exit, stopped or signaled result was obtained during the final wait.

## What to check

1. Check the reported process and process-wait error.
