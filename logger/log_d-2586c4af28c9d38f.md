# Trying the next origin

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-2586c4af28c9d38f

## Log pattern

```text
switching to another origin i=%u origins_count=%u
```

## Parameters

- Argument 1 — Origin attempt index: Unsigned zero-based index of the next origin attempt; incremented after failure.
- Argument 2 — Origin count: Unsigned total number of candidate origins.

## Log examples

Illustrative examples; these are not captured server logs.

```text
switching to another origin i=1 origins_count=2
```

## Short description

Trying the next origin.

## Trigger condition

An origin connection failure leaves another origin available in the configured route.

## Explanation

The failed origin is closed, the cache reservation is released, and routing switches to the next origin.

## Possible causes

- An origin connection failure leaves another origin available in the configured route.

## What to check

1. Check the failed origin and the outcome of the next connection attempt.

## Recommended action

Check the failed origin and the outcome of the next connection attempt.
