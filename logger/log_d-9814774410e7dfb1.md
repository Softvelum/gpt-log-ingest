# Local process connection accepted

Product: Nimble Streamer
Component: Local process connections
Logging function: log_d
Log level: debug
Documentation ID: log_d-9814774410e7dfb1

## Log pattern

```text
accepted sock=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.

The contexts are a generic process worker, AJA input/output, local device discovery, local device output and the scenario transcoder manager.

## Log examples

Illustrative examples; these are not captured server logs.

```text
accepted sock=12
```

## Short description

Local process connection accepted.

## Trigger condition

A listening endpoint accepts a new local process connection. Shared process sessions log after attachment to event monitoring; AJA endpoints log after accepting their helper socket; the scenario manager logs before registering the new socket for its initial message.

## Explanation

The accepted descriptor identifies the connection used for subsequent helper or scenario communication. Further initialization or registration may still fail.
