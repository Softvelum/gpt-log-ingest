# Scheduled SCTE-35 marker failed during live playback

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-cb381c56d21b7f81

## Log pattern

```text
ServerBlockProcessor: inject scte35 marker failed for livestream [%s], stream=[%s/%s]
```

## Parameters

- Argument 1 — Live source: Text naming the source application and stream.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: inject scte35 marker failed for livestream [input/camera], stream=[live/camera]
```

## Short description

Scheduled SCTE-35 marker failed during live playback.

## Trigger condition

A due wall-clock marker cannot be submitted while processing live input.

## Explanation

Live media processing continues and the marker remains pending.

## Possible causes

- A due wall-clock marker cannot be submitted while processing live input.

## What to check

1. Check that the output stream accepts SCTE-35 injection and inspect preceding injection errors.

## Recommended action

Check that the output stream accepts SCTE-35 injection and inspect preceding injection errors.
