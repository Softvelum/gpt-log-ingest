# Shared FFmpeg CUDA device reference is being released

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-63789fda048f3568

## Log pattern

```text
destroyed shared hw device ctx=%p, gpu=%s
```

## Parameters

- Argument 1 — Hardware context: FFmpeg hardware device reference address, pointer printed in hexadecimal.
- Argument 2 — GPU: CUDA device index passed to FFmpeg as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
destroyed shared hw device ctx=0x12340000, gpu=0
```

## Short description

Shared FFmpeg CUDA device reference is being released.

## Trigger condition

Manager release visits a cached FFmpeg CUDA device reference.

## Explanation

The cache reference is released and the GPU entry removed; remaining external references can keep the device alive.
