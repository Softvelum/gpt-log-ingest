# Cache update arrived in an unsupported phase

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-67d805b427e7d4c7

## Log pattern

```text
OnCacheItemUpdated invalid session state=%d key='%s' st=%u cap=%lu sz=%lu
```

## Parameters

- Argument 1 — Session state: Integer identifying the HTTP client session phase: 0 reading a request, 1 sending a response, 2 connecting to origin, 3 sending to origin, 4 reading origin headers, 5 reading an origin playlist, 6 reading origin media, 29 shutting down, or 30 finished; intermediate values identify pending asynchronous work.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 3 — Cache state: Integer cache state: 0 newly reserved, 1 receiving data, 2 fragmented, 3 ready, or 4 marked for removal.
- Argument 4 — Capacity bytes: Unsigned 64-bit allocated or logical cache capacity in bytes.
- Argument 5 — Stored bytes: Unsigned 64-bit amount of cached data in bytes.

Capacity and size are unsigned 64-bit byte counts printed with %lu; the output assumes unsigned long is 64 bits.

## Log examples

Illustrative examples; these are not captured server logs.

```text
OnCacheItemUpdated invalid session state=4 key='/live/camera/segment1.ts' st=1 cap=65536 sz=32768
```

## Short description

Cache update arrived in an unsupported phase.

## Trigger condition

An observed, non-canceled cache item update reaches a session phase with no corresponding cache-update handler.

## Explanation

An HTTP 500 response is prepared.

## Possible causes

- An observed, non-canceled cache item update reaches a session phase with no corresponding cache-update handler.

## What to check

1. Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.

## Recommended action

Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.
