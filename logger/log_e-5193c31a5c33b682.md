# LATM differing stream framing unsupported

Product: Nimble Streamer
Component: AAC LATM parsing
Logging function: log_e
Log level: error
Documentation ID: log_e-5193c31a5c33b682

## Log pattern

```text
unsupported allStreamsSameTimeFraming=%d
```

## Parameters

- Argument 1 — Flag: The rejected framing flag, zero on this branch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported allStreamsSameTimeFraming=0
```

## Short description

LATM differing stream framing unsupported.

## Trigger condition

The LATM all-streams-same-time-framing flag is zero.

## Explanation

Stream configuration parsing fails because uniform time framing is required.

## Possible causes

- The LATM all-streams-same-time-framing flag is zero.

## What to check

1. Check the LATM framing flag.

## Recommended action

Use LATM with uniform time framing.
