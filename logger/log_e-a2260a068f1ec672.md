# Cache notification without an observed item

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a2260a068f1ec672

## Log pattern

```text
ClientSession(%p) no cache items observed (key='%s')
```

## Parameters

- Argument 1 — Session address: Pointer identifying this client session within the process.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ClientSession(0x1234) no cache items observed (key='/live/camera/segment1.ts')
```

## Short description

Cache notification without an observed item.

## Trigger condition

A cache update arrives outside the multi-item wait phase while no single cache item is held.

## Explanation

The unexpected notification is logged and ignored.

## Possible causes

- A cache update arrives outside the multi-item wait phase while no single cache item is held.

## What to check

1. Check the request cleanup and cache-observer lifecycle if this repeats; no item is available to handle the notification.

## Recommended action

Check the request cleanup and cache-observer lifecycle if this repeats; no item is available to handle the notification.
