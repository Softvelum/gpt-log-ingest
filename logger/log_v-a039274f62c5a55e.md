# Playback session registered

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_v
Log level: verbose
Documentation ID: log_v-a039274f62c5a55e

## Log pattern

```text
registered session=%lu type=%d client='%s' host='%s' url='%s'
```

## Parameters

- Argument 1 — session: Numeric playback session identifier.
- Argument 2 — type: Numeric playback protocol.
- Argument 3 — client: Client IP address.
- Argument 4 — host: Reported request host, with its port removed if that option is enabled.
- Argument 5 — URL: Requested resource URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
registered session=42 type=1 client='192.0.2.10' host='media.example' url='/live/camera/playlist.m3u8'
```

## Short description

Playback session registered.

## Trigger condition

A new nonshared session is inserted and associated with the client IP.

## Explanation

RTMP, RTSP, SLDP, SRT, and WHEP sessions become active immediately; other protocols initially enter the inactive list until traffic activates them.
