# Invalid transcription settings JSON

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-57379554c0d1854d

## Log pattern

```text
failed to parse transcriber config '%s'
```

## Parameters

- Argument 1 — Settings source: Configuration file path or WMSPanel for settings supplied by the control panel.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse transcriber config 'WMSPanel'
```

## Short description

Invalid transcription settings JSON.

## Trigger condition

Transcription settings cannot be parsed as a JSON object.

## Explanation

That settings source fails to load. Depending on the caller, another settings source may still be used; WMSPanel settings can override file settings.

## Possible causes

- Transcription settings cannot be parsed as a JSON object.

## What to check

1. Check the indicated settings source for valid JSON with an object at its root.

## Recommended action

Correct the JSON settings.
