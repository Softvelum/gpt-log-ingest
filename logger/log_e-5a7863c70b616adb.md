# AJA capture frame-buffer format is unsupported

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-5a7863c70b616adb

## Log pattern

```text
Device '%s' doesn't support UYVY422
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device 'AJA device' doesn't support UYVY422
```

## Short description

AJA capture frame-buffer format is unsupported.

## Trigger condition

The device does not support the requested capture frame-buffer pixel format.

## Explanation

Format checking returns failure. The message names UYVY422 because this capture path uses that format.

## Possible causes

- The device does not support the requested capture frame-buffer pixel format.

## What to check

1. Check device support for UYVY422 capture.

## Recommended action

Use a device supporting the requested capture format.
