# DVR HLS chunk name was decoded

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-b0c39c4ef1943a83

## Log pattern

```text
DvrArchive::GetDvrSegmentsForHlsChunk chunk_name='%s' p=%llu st=%llu
```

## Parameters

- Argument 1 — Chunk name: Text naming the requested HLS chunk.
- Argument 2 — Requested period: Unsigned 64-bit parsed recording period.
- Argument 3 — Media start: 64-bit media start timestamp in the segment track timescale.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DvrArchive::GetDvrSegmentsForHlsChunk chunk_name='dvr_v_p1_90000.ts' p=1 st=90000
```

## Short description

DVR HLS chunk name was decoded.

## Trigger condition

A requested HLS chunk matches the recorded-chunk naming pattern.

## Explanation

The period and start timestamp are extracted before looking up media and associated audio or metadata.

## Possible causes

- A requested HLS chunk matches the recorded-chunk naming pattern.
