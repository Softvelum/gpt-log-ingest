# Selected VCAS key has a failed request

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-fd2b78769e0264de

## Log pattern

```text
last key request pos=%d for '%s' has failed
```

## Parameters

- Argument 1 — Key position: Integer index of the selected key in the rotating key set.
- Argument 2 — Application: Text naming the application owning the key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
last key request pos=0 for 'live' has failed
```

## Short description

Selected VCAS key has a failed request.

## Trigger condition

The selected HLS key slot is marked failed by its latest key request.

## Explanation

The HLS operation fails unless fallback to the configured default key is permitted; with fallback permitted, default-key selection is attempted.

## Possible causes

- The selected HLS key slot is marked failed by its latest key request.

## What to check

1. Check the latest VCAS response or transport failure and restore key-server access.

## Recommended action

Check the latest VCAS response or transport failure and restore key-server access.
