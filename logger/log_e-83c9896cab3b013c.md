# DVR database cannot be expanded

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-83c9896cab3b013c

## Log pattern

```text
failed to open dvr segments db file='%s'
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open dvr segments db file='/data/dvr/live/camera/nimble-dvr-segments.db'
```

## Short description

DVR database cannot be expanded.

## Trigger condition

The segment database cannot be opened for append while reserving another storage block.

## Explanation

Database expansion and the pending record write fail.

## Possible causes

- The segment database cannot be opened for append while reserving another storage block.

## What to check

1. Check database access and filesystem permissions.

## Recommended action

Check database access and filesystem permissions.
