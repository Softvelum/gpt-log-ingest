# SDI output header write failed

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-0931832536721108

## Log pattern

```text
failed to write header into [%s/%s]
```

## Parameters

- Argument 1 — Device type: FFmpeg output device type, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write header into [decklink/live/camera]
```

## Short description

SDI output header write failed.

## Trigger condition

Output initialization requests header writing, and writing the device output header returns a negative result.

## Explanation

The device output creation request returns failure.

## Possible causes

- The device output rejects or cannot write its header.

## What to check

1. Check device availability and the configured video and audio modes.

## Recommended action

Correct the device setup and retry the output.
