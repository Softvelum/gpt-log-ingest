# QUIC session capacity reached

Product: Nimble Streamer
Component: QUIC datagram listener
Logging function: log_d
Log level: debug
Documentation ID: log_d-67071a163c0f7578

## Log pattern

```text
quic sessions count limit reached
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
quic sessions count limit reached
```

## Short description

QUIC session capacity reached.

## Trigger condition

An unrecognized QUIC connection identifier arrives in a packet of at least 1,200 bytes and the total active plus pending sessions is at or above the configured HTTP/3 viewer limit multiplied by worker count.

## Explanation

The packet is ignored and no new QUIC session is queued. Packets for already recognized sessions take another path.

## Possible causes

- The aggregate configured HTTP/3 session capacity is occupied by active and pending sessions.

## What to check

1. Check HTTP/3 active/pending session load and the configured viewer and worker limits.

## Recommended action

Reduce session pressure or adjust capacity to match available resources.
