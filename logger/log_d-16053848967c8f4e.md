# Whisper child process started

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_d
Log level: debug
Documentation ID: log_d-16053848967c8f4e

## Log pattern

```text
started process '%s'
```

## Parameters

- Argument 1 — Command: Complete command line used to start the transcription process.

## Log examples

Illustrative examples; these are not captured server logs.

```text
started process '/opt/nimble/bin/nimble_transcriber --ip=127.0.0.1 --port=45000 --stream=live/news --nimble-logging=info --whisper-logging=info --lang=en'
```

## Short description

Whisper child process started.

## Trigger condition

Creating the child transcription process succeeds.

## Explanation

The process must still connect back to the media server and initialize its decoder. This path is available when Whisper support is enabled.

## Possible causes

- Creating the child transcription process succeeds.

## What to check

1. Check for the matching transcription connection message.
