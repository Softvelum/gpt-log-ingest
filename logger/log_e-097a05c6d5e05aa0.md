# External request host cannot be split

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-097a05c6d5e05aa0

## Log pattern

```text
SplitHostName failed to split host='%s'
```

## Parameters

- Argument 1 — host: Peer host text being parsed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SplitHostName failed to split host='media.example:invalid'
```

## Short description

External request host cannot be split.

## Trigger condition

The peer host cannot be separated into hostname and port.

## Explanation

Connection setup throws a fatal request exception; startup cleanup reports failure.

## Possible causes

- The hostname or port syntax is invalid.

## What to check

1. Check the authority portion of the request URL.

## Recommended action

Correct the host and port.
