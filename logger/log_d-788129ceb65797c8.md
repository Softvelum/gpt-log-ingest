# External request socket event received

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_d
Log level: debug
Documentation ID: log_d-788129ceb65797c8

## Log pattern

```text
[ReqS::PE] p=%p st=%d s=%d ev=0x%x ssl=%d in=%d
```

## Parameters

- Argument 1 — address: Request session memory address.
- Argument 2 — state: Request state: 0 unknown, 1 connecting, 2 resuming, 3 sending, 4 reading headers, 5 reading body, 6 reading chunked body.
- Argument 3 — socket: Peer socket descriptor.
- Argument 4 — events: Socket event flags in hexadecimal.
- Argument 5 — TLS: 1 for TLS, otherwise 0.
- Argument 6 — input: 1 for logical input, otherwise 0.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[ReqS::PE] p=0x1000 st=4 s=12 ev=0x1 ssl=1 in=1
```

## Short description

External request socket event received.

## Trigger condition

A worker dispatches an event to the external HTTP request session.

## Explanation

The socket identity is checked before the event updates activity time and dispatches input, output, or closure handling.
