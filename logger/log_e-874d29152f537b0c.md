# Source MPEG-TS advertising boundary chunk is invalid

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-874d29152f537b0c

## Log pattern

```text
failed to process chunk='%s'
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process chunk='/app/stream/ad_1.ts'
```

## Short description

Source MPEG-TS advertising boundary chunk is invalid.

## Trigger condition

The source chunk is too short or lacks the transport sync byte when continuity is preserved, or parsing a transport packet fails.

## Explanation

The request for the stream section before or after the advertisement is marked failed.

## Possible causes

- The source chunk is too short or lacks the transport sync byte when continuity is preserved, or parsing a transport packet fails.

## What to check

1. Check that the source chunk contains valid complete MPEG-TS packets.

## Recommended action

Check that the source chunk contains valid complete MPEG-TS packets.
