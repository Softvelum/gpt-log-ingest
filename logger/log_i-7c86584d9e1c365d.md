# Delayed multi-stream pull application changed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_i
Log level: info
Documentation ID: log_i-7c86584d9e1c365d

## Log pattern

```text
live pull task for %s/%s deleted. multi-stream pull settings changed
```

## Parameters

- Argument 1 — application: Application of the delayed pull task.
- Argument 2 — stream: Stream of the delayed pull task.

## Log examples

Illustrative examples; these are not captured server logs.

```text
live pull task for live/camera deleted. multi-stream pull settings changed
```

## Short description

Delayed multi-stream pull application changed.

## Trigger condition

The current multi-stream pull settings name a different application from the existing task.

## Explanation

The old task is removed and recreation is attempted against current matching settings.
