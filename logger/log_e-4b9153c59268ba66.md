# DRM identifier group is misplaced

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-4b9153c59268ba66

## Log pattern

```text
unexpected line at %s:%u '%s'
```

## Parameters

- Argument 1 — Settings file: Text naming the DRM settings file.
- Argument 2 — Settings line: Unsigned line number within the settings file.
- Argument 3 — Setting text: Text containing the rejected settings line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unexpected line at /etc/nimble/drm.conf:12 'unsupported=value'
```

## Short description

DRM identifier group is misplaced.

## Trigger condition

A content or resource identifier group begins outside a DRM group or while another such group is open.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- A content or resource identifier group begins outside a DRM group or while another such group is open.

## What to check

1. Place identifier mappings inside one correctly delimited DRM group.

## Recommended action

Place identifier mappings inside one correctly delimited DRM group.
