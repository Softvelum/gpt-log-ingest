# Quick Sync packet memory allocation failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-e2c92c8333ea16f4

## Log pattern

```text
%p failed to alloc packet buffer
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

Storage uses at least one packet slot and the runtime buffer-size multiplier, with kilobytes converted using 1000 bytes. This message covers the explicit null check.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to alloc packet buffer
```

## Short description

Quick Sync packet memory allocation failed.

## Trigger condition

Allocating the contiguous encoded-packet buffer returns a null pointer.

## Explanation

Encoder initialization fails before packet slots are assigned storage.

## Possible causes

- The packet buffer cannot be allocated for the runtime buffer size and asynchronous depth.

## What to check

1. Check available memory, asynchronous depth, and the runtime-reported packet buffer size.

## Recommended action

Restore memory availability or lower encoding buffer demand and restart encoding.
