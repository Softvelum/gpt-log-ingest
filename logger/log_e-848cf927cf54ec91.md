# DRM wait queue has reached its request limit

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-848cf927cf54ec91

## Log pattern

```text
dropped VOD transmuxer request for key='%s' as queue size limit=%u reached
```

## Parameters

- Argument 1 — Output cache key: Text cache key reserved for the requested generated output.
- Argument 2 — Queue limit: Unsigned-formatted maximum number of postponed DRM requests, fixed at 2000.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dropped VOD transmuxer request for key='/vod/movie.mp4/n_0_0_0.ts' as queue size limit=2000 reached
```

## Short description

DRM wait queue has reached its request limit.

## Trigger condition

A VOD playlist or media request needs CENC keys, but the number of postponed DRM requests has already reached 2000.

## Explanation

The new output item is canceled and released; this request is not added to the wait queue.

## Possible causes

- A VOD playlist or media request needs CENC keys, but the number of postponed DRM requests has already reached 2000.

## What to check

1. Check DRM key-server responsiveness and repeated pending key requests; requests cannot wait once the worker queue limit is reached.

## Recommended action

Check DRM key-server responsiveness and repeated pending key requests; requests cannot wait once the worker queue limit is reached.
