# Advancing to the next cached fragment

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-c4ff82110a83e997

## Log pattern

```text
key='%s' fr=%u rem=%llu
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Fragment index: Unsigned zero-based cache fragment index.
- Argument 3 — Remaining response bytes: Unsigned 64-bit response bytes still to send after the prior fragment.

## Log examples

Illustrative examples; these are not captured server logs.

```text
key='/live/camera/segment1.ts' fr=1 rem=1048576
```

## Short description

Advancing to the next cached fragment.

## Trigger condition

The response releases the fragment just sent and selects the next fragment index.

## Explanation

The next fragment is checked for failure or availability before further output.

## Possible causes

- The response releases the fragment just sent and selects the next fragment index.
