# SDI input receiver creation failed

Product: Nimble Streamer
Component: SDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-10c950877f303a2a

## Log pattern

```text
failed to create sdi receiver for [%s]
```

## Parameters

- Argument 1 — Device stream: Configured SDI device or stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create sdi receiver for [SDI input]
```

## Short description

SDI input receiver creation failed.

## Trigger condition

The input has no receiver and creating one fails; the diagnostic is emitted only after its five-second reporting interval has elapsed.

## Explanation

A no-frame message is sent to the parent process, allowing later calls to retry receiver creation if that delivery succeeds.

## Possible causes

- The input has no receiver and creating one fails; the diagnostic is emitted only after its five-second reporting interval has elapsed.

## What to check

1. Check the selected SDI device and preceding device-opening errors.
