# Selected configuration file

Product: Nimble Streamer
Component: Server startup
Logging function: log_i
Log level: info
Documentation ID: log_i-4982976f28431d79

## Log pattern

```text
Using config file: %s
```

## Parameters

- Argument 1 — File name: Text containing the selected configuration file name or path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Using config file: /etc/nimble/nimble.conf
```

## Short description

Selected configuration file.

## Trigger condition

Configuration loading and the startup registration check have succeeded.

## Explanation

Reports the selected configuration file name before background mode and server execution begin. This message alone does not establish that every configured service will initialize successfully.

## What to check

1. Confirm that the selected configuration file is the intended one.
