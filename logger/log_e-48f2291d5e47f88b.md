# Server playlist synchronization interval is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-48f2291d5e47f88b

## Log pattern

```text
invalid parameter value: %s. should be >= 1000 && <=3600000
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1000 && <=3600000
```

## Short description

Server playlist synchronization interval is invalid.

## Trigger condition

While reading configuration, the server-playlist synchronization interval is outside 1000 through 3600000 milliseconds.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 1000 through 3600000 milliseconds.

## Recommended action

Correct the value to 1000 through 3600000 milliseconds and reload configuration.
