# Stored cache metadata is invalid

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-1325c3eb7725630b

## Log pattern

```text
invalid metadata in cache item metadata file='%s'
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid metadata in cache item metadata file='/var/cache/nimble/movie.meta'
```

## Short description

Stored cache metadata is invalid.

## Trigger condition

Loading a saved item finds malformed or unrecognized metadata.

## Explanation

The data and metadata files are scheduled for deletion through cache cleanup and the item is not loaded.

## Possible causes

- Saved metadata fails the parser or required field validation.

## What to check

1. Check whether cached files were changed or incompletely written.

## Recommended action

Investigate damaged cache storage; the rejected item must be cached again.
