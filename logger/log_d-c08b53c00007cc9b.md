# Origin input resumed after client output

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-c08b53c00007cc9b

## Log pattern

```text
%d bytes freed to receive data from origin s=%d, restoring kEventIn
```

## Parameters

- Argument 1 — Freed bytes: Native-size signed bytes written to the client, incorrectly printed with %d.
- Argument 2 — Origin socket: Integer identifying the local origin socket.

The freed-byte count is a native-size signed write result passed to %d, making its printed value unreliable on 64-bit builds.

## Log examples

The freed-byte count is a native-size signed write result passed to %d, making its printed value unreliable on 64-bit builds.

## Short description

Origin input resumed after client output.

## Trigger condition

A positive client write frees response-buffer space while origin input monitoring is disabled and the origin socket still exists.

## Explanation

The origin is enabled for input again to resume receiving the body.

## Possible causes

- A positive client write frees response-buffer space while origin input monitoring is disabled and the origin socket still exists.
