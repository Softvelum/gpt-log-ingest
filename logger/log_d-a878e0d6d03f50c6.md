# HTTP/2 socket event received

Product: Nimble Streamer
Component: HTTP/2 connection
Logging function: log_d
Log level: debug
Documentation ID: log_d-a878e0d6d03f50c6

## Log pattern

```text
[H2C::PE] p=%p st=%d s=%d ev=0x%x
```

## Parameters

- Argument 1 — Connection identity: In-process connection object address, pointer displayed in hexadecimal; useful only for correlating this process lifetime.
- Argument 2 — Connection state: Connection state code, integer: 0 awaiting preface, 1 awaiting settings, 2 sending settings/acknowledgment, 3 main processing, 4 sending GOAWAY, 5 shutting down, 6 stopped.
- Argument 3 — Socket: Socket descriptor, integer; no unit.
- Argument 4 — Event mask: Socket readiness and error bitmask, integer displayed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[H2C::PE] p=0x12340000 st=3 s=12 ev=0x1
```

## Short description

HTTP/2 socket event received.

## Trigger condition

An HTTP/2 connection receives any event mask other than exactly output-ready.

## Explanation

The activity time is updated and processing follows the current connection state and input/output/error flags. Output-only events are intentionally omitted from this diagnostic.
