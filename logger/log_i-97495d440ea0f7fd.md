# Bus-signal recovery records request objects

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_i
Log level: info
Documentation ID: log_i-97495d440ea0f7fd

## Log pattern

```text
file_name_is_cache_key=%d f=0x%x file_mapper_=0x%x r=0x%x
```

## Parameters

- Argument 1 — Source is cached: Integer flag: 1 for a source cache item and 0 for a local file.
- Argument 2 — Media object address: Pointer to the prepared media object, incorrectly printed with %x.
- Argument 3 — File mapper address: Pointer to the file-mapping service, incorrectly printed with %x.
- Argument 4 — Request address: Pointer to the active packaging request, incorrectly printed with %x.

The three object addresses are pointers passed to %x conversions, so their values can be truncated or otherwise unreliable.

## Log examples

## Short description

Bus-signal recovery records request objects.

## Trigger condition

General media processing has returned from the bus-signal handler and is preparing to clean up its input and output.

## Explanation

The source-kind flag and object identities are logged before local mapping removal and cache-output cancellation.

## Possible causes

- General media processing has returned from the bus-signal handler and is preparing to clean up its input and output.

## What to check

1. Use the surrounding source path and cache-key messages to identify the failed request; the address fields are not trustworthy.
