# AJA capture input selection failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-11855c615785c315

## Log pattern

```text
init failed device=%s/%d reason='invalid input source or channel'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
init failed device=0/0 reason='invalid input source or channel'
```

## Short description

AJA capture input selection failed.

## Trigger condition

Receiver initialization fails because input-source/channel adjustment fails.

## Explanation

Capture video setup is not attempted.

## Possible causes

- Receiver initialization fails because input-source/channel adjustment fails.

## What to check

1. Check the preceding device or capture input selection error details.
