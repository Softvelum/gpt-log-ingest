# Origin restreaming cache lookup prepared

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-8e38d64e68860612

## Log pattern

```text
[CliS::POR] r='%s%s' st=%d cu='%s'
```

## Parameters

- Argument 1 — Origin host: Text containing the origin hostname and optional port.
- Argument 2 — Origin URL: Text giving the origin request path and query string.
- Argument 3 — Protocol: Integer protocol value: 0 unknown, 1 HLS, 2 progressive download, 3 Smooth, 4 HDS, 5 MPEG-TS over HTTP, 6 Icecast, or 7 DASH.
- Argument 4 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[CliS::POR] r='media.example:8080/live/camera/playlist.m3u8' st=2 cu='/live/camera/segment1.ts'
```

## Short description

Origin restreaming cache lookup prepared.

## Trigger condition

An HTTP restreaming request has been translated and its cache key normalized for the protocol and playlist-cache settings.

## Explanation

The session will use an existing item, reserve a new item, or connect directly to the origin.

## Possible causes

- An HTTP restreaming request has been translated and its cache key normalized for the protocol and playlist-cache settings.
