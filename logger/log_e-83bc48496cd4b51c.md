# Recorded JPEG thumbnail creation failed

Product: Nimble Streamer
Component: JPEG thumbnails
Logging function: log_e
Log level: error
Documentation ID: log_e-83bc48496cd4b51c

## Log pattern

```text
failed to create jpg thumbnail for stream='%s/%s' init seg f=%s of=%d sz=%d video seg f=%s of=%d sz=%d
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.
- Argument 3 — Initialization file: File containing the MP4 initialization region, text.
- Argument 4 — Initialization offset: Start of the initialization region, integer bytes.
- Argument 5 — Initialization size: Length of the initialization region, integer bytes.
- Argument 6 — Video file: File containing the media region, text.
- Argument 7 — Video offset: Start of the video region, integer bytes.
- Argument 8 — Video size: Length of the video region, integer bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create jpg thumbnail for stream='live/camera' init seg f=init.mp4 of=0 sz=1024 video seg f=segment.mp4 of=1024 sz=65536
```

## Short description

Recorded JPEG thumbnail creation failed.

## Trigger condition

A thumbnail request using recorded MP4 initialization and video segments returns failure.

## Explanation

No thumbnail result is queued for this request; the worker continues with later requests.

## Possible causes

- An initialization or video segment cannot be read.
- The MP4 data cannot be parsed, uses a codec other than H.264, HEVC or AV1, fails decoding, or produces no JPEG after flushing.

## What to check

1. Check the reported file regions, their readability, matching MP4 structure and preceding decoder or MP4 parsing errors.

## Recommended action

Restore readable valid segments and supported video before retrying.
