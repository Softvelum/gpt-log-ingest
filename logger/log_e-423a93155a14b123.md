# Advertising playlist generation request failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-423a93155a14b123

## Log pattern

```text
failed to process advertising playlist request content=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process advertising playlist request content=ad-01
```

## Short description

Advertising playlist generation request failed.

## Trigger condition

A newly created advertising playlist request cannot be submitted to the advertising worker.

## Explanation

The failure path requests HTTP 500 instead of waiting for the generated playlist. This log alone does not establish that the response reached the player.

## Possible causes

- A newly created advertising playlist request cannot be submitted to the advertising worker.

## What to check

1. Check advertising worker and media-preparation errors for the named content.

## Recommended action

Check advertising worker and media-preparation errors for the named content.
