# AVC transport frame exceeds its output buffer

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-8a74e599780660a2

## Log pattern

```text
[VM] cannot write mpeg2ts body for [%s/%s], used_size=%u, frame_size=%u (%u < %u)
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Used size: Bytes already used in the affected output buffer.
- Argument 4 — Frame size: Media payload size in bytes, including any prepared transport header.
- Argument 5 — Buffer capacity: Actual transport writer buffer capacity in bytes.
- Argument 6 — Required capacity: Byte capacity required by the failed write.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] cannot write mpeg2ts body for [live/camera], used_size=1048576, frame_size=65536 (1048576 < 1048764)
```

## Short description

AVC transport frame exceeds its output buffer.

## Trigger condition

The transport packet writer reports insufficient output capacity while packaging the frame. This covers AVC in HLS and MPEG-TS over HTTP.

## Explanation

The current video-processing call fails. Other enabled outputs may already have received this frame before this transport-packaging failure.

## Possible causes

- The transport packet writer reports insufficient output capacity while packaging the frame. This covers AVC in HLS and MPEG-TS over HTTP.

## What to check

1. Compare current buffer use and complete frame size with memory availability and buffer limits.

## Recommended action

Resolve oversized input frames or the output-buffer capacity problem.
