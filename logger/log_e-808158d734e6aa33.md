# SRT bonding node absent from connected set

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-808158d734e6aa33

## Log pattern

```text
group node %s:%d disconnected
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
group node 192.0.2.10:9000 disconnected
```

## Short description

SRT bonding node absent from connected set.

## Trigger condition

During a periodic group check, a configured node has no member in connected or connecting state.

## Explanation

A reconnection attempt is immediately made for that node. Checks are limited to about once every five seconds.

## Possible causes

- During a periodic group check, a configured node has no member in connected or connecting state.

## What to check

1. Check the affected path and subsequent reconnect result.
