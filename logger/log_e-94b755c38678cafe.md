# Exception while applying panel response

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-94b755c38678cafe

## Log pattern

```text
exception e.what()='%s' caught while processing sync response='%s'
```

## Parameters

- Argument 1 — exception\_text: Text supplied by the caught standard exception.
- Argument 2 — response\_body: Complete panel response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
exception e.what()='invalid value' caught while processing sync response='{"SyncResponse":{"status":"success"}}'
```

## Short description

Exception while applying panel response.

## Trigger condition

A standard exception escapes synchronization-response processing or its associated success bookkeeping.

## Explanation

The exception and complete response are logged. Execution continues with statistics recovery, requested uploads, and the normal delay; the catch does not restore settings already applied before the exception.

## Possible causes

- Response processing or its success bookkeeping raised a standard exception.

## What to check

1. Check the exception text and response fields.

## Recommended action

Correct the indicated response or settings problem.
