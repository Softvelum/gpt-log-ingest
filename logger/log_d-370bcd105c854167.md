# Stream-check read would block

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-370bcd105c854167

## Log pattern

```text
recv error=%d (EAGAIN | EWOULDBLOCK) on s=%d
```

## Parameters

- Argument 1 — error: Operating system error number.
- Argument 2 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
recv error=11 (EAGAIN | EWOULDBLOCK) on s=12
```

## Short description

Stream-check read would block.

## Trigger condition

A plain nonblocking receive returns the temporary would-block error.

## Explanation

The message identifies unavailable input, but this implementation continues into response handling and adds the negative receive result to its byte count rather than returning immediately.
