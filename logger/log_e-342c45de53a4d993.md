# DVR audio entry is missing from its secondary index

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-342c45de53a4d993

## Log pattern

```text
segment file='%s' is not found in audio segments list
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
segment file='/data/dvr/live/camera/1700000000000.dat' is not found in audio segments list
```

## Short description

DVR audio entry is missing from its secondary index.

## Trigger condition

An audio segment in the combined timeline has no matching audio-index entry.

## Explanation

Its storage reference is removed and it is erased from the combined timeline.

## Possible causes

- An audio segment in the combined timeline has no matching audio-index entry.

## What to check

1. Check duplicate timestamps and archive index consistency.

## Recommended action

Check duplicate timestamps and archive index consistency.
