# Requested AJA device was not found

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-62a56fcbc8821506

## Log pattern

```text
Device '%s' not found
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device '0' not found
```

## Short description

Requested AJA device was not found.

## Trigger condition

The device scanner cannot open a device matching the configured selector.

## Explanation

Card initialization stops before checking readiness or acquiring the streaming session.

## Possible causes

- The device scanner cannot open a device matching the configured selector.

## What to check

1. Check that the configured device selector identifies an available AJA card.

## Recommended action

Select an available AJA device.
