# AAC audio object type rejected

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-8f22e374557be53c

## Log pattern

```text
icecast stream aac object type unknown %s %d
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.
- Argument 2 — Object type: AAC audio object type derived from the ADTS profile.

## Log examples

No reachable example is established: the current profile extraction only yields accepted values one through four.

## Short description

AAC audio object type rejected.

## Trigger condition

The AAC object type extracted from the ADTS profile would fall outside the accepted object-type cases.

## Explanation

The branch shuts down the session, but the current two-bit ADTS extraction always produces values one through four, all of which are accepted.

## Possible causes

- The AAC object type extracted from the ADTS profile would fall outside the accepted object-type cases.
