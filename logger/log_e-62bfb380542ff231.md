# Could not create the DVB subtitle decoder worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error

## Log examples

## Short description

Could not create the DVB subtitle decoder worker.

## Trigger condition

The DVB subtitle decoder worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the DVB subtitle decoder worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed DVB subtitle decoder worker.
