# Advertising session rules refresh requested

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-5840b4d2d0f90ae2

## Log pattern

```text
request session rules update for app=%s stream=%s session=%lld protocol=%s stream_time=%lld
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Session ID: Signed 64-bit viewer session identifier.
- Argument 4 — Protocol: Text naming hls, icecast, rtmp, sldp, or unknown.
- Argument 5 — Stream time: Playback position in seconds; initial requests may use zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
request session rules update for app=live stream=camera session=12345 protocol=hls stream_time=0
```

## Short description

Advertising session rules refresh requested.

## Trigger condition

A ready session has a positive refresh interval and its playback time crosses into another interval.

## Explanation

A refresh is queued while the current request continues using the existing rules.

## Possible causes

- A ready session has a positive refresh interval and its playback time crosses into another interval.
