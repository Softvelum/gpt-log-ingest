# Sigma DRM merchant identifier is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-ea10146c307a96a3

## Log pattern

```text
Merchant ID must be provided for Sigma DRM (sigma_drm_merchant_id)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Merchant ID must be provided for Sigma DRM (sigma_drm_merchant_id)
```

## Short description

Sigma DRM merchant identifier is missing.

## Trigger condition

The Sigma DRM merchant identifier is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The Sigma DRM merchant identifier is empty.

## What to check

1. Provide the Sigma DRM merchant identifier.

## Recommended action

Provide the Sigma DRM merchant identifier.
