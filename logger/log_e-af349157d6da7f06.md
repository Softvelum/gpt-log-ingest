# SRT multipoint session startup failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-af349157d6da7f06

## Log pattern

```text
failed to start srt session s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start srt session s=101
```

## Short description

SRT multipoint session startup failed.

## Trigger condition

An accepted sender fails stream/session initialization in its assigned worker.

## Explanation

The sender is not installed in that worker session set or socket map.

## Possible causes

- An accepted sender fails stream/session initialization in its assigned worker.

## What to check

1. Inspect preceding stream-ID, reporting, or event-registration diagnostics.
