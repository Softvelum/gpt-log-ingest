# Quick Sync resolved incompatible encoder parameters

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_i
Log level: info
Documentation ID: log_i-4e3764ac7c65f89f

## Log pattern

```text
%p some video params were incompatible with others, incompatibility resolved
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 some video params were incompatible with others, incompatibility resolved
```

## Short description

Quick Sync resolved incompatible encoder parameters.

## Trigger condition

Encoder initialization returns the incompatible-video-parameters warning.

## Explanation

The warning is accepted and output configuration preparation continues with the runtime-adjusted parameters.
