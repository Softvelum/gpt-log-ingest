# Compressed audio forwarding fell behind

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-1e1c76354a41a9b6

## Log pattern

```text
failed to read audio in appropriate rate [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read audio in appropriate rate [live/camera]
```

## Short description

Compressed audio forwarding fell behind.

## Trigger condition

Reading the next live audio item reports that its requested position has expired because the reader is too slow.

## Explanation

The read index is reset and forwarding attempts to resume from the first available decodable item.

## Possible causes

- The output worker cannot keep pace with retained input audio.

## What to check

1. Check output processing capacity and host load.

## Recommended action

Remove the processing bottleneck; the worker already attempts to catch up.
