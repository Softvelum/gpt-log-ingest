# SRT output connection accepted

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_d
Log level: debug
Documentation ID: log_d-347471ed18d0d833

## Log pattern

```text
srt connection accepted s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt connection accepted s=101
```

## Short description

SRT output connection accepted.

## Trigger condition

The SRT library returns a valid socket for a receiver connecting to an output listener.

## Explanation

Stream selection, authorization/reporting, and event registration may still follow, so acceptance does not prove media delivery has started.

## Possible causes

- The SRT library returns a valid socket for a receiver connecting to an output listener.

## What to check

1. Check subsequent stream selection or session setup messages.
