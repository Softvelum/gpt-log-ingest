# Playlist task file cannot be read

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-c2f883f750d9c33a

## Log pattern

```text
Failed to load server playlists. url=[%s]
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Failed to load server playlists. url=[https://api.example/playlist]
```

## Short description

Playlist task file cannot be read.

## Trigger condition

A local synchronization file exists but loading its content fails.

## Explanation

Synchronization returns failure without replacing the response.

## Possible causes

- A local synchronization file exists but loading its content fails.

## What to check

1. Restore read access to the playlist task file.

## Recommended action

Restore read access to the playlist task file.
