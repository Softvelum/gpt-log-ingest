# SMIL document could not be read as XML

Product: Nimble Streamer
Component: SMIL media playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-69b5da1151546e11

## Log pattern

```text
cannot open SMIL file='%s' or file is invalid
```

## Parameters

- Argument 1 — SMIL filename: Text filename passed to the XML reader. It is a local SMIL path or the local cache-fragment filename for a downloaded SMIL document.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot open SMIL file='/media/movie.smil' or file is invalid
```

## Short description

SMIL document could not be read as XML.

## Trigger condition

The XML file reader returns no document while preparing HLS or DASH output from the named SMIL file.

## Explanation

HLS playlist generation, including fragmented-MP4 HLS, returns failure and the HTTP caller prepares HTTP 500. DASH input discovery returns an empty item list, so its HTTP caller prepares HTTP 404. No requested playlist or manifest is generated from this document.

## Possible causes

- The XML file reader returns no document while preparing HLS or DASH output from the named SMIL file.

## What to check

1. Check that the named file exists, is readable, and contains well-formed XML. This message does not distinguish a file-access failure from XML parsing failure; detailed parser warnings are suppressed here.

## Recommended action

Check that the named file exists, is readable, and contains well-formed XML. This message does not distinguish a file-access failure from XML parsing failure; detailed parser warnings are suppressed here.
