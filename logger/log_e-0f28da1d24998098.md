# NVIDIA input pixel aspect ratio changed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-0f28da1d24998098

## Log pattern

```text
failed to change sar from %d/%d to %d/%d on the fly
```

## Parameters

- Argument 1 — Old numerator: Old numerator, integer ratio component; no unit.
- Argument 2 — Old denominator: Old denominator, integer ratio component; no unit.
- Argument 3 — New numerator: New numerator, integer ratio component; no unit.
- Argument 4 — New denominator: New denominator, integer ratio component; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to change sar from 1/1 to 4/3 on the fly
```

## Short description

NVIDIA input pixel aspect ratio changed.

## Trigger condition

Preserving input sample aspect ratio is enabled, and a later frame has a ratio unequal to the initial ratio.

## Explanation

The frame write returns failure instead of reconfiguring display aspect ratio.

## Possible causes

- The source or filter changes pixel aspect ratio during encoding.

## What to check

1. Compare the reported ratios and source/filter aspect-ratio settings.

## Recommended action

Keep pixel aspect ratio stable or restart encoding for the new ratio.
