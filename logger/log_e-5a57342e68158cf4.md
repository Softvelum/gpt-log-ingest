# Common-encryption initialization has no key set

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-5a57342e68158cf4

## Log pattern

```text
[drm] Widevine key for '%s/%s' is not available
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine key for 'live/camera' is not available
```

## Short description

Common-encryption initialization has no key set.

## Trigger condition

Initialization parameters are requested for a protected stream whose key set is absent or empty.

## Explanation

Initialization reports failure. The message says Widevine but also applies to other common-encryption providers.

## Possible causes

- Initialization parameters are requested for a protected stream whose key set is absent or empty.

## What to check

1. Check stream key registration and provider request failures.

## Recommended action

Check stream key registration and provider request failures.
