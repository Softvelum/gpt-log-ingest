# Complete client HTTP request received

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-78ade97664a69a98

## Log pattern

```text
cli s=%d req (%dB):
%.*s
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Request bytes: Integer number of buffered request bytes.
- Argument 3 — Text byte limit: Integer precision limiting the request text; equal to the request byte count.
- Argument 4 — Request text: Raw buffered HTTP request text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cli s=18 req (43B):
GET /live/camera/playlist.m3u8 HTTP/1.0


```

## Short description

Complete client HTTP request received.

## Trigger condition

A parsed complete HTTP request enters request dispatch.

## Explanation

The raw buffered request is logged before method, routing, and authorization handling.

## Possible causes

- A parsed complete HTTP request enters request dispatch.
