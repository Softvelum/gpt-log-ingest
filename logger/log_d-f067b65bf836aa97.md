# SRT library loading failed

Product: Nimble Streamer
Component: SRT transport
Logging function: log_d
Log level: debug
Documentation ID: log_d-f067b65bf836aa97

## Log pattern

```text
LoadSrtLibraries exception what()='%s'
```

## Parameters

- Argument 1 — Error: Dynamic-library loading exception description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
LoadSrtLibraries exception what()='SRT library unavailable'
```

## Short description

SRT library loading failed.

## Trigger condition

Loading the SRT library or resolving a required entry point throws an exception.

## Explanation

The partial library handle is closed and SRT initialization returns failure. This diagnostic is available in builds with SRT support.

## Possible causes

- Loading the SRT library or resolving a required entry point throws an exception.

## What to check

1. Inspect the exception text for the unavailable library or entry point.
