# RTMP or Icecast output buffer cannot be sent

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-bd5587b464809b89

## Log pattern

```text
failed to send buffer to client: %d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer to client: 42
```

## Short description

RTMP or Icecast output buffer cannot be sent.

## Trigger condition

An Icecast request or response send fails, a plain RTMP response send fails, or continuation of an RTMP media-buffer send fails.

## Explanation

The connection output fails and the connection is shut down through its caller. The media continuation case can involve either plain transport or TLS.

## Possible causes

- An Icecast request or response send fails, a plain RTMP response send fails, or continuation of an RTMP media-buffer send fails.

## What to check

1. Check earlier transport errors and whether the receiving peer closed or stopped accepting data.

## Recommended action

Resolve the transport failure before reconnecting.
