# VAAPI surface status query failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-39e0f6b5e548469f

## Log pattern

```text
%p failed to get surface status, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to get surface status, 0x1
```

## Short description

VAAPI surface status query failed.

## Trigger condition

The VA surface-status query returns a non-success status.

## Explanation

The input frame is not copied or submitted for encoding.

## Possible causes

- The VA driver cannot query the input surface.

## What to check

1. Check the VA status, preceding device errors, and whether the encoder context remains usable.

## Recommended action

Resolve the VA driver or device failure and restart the affected encoder.
