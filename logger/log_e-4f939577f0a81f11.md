# HLS AES-128 segment decryption failed

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-4f939577f0a81f11

## Log pattern

```text
failed to decrypt chunk=%s, hls camera s=%d
```

## Parameters

- Argument 1 — url: Current origin URL.
- Argument 2 — socket: Origin connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decrypt chunk=https://origin.example/segment.ts, hls camera s=42
```

## Short description

HLS AES-128 segment decryption failed.

## Trigger condition

A complete AES-128 encrypted segment is available but its decryption helper returns false.

## Explanation

The helper can fail while allocating output space or decrypting. Both chunked and fixed-length HTTP body paths request shutdown and return before passing decrypted data to media processing.

## Possible causes

- Output allocation or AES-128 decryption failed.

## What to check

1. Check encryption key and IV selection, encrypted segment integrity, and earlier allocation or crypto errors.

## Recommended action

Correct the indicated encryption or resource problem.
