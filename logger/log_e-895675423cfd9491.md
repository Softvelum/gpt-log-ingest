# NVIDIA B-direct option was not applied

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-895675423cfd9491

## Log pattern

```text
No HW support for BDirect modes, nvenc=%p
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No HW support for BDirect modes, nvenc=0x12340000
```

## Short description

NVIDIA B-direct option was not applied.

## Trigger condition

The B-direct parameter is present and the capability query succeeds, but the current preset B-direct mode value is zero.

## Explanation

The requested B-direct option is ignored and parameter setup continues. The condition checks the current mode value, so this message alone does not establish that the hardware lacks B-direct support.

## Possible causes

- The preset currently has a zero B-direct mode.

## What to check

1. Check the selected preset and whether the requested B-direct mode takes effect.

## Recommended action

Use a preset with the required mode or investigate the option handling if explicit B-direct selection is needed.
