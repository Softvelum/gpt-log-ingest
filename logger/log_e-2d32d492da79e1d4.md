## Short description

JSON parsing or required response data failed.

## Trigger condition

JSON parsing fails in one of these components. Publisher authorization also uses this text for a non-object response or a missing requested sequence result; management session deletion also uses it for a non-array body.

## Explanation

Consequences depend on the caller. Publisher authorization applies configured default decisions to all requests after a parse/shape failure, or only to missing sequence results. Management handlers attempt HTTP 500 and return without applying the requested operation. Panel settings mark the optional parse-failure flag but return permission to keep interacting. VCAS asset/key parsing returns failure; its caller does not install the requested key, and asset-response failure removes the corresponding application/stream key state.

## Possible causes

- Malformed JSON, an unexpected top-level type in the stated contexts, or missing publisher sequence results.

## What to check

1. Identify the component and check JSON syntax, required top-level type, and requested publisher sequence coverage.

## Recommended action

Correct the request or upstream response structure and required results.
