# HTTP media input received a socket-error event

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_d
Log level: debug
Documentation ID: log_d-df141a70b9929937

## Log pattern

```text
kEventError received for s=%d
```

## Parameters

- Argument 1 — socket: Origin connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
kEventError received for s=42
```

## Short description

HTTP media input received a socket-error event.

## Trigger condition

A socket-error flag is present in an HLS or MPEG-TS HTTP input event.

## Explanation

The input immediately enters its completed shutdown state and returns failure to its owner. Normal read/write processing is skipped for this event.
