# Dante port range is reversed

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-58f69efa2d122865

## Log pattern

```text
max_dante_port should be > min_dante_port
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
max_dante_port should be > min_dante_port
```

## Short description

Dante port range is reversed.

## Trigger condition

After reading configuration, the minimum Dante port is greater than the maximum.

## Explanation

Configuration loading returns failure. Equality is accepted by this check despite the wording of the message.

## Possible causes

- The configured port-range endpoints are reversed.

## What to check

1. Compare the minimum and maximum Dante ports.

## Recommended action

Set the maximum port greater than or equal to the minimum.
