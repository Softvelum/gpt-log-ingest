# SLDP requested stream is unavailable

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-530e44700e16bf5e

## Log pattern

```text
viewer tries to play invalid stream='%s' for url='%s/%s'
```

## Parameters

- Argument 1 — Requested stream: Name from the Play stream entry.
- Argument 2 — Application: Application from the playback URL.
- Argument 3 — URL stream: Stream or adaptive-stream name from the playback URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
viewer tries to play invalid stream='missing' for url='live/camera'
```

## Short description

SLDP requested stream is unavailable.

## Trigger condition

A Play stream is absent from the connection advertised-buffer map or its buffer is inactive.

## Explanation

The Play command fails and the caller closes the connection.

## Possible causes

- A Play stream is absent from the connection advertised-buffer map or its buffer is inactive.

## What to check

1. Compare the requested name with the status stream list and current live-input availability.

## Recommended action

Request an active stream advertised for this playback URL.
