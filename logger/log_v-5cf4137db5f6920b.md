# Advertising rule selected for a time interval

Product: Nimble Streamer
Component: Advertising
Logging function: log_v
Log level: verbose
Documentation ID: log_v-5cf4137db5f6920b

## Log pattern

```text
%u %u display content per rule='%s' at %d
```

## Parameters

- Argument 1 — Interval start: Stream-relative interval start in seconds.
- Argument 2 — Interval end: Stream-relative interval end in seconds.
- Argument 3 — Rule ID: Text identifying the advertising rule.
- Argument 4 — Insertion time: Scheduled insertion time in stream-relative seconds.

The time values are passed as 64-bit unsigned integers although the original format uses 32-bit integer conversions; large values may not be represented reliably.

## Log examples

No sound example is given because 64-bit time arguments are supplied to 32-bit printf conversions.

## Short description

Advertising rule selected for a time interval.

## Trigger condition

A rule start or repeat time falls within the requested stream or UTC interval.

## Explanation

Its content entries are added to the display schedule at the computed stream time.

## Possible causes

- A rule start or repeat time falls within the requested stream or UTC interval.
