# NVIDIA encoder-session destruction failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-23e9ae910344a990

## Log pattern

```text
failed to destroy nvenc session
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to destroy nvenc session
```

## Short description

NVIDIA encoder-session destruction failed.

## Trigger condition

Destroying the existing encoder session returns an error.

## Explanation

The stored session handle is cleared and CUDA-context cleanup continues.

## Possible causes

- The NVIDIA driver rejects the requested cleanup operation.

## What to check

1. Check preceding encoding failures and NVIDIA device/driver state.

## Recommended action

If cleanup failures recur, restore the device/driver state before restarting encoding.
