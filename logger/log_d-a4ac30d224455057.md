# Stored Transcoder license could not be parsed

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Stored Transcoder license could not be parsed.

## Trigger condition

Parsing the stored Transcoder license text returns no JSON value.

## Explanation

Initial license discovery keeps waiting for changed usable data. If a changed active license is being checked, it is classified invalid and transcoding is stopped by the verification loop.

## Possible causes

- The stored license is not parseable JSON.

## What to check

1. Check whether registration produced a complete valid license.

## Recommended action

Restore the license through registration.
