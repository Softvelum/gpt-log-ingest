# HTTP/2 on-demand advertising chunk request started

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_d
Log level: debug
Documentation ID: log_d-d0726ae259e16c48

## Log pattern

```text
[H2C::PVACR] id=%lu o_url='%s' a_url='%s'
```

## Parameters

- Argument 1 — Request stream identifier: HTTP request stream identifier, unsigned 64-bit integer displayed in decimal; no unit.
- Argument 2 — Origin URL: Origin resource URL after request routing, text; may include query parameters.
- Argument 3 — Aliased URL: Aliased request URL retained for this request, text; can be empty when no alias applies.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[H2C::PVACR] id=4 o_url='/live/camera/playlist.m3u8' a_url='/public/camera/playlist.m3u8'
```

## Short description

HTTP/2 on-demand advertising chunk request started.

## Trigger condition

An on-demand advertising chunk request enters its request handler.

## Explanation

Nimble extracts the chunk from the request path, consults advertising tracking data, and attempts chunk delivery using the applicable application. This message precedes validation and delivery.
