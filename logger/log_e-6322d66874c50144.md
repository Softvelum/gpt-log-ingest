# Captions could not be copied into the preservation buffer

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-6322d66874c50144

## Log pattern

```text
failed to write to subtitles buffer f='%s', stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write to subtitles buffer f='[in]null[out]', stream=live/camera
```

## Short description

Captions could not be copied into the preservation buffer.

## Trigger condition

The caption-buffer write fails after ensuring the requested capacity.

## Explanation

This output skips retaining the current caption data while video processing continues.

## Possible causes

- The bounded caption buffer rejected the write.

## What to check

1. Check caption preservation settings, accumulated caption size, and allocation diagnostics.

## Recommended action

Resolve the caption storage failure if caption preservation is required.
