# Server TLS certificate setup failed

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-14a6526896a106ab

## Log pattern

```text
failed to load SSL certificate(s)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load SSL certificate(s)
```

## Short description

Server TLS certificate setup failed.

## Trigger condition

Reloading the ordinary TLS contexts fails, or HTTP/3 is needed and its separate TLS-context reload fails.

## Explanation

Initialization exits with a failure status. The HTTP/3 occurrence is available only in a build with HTTP/3 support.

## Possible causes

- The relevant TLS context cache failed to load its certificates or contexts.

## What to check

1. Inspect preceding TLS-context and certificate errors.
