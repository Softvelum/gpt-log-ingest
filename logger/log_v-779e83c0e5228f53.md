# Short-lived cache wake time updated

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-779e83c0e5228f53

## Log pattern

```text
set short lived cache expiration_time=%lld from '%s'
```

## Parameters

- Argument 1 — expiry: Next expiration marker in seconds, or special values 0 and 1.
- Argument 2 — key: Selected cache key, or none when no item was provided.

The timestamp uses a platform-dependent time type with a signed 64-bit conversion.

## Log examples

No portable example is established for the platform-dependent timestamp representation.

## Short description

Short-lived cache wake time updated.

## Trigger condition

The cache updates the next short-lived item expiration marker.

## Explanation

A marked item produces 1 to request cleanup at the next opportunity. A ready item supplies its expiration time; no eligible item produces 0.
