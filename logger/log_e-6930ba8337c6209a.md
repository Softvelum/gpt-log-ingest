# Icecast response protocol unsupported

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-6930ba8337c6209a

## Log pattern

```text
protocol not supported for %s [%d, %d, %d]
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.
- Argument 2 — Byte 1: First response character converted to an integer.
- Argument 3 — Byte 2: Second response character converted to an integer.
- Argument 4 — Byte 3: Third response character converted to an integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
protocol not supported for http://radio.example.net/live [82, 84, 83]
```

## Short description

Icecast response protocol unsupported.

## Trigger condition

The received response starts with neither HTTP nor ICY followed by a space.

## Explanation

The pulled session is shut down before header parsing.

## Possible causes

- The received response starts with neither HTTP nor ICY followed by a space.

## What to check

1. Check that the source endpoint serves HTTP or ICY audio.

## Recommended action

Correct the source URL or response protocol.
