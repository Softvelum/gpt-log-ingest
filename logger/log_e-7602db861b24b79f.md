# Management request filled its input buffer

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-7602db861b24b79f

## Log pattern

```text
incoming buffer exhausted for s=%d (%s) size=%u max=%u
```

## Parameters

- Argument 1 — socket: Client socket descriptor.
- Argument 2 — client\_ip: Peer IP address.
- Argument 3 — used\_bytes: Bytes currently held in the input buffer.
- Argument 4 — maximum\_bytes: Maximum buffer capacity in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
incoming buffer exhausted for s=42 (192.0.2.10) size=4096 max=4096
```

## Short description

Management request filled its input buffer.

## Trigger condition

After reading input, the number of buffered bytes is at least the maximum incoming-buffer size.

## Explanation

The request is rejected before parsing at this point and connection shutdown is requested. The incoming buffer is constructed with a 4,096-byte maximum.

## Possible causes

- The incoming request filled the management connection input buffer.

## What to check

1. Check request headers and body length against the reported maximum.

## Recommended action

Reduce the request size where the management operation permits it.
