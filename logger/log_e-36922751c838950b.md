# Widevine signing material is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-36922751c838950b

## Log pattern

```text
widevine_signer, widevine_aes_signing_key and widevine_aes_signing_iv must be provided for Widevine license server
```

## Parameters

The original message also names the signer; this condition specifically checks the signing key and IV.

## Log examples

Illustrative examples; these are not captured server logs.

```text
widevine_signer, widevine_aes_signing_key and widevine_aes_signing_iv must be provided for Widevine license server
```

## Short description

Widevine signing material is missing.

## Trigger condition

A Widevine group ends with an empty AES signing key or signing IV.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- A Widevine group ends with an empty AES signing key or signing IV.

## What to check

1. Provide the Widevine signing key and IV and verify the intended signer.

## Recommended action

Provide the Widevine signing key and IV and verify the intended signer.
