# DVR combined MPEG-TS chunk generation failed

Product: Nimble Streamer
Component: DVR playback conversion
Logging function: log_e
Log level: error
Documentation ID: log_e-1c2b3dc845252a38

## Log pattern

```text
failed to generate chunk key='%s'
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested cache output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to generate chunk key='/live/camera/dvr_v_p1_90000.fmp4'
```

## Short description

DVR combined MPEG-TS chunk generation failed.

## Trigger condition

Audio/video MPEG-TS generation returns failure or the recorded video codec has no supported combined muxing branch.

## Explanation

The cache item is canceled.

## Possible causes

- Audio/video MPEG-TS generation returns failure or the recorded video codec has no supported combined muxing branch.

## What to check

1. Check preceding media parsing and buffer errors and the recorded video codec.

## Recommended action

Check preceding media parsing and buffer errors and the recorded video codec.
