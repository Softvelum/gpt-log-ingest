# Live stream metadata update requested

Product: Nimble Streamer
Component: Live stream metadata
Logging function: log_d
Log level: debug
Documentation ID: log_d-21d9eb41f32ab522

## Log pattern

```text
RtmpStreamBuffer::setMetadata for %s/%s
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
RtmpStreamBuffer::setMetadata for live/camera
```

## Short description

Live stream metadata update requested.

## Trigger condition

Metadata is supplied to the live stream buffer while debug logging is selected.

## Explanation

The message precedes duplicate detection. Identical metadata can be ignored; otherwise a new metadata item replaces the retained metadata and enters the circular stream buffer.
