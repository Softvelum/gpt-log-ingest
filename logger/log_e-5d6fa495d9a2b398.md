# Unclassified exception interrupted media generation

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-5d6fa495d9a2b398

## Log pattern

```text
unknown exception caught while processing file='%s'
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown exception caught while processing file='/media/movie.mp4'
```

## Short description

Unclassified exception interrupted media generation.

## Trigger condition

An exception not handled by the earlier media-specific or standard-exception handlers escapes output generation.

## Explanation

The requested output cache item is canceled with a transmuxing-failure reason and released.

## Possible causes

- An exception not handled by the earlier media-specific or standard-exception handlers escapes output generation.

## What to check

1. Inspect preceding parser, DRM, and allocation diagnostics for this source; the catch-all message itself carries no exception detail.
