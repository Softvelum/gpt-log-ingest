# Local output video format is unsupported

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-5a093a913d38f423

## Log pattern

```text
unsupported video format=%d, add format=uyvy422|nv12|yuv420p into video pipeline for stream=%s
```

## Parameters

- Argument 1 — Pixel format: FFmpeg pixel-format identifier, integer enumeration value; no unit.
- Argument 2 — Output: Local output stream or AJA writer name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported video format=28, add format=uyvy422|nv12|yuv420p into video pipeline for stream=camera
```

## Short description

Local output video format is unsupported.

## Trigger condition

The common local socket writer receives a frame outside UYVY422, NV12, and YUV420P.

## Explanation

The frame is rejected before writer-state checking and queueing.

## Possible causes

- The upstream filter chain supplies a pixel layout not supported by local frame serialization.

## What to check

1. Check the reported FFmpeg pixel format and output filter settings.

## Recommended action

Add a format filter selecting uyvy422, nv12, or yuv420p.
