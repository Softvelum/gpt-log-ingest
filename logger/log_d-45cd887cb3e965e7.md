# VCAS key value updated

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-45cd887cb3e965e7

## Log pattern

```text
updated value for VCAS key url='%s' client_url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Client key URL: Text giving the URL clients use to retrieve the key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updated value for VCAS key url='https://keys.example/key' client_url='https://keys.example/client'
```

## Short description

VCAS key value updated.

## Trigger condition

A successful create-key or get-key response provides a key string exactly 32 characters long.

## Explanation

The key bytes and client URL are stored, the update time advances, and the failed flag clears.

## Possible causes

- A successful create-key or get-key response provides a key string exactly 32 characters long.
