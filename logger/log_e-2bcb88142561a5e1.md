# Session URL cannot be separated into application and stream

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_e
Log level: error
Documentation ID: log_e-2bcb88142561a5e1

## Log pattern

```text
failed to split url='%s' session_type=%d
```

## Parameters

- Argument 1 — URL: Requested resource URL.
- Argument 2 — type: Protocol value during registration; VOD/live subtype value during restoration.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to split url='/' session_type=1
```

## Short description

Session URL cannot be separated into application and stream.

## Trigger condition

New-session registration or saved-session restoration cannot split the supplied URL for its playback protocol.

## Explanation

Registration returns an invalid session identifier, or restoration skips the affected saved session. The second field means protocol during registration but means VOD/live subtype during restoration.

## Possible causes

- The URL cannot be interpreted as an application and stream for the requested protocol.

## What to check

1. Check URL shape and whether the message occurs during registration or saved-session loading.

## Recommended action

Correct the requested or saved session URL.
