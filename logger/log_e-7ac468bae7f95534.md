# SDI output audio sample rate is missing

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-7ac468bae7f95534

## Log pattern

```text
audio sample_rate is invalid for [%s/%s]
```

## Parameters

- Argument 1 — Device type: FFmpeg output device type, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio sample_rate is invalid for [decklink/live/camera]
```

## Short description

SDI output audio sample rate is missing.

## Trigger condition

Output audio setup is requested with a sample rate of zero.

## Explanation

The audio setup request returns failure.

## Possible causes

- No valid audio sample rate was supplied.

## What to check

1. Check that the source audio configuration includes a nonzero sample rate.

## Recommended action

Supply the source sample rate before creating the output.
