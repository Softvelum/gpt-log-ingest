# VP8 hardware decoder is unavailable in FFmpeg

Product: Nimble Streamer
Component: Video decoding
Logging function: log_i
Log level: info
Documentation ID: log_i-38c054b733d003a8

## Log pattern

```text
vp8_qsv decoder is unavailable, using default decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
vp8_qsv decoder is unavailable, using default decoder for [live/camera]
```

## Short description

VP8 hardware decoder is unavailable in FFmpeg.

## Trigger condition

The quicksync-ffmpeg option is selected but FFmpeg cannot find the vp8_qsv decoder.

## Explanation

The worker constructs the default VP8 decoder and continues.

## Possible causes

- The loaded FFmpeg codec library does not register the requested hardware decoder.

## What to check

1. Check the selected decoder option and the loaded FFmpeg library capabilities.

## Recommended action

Use a codec library providing vp8_qsv if that backend is required; otherwise allow the default decoder.
