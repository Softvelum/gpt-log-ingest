# Unknown panel user action

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_v
Log level: verbose
Documentation ID: log_v-cd9e474bd9234458

## Log pattern

```text
unknown user action='%s'
```

## Parameters

- Argument 1 — action: Requested action string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown user action='unsupportedAction'
```

## Short description

Unknown panel user action.

## Trigger condition

A user-action entry has an action value other than deleteDvrArchive.

## Explanation

The action is logged and ignored; subsequent actions are still considered. An absent action produces an empty value.
