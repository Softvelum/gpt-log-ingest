# RIST address could not be parsed

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-9f6a051af957ed57

## Log pattern

```text
failed to parse rist url=%s, id=%s
```

## Parameters

- Argument 1 — RIST URL: Configured transport address and query options.
- Argument 2 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse rist url=rist://invalid, id=rist-output
```

## Short description

RIST address could not be parsed.

## Trigger condition

The RIST library rejects the configured URL.

## Explanation

Initialization returns failure before transport context creation.

## Possible causes

- The RIST library rejects the configured URL.

## What to check

1. Check the configured RIST URL and options.

## Recommended action

Provide a RIST URL accepted by the transport library.
