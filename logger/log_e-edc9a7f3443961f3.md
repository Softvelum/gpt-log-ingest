# RTSP named audio encoding is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-edc9a7f3443961f3

## Log pattern

```text
unsupported audio codec='%s' stream url='%s'
```

## Parameters

- Argument 1 — Encoding: SDP audio encoding name.
- Argument 2 — Stream URL: RTSP input base URL identifying the affected source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audio codec='unsupported-audio' stream url='rtsp://192.0.2.1/live'
```

## Short description

RTSP named audio encoding is unsupported.

## Trigger condition

The nonempty audio encoding does not match the supported AAC, MPEG audio, Opus, AC-3, E-AC-3, or G.711 selections.

## Explanation

RTSP audio codec selection returns failure.

## Possible causes

- The nonempty audio encoding does not match the supported AAC, MPEG audio, Opus, AC-3, E-AC-3, or G.711 selections.

## What to check

1. Check the named audio encoding in SDP.

## Recommended action

Use one of the audio encodings accepted by the RTSP input.
