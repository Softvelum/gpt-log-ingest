# EAC3 decoder is unavailable

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e4ca39134e2e9567

## Log pattern

```text
failed to find eac3 decoder for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find eac3 decoder for [live/camera]
```

## Short description

EAC3 decoder is unavailable.

## Trigger condition

The first availability lookup finds no registered FFmpeg EAC3 decoder.

## Explanation

The missing-decoder result is cached, the update returns success, and subsequent EAC3 frames are skipped by this worker.

## Possible causes

- The loaded FFmpeg codec library does not provide this decoder.

## What to check

1. Check the loaded codec library and required EAC3 support.

## Recommended action

Use a codec library with EAC3 decoding support or change the input codec.
