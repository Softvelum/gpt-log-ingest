# Existing cache fragment could not be mapped

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-a8a934caa7734775

## Log pattern

```text
failed to map fragment file='%s'
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to map fragment file='/var/cache/nimble/movie.fr/0'
```

## Short description

Existing cache fragment could not be mapped.

## Trigger condition

Opening an existing fragment succeeds but creating its memory mapping fails.

## Explanation

The newly created fragment tracking object is deleted, the fragment slot is cleared, and a cache error is thrown.

## Possible causes

- The operating system could not map the existing fragment file.

## What to check

1. Check file access and nearby file mapping errors.

## Recommended action

Resolve the file mapping failure before retrying the affected media request.
