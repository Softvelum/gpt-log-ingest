# VCAS key response cannot be interpreted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-b29430e7b698045d

## Log pattern

```text
failed to process VCAS keyResponse url='%s' response:
%.*s
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Response length: Integer limit in bytes for the response text that follows.
- Argument 3 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process VCAS keyResponse url='https://keys.example/key' response:
{}
```

## Short description

VCAS key response cannot be interpreted.

## Trigger condition

A create-key or get-key response fails JSON or required-field validation.

## Explanation

The response is discarded and the key is not updated.

## Possible causes

- A create-key or get-key response fails JSON or required-field validation.

## What to check

1. Check the VCAS response status, key, and client URL fields.

## Recommended action

Check the VCAS response status, key, and client URL fields.
