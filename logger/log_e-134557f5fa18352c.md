# Requested track combination cannot produce a playlist

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-134557f5fa18352c

## Log pattern

```text
file='%s' invalid video_index=%d or audio_index=%d
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.
- Argument 2 — Video selection: Integer video-track selection from the request or chunk name; 0 is the default selection.
- Argument 3 — Audio selection: Integer audio-track selection from the request or chunk name; 0 is the default selection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
file='/media/movie.mp4' invalid video_index=9 or audio_index=9
```

## Short description

Requested track combination cannot produce a playlist.

## Trigger condition

Building a playlist structure for selected audio/video tracks returns no structure during MKV or MP4 playlist, chunk, or advertising-subtitle processing.

## Explanation

The requested output is canceled and released. Advertising-subtitle helpers first return failure to their caller, which cancels that output.

## Possible causes

- Building a playlist structure for selected audio/video tracks returns no structure during MKV or MP4 playlist, chunk, or advertising-subtitle processing.

## What to check

1. Verify the requested audio/video selections and supported codecs. This message can indicate failure to build a playlist structure, not just an out-of-range selection.

## Recommended action

Verify the requested audio/video selections and supported codecs. This message can indicate failure to build a playlist structure, not just an out-of-range selection.
