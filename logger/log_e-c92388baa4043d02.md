# VCAS create-key request failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-c92388baa4043d02

## Log pattern

```text
VCAS failed to create key url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VCAS failed to create key url='https://keys.example/key'
```

## Short description

VCAS create-key request failed.

## Trigger condition

A submitted VCAS create-key request receives a failure callback.

## Explanation

The pending request is removed and no key is installed.

## Possible causes

- A submitted VCAS create-key request receives a failure callback.

## What to check

1. Check the VCAS create-key HTTP failure and endpoint availability.

## Recommended action

Check the VCAS create-key HTTP failure and endpoint availability.
