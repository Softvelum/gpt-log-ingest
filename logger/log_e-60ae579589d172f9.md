# Encoded audio format is unknown

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-60ae579589d172f9

## Log pattern

```text
failed to write audio pkt, unknown audio_format=%d state=%d for [%s/%s]
```

## Parameters

- Argument 1 — Audio format: Packet-writer format integer: 0 MP3, 1 AAC, 2 AC3, 3 EAC3, 4 Opus, 5 MP2; no unit.
- Argument 2 — Processing state: Integer state: 0 initial, 1 video only, 2 audio only, 3 processing audio after video, 4 processing video with audio paused, 5 waiting for video, 6 waiting for audio, 7 finding first audio, 8 processing audio with video paused.
- Argument 3 — Application: Output application name, text.
- Argument 4 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write audio pkt, unknown audio_format=6 state=0 for [live/encoded]
```

## Short description

Encoded audio format is unknown.

## Trigger condition

Initial encoded-audio output setup receives a packet-writer format other than AAC, MP3, AC3, EAC3, Opus, or MP2.

## Explanation

No output codec is selected and the packet is rejected before synchronization.

## Possible causes

- The encoder reported a format outside the supported audio output dispatch list.

## What to check

1. Check the configured encoder, reported format, and processing state.

## Recommended action

Select a supported audio codec and restart output.
