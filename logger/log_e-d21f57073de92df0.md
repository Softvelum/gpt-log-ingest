# HTTP/3 decoded header is absent from its set

Product: Nimble Streamer
Component: HTTP/3 header decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-d21f57073de92df0

## Log pattern

```text
lsquic error. hset_add_header called with invalid hdr
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
lsquic error. hset_add_header called with invalid hdr
```

## Short description

HTTP/3 decoded header is absent from its set.

## Trigger condition

The library supplies a non-null decoded header for addition, but the header cannot be found in the active header set.

## Explanation

The callback returns an error instead of accepting the decoded header, indicating a connection error to the library.

## Possible causes

- Header ownership or callback ordering is inconsistent between the library and server.

## What to check

1. Check the HTTP/3 library/server build and surrounding header callback failures.

## Recommended action

Investigate repeated invalid header callbacks as an integration or lifetime defect.
