# Subtitle chunk is absent from the generated subtitle list

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-1919e0148010d248

## Log pattern

```text
invalid subtitle chunk request(%s)'
```

## Parameters

- Argument 1 — Subtitle resource: Text WebVTT resource whose language or index cannot be served.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid subtitle chunk request(n_999.webvtt)'
```

## Short description

Subtitle chunk is absent from the generated subtitle list.

## Trigger condition

The parsed subtitle language is not present or its chunk index is beyond the generated list.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- The parsed subtitle language is not present or its chunk index is beyond the generated list.

## What to check

1. Compare its language and index with the current subtitle playlist; regenerate or refresh stale playlist requests after subtitle changes.

## Recommended action

Compare its language and index with the current subtitle playlist; regenerate or refresh stale playlist requests after subtitle changes.
