# Initial child request could not be queued

Product: Nimble Streamer
Component: Child process communication
Logging function: log_e
Log level: error
Documentation ID: log_e-d9b1e572c304f833

## Log pattern

```text
failed to write initial request
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write initial request
```

## Short description

Initial child request could not be queued.

## Trigger condition

A stopped session has a waiting request, but adding it to the output buffer fails.

## Explanation

The current attempt fails before launching a new child.

## Possible causes

- The framed request cannot fit in the bounded output buffer.

## What to check

1. Check the size of the initial request and the output buffer limit.

## Recommended action

Resolve the reported child communication problem before retrying.
