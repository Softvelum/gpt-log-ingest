# Socket receive returned no data

Product: Nimble Streamer
Component: Stream checks and MPEG-TS inputs
Logging function: log_d
Log level: debug
Documentation ID: log_d-1022a60d81d97cb7

## Log pattern

```text
connection closed by s=%d
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed by s=12
```

## Short description

Socket receive returned no data.

## Trigger condition

A stream-check, MPEG-TS UDP, or local Zixi receive returns zero bytes.

## Explanation

The checker requests shutdown, while the media input handlers report failure to their caller. For UDP, a zero-length datagram can reach this same branch; the wording alone does not prove a TCP peer closed.
