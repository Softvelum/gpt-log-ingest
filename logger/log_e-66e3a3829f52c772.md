# AJA output audio sample rate is not 48 kHz

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-66e3a3829f52c772

## Log pattern

```text
AJA output audio requires 48kHz for %s, sample_rate=%d
```

## Parameters

- Argument 1 — Session name: Configured AJA device and channel name.
- Argument 2 — Sample rate: Incoming audio sample rate in samples per second.

## Log examples

Illustrative examples; these are not captured server logs.

```text
AJA output audio requires 48kHz for 0/0, sample_rate=44100
```

## Short description

AJA output audio sample rate is not 48 kHz.

## Trigger condition

Planar floating-point audio has a sample rate other than 48000 samples per second.

## Explanation

Audio configuration returns failure before accepting its channel count.

## Possible causes

- Planar floating-point audio has a sample rate other than 48000 samples per second.

## What to check

1. Check the output audio sample rate.

## Recommended action

Resample audio to 48000 samples per second.
