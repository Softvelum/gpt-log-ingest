# Panel does not recognize recovered-statistics server

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-77065bbaaa78732a

## Log pattern

```text
this server is 'unknown' to the panel
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
this server is 'unknown' to the panel
```

## Short description

Panel does not recognize recovered-statistics server.

## Trigger condition

The recovered-statistics response contains a status equal to unknown.

## Explanation

The response handler returns false. Its caller keeps the recovered-statistics batch and leaves the current retry loop, allowing later synchronization to try recovery again; this branch does not stop the main synchronization thread.

## Possible causes

- The recovery endpoint reported that the server is unknown.

## What to check

1. Check server registration and identity used with the selected panel.

## Recommended action

Correct the server registration or panel identity.
