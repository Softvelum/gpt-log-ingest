## Short description

Return-to-primary probing requires Addenda.

## Trigger condition

An active fallback has a scheduled primary probe, but Addenda is not enabled.

## Explanation

RTMP/Icecast pull removes the probe schedule. HTTP/HLS MPEG-TS and SRT pull stop the periodic probe timer. The existing fallback input is left running.

## Possible causes

- Primary-source probing was requested without the required Addenda entitlement.

## What to check

1. Check Addenda availability and primary probe settings.

## Recommended action

Enable the required entitlement if automatic return to the primary is needed.
