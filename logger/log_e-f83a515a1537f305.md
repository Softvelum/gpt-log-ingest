# DRM protection type is unknown

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-f83a515a1537f305

## Log pattern

```text
unknown DRM protection type %s:%u '%s'
```

## Parameters

- Argument 1 — Settings file: Text naming the DRM settings file.
- Argument 2 — Settings line: Unsigned line number within the settings file.
- Argument 3 — Setting text: Text containing the rejected settings line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown DRM protection type /etc/nimble/drm.conf:12 'unsupported=value'
```

## Short description

DRM protection type is unknown.

## Trigger condition

The protection type does not match a supported provider or HLS AES-128 mode.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The protection type does not match a supported provider or HLS AES-128 mode.

## What to check

1. Use a protection type supported by the installed DRM integration.

## Recommended action

Use a protection type supported by the installed DRM integration.
