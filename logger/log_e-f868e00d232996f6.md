# Awaited advertising chunk could not be queued

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-f868e00d232996f6

## Log pattern

```text
failed to add advertising chunk request, key=%s
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add advertising chunk request, key=/live/camera/segment1.ts
```

## Short description

Awaited advertising chunk could not be queued.

## Trigger condition

After the advertising playlist becomes usable and a cache observer is installed, submitting the awaited chunk-generation request fails.

## Explanation

HTTP 500 is prepared; HTTP/2 or HTTP/3 also removes its cache observer.

## Possible causes

- After the advertising playlist becomes usable and a cache observer is installed, submitting the awaited chunk-generation request fails.

## What to check

1. Inspect preceding advertising playlist and transcoding errors for this chunk; its generation request was not accepted.

## Recommended action

Inspect preceding advertising playlist and transcoding errors for this chunk; its generation request was not accepted.
