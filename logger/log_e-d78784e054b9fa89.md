# Could not create the SRT input connection worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-d78784e054b9fa89

## Log pattern

failed to create SrtPull thread

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Could not create the SRT input connection worker.

## Trigger condition

SRT support is compiled in, its library is available, and a configured pull worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the SRT input connection worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed SRT input connection worker.
