# Could not create the Icecast input worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Could not create the Icecast input worker.

## Trigger condition

The Icecast server worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the Icecast input worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed Icecast input worker.
