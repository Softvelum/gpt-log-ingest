# Cannot write Ogg chunk initialization header

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-588c600336c1edab

## Log pattern

```text
icecast stream failed to write OGG chunk header %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream failed to write OGG chunk header http://radio.example.net/live
```

## Short description

Cannot write Ogg chunk initialization header.

## Trigger condition

At the start of an Icecast Ogg chunk, writing the FLAC header version, size, or saved header fails.

## Explanation

The Ogg frame cannot be added to the chunk and the ingest session is shut down.

## Possible causes

- At the start of an Icecast Ogg chunk, writing the FLAC header version, size, or saved header fails.

## What to check

1. Check output chunk capacity and saved FLAC header size.
