# Dequeued client socket is already active

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-541d2682718a204c

## Log pattern

```text
s=%d is already in active clients list
```

## Parameters

- Argument 1 — Socket: Integer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=12 is already in active clients list
```

## Short description

Dequeued client socket is already active.

## Trigger condition

An accepted socket descriptor is already present in the worker active-client map.

## Explanation

The worker stops taking new queued clients during this iteration. This branch does not explicitly close the duplicate descriptor.

## Possible causes

- The dequeued descriptor already belongs to an active session.

## What to check

1. Compare the descriptor with earlier accepted-client and session events.
