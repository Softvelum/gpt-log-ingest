# Client connection statistics update begins

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_d
Log level: debug
Documentation ID: log_d-ae81ab04503e02a2

## Log pattern

```text
StatisticsItem::Connect(%s) [%s]
```

## Parameters

- Argument 1 — Client address: Client IP address as text; an empty value can represent a request to create statistics records only.
- Argument 2 — Recent connections: Semicolon-separated client addresses accumulated for reporting; this is not necessarily the current active-client list.

## Log examples

Illustrative examples; these are not captured server logs.

```text
StatisticsItem::Connect(192.0.2.10) []
```

## Short description

Client connection statistics update begins.

## Trigger condition

A stream statistics record receives a connection notification.

## Explanation

The message shows the previous connection list. An empty client address returns without counting a connection; otherwise the address is appended and stream, application and host connection counts increase.
