# Playlist AC-3 channel layout cannot be read

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-11031627d3adc453

## Log pattern

```text
ServerBlockProcessor: AC3_Reader::getChannelLayout failed for vod file [%s], stream=[%s/%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: AC3_Reader::getChannelLayout failed for vod file [/media/program.mp4], stream=[live/camera]
```

## Short description

Playlist AC-3 channel layout cannot be read.

## Trigger condition

Reading channel layout from the last parsed AC-3 frame fails.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- Reading channel layout from the last parsed AC-3 frame fails.

## What to check

1. Check the AC-3 frame header and channel configuration.

## Recommended action

Check the AC-3 frame header and channel configuration.
