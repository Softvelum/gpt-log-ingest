# SDI output has no video

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-a6f759012a91d8b7

## Log pattern

```text
video MUST exist [%s/%s]
```

## Parameters

- Argument 1 — Device type: FFmpeg output device type, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
video MUST exist [decklink/live/camera]
```

## Short description

SDI output has no video.

## Trigger condition

Device output creation is attempted before video has been configured.

## Explanation

The output is not created.

## Possible causes

- Output setup has no video configuration.

## What to check

1. Check that a video stream has been supplied before starting the SDI output.

## Recommended action

Configure video for the output.
