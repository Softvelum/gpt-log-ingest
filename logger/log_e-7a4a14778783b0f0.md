# SRT stream-ID listener requires Addenda

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-7a4a14778783b0f0

## Log pattern

```text
failed to bind srt socket %s:%d with '%s' (requires Addenda package license)
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Option: The password-path option name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to bind srt socket 0.0.0.0:9000 with 'nimble-srt-password-path' (requires Addenda package license)
```

## Short description

SRT stream-ID listener requires Addenda.

## Trigger condition

The password-path option is configured while Addenda is unavailable, including when its value disables file-based authentication.

## Explanation

This listener setting is skipped before opening a listening socket.

## Possible causes

- The password-path option is configured while Addenda is unavailable, including when its value disables file-based authentication.

## What to check

1. Check the Addenda license and need for stream-ID processing.

## Recommended action

Enable the required package for this listener configuration.
