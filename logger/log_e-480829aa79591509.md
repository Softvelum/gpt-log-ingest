# RTMP publisher cannot send the VP8 or VP9 sequence start

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-480829aa79591509

## Log pattern

```text
failed to send VP9/Vp9 sequence start to client: %d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send VP9/Vp9 sequence start to client: 42
```

## Short description

RTMP publisher cannot send the VP8 or VP9 sequence start.

## Trigger condition

Sending the generated enhanced RTMP sequence-start item for a VP8 or VP9 key frame fails.

## Explanation

The publishing operation fails and the connection is shut down. The printed VP9/Vp9 wording also covers VP8.

## Possible causes

- Sending the generated enhanced RTMP sequence-start item for a VP8 or VP9 key frame fails.

## What to check

1. Check transport errors and the destination connection at the start of VP8 or VP9 publishing.

## Recommended action

Resolve the output failure before retrying publication.
