# Cannot initialize TLS for pulled media

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-68481f1cda39828d

## Log pattern

```text
failed to init ssl for %s s=%d
```

## Parameters

- Argument 1 — Role: Socket role label identifying the media puller.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init ssl for icecast s=42
```

## Short description

Cannot initialize TLS for pulled media.

## Trigger condition

A nonblocking source connection starts but TLS initialization fails when HTTPS is requested.

## Explanation

The source socket is closed and connection setup reports failure. This message is shared by Icecast, MPEG-TS over HTTP, and HLS pull sessions.

## Possible causes

- A nonblocking source connection starts but TLS initialization fails when HTTPS is requested.

## What to check

1. Check TLS initialization diagnostics for the indicated connection role.
