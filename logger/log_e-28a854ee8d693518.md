# AJA capture circulation stopped

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-28a854ee8d693518

## Log pattern

```text
capture stopped device=%s/%d reason='AutoCirculate stopped'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
capture stopped device=0/0 reason='AutoCirculate stopped'
```

## Short description

AJA capture circulation stopped.

## Trigger condition

The capture loop observes the card circulation engine in a stopped or stopping state.

## Explanation

The capture quit flag is set, the loop exits, and circulation is stopped during cleanup.

## Possible causes

- The capture loop observes the card circulation engine in a stopped or stopping state.

## What to check

1. Check what stopped device capture and preceding card errors.
