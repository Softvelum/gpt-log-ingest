# License validation credentials are incomplete

Product: Nimble Streamer
Component: Transcoder and Addenda licensing
Logging function: log_e
Log level: error
Documentation ID: log_e-941e53609713ade3

## Log pattern

```text
domain, uuid or password empty
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
domain, uuid or password empty
```

## Short description

License validation credentials are incomplete.

## Trigger condition

The selected license-server domain, server identifier, or registration password is empty.

## Explanation

Validation fails before opening a connection. The Transcoder or Addenda verification worker stops its feature and waits for a license change.

## Possible causes

- Required server registration data is missing.

## What to check

1. Check the configured domain and server registration credentials.

## Recommended action

Restore the missing registration settings.
