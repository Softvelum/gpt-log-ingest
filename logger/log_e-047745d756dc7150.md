# RTMP play status command-object placeholder cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-047745d756dc7150

## Log pattern

```text
failed to read null object for play/onStatus
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read null object for play/onStatus
```

## Short description

RTMP play status command-object placeholder cannot be decoded.

## Trigger condition

The remote play onStatus response lacks a readable AMF null value at its command-object placeholder.

## Explanation

The pending command response is marked failed and connection processing stops.

## Possible causes

- The remote play onStatus response lacks a readable AMF null value at its command-object placeholder.

## What to check

1. Inspect the play status response field order and AMF types.

## Recommended action

Correct the malformed status response at the remote endpoint.
