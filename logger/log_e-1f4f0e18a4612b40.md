# NVIDIA management initialization failed

Product: Nimble Streamer
Component: Transcoding library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-1f4f0e18a4612b40

## Log pattern

```text
failed to init nvml, res=%u
```

## Parameters

- Argument 1 — Status: NVIDIA management-library result, unsigned integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init nvml, res=9
```

## Short description

NVIDIA management initialization failed.

## Trigger condition

The NVIDIA management library loads, but its initialization returns a result other than success.

## Explanation

NVIDIA management support is left unavailable; other transcoding-library loading continues.

## Possible causes

- The NVIDIA management library cannot initialize access to the installed NVIDIA environment.

## What to check

1. Check the numeric NVIDIA management status and driver/device availability.

## Recommended action

Restore the NVIDIA management environment if its capabilities are required.
