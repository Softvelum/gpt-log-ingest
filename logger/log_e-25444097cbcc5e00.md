# Pending socket connection reports an error

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_e
Log level: error
Documentation ID: log_e-25444097cbcc5e00

## Log pattern

```text
failed to connect to s=%d opt_val=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Socket error: Nonzero pending socket error code, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect to s=12 opt_val=111
```

## Short description

Pending socket connection reports an error.

## Trigger condition

A socket is present in the exception set but not the writable set, and reading its pending socket error succeeds with a nonzero value.

## Explanation

An output event is delivered so the owning connection can handle the failure.

## Possible causes

- The pending connection has an operating system socket error.

## What to check

1. Check the socket and its pending error code.

## Recommended action

Resolve the connection error reported by the operating system.
