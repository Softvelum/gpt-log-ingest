# Scenario output unregister request received

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_d
Log level: debug
Documentation ID: log_d-605c687ad11331ad

## Log pattern

```text
unregister encoder stream=%s, scenario=%s
```

## Parameters

- Argument 1 — Output stream: Output application and stream joined with a slash, text.
- Argument 2 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unregister encoder stream=live/output, scenario=scenario1
```

## Short description

Scenario output unregister request received.

## Trigger condition

The child asks the parent to unregister an output stream.

## Explanation

The parent removes the output registration if this scenario currently owns it; an untracked name has no effect.
