# Video acceleration display initialized

Product: Nimble Streamer
Component: Linux video acceleration initialization
Logging function: log_d
Log level: debug
Documentation ID: log_d-5346c169f49ffc34

## Log pattern

```text
dev=%s driver:'%s' va-api:%d.%d
```

## Parameters

- Argument 1 — Device: Linux render-device path being probed, text.
- Argument 2 — Driver: Driver vendor description, text.
- Argument 3 — Major version: Video acceleration API major version, integer.
- Argument 4 — Minor version: Video acceleration API minor version, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dev=/dev/dri/renderD128 driver:'Example driver' va-api:1.0
```

## Short description

Video acceleration display initialized.

## Trigger condition

A Linux render device opens and its video acceleration display initializes successfully. The driver description is available.

## Explanation

The first working display is retained and device probing succeeds.
