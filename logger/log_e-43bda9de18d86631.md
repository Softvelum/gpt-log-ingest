# Windows mapping object creation failed

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-43bda9de18d86631

## Log pattern

```text
CreateFileMapping failed error=%d
```

## Parameters

- Argument 1 — Error: Windows error code, printed in decimal.

One occurrence supplies the unsigned Windows error type directly; other occurrences store the code in an int.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CreateFileMapping failed error=8
```

## Short description

Windows mapping object creation failed.

## Trigger condition

Windows cannot create the mapping object for an opened existing or newly sized file.

## Explanation

No memory view is returned and file handles are cleaned up.

## Possible causes

- Windows cannot create the mapping object for an opened existing or newly sized file.

## What to check

1. Check the Windows error, requested mapping access, and file size.
