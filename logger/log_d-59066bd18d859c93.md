# Advertising content completion delivered to a session

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-59066bd18d859c93

## Log pattern

```text
[WrkT::AdCtLd] key='%s' p=%p
```

## Parameters

- Argument 1 — Content identifier: Text identifying the observed resource.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::AdCtLd] key='example-item' p=0x1000
```

## Short description

Advertising content completion delivered to a session.

## Trigger condition

A queued content-loaded notification has a matching waiting session.

## Explanation

The content-loaded callback is invoked and the session is deleted afterward if finished.
