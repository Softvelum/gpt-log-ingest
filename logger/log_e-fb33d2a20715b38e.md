# DASH resource has an unknown segment prefix

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-fb33d2a20715b38e

## Log pattern

```text
unknown DASH segment type: '%s'
```

## Parameters

- Argument 1 — DASH resource: Text requested DASH media or initialization resource.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown DASH segment type: 'x_0.m4s'
```

## Short description

DASH resource has an unknown segment prefix.

## Trigger condition

A requested .m4s, .m4a, or .m4v resource reaches DASH packaging but has none of the supported v_, y_, s_, or i_ prefixes.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- A requested .m4s, .m4a, or .m4v resource reaches DASH packaging but has none of the supported v_, y_, s_, or i_ prefixes.

## What to check

1. Use segment URLs from the matching DASH manifest and preserve their generated prefix and suffix.

## Recommended action

Use segment URLs from the matching DASH manifest and preserve their generated prefix and suffix.
