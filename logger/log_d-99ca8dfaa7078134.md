## Short description

Icecast server thread stopped.

## Trigger condition

The Icecast server loop exits after shutdown is requested and sessions and listening sockets are cleaned up.

## Explanation

The thread returns and stops handling Icecast connections.

## Possible causes

- The Icecast server loop exits after shutdown is requested and sessions and listening sockets are cleaned up.

## What to check

1. Check whether server shutdown was expected.
