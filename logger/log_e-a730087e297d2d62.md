# Cannot observe pending Icecast advertisement

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a730087e297d2d62

## Log pattern

```text
failed to add content observer for %s
```

## Parameters

- Argument 1 — Content ID: Text identifier of the advertising content being awaited.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add content observer for ad-01
```

## Short description

Cannot observe pending Icecast advertisement.

## Trigger condition

Registering for advertising-content readiness fails while an Icecast session is waiting for its next advertisement.

## Explanation

The client session is marked finished.

## Possible causes

- Registering for advertising-content readiness fails while an Icecast session is waiting for its next advertisement.

## What to check

1. Check nearby advertising-content and observer-registration errors; the session cannot be resumed when the content becomes ready.

## Recommended action

Check nearby advertising-content and observer-registration errors; the session cannot be resumed when the content becomes ready.
