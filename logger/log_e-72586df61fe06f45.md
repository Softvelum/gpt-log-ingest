# Management event has no registered socket

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-72586df61fe06f45

## Log pattern

```text
unknown socket event fd=%d event=%d
```

## Parameters

- Argument 1 — socket: Unrecognized descriptor.
- Argument 2 — event\_mask: Event flags printed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown socket event fd=42 event=1
```

## Short description

Management event has no registered socket.

## Trigger condition

An event descriptor is neither a management listening socket nor a tracked management client.

## Explanation

The event is ignored by returning immediately. This branch does not explicitly close that descriptor or stop the thread.

## Possible causes

- The event descriptor is absent from both management socket tables.

## What to check

1. Check preceding acceptance, shutdown, and client-removal activity for that descriptor.
