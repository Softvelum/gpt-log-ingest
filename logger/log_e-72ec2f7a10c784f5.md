# DVR free-space limit could not be checked

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-72ec2f7a10c784f5

## Log pattern

```text
failed to get free space for dir='%s' ec.value()=%d ec.message()='%s'
```

## Parameters

- Argument 1 — Archive directory: Text giving the recording directory.
- Argument 2 — Filesystem error: Integer filesystem error code.
- Argument 3 — Error text: Text describing the filesystem query failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get free space for dir='/data/dvr/live/camera' ec.value()=13 ec.message()='Permission denied'
```

## Short description

DVR free-space limit could not be checked.

## Trigger condition

Recording retention checks disk free space and the filesystem query returns an error.

## Explanation

Cleanup continues using the existing retention depth and size limits without a new free-space adjustment.

## Possible causes

- Recording retention checks disk free space and the filesystem query returns an error.

## What to check

1. Check the archive filesystem and the reported access error.

## Recommended action

Check the archive filesystem and the reported access error.
