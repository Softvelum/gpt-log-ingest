# NVIDIA hardware decoder creation failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-26524c8e3070d31d

## Log pattern

```text
failed to create nvenc decoder for [%s], res=%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create nvenc decoder for [live/camera], res=2
```

## Short description

NVIDIA hardware decoder creation failed.

## Trigger condition

Creating a decoder with the incoming sequence, NV12 output and configured deinterlacing returns a driver error.

## Explanation

Decoder creation fails and the sequence callback marks packet processing failed.

## Possible causes

- The device or driver cannot support or allocate the requested decoding configuration.

## What to check

1. Check the CUDA status, codec, coded dimensions, chroma format and GPU resources.

## Recommended action

Use a supported input format or restore decoding resources.
