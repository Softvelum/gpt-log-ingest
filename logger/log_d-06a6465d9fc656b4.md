# HTTP/2 local media request started

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_d
Log level: debug
Documentation ID: log_d-06a6465d9fc656b4

## Log pattern

```text
[H2C::PLR] url='%s'
```

## Parameters

- Argument 1 — Origin URL: Origin resource URL after request routing, text; may include query parameters.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[H2C::PLR] url='/live/camera/playlist.m3u8'
```

## Short description

HTTP/2 local media request started.

## Trigger condition

A local resource request has decoded and sanitized its working path and is about to select subtitle, transmuxing, playlist, or file handling.

## Explanation

Processing continues according to the resource type and file availability. The logged value remains the original routed origin URL, so the message does not prove that a local file exists.
