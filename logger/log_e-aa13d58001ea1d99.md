# SVT HEVC input pixel format is unsupported

Product: Nimble Streamer
Component: SVT HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-aa13d58001ea1d99

## Log pattern

```text
unsupported frame format, %d
```

## Parameters

- Argument 1 — Pixel format: FFmpeg pixel-format identifier, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported frame format, 23
```

## Short description

SVT HEVC input pixel format is unsupported.

## Trigger condition

A video frame passed to SVT HEVC has a pixel format other than planar 8-bit YUV420P.

## Explanation

The frame write returns failure before encoder initialization or submission.

## Possible causes

- The filter or decoder supplies a format other than YUV420P.

## What to check

1. Check the numeric pixel format and upstream video conversion.

## Recommended action

Convert input to YUV420P before SVT HEVC encoding.
