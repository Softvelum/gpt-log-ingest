# Inactive DVR export was removed

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-a277dea5507f0c58

## Log pattern

```text
removed dvr export request on inactivity url='%s' client_ip=%s
```

## Parameters

- Argument 1 — Request URL: Text giving the export URL.
- Argument 2 — Client IP: Text containing the connected client address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
removed dvr export request on inactivity url='/manage/dvr/export/live/camera' client_ip=192.0.2.10
```

## Short description

Inactive DVR export was removed.

## Trigger condition

A prepared export exceeds the configured client inactivity timeout at a periodic check.

## Explanation

The current request processor is released and the worker can accept another request.

## Possible causes

- A prepared export exceeds the configured client inactivity timeout at a periodic check.

## What to check

1. Check whether the client stopped consuming the export and review the client inactivity timeout.

## Recommended action

Check whether the client stopped consuming the export and review the client inactivity timeout.
