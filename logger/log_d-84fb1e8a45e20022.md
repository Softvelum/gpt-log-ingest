# Recovered-statistics transport result

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-84fb1e8a45e20022

## Log pattern

```text
sync status[recovery]=%d
```

## Parameters

- Argument 1 — sync\_status: Transport result number: 0 success, 1 send failure, 2 receive failure, 3 invalid HTTP response, 4 TLS context creation failure, 5 TLS object creation failure, 6 TLS socket assignment failure, 7 partial TLS send, 8 TLS request-send failure, 9 TLS read failure, 10 internal error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync status[recovery]=0
```

## Short description

Recovered-statistics transport result.

## Trigger condition

A connected recovery-report socket has completed its request and has been shut down.

## Explanation

On transport success, the recovery response is processed before clearing the stored ready batch. An unknown-server response prevents that clearing. A transport failure also keeps the batch.
