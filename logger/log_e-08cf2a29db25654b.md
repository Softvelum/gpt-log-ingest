# NVIDIA picture submission failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-08cf2a29db25654b

## Log pattern

```text
failed to encode frame encoder=%p, status=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encode frame encoder=0x12340000, status=8
```

## Short description

NVIDIA picture submission failed.

## Trigger condition

Submitting the prepared picture returns a result other than success or the normal need-more-input status.

## Explanation

The current slot is marked free and the frame write returns failure.

## Possible causes

- The NVIDIA encoder API rejects this buffer or picture operation.

## What to check

1. Check frame configuration, driver state and the status code.

## Recommended action

Correct the reported driver/resource or encoder-state problem before retrying.
