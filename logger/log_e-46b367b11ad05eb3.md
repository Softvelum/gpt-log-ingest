# Audio selection cannot produce the requested output

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-46b367b11ad05eb3

## Log pattern

```text
file='%s' invalid audio_index=%d
```

## Parameters

- Argument 1 — Source media: Text filesystem path for local media, or source cache key for remote media.
- Argument 2 — Audio selection: Integer audio-track selection from the request or chunk name; 0 is the default selection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
file='/media/movie.mp4' invalid audio_index=9
```

## Short description

Audio selection cannot produce the requested output.

## Trigger condition

An audio-only playlist structure cannot be built for a fragmented-MP4 playlist/chunk or advertising-subtitle alignment.

## Explanation

The output is canceled, directly or through the subtitle helper caller.

## Possible causes

- An audio-only playlist structure cannot be built for a fragmented-MP4 playlist/chunk or advertising-subtitle alignment.

## What to check

1. Check the selected audio track and codec; for an audio chunk the selection is extracted from its resource name.

## Recommended action

Check the selected audio track and codec; for an audio chunk the selection is extracted from its resource name.
