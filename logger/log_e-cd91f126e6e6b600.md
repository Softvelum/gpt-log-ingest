# SRT target stream already has a publisher

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-cd91f126e6e6b600

## Log pattern

```text
already registered, %s
```

## Parameters

- Argument 1 — Stream: Requested application/stream identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
already registered, live/news
```

## Short description

SRT target stream already has a publisher.

## Trigger condition

The requested application/stream is already present in the active stream-ID camera set.

## Explanation

The newly accepted socket is removed and closed; the existing publisher is retained.

## Possible causes

- The requested application/stream is already present in the active stream-ID camera set.

## What to check

1. Check for another publisher using the same application/stream.

## Recommended action

Use a distinct target or stop the existing publisher before replacing it.
