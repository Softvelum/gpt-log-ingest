# Saved sessions loading line by line

Product: Nimble Streamer
Component: Playback session tracking
Logging function: log_i
Log level: info
Documentation ID: log_i-9c8180a580eb448c

## Log pattern

```text
Loading sessions partially from '%s'
```

## Parameters

- Argument 1 — file: Path of the saved session or recovery-statistics data file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Loading sessions partially from '/var/lib/nimble/sessions.db'
```

## Short description

Saved sessions loading line by line.

## Trigger condition

The partial loader is selected.

## Explanation

The loader reads session records from individual formatted lines, reducing whole-file buffering. Automatic selection uses this mode above 10 MiB; this does not mean only some valid records are intended to load.
