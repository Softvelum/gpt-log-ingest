# RTSP or HTTP status line is malformed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-b4557d69fc84347e

## Log pattern

```text
unable to parse status line for [%s]: %s
```

## Parameters

- Argument 1 — Stream identity: Application and stream label used by the RTSP parser.
- Argument 2 — Status line: Received RTSP or HTTP response line without its terminating newline.

The same format covers native RTSP responses and HTTP tunnel responses.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unable to parse status line for [live/camera]: RTSP/1.0 invalid
```

## Short description

RTSP or HTTP status line is malformed.

## Trigger condition

A complete response line fails the expected RTSP/1.0 or HTTP/1.x status-line structure, including its three-digit code and reason text.

## Explanation

Both response paths reset the parser to its interleaved-data state and return parse failure.

## Possible causes

- A complete response line fails the expected RTSP/1.0 or HTTP/1.x status-line structure, including its three-digit code and reason text.

## What to check

1. Check the response status line received from the RTSP source or HTTP tunnel endpoint.

## Recommended action

Return a complete protocol status line.
