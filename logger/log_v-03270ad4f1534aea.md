# DVR export range has no segments

Product: Nimble Streamer
Component: DVR export
Logging function: log_v
Log level: verbose
Documentation ID: log_v-03270ad4f1534aea

## Log pattern

```text
no segments to export for '%s' start=%llu end=%llu
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no segments to export for 'live/camera' start=1700000000 end=1700000060
```

## Short description

DVR export range has no segments.

## Trigger condition

MP4 export finds no video or audio segments, or subtitle export finds no video timeline segments, in the requested range.

## Explanation

The export returns HTTP 404.

## Possible causes

- MP4 export finds no video or audio segments, or subtitle export finds no video timeline segments, in the requested range.

## What to check

1. Choose a time range containing recorded segments.

## Recommended action

Choose a time range containing recorded segments.
