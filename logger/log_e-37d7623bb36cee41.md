# RTMP publishing connection closes

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-37d7623bb36cee41

## Log pattern

```text
connection closed for s=%d [%s:%d/%s/%s]
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for this connection.
- Argument 2 — Destination host: Publishing destination host.
- Argument 3 — Destination port: Publishing destination TCP port.
- Argument 4 — Application: Destination application name.
- Argument 5 — Stream: Destination stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed for s=42 [destination.example:1935/live/camera]
```

## Short description

RTMP publishing connection closes.

## Trigger condition

A publisher reports a receive-side connection termination or transport event outside the expected final Adobe/Limelight authentication transition or completed Twitch stream deletion.

## Explanation

The connection is ending; this message suppresses expected closures in those special transitions. It does not expose the underlying operating-system error.

## Possible causes

- A publisher reports a receive-side connection termination or transport event outside the expected final Adobe/Limelight authentication transition or completed Twitch stream deletion.

## What to check

1. Check preceding socket and remote-server events for this publishing destination.

## Recommended action

Resolve persistent destination or network failures before retrying publication.
