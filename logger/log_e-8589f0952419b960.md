# Stream-check event refers to an unknown socket

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-8589f0952419b960

## Log pattern

```text
invalid fd=%d in selector
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid fd=12 in selector
```

## Short description

Stream-check event refers to an unknown socket.

## Trigger condition

An event descriptor is absent from the active task map.

## Explanation

The descriptor is removed from the event selector and other events continue.

## Possible causes

- The selector returned a socket without a matching active task.

## What to check

1. Compare recent socket changes and task completion messages.

## Recommended action

Investigate inconsistent task event registration.
