# MKV audio output exceeds the available buffer

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-a6c4901484bb64ea

## Log pattern

```text
buffer is too small to generate file='%s' chunk='%s'
```

## Parameters

- Argument 1 — MKV filename: Text filesystem path of the source MKV file.
- Argument 2 — Requested resource: Text name of the requested playlist, initialization segment, or media chunk.

## Log examples

Illustrative examples; these are not captured server logs.

```text
buffer is too small to generate file='/media/movie.mkv' chunk='n_0_0_0.ts'
```

## Short description

MKV audio output exceeds the available buffer.

## Trigger condition

Audio processing within MKV transmuxing raises a buffer-too-small exception.

## Explanation

The output item is canceled with the insufficient-memory reason and released.

## Possible causes

- Audio processing within MKV transmuxing raises a buffer-too-small exception.

## What to check

1. Check source audio sample sizes and the VOD transmuxing buffer capacity; this message does not report the required byte count.

## Recommended action

Check source audio sample sizes and the VOD transmuxing buffer capacity; this message does not report the required byte count.
