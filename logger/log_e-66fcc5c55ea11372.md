# Advertising synchronization interval is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-66fcc5c55ea11372

## Log pattern

```text
invalid parameter value: %s. should be >= 1 && <=3600
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1 && <=3600
```

## Short description

Advertising synchronization interval is invalid.

## Trigger condition

While reading configuration, the advertising synchronization interval is outside 1 through 3600.

## Explanation

Configuration processing reports failure and the file loader stops at this line. The parsed value is assigned before the failure is returned; this message does not mean it was clamped to a valid range.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires an interval from 1 through 3600.

## Recommended action

Correct the value to an interval from 1 through 3600 and reload configuration.
