# NVIDIA codec dispatch is unsupported

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-4b81251c4b100b77

## Log pattern

```text
unknown nvenc codec %d
```

## Parameters

- Argument 1 — Codec: FFmpeg codec identifier, integer; no unit.

One occurrence is before driver initialization; the other is after retrieving sequence parameters. The earlier codec-mapping check normally rejects the same unsupported identifiers first.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown nvenc codec 999
```

## Short description

NVIDIA codec dispatch is unsupported.

## Trigger condition

The codec reaches encoder-parameter selection or output-header dispatch without matching H.264, HEVC or compiled AV1 support.

## Explanation

Encoder initialization returns failure.

## Possible causes

- The codec identifier is unsupported by this encoder path.

## What to check

1. Check the selected codec and build codec support.

## Recommended action

Select a supported codec.
