# Proxy refused the requested tunnel

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_e
Log level: error
Documentation ID: log_e-6e1d363c349c4e0f

## Log pattern

```text
failed to connect to '%s:%d' proxy response status=%d:
%.*s
```

## Parameters

- Argument 1 — Host: Destination host or proxy host, text.
- Argument 2 — Port: TCP destination port number, integer.
- Argument 3 — HTTP status: Proxy HTTP response status code, integer.
- Argument 4 — Header length: Maximum bytes printed from the accumulated proxy response; integer precision for the following text.
- Argument 5 — Response: Proxy response header bytes, truncated to the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect to 'panel.example:443' proxy response status=403:
HTTP/1.1 403 Forbidden


```

## Short description

Proxy refused the requested tunnel.

## Trigger condition

The proxy response headers are complete and its status is not 200.

## Explanation

Tunnel setup fails; the caller closes the proxy connection.

## Possible causes

- The proxy returned a non-success CONNECT status.

## What to check

1. Check the requested destination, proxy status, and included response headers.

## Recommended action

Correct proxy authorization or destination access according to the response.
