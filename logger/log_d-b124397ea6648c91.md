# Video acceleration display initialized

Product: Nimble Streamer
Component: Linux video acceleration initialization
Logging function: log_d
Log level: debug
Documentation ID: log_d-b124397ea6648c91

## Log pattern

```text
dev=%s driver:unknown va-api:%d.%d
```

## Parameters

- Argument 1 — Device: Linux render-device path being probed, text.
- Argument 2 — Major version: Video acceleration API major version, integer.
- Argument 3 — Minor version: Video acceleration API minor version, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dev=/dev/dri/renderD128 driver:unknown va-api:1.0
```

## Short description

Video acceleration display initialized.

## Trigger condition

A Linux render device opens and its video acceleration display initializes successfully. The library supplies no driver description.

## Explanation

The first working display is retained and device probing succeeds.
