# Management response send failed

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_e
Log level: error
Documentation ID: log_e-b7f713d2676e5498

## Log pattern

```text
failed to send buffer to s=%d
```

## Parameters

- Argument 1 — socket: Client socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer to s=42
```

## Short description

Management response send failed.

## Trigger condition

Sending the pending management response buffer reports failure.

## Explanation

The client requests connection shutdown and returns without the normal successful-send completion processing.

## Possible causes

- The socket send operation reported failure.

## What to check

1. Check preceding connection or TLS diagnostics.

## Recommended action

Resolve the reported connection failure before retrying the management request.
