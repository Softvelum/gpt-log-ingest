# Filter output has no name

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-cad321410f658e3f

## Log pattern

```text
failed to link unnamed filter output: %s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to link unnamed filter output: [in]anull[out]
```

## Short description

Filter output has no name.

## Trigger condition

An audio or video output endpoint has no name after its sink is created and connected.

## Explanation

Initialization fails before attaching output writers by name.

## Possible causes

- The configured filter expression leaves an unnamed output.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
