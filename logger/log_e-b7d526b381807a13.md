# Received NDI audio frame could not be forwarded

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-b7d526b381807a13

## Log pattern

```text
failed to write ndi audio frame, ndi_name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write ndi audio frame, ndi_name=HOST (Camera)
```

## Short description

Received NDI audio frame could not be forwarded.

## Trigger condition

Converting or delivering a captured NDI audio frame returns failure.

## Explanation

The captured NDI frame is released and the receive operation returns failure. Possible failing stages include unsupported sample format, invalid channel or sample data, allocation, message construction, or parent-process delivery.

## Possible causes

- Converting or delivering a captured NDI audio frame returns failure.

## What to check

1. Check preceding format messages and the parent-process frame-delivery connection.
