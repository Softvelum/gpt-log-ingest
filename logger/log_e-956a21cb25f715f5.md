# Quick Sync surface requirement query failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-956a21cb25f715f5

## Log pattern

```text
%p quick sync failed to get surface num, ret=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 quick sync failed to get surface num, ret=-3
```

## Short description

Quick Sync surface requirement query failed.

## Trigger condition

The encoder surface-requirement query returns a negative status.

## Explanation

Encoder initialization stops before the input surface pool is allocated.

## Possible causes

- The media runtime cannot determine input surface requirements for the active encoding parameters.

## What to check

1. Check the status and the finalized encoding settings.

## Recommended action

Correct the media runtime or unsupported encoding configuration and restart encoding.
