# Audio arrived without transcription configuration

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-0f454ac69607f589

## Log pattern

```text
failed to get audio config for [%s]
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get audio config for [live/news]
```

## Short description

Audio arrived without transcription configuration.

## Trigger condition

Audio arrives for a stream with no stored audio/transcription configuration.

## Explanation

Processing of the incoming audio message fails before a service connection can be created.

## Possible causes

- Audio arrives for a stream with no stored audio/transcription configuration.

## What to check

1. Check that valid audio configuration reaches the transcription process before audio.
