# SDI video converter is unavailable

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-7058d0b099199362

## Log pattern

```text
failed to find video converter for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find video converter for [live/camera]
```

## Short description

SDI video converter is unavailable.

## Trigger condition

FFmpeg cannot find its wrapped video frame encoder.

## Explanation

The current output frame operation returns failure.

## Possible causes

- The loaded FFmpeg libraries do not provide the wrapped video frame encoder.

## What to check

1. Check encoder support in the installed FFmpeg libraries.

## Recommended action

Provide the required FFmpeg encoder.
