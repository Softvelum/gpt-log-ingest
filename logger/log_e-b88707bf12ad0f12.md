# VCAS asset response cannot be interpreted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-b88707bf12ad0f12

## Log pattern

```text
failed to process VCAS createAsset url='%s' response:
%.*s
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Response length: Integer limit in bytes for the response text that follows.
- Argument 3 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process VCAS createAsset url='https://keys.example/key' response:
{}
```

## Short description

VCAS asset response cannot be interpreted.

## Trigger condition

The create-asset response fails JSON or required-field validation.

## Explanation

The application key set is erased and asset processing stops.

## Possible causes

- The create-asset response fails JSON or required-field validation.

## What to check

1. Check that the VCAS create-asset response has the expected JSON status fields.

## Recommended action

Check that the VCAS create-asset response has the expected JSON status fields.
