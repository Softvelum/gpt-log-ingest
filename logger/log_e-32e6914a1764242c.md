# RTMP or RTSP receive operation fails

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-32e6914a1764242c

## Log pattern

```text
failed to recv buffer from client: %d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv buffer from client: 42
```

## Short description

RTMP or RTSP receive operation fails.

## Trigger condition

Receiving handshake or message data reports a transport read error. RTMP reads may use either a plain socket or TLS.

## Explanation

The connection is marked shut down. Waiting for more data and ordinary plain-socket closure have separate handling.

## Possible causes

- Receiving handshake or message data reports a transport read error. RTMP reads may use either a plain socket or TLS.

## What to check

1. Check accompanying transport errors and whether the peer disconnected during handshake or streaming.

## Recommended action

Resolve the peer or network read failure before reconnecting.
