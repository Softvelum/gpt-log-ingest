# External request event refers to another socket

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-c3f542f52c8e31c9

## Log pattern

```text
requestor session p=%p event e=%x for unknown s=%d
```

## Parameters

- Argument 1 — address: Request session memory address.
- Argument 2 — events: Socket event flags in hexadecimal.
- Argument 3 — socket: Peer socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
requestor session p=0x1000 event e=1 for unknown s=12
```

## Short description

External request event refers to another socket.

## Trigger condition

The event descriptor differs from the request session peer descriptor.

## Explanation

The session is marked finished without processing the event or updating its activity time.

## Possible causes

- A socket event was delivered to a session that does not own that descriptor.

## What to check

1. Compare request socket creation and event registration.

## Recommended action

Investigate inconsistent event routing.
