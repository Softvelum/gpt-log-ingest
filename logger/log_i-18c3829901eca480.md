# SRT bonding entry points available

Product: Nimble Streamer
Component: SRT transport
Logging function: log_i
Log level: info
Documentation ID: log_i-18c3829901eca480

## Log pattern

```text
SRT bonding is supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
SRT bonding is supported
```

## Short description

SRT bonding entry points available.

## Trigger condition

The optional SRT group and endpoint-configuration entry points are successfully loaded.

## Explanation

Bonded connections can use these library facilities. This does not mean a bonded connection has been configured or established.

## Possible causes

- The optional SRT group and endpoint-configuration entry points are successfully loaded.

## What to check

1. Check bonding configuration only if multiple network paths are intended.
