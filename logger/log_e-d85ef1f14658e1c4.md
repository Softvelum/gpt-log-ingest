# SDI audio decoder allocation failed

Product: Nimble Streamer
Component: SDI device input
Logging function: log_e
Log level: error
Documentation ID: log_e-d85ef1f14658e1c4

## Log pattern

```text
failed to create audio decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create audio decoder for [live/camera]
```

## Short description

SDI audio decoder allocation failed.

## Trigger condition

Allocating the device audio decoder context returns no context.

## Explanation

The current device decoding operation returns failure.

## Possible causes

- Decoder context allocation fails.

## What to check

1. Check memory availability while the device audio decoder starts.

## Recommended action

Restore available memory and retry the input.
