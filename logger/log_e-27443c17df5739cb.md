# Advertising chunk name cannot be parsed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-27443c17df5739cb

## Log pattern

```text
failed to parse ad chunk name=%s
```

## Parameters

- Argument 1 — Chunk name: Text of the requested advertising resource name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse ad chunk name=ad_chunk_invalid.ts
```

## Short description

Advertising chunk name cannot be parsed.

## Trigger condition

An advertising chunk name fails extraction of its expected numeric chunk index.

## Explanation

The advertising chunk request is rejected with HTTP 500.

## Possible causes

- An advertising chunk name fails extraction of its expected numeric chunk index.

## What to check

1. Compare the requested chunk URL with the advertising playlist that generated it; use its unmodified resource names.

## Recommended action

Compare the requested chunk URL with the advertising playlist that generated it; use its unmodified resource names.
