# HLS segment queue remained empty

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-006f68b837353acb

## Log pattern

```text
failed to enqueue hls chunks from url='%s' media_seq=%u
```

## Parameters

- Argument 1 — url: Current origin URL.
- Argument 2 — media\_sequence: Current stored sequence after the attempted queue population.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to enqueue hls chunks from url='https://origin.example/live.m3u8' media_seq=100
```

## Short description

HLS segment queue remained empty.

## Trigger condition

The next media sequence is within the playlist range, but the queue is still empty after attempting to add segments.

## Explanation

This is an internal consistency failure in segment selection. The input requests shutdown and returns before requesting the next item.

## Possible causes

- The expected eligible segment did not result in a queued item.

## What to check

1. Check the sequence window and playlist segment list.
