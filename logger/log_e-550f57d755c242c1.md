# Protected video initialization segment is unavailable

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-550f57d755c242c1

## Log pattern

```text
failed to get fmp4 video init segment for [%s/%s]
```

## Parameters

- Argument 1 — Application: Text naming the VOD application.
- Argument 2 — Stream: Text naming the protected media stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get fmp4 video init segment for [vod/movie.mp4]
```

## Short description

Protected video initialization segment is unavailable.

## Trigger condition

A protected fragmented-MP4 video chunk cannot reserve or retrieve its initialization-segment cache item, or finds that item in a state other than ready or actively being prepared.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- A protected fragmented-MP4 video chunk cannot reserve or retrieve its initialization-segment cache item, or finds that item in a state other than ready or actively being prepared.

## What to check

1. Check initialization-segment cache allocation, generation, and cancellation before retrying the protected video chunk.

## Recommended action

Check initialization-segment cache allocation, generation, and cancellation before retrying the protected video chunk.
