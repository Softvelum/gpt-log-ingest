# RTMP socket shutdown fails

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_v
Log level: verbose
Documentation ID: log_v-7f06d406a4dba575

## Log pattern

```text
failed to shutdown s=%d (errno=%d)
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for this connection.
- Argument 2 — Error code: Operating-system socket error captured immediately after shutdown failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to shutdown s=42 (errno=9)
```

## Short description

RTMP socket shutdown fails.

## Trigger condition

Closing both directions of a plain RTMP socket fails with an error other than the ordinary not-connected case.

## Explanation

The session is marked shut down despite the operating-system shutdown failure.

## Possible causes

- Closing both directions of a plain RTMP socket fails with an error other than the ordinary not-connected case.

## What to check

1. Interpret the operating-system error and check earlier connection failures.

## Recommended action

Investigate the reported socket error; the session is already being closed.
