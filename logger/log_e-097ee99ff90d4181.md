# Required directory could not be created

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-097ee99ff90d4181

## Log pattern

```text
failed to create directory='%s' error=%d message()='%s'
```

## Parameters

- Argument 1 — Directory: Requested temporary or DVR archive directory path, text.
- Argument 2 — Filesystem error: Filesystem error-code value, integer.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

Temporary and DVR creation share this pattern but have different recovery behavior.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create directory='/var/lib/nimble/archive' error=13 message()='operation failed'
```

## Short description

Required directory could not be created.

## Trigger condition

Creating a missing temporary directory or DVR archive directory fails. Temporary-path handling requires a nonzero filesystem error; the DVR branches treat any unsuccessful creation as failure.

## Explanation

System temporary-directory failure leads to a cache-directory attempt. Cache temporary-directory failure returns an empty path. DVR directory failure rejects the current segment before saving its data.

## Possible causes

- The requested directory cannot be created by the filesystem operation.

## What to check

1. Check the reported directory, filesystem error, and access to its parent directories.

## Recommended action

Restore writable directory access.
