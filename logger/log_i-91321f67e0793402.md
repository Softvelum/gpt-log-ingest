# Whisper transcription stream created

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_i
Log level: info
Documentation ID: log_i-91321f67e0793402

## Log pattern

```text
whisper transcriber created for [%s] lang=%s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Language: Configured language identifier for this transcription process; it may differ from the effective detected language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whisper transcriber created for [live/news] lang=en
```

## Short description

Whisper transcription stream created.

## Trigger condition

The child process is started successfully for a newly requested stream language.

## Explanation

The transcription stream is retained and audio configuration and data can be queued before its local connection is established.

## Possible causes

- The child process is started successfully for a newly requested stream language.

## What to check

1. Check for the matching process connection and model initialization messages.
