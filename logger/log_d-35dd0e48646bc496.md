# Icecast advertisement is waiting for download

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-35dd0e48646bc496

## Log pattern

```text
waiting %d sec for content id=%s uri='%s'
```

## Parameters

- Argument 1 — Wait seconds: Integer configured wait interval in seconds.
- Argument 2 — Content ID: Text identifying the advertising content.
- Argument 3 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waiting 5 sec for content id=ad-01 uri='https://media.example/ad.mp4'
```

## Short description

Icecast advertisement is waiting for download.

## Trigger condition

The scheduled advertisement is not ready, is remote, has a nonempty URI, and has a positive allowed wait.

## Explanation

Advertising sample selection returns a waiting result instead of skipping or ending the session.

## Possible causes

- The scheduled advertisement is not ready, is remote, has a nonempty URI, and has a positive allowed wait.

## What to check

1. Check the download state if the advertisement does not become ready within its allowed wait.

## Recommended action

Check the download state if the advertisement does not become ready within its allowed wait.
