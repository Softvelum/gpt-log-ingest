# Cannot install TLS server-name callback

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_e
Log level: error
Documentation ID: log_e-110f8c0c01cd1770

## Log pattern

```text
SSL_CTX_set_tlsext_servername_callback() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
SSL_CTX_set_tlsext_servername_callback() failed
```

## Short description

Cannot install TLS server-name callback.

## Trigger condition

After installing multiple certificate contexts, the TLS library rejects installing the SNI callback on the default context.

## Explanation

The reload still returns success, but hostname-based certificate switching through that callback is not installed.

## Possible causes

- After installing multiple certificate contexts, the TLS library rejects installing the SNI callback on the default context.

## What to check

1. Check that clients receive the intended certificate for each configured hostname.
