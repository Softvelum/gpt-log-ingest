# WebSocket text output exceeds its supported length

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-6887ac213f555020

## Log pattern

```text
websocket messages len > 64K not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

WebSocket text output exceeds its supported length.

## Trigger condition

A generated text message is longer than 65,535 bytes.

## Explanation

Text framing fails and the caller cannot send the response. This limit applies to the text builder, not the fragmented binary media output path.

## Possible causes

- A generated text message is longer than 65,535 bytes.

## What to check

1. Check the generated status or time message size.

## Recommended action

Reduce the text response to the supported length.
