# AAC channel mode failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-2b69ac590e66a36c

## Log pattern

```text
failed to set channel_mode=%d, status=%d
```

## Parameters

- Argument 1 — Mode: FDK channel-mode identifier, integer.
- Argument 2 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set channel_mode=2, status=1
```

## Short description

AAC channel mode failed.

## Trigger condition

In an FDK-enabled build, applying the mapped channel mode returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected channel mode for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in channel mode.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
