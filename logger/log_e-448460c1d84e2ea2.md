# Origin connection returned an invalid socket

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-448460c1d84e2ea2

## Log pattern

```text
invalid s=%d after connecting to origin='%s:%d'
```

## Parameters

- Argument 1 — Origin socket: Integer nonpositive origin descriptor.
- Argument 2 — Origin hostname: Text hostname without the port.
- Argument 3 — Origin port: Integer TCP port.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid s=-1 after connecting to origin='media.example:443'
```

## Short description

Origin connection returned an invalid socket.

## Trigger condition

An origin connect reports in-progress but the resulting descriptor is zero or negative.

## Explanation

The connection setup fails; the client path prepares HTTP 500 and download paths return failure.

## Possible causes

- An origin connect reports in-progress but the resulting descriptor is zero or negative.

## What to check

1. Check nearby socket creation and connection errors and available file descriptors.

## Recommended action

Check nearby socket creation and connection errors and available file descriptors.
