# Selected rules file

Product: Nimble Streamer
Component: Server startup
Logging function: log_i
Log level: info
Documentation ID: log_i-e915b395ca4040a6

## Log pattern

```text
Using rules file:  %s
```

## Parameters

- Argument 1 — File name: Text containing the selected rules file name or path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Using rules file:  /etc/nimble/rules.conf
```

## Short description

Selected rules file.

## Trigger condition

Configuration loading and the startup registration check have succeeded.

## Explanation

Reports the selected rules file name before background mode and server execution begin. This message alone does not establish that every configured service will initialize successfully.

## What to check

1. Confirm that the selected rules file is the intended one.
