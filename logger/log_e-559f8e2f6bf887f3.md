## Short description

WHIP initial session request send returned zero.

## Trigger condition

The first control-socket send of a newly serialized WHIP session request returns zero.

## Explanation

The control socket is closed, pending starts are marked finished, pending data is cleared, and active WHIP publications are removed and their stream registrations released. The current new session is also marked finished and loses its authorization record.

## Possible causes

- The helper control connection cannot accept the session request.

## What to check

1. Check whether the WHIP helper disconnected during session creation.

## Recommended action

Restore the helper connection and retry the publication.
