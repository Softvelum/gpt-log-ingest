# No Quick Sync decoder surface is free

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-9a97a094e736f6cd

## Log pattern

```text
failed to get free surface for decoder
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

No Quick Sync decoder surface is free.

## Trigger condition

All 17 decoder surfaces are still locked when another packet needs a surface.

## Explanation

The packet-writing operation returns failure without submitting another decode operation.

## Possible causes

- Outstanding decoding work retains every surface in the fixed output pool.

## What to check

1. Check preceding decoder or synchronization errors and whether the device is making progress.

## Recommended action

Resolve the stalled media operation and restart the affected decoder.
