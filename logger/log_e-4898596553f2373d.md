# Could not create the HTTP/3 request worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-4898596553f2373d

## Log pattern

```text
failed to create quic worker thread %d
```

## Parameters

- Argument 1 — Worker index: Zero-based index of the worker whose creation failed.

The index is passed as the platform size type to an int conversion, so the types can differ.

## Log examples

No reliable example is supplied because the worker index type can be wider than its conversion.

## Short description

Could not create the HTTP/3 request worker.

## Trigger condition

HTTP/3 support is included and needed by the TLS configuration; a configured HTTP/3 worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the HTTP/3 request worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed HTTP/3 request worker.
