# CPIX provider response processing failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-5224ef406be6a11e

## Log pattern

```text
[drm] %s response processing failed for='%s':
%.*s
```

## Parameters

- Argument 1 — Provider: Text naming the DRM provider.
- Argument 2 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 3 — Response length: Integer limit in bytes for the response text that follows.
- Argument 4 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine response processing failed for='live/camera':
{}
```

## Short description

CPIX provider response processing failed.

## Trigger condition

The selected provider parser cannot process its key response.

## Explanation

The affected key slot is marked failed and waiting consumers are notified.

## Possible causes

- The selected provider parser cannot process its key response.

## What to check

1. Check the provider response format and any preceding parsing or validation error.

## Recommended action

Check the provider response format and any preceding parsing or validation error.
