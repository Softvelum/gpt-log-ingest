# Network receive failed

Product: Nimble Streamer
Component: Network input receive
Logging function: log_e
Log level: error
Documentation ID: log_e-9d4e2179741d7d1a

## Log pattern

```text
recv error=%d on s=%d
```

## Parameters

- Argument 1 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.
- Argument 2 — Socket: Socket descriptor, integer; no unit.

QUIC, checker, and MPEG-TS occurrences use POSIX errno. Zixi uses the platform socket-error value, including Windows socket codes on Windows.

## Log examples

Illustrative examples; these are not captured server logs.

```text
recv error=5 on s=12
```

## Short description

Network receive failed.

## Trigger condition

A receive operation returns a hard error rather than a would-block condition.

## Explanation

QUIC returns from the current listener event; the stream availability checker shuts down its current connection; MPEG-TS UDP and Zixi media inputs return failure to their callers.

## Possible causes

- The operating system reports a receive error on the affected connection or datagram socket.

## What to check

1. Use the error code and socket context to identify whether this concerns QUIC, stream checking, UDP ingest, or Zixi ingest.

## Recommended action

Correct the reported transport error and restore the affected connection or input.
