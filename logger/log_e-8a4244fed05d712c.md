# Socket address family is unsupported

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-8a4244fed05d712c

## Log pattern

```text
GetAddrIp. unexpected addr family=%d
```

## Parameters

- Argument 1 — Address family: Operating system address-family identifier, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
GetAddrIp. unexpected addr family=1
```

## Short description

Socket address family is unsupported.

## Trigger condition

An address is neither IPv4 nor IPv6 during conversion to display text.

## Explanation

The address conversion returns empty text.

## Possible causes

- The supplied socket address uses an unexpected family.

## What to check

1. Check which address family was passed to the socket-address conversion.

## Recommended action

Use an IPv4 or IPv6 address.
