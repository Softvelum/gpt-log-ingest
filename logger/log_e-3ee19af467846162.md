# Configuration file could not be opened

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-3ee19af467846162

## Log pattern

```text
unable to open config file: '%s'
```

## Parameters

- Argument 1 — File: Requested file path, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unable to open config file: '/var/lib/nimble/example.xml'
```

## Short description

Configuration file could not be opened.

## Trigger condition

The supplied or default configuration file cannot be opened for input.

## Explanation

The load operation returns failure without parsing lines.

## Possible causes

- The configuration file is missing or cannot be read.

## What to check

1. Check the logged file path and read access.

## Recommended action

Restore the configuration file or its read access.
