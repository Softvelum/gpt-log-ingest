## Short description

WHEP initial session request send returned zero.

## Trigger condition

The first control-socket send of a WHEP session-start request returns zero.

## Explanation

The new session is marked finished. The helper control socket and pending output are cleared, pending starts are marked finished, and unclassified accepted sockets are removed. Playback sockets already assigned to media workers are not directly closed by this cleanup.

## Possible causes

- The helper control connection cannot accept the request.

## What to check

1. Check whether the WHEP helper disconnected during negotiation.

## Recommended action

Restore the helper and retry playback.
