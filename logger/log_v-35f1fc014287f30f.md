# Child process reached a reported terminal state

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_v
Log level: verbose
Documentation ID: log_v-35f1fc014287f30f

## Log pattern

```text
pid=%d is exited status=%d
```

## Parameters

- Argument 1 — Process: Integer task process identifier.
- Argument 2 — Exit status: Exit-status field extracted from the process wait result; meaningful as an exit code only when normal exit is indicated.

## Log examples

Illustrative examples; these are not captured server logs.

```text
pid=1234 is exited status=0
```

## Short description

Child process reached a reported terminal state.

## Trigger condition

A nonblocking process wait returns a positive process identifier with an exited, stopped or signaled state. Available only on Linux builds.

## Explanation

The managed task table is searched next. The printed status field is meaningful as an exit code only for normal exit.
