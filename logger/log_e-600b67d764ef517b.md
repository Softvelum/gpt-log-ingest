# Reserved packaging output is missing

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-600b67d764ef517b

## Log pattern

```text
cache item not found key='%s'
```

## Parameters

- Argument 1 — Output cache key: Text cache key reserved for the requested generated output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item not found key='/vod/movie.mp4/n_0_0_0.ts'
```

## Short description

Reserved packaging output is missing.

## Trigger condition

A VOD or DVR packaging worker starts a request but cannot retrieve its reserved output cache item.

## Explanation

The worker returns without generating the requested output.

## Possible causes

- A VOD or DVR packaging worker starts a request but cannot retrieve its reserved output cache item.

## What to check

1. Check output-cache removal or cancellation between request submission and worker processing.

## Recommended action

Check output-cache removal or cancellation between request submission and worker processing.
