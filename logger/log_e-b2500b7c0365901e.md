# Playlist media timing origin reset

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-b2500b7c0365901e

## Log pattern

```text
ServerBlockProcessor: dts/steady delta is reset for vod file url=[%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: dts/steady delta is reset for vod file url=[/media/program.mp4]
```

## Short description

Playlist media timing origin reset.

## Trigger condition

Elapsed decode time differs from elapsed monotonic clock time by at least two seconds in either direction.

## Explanation

The timing origin and metadata resend timer are reset; the current packet is retained and playback waits 20 milliseconds.

## Possible causes

- Elapsed decode time differs from elapsed monotonic clock time by at least two seconds in either direction.

## What to check

1. Check source timestamp continuity and processing delays if timing resets recur.

## Recommended action

Check source timestamp continuity and processing delays if timing resets recur.
