# SRT output send failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-830694f973a7e7eb

## Log pattern

```text
failed to send s=%d '%s:%d' errno=%d: %s
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.
- Argument 2 — Address: Configured endpoint address.
- Argument 3 — Port: Configured endpoint port number.
- Argument 4 — Error number: SRT library error code.
- Argument 5 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send s=101 '192.0.2.20:9000' errno=2001: Connection was broken
```

## Short description

SRT output send failed.

## Trigger condition

A regular or grouped SRT send fails with an error other than asynchronous-send-wait.

## Explanation

The send operation returns failure. Ordinary backpressure takes a separate path that retains unsent output and waits for readiness.

## Possible causes

- A regular or grouped SRT send fails with an error other than asynchronous-send-wait.

## What to check

1. Check the endpoint and SRT error.
