# Internal HTTP request reached its custom timeout

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-80d3069c875da5e7

## Log pattern

```text
requestor session url='%s' timeout=%u expired
```

## Parameters

- Argument 1 — URL: Requested resource URL as text.
- Argument 2 — Timeout: Configured request-session timeout in milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
requestor session url='https://origin.example/media' timeout=5000 expired
```

## Short description

Internal HTTP request reached its custom timeout.

## Trigger condition

The steady-clock deadline of a request session has passed during the custom-timeout scan.

## Explanation

The request session is deleted. The scan normally checks at intervals of at least 100 milliseconds.

## Possible causes

- The request session remained active beyond its configured deadline.

## What to check

1. Compare the request completion time with its configured timeout.
