# Origin read reported end of connection

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-cd941c3b33c142b6

## Log pattern

```text
connection closed by origin s=%d
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed by origin s=17
```

## Short description

Origin read reported end of connection.

## Trigger condition

An origin response read reaches the zero-byte closure branch in an HTTP client, cache downloader, or advertising downloader.

## Explanation

Downloaders finish; the HTTP client may forward a parseable close-delimited response, follow a redirect, or stop an incomplete response.

## Possible causes

- An origin response read reaches the zero-byte closure branch in an HTTP client, cache downloader, or advertising downloader.

## What to check

1. If media is incomplete, compare declared Content-Length with the received body and check why the origin closed the connection.

## Recommended action

If media is incomplete, compare declared Content-Length with the received body and check why the origin closed the connection.
