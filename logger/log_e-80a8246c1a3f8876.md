# Child process did not start

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-80a8246c1a3f8876

## Log pattern

```text
failed to start process '%s'
```

## Parameters

- Argument 1 — Command: Command supplied for launching the child, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start process 'nimble_transcoder'
```

## Short description

Child process did not start.

## Trigger condition

No child handle is obtained after launch, or the transcription worker receives a missing child handle from its launch helper.

## Explanation

The caller reports startup failure.

## Possible causes

- The launch helper did not create a usable child process.

## What to check

1. Check the command and preceding process-launch exception.

## Recommended action

Resolve the child launch failure.
