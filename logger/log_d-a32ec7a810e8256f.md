# SLDP advances to another advertising item

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-a32ec7a810e8256f

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d next advertising content
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 next advertising content
```

## Short description

SLDP advances to another advertising item.

## Trigger condition

After skipping an item or reaching an unusable content start, selecting the next due item succeeds.

## Explanation

The sender moves to loading that next item. This log does not yet establish load success.

## Possible causes

- After skipping an item or reaching an unusable content start, selecting the next due item succeeds.

## What to check

1. Check subsequent content loading and start messages.

## Recommended action

No action is required for an expected next advertisement.
