# AJA output format description is invalid

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-1794c1f911144253

## Log pattern

```text
Invalid output format descriptor for device '%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Invalid output format descriptor for device 'AJA device'
```

## Short description

AJA output format description is invalid.

## Trigger condition

The runtime cannot construct a valid descriptor for the selected video and pixel formats.

## Explanation

Video setup stops before enabling the channel or changing hardware formats.

## Possible causes

- The runtime cannot construct a valid descriptor for the selected video and pixel formats.

## What to check

1. Check the selected video and frame-buffer format combination.

## Recommended action

Use a valid format combination.
