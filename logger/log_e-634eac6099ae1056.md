# Cannot open DVB subtitle decoder

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-634eac6099ae1056

## Log pattern

```text
failed to open dvb subtitle decoder for [%s]: %s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Error: Media-library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open dvb subtitle decoder for [live/news]: Invalid argument
```

## Short description

Cannot open DVB subtitle decoder.

## Trigger condition

Opening the allocated DVB subtitle decoder fails.

## Explanation

Initialization stops and the subtitle decode returns failure.

## Possible causes

- Opening the allocated DVB subtitle decoder fails.

## What to check

1. Read the media-library error text and check decoder availability.
