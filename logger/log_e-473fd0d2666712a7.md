# Encrypted stream-check request send failed

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-473fd0d2666712a7

## Log pattern

```text
failed to send to s=%d (sslerr=%d e='%s') task='%s'
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — TLS error: TLS operation error category.
- Argument 3 — detail: Text for an error taken from the TLS error queue.
- Argument 4 — task: Panel-supplied stream-check task identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send to s=12 (sslerr=5 e='error:00000000:lib(0)::reason(0)') task='check-a'
```

## Short description

Encrypted stream-check request send failed.

## Trigger condition

A TLS write returns zero or a nonretryable negative result.

## Explanation

The task starts shutdown. TLS requests to wait for reading or writing are handled separately and do not produce this message.

## Possible causes

- The encrypted connection closed or TLS could not send the request.

## What to check

1. Check the TLS error category and origin connection state.

## Recommended action

Resolve the TLS or origin connection problem.
