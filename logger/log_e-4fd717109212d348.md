# Playlist content download could not start

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-4fd717109212d348

## Log pattern

```text
failed to request content url='%s'
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to request content url='/media/program.mp4'
```

## Short description

Playlist content download could not start.

## Trigger condition

Initializing a newly reserved remote content download fails.

## Explanation

The cache observer is removed and the content is not entered into pending downloads.

## Possible causes

- Initializing a newly reserved remote content download fails.

## What to check

1. Check the remote content destination and media-cache request processing.

## Recommended action

Check the remote content destination and media-cache request processing.
