# RTSP input connection destroyed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-85c7038dc68d610f

## Log pattern

```text
rtsp close, s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtsp close, s=25
```

## Short description

RTSP input connection destroyed.

## Trigger condition

The RTSP input connection is being destroyed.

## Explanation

Associated UDP media connections are shut down, parsed media tracks are deleted, and the live stream is unregistered. The message alone does not establish why destruction began.

## Possible causes

- The RTSP input connection is being destroyed.

## What to check

1. Check earlier messages for the connection shutdown reason.
