# Requested DVR subtitle track does not exist

Product: Nimble Streamer
Component: DVR
Logging function: log_v
Log level: verbose
Documentation ID: log_v-f77605f25dc84876

## Log pattern

```text
no segments to export for '%s' track=%d
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Track index: Zero-based requested subtitle track index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no segments to export for 'live/camera' track=2
```

## Short description

Requested DVR subtitle track does not exist.

## Trigger condition

The requested numeric track is outside the available language list or has no language entry.

## Explanation

The export returns HTTP 404.

## Possible causes

- The requested numeric track is outside the available language list or has no language entry.

## What to check

1. Select an available subtitle track for the recording.

## Recommended action

Select an available subtitle track for the recording.
