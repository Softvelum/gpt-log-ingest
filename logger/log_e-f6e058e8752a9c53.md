# NVIDIA input buffer allocation failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-f6e058e8752a9c53

## Log pattern

```text
failed to create input buffer encoder=%p, status=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create input buffer encoder=0x12340000, status=8
```

## Short description

NVIDIA input buffer allocation failed.

## Trigger condition

Creating a lazily allocated input buffer, aligned to 32 pixels in each dimension, returns an error.

## Explanation

The current frame write returns failure.

## Possible causes

- The NVIDIA encoder API rejects this buffer or picture operation.

## What to check

1. Check GPU/session resources and the selected input format and dimensions.

## Recommended action

Correct the reported driver/resource or encoder-state problem before retrying.
