# Cannot enable SRT timestamp-based delivery

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-7cf212611a7c2d5d

## Log pattern

```text
failed to set tsbpd mode s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set tsbpd mode s=100
```

## Short description

Cannot enable SRT timestamp-based delivery.

## Trigger condition

The SRT library rejects enabling timestamp-based packet delivery on a new socket.

## Explanation

The socket is closed and creation fails.

## Possible causes

- The SRT library rejects enabling timestamp-based packet delivery on a new socket.

## What to check

1. Check the SRT library diagnostics and socket option support.
