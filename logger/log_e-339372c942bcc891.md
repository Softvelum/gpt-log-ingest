# Codec is unsupported by native Quick Sync decoding

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-339372c942bcc891

## Log pattern

```text
unsupported quicksync codec=%d
```

## Parameters

- Argument 1 — Codec: FFmpeg codec identifier, integer enumeration value; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported quicksync codec=167
```

## Short description

Codec is unsupported by native Quick Sync decoding.

## Trigger condition

The packet-writing path receives a codec other than H.264, HEVC, VP8, or VP9.

## Explanation

The video packet is rejected before decoding.

## Possible causes

- The configured input codec is outside the native Quick Sync decoder dispatch list.

## What to check

1. Check the numeric FFmpeg codec identifier and selected decoder.

## Recommended action

Choose a decoder that supports the input codec.
