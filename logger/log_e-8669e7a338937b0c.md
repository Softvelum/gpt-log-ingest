# SRT publisher stream ID required

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-8669e7a338937b0c

## Log pattern

```text
srt streamid must be set for [%s:%d] since %s specified. socket=%d
```

## Parameters

- Argument 1 — Address: Configured endpoint address.
- Argument 2 — Port: Configured endpoint port number.
- Argument 3 — Option: Password-path option requiring stream-ID processing.
- Argument 4 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt streamid must be set for [0.0.0.0:9000] since nimble-srt-password-path specified. socket=101
```

## Short description

SRT publisher stream ID required.

## Trigger condition

The password-path option is present but the accepted socket stream ID is empty.

## Explanation

The accepted socket is closed; this also applies when the option value is none.

## Possible causes

- The password-path option is present but the accepted socket stream ID is empty.

## What to check

1. Check the publisher stream-ID setting.

## Recommended action

Supply the required application/stream identifier.
