# Video filter fell behind its input buffer

Product: Nimble Streamer
Component: Video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-0da9927050d7dd0a

## Log pattern

```text
failed to filter video in appropriate rate, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Configured filter identifier, text.
- Argument 2 — Input: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to filter video in appropriate rate, filter=overlay1, stream=live/overlay
```

## Short description

Video filter fell behind its input buffer.

## Trigger condition

Reading a filter input reports that its reader is too slow and the required frame is no longer retained.

## Explanation

Filtering returns failure and the worker stops; this path does not reset its read position.

## Possible causes

- Filter processing or its output consumers cannot keep pace with incoming frames.

## What to check

1. Check filter complexity, input rates, and host or GPU load.

## Recommended action

Reduce processing demand or restore consumer throughput and restart the filter.
