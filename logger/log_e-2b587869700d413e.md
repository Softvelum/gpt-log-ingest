# Icecast advertisement skipped after reader failure

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-2b587869700d413e

## Log pattern

```text
skip advertising content on error id=%s uri=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip advertising content on error id=ad-01 uri=https://media.example/ad.mp4
```

## Short description

Icecast advertisement skipped after reader failure.

## Trigger condition

The advertisement is ready but an audio reader cannot be created.

## Explanation

The pending advertisement entry is removed and selection continues.

## Possible causes

- The advertisement is ready but an audio reader cannot be created.

## What to check

1. Check that the advertisement has supported, readable audio.

## Recommended action

Check that the advertisement has supported, readable audio.
