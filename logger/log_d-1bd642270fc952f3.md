# DVR thumbnail has no matching video segment

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_d
Log level: debug
Documentation ID: log_d-1bd642270fc952f3

## Log pattern

```text
missing video segment for thumbnail str='%s/%s' offset=%llu size=%u t=%d p=%u st=%llu dbof=%u
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — File offset: Unsigned 64-bit byte offset within the media storage file.
- Argument 4 — Segment bytes: Unsigned segment size in bytes.
- Argument 5 — Segment type: Integer category: 0 video initialization, 1 audio initialization, 2 video, 3 audio, 4 shared data file, 5 JPEG, 6 DVB subtitles, 7 KLV metadata, 8 WebVTT.
- Argument 6 — Current archive period: Unsigned current archive period field; this may differ from the period being loaded.
- Argument 7 — Media start: Unsigned 64-bit media start timestamp in the segment track timescale.
- Argument 8 — Database offset: Unsigned byte offset of the segment record in its database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
missing video segment for thumbnail str='live/camera' offset=1024 size=65536 t=2 p=1 st=90000 dbof=512
```

## Short description

DVR thumbnail has no matching video segment.

## Trigger condition

Loading a JPEG thumbnail finds no corresponding video segment at its media start.

## Explanation

The thumbnail entry remains loaded, but no video segment is marked as having that thumbnail.

## Possible causes

- Loading a JPEG thumbnail finds no corresponding video segment at its media start.

## What to check

1. Check whether the matching recorded video segment was removed or absent from the database.

## Recommended action

Check whether the matching recorded video segment was removed or absent from the database.
