# Released TLS context absent from cache

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_e
Log level: error
Documentation ID: log_e-1517a916dcb259b5

## Log pattern

```text
SSL_ctx p=%p is not found in cache
```

## Parameters

- Argument 1 — Context: Address of the TLS library context being released.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SSL_ctx p=0x12345000 is not found in cache
```

## Short description

Released TLS context absent from cache.

## Trigger condition

A context release cannot find the given TLS context in either active or retired caches.

## Explanation

The release reports failure without freeing an unknown context.

## Possible causes

- A context release cannot find the given TLS context in either active or retired caches.

## What to check

1. Check for duplicate release or a context that was never registered in this cache.
