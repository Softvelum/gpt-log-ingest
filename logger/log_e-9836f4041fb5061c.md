# NVIDIA decoder flush failed

Product: Nimble Streamer
Component: NVIDIA video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-9836f4041fb5061c

## Log pattern

```text
failed to flush decoder for [%s], res=%d
```

## Parameters

- Argument 1 — Stream: Input stream name, text.
- Argument 2 — CUDA status: CUDA or NVIDIA video-decoder driver result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to flush decoder for [live/camera], res=2
```

## Short description

NVIDIA decoder flush failed.

## Trigger condition

Sending an end-of-stream packet to the NVIDIA parser returns an error.

## Explanation

Flushing stops before processing the remaining display-frame queue.

## Possible causes

- The parser rejects the end-of-stream operation or fails while draining decoding.

## What to check

1. Check the driver status and preceding decoding errors.

## Recommended action

Correct the decoder failure before restarting the stream.
