# RTSP output fragment could not be buffered

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-f66e95444325c1b8

## Log pattern

```text
failed to append buffer to client: %d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to append buffer to client: 25
```

## Short description

RTSP output fragment could not be buffered.

## Trigger condition

Appending an output fragment to the RTSP connection buffer fails.

## Explanation

The append operation returns failure to its caller; this call does not itself start shutdown. The output buffer is limited to four MiB.

## Possible causes

- Appending an output fragment to the RTSP connection buffer fails.

## What to check

1. Check the fragment size and already queued output data.
