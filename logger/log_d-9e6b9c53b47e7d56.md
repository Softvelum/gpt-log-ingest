# RTMP input worker stopped

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-9e6b9c53b47e7d56

## Log pattern

```text
RTMPCameraWorkerThread(%s) stopped
```

## Parameters

- Argument 1 — worker: Configured worker thread name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
RTMPCameraWorkerThread(rtmpcam0) stopped
```

## Short description

RTMP input worker stopped.

## Trigger condition

The worker observes exit and deletes its assigned input connections.

## Explanation

The event loop has ended and the worker returns.
