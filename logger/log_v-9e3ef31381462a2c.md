# Managed task process created

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_v
Log level: verbose
Documentation ID: log_v-9e3ef31381462a2c

## Log pattern

```text
started task id=%s pid=%d command='%s' outfd=%d
```

## Parameters

- Argument 1 — Task identifier: Text identifying the managed task.
- Argument 2 — Process: Integer task process identifier.
- Argument 3 — Command: Configured shell command text.
- Argument 4 — Output descriptor: Integer descriptor used by Nimble to read the task output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
started task id=task1 pid=1234 command='echo ready' outfd=12
```

## Short description

Managed task process created.

## Trigger condition

The shell subprocess was created successfully. Available only on Linux builds.

## Explanation

Its output pipe is made nonblocking and added to event monitoring next. This message precedes completion of task startup.
