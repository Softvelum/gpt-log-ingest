# NDI receiver stopped after its source disappeared

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-b7527187e830eab3

## Log pattern

```text
ndi receiver stopped,  ndi_name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ndi receiver stopped,  ndi_name=HOST (Camera)
```

## Short description

NDI receiver stopped after its source disappeared.

## Trigger condition

The current receiver name is absent from the newly discovered source list.

## Explanation

The receiver is destroyed and its name cleared. Discovery then searches again for the requested source.

## Possible causes

- The current receiver name is absent from the newly discovered source list.

## What to check

1. Check whether the previously selected NDI source remains advertised.
