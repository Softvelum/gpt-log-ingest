# DRMToday login response accepted

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-c115bf696d62c8b5

## Log pattern

```text
[drm] response for='%s' from DRMToday login server: %s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — HTTP response details: Text containing the HTTP status and optional response body; empty when no response parser exists.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] response for='live/camera' from DRMToday login server: status=503 body='unavailable'
```

## Short description

DRMToday login response accepted.

## Trigger condition

The login response is HTTP 201 and contains a nonempty Location.

## Explanation

The returned login URL is used to request a CAS ticket.

## Possible causes

- The login response is HTTP 201 and contains a nonempty Location.
