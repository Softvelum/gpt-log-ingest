# Scenario connection listener is ready

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_i
Log level: info
Documentation ID: log_i-9acf992c70381e0d

## Log pattern

```text
remote_transcoder interface listening %s:%d
```

## Parameters

- Argument 1 — Address: Assigned loopback IP address, text.
- Argument 2 — Port: Assigned TCP port, integer port number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remote_transcoder interface listening 127.0.0.1:45000
```

## Short description

Scenario connection listener is ready.

## Trigger condition

The loopback listener is created and its automatically assigned address and port are retrieved.

## Explanation

Child processes can be started with this parent connection endpoint.
