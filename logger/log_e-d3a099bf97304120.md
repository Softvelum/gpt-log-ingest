# RTMP audio metadata cannot be generated

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-d3a099bf97304120

## Log pattern

```text
cannot fill id3 audio info(%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot fill id3 audio info(live/camera)
```

## Short description

RTMP audio metadata cannot be generated.

## Trigger condition

The parsed metadata cannot be serialized into the audio metadata buffer.

## Explanation

The existing audio metadata buffer has been reset, and this metadata handler fails before updating resolution and bandwidth. Normal AMF0 dispatch does not propagate this failure; probed-message replay does.

## Possible causes

- The parsed metadata cannot be serialized into the audio metadata buffer.

## What to check

1. Check earlier metadata decoding errors and whether the metadata payload fits available buffer capacity.

## Recommended action

Correct malformed or excessive metadata and inspect buffer-allocation failures.
