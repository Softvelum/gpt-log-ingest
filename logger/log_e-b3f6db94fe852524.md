# RTMP result has no recognized pending command

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error

## Log pattern


Illustrative examples; these are not captured server logs.

## Short description

RTMP result has no recognized pending command.

## Trigger condition

An outbound pull or publish connection receives _result with a transaction ID that does not identify a pending connect or createStream command.

## Explanation

The response cannot be matched to the connection setup sequence, so processing fails and the connection is stopped.

## Possible causes

- An outbound pull or publish connection receives _result with a transaction ID that does not identify a pending connect or createStream command.

## What to check

1. Compare response transaction IDs with the outstanding connect and createStream requests.

## Recommended action

Correct mismatched, duplicate, or out-of-sequence responses at the remote endpoint.
