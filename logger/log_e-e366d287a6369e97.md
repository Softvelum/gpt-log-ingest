# GPU encoder query disabled automatic assignment

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-e366d287a6369e97

## Log pattern

```text
failed to get encoder utilization, gpu=%d, err=%d, nvenc gpu auto assigning disabled
```

## Parameters

- Argument 1 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 2 — Management status: NVIDIA management-library result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get encoder utilization, gpu=0, err=3, nvenc gpu auto assigning disabled
```

## Short description

GPU encoder query disabled automatic assignment.

## Trigger condition

A startup probe for encoder utilization returns a management-library error.

## Explanation

The temporary GPU mapping is cleared and automatic load-based assignment is not enabled; other context initialization may continue.

## Possible causes

- The selected device or driver cannot provide encoder utilization.

## What to check

1. Check the management status and whether the device supports utilization reporting.

## Recommended action

Restore utilization reporting or explicitly select a GPU.
