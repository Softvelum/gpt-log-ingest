# Released cache fragment unmapped

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-142f76e86029fe90

## Log pattern

```text
close fr=%u key='%s'
```

## Parameters

- Argument 1 — fragment: Zero-based fragment index.
- Argument 2 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
close fr=0 key='movie'
```

## Short description

Released cache fragment unmapped.

## Trigger condition

A fragment loses its last reference and immediate unmapping was requested.

## Explanation

The fragment file mapping and handle are closed; its stored fragment remains in the cache.
