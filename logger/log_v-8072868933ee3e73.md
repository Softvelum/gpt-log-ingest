# Remote fragment is already available

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-8072868933ee3e73

## Log pattern

```text
item key='%s' fragment index=%u is already available
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — fragment: Zero-based fragment index.

The fragment index is a platform-sized value passed to a 32-bit unsigned conversion.

## Log examples

No portable example is provided for the mismatched fragment-index conversion.

## Short description

Remote fragment is already available.

## Trigger condition

The requested fragment is already marked available after allocation checks.

## Explanation

The request reports that data is ready without starting an origin download.
