# Advertising redirect limit exceeded

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-b685f48213c1e239

## Log pattern

```text
max redirect count reached, uri=%s
```

## Parameters

- Argument 1 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
max redirect count reached, uri=https://media.example/ad.mp4
```

## Short description

Advertising redirect limit exceeded.

## Trigger condition

An advertising download attempts a fourth redirect; the permitted maximum is three.

## Explanation

The download is marked finished before opening the next destination.

## Possible causes

- An advertising download attempts a fourth redirect; the permitted maximum is three.

## What to check

1. Remove redirect loops or shorten the content redirect chain to at most three redirects.

## Recommended action

Remove redirect loops or shorten the content redirect chain to at most three redirects.
