# MP4 thumbnail exceeds its available buffer

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-7607e1e876fd0ac5

## Log pattern

```text
cannot allocate mp4 thumbnail for [%s/%s], thumbnail size=%u
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.
- Argument 3 — Thumbnail size: Calculated MP4 preview-segment size in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot allocate mp4 thumbnail for [live/camera], thumbnail size=67108865
```

## Short description

MP4 thumbnail exceeds its available buffer.

## Trigger condition

A scheduled key-frame thumbnail cannot reserve the calculated MP4 preview size in a buffer capped at 64 MiB.

## Explanation

The MP4 thumbnail is not updated, and this invocation returns before JPEG thumbnail processing.

## Possible causes

- A scheduled key-frame thumbnail cannot reserve the calculated MP4 preview size in a buffer capped at 64 MiB.

## What to check

1. Check calculated preview size, key-frame size, and memory availability.

## Recommended action

Reduce oversized thumbnail input or resolve allocation pressure.
