# RTMP status code cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-bf3f210a81667e43

## Log pattern

```text
cannot process AMF. get code
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process AMF. get code
```

## Short description

RTMP status code cannot be decoded.

## Trigger condition

The code field of a connect result, play status, or publish status cannot be read as an AMF string.

## Explanation

The response handler fails and stops connection processing instead of accepting the requested connect, play, or publish operation.

## Possible causes

- The code field of a connect result, play status, or publish status cannot be read as an AMF string.

## What to check

1. Inspect the code field type and available bytes in the remote status object.

## Recommended action

Have the remote endpoint return a correctly encoded string status code.
