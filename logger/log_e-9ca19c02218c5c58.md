# SLDP requested stream name is empty

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-9ca19c02218c5c58

## Log pattern

```text
viewer tries to play empty name
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
viewer tries to play empty name
```

## Short description

SLDP requested stream name is empty.

## Trigger condition

A requested Play stream has an empty decoded stream name.

## Explanation

The Play request fails before this stream can be selected and the caller closes the connection.

## Possible causes

- A requested Play stream has an empty decoded stream name.

## What to check

1. Check each streams entry for a nonempty stream name.

## Recommended action

Request a named stream from the announced status list.
