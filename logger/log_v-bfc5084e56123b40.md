# Managed task completion matched

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_v
Log level: verbose
Documentation ID: log_v-bfc5084e56123b40

## Log pattern

```text
task id=%s pid=%d command='%s' outfd=%d finished status=%d
```

## Parameters

- Argument 1 — Task identifier: Text identifying the managed task.
- Argument 2 — Process: Integer task process identifier.
- Argument 3 — Command: Configured shell command text.
- Argument 4 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 5 — Exit status: Exit-status field extracted from the process wait result; meaningful as an exit code only when normal exit is indicated.

## Log examples

Illustrative examples; these are not captured server logs.

```text
task id=task1 pid=1234 command='echo ready' outfd=12 finished status=0
```

## Short description

Managed task completion matched.

## Trigger condition

A reported completed child process matches a managed task. Available only on Linux builds.

## Explanation

Its output is removed from monitoring and closed. A zero extracted exit-status field marks the task stopped; another value marks failure. A configured restart interval schedules a later start.
