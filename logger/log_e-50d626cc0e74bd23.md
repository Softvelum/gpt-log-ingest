# Could not create the HTTP connection listener

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-50d626cc0e74bd23

## Log pattern

```text
failed to create listener thread
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Could not create the HTTP connection listener.

## Trigger condition

The HTTP connection listener is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the HTTP connection listener failed.

## What to check

1. Inspect the preceding thread resource error for the failed HTTP connection listener.
