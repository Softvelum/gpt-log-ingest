# Live stream request processing started

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-3027d0c76cb1658e

## Log pattern

```text
[CliS::PLSR] o_url='%s' a_url='%s' f_name='%s'
```

## Parameters

- Argument 1 — Origin URL: Text giving the origin request path and query string.
- Argument 2 — Aliased URL: Text of the original public alias URL, or empty when no alias was applied.
- Argument 3 — Decoded path: Percent-decoded origin path with query parameters removed; a logical stream resource rather than a disk filename.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[CliS::PLSR] o_url='/live/camera/playlist.m3u8' a_url='/public/camera/playlist.m3u8' f_name='/live/camera/playlist.m3u8'
```

## Short description

Live stream request processing started.

## Trigger condition

A live request is dispatched for HLS, DASH, MPEG-TS over HTTP, or Icecast delivery.

## Explanation

The decoded request path is split into application, stream, and resource before media or playlist selection.

## Possible causes

- A live request is dispatched for HLS, DASH, MPEG-TS over HTTP, or Icecast delivery.
