# Configured caption languages exceed the track limit

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-5642eae7c01fd967

## Log pattern

```text
cea708_langs: dropping "%s" for [%s/%s], exceeds max of %zu tracks
```

## Parameters

- Argument 1 — Language: First additional configured language that cannot receive a caption service.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.
- Argument 4 — Track limit: Maximum supported caption track count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cea708_langs: dropping "spa" for [live/camera], exceeds max of 4 tracks
```

## Short description

Configured caption languages exceed the track limit.

## Trigger condition

CEA-708 generation from WebVTT cannot assign another language after all supported caption services have been used.

## Explanation

The named language is dropped and processing of the remaining configured language order stops. The current supported limit is four tracks.

## Possible causes

- CEA-708 generation from WebVTT cannot assign another language after all supported caption services have been used.

## What to check

1. Check the number and order of distinct configured caption languages.

## Recommended action

Keep the desired language order within the supported track count.
