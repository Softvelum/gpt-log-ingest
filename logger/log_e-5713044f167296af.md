# Child shutdown raised an exception

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-5713044f167296af

## Log pattern

```text
exception caught during encoder termination e.what()='%s'
```

## Parameters

- Argument 1 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
exception caught during encoder termination e.what()='operation failed'
```

## Short description

Child shutdown raised an exception.

## Trigger condition

The child termination or waiting sequence raises a process-library exception.

## Explanation

The exception is caught and the helper returns without another termination attempt.

## Possible causes

- The child-process termination or wait operation raised an exception.

## What to check

1. Check the child state and exception description where present.

## Recommended action

Investigate whether the child stopped successfully.
