# AJA output video frame could not be copied

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-b89620b911950ccb

## Log pattern

```text
playback failed device=%s/%d reason='video frame copy failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback failed device=0/0 reason='video frame copy failed'
```

## Short description

AJA output video frame could not be copied.

## Trigger condition

Preparing the current video frame in the host output buffer returns failure.

## Explanation

The frame-transfer routine returns failure before waiting for or transferring a device output frame. Missing frame/buffer data or incompatible format/geometry can cause the preparation failure.

## Possible causes

- Preparing the current video frame in the host output buffer returns failure.

## What to check

1. Check the preceding pixel-format or frame-size message.
