# SLDP Play message is received

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-b12ba0b163c7c707

## Log pattern

```text
s=%d, play: %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Command JSON: Complete received text submitted for Play processing.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, play: {"command":"Play","streams":[{"stream":"camera","type":"video","sn":1}]}
```

## Short description

SLDP Play message is received.

## Trigger condition

A received message is passed to the Play command parser.

## Explanation

The text is logged before JSON validation and stream selection, so it can still be rejected.

## Possible causes

- A received message is passed to the Play command parser.

## What to check

1. Inspect the command and requested streams in the logged JSON.

## Recommended action

No action is required for a valid Play request.
