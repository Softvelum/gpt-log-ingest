# AJA device cannot play back video

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-a1f023479b0179e3

## Log pattern

```text
Device '%s' is capture-only
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Device 'AJA device' is capture-only
```

## Short description

AJA device cannot play back video.

## Trigger condition

Playback capability is absent on the selected card.

## Explanation

The playback-capability check fails and sender initialization cannot continue.

## Possible causes

- Playback capability is absent on the selected card.

## What to check

1. Check the card playback capability.

## Recommended action

Use a playback-capable device for output.
