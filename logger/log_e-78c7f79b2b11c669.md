# RTMP createStream result assigned stream ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-78c7f79b2b11c669

## Log pattern

```text
failed to process stream id for createStream command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process stream id for createStream command
```

## Short description

RTMP createStream result assigned stream ID cannot be decoded.

## Trigger condition

The remote createStream result cannot supply its assigned stream ID as an AMF number.

## Explanation

The result is rejected before a local message stream is established and connection processing fails.

## Possible causes

- The remote createStream result cannot supply its assigned stream ID as an AMF number.

## What to check

1. Inspect the assigned stream ID and framing in the remote createStream result.

## Recommended action

Correct the malformed createStream response at the remote endpoint.
