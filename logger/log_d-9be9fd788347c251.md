# Unrecognized Quick Sync encoder implementation

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_d
Log level: debug
Documentation ID: log_d-9be9fd788347c251

## Log pattern

```text
%p quick sync %d.%d unknown
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Major version: Selected media API major version, integer.
- Argument 3 — Minor version: Selected media API minor version, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 quick sync 1.17 unknown
```

## Short description

Unrecognized Quick Sync encoder implementation.

## Trigger condition

Encoder setup receives an implementation outside the software and four recognized hardware cases.

## Explanation

The API version is reported and session setup continues.
