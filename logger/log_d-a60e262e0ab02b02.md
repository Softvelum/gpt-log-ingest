# Local Zixi receive would block

Product: Nimble Streamer
Component: Zixi integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-a60e262e0ab02b02

## Log pattern

```text
recv error=%d (WouldBlock) on s=%d
```

## Parameters

- Argument 1 — Error: Operating-system would-block error code.
- Argument 2 — Socket: Local Zixi ingest socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
recv error=11 (WouldBlock) on s=42
```

## Short description

Local Zixi receive would block.

## Trigger condition

A nonblocking receive on the local Zixi ingest connection has no data immediately available.

## Explanation

The receive path returns success and waits for later input; the connection is retained.

## Possible causes

- A nonblocking receive on the local Zixi ingest connection has no data immediately available.

## What to check

1. Check subsequent input events if media does not resume.
