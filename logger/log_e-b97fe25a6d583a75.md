# VAAPI decode timestamp queue is empty

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-b97fe25a6d583a75

## Log pattern

```text
failed to get dts: empty dts queue
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

VAAPI decode timestamp queue is empty.

## Trigger condition

Encoded output is available but no queued timestamp remains to assign its decode time.

## Explanation

The encoded packet is not delivered and frame encoding returns failure.

## Possible causes

- The queued timestamp state no longer matches the output frame order.

## What to check

1. Check frame reordering and keyframe transitions around the failure; normal frame submission queues timestamps before encoding.

## Recommended action

Restart the encoder and investigate a reproducible timestamp-state mismatch.
