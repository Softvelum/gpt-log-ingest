# Audio frame allocation failed

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_e
Log level: error
Documentation ID: log_e-3a9bc5185407bc56

## Log pattern

```text
failed to alloc audio frame
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc audio frame
```

## Short description

Audio frame allocation failed.

## Trigger condition

Allocating an audio frame object returns no object while preparing encoder input or sample-format conversion.

## Explanation

Frame preparation fails; no audio frame is passed to the encoder.

## Possible causes

- The stated frame allocation, layout copy, or sample conversion operation failed.

## What to check

1. Check the input audio format, channel layout, and accompanying FFmpeg diagnostics.

## Recommended action

Resolve the reported frame-preparation failure.
