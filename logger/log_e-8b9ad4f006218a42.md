# NDI receiver creation failed

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-8b9ad4f006218a42

## Log pattern

```text
failed to create NDI receiver, ndi_name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create NDI receiver, ndi_name=HOST (Camera)
```

## Short description

NDI receiver creation failed.

## Trigger condition

A source name is resolved but the NDI runtime returns no receiver for it.

## Explanation

The receive operation returns failure before entering media capture.

## Possible causes

- A source name is resolved but the NDI runtime returns no receiver for it.

## What to check

1. Check the resolved source name and whether the NDI runtime can create its receiver.
