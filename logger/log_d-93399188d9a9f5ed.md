# Raw DRM key updated

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-93399188d9a9f5ed

## Log pattern

```text
updated value for key url='%s' client_url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Client key URL: Text giving the URL clients use to fetch the key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updated value for key url='https://keys.example/key' client_url='https://keys.example/client'
```

## Short description

Raw DRM key updated.

## Trigger condition

A registered raw-key URL returns HTTP 200 with exactly 16 bytes.

## Explanation

The key is stored and marked successful. The client URL uses Location with request parameters, or the original request URL if Location is absent.

## Possible causes

- A registered raw-key URL returns HTTP 200 with exactly 16 bytes.
