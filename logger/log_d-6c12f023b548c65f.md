# SLDP time response is prepared

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-6c12f023b548c65f

## Log pattern

```text
s=%d, send time: %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Time JSON: Generated time response with steady and system decimal microsecond strings.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, send time: {"command":"time","steady":"1000000000","system":"1790596800000000"}
```

## Short description

SLDP time response is prepared.

## Trigger condition

A time response is generated for the player.

## Explanation

The response contains monotonic-clock and system-clock values before framing and sending. Their units are microseconds; the monotonic clock has its own epoch and is not a wall-clock timestamp.

## Possible causes

- A time response is generated for the player.

## What to check

1. Check the response fields when diagnosing player time synchronization.

## Recommended action

No action is required for an expected Time exchange.
