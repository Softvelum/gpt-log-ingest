# Video source file could not be mapped

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-0b04f4c779cc09e1

## Log pattern

```text
failed to open and map video file='%s'
```

## Parameters

- Argument 1 — Media filename: Text filesystem path of the source media.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open and map video file='/media/movie.mp4'
```

## Short description

Video source file could not be mapped.

## Trigger condition

Opening and mapping a local MP4 or MKV source returns an invalid mapping.

## Explanation

The temporary media object is discarded and preparation returns failure. Direct media requests are canceled; optional subtitle synchronization or SMIL processing can omit the failed source.

## Possible causes

- Opening and mapping a local MP4 or MKV source returns an invalid mapping.

## What to check

1. Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.

## Recommended action

Check the named file exists, remains readable by the service, and has not been removed or truncated while being used.
