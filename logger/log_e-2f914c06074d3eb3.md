# RTSP plain socket send failed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-2f914c06074d3eb3

## Log pattern

```text
failed to send buffer to s=%d errno=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.
- Argument 2 — Error number: Integer error value reported by the socket operation; its meaning depends on the operating system.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send buffer to s=25 errno=32
```

## Short description

RTSP plain socket send failed.

## Trigger condition

Sending the queued output buffer through the non-TLS socket path fails.

## Explanation

The send operation returns failure. Event-processing callers then request connection shutdown.

## Possible causes

- Sending the queued output buffer through the non-TLS socket path fails.

## What to check

1. Check the reported socket error and connection state.
