# CUDA driver initialization failed

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_e
Log level: error
Documentation ID: log_e-963bc28af091d710

## Log pattern

```text
failed to init cuda res=%u
```

## Parameters

- Argument 1 — CUDA status: CUDA driver result code printed as unsigned decimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init cuda res=100
```

## Short description

CUDA driver initialization failed.

## Trigger condition

Initializing the CUDA driver with zero flags returns a result other than success.

## Explanation

NVIDIA context-manager initialization returns failure before device enumeration.

## Possible causes

- The CUDA driver cannot initialize.

## What to check

1. Check the CUDA status and installed NVIDIA driver/device accessibility.

## Recommended action

Restore CUDA driver operation before using NVIDIA transcoding.
