# DVR directory removal raised an exception

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-4c7e8461d8ef13b1

## Log pattern

```text
failed to remove dvr arhive dir='%s' e.what()='%s'
```

## Parameters

- Argument 1 — Archive directory: Text giving the archive or time-bucket directory.
- Argument 2 — Exception: Text describing the removal exception.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove dvr arhive dir='/data/dvr/live/camera/1700000000000' e.what()='Permission denied'
```

## Short description

DVR directory removal raised an exception.

## Trigger condition

Recursive time-bucket directory removal throws a standard exception.

## Explanation

The exception is caught and directory cleanup returns failure.

## Possible causes

- Recursive time-bucket directory removal throws a standard exception.
