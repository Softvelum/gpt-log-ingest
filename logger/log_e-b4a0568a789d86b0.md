# HLS response reached its redirect limit

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-b4a0568a789d86b0

## Log pattern

```text
max redirect count reached for url='%s' hls camera s=%d
```

## Parameters

- Argument 1 — url: Current origin URL.
- Argument 2 — socket: Origin connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
max redirect count reached for url='https://origin.example/live.m3u8' hls camera s=42
```

## Short description

HLS response reached its redirect limit.

## Trigger condition

A response status is 301 or 302 when the redirect counter is already five.

## Explanation

No new redirect target is accepted by this branch. With no pending target, a non-playlist item causes a new playlist request, while a playlist request is shut down. Successful HTTP 200 responses reset the counter.

## Possible causes

- The current request has already reached the redirect count limit.

## What to check

1. Check the origin redirect chain and Location values.

## Recommended action

Remove the redirect loop or use the final origin URL.
