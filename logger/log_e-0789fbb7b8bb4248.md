# Replacing an existing live stream

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-0789fbb7b8bb4248

## Log pattern

```text
stream already registered [%s]. Unregister previous stream
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream already registered [live/camera]. Unregister previous stream
```

## Short description

Replacing an existing live stream.

## Trigger condition

A stream with the requested name is registered and can be removed.

## Explanation

The previous stream is marked dead and removed from registration and delivery tables, with an unpublish notification when enabled. Registration then continues with a new stream object under the same name.

## Possible causes

- A new registration reused an existing removable stream name.

## What to check

1. Check whether two inputs are publishing the same application and stream name.

## Recommended action

Use distinct names if replacement was not intended.
