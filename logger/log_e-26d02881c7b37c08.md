# Windows file handle close failed

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-26d02881c7b37c08

## Log pattern

```text
CloseHandle fd=%d failed error=%d
```

## Parameters

- Argument 1 — Handle: File handle represented as an integer.
- Argument 2 — Error: Windows error code, printed in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CloseHandle fd=101 failed error=6
```

## Short description

Windows file handle close failed.

## Trigger condition

Closing the mapped file handle fails during cleanup.

## Explanation

The close is not confirmed; this diagnostic does not indicate a new file-read operation.

## Possible causes

- Closing the mapped file handle fails during cleanup.

## What to check

1. Inspect the Windows error and file lifecycle.
