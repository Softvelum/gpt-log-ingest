# Accepted client connection was rejected by the queue

Product: Nimble Streamer
Component: HTTP listener
Logging function: log_d
Log level: debug
Documentation ID: log_d-849d34d94ea776d9

## Log pattern

```text
clients queue is too big, closing s=%d
```

## Parameters

- Argument 1 — Socket: Integer descriptor of the connection being closed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
clients queue is too big, closing s=12
```

## Short description

Accepted client connection was rejected by the queue.

## Trigger condition

Submitting the accepted socket to the worker queue fails.

## Explanation

The accepted connection is closed instead of being processed. The queue rejects a full queue and also nonpositive socket descriptors, so the wording is not exclusive proof of overload.

## Possible causes

- The queue has reached its configured limit, or the submitted descriptor is nonpositive.

## What to check

1. Check the accepted descriptor and worker queue capacity.
