# Widevine response received

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-b13b9ca55d02954c

## Log pattern

```text
[drm] response for='%s' cpi=%u/%u from Widevine server:
%.*s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned index of the requested or selected key rotation period.
- Argument 3 — Period count: Unsigned number of consecutive crypto periods requested.
- Argument 4 — Response length: Integer limit in bytes for the response text that follows.
- Argument 5 — Response body: Text from the key server, limited by the preceding length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] response for='live/camera' cpi=120/2 from Widevine server:
{}
```

## Short description

Widevine response received.

## Trigger condition

A managed Widevine request completes and its pending request is found.

## Explanation

The body is logged before checking the key set and parsing the provider response.

## Possible causes

- A managed Widevine request completes and its pending request is found.
