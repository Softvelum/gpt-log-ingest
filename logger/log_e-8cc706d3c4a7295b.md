# ExpressPlay authenticator is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-8cc706d3c4a7295b

## Log pattern

```text
Customer authenticator must be provided for ExpressPlay (expressplay_customer_authenticator)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
Customer authenticator must be provided for ExpressPlay (expressplay_customer_authenticator)
```

## Short description

ExpressPlay authenticator is missing.

## Trigger condition

The ExpressPlay customer authenticator is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The ExpressPlay customer authenticator is empty.

## What to check

1. Provide the ExpressPlay customer authenticator.

## Recommended action

Provide the ExpressPlay customer authenticator.
