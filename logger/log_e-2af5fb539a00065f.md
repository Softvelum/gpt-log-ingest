# Pay-per-view handler socket could not be opened

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-2af5fb539a00065f

## Log pattern

```text
PPV Api sync failed cannot open socket to api handler
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
PPV Api sync failed cannot open socket to api handler
```

## Short description

Pay-per-view handler socket could not be opened.

## Trigger condition

Opening the connection to the parsed API hostname and port fails.

## Explanation

Any previously applied deny list is cleared. The thread continues after its synchronization delay.

## Possible causes

- The API connection could not be opened.

## What to check

1. Check the configured API URL and connection diagnostics.

## Recommended action

Correct the API address or connection problem.
