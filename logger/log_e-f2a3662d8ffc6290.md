# DRM failure notification found no output item

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-f2a3662d8ffc6290

## Log pattern

```text
ProcessNotifications: cache item not found key='%s' stream='%s'
```

## Parameters

- Argument 1 — Output cache key: Text cache key reserved for the requested generated output.
- Argument 2 — Protected stream: Text application/stream name used to group pending DRM requests.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ProcessNotifications: cache item not found key='/vod/movie.mp4/n_0_0_0.ts' stream='vod/movie.mp4'
```

## Short description

DRM failure notification found no output item.

## Trigger condition

A failed DRM-key notification reaches postponed VOD or DVR requests, but one output cache item is already missing.

## Explanation

The worker skips cancellation of that missing item and continues through the waiting requests before removing the notified stream group.

## Possible causes

- A failed DRM-key notification reaches postponed VOD or DVR requests, but one output cache item is already missing.

## What to check

1. Correlate the DRM key failure with earlier output-cache removal or client cancellation; there is no remaining item to cancel.

## Recommended action

Correlate the DRM key failure with earlier output-cache removal or client cancellation; there is no remaining item to cancel.
