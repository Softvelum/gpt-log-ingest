# RTMP createStream result command-object placeholder cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-6db441e4f215c9c6

## Log pattern

```text
failed to process null for createStream command
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

RTMP createStream result command-object placeholder cannot be decoded.

## Trigger condition

The remote createStream result cannot supply its command-object placeholder as an AMF null value.

## Explanation

The result is rejected before a local message stream is established and connection processing fails.

## Possible causes

- The remote createStream result cannot supply its command-object placeholder as an AMF null value.

## What to check

1. Inspect the command-object placeholder and framing in the remote createStream result.

## Recommended action

Correct the malformed createStream response at the remote endpoint.
