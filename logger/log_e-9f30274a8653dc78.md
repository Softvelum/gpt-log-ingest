# DRM settings line cannot be parsed

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-9f30274a8653dc78

## Log pattern

```text
failed to parse line %s:%u '%s'
```

## Parameters

- Argument 1 — Settings file: Text naming the DRM settings file.
- Argument 2 — Settings line: Unsigned line number within the settings file.
- Argument 3 — Setting text: Text containing the rejected settings line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse line /etc/nimble/drm.conf:12 'unsupported=value'
```

## Short description

DRM settings line cannot be parsed.

## Trigger condition

A line inside a DRM, content-identifier, or key-identifier group cannot be separated into parameter and value.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- A line inside a DRM, content-identifier, or key-identifier group cannot be separated into parameter and value.

## What to check

1. Correct the indicated parameter and value syntax.

## Recommended action

Correct the indicated parameter and value syntax.
