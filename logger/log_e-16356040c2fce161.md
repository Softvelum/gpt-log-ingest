# RTMP playback cannot open video-only advertising

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-16356040c2fce161

## Log pattern

```text
s=%d, top on advertising content error %s
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Content URI: Configured URI of the selected advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, top on advertising content error https://media.example/ad.mp4
```

## Short description

RTMP playback cannot open video-only advertising.

## Trigger condition

The reader for a ready video-only advertising item cannot be created.

## Explanation

The send operation fails and the caller shuts down playback. The word top in the original message is a typo for stop.

## Possible causes

- The reader for a ready video-only advertising item cannot be created.

## What to check

1. Check the advertising media format and video-reader errors.

## Recommended action

Use a readable video advertising item.
