# Streaming response body counters

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-0873763044c9ba2b

## Log pattern

```text
[CliS::AResp] bsnt=%llu rcv=%llu sz=%llu
```

## Parameters

- Argument 1 — Sent bytes: Unsigned 64-bit body bytes sent to the client.
- Argument 2 — Received bytes: Unsigned 64-bit body bytes received or made available in cache.
- Argument 3 — Expected body bytes: Unsigned 64-bit total expected body length.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[CliS::AResp] bsnt=32768 rcv=65536 sz=1048576
```

## Short description

Streaming response body counters.

## Trigger condition

The asynchronous response sender has completed the headers and is checking body availability.

## Explanation

The counters determine whether to send buffered data or wait for more input.

## Possible causes

- The asynchronous response sender has completed the headers and is checking body availability.
