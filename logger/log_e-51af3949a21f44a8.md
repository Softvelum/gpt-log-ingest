# WebVTT subtitle language is unsupported

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-51af3949a21f44a8

## Log pattern

```text
unsupported subtitles lang_code=%s for [%s/%s]
```

## Parameters

- Argument 1 — Language code: Language identifier carried by the subtitle.
- Argument 2 — Application: Application containing the affected live stream.
- Argument 3 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported subtitles lang_code=zzz for [live/camera]
```

## Short description

WebVTT subtitle language is unsupported.

## Trigger condition

A synchronized WebVTT subtitle has a language code that cannot be mapped to a language name.

## Explanation

The subtitle is rejected before it is passed into live WebVTT packaging.

## Possible causes

- A synchronized WebVTT subtitle has a language code that cannot be mapped to a language name.

## What to check

1. Check the subtitle language code against supported three-letter language codes.

## Recommended action

Supply a recognized language code for the subtitle.
