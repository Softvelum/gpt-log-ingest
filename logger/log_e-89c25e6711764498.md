# Scenario connection timed out

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-89c25e6711764498

## Log pattern

```text
remove remote transcoder id=%s, accept timeout
```

## Parameters

- Argument 1 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remove remote transcoder id=scenario1, accept timeout
```

## Short description

Scenario connection timed out.

## Trigger condition

A child remains running without a connected socket more than 2000 milliseconds after its recorded creation time.

## Explanation

The controller is removed and cleaned up; audio and video synchronization is invalidated so the required scenario can be created again.

## Possible causes

- The running child has not completed its connection to the parent within two seconds.

## What to check

1. Check child startup diagnostics and local parent connection availability.

## Recommended action

Correct slow or failed child initialization or local connection problems.
