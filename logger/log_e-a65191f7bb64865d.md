# TCP socket creation failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_e
Log level: error
Documentation ID: log_e-a65191f7bb64865d

## Log pattern

```text
%s socket creation failed (errno=%d)
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — System error: Integer operating-system socket error value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
origin socket creation failed (errno=24)
```

## Short description

TCP socket creation failed.

## Trigger condition

Creating an IPv4 or IPv6 stream socket returns failure.

## Explanation

The socket initialization helper stores the system error and returns failure before configuring nonblocking operation.

## Possible causes

- The operating system rejected socket creation.

## What to check

1. Inspect the socket error for the named peer role.
