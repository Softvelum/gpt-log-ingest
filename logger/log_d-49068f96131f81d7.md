# Socket shutdown accepted

Product: Nimble Streamer
Component: Stream checks and RTMP
Logging function: log_d
Log level: debug
Documentation ID: log_d-49068f96131f81d7

## Log pattern

```text
shutdown s=%d
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
shutdown s=12
```

## Short description

Socket shutdown accepted.

## Trigger condition

A bidirectional plain socket shutdown succeeds.

## Explanation

The stream-check or RTMP object enters its shutting-down state. The descriptor remains open until later close handling.
