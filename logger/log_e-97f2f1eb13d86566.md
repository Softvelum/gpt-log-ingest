# Cache allocation object disagrees with reservation

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-97f2f1eb13d86566

## Log pattern

```text
DataCache::AllocateItemData invalid item key='%s' cache p=%p item p=%p
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — cached address: Address of the object currently registered for this key.
- Argument 3 — supplied address: Address of the object passed for allocation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DataCache::AllocateItemData invalid item key='movie' cache p=0x1000 item p=0x2000
```

## Short description

Cache allocation object disagrees with reservation.

## Trigger condition

The key exists, but its recorded cache object differs from the supplied object.

## Explanation

The cache throws an invalid-item error instead of allocating data.

## Possible causes

- The supplied object no longer matches the current reservation.

## What to check

1. Compare replacement, reservation, and removal messages for the key.

## Recommended action

Investigate the competing cache objects.
