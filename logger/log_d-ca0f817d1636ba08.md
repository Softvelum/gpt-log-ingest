# Output-chain file transfer starting

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-ca0f817d1636ba08

## Log pattern

```text
sendf s=%d f=%d off=%lld sz=%lld
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — File descriptor: Integer descriptor of the output-chain file.
- Argument 3 — File offset: Signed 64-bit starting byte offset.
- Argument 4 — Requested bytes: Signed 64-bit remaining bytes in this output-chain buffer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sendf s=18 f=23 off=4096 sz=8192
```

## Short description

Output-chain file transfer starting.

## Trigger condition

The next local media output-chain buffer is backed by an open file.

## Explanation

A file-to-client send is attempted at the logged byte offset and remaining buffer length.

## Possible causes

- The next local media output-chain buffer is backed by an open file.
