# Interleaved RTP parsing failed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-68425745d8e48906

## Log pattern

```text
parse_rtp returns %d stream=[%s]
```

## Parameters

- Argument 1 — Status: Integer parser status: one means packet parse failure; two means stream processing failure.
- Argument 2 — Stream identity: Application and stream label used by the RTSP parser.

## Log examples

Illustrative examples; these are not captured server logs.

```text
parse_rtp returns 1 stream=[live/camera]
```

## Short description

Interleaved RTP parsing failed.

## Trigger condition

Parsing a complete interleaved RTP payload returns a nonzero status.

## Explanation

The payload status is returned to the surrounding RTSP parser. A later message can describe its handling of that failure.

## Possible causes

- Parsing a complete interleaved RTP payload returns a nonzero status.

## What to check

1. Check adjacent RTP codec or packet-format errors.
