Component: Advertising
Logging function: log_e

failed to process advertising chunk request, playlist is null

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Advertising chunk has no playlist.

## Trigger condition

An MPEG-TS, audio, or fragmented MP4 advertising chunk request starts without its playlist.

## Explanation

Chunk generation returns immediately; any still-pending cache item is canceled when the request is destroyed.

## Possible causes

- An MPEG-TS, audio, or fragmented MP4 advertising chunk request starts without its playlist.

## What to check

1. Check that advertising playlist generation completed before requesting the chunk.

## Recommended action

Check that advertising playlist generation completed before requesting the chunk.
