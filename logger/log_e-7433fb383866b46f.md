# Encoder has no suitable conversion format

Product: Nimble Streamer
Component: Encoder pixel-format selection
Logging function: log_e
Log level: error
Documentation ID: log_e-7433fb383866b46f

## Log pattern

```text
failed to find conv format for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

The FFmpeg path uses the codec format list; the native NVIDIA path uses formats enumerated from the NVIDIA session.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find conv format for [live/camera]
```

## Short description

Encoder has no suitable conversion format.

## Trigger condition

The input format is not directly supported and FFmpeg cannot choose a compatible format from the encoder accepted-format list.

## Explanation

Encoder initialization returns failure before creating a pixel converter.

## Possible causes

- No supported destination pixel format can be selected for the input.

## What to check

1. Check the input pixel format and the selected FFmpeg or native NVIDIA encoder format support.

## Recommended action

Supply a compatible input format or choose an encoder that accepts it.
