# DRMToday user name is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-a04c856eb9d53917

## Log pattern

```text
user must be provided for DRMToday (drmtoday_user)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
user must be provided for DRMToday (drmtoday_user)
```

## Short description

DRMToday user name is missing.

## Trigger condition

The DRMToday user name is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The DRMToday user name is empty.

## What to check

1. Provide the DRMToday user name.

## Recommended action

Provide the DRMToday user name.
