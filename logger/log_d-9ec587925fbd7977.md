# OMT receiver created

Product: Nimble Streamer
Component: OMT media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-9ec587925fbd7977

## Log pattern

```text
omt receiver created for [%s]
```

## Parameters

- Argument 1 — OMT name: Requested output name or resolved full input source name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
omt receiver created for [HOST (Camera)]
```

## Short description

OMT receiver created.

## Trigger condition

The OMT runtime creates an audio/video receiver and its suggested quality is set.

## Explanation

The input proceeds to capture frames with a 250-millisecond receive timeout. This message does not confirm frame arrival.

## Possible causes

- Successful OMT input initialization.
