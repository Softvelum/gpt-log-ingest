# Cannot set SRT packet filter

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-2d94d14a45569b3e

## Log pattern

```text
failed to set filter=%s, s=%d
```

## Parameters

- Argument 1 — Filter: Configured packet-filter expression.
- Argument 2 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set filter=unknown, s=100
```

## Short description

Cannot set SRT packet filter.

## Trigger condition

The SRT library rejects the configured packet-filter expression.

## Explanation

Socket settings application stops with failure.

## Possible causes

- The SRT library rejects the configured packet-filter expression.

## What to check

1. Check the filter expression and support in the loaded SRT library.
