# WHIP publish signature rejected

Product: Nimble Streamer
Component: WHIP publishing authorization
Logging function: log_e
Log level: error
Documentation ID: log_e-83e8b0f773494b72

## Log pattern

```text
WHIP publish not authorized as 'publishsign' incorrect stream=[%s/%s] ip=[%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.
- Argument 3 — Client address: Publisher IP address supplied with the request, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WHIP publish not authorized as 'publishsign' incorrect stream=[live/camera] ip=[192.0.2.10]
```

## Short description

WHIP publish signature rejected.

## Trigger condition

Publish-signature processing returns a failure for the WHIP publishing request.

## Explanation

The WHIP session is not created; the caller receives no session.

## Possible causes

- The supplied publish authorization fails the configured publishing policy.

## What to check

1. Check the publish signature and the authorization settings for the named application and client.

## Recommended action

Correct the publishing authorization and retry.
