# Protected video initialization request could not be submitted

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-2cb717016a648e65

## Log pattern

```text
failed to request fmp4 video init segment for[%s / %s]
```

## Parameters

- Argument 1 — Application: Text naming the VOD application.
- Argument 2 — Stream: Text naming the protected media stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to request fmp4 video init segment for[vod / movie.mp4]
```

## Short description

Protected video initialization request could not be submitted.

## Trigger condition

A new initialization-segment cache item and dependency observer exist, but queueing its video initialization request fails.

## Explanation

The dependency observer and postponed-request entry are removed; the waiting video chunk output is canceled and released.

## Possible causes

- A new initialization-segment cache item and dependency observer exist, but queueing its video initialization request fails.

## What to check

1. Check request-queue availability and adjacent media-worker errors; the required initialization segment was not scheduled.

## Recommended action

Check request-queue availability and adjacent media-worker errors; the required initialization segment was not scheduled.
