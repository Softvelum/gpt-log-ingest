# Unrecognized Quick Sync decoder implementation

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_i
Log level: info
Documentation ID: log_i-d9d1165883edd90e

## Log pattern

```text
%p quick sync %d.%d unknown, impl=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Major version: Selected media API major version, integer.
- Argument 3 — Minor version: Selected media API minor version, integer.
- Argument 4 — Implementation: Integer media implementation value, including any implementation flags; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 quick sync 1.17 unknown, impl=99
```

## Short description

Unrecognized Quick Sync decoder implementation.

## Trigger condition

The decoder session reports an implementation outside the software and four recognized hardware cases.

## Explanation

The implementation and API version are reported; this branch still allows session setup to succeed.
