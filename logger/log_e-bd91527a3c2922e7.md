# Client request event has the wrong socket

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-bd91527a3c2922e7

## Log pattern

```text
expected s=%d but event is for s=%d
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Event socket: Integer descriptor supplied with the input event.

## Log examples

Illustrative examples; these are not captured server logs.

```text
expected s=18 but event is for s=19
```

## Short description

Client request event has the wrong socket.

## Trigger condition

Request input is dispatched with a descriptor different from the session client socket.

## Explanation

The request is not read and the default shutdown response is prepared.

## Possible causes

- Request input is dispatched with a descriptor different from the session client socket.

## What to check

1. Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.

## Recommended action

Correlate the socket and surrounding connection events; repeated unexpected events require investigation of session or socket ownership.
