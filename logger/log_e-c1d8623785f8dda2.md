# DRMToday login response rejected

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-c1d8623785f8dda2

## Log pattern

```text
[drm] DRMToday response processing login failed for: '%s' %s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — HTTP response details: Text containing the HTTP status and optional response body; empty when no response parser exists.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] DRMToday response processing login failed for: 'live/camera' status=503 body='unavailable'
```

## Short description

DRMToday login response rejected.

## Trigger condition

The login response is not HTTP 201 or has an empty Location.

## Explanation

The requested keys are marked failed and waiting consumers are notified.

## Possible causes

- The login response is not HTTP 201 or has an empty Location.

## What to check

1. Check DRMToday login credentials, HTTP status, and Location header.

## Recommended action

Check DRMToday login credentials, HTTP status, and Location header.
