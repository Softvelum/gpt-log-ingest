# FFmpeg video encoder context allocation failed

Product: Nimble Streamer
Component: FFmpeg video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-6c03750ef57292a5

## Log pattern

```text
failed to alloc %s video encoder context for [%s]
```

## Parameters

- Argument 1 — Encoder name: Requested FFmpeg encoder name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc h264_nvenc video encoder context for [live/camera]
```

## Short description

FFmpeg video encoder context allocation failed.

## Trigger condition

Allocating a context for the located encoder returns no context.

## Explanation

Video encoder initialization returns failure.

## Possible causes

- FFmpeg cannot allocate the encoder context.

## What to check

1. Check host memory and concurrent encoder resource use.

## Recommended action

Restore available memory or reduce encoding load.
