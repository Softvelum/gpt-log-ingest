## Short description

Advertising validation response exceeded its buffer.

## Trigger condition

The license-validation response exceeds the available receive capacity.

## Explanation

This license-validation attempt did not complete because the response exceeded the available receive capacity. Check the response size and the license endpoint or proxy response.

## Possible causes

- The license-validation response exceeds the available receive capacity.

## What to check

1. Check whether the license endpoint or proxy returned an unexpectedly large response.

## Recommended action

Check whether the license endpoint or proxy returned an unexpectedly large response.
