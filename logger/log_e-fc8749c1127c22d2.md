# WebRTC control interface is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-fc8749c1127c22d2

## Log pattern

```text
invalid parameter webrtc_listen_interface value: %s
```

## Parameters

- Argument 1 — Interface: Configured control-interface address, text.

The text applies to WHIP and WHEP configuration; the runtime listener occurrence is WHIP.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter webrtc_listen_interface value: invalid-address
```

## Short description

WebRTC control interface is invalid.

## Trigger condition

A configured WHIP or WHEP control interface cannot be parsed as an IPv4 address, or the WHIP worker encounters this invalid address during listener startup.

## Explanation

Configuration parsing fails. In worker startup, the newly created listener socket is closed and startup returns failure.

## Possible causes

- The supplied control interface is not an accepted IPv4 address.

## What to check

1. Check the WHIP or WHEP control interface value.

## Recommended action

Supply a valid local IPv4 address.
