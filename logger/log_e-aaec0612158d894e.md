# IPv6 listener socket creation failed

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-aaec0612158d894e

## Log pattern

```text
ipv6 listener socket creation failed errno=%d
```

## Parameters

- Argument 1 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ipv6 listener socket creation failed errno=5
```

## Short description

IPv6 listener socket creation failed.

## Trigger condition

An IPv6 listener is requested and socket creation fails.

## Explanation

Listener setup returns failure.

## Possible causes

- The operating system rejected socket creation.

## What to check

1. Check the socket error and available socket resources.

## Recommended action

Resolve the reported socket creation failure.
