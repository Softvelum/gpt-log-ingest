# RTMP advertising content finishes loading

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-9655b8251c94fada

## Log pattern

```text
s=%d, %s content loaded
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Content URI: Configured URI of the selected advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, https://media.example/ad.mp4 content loaded
```

## Short description

RTMP advertising content finishes loading.

## Trigger condition

A content-load callback matches the waiting session and selected item, and that item is now ready.

## Explanation

The load observer and timeout are removed, then playback attempts to load and send the advertising item.

## Possible causes

- A content-load callback matches the waiting session and selected item, and that item is now ready.

## What to check

1. Check subsequent content-start or reader errors.

## Recommended action

No action is required for a successful load.
