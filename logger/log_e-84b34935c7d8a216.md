# Runtime library could not be unloaded on Linux

Product: Nimble Streamer
Component: Runtime library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-84b34935c7d8a216

## Log pattern

```text
dlclose failed for lib='%s' eret=%d error='%s'
```

## Parameters

- Argument 1 — Library: Requested library name or path, text.
- Argument 2 — Result: Library-close return value, signed integer.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dlclose failed for lib='libexample.so' eret=-1 error='operation failed'
```

## Short description

Runtime library could not be unloaded on Linux.

## Trigger condition

Closing a non-null library handle returns a nonzero result on Linux.

## Explanation

The failure is logged and the stored handle is cleared; this code does not retry unloading.

## Possible causes

- The runtime loader rejected the unload operation.

## What to check

1. Check the loader diagnostic and library name.

## Recommended action

Investigate the reported loader error.
