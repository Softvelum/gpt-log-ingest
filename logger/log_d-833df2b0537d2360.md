# OMT video waits for a video timecode reference

Product: Nimble Streamer
Component: OMT media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-833df2b0537d2360

## Log pattern

```text
skip video frame till first video frame with sei timecode for [%s]
```

## Parameters

- Argument 1 — OMT name: Requested output name or resolved full input source name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip video frame till first video frame with sei timecode for [Output]
```

## Short description

OMT video waits for a video timecode reference.

## Trigger condition

SEI-timecode output receives video without a valid system-time reference.

## Explanation

The frame is skipped and the message handler reports success. Ordinary unscheduled OMT sending bypasses this check.

## Possible causes

- SEI-timecode output receives video without a valid system-time reference.

## What to check

1. Check that the source supplies SEI timecode and a video timestamp.

## Recommended action

Supply a video timecode reference before scheduled video output.
