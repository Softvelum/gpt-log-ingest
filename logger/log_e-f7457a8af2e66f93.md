# RTSP request URL cannot identify an application and stream

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-f7457a8af2e66f93

## Log pattern

```text
failed to parse url=%s client=%d
```

## Parameters

- Argument 1 — URL: RTSP stream or track URL for the request.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse url=rtsp://192.0.2.1/ client=25
```

## Short description

RTSP request URL cannot identify an application and stream.

## Trigger condition

An ANNOUNCE or DESCRIBE URL is not accepted as an rtsp URL with nonempty application and stream names.

## Explanation

The server requests shutdown before registering the publisher or locating a playback stream.

## Possible causes

- An ANNOUNCE or DESCRIBE URL is not accepted as an rtsp URL with nonempty application and stream names.

## What to check

1. Check the URL scheme and application/stream path.

## Recommended action

Use an rtsp URL containing both an application and stream name.
