# DVR archive cleanup begins

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-0bf31d3151ec7d22

## Log pattern

```text
dvr cleanup str='%s/%s' dur=%llu td=%llu sz=%llu tsz=%llu sftd=%llu oth=%llu nth=%llu
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Recorded duration: Unsigned total archive duration in milliseconds.
- Argument 4 — Target duration: Unsigned retention depth in milliseconds; the maximum 64-bit value means unlimited.
- Argument 5 — Storage bytes: Unsigned accounted physical media storage size in bytes.
- Argument 6 — Target bytes: Unsigned configured storage limit in bytes; zero means unlimited.
- Argument 7 — Deferred files: Unsigned count of files awaiting physical deletion.
- Argument 8 — Older boundary: Unsigned UTC cutoff in milliseconds since the Unix epoch; zero means absent.
- Argument 9 — Newer boundary: Unsigned UTC lower bound in milliseconds since the Unix epoch; zero means absent.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dvr cleanup str='live/camera' dur=3600000 td=1800000 sz=104857600 tsz=0 sftd=2 oth=1700000060000 nth=1700000000000
```

## Short description

DVR archive cleanup begins.

## Trigger condition

A retention limit requires cleanup or an explicit cleanup operation is requested.

## Explanation

Eligible segments are deleted, kept, blacked out, or muted according to the cleanup mode. Recording-time cleanup limits each pass to eight counted segments.

## Possible causes

- A retention limit requires cleanup or an explicit cleanup operation is requested.

## What to check

1. Check the applied retention, size, free-space, and cleanup-range settings.

## Recommended action

Check the applied retention, size, free-space, and cleanup-range settings.
