# Video encoder input color description changed

Product: Nimble Streamer
Component: Video encoder input stability
Logging function: log_e
Log level: error
Documentation ID: log_e-2c26195a9fb56891

## Log pattern

```text
failed to change color params from %d/%d/%d to %d/%d/%d on the fly for [%s]
```

## Parameters

- Argument 1 — Old primaries: Old primaries, FFmpeg color enum identifier, integer; no unit.
- Argument 2 — Old transfer: Old transfer, FFmpeg color enum identifier, integer; no unit.
- Argument 3 — Old matrix: Old matrix, FFmpeg color enum identifier, integer; no unit.
- Argument 4 — New primaries: New primaries, FFmpeg color enum identifier, integer; no unit.
- Argument 5 — New transfer: New transfer, FFmpeg color enum identifier, integer; no unit.
- Argument 6 — New matrix: New matrix, FFmpeg color enum identifier, integer; no unit.
- Argument 7 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to change color params from 1/1/1 to 9/16/9 on the fly for [live/camera]
```

## Short description

Video encoder input color description changed.

## Trigger condition

An initialized FFmpeg, x264, native NVIDIA or native Quick Sync encoder receives different color primaries, transfer characteristics or color-matrix coefficients.

## Explanation

The frame write fails; the active encoder session does not adopt the new color description.

## Possible causes

- The source or filter changes the frame color metadata after initialization.

## What to check

1. Compare old and new color identifiers and upstream source/filter changes.

## Recommended action

Keep color metadata consistent or restart encoding for the new color description.
