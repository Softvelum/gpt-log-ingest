# Stream-check peer closure event received

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-03160fb890d48ae5

## Log pattern

```text
connection closed by s=%d (ev=0x%x & EPOLLRDHUP)
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.
- Argument 2 — events: Event flags including peer half-close, printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed by s=12 (ev=0x2000 & EPOLLRDHUP)
```

## Short description

Stream-check peer closure event received.

## Trigger condition

The socket event contains peer half-close and the task did not replace its socket during earlier processing.

## Explanation

A connecting task can try another resolved address; otherwise the task becomes shut down.
