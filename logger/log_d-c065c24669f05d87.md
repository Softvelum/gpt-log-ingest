# Playback session URL redirect prepared

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-c065c24669f05d87

## Log pattern

```text
redirecting to url='%s'
```

## Parameters

- Argument 1 — Session URL: Text redirect target carrying the assigned nimblesessionid query parameter.

## Log examples

Illustrative examples; these are not captured server logs.

```text
redirecting to url='/live/camera/playlist.m3u8?nimblesessionid=42'
```

## Short description

Playback session URL redirect prepared.

## Trigger condition

A new playback session requires a redirect to a URL containing its assigned session identifier.

## Explanation

HTTP 302 is prepared with the generated session-bearing URL.

## Possible causes

- A new playback session requires a redirect to a URL containing its assigned session identifier.

## What to check

1. Allow the player to follow this redirect and preserve its session parameter on subsequent playlist and media requests.

## Recommended action

Allow the player to follow this redirect and preserve its session parameter on subsequent playlist and media requests.
