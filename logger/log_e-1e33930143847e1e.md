# SLDP advertising content is not ready

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-1e33930143847e1e

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d failed to load cache item for content %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — Content URI: Configured URI of the advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 failed to load cache item for content https://media.example/ad.mp4
```

## Short description

SLDP advertising content is not ready.

## Trigger condition

A selected advertisement is not ready when its media-loading phase begins.

## Explanation

The sender next chooses waiting, skipping, or stopping according to locality, URI, wait timeout, and error policy.

## Possible causes

- A selected advertisement is not ready when its media-loading phase begins.

## What to check

1. Check subsequent wait/skip/stop messages and the content cache status.

## Recommended action

Make the media ready before its scheduled insertion.
