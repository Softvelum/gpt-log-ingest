# Playlist cache item cannot be reserved

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-84c4a7236b9e541b

## Log pattern

```text
failed to reserve cache_item key=%s
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to reserve cache_item key=/media/program.mp4
```

## Short description

Playlist cache item cannot be reserved.

## Trigger condition

Remote content reservation provides neither a usable existing item nor a new reserved item.

## Explanation

No download request is created for this content.

## Possible causes

- Remote content reservation provides neither a usable existing item nor a new reserved item.

## What to check

1. Check cache availability for the required playlist content.

## Recommended action

Check cache availability for the required playlist content.
