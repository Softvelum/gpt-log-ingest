# Quick Sync encoder parameter query returned a status

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_i
Log level: info
Documentation ID: log_i-d483e2ffe876352e

## Log pattern

```text
%p failed to set requested encoder params, set corrected values, error=%d
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to set requested encoder params, set corrected values, error=-3
```

## Short description

Quick Sync encoder parameter query returned a status.

## Trigger condition

The query that checks and updates requested encoding parameters returns any nonzero status.

## Explanation

The status is reported and initialization is still attempted with the returned parameters. The wording does not establish that the query succeeded or that every incompatibility was corrected.

## Possible causes

- The media runtime reports a parameter adjustment, warning, or error during parameter checking.

## What to check

1. Check the status and the following encoder initialization result.

## Recommended action

If initialization fails, correct unsupported encoding parameters or select compatible hardware.
