# SDI teletext descriptor is invalid

Product: Nimble Streamer
Component: SDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-db0805c5740272e5

## Log pattern

```text
invalid mpeg2ts_dvb_descriptor for sdi stream [%s]
```

## Parameters

- Argument 1 — Device stream: Configured SDI device or stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid mpeg2ts_dvb_descriptor for sdi stream [SDI input]
```

## Short description

SDI teletext descriptor is invalid.

## Trigger condition

The configured hexadecimal descriptor cannot decode, is shorter than seven bytes, has the wrong teletext tag, or has an inconsistent declared length.

## Explanation

A default English teletext subtitle descriptor for magazine eight and page 801 is installed, and option processing continues.

## Possible causes

- The configured hexadecimal descriptor cannot decode, is shorter than seven bytes, has the wrong teletext tag, or has an inconsistent declared length.

## What to check

1. Check the descriptor hexadecimal encoding, tag, and length.

## Recommended action

Supply a valid teletext descriptor when the default language and page are unsuitable.
