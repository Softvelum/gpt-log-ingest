# Disconnection has no matching statistics record

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_e
Log level: error
Documentation ID: log_e-517b0275ff05631e

## Log pattern

```text
Statistics::Disconnected statistics item not found for ip='%s' host='%s' app='%s' stream='%s'
```

## Parameters

- Argument 1 — Client address: Client IP address as text; an empty value can represent a request to create statistics records only.
- Argument 2 — Host: Text identifying the statistics host.
- Argument 3 — Application: Application name as text.
- Argument 4 — Stream: Stream name as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Statistics::Disconnected statistics item not found for ip='192.0.2.10' host='media.example' app='live' stream='camera'
```

## Short description

Disconnection has no matching statistics record.

## Trigger condition

Statistics are enabled, names are nonempty, but the host, application or stream cannot be found.

## Explanation

No disconnection is applied and no global client count is decreased for this notification.

## Possible causes

- A required host, application or stream record is absent.

## What to check

1. Compare the reported hierarchy with preceding connection notifications.
