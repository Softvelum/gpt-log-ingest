# Encoder input dimensions changed

Product: Nimble Streamer
Component: Video encoder input stability
Logging function: log_e
Log level: error
Documentation ID: log_e-5e351369e9b33612

## Log pattern

```text
failed to change frame size from %dx%d to %dx%d on the fly
```

## Parameters

- Argument 1 — Old width: Old width, integer pixels.
- Argument 2 — Old height: Old height, integer pixels.
- Argument 3 — New width: New width, integer pixels.
- Argument 4 — New height: New height, integer pixels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to change frame size from 1920x1080 to 1280x720 on the fly
```

## Short description

Encoder input dimensions changed.

## Trigger condition

An initialized native NVIDIA, SVT HEVC or VPX encoder receives a frame whose width or height differs from its initial dimensions.

## Explanation

The frame write returns failure; these paths do not reconfigure resolution during that encoding session.

## Possible causes

- The source or filter changes video dimensions after encoder initialization.

## What to check

1. Compare old and new dimensions and check upstream source/filter changes.

## Recommended action

Keep dimensions stable or restart encoding for the new resolution.
