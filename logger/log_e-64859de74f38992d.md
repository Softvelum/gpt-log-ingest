# SLDP stops on unavailable advertising content

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-64859de74f38992d

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d stop on advertising content error %s
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — Content URI: Configured URI of the advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, video_sn=1, audio_sn=2 stop on advertising content error https://media.example/ad.mp4
```

## Short description

SLDP stops on unavailable advertising content.

## Trigger condition

Unready advertising content cannot use the wait path and is not configured to skip errors.

## Explanation

The output operation fails and the caller shuts down the playback connection.

## Possible causes

- Unready advertising content cannot use the wait path and is not configured to skip errors.

## What to check

1. Check content readiness, locality, wait timeout, and error policy.

## Recommended action

Restore the advertising media or correct its intended error behavior.
