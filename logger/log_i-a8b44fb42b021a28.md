# CUDA context added during cache initialization

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-a8b44fb42b021a28

## Log pattern

```text
created cuda ctx=%p, gpu=%d, flag=%d, time=%ld(ms)
```

## Parameters

- Argument 1 — Context: CUDA context handle, pointer printed in hexadecimal.
- Argument 2 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 3 — Flags: CUDA context creation flags, integer bit mask printed in decimal; no unit.
- Argument 4 — Duration: Elapsed wall-clock duration, signed long milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created cuda ctx=0x12340000, gpu=0, flag=0, time=12(ms)
```

## Short description

CUDA context added during cache initialization.

## Trigger condition

Creating and detaching the next cache context succeeds.

## Explanation

The context is added to the free-context cache for its GPU and flags.
