# DRM response has no application key set

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-02e7f1450ad611bc

## Log pattern

```text
[drm] failed to find app/stream key(s) to update for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] failed to find app/stream key(s) to update for 'live/camera'
```

## Short description

DRM response has no application key set.

## Trigger condition

A Widevine or CPIX response arrives after its application key set is absent.

## Explanation

The response is discarded and waiting consumers are notified of failure.

## Possible causes

- A Widevine or CPIX response arrives after its application key set is absent.

## What to check

1. Check whether the stream or DRM settings were removed while keys were requested.

## Recommended action

Check whether the stream or DRM settings were removed while keys were requested.
