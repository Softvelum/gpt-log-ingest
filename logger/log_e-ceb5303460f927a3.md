# Advertising playlist has no content reader

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-ceb5303460f927a3

## Log pattern

```text
failed to get content loader, content_id=%s uri=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get content loader, content_id=ad-01 uri=https://media.example/ad.mp4
```

## Short description

Advertising playlist has no content reader.

## Trigger condition

Neither an MP4 loader nor an audio loader is available while generating an advertising playlist.

## Explanation

The playlist is marked failed and generation returns.

## Possible causes

- Neither an MP4 loader nor an audio loader is available while generating an advertising playlist.

## What to check

1. Ensure the advertising content loaded successfully before requesting its playlist.

## Recommended action

Ensure the advertising content loaded successfully before requesting its playlist.
