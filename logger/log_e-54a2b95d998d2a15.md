# SRT bonding node reconnection failed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_e
Log level: error
Documentation ID: log_e-54a2b95d998d2a15

## Log pattern

```text
failed to connect s=%d to %s:%d: '%s'
```

## Parameters

- Argument 1 — Group: SRT group socket identifier.
- Argument 2 — Address: Configured endpoint address.
- Argument 3 — Port: Configured endpoint port number.
- Argument 4 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to connect s=1073741924 to 192.0.2.10:9000: 'Connection setup failure'
```

## Short description

SRT bonding node reconnection failed.

## Trigger condition

A reconnect attempt to a missing group node returns an SRT connection error.

## Explanation

The node is not restored by this attempt. Group processing can continue and later disconnected-node checks may retry.

## Possible causes

- A reconnect attempt to a missing group node returns an SRT connection error.

## What to check

1. Check the destination endpoint and SRT error.
