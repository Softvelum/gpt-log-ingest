# RTMP connect flashVer cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-6aca82f3fe574074

## Log pattern

```text
failed to read flashVer name
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read flashVer name
```

## Short description

RTMP connect flashVer cannot be decoded.

## Trigger condition

The connect request cannot supply its flashVer as an AMF string.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The connect request cannot supply its flashVer as an AMF string.

## What to check

1. Inspect the flashVer field and AMF framing in the incoming connect command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
