# Geolocation verification country found

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_v
Log level: verbose
Documentation ID: log_v-9df266059d480602

## Log pattern

```text
country code for '%s' is '%s'
```

## Parameters

- Argument 1 — Verification address: The built-in IPv4 or IPv6 verification address.
- Argument 2 — Country: Country-code text returned for that address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
country code for '8.8.8.8' is 'US'
```

## Short description

Geolocation verification country found.

## Trigger condition

A built-in IPv4 or IPv6 database verification lookup returns a nonempty country code.

## Explanation

Reports the verification address and its result. Acceptance checks for a nonempty country; this message alone does not establish completion of the update.
