# Widevine protection selected

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-4791451898dee873

## Log pattern

```text
[drm] app='%s' stream='%s' is protected with Widevine
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] app='live' stream='camera' is protected with Widevine
```

## Short description

Widevine protection selected.

## Trigger condition

The application uses Widevine and stream registration includes MPEG-DASH.

## Explanation

Key registration continues; this message alone does not confirm that usable keys have arrived.

## Possible causes

- The application uses Widevine and stream registration includes MPEG-DASH.
