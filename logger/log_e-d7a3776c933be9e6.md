# Transcription queue drops an audio request

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-d7a3776c933be9e6

## Log pattern

```text
transcriber too slow, dropped audio for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
transcriber too slow, dropped audio for [live/camera]
```

## Short description

Transcription queue drops an audio request.

## Trigger condition

Transcription is enabled and configured, but the transcription request queue refuses another audio message.

## Explanation

This audio request is dropped for transcription. Audio still enters the media synchronization queue, so this log does not itself mean playback audio was dropped.

## Possible causes

- Transcription is enabled and configured, but the transcription request queue refuses another audio message.

## What to check

1. Check transcription throughput and request-queue pressure.

## Recommended action

Reduce transcription workload or restore sufficient transcription processing capacity.
