# RTSP publisher requested unsupported transport

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-650f3f216c4e3f91

## Log pattern

```text
Unsupported transport %s
```

## Parameters

- Argument 1 — Transport: Requested Transport header protocol value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Unsupported transport RTP/AVP/UDP
```

## Short description

RTSP publisher requested unsupported transport.

## Trigger condition

SETUP matches a published track but requests a transport other than RTP/AVP/TCP.

## Explanation

The incoming publishing connection requests shutdown without accepting that transport.

## Possible causes

- SETUP matches a published track but requests a transport other than RTP/AVP/TCP.

## What to check

1. Check the publisher Transport header.

## Recommended action

Publish using interleaved RTP over TCP.
