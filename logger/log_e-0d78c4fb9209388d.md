# Video packet awaits its sequence header

Product: Nimble Streamer
Component: Video input
Logging function: log_e
Log level: error
Documentation ID: log_e-0d78c4fb9209388d

## Log pattern

```text
[VM] AVC SEQUENCE header is required first for '%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] AVC SEQUENCE header is required first for 'live/camera'
```

## Short description

Video packet awaits its sequence header.

## Trigger condition

An AVC-style media or end packet arrives before codec initialization in DVR AVC recording or RTMP AVC/HEVC input.

## Explanation

The packet is ignored while processing reports success and waits for a sequence header.

## Possible causes

- An AVC-style media or end packet arrives before codec initialization in DVR AVC recording or RTMP AVC/HEVC input.

## What to check

1. Ensure the publisher sends its codec sequence header before media.

## Recommended action

Ensure the publisher sends its codec sequence header before media.
