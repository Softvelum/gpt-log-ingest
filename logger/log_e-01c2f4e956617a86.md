# DRM response has an unknown request category

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-01c2f4e956617a86

## Log pattern

```text
unknown DRM request type=%llu url='%s'
```

## Parameters

- Argument 1 — Request category: Unsigned numeric request category.
- Argument 2 — Key-server URL: Text giving the configured or requested key-server URL.

The request category is supplied as an enum while the format requires an unsigned long long. The variadic argument type does not match the conversion.

## Log examples

No sound example is given because the request-category argument is incompatible with its printf conversion.

## Short description

DRM response has an unknown request category.

## Trigger condition

A pending response contains a request category unsupported by the DRM response dispatcher.

## Explanation

No provider-specific response handling runs.

## Possible causes

- A pending response contains a request category unsupported by the DRM response dispatcher.

## What to check

1. Preserve surrounding request messages and investigate inconsistent pending-request state.

## Recommended action

Preserve surrounding request messages and investigate inconsistent pending-request state.
