# VAAPI parameter buffer creation failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-30476b06d2c03c33

## Log pattern

```text
%p failed to create packed header buffer, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

The literal wording mentions a packed header, but the shared helper also creates sequence, picture, slice, and VP8 quantization buffers.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to create packed header buffer, 0x1
```

## Short description

VAAPI parameter buffer creation failed.

## Trigger condition

Creating a VA parameter buffer returns a non-success status.

## Explanation

The buffer is not added to the submission list and the current encoder initialization or frame operation fails.

## Possible causes

- The driver cannot create the requested sequence, picture, slice, or quantization parameter buffer.

## What to check

1. Check the status and encoding settings for the operation being initialized or submitted.

## Recommended action

Correct unsupported parameters or restore device resources and restart encoding.
