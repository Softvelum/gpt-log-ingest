# WebSocket client frame is unmasked

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-a34fc5014a95a263

## Log pattern

```text
all messages from client must be masked
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
all messages from client must be masked
```

## Short description

WebSocket client frame is unmasked.

## Trigger condition

The received client frame does not set its mask bit.

## Explanation

Command decoding fails and the caller closes the connection.

## Possible causes

- The received client frame does not set its mask bit.

## What to check

1. Check whether the client applies WebSocket masking to every outgoing frame.

## Recommended action

Use masked client frames.
