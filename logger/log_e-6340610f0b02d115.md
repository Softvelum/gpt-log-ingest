# H.264 encoding requires even dimensions

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-6340610f0b02d115

## Log pattern

```text
failed to encode non mod2 resolution=%dx%d
```

## Parameters

- Argument 1 — Width: Input width in pixels, integer.
- Argument 2 — Height: Input height in pixels, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encode non mod2 resolution=1921x1080
```

## Short description

H.264 encoding requires even dimensions.

## Trigger condition

The input width or height is odd.

## Explanation

H.264 encoder initialization fails.

## Possible causes

- At least one video dimension is not divisible by two.

## What to check

1. Check the video format and selected x264 profile, preset, tuning, and codec options.

## Recommended action

Correct the rejected encoder configuration.
