# DVR initialization record is being removed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_d
Log level: debug
Documentation ID: log_d-c6dcb6c198b16960

## Log pattern

```text
remove dvr f='%s' init for p=%u t=%u st=%llu of=%llu dbof=%u
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.
- Argument 2 — Period: Unsigned recording period identifier.
- Argument 3 — Segment type: Integer category: 0 video initialization, 1 audio initialization, 2 video, 3 audio, 4 shared data file, 5 JPEG, 6 DVB subtitles, 7 KLV metadata, 8 WebVTT.
- Argument 4 — Media start: Unsigned 64-bit media start timestamp in the segment track timescale.
- Argument 5 — File offset: Unsigned 64-bit byte offset within the media storage file.
- Argument 6 — Database offset: Unsigned byte offset of the segment record in its database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remove dvr f='/data/dvr/live/camera/1700000000000.dat' init for p=1 t=2 st=90000 of=1024 dbof=512
```

## Short description

DVR initialization record is being removed.

## Trigger condition

A storage file ready for deletion contains deferred initialization records.

## Explanation

The indicated database record is marked deleted before file removal is attempted.

## Possible causes

- A storage file ready for deletion contains deferred initialization records.
