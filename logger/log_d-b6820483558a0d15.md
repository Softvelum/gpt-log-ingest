# RTMP advertising wait expires and skips the item

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-b6820483558a0d15

## Log pattern

```text
s=%d, timer expired, skip advertising content %s
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Content URI: Configured URI of the selected advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, timer expired, skip advertising content https://media.example/ad.mp4
```

## Short description

RTMP advertising wait expires and skips the item.

## Trigger condition

The matching content-wait timer expires while the session is waiting and the error action is skip.

## Explanation

The observer and timer are removed; playback advances to the next scheduled content and resumes sending if possible.

## Possible causes

- The matching content-wait timer expires while the session is waiting and the error action is skip.

## What to check

1. Check download duration and the configured wait and skip policy.

## Recommended action

Make content available sooner or adjust the intended wait behavior.
