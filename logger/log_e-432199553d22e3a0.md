# Video source structure could not be loaded

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-432199553d22e3a0

## Log pattern

```text
failed to load mp4 file structure for file='%s'
```

## Parameters

- Argument 1 — Media filename: Text filesystem path of the source media.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load mp4 file structure for file='/media/movie.mp4'
```

## Short description

Video source structure could not be loaded.

## Trigger condition

A base MP4-loader exception is caught while loading a local source structure. The same catch text is present in the MKV preparation helper.

## Explanation

The file is unmapped and closed and preparation fails; callers cancel direct output or omit an optional source.

## Possible causes

- A base MP4-loader exception is caught while loading a local source structure. The same catch text is present in the MKV preparation helper.

## What to check

1. Check media structure and integrity. The fixed MP4 wording alone does not prove that the requested file was MP4.

## Recommended action

Check media structure and integrity. The fixed MP4 wording alone does not prove that the requested file was MP4.
