# DVR time lookup has no recording periods

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_v
Log level: verbose
Documentation ID: log_v-238a32852e67d053

## Log pattern

```text
failed to get period for empty dvr archive stream='%s/%s' utc_time=%llu
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Requested UTC: Unsigned requested time in seconds since the Unix epoch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get period for empty dvr archive stream='live/camera' utc_time=1700000000
```

## Short description

DVR time lookup has no recording periods.

## Trigger condition

A UTC lookup is attempted on an archive with an empty period map.

## Explanation

The period lookup fails.

## Possible causes

- A UTC lookup is attempted on an archive with an empty period map.

## What to check

1. Check whether the stream has recorded content or whether archive loading skipped its entries.

## Recommended action

Check whether the stream has recorded content or whether archive loading skipped its entries.
