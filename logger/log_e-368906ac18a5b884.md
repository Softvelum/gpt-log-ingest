# VAAPI cannot write chroma location metadata

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-368906ac18a5b884

## Log pattern

```text
chroma loc info not supported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
chroma loc info not supported
```

## Short description

VAAPI cannot write chroma location metadata.

## Trigger condition

The H.264 sequence settings mark chroma location information as present.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested chroma location metadata and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
