# DVR subtitle export closed

Product: Nimble Streamer
Component: DVR
Logging function: log_d
Log level: debug
Documentation ID: log_d-8fc909d1616a22a1

## Log pattern

```text
shutdown: stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch.

## Log examples

Illustrative examples; these are not captured server logs.

```text
shutdown: stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

DVR subtitle export closed.

## Trigger condition

Subtitle export completes or encounters a condition requiring shutdown.

## Explanation

The peer socket is shut down and the export is marked finished.

## Possible causes

- Subtitle export completes or encounters a condition requiring shutdown.

## What to check

1. Check preceding subtitle or transport errors if export was incomplete.

## Recommended action

Check preceding subtitle or transport errors if export was incomplete.
