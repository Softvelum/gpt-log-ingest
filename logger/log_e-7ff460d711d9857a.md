# Managed task process could not be started

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-7ff460d711d9857a

## Log pattern

```text
failed to start task='%s'
```

## Parameters

- Argument 1 — Command: Configured shell command text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start task='echo ready'
```

## Short description

Managed task process could not be started.

## Trigger condition

Creating the shell subprocess returns a negative process identifier. Available only on Linux builds.

## Explanation

Startup reports failure. The caller schedules another attempt only when a restart interval is configured.

## Possible causes

- Account lookup, pipe creation or process creation failed.

## What to check

1. Check the preceding account, pipe or process error.
