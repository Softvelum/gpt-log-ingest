# DVR database file size is unavailable

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-79c6f629d625e2f7

## Log pattern

```text
failed to get file='%s' size error=%d message()='%s'
```

## Parameters

- Argument 1 — Segment database: Text naming the recording segment-index database.
- Argument 2 — Filesystem error: Integer filesystem error code.
- Argument 3 — Error message: Text describing the reported filesystem failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get file='/data/dvr/live/camera/nimble-dvr-segments.db' size error=13 message()='Permission denied'
```

## Short description

DVR database file size is unavailable.

## Trigger condition

Resuming version-2 recording cannot obtain the actual segment database size.

## Explanation

The loaded database-offset position is used as the size fallback.

## Possible causes

- Resuming version-2 recording cannot obtain the actual segment database size.

## What to check

1. Check the database file and reported filesystem error.

## Recommended action

Check the database file and reported filesystem error.
