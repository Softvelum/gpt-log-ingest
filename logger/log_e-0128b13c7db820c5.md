# Connection session deletion raised an exception

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-0128b13c7db820c5

## Log pattern

```text
unknown exception while deleting session=%p
```

## Parameters

- Argument 1 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown exception while deleting session=0x1000
```

## Short description

Connection session deletion raised an exception.

## Trigger condition

An exception escapes session destruction or its surrounding cleanup.

## Explanation

The exception is reported and the caller continues. Occurrences cover HTTP-worker cleanup and advertising-download completion or a failed advertising redirect.

## Possible causes

- Session destruction or associated cleanup raised an exception.

## What to check

1. Compare this session with preceding completion, redirect and deletion messages.
