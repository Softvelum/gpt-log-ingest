# Disconnection statistics lack application or stream

Product: Nimble Streamer
Component: Streaming statistics
Logging function: log_e
Log level: error
Documentation ID: log_e-c0b087954b5a2fd8

## Log pattern

```text
Statistics::Disconnected invalid app='%s' stream='%s' protocol=%d
```

## Parameters

- Argument 1 — Application: Application name as text.
- Argument 2 — Stream: Stream name as text.
- Argument 3 — Protocol: Numeric internal session-type value for the disconnecting session.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Statistics::Disconnected invalid app='' stream='camera' protocol=0
```

## Short description

Disconnection statistics lack application or stream.

## Trigger condition

A disconnection notification has an empty application name or stream name.

## Explanation

No stream lookup or counter decrement is performed.

## Possible causes

- At least one required application or stream name is empty.

## What to check

1. Inspect both reported names.

## Recommended action

Provide nonempty application and stream names for the statistics notification.
