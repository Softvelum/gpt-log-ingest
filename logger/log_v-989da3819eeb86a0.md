# Origin response headers received

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-989da3819eeb86a0

## Log pattern

```text
origin s=%d response (header):
%.*s
```

## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.
- Argument 2 — Header byte limit: Pointer-difference byte distance to the body, incorrectly supplied as the int precision.
- Argument 3 — Response text: Raw response buffer; the precision is intended to restrict it to headers.

The text precision for %.*s is supplied as a pointer difference instead of int. Its width differs on 64-bit builds, so no portable exact example is provided.

## Log examples

The text precision for %.*s is supplied as a pointer difference instead of int. Its width differs on 64-bit builds, so no portable exact example is provided.

## Short description

Origin response headers received.

## Trigger condition

Parsed origin headers are complete and a body pointer is available.

## Explanation

Only bytes before the body are logged; status, redirects, and response length are then processed.

## Possible causes

- Parsed origin headers are complete and a body pointer is available.
