# Quick Sync output frame allocation failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-309798b9d17f28f5

## Log pattern

```text
failed to alloc output frame
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to alloc output frame
```

## Short description

Quick Sync output frame allocation failed.

## Trigger condition

Allocating the output frame or its NV12 pixel storage fails after a decoded surface becomes available.

## Explanation

No copied output frame is delivered and packet processing fails.

## Possible causes

- System memory cannot provide the frame object or aligned pixel storage.

## What to check

1. Check available memory and decoded frame dimensions.

## Recommended action

Restore memory availability or lower video memory demand and restart the affected stream.
