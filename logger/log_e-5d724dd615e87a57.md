# RTSP media socket could not bind its local port

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-5d724dd615e87a57

## Log pattern

```text
socket s=%d bind to port=%d failed (errno=%d)
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.
- Argument 2 — Local port: Decimal local UDP port selected for media or control.
- Argument 3 — Error number: Integer error value reported by the socket operation; its meaning depends on the operating system.

## Log examples

Illustrative examples; these are not captured server logs.

```text
socket s=26 bind to port=5000 failed (errno=98)
```

## Short description

RTSP media socket could not bind its local port.

## Trigger condition

Binding the created socket to all local IPv4 addresses on the chosen port fails.

## Explanation

The socket is closed and creation reports failure. UDP pair setup can then try another port pair.

## Possible causes

- Binding the created socket to all local IPv4 addresses on the chosen port fails.

## What to check

1. Check the reported socket error for the selected local port.
