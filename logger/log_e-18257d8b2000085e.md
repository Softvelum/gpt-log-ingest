# NDI audio frame cannot be serialized

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-18257d8b2000085e

## Log pattern

```text
invalid NDI audio message for [%s]
```

## Parameters

- Argument 1 — Output: Local output stream or AJA writer name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid NDI audio message for [camera]
```

## Short description

NDI audio frame cannot be serialized.

## Trigger condition

Creating the outgoing NDI audio message fails validation, size accounting, or payload writes.

## Explanation

The frame is rejected before writer-state checking and queueing.

## Possible causes

- The frame is missing, not planar float audio, has invalid sample counts/rate/strides, missing channel planes, an unsupported native channel mask, too many channels for the frame data pointers, or an oversized message.

## What to check

1. Check sample format, channel layout, samples, and payload size; the complete message must fit within 20 megabytes.

## Recommended action

Provide valid planar float audio with a matching native channel mask and supported channel count.
