# WHIP incomplete request cannot await output

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-247d9e5475f463c7

## Log pattern

```text
whip control socket failed to switch to output on partial send of new session request
```

## Parameters

The code reaches this branch after any non-full send not handled by the would-block branch, including a hard negative send result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
whip control socket failed to switch to output on partial send of new session request
```

## Short description

WHIP incomplete request cannot await output.

## Trigger condition

An initial control send leaves an incomplete session request and enabling writable events fails.

## Explanation

The control socket is closed, pending starts are marked finished, pending data is cleared, and active WHIP publications are removed and their stream registrations released. The current session is marked finished and its authorization record is removed.

## Possible causes

- The event monitor rejects the socket update after an incomplete send.

## What to check

1. Check for partial-send or connection failures immediately before this event.

## Recommended action

Restore the helper control connection and retry.
