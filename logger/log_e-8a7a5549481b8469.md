# Default OCR language data unavailable

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_e
Log level: error
Documentation ID: log_e-8a7a5549481b8469

## Log pattern

```text
default tesseract lang doesn't found, add eng.traineddata into %s folder
```

## Parameters

- Argument 1 — Directory: Configured Tesseract training-data directory.

## Log examples

Illustrative examples; these are not captured server logs.

```text
default tesseract lang doesn't found, add eng.traineddata into /data/tessdata folder
```

## Short description

Default OCR language data unavailable.

## Trigger condition

Tesseract initialization with its default language fails during language discovery.

## Explanation

Language discovery fails and processing of this subtitle message returns failure. The diagnostic requests English training data in the configured directory.

## Possible causes

- Tesseract initialization with its default language fails during language discovery.

## What to check

1. Check the training-data directory and availability of English language data.

## Recommended action

Install readable English training data in the configured directory.
