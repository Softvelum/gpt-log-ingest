# Decoded AAC samples could not be copied

Product: Nimble Streamer
Component: FDK AAC audio decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-3cd5180475d18d4b

## Log pattern

```text
failed to copy frame data, %d
```

## Parameters

- Argument 1 — Copy result: FFmpeg sample-copy return code, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to copy frame data, -22
```

## Short description

Decoded AAC samples could not be copied.

## Trigger condition

In an FDK-enabled build, copying decoded samples into the allocated output frame returns a nonzero result.

## Explanation

The output frame is not forwarded and packet processing fails.

## Possible causes

- The decoder or sample-handling operation described by the message failed.

## What to check

1. Check the AAC input parameters and accompanying decoder diagnostics.

## Recommended action

Resolve the indicated AAC decode or output-frame failure.
