# Bounded count or cache size is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-7455b129d785324f

## Log pattern

```text
invalid parameter value: %s. should be >= 1 && <= 100
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1 && <= 100
```

## Short description

Bounded count or cache size is invalid.

## Trigger condition

While reading configuration, the Whisper transcriber stream limit, in builds with Whisper support, or remote-VOD cache granularity is outside 1 through 100.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 1 through 100 streams for transcription or 1 through 100 megabytes for remote-VOD cache granularity.

## Recommended action

Correct the value to 1 through 100 streams for transcription or 1 through 100 megabytes for remote-VOD cache granularity and reload configuration.
