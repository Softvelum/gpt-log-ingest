# AJA sender host buffers failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-d11f484e6e26492d

## Log pattern

```text
sender init failed device=%s/%d reason='host buffer setup failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender init failed device=0/0 reason='host buffer setup failed'
```

## Short description

AJA sender host buffers failed.

## Trigger condition

Starting the sender fails because video/audio host-buffer allocation or device memory locking fails.

## Explanation

Output signal routing and frame-circulation initialization are not attempted.

## Possible causes

- Starting the sender fails because video/audio host-buffer allocation or device memory locking fails.

## What to check

1. Check the preceding host buffers diagnostics and the selected device/channel.
