# DVR transmux request leaves its queue

Product: Nimble Streamer
Component: DVR
Logging function: log_d
Log level: debug
Documentation ID: log_d-0df74f6237a1ff77

## Log pattern

```text
[DTRQ::Pop] stream='%s' chunk='%s' key='%s' qsize=%zu
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Chunk name: Text naming the requested recorded media chunk.
- Argument 3 — Cache key: Text identifying the requested output in the cache.
- Argument 4 — Queue size: Unsigned number of queued requests after removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DTRQ::Pop] stream='live/camera' chunk='dvr_v_p1_90000.m4s' key='/live/camera/dvr_v_p1_90000.m4s' qsize=1
```

## Short description

DVR transmux request leaves its queue.

## Trigger condition

The front request has been removed from a nonempty queue.

## Explanation

The request is returned for processing.

## Possible causes

- The front request has been removed from a nonempty queue.
