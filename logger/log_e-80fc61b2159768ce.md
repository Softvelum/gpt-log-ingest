# Cannot remove SRT socket from event poller

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-80fc61b2159768ce

## Log pattern

```text
srt_epoll_remove_usock epfd=%d failed for fd=%d: %s
```

## Parameters

- Argument 1 — Poller: SRT event-poller identifier.
- Argument 2 — Socket: SRT socket or group identifier.
- Argument 3 — Error: SRT library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt_epoll_remove_usock epfd=1 failed for fd=100: Invalid socket ID
```

## Short description

Cannot remove SRT socket from event poller.

## Trigger condition

The SRT library rejects removing the socket from the poller.

## Explanation

The removal operation returns failure; the log does not confirm removal.

## Possible causes

- The SRT library rejects removing the socket from the poller.

## What to check

1. Check the socket identity and prior registration or removal messages.
