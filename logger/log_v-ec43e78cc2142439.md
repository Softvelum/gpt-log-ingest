# Incompatible disk cache cleaning started

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-ec43e78cc2142439

## Log pattern

```text
Start cache cleaning from path='%s'
```

## Parameters

- Argument 1 — directory: Disk cache root whose protocol subdirectories are scanned.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Start cache cleaning from path='/var/cache/nimble'
```

## Short description

Incompatible disk cache cleaning started.

## Trigger condition

The stored version was missing or different and the replacement marker was written.

## Explanation

The cache iterates protocol directories and attempts to remove regular files. File deletion results are not individually checked in this loop.
