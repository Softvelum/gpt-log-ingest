# RTMP response object field cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-674110603ca5e0a7

## Log pattern

```text
cannot process AMF object
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process AMF object
```

## Short description

RTMP response object field cannot be decoded.

## Trigger condition

Reading the next AMF object field name fails during a connect result, Limelight authentication response, play status, or publish status.

## Explanation

Behavior depends on the response. Connect and Limelight parsing continue after the log. Play and publish status parsing leave the field loop and then treat the missing status code as success. This message therefore does not by itself prove that the connection was rejected.

## Possible causes

- Reading the next AMF object field name fails during a connect result, Limelight authentication response, play status, or publish status.

## What to check

1. Identify the response command and inspect its AMF object framing and subsequent connection logs.

## Recommended action

Correct malformed object fields at the remote server.
