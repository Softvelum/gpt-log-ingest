# VCAS get-key request failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-5dd5da8405a5c625

## Log pattern

```text
VCAS failed to get key url='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VCAS failed to get key url='https://keys.example/key'
```

## Short description

VCAS get-key request failed.

## Trigger condition

A submitted VCAS get-key request receives a failure callback.

## Explanation

The matching registered key is marked failed; an unknown URL produces a further diagnostic.

## Possible causes

- A submitted VCAS get-key request receives a failure callback.

## What to check

1. Check the VCAS get-key response or transport failure.

## Recommended action

Check the VCAS get-key response or transport failure.
