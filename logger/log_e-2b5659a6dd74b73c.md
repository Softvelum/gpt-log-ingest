# AAC sample-rate index unsupported

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-2b5659a6dd74b73c

## Log pattern

```text
icecast stream aac sampling frequency unknown %s %d
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.
- Argument 2 — Index: Four-bit ADTS sampling-frequency index.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream aac sampling frequency unknown http://radio.example.net/live 15
```

## Short description

AAC sample-rate index unsupported.

## Trigger condition

The ADTS sampling-frequency index maps to a zero sampling rate.

## Explanation

The Icecast ingest session is shut down before the frame length is processed.

## Possible causes

- The ADTS sampling-frequency index maps to a zero sampling rate.

## What to check

1. Check the source ADTS sampling-frequency index.

## Recommended action

Supply an AAC stream with a recognized sample-rate index.
