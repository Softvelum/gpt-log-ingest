# Panel synchronization thread started

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-b954b44ae91d3c39

## Log pattern

```text
wmspanelSyncThread started
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
wmspanelSyncThread started
```

## Short description

Panel synchronization thread started.

## Trigger condition

The synchronization thread begins before checking the configured server identity and disabled state.

## Explanation

The thread can immediately stop if the panel identity is empty or synchronization is disabled; this message does not prove that a request was sent.
