# Configured audio language descriptor is invalid

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_e
Log level: error
Documentation ID: log_e-9bf8c21793ea8849

## Log pattern

```text
failed to create language descriptor: language_code=%s audio_type=%d stream=[%s/%s]
```

## Parameters

- Argument 1 — language\_code: Configured audio language code.
- Argument 2 — audio\_type: Audio type byte printed as a decimal integer.
- Argument 3 — application: Configured application name.
- Argument 4 — stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create language descriptor: language_code=en audio_type=0 stream=[live/camera]
```

## Short description

Configured audio language descriptor is invalid.

## Trigger condition

Live-stream construction receives a nonempty audio language code, but language-descriptor creation returns no descriptor.

## Explanation

The descriptor helper rejects language strings whose length is not exactly three bytes. Construction continues without that configured language descriptor; this log does not stop stream creation.

## Possible causes

- The nonempty language code does not contain exactly three bytes.

## What to check

1. Check the configured audio language code length.

## Recommended action

Supply a three-byte language code.
