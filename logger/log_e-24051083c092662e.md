# VCAS rejected asset creation

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-24051083c092662e

## Log pattern

```text
VCAS createAsset failed url='%s' code='%s' message='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Provider status: Text containing the provider status code.
- Argument 3 — Provider message: Text explaining the provider status.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VCAS createAsset failed url='https://keys.example/key' code='ERROR' message='asset unavailable'
```

## Short description

VCAS rejected asset creation.

## Trigger condition

A parsed create-asset response has a status other than OK.

## Explanation

The application key set is erased and no keys are created.

## Possible causes

- A parsed create-asset response has a status other than OK.

## What to check

1. Correct the asset or authorization problem reported by VCAS.

## Recommended action

Correct the asset or authorization problem reported by VCAS.
