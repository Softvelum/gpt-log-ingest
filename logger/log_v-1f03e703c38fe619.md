# Cache storage path already exists

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-1f03e703c38fe619

## Log pattern

```text
file='%s' already exists
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
file='/var/cache/nimble/movie' already exists
```

## Short description

Cache storage path already exists.

## Trigger condition

A target data file or its parent directory already exists during disk allocation.

## Explanation

For an existing data file, a replacement item tries numbered alternative names; a nonreplacement allocation fails. An existing parent directory is simply reused.
