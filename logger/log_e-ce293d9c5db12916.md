# FFmpeg video encoder initialization failed

Product: Nimble Streamer
Component: FFmpeg video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-ce293d9c5db12916

## Log pattern

```text
failed to init video encoder for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init video encoder for [live/camera]
```

## Short description

FFmpeg video encoder initialization failed.

## Trigger condition

First-frame encoder setup returns failure.

## Explanation

The frame write stops before submitting any picture to that encoder.

## Possible causes

- Encoder lookup, allocation, format selection/conversion, hardware-context setup, codec opening or configuration publishing fails.

## What to check

1. Check the preceding detailed encoder initialization message for this stream.

## Recommended action

Correct that specific initialization failure.
