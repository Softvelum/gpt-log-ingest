# Required video acceleration DRM display library is unavailable

Product: Nimble Streamer
Component: Linux video acceleration initialization
Logging function: log_i
Log level: info
Documentation ID: log_i-4362c686bb4a271d

## Log pattern

```text
failed to load libva-drm
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load libva-drm
```

## Short description

Required video acceleration DRM display library is unavailable.

## Trigger condition

In a Linux Quick Sync or VA-API build, a required video acceleration DRM display library function pointer is unavailable.

## Explanation

Video acceleration display opening returns failure without probing devices.

## Possible causes

- The required runtime library was not loaded successfully.

## What to check

1. Check availability of the video acceleration DRM display library.

## Recommended action

Install or load compatible video acceleration libraries.
