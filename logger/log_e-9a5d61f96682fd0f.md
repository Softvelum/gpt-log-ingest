# Live HTTP pull redirect host is invalid

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-9a5d61f96682fd0f

## Log pattern

```text
invalid redirect location(split): %s
```

## Parameters

- Argument 1 — location: Redirect URL returned by the origin.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid redirect location(split): https://media.example:invalid/live
```

## Short description

Live HTTP pull redirect host is invalid.

## Trigger condition

The redirect host cannot be split into hostname and port.

## Explanation

A probe connection is removed and periodic probing is restarted. A normal receiver is removed and its settings are scheduled for synchronization again.

## Possible causes

- The redirect host cannot be split into hostname and port.

## What to check

1. Inspect the origin redirect target.

## Recommended action

Correct the redirect to a usable HTTP or HTTPS address.
