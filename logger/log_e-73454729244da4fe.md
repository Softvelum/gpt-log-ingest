# MPEG-TS camera worker count is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-73454729244da4fe

## Log pattern

```text
invalid parameter value: %s, should be >=0 && <= 512
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0, should be >=0 && <= 512
```

## Short description

MPEG-TS camera worker count is invalid.

## Trigger condition

While reading configuration, the MPEG-TS camera worker count is zero, negative, or above 512.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 1 through 512 workers; despite the printed lower bound, zero is rejected.

## Recommended action

Correct the value to 1 through 512 workers; despite the printed lower bound, zero is rejected and reload configuration.
