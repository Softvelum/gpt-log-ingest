# NVIDIA input-format list query failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-43884a8e1c28a43e

## Log pattern

```text
failed to get nvenc format list for [%s], %d
```

## Parameters

- Argument 1 — Stream: Output stream name, text.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get nvenc format list for [live/camera], 8
```

## Short description

NVIDIA input-format list query failed.

## Trigger condition

The input pixel format is neither YUV420P nor NV12, and querying the supported encoder input-format list returns an error.

## Explanation

Encoder initialization fails before selecting a direct or converted input format.

## Possible causes

- The driver cannot enumerate input formats for this codec/session.

## What to check

1. Check the result code, input format and driver codec support.

## Recommended action

Restore supported format enumeration or supply YUV420P/NV12 input.
