# Management GET or DELETE request received

Product: Nimble Streamer
Component: HTTP management API
Logging function: log_d
Log level: debug
Documentation ID: log_d-d1d065bb1a76006a

## Log pattern

```text
processing request url='%s'
```

## Parameters

- Argument 1 — request\_url: The received URL including any query string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
processing request url='/manage/server_status'
```

## Short description

Management GET or DELETE request received.

## Trigger condition

A complete parsed GET or DELETE request reaches management request dispatch.

## Explanation

The complete URL, including query parameters, is logged before management-token validation and route selection. This message alone does not mean the request was authorized or completed.
