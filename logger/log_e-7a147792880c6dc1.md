# AAC encoder initialization failed

Product: Nimble Streamer
Component: FDK AAC audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-7a147792880c6dc1

## Log pattern

```text
failed to init the encoder, status=%d
```

## Parameters

- Argument 1 — Library status: Library-specific status code, integer; not an operating system error.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init the encoder, status=1
```

## Short description

AAC encoder initialization failed.

## Trigger condition

In an FDK-enabled build, finalizing the configured encoder with an empty encode call returns a non-success library status.

## Explanation

Encoder initialization fails and the triggering frame write returns failure.

## Possible causes

- FDK rejected encoder initialization for the selected audio settings.

## What to check

1. Check the reported FDK status and settings involved in encoder initialization.

## Recommended action

Use compatible AAC audio settings or resolve the reported library failure.
