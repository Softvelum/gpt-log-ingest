# Scenario connection request received

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_d
Log level: debug
Documentation ID: log_d-c962e04495dd4381

## Log pattern

```text
connecting sock=%d scenario=%s
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connecting sock=12 scenario=scenario1
```

## Short description

Scenario connection request received.

## Trigger condition

An accepted socket contains a complete initial connect message with a scenario identifier.

## Explanation

The parent looks for the named scenario before attaching the socket.
