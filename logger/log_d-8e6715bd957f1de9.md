# Expired disk cache item skipped

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-8e6715bd957f1de9

## Log pattern

```text
cache item='%s' is expired
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item='movie' is expired
```

## Short description

Expired disk cache item skipped.

## Trigger condition

Stored metadata describes an expired nonfragmented item.

## Explanation

The data and metadata are removed instead of registering the item in the active cache.
