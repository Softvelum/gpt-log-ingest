# RTMP handshake version is unsupported

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-382bcb9017b58700

## Log pattern

```text
Invalid protocol version: %d
```

## Parameters

- Argument 1 — Version: Unsigned first handshake byte printed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Invalid protocol version: 6
```

## Short description

RTMP handshake version is unsupported.

## Trigger condition

The first byte of a complete incoming client or server handshake is not protocol version 3.

## Explanation

The handshake is rejected and the connection is shut down before RTMP commands are processed.

## Possible causes

- The first byte of a complete incoming client or server handshake is not protocol version 3.

## What to check

1. Check the first handshake byte and whether the peer is using the intended RTMP endpoint.

## Recommended action

Use RTMP version 3 on the configured endpoint.
