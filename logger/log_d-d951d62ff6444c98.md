# Advertising download socket event

Product: Nimble Streamer
Component: Advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-d951d62ff6444c98

## Log pattern

```text
ClientSession::ProcessEvent p=%p (state=%d s=%d ev=0x%x)
```

## Parameters

- Argument 1 — Session address: Pointer identifying the session in this process.
- Argument 2 — Session state: Integer representing the advertising download session state.
- Argument 3 — Socket descriptor: Integer identifying the local socket.
- Argument 4 — Socket events: Hexadecimal mask of events reported for the socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ClientSession::ProcessEvent p=0x1234 (state=2 s=17 ev=0x10)
```

## Short description

Advertising download socket event.

## Trigger condition

The advertising download session receives a socket event.

## Explanation

The activity time is updated, then the event is handled according to session state and TLS direction.

## Possible causes

- The advertising download session receives a socket event.

## What to check

1. Use the state and socket identifier to correlate the subsequent connection messages.
