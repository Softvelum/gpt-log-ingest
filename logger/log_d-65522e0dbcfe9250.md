# Audio component added

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_d
Log level: debug
Documentation ID: log_d-65522e0dbcfe9250

## Log pattern

```text
audio encoder added for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

Initial output becomes audio-only unless audio must follow video, when it waits for video. Adding to video-only output starts combined processing with audio paused until video advances.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio encoder added for live/encoded
```

## Short description

Audio component added.

## Trigger condition

An audio-settings update is applied in an initial or video-only state where audio can be added.

## Explanation

The processing state is updated before the audio source or encoder is configured.
