# Required VOD cache item updated

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-2937bea2340749f0

## Log pattern

```text
[CliS::OnCIU] sst=%d key='%s'
```

## Parameters

- Argument 1 — Session state: Integer identifying the HTTP client session phase: 0 reading a request, 1 sending a response, 2 connecting to origin, 3 sending to origin, 4 reading origin headers, 5 reading an origin playlist, 6 reading origin media, 29 shutting down, or 30 finished; intermediate values identify pending asynchronous work.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[CliS::OnCIU] sst=4 key='/live/camera/segment1.ts'
```

## Short description

Required VOD cache item updated.

## Trigger condition

A cache update arrives while the request is waiting for several SMIL-referenced VOD items.

## Explanation

The matching required item is released and removed from the wait set; missing keys fail the request, and an empty wait set resumes processing.

## Possible causes

- A cache update arrives while the request is waiting for several SMIL-referenced VOD items.
