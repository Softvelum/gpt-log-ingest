# DVR archive loading completed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_v
Log level: verbose
Documentation ID: log_v-cd13f0f42a5c6462

## Log pattern

```text
DvrArchive::LoadArchive app='%s' stream='%s' path='%s' segments_loaded=%u p=%u
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Archive directory: Text giving the archive or time-bucket directory.
- Argument 4 — Loaded segments: Unsigned number of accepted segment entries.
- Argument 5 — Latest period: Unsigned highest loaded recording period.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DvrArchive::LoadArchive app='live' stream='camera' path='/data/dvr/live/camera/1700000000000' segments_loaded=120 p=2
```

## Short description

DVR archive loading completed.

## Trigger condition

All time buckets finish without a fatal metadata error or exit request.

## Explanation

The archive is marked ready and load/update times are stored. Some invalid records may have been skipped.

## Possible causes

- All time buckets finish without a fatal metadata error or exit request.

## What to check

1. Check earlier skipped-record messages if recordings are missing.

Check earlier skipped-record messages if recordings are missing.
