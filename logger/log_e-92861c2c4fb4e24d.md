# FFmpeg encoder input conversion failed

Product: Nimble Streamer
Component: FFmpeg video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-92861c2c4fb4e24d

## Log pattern

```text
failed to convert frame: %d->%d for [%s]
```

## Parameters

- Argument 1 — Input format: FFmpeg input pixel-format identifier, integer.
- Argument 2 — Output format: Chosen FFmpeg destination pixel-format identifier, integer.
- Argument 3 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to convert frame: 0->23 for [live/camera]
```

## Short description

FFmpeg encoder input conversion failed.

## Trigger condition

Converting the current frame to the encoder selected pixel format returns failure.

## Explanation

The current frame write stops before submitting the frame.

## Possible causes

- Converted-frame allocation, property copying, pixel-buffer allocation or image conversion fails.

## What to check

1. Check source and destination formats, frame validity and host memory.

## Recommended action

Restore conversion resources or supply input in the encoder format.
