# AJA output format could not be inferred

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-323505df4d2b55aa

## Log pattern

```text
failed to infer AJA output format for %s size=%dx%d fps=%d/%d interlaced=%d
```

## Parameters

- Argument 1 — Session name: Configured AJA device and channel name.
- Argument 2 — Width: Video width in pixels.
- Argument 3 — Height: Video height in pixels.
- Argument 4 — Frame-rate numerator: Numerator of the displayed frames-per-second ratio.
- Argument 5 — Frame-rate denominator: Denominator of the displayed frames-per-second ratio.
- Argument 6 — Interlaced flag: One for interlaced video, otherwise zero.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to infer AJA output format for 0/0 size=640x360 fps=25/1 interlaced=0
```

## Short description

AJA output format could not be inferred.

## Trigger condition

Incoming geometry, frame rate, or interlace mode cannot be mapped to a recognized AJA video format.

## Explanation

Video configuration returns failure without recording a configured output format. Supported geometry and frame-rate mappings are checked before the device-format lookup.

## Possible causes

- Incoming geometry, frame rate, or interlace mode cannot be mapped to a recognized AJA video format.

## What to check

1. Check the displayed frame geometry, rational frame rate, and interlace flag.

## Recommended action

Supply a video format that maps to a supported AJA output mode.
