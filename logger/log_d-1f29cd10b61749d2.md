# Waiting for more cached body data

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-1f29cd10b61749d2

## Log pattern

```text
waiting for more data for s=%d key='%s'
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waiting for more data for s=18 key='/live/camera/segment1.ts'
```

## Short description

Waiting for more cached body data.

## Trigger condition

An incomplete asynchronously sent cached response exhausts the bytes currently available.

## Explanation

Client output monitoring is paused until another cache update makes more bytes available.

## Possible causes

- An incomplete asynchronously sent cached response exhausts the bytes currently available.
