# Cannot read accepted SRT publisher stream ID

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-b5182b473155469a

## Log pattern

```text
failed to get srt streamid, s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get srt streamid, s=101
```

## Short description

Cannot read accepted SRT publisher stream ID.

## Trigger condition

A listener configured for stream-ID processing cannot read the accepted socket stream-ID option.

## Explanation

The accepted socket is closed before camera creation.

## Possible causes

- A listener configured for stream-ID processing cannot read the accepted socket stream-ID option.

## What to check

1. Check the publisher handshake and preceding SRT errors.
