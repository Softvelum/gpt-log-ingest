# MPEG-2 picture segment is empty

Product: Nimble Streamer
Component: Video decoding
Logging function: log_e
Log level: error
Documentation ID: log_e-84c5f528bc77e8c0

## Log pattern

```text
invalid mpeg2video packet size [%s/%s]
```

## Parameters

- Argument 1 — Application: Application name, text.
- Argument 2 — Stream: Stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid mpeg2video packet size [live/camera]
```

## Short description

MPEG-2 picture segment is empty.

## Trigger condition

While splitting a live MPEG-2 message at a later picture start code, the computed preceding packet length is nonpositive.

## Explanation

The segment is rejected before decoding and the video worker stops.

## Possible causes

- The calculated picture boundary does not advance beyond the packet start; this is a defensive consistency check in the start-code scan.

## What to check

1. Inspect MPEG-2 picture start codes and retain the failing input message.

## Recommended action

Correct malformed MPEG-2 input or investigate a reproducible boundary calculation failure.
