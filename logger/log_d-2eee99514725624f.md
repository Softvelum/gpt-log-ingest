# Tesseract library loading failed

Product: Nimble Streamer
Component: DVB subtitle text recognition
Logging function: log_d
Log level: debug
Documentation ID: log_d-2eee99514725624f

## Log pattern

```text
LoadTesseractLibrary exception what()='%s'
```

## Parameters

- Argument 1 — Error: Exception description returned by the library loader.

## Log examples

Illustrative examples; these are not captured server logs.

```text
LoadTesseractLibrary exception what()='OCR library unavailable'
```

## Short description

Tesseract library loading failed.

## Trigger condition

Loading the OCR library or resolving its required entry points throws an exception.

## Explanation

The partial library handle is closed and OCR library initialization returns failure.

## Possible causes

- Loading the OCR library or resolving its required entry points throws an exception.

## What to check

1. Read the exception text for the missing library, missing entry point, or loading error.
