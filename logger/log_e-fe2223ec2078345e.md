# RTSP request received an unsuccessful response

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-fe2223ec2078345e

## Log pattern

```text
bad rtsp status = %d on socket %d
```

## Parameters

- Argument 1 — RTSP status: Decimal response status code.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
bad rtsp status = 404 on socket 25
```

## Short description

RTSP request received an unsuccessful response.

## Trigger condition

A complete response has status other than 200 and is not handled by the authentication or transport-fallback branches.

## Explanation

The input requests shutdown rather than advancing protocol negotiation.

## Possible causes

- A complete response has status other than 200 and is not handled by the authentication or transport-fallback branches.

## What to check

1. Check the status returned for the outstanding RTSP request.
