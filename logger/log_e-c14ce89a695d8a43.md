# VCAS asset request failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-c14ce89a695d8a43

## Log pattern

```text
VCAS failed to create asset id='%s' url='%s'
```

## Parameters

- Argument 1 — Asset ID: Text identifying the VCAS asset.
- Argument 2 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VCAS failed to create asset id='asset-01' url='https://keys.example/key'
```

## Short description

VCAS asset request failed.

## Trigger condition

A submitted VCAS create-asset request receives a failure callback.

## Explanation

Its pending request and application key set are removed.

## Possible causes

- A submitted VCAS create-asset request receives a failure callback.

## What to check

1. Check VCAS availability, authorization, and asset identifiers.

## Recommended action

Check VCAS availability, authorization, and asset identifiers.
