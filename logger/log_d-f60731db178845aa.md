# VAAPI reference limits reported

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-f60731db178845aa

## Log pattern

```text
ref_l0=%d, ref_l1=%d
```

## Parameters

- Argument 1 — List 0 references: Driver maximum for reference list 0, unsigned integer frame count.
- Argument 2 — List 1 references: Driver maximum for reference list 1, unsigned integer frame count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ref_l0=2, ref_l1=1
```

## Short description

VAAPI reference limits reported.

## Trigger condition

The H.264 maximum-reference-frame query succeeds.

## Explanation

The supported list limits are reported. The encoder subsequently selects one reference without B frames or two with B frames.
