# Filtered video could not be read

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-086ec495ddf57441

## Log pattern

```text
failed to get filtered frame ret=%s, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Error text: Diagnostic description supplied by the operating system or library, text.
- Argument 2 — Filter: Complete configured video filter expression, text.
- Argument 3 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get filtered frame ret=operation failed, filter=[in]null[out], stream=live/camera
```

## Short description

Filtered video could not be read.

## Trigger condition

Reading a video filter output returns an error other than need-more-input or end-of-stream.

## Explanation

Video frame processing fails.

## Possible causes

- FFmpeg reported the included video-filter error.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
