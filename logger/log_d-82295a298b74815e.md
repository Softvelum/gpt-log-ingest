# Wildcard adaptive-stream mapping matched

Product: Nimble Streamer
Component: Adaptive live delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-82295a298b74815e

## Log pattern

```text
matched wildcard ABR app='%s' stream='%s' live stream='%s'
```

## Parameters

- Argument 1 — application: Requested application used to select the adaptive settings.
- Argument 2 — requested\_stream: Requested stream name compared with the expanded template.
- Argument 3 — live\_stream: Live-stream name computed from the matching wildcard rendition.

## Log examples

Illustrative examples; these are not captured server logs.

```text
matched wildcard ABR app='abr' stream='camera/720p' live stream='live/camera_720p'
```

## Short description

Wildcard adaptive-stream mapping matched.

## Trigger condition

Replacing the wildcard stream placeholder in a rendition template produces the requested stream name.

## Explanation

The matching live-stream name and optional rendition-report details are returned to the caller. Matching a rule does not by itself prove that its live stream is currently available.
