# Listener event registration failed

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-5ef94384817611ea

## Log pattern

```text
failed to add listening s=%d to selector fd=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Event monitor: Linux event-monitor descriptor, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to add listening s=12 to selector fd=10
```

## Short description

Listener event registration failed.

## Trigger condition

Adding the listening socket to the event monitor fails.

## Explanation

The listener is closed and setup returns failure even though listening had already started.

## Possible causes

- The event monitor rejected input registration.

## What to check

1. Check preceding event-monitor diagnostics.

## Recommended action

Resolve the registration failure.
