# Cache file unmapping failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-45472f64268fad6d

## Log pattern

```text
munmap failed key='%s' fd=%d errno=%d
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — descriptor: Open file descriptor used for the operation.
- Argument 3 — error: Operating system error number reported for the failed operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
munmap failed key='movie' fd=12 errno=22
```

## Short description

Cache file unmapping failed.

## Trigger condition

A non-Windows cache data mapping cannot be unmapped.

## Explanation

The cache clears its recorded data pointer and continues to close the file despite the unmapping error.

## Possible causes

- The operating system rejected the indicated cleanup operation.

## What to check

1. Use the error number and preceding mapping lifecycle messages for the key.

## Recommended action

Investigate the failed file cleanup.
