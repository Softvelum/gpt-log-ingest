# NVIDIA context cache initialization finished

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-bfa5790e50e1b225

## Log pattern

```text
nvenc context cache initialized, %ld(ms)
```

## Parameters

- Argument 1 — Duration: Elapsed wall-clock duration, signed long milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
nvenc context cache initialized, 12(ms)
```

## Short description

NVIDIA context cache initialization finished.

## Trigger condition

All configured cache fill batches have returned.

## Explanation

Cache initialization has finished; this does not guarantee every allocation succeeded, so preceding allocation failures still matter.
