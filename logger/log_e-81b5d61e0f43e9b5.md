# RTMP aggregate contains another aggregate

Component: RTMP command handling
Logging function: log_e

## Log pattern

```text
failed to process aggregated message. Don't support aggregated submessages
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

RTMP aggregate contains another aggregate.

## Trigger condition

An RTMP aggregate submessage has the aggregate message type.

## Explanation

Nested aggregation is unsupported; the aggregate is rejected and connection processing fails.

## Possible causes

- An RTMP aggregate submessage has the aggregate message type.

## What to check

1. Check whether the sender nests aggregate messages.

## Recommended action

Configure the sender to place supported media or command submessages directly in the aggregate.
