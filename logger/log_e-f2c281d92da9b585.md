# AJA sender audio setup failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-f2c281d92da9b585

## Log pattern

```text
sender init failed device=%s/%d reason='audio setup failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender init failed device=0/0 reason='audio setup failed'
```

## Short description

AJA sender audio setup failed.

## Trigger condition

Starting the sender fails because configuring the output audio system fails.

## Explanation

Host-buffer preparation is not attempted.

## Possible causes

- Starting the sender fails because configuring the output audio system fails.

## What to check

1. Check the preceding audio setup diagnostics and the selected device/channel.
