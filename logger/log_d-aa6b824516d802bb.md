# DVR DASH manifest waits for DRM signaling

Product: Nimble Streamer
Component: DVR playback conversion
Logging function: log_d
Log level: debug
Documentation ID: log_d-aa6b824516d802bb

## Log pattern

```text
wait for DRM key for Pallycon stream='%s'
```

## Parameters

- Argument 1 — Manifest path: Text containing the application, stream, and manifest resource path.

## Log examples

Illustrative examples; these are not captured server logs.

```text
wait for DRM key for Pallycon stream='/live/camera/manifest.mpd'
```

## Short description

DVR DASH manifest waits for DRM signaling.

## Trigger condition

The manifest needs DRM protection-header data and usable keys have not arrived.

## Explanation

The request is postponed unless its queue is full. The wording names PallyCon but the manifest check covers providers whose keys supply these headers.

## Possible causes

- The manifest needs DRM protection-header data and usable keys have not arrived.

## What to check

1. Check the pending DRM key request and provider response.

## Recommended action

Check the pending DRM key request and provider response.
