# Buffered response bytes ready to send

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-7f4a0e7438576aa1

## Log pattern

```text
%llu avail from %p for cli s=%d
```

## Parameters

- Argument 1 — Available bytes: Unsigned 64-bit contiguous bytes available for this send.
- Argument 2 — Data address: Pointer to the start of the data block within the cache or circular buffer.
- Argument 3 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
8192 avail from 0x1234 for cli s=18
```

## Short description

Buffered response bytes ready to send.

## Trigger condition

The asynchronous response sender identifies a contiguous block of body data for the client.

## Explanation

It attempts a write using the shown memory address and length.

## Possible causes

- The asynchronous response sender identifies a contiguous block of body data for the client.
