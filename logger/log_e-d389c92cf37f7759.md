# FFmpeg video encoder opening failed

Product: Nimble Streamer
Component: FFmpeg video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-d389c92cf37f7759

## Log pattern

```text
failed to open %s video encoder for [%s]: %s
```

## Parameters

- Argument 1 — Encoder name: Requested FFmpeg encoder name, text.
- Argument 2 — Stream: Output stream name, text.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open h264_nvenc video encoder for [live/camera]: operation failed
```

## Short description

FFmpeg video encoder opening failed.

## Trigger condition

Opening the configured FFmpeg encoder returns a negative result.

## Explanation

The encoder context is freed and cleared, and initialization returns failure.

## Possible causes

- The encoder rejects the configured options, frame parameters or hardware resources.

## What to check

1. Check the error text, named encoder, video settings and required device availability.

## Recommended action

Correct the reported configuration or resource issue.
