# RTMP legacy audio format is unsupported

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-f9413d81d4557966

## Log pattern

```text
[AM] format not supported %d
```

## Parameters

- Argument 1 — Audio format: Numeric legacy audio format from the first tag byte; supported legacy values are 2 for MP3, 10 for AAC, and 11 for Speex.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] format not supported 7
```

## Short description

RTMP legacy audio format is unsupported.

## Trigger condition

The legacy audio tag format is neither MP3, AAC, nor Speex and does not select an enhanced audio header.

## Explanation

The audio message is rejected and connection processing fails.

## Possible causes

- The legacy audio tag format is neither MP3, AAC, nor Speex and does not select an enhanced audio header.

## What to check

1. Check the high four bits of the first audio tag byte and the encoder audio codec.

## Recommended action

Use MP3, AAC, Speex, or a supported enhanced RTMP audio encoding.
