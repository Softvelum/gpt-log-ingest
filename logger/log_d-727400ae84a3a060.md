# VCAS key server selected for HLS encryption

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-727400ae84a3a060

## Log pattern

```text
stream='%s/%s' is DRM protected with key server='%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream='live/camera' is DRM protected with key server='https://keys.example/key'
```

## Short description

VCAS key server selected for HLS encryption.

## Trigger condition

HLS key-parameter retrieval or chunk preparation uses a VCAS-protected application.

## Explanation

The rotating key position is calculated next.

## Possible causes

- HLS key-parameter retrieval or chunk preparation uses a VCAS-protected application.
