# TLS server name indication could not be set

Product: Nimble Streamer
Component: Panel synchronization and proxy transport
Logging function: log_v
Log level: verbose
Documentation ID: log_v-c10405b689e0d1cb

## Log pattern

```text
SSL_set_tlsext_host_name failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
SSL_set_tlsext_host_name failed
```

## Short description

TLS server name indication could not be set.

## Trigger condition

Server-name support is compiled in, the requested hostname is nonempty and not an IPv4 literal, and setting TLS server name indication fails.

## Explanation

TLS request setup continues after this diagnostic.

## Possible causes

- The TLS library rejected the supplied server name.

## What to check

1. Check the requested hostname and subsequent TLS outcome.

## Recommended action

Use a hostname accepted by the TLS implementation.
