# UDP input receives a closure event

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_d
Log level: debug
Documentation ID: log_d-7272bc5247b5119d

## Log pattern

```text
connection closed by s=%d (ev 0x%x & EPOLLRDHUP)
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Events: Complete received event bitmask in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
connection closed by s=42 (ev 0x2000 & EPOLLRDHUP)
```

## Short description

UDP input receives a closure event.

## Trigger condition

After any readable-data work, the event flags contain the peer-read-closure flag.

## Explanation

Event processing returns failure so the input can be removed by its owner.

## Possible causes

- After any readable-data work, the event flags contain the peer-read-closure flag.

## What to check

1. Check the complete event mask and surrounding receive errors.

## Recommended action

Investigate unexpected repeated input closure events.
