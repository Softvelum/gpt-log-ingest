# Icecast metadata cue injection failed

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-db49943eda28e547

## Log pattern

```text
failed to inject_scte35 to '%s'
```

## Parameters

- Argument 1 — Stream: Full application/stream name targeted by the cue.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to inject_scte35 to 'live/radio'
```

## Short description

Icecast metadata cue injection failed.

## Trigger condition

A matching metadata rule produces a splice cue but the live-stream manager rejects cue injection.

## Explanation

This cue is not injected through the requested operation. The log does not itself stop metadata updates.

## Possible causes

- A matching metadata rule produces a splice cue but the live-stream manager rejects cue injection.

## What to check

1. Check that the target stream is available for cue injection.
