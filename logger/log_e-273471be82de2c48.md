# DVR AVC NAL length field is unsupported

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-273471be82de2c48

## Log pattern

```text
[VM] NALU unit size not supported %d
```

## Parameters

- Argument 1 — Length-field bytes: Integer number of bytes used to encode a NAL-unit length; this condition is 3.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] NALU unit size not supported 3
```

## Short description

DVR AVC NAL length field is unsupported.

## Trigger condition

The AVC configuration declares a three-byte NAL length field.

## Explanation

The sequence header is rejected.

## Possible causes

- The AVC configuration declares a three-byte NAL length field.

## What to check

1. Configure one-, two-, or four-byte AVC NAL length fields.

## Recommended action

Configure one-, two-, or four-byte AVC NAL length fields.
