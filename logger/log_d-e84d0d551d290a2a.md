# DVR archive removed from the active archive list

Product: Nimble Streamer
Component: DVR
Logging function: log_d
Log level: debug
Documentation ID: log_d-e84d0d551d290a2a

## Log pattern

```text
dropping dvr archive='%s'
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
dropping dvr archive='live/camera'
```

## Short description

DVR archive removed from the active archive list.

## Trigger condition

An existing archive is absent from the newly applied stream or application settings.

## Explanation

It is detached from the active list and recording contexts are subsequently removed; this message does not itself delete stored files.

## Possible causes

- An existing archive is absent from the newly applied stream or application settings.

## What to check

1. Check removed DVR settings if detachment was unexpected.

## Recommended action

Check removed DVR settings if detachment was unexpected.
