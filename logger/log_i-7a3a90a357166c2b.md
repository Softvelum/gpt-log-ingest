# NDI sender pacing fell more than a frame behind

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-7a3a90a357166c2b

## Log pattern

```text
sender too slow, buffer delay=%lld, sender delay=%lld
```

## Parameters

- Argument 1 — Buffer delay: Buffered stream duration in milliseconds.
- Argument 2 — Sender delay: Wall-clock lateness relative to the expected stream time, in milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender too slow, buffer delay=500, sender delay=80
```

## Short description

NDI sender pacing fell more than a frame behind.

## Trigger condition

Elapsed wall time exceeds the accumulated expected stream time by more than the current frame duration.

## Explanation

The pacing origin is reset to the current time and accumulated stream duration is cleared. Output then continues from the adjusted schedule.

## Possible causes

- Elapsed wall time exceeds the accumulated expected stream time by more than the current frame duration.

## What to check

1. Check whether sending and scheduling keep pace with the supplied frame rate.
