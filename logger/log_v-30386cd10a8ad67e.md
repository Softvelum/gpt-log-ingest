# Short-lived cache cleanup is due

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-30386cd10a8ad67e

## Log pattern

```text
invalidating short lived cache cur_time=%lld expiration_time=%lld
```

## Parameters

- Argument 1 — current time: Current cache clock time in seconds.
- Argument 2 — expiry: Scheduled expiration time in seconds, or marker 1.

Both timestamps use platform-dependent time values passed to signed 64-bit conversions.

## Log examples

No portable example is provided for the timestamp argument types.

## Short description

Short-lived cache cleanup is due.

## Trigger condition

The next short-lived expiration marker is positive and earlier than the current cache clock.

## Explanation

The cache enters its short-lived cleanup pass. An expiration marker of 1 requests cleanup on the next opportunity.
