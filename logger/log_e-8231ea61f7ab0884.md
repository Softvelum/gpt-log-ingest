# Encoder ordinary-frame counter reported

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-8231ea61f7ab0884

## Log pattern

```text
debugWriteVideoFrame for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
debugWriteVideoFrame for [live/encoded]
```

## Short description

Encoder ordinary-frame counter reported.

## Trigger condition

Encoder debug logging is enabled and ordinary frame-write attempts since the last report exceed 1500.

## Explanation

The counter resets before the next frame submission; no failure is implied by this diagnostic.
