# Local output audio is not planar

Product: Nimble Streamer
Component: Local media output
Logging function: log_e
Log level: error
Documentation ID: log_e-72fba789d8d29a13

## Log pattern

```text
audio sample format MUST be planar for [%s]
```

## Parameters

- Argument 1 — Output: Local output stream or AJA writer name, text.

Shared by the AJA writer and the common local socket writer; the parameter is their configured writer or stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio sample format MUST be planar for [camera]
```

## Short description

Local output audio is not planar.

## Trigger condition

After the writer state is accepted, FFmpeg reports that the input audio sample format is not planar.

## Explanation

The audio frame is rejected before queueing.

## Possible causes

- The upstream audio pipeline supplies interleaved or otherwise non-planar samples.

## What to check

1. Check the audio sample format reaching the device writer.

## Recommended action

Convert audio to the planar format required by the output.
