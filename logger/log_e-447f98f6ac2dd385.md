# RTSP publishing announcement has no media tracks

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-447f98f6ac2dd385

## Log pattern

```text
unable to get streams from s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unable to get streams from s=25
```

## Short description

RTSP publishing announcement has no media tracks.

## Trigger condition

An ANNOUNCE request yields no parsed SDP media descriptions.

## Explanation

The server requests connection shutdown before URL parsing or publishing authorization.

## Possible causes

- An ANNOUNCE request yields no parsed SDP media descriptions.

## What to check

1. Check the SDP body supplied with ANNOUNCE.

## Recommended action

Announce at least one parseable media track.
