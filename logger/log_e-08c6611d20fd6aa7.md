# Geolocation database could not be opened

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_e
Log level: error
Documentation ID: log_e-08c6611d20fd6aa7

## Log pattern

```text
failed to open GeoIP database '%s' status=%d
```

## Parameters

- Argument 1 — Database path: Text path of the database being opened.
- Argument 2 — Result: Integer database-library status from the open operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open GeoIP database '/var/cache/nimble/GeoLite2-Country.mmdb' status=1
```

## Short description

Geolocation database could not be opened.

## Trigger condition

Opening either the cached country database or a proposed replacement fails.

## Explanation

During cached loading, no active database remains. During an update, the proposed database is discarded and the cached database is reopened before the update reports failure.

## Possible causes

- The database library rejected the file-open operation.

## What to check

1. Check the indicated database file and returned status.
