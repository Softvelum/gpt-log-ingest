# RTMP connect result client ID cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-ae6b2144319df903

## Log pattern

```text
cannot process AMF. get clientid
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process AMF. get clientid
```

## Short description

RTMP connect result client ID cannot be decoded.

## Trigger condition

The clientid field of a connect result cannot be read as an AMF number.

## Explanation

The response handler fails and connection processing stops, even if other fields were already decoded.

## Possible causes

- The clientid field of a connect result cannot be read as an AMF number.

## What to check

1. Check the clientid type and AMF framing in the remote connect result.

## Recommended action

Correct the client ID encoding at the remote endpoint.
