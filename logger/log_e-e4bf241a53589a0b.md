# SVT HEVC handle initialization failed

Product: Nimble Streamer
Component: SVT HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e4bf241a53589a0b

## Log pattern

```text
failed to init encode handle, err=%d
```

## Parameters

- Argument 1 — Encoder status: SVT HEVC result code, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init encode handle, err=-1
```

## Short description

SVT HEVC handle initialization failed.

## Trigger condition

Creating the SVT HEVC handle returns an error.

## Explanation

Encoder initialization returns failure.

## Possible causes

- The encoding library cannot create the encoder handle.

## What to check

1. Check the SVT status, available memory and installed library compatibility.

## Recommended action

Restore encoder resources or compatible library support.
