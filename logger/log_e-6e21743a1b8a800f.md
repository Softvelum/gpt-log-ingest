# AJA capture has no recognized input video format

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-6e21743a1b8a800f

## Log pattern

```text
No input signal or unknown format for device/channel '%s'/%u
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
No input signal or unknown format for device/channel 'AJA device'/0
```

## Short description

AJA capture has no recognized input video format.

## Trigger condition

Video setup receives an unknown format from input detection.

## Explanation

Capture initialization stops before configuring the frame-buffer video format. Missing input signal and unrecognized signal format share this message.

## Possible causes

- Video setup receives an unknown format from input detection.

## What to check

1. Check the signal connected to the selected input and whether its format can be detected.
