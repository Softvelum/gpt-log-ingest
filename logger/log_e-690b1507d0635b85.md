# AAC RTP header length is not a multiple of sixteen bits

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-690b1507d0635b85

## Log pattern

```text
incorrect au_headers_length=%d

```

## Parameters

- Argument 1 — Header length: Unsigned sixteen-bit access-unit-header length in bits, displayed in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
incorrect au_headers_length=15

```

## Short description

AAC RTP header length is not a multiple of sixteen bits.

## Trigger condition

The AAC access-unit header length is not divisible by sixteen.

## Explanation

The packet is rejected before converting the length into bytes or reading individual access-unit headers.

## Possible causes

- The AAC access-unit header length is not divisible by sixteen.

## What to check

1. Check the AAC RTP access-unit header length.

## Recommended action

Send access-unit headers using the supported sixteen-bit header layout.
