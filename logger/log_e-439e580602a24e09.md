# External request redirect limit reached

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-439e580602a24e09

## Log pattern

```text
url='%s' request failed status=%hu (too many redirections)
```

## Parameters

- Argument 1 — URL: Original external request URL, retained even when following a redirect.
- Argument 2 — status: HTTP response status code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url='https://media.example/movie.mp4' request failed status=302 (too many redirections)
```

## Short description

External request redirect limit reached.

## Trigger condition

A second HTTP 301 or 302 redirect is encountered.

## Explanation

Only one redirect is followed by this request session; another redirect causes a failure callback.

## Possible causes

- A second HTTP 301 or 302 redirect is encountered.

## What to check

1. Inspect the origin redirect chain and location headers.

## Recommended action

Use a valid target reachable within one redirect.
