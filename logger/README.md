# Nimble log catalog

Each of the following files describes one log entry on [Nimble Streamer](https://softvelum.com/nimble/) software media server.

[`search-index.json`](search-index.json) is generated from these Markdown
entries for the Rust watcher and Python fallback. It ranks possible
descriptions by literal terms and level; read the linked Markdown entry to
verify a match. Regenerate it with `python3 scripts/build_logger_map.py` after
catalog edits, and use `--check` to verify it is current. This index does not
replace the descriptions or `manifest.json`.
