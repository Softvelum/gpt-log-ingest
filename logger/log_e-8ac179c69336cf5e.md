# Advertising API response is not valid JSON

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-8ac179c69336cf5e

## Log pattern

```text
failed to parse advertising API response='%s'
```

## Parameters

- Argument 1 — Response body: Text containing the received response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse advertising API response='invalid JSON'
```

## Short description

Advertising API response is not valid JSON.

## Trigger condition

Parsing a main or session advertising rules response produces no JSON value.

## Explanation

A main response is rejected. A session response marks its pending rules requests failed, subject to the session error policy.

## Possible causes

- Parsing a main or session advertising rules response produces no JSON value.

## What to check

1. Return a valid JSON object from the advertising API.

## Recommended action

Return a valid JSON object from the advertising API.
