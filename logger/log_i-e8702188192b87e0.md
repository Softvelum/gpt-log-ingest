# Replacement geolocation database opened

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_i
Log level: info
Documentation ID: log_i-e8702188192b87e0

## Log pattern

```text
opened GeoIP database '%s'
```

## Parameters

- Argument 1 — Database path: Text path of the proposed database file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
opened GeoIP database '/tmp/country.mmdb'
```

## Short description

Replacement geolocation database opened.

## Trigger condition

The proposed replacement database opens successfully during an update.

## Explanation

Verification and installation still follow. This message does not mean the replacement has been accepted or copied into the cache.
