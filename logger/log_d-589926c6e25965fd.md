# Socket event registration updated

Product: Nimble Streamer
Component: Socket event monitoring
Logging function: log_d
Log level: debug
Documentation ID: log_d-589926c6e25965fd

## Log pattern

```text
epoll_ctl epfd=%d MOD fd=%d f=0x%x
```

## Parameters

- Argument 1 — Event monitor: Linux event-monitor descriptor, integer.
- Argument 2 — Socket: Socket descriptor, integer; no unit.
- Argument 3 — Event flags: Requested event-interest bit mask, hexadecimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
epoll_ctl epfd=10 MOD fd=12 f=0x1
```

## Short description

Socket event registration updated.

## Trigger condition

Linux successfully completes the request to modify a descriptor in the event monitor. Modification reporting is enabled.

## Explanation

Future event monitoring uses the updated registration.
