# RTMP aggregate submessage exceeds the aggregate boundary

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-d76973c682338193

## Log pattern

```text
failed to process aggregated message. Submessage payload size invalid
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process aggregated message. Submessage payload size invalid
```

## Short description

RTMP aggregate submessage exceeds the aggregate boundary.

## Trigger condition

The submessage payload length plus its remaining framing would extend beyond the complete aggregate message.

## Explanation

The aggregate is rejected before this submessage is dispatched and connection processing fails.

## Possible causes

- The submessage payload length plus its remaining framing would extend beyond the complete aggregate message.

## What to check

1. Compare the declared submessage payload length with the bytes remaining in the aggregate.

## Recommended action

Correct the peer aggregate lengths and framing.
