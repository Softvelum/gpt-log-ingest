# Video frame output failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-6373b4d98c561f26

## Log pattern

```text
failed to encode video frame for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

Four call sites cover the three keyframe alignment modes and ordinary frames. Local device output can trigger this message without compressed-video encoding.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encode video frame for [live/encoded]
```

## Short description

Video frame output failed.

## Trigger condition

A keyframe or ordinary video-frame write returns failure during source-aligned, frame-count-aligned, time-aligned, or ordinary encoding.

## Explanation

The encoder worker stops processing the output.

## Possible causes

- Encoder creation or frame encoding failed, a local device writer rejected the frame, or encoded output delivery failed.

## What to check

1. Check preceding codec, frame-property, local-writer, and destination diagnostics.

## Recommended action

Correct the specific output failure and restart the affected stream.
