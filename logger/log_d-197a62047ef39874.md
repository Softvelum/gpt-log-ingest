# Local subtitle source cannot be prepared

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_d
Log level: debug
Documentation ID: log_d-197a62047ef39874

## Log pattern

```text
failed to get subtitles file for [%s]
```

## Parameters

- Argument 1 — Subtitle source: Text local media/subtitle path or remote subtitle cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get subtitles file for [/media/movie.srt]
```

## Short description

Local subtitle source cannot be prepared.

## Trigger condition

A direct subtitle request cannot find or load its local subtitle source. When a media path is given, discovery checks matching TTML, SRT, then WebVTT files.

## Explanation

The requested output cache item is canceled and released; this attempt produces no usable output.

## Possible causes

- A direct subtitle request cannot find or load its local subtitle source. When a media path is given, discovery checks matching TTML, SRT, then WebVTT files.

## What to check

1. Check the named subtitle file or corresponding subtitle files beside the media, including read permissions and preceding load errors.

## Recommended action

Check the named subtitle file or corresponding subtitle files beside the media, including read permissions and preceding load errors.
