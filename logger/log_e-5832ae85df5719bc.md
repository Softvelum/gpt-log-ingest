# File information query failed

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-5832ae85df5719bc

## Log pattern

```text
fstat failed fd=%d errno=%d
```

## Parameters

- Argument 1 — Descriptor: Open file descriptor, integer.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
fstat failed fd=12 errno=5
```

## Short description

File information query failed.

## Trigger condition

Querying file size and modification time through an open descriptor fails.

## Explanation

The requested file size and modification time are not returned.

## Possible causes

- The operating system rejected the descriptor metadata query.

## What to check

1. Check the descriptor and operating system error.

## Recommended action

Resolve the file-information query failure.
