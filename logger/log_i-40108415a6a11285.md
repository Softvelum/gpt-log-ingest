# Unused delayed pull task expired

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_i
Log level: info
Documentation ID: log_i-40108415a6a11285

## Log pattern

```text
live pull task for %s/%s expired
```

## Parameters

- Argument 1 — application: Application of the delayed pull task.
- Argument 2 — stream: Stream of the delayed pull task.

## Log examples

Illustrative examples; these are not captured server logs.

```text
live pull task for live/camera expired
```

## Short description

Unused delayed pull task expired.

## Trigger condition

A task with no users reaches its idle timeout, or the clock moves before its idle start.

## Explanation

The task leaves the unused-task index and, if still the current task, its active indexes. The task marker is updated to cause receiver synchronization.
