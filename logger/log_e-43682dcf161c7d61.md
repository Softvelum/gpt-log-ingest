# MPEG-TS fallback protocol is unsupported

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-43682dcf161c7d61

## Log pattern

```text
unsupported fallback protocol=%d, url=%s
```

## Parameters

- Argument 1 — protocol: Numeric fallback protocol after applying any default protocol.
- Argument 2 — URL: Selected fallback URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported fallback protocol=1, url=udp://192.0.2.20:5000
```

## Short description

MPEG-TS fallback protocol is unsupported.

## Trigger condition

The next fallback resolves to a protocol other than HTTP or HLS.

## Explanation

The selected fallback is removed from the pending list, but no receiver is created and the attempt returns failure.

## Possible causes

- This fallback path supports only HTTP and HLS.

## What to check

1. Check the primary protocol and explicit fallback protocol.

## Recommended action

Use a supported fallback source for this input path.
