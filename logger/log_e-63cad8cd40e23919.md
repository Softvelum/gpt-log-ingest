# NVIDIA input plane layout could not be prepared

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-63cad8cd40e23919

## Log pattern

```text
failed to init nvBuffers, format=%d
```

## Parameters

- Argument 1 — Pixel format: FFmpeg input pixel-format identifier after any conversion, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to init nvBuffers, format=62
```

## Short description

NVIDIA input plane layout could not be prepared.

## Trigger condition

Preparing plane pointers for P010, YUV444P or YUV444P16 in the locked NVIDIA buffer returns a negative result.

## Explanation

The frame write returns failure before copying the image and unlocking the input buffer.

## Possible causes

- FFmpeg cannot represent the selected format with the supplied buffer layout.

## What to check

1. Check the reported pixel format, aligned frame height and buffer pitch.

## Recommended action

Use a valid supported frame layout.
