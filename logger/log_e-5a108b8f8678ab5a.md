# WHIP media connection read failed

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-5a108b8f8678ab5a

## Log pattern

```text
failed to read frame for session=%d, stream=[%s/%s]
```

## Parameters

- Argument 1 — Session identifier: WebRTC helper session identifier, unsigned 32-bit integer displayed in decimal; no unit.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.

The two occurrences distinguish end-of-connection from a hard read error; would-block leaves the session active.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read frame for session=7, stream=[live/camera]
```

## Short description

WHIP media connection read failed.

## Trigger condition

Reading a WHIP helper media socket returns zero, or a negative result other than would-block.

## Explanation

The active publishing session and authorization record are removed and its media socket is closed.

## Possible causes

- The helper closes the media connection or a socket read error occurs.

## What to check

1. Check whether the helper stopped or the publication ended, and inspect nearby connection errors.

## Recommended action

Reconnect the publisher after restoring the helper if this was unexpected.
