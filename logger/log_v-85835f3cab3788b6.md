# Postponed cache object is still in use

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-85835f3cab3788b6

## Log pattern

```text
p key='%s' st=%d ref=%u live=%d et=%lld to=%lld
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — state: Numeric cache state: 0 empty, 1 downloading, 2 fragmented, 3 ready, or 4 marked for removal.
- Argument 3 — references: Current number of users holding the item.
- Argument 4 — live: 1 when the item has a positive timeout, otherwise 0.
- Argument 5 — expiry: Stored expiration time in seconds.
- Argument 6 — timeout: Configured item lifetime in seconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
p key='movie' st=3 ref=1 live=1 et=1700000045 to=45
```

## Short description

Postponed cache object is still in use.

## Trigger condition

A periodic cleanup finds references to an item whose deletion was deferred.

## Explanation

The object remains in the deferred set for a later cleanup or its last release.
