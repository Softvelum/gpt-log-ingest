# Operating system thread name could not be set

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-12ed8c26e942344c

## Log pattern

```text
set thread name for [%s] failed
```

## Parameters

- Argument 1 — Thread name: Requested operating system thread name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
set thread name for [decoder] failed
```

## Short description

Operating system thread name could not be set.

## Trigger condition

The non-Windows thread-naming request fails.

## Explanation

Execution continues with the thread name unchanged by this request.

## Possible causes

- The operating system rejected the thread-name request.

## What to check

1. Check the requested thread name if thread identification matters.

## Recommended action

Investigate only if thread identification is required.
