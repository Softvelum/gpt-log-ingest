# Icecast FLAC header cannot be installed

Product: Nimble Streamer
Component: Live stream codec and packaging setup
Logging function: log_e
Log level: error
Documentation ID: log_e-894cedbd87f15619

## Log pattern

```text
failed to set FLAC header for Icecast stream [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the affected live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set FLAC header for Icecast stream [live/camera]
```

## Short description

Icecast FLAC header cannot be installed.

## Trigger condition

The Ogg output wrapper rejects the FLAC sequence header while Icecast output is enabled.

## Explanation

The Ogg wrapper is discarded, but live FLAC codec and stream-buffer setup continue. This message does not mean all live outputs were stopped.

## Possible causes

- The Ogg output wrapper rejects the FLAC sequence header while Icecast output is enabled.

## What to check

1. Check the FLAC header and preceding Ogg/FLAC configuration errors.

## Recommended action

Provide a valid FLAC sequence header for Icecast packaging.
