# Audio boundary chunk has no usable extension

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-578b0544b9596a79

## Log pattern

```text
failed to get chunk extension, %s
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get chunk extension, /app/stream/ad_1.ts
```

## Short description

Audio boundary chunk has no usable extension.

## Trigger condition

The source audio chunk name does not provide an extension after its ID3 tags have been read.

## Explanation

The remainder request is marked failed.

## Possible causes

- The source audio chunk name does not provide an extension after its ID3 tags have been read.

## What to check

1. Check the source audio chunk name and extension.

## Recommended action

Check the source audio chunk name and extension.
