# Quick Sync version query failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-140c5347721a2005

## Log pattern

```text
failed to get quick sync version, error=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

Shared by native decoder and encoder setup.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get quick sync version, error=-3
```

## Short description

Quick Sync version query failed.

## Trigger condition

The media runtime returns a nonzero status when queried for the session API version.

## Explanation

Decoder or encoder setup fails before implementation-specific setup completes.

## Possible causes

- The initialized media session cannot report its API version.

## What to check

1. Check the status and preceding session or plugin diagnostics.

## Recommended action

Correct the media runtime initialization problem and restart the stream.
