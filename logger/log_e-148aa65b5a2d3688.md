# VAAPI VP8 packet assembly failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-148aa65b5a2d3688

## Log pattern

```text
failed to write vp8 pkt part
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write vp8 pkt part
```

## Short description

VAAPI VP8 packet assembly failed.

## Trigger condition

Appending a coded VP8 buffer segment to the output assembly buffer fails.

## Explanation

No assembled VP8 packet is delivered for the frame.

## Possible causes

- The accumulated VP8 packet exceeds available output-buffer capacity or the buffer cannot grow.

## What to check

1. Check memory availability and encoded frame sizes; the assembly buffer has a four-megabyte maximum.

## Recommended action

Reduce excessive encoded frame size or restore memory availability and restart encoding.
