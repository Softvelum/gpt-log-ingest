# Mixed DVR export header send failed

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-2e9e423b3fa34a64

## Log pattern

```text
failed to send mixed mp4 header, stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 3 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send mixed mp4 header, stream=live/camera utc_start=1700000000 utc_end=1700000060
```

## Short description

Mixed DVR export header send failed.

## Trigger condition

Sending the HTTP and initial MP4 headers for combined audio/video fails.

## Explanation

The export socket is shut down.

## Possible causes

- Sending the HTTP and initial MP4 headers for combined audio/video fails.

## What to check

1. Check the client connection and accompanying socket or TLS errors.

## Recommended action

Check the client connection and accompanying socket or TLS errors.
