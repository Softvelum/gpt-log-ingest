# HEVC forwarding configuration failed

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-5b99b9501fce7b13

## Log pattern

```text
failed to set hevc codec params for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

In-process output validates parameter sets and transport headers. The separate transcoder process also parses the SPS and builds the HEVC configuration before sending it.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to set hevc codec params for [live/encoded]
```

## Short description

HEVC forwarding configuration failed.

## Trigger condition

Applying HEVC parameters from the live input sequence header to the output stream returns failure.

## Explanation

Compressed video forwarding cannot continue with this sequence header.

## Possible causes

- Parameter sets are missing, the SPS cannot be parsed, codec configuration or transport headers exceed their buffers, or the destination is closed.

## What to check

1. Check preceding codec-configuration diagnostics and the publisher sequence header.

## Recommended action

Correct the input codec configuration or destination setup and restart forwarding.
