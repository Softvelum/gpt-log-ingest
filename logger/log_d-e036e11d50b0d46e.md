# File bytes read for TLS transmission

Product: Nimble Streamer
Component: TLS file delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-e036e11d50b0d46e

## Log pattern

```text
read %lluB fd=%d off=%ld
```

## Parameters

- Argument 1 — bytes: Bytes read, limited to 128 KiB for this operation.
- Argument 2 — descriptor: Input file descriptor.
- Argument 3 — offset: File byte offset used for the read.

The byte count is a platform-sized value passed to an unsigned 64-bit conversion, and the file offset is passed to a signed-long conversion.

## Log examples

A portable example is not established for these platform-dependent argument widths.

## Short description

File bytes read for TLS transmission.

## Trigger condition

A file read returns exactly the requested byte count before encrypted transmission.

## Explanation

The buffer is ready for the following TLS write. Successful reading does not establish that the bytes were sent to the peer.
