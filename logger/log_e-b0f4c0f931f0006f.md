# CPIX partner private key cannot be loaded

Product: Nimble Streamer
Component: KeyOS DRM
Logging function: log_e
Log level: error

## Log pattern

```text
cannot load CPIX partner private key
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

CPIX partner private key cannot be loaded.

## Trigger condition

Creating a memory reader for the partner private key or parsing it as a PEM private key fails.

## Explanation

The KeyOS response is rejected before XML parsing.

## Possible causes

- Creating a memory reader for the partner private key or parsing it as a PEM private key fails.

## What to check

1. Provide a readable valid PEM partner private key matching the provider account.

## Recommended action

Provide a readable valid PEM partner private key matching the provider account.
