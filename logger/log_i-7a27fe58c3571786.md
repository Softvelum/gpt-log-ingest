# Child process started

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_i
Log level: info
Documentation ID: log_i-7a27fe58c3571786

## Log pattern

```text
started process '%s' pid=%d
```

## Parameters

- Argument 1 — Command: Command supplied for launching the child, text.
- Argument 2 — Process: Child process identifier, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
started process 'nimble_transcoder' pid=1234
```

## Short description

Child process started.

## Trigger condition

Creation of the child process returns a usable handle.

## Explanation

The process identifier is reported; this does not establish that later child initialization or communication will succeed.
