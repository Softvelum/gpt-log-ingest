# VAAPI cannot write scaling matrices

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-e19e21a1891c9f02

## Log pattern

```text
scaling matrices not supported
```

## Parameters

Shared by sequence and picture parameter-set writing.

## Log examples

Illustrative examples; these are not captured server logs.

```text
scaling matrices not supported
```

## Short description

VAAPI cannot write scaling matrices.

## Trigger condition

The H.264 sequence or picture parameters request a scaling matrix.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested scaling matrices and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
