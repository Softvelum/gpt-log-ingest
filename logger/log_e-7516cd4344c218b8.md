# DVR media file removal failed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-7516cd4344c218b8

## Log pattern

```text
failed to remove segment file='%s' error=%d message='%s'
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.
- Argument 2 — Filesystem error: Integer filesystem error code.
- Argument 3 — Error message: Text describing the reported filesystem failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove segment file='/data/dvr/live/camera/1700000000000.dat' error=13 message='Permission denied'
```

## Short description

DVR media file removal failed.

## Trigger condition

Filesystem removal fails with a nonzero error code.

## Explanation

The file-removal operation returns failure.

## Possible causes

- Filesystem removal fails with a nonzero error code.

## What to check

1. Check the reported file access or filesystem error.

## Recommended action

Check the reported file access or filesystem error.
