# Audio decoder worker stopped

Product: Nimble Streamer
Component: Audio decoding
Logging function: log_d
Log level: debug
Documentation ID: log_d-879da76419ccb128

## Log pattern

```text
AudioDecoderThread(%s) stopped
```

## Parameters

- Argument 1 — Input: Input display name captured when the worker started, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
AudioDecoderThread(live/camera) stopped
```

## Short description

Audio decoder worker stopped.

## Trigger condition

The audio worker leaves its loop after a stop request or a failed source update or decode operation.

## Explanation

The decoder and local input reader are released before this message, and the worker returns.
