# AJA output audio channel count is negative

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-6b596d3bff28b058

## Log pattern

```text
Bad output audio channel count for device '%s': %d
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Configured value: Signed integer count of channels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad output audio channel count for device '0': -1
```

## Short description

AJA output audio channel count is negative.

## Trigger condition

The configured audio channel count is below zero.

## Explanation

Output parameter validation returns failure. A value of zero is not rejected by this check.

## Possible causes

- The configured audio channel count is below zero.

## What to check

1. Check the audio channel count setting.

## Recommended action

Use a nonnegative audio channel count.
