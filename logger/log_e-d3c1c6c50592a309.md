# H.264 live-stream codec setup failed

## Short description

H.264 live-stream codec setup failed.

## Trigger condition

The live-stream configuration operation rejects the constructed AVC configuration.

## Explanation

RTSP H.264 initialization returns failure. Rejection can occur because the live stream ended or codec-header validation or output-header preparation failed.

## Possible causes

- The live-stream configuration operation rejects the constructed AVC configuration.

## What to check

1. Check the H.264 configuration and accompanying live-stream codec errors.
