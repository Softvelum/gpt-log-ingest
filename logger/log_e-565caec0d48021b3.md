# Icecast authorization scheme missing

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-565caec0d48021b3

## Log pattern

```text
failed to get icecast auth scheme from %s, client=%d
```

## Parameters

- Argument 1 — Authorization: Received authorization-header value.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get icecast auth scheme from    , client=42
```

## Short description

Icecast authorization scheme missing.

## Trigger condition

A nonempty authorization header yields no token after splitting and trimming whitespace.

## Explanation

The metadata-update or publishing connection is shut down without authorization.

## Possible causes

- A nonempty authorization header yields no token after splitting and trimming whitespace.

## What to check

1. Check the authorization header contains its scheme and credentials.

## Recommended action

Send a correctly formed Basic authorization header.
