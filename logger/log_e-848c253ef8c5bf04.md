# AJA sender video setup failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-848c253ef8c5bf04

## Log pattern

```text
sender init failed device=%s/%d reason='video setup failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sender init failed device=0/0 reason='video setup failed'
```

## Short description

AJA sender video setup failed.

## Trigger condition

Starting the sender fails because device video configuration fails or its derived frame rate is unknown.

## Explanation

Audio setup and host-buffer preparation are not attempted.

## Possible causes

- Starting the sender fails because device video configuration fails or its derived frame rate is unknown.

## What to check

1. Check the preceding video setup diagnostics and the selected device/channel.
