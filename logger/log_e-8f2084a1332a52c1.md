# AJA reader worker did not start

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-8f2084a1332a52c1

## Log pattern

```text
failed to start AJA reader worker id=%llu
```

## Parameters

- Argument 1 — Session ID: Positive unsigned 64-bit identifier for the reader or writer session.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start AJA reader worker id=1
```

## Short description

AJA reader worker did not start.

## Trigger condition

The newly constructed reader worker reports startup failure.

## Explanation

The replacement worker is not stored as an active session. Any previous session with the same ID has already been stopped.

## Possible causes

- The newly constructed reader worker reports startup failure.

## What to check

1. Check the accompanying thread-start exception message.
