# Stream checker is waiting for its next poll

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_v
Log level: verbose
Documentation ID: log_v-cf831a330e5791f7

## Log pattern

```text
sleeping for %d seconds before the next stream request
```

## Parameters

- Argument 1 — seconds: Requested remaining sleep duration in seconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sleeping for 10 seconds before the next stream request
```

## Short description

Stream checker is waiting for its next poll.

## Trigger condition

A regular or immediate check iteration calculates its remaining polling delay.

## Explanation

Regular polling uses a panel interval constrained to 30–300 seconds; immediate polling uses 10 seconds. Time already spent since the last panel exchange is deducted, and exit can interrupt the wait.
