# AJA output video does not match the configured raster

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-577eaf416e1932de

## Log pattern

```text
bad output video frame format=%d size=%dx%d expected=%dx%d UYVY422
```

## Parameters

- Argument 1 — Pixel format: Integer pixel-format identifier of the received frame.
- Argument 2 — Actual width: Received frame width in pixels.
- Argument 3 — Actual height: Received frame height in pixels.
- Argument 4 — Expected width: Configured output raster width in pixels.
- Argument 5 — Expected height: Configured visible raster height in pixels.

## Log examples

Illustrative examples; these are not captured server logs.

```text
bad output video frame format=-1 size=1280x720 expected=1920x1080 UYVY422
```

## Short description

AJA output video does not match the configured raster.

## Trigger condition

The supplied frame is not UYVY422 or its width/height differ from the configured visible output raster.

## Explanation

Video preparation returns failure before copying pixels into the card host buffer.

## Possible causes

- The supplied frame is not UYVY422 or its width/height differ from the configured visible output raster.

## What to check

1. Check pixel format and dimensions against the expected raster.

## Recommended action

Convert video to UYVY422 with the expected width and visible height.
