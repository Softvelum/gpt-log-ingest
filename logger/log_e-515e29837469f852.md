# RTMP connect result first object cannot be skipped

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-515e29837469f852

## Log pattern

```text
failed to process first object for connect _result
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process first object for connect _result
```

## Short description

RTMP connect result first object cannot be skipped.

## Trigger condition

The first object in a remote connect _result response cannot be decoded sufficiently to skip it.

## Explanation

The parser logs the failure and still attempts the second object. This message alone does not immediately return a failed connection result; subsequent parsing determines the outcome.

## Possible causes

- The first object in a remote connect _result response cannot be decoded sufficiently to skip it.

## What to check

1. Inspect the first object and its AMF encoding in the remote connect response.

## Recommended action

Correct malformed response objects at the remote server.
