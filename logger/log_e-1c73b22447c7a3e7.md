# RTMP metadata container type is unsupported

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-1c73b22447c7a3e7

## Log pattern

```text
cannot process metadata. unsupported type(%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process metadata. unsupported type(live/camera)
```

## Short description

RTMP metadata container type is unsupported.

## Trigger condition

The onMetaData payload begins with neither a readable AMF object nor an ECMA array.

## Explanation

The original metadata has already been stored. Structured field parsing is skipped, but audio metadata generation and default resolution/data-rate updates are still attempted.

## Possible causes

- The onMetaData payload begins with neither a readable AMF object nor an ECMA array.

## What to check

1. Check the AMF container immediately after onMetaData.

## Recommended action

Encode metadata as a supported AMF object or ECMA array.
