# SDI output format is unavailable

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-627801f98ab39afe

## Log pattern

```text
cannot find requested output format [%s/%s]
```

## Parameters

- Argument 1 — Device type: FFmpeg output device type, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot find requested output format [decklink/live/camera]
```

## Short description

SDI output format is unavailable.

## Trigger condition

FFmpeg cannot find the requested output device format.

## Explanation

The device output creation request returns failure.

## Possible causes

- The requested device type is unavailable in the loaded FFmpeg libraries.

## What to check

1. Check the requested device type and available FFmpeg device support.

## Recommended action

Install or select an available output device type.
