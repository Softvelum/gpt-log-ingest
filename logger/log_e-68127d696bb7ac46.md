# Managed task output monitor removal failed

Product: Nimble Streamer
Component: Managed operating-system tasks
Logging function: log_e
Log level: error
Documentation ID: log_e-68127d696bb7ac46

## Log pattern

```text
failed to remove task fd=%d pid=%d cmd='%s' from selector fd=%d
```

## Parameters

- Argument 1 — Process: Integer task process identifier.
- Argument 2 — Output descriptor: Integer descriptor used by Nimble to read the task output.
- Argument 3 — Command: Configured shell command text.
- Argument 4 — Selector: Integer event-selector descriptor.

Argument 1 is the process identifier despite the fd label; argument 2 is the output descriptor despite the pid label.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove task fd=1234 pid=12 cmd='echo ready' from selector fd=7
```

## Short description

Managed task output monitor removal failed.

## Trigger condition

Removing a stopped or completed task output descriptor from the selector fails. Available only on Linux builds.

## Explanation

Descriptor closure still follows. The first two printed labels are reversed relative to their actual values.

## Possible causes

- The event selector rejected removal.

## What to check

1. Interpret the first two values using their actual meanings, then check selector diagnostics.
