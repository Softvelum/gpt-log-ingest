# NDI discovery returned a source list

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_d
Log level: debug
Documentation ID: log_d-21ce18821f176f4f

## Log pattern

```text
ndi finder found %d ndi sources: %s
```

## Parameters

- Argument 1 — Source count: Number of sources reported by discovery.
- Argument 2 — Source names: Newline-separated full NDI names; the constructed text begins each name with a newline.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ndi finder found 1 ndi sources: 
HOST (Camera)
```

## Short description

NDI discovery returned a source list.

## Trigger condition

The receiver refreshes discovery and receives a non-null source array.

## Explanation

The current source names are logged before matching the requested name. This list does not by itself mean the requested source was found.

## Possible causes

- Normal discovery refresh while selecting an NDI source.

## What to check

1. Compare the requested NDI name with the discovered names.
