# Quick Sync encoder uses partial hardware acceleration

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_i
Log level: info
Documentation ID: log_i-9890692f3d76cfc3

## Log pattern

```text
%p partial hw acceleration
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 partial hw acceleration
```

## Short description

Quick Sync encoder uses partial hardware acceleration.

## Trigger condition

Encoder initialization returns the partial-hardware-acceleration warning.

## Explanation

The warning is accepted and initialization continues with the media runtime fallback.
