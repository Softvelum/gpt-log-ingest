# Origin closed before its body completed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-50637cf52b0ac62e

## Log pattern

```text
origin closed connection early (%u of %u bytes received)
```

## Parameters

- Argument 1 — Received bytes: Unsigned 64-bit received body bytes, incorrectly printed with %u.
- Argument 2 — Expected bytes: Unsigned 64-bit expected body length, incorrectly printed with %u.

Both byte counts are unsigned 64-bit values supplied to %u conversions, so their printed values are not reliable.

## Log examples

Both byte counts are unsigned 64-bit values supplied to %u conversions, so their printed values are not reliable.

## Short description

Origin closed before its body completed.

## Trigger condition

An origin closure event arrives with fewer body bytes received than expected.

## Explanation

The client shutdown response is prepared.

## Possible causes

- An origin closure event arrives with fewer body bytes received than expected.

## What to check

1. Check the origin Content-Length and disconnection cause if the body was interrupted.

## Recommended action

Check the origin Content-Length and disconnection cause if the body was interrupted.
