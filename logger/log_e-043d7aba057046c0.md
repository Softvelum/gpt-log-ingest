# Video pipeline has no source

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_e
Log level: error
Documentation ID: log_e-043d7aba057046c0

## Log pattern

```text
failed to get video source
```

## Parameters

The encoder occurrence is after settings and synchronization-state updates. The decoder occurrence is immediately after replacing its source buffer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get video source
```

## Short description

Video pipeline has no source.

## Trigger condition

An encoder video-settings update has neither a decoded-frame input nor a live compressed buffer, or a decoder source update removes its live buffer.

## Explanation

The update fails and the relevant worker stops processing.

## Possible causes

- The source was removed or the replacement settings contain no usable video input.

## What to check

1. Check video source availability and the scenario change that replaced or removed it.

## Recommended action

Restore a valid input or remove the dependent video output.
