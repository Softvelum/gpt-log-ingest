# Internal HTTP request session created

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-4968270a73b33db9

## Log pattern

```text
created requestor session=%p type=%u url='%s'
```

## Parameters

- Argument 1 — Session: Connection-session address used for diagnostic correlation.
- Argument 2 — Request type: Numeric HTTP request category.
- Argument 3 — URL: Requested resource URL as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
created requestor session=0x1000 type=0 url='https://origin.example/media'
```

## Short description

Internal HTTP request session created.

## Trigger condition

A queued internal HTTP request has been converted into a request session without an exception.

## Explanation

A positive custom request timeout is registered before this message. The request has not necessarily completed.
