# HLS playlist contains no usable download work

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-b3bff9931006b164

## Log pattern

```text
nothing to download url_='%s' ('%s')
```

## Parameters

- Argument 1 — original\_url: Original configured HLS URL.
- Argument 2 — current\_url: Current URL after playlist selection or redirection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
nothing to download url_='https://origin.example/master.m3u8' ('https://origin.example/live.m3u8')
```

## Short description

HLS playlist contains no usable download work.

## Trigger condition

The parsed playlist has no child playlists and lacks either a nonempty media-sequence value or at least one segment.

## Explanation

The input logs the original and current URLs and requests shutdown. The message can represent a missing sequence tag even when segment lines exist.

## Possible causes

- No child playlist was selected and the required media-sequence/segment pair was incomplete.

## What to check

1. Check the playlist body, media-sequence tag, and segment lines.

## Recommended action

Supply a live media playlist with the required sequence and segments.
