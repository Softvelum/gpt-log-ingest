# Video filter input properties changed

Product: Nimble Streamer
Component: Video filtering
Logging function: log_d
Log level: debug
Documentation ID: log_d-945b4950af7be49e

## Log pattern

```text
video filter frame params changed from %dx%d/%d to %dx%d/%d, filter=%s stream=%s
```

## Parameters

- Argument 1 — Old width: Previous width, integer pixels.
- Argument 2 — Old height: Previous height, integer pixels.
- Argument 3 — Old format: Previous FFmpeg pixel-format identifier, integer.
- Argument 4 — New width: Current width, integer pixels.
- Argument 5 — New height: Current height, integer pixels.
- Argument 6 — New format: Current FFmpeg pixel-format identifier, integer.
- Argument 7 — Filter: Configured filter identifier, text.
- Argument 8 — Input: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
video filter frame params changed from 1280x720/0 to 1920x1080/0, filter=overlay1 stream=live/overlay
```

## Short description

Video filter input properties changed.

## Trigger condition

Dynamic parameter changes are enabled and a configured input receives a different width, height, or pixel format.

## Explanation

The filter and input links are recreated before the current frame is submitted.
