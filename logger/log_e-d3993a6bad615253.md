# AJA output audio buffer size is negative

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-d3993a6bad615253

## Log pattern

```text
Bad output audio buffer size for device '%s': audio=%d
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Configured value: Signed integer count of buffered audio entries.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad output audio buffer size for device '0': audio=-1
```

## Short description

AJA output audio buffer size is negative.

## Trigger condition

The configured audio buffer size is below zero.

## Explanation

Output parameter validation returns failure. A value of zero is not rejected by this check.

## Possible causes

- The configured audio buffer size is below zero.

## What to check

1. Check the audio buffer size setting.

## Recommended action

Use a nonnegative audio buffer size.
