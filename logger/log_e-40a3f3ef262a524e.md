# RTMP pull command is rejected

Product: Nimble Streamer
Component: RTMP connection transport
Logging function: log_e
Log level: error
Documentation ID: log_e-40a3f3ef262a524e

## Log pattern

```text
command[%d] failed for client: %d, %s:%d/%s/%s
```

## Parameters

- Argument 1 — Transaction ID: AMF command transaction ID converted to an integer for display.
- Argument 2 — Socket: Operating-system socket descriptor for this connection.
- Argument 3 — Remote host: Pull source host.
- Argument 4 — Remote port: Pull source TCP port.
- Argument 5 — Application: Local output application for the pulled stream.
- Argument 6 — Stream: Local output stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
command[1] failed for client: 42, origin.example:1935/live/camera
```

## Short description

RTMP pull command is rejected.

## Trigger condition

The response handler reports a failed outbound pull command.

## Explanation

This log records the transaction and pull destination; the surrounding response handler determines connection termination. It does not include the remote status text.

## Possible causes

- The response handler reports a failed outbound pull command.

## What to check

1. Check the remote response corresponding to this transaction and the pull configuration.

## Recommended action

Resolve the command rejection at the remote source.
