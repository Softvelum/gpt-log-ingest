# Transcription audio queue cannot grow

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-5531fe85a0942ca5

## Log pattern

```text
transcriber too slow, stream=%s
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
transcriber too slow, stream=live/news
```

## Short description

Transcription audio queue cannot grow.

## Trigger condition

The transcription audio buffer cannot reserve space for the latest resampled audio.

## Explanation

Previously queued audio is discarded and the current chunk is attempted again. Failure to store even that chunk makes audio processing fail.

## Possible causes

- The transcription audio buffer cannot reserve space for the latest resampled audio.

## What to check

1. Check whether queued audio is accumulating while the transcription connection is not sending successfully.
