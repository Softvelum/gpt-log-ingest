# Audio channel layout could not be copied

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_e
Log level: error
Documentation ID: log_e-9972554159700566

## Log pattern

```text
failed to copy channel_layout, %d
```

## Parameters

- Argument 1 — FFmpeg error: FFmpeg operation result, signed integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to copy channel_layout, -12
```

## Short description

Audio channel layout could not be copied.

## Trigger condition

Copying the requested channel layout into a newly allocated audio frame returns a negative result.

## Explanation

Audio frame creation returns no frame.

## Possible causes

- The stated frame allocation, layout copy, or sample conversion operation failed.

## What to check

1. Check the input audio format, channel layout, and accompanying FFmpeg diagnostics.

## Recommended action

Resolve the reported frame-preparation failure.
