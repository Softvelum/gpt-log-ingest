# Origin TLS initialization started

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-136f47d82dd60f1d

## Log pattern

```text
enabling ssl for origin='%s' s=%d
```

## Parameters

- Argument 1 — Origin host: Text containing the origin hostname and optional port.
- Argument 2 — Origin socket: Integer identifying the local origin socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
enabling ssl for origin='media.example:8080' s=17
```

## Short description

Origin TLS initialization started.

## Trigger condition

An HTTPS origin connection is in progress.

## Explanation

TLS state is initialized before the socket is monitored for connection completion.

## Possible causes

- An HTTPS origin connection is in progress.

1. Not applicable; this is normal diagnostic progress. Use the socket identifier to follow the same request if troubleshooting.

Not applicable; this is normal diagnostic progress. Use the socket identifier to follow the same request if troubleshooting.
