# HLS advertising stops on unready content

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-8faf2ac6296474f7

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu stop on advertising content error %s
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.
- Argument 5 — Content URI: URI of the unavailable advertising media.

## Log examples

Illustrative examples; these are not captured server logs.

```text
app=live stream=camera stream_name=live/camera session=123 stop on advertising content error https://media.example/ad.mp4
```

## Short description

HLS advertising stops on unready content.

## Trigger condition

Selected content is not ready, no remote wait remains, and its error policy does not permit skipping.

## Explanation

The advertising playlist update returns failure. This message does not itself specify the HTTP response sent by the request handler.

## Possible causes

- Selected content is not ready, no remote wait remains, and its error policy does not permit skipping.

## What to check

1. Check media availability and the wait and error policy.

## Recommended action

Restore the media or correct the intended error handling.
