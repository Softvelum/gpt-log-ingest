# HTTP request parser did not consume the buffer

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-f0b61f061ce381b0

## Log pattern

```text
nparsed=%d != req_len=%d
```

## Parameters

- Argument 1 — Parsed: Bytes consumed by the parser.
- Argument 2 — Length: Supplied request length in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
nparsed=3 != req_len=24
```

## Short description

HTTP request parser did not consume the buffer.

## Trigger condition

The HTTP request parser consumes a different number of bytes from the supplied request length.

## Explanation

Request parsing returns failure to its caller. The log gives counts, not a specific parsing error.

## Possible causes

- The HTTP request parser consumes a different number of bytes from the supplied request length.

## What to check

1. Compare the supplied request bytes with valid HTTP request framing.
