# Last advertising playlist waiting session removed

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-a9c9c042197d388d

## Log pattern

```text
[WrkT::RemAdsPlO] empty set
```

## Parameters

The source supplies two extra arguments, a playlist identifier and a session address, but the fixed format consumes neither.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::RemAdsPlO] empty set
```

## Short description

Last advertising playlist waiting session removed.

## Trigger condition

No sessions remain after removing a playlist subscription.

## Explanation

The worker has unsubscribed from the playlist and removed the empty waiting set.
