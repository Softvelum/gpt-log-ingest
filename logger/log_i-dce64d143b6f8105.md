# Audio sample format converter added

Product: Nimble Streamer
Component: Audio frame preparation
Logging function: log_i
Log level: info
Documentation ID: log_i-dce64d143b6f8105

## Log pattern

```text
added audio converter from %d to %d for %s
```

## Parameters

- Argument 1 — Format: FFmpeg sample or pixel format identifier, integer; an enumeration rather than a bit depth.
- Argument 2 — Output format: Encoder-required FFmpeg sample-format identifier, integer.
- Argument 3 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
added audio converter from 0 to 1 for live/camera
```

## Short description

Audio sample format converter added.

## Trigger condition

The input sample format differs from the required encoder format and the conversion context is created successfully.

## Explanation

Frames are converted to the encoder format while retaining sample rate and channel layout.
