# MPEG-TS input event has no camera

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-369f0227dd1928ee

## Log pattern

```text
invalid fd in selector: %d
```

## Parameters

- Argument 1 — socket: Unexpected descriptor returned by the selector.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid fd in selector: 12
```

## Short description

MPEG-TS input event has no camera.

## Trigger condition

The event descriptor is absent from the camera socket map.

## Explanation

The descriptor is removed from the selector; the remaining camera processing continues.

## Possible causes

- An event arrived without an associated camera.

## What to check

1. Compare camera socket replacement and cleanup messages.

## Recommended action

Investigate inconsistent event registration.
