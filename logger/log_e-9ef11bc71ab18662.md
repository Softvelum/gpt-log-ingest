# Automatic SCTE-35 return marker cannot be encoded

Product: Nimble Streamer
Component: Live media packaging and timed metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-9ef11bc71ab18662

## Log pattern

```text
[SCTE35] failed to create auto splice in marker for [%s/%s]
```

## Parameters

- Argument 1 — Application: Application containing the live stream.
- Argument 2 — Stream: Live stream name.

## Log examples

The reviewed path provides a 35-byte buffer for an immediate, duration-free marker that requires 30 bytes; no ordinary input-driven failure of this fixed serialization path is established.

## Short description

Automatic SCTE-35 return marker cannot be encoded.

## Trigger condition

An ad break duration has elapsed, automatic return markers are enabled, no new splice point is available, and marker serialization returns zero.

## Explanation

Chunk splitting returns failure after the previous output chunk may already have been published.

## Possible causes

- An ad break duration has elapsed, automatic return markers are enabled, no new splice point is available, and marker serialization returns zero.

## What to check

1. Check automatic marker generation if this message is observed.

## Recommended action

Investigate marker serialization failure.
