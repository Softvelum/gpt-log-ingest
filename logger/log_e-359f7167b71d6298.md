# DVR subtitle text cannot be parsed

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-359f7167b71d6298

## Log pattern

```text
failed to read subs from .vtt segment file, stream=%s period=%d start_time=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Period: Integer identifying a continuous recording period.
- Argument 3 — Segment start: 64-bit media timestamp in 90000-Hz ticks.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read subs from .vtt segment file, stream=live/camera period=1 start_time=90000
```

## Short description

DVR subtitle text cannot be parsed.

## Trigger condition

The recorded WebVTT text cannot be parsed into subtitle cues.

## Explanation

This segment contributes no subtitle text; export continues with subsequent segments.

## Possible causes

- The recorded WebVTT text cannot be parsed into subtitle cues.

## What to check

1. Check the affected recorded subtitle segment and its language metadata.

## Recommended action

Check the affected recorded subtitle segment and its language metadata.
