# Peer host name resolved

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-1887996e1b79ab7c

## Log pattern

```text
resolved %s='%s' -> '%s'
```

## Parameters

- Argument 1 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 2 — Host: Text host name submitted for connection.
- Argument 3 — Address: Resolved address as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
resolved origin='origin.example' -> '192.0.2.20'
```

## Short description

Peer host name resolved.

## Trigger condition

Debug logging is enabled and name resolution has selected an IPv4 or IPv6 address.

## Explanation

The destination port is applied, a socket of the selected address family is created, and connection is attempted. The three occurrences cover IPv6-capable IPv4 and IPv6 resolution and the IPv4-only resolver path.
