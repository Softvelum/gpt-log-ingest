# x264 option value is invalid

Product: Nimble Streamer
Component: x264 H.264 encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-2dde574250633c3e

## Log pattern

```text
bad param value: %s=%s
```

## Parameters

- Argument 1 — Option: Requested option name, text.
- Argument 2 — Value: Requested option value, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
bad param value: bitrate=invalid
```

## Short description

x264 option value is invalid.

## Trigger condition

The x264 option parser returns a nonzero error other than unknown name.

## Explanation

H.264 encoder initialization fails.

## Possible causes

- The option value is not accepted.

## What to check

1. Check the video format and selected x264 profile, preset, tuning, and codec options.

## Recommended action

Correct the rejected encoder configuration.
