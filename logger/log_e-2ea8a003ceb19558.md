# NVIDIA input buffer unlock failed

Product: Nimble Streamer
Component: NVIDIA video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-2ea8a003ceb19558

## Log pattern

```text
failed to unlock input buffer encoder=%p, status=%d
```

## Parameters

- Argument 1 — Encoder: NVIDIA encoder session handle, pointer printed in hexadecimal.
- Argument 2 — Status: NVIDIA encoder API result, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to unlock input buffer encoder=0x12340000, status=8
```

## Short description

NVIDIA input buffer unlock failed.

## Trigger condition

Unlocking the input buffer after copying pixels returns an error.

## Explanation

The frame write returns failure before picture submission.

## Possible causes

- The NVIDIA encoder API rejects this buffer or picture operation.

## What to check

1. Check driver and buffer/session state.

## Recommended action

Correct the reported driver/resource or encoder-state problem before retrying.
