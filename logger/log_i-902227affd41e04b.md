# Overlay input resumed

Product: Nimble Streamer
Component: Video filtering
Logging function: log_i
Log level: info
Documentation ID: log_i-902227affd41e04b

## Log pattern

```text
resume stream=%s with main_stream=%s, filter=%s
```

## Parameters

- Argument 1 — Input: Input stream name, text.
- Argument 2 — Main input: Main video stream name, text.
- Argument 3 — Filter: Configured filter identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
resume stream=live/overlay with main_stream=live/camera, filter=overlay1
```

## Short description

Overlay input resumed.

## Trigger condition

An eligible secondary input delivers a frame after its filter input was marked ended, with overlay timestamp adjustment enabled and a main timestamp available.

## Explanation

The filter and its input links are recreated; the returning frame is considered for synchronization to the main stream.
