# Audio frame is late

Product: Nimble Streamer
Component: Timed local media sending
Logging function: log_e
Log level: error
Documentation ID: log_e-3f317c0e2784cdf0

## Log pattern

```text
audio frame too late, delta=%lld, name=%s
```

## Parameters

- Argument 1 — Time difference: Sender current system time minus frame timecode, signed 64-bit milliseconds; a sub-millisecond lateness can print zero.
- Argument 2 — Stream: Timecode sender stream name, text.

The millisecond count is the duration representation type, passed without a cast to a signed long-long conversion. On platforms using signed long for that representation, the argument and conversion types differ.

## Short description

Audio frame is late.

## Trigger condition

The frame system timecode is earlier than the sender current system-clock sample.

## Explanation

The incoming audio frame is discarded and is not added to the timed send queue.

## Possible causes

- Transport or processing delay consumed the configured send delay, or the timecode is behind the sender clock.

## What to check

1. Check timecode clock alignment, configured delay, and upstream processing latency.

## Recommended action

Correct timecode order, delay, or clock alignment before resuming timed output.
