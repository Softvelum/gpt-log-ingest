# Audio encoder resets after a channel change

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_d
Log level: debug
Documentation ID: log_d-add94182259a6464

## Log pattern

```text
audio encoder frame params changed for [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

The FFmpeg audio implementation currently requests this reset when the input channel count differs from the configured output frame channel count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio encoder frame params changed for [live/encoded]
```

## Short description

Audio encoder resets after a channel change.

## Trigger condition

Dynamic parameter changes are enabled and the active audio encoder reports a frame mismatch.

## Explanation

The encoder is flushed, replaced, and then asked to encode the current frame.
