# IPv6 listener could not accept IPv4 connections

Product: Nimble Streamer
Component: Socket communication
Logging function: log_e
Log level: error
Documentation ID: log_e-4a3159dd2a6c259d

## Log pattern

```text
setsockopt IPV6_V6ONLY failed for s=%d errno=%d
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: Operating system error code, integer; Windows uses its socket error codes for socket operations.

## Log examples

Illustrative examples; these are not captured server logs.

```text
setsockopt IPV6_V6ONLY failed for s=12 errno=5
```

## Short description

IPv6 listener could not accept IPv4 connections.

## Trigger condition

On Windows, disabling IPv6-only mode fails.

## Explanation

The helper logs the failure and listener setup continues.

## Possible causes

- The operating system rejected the dual-stack socket option.

## What to check

1. Check the Windows socket error and whether IPv4 clients reach this listener.

## Recommended action

Resolve the socket-option failure when dual-stack listening is required.
