# Stream-check origin socket created

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_d
Log level: debug
Documentation ID: log_d-b2474c158f61c93a

## Log pattern

```text
checker origin socket s=%d
```

## Parameters

- Argument 1 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
checker origin socket s=12
```

## Short description

Stream-check origin socket created.

## Trigger condition

Socket creation succeeds for the initial or an additional address.

## Explanation

Nonblocking setup, event registration, and connecting still follow; this message does not mean the origin is connected.
