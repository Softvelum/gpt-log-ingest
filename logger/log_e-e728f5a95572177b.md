# RTMP createStream result reuses an allocated ID

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-e728f5a95572177b

## Log pattern

```text
failed to create stream id for createStream command [%f]
```

## Parameters

- Argument 1 — Returned stream ID: AMF numeric ID from the remote result, printed with six fractional digits; local allocation converts it to a 16-bit ID.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create stream id for createStream command [1.000000]
```

## Short description

RTMP createStream result reuses an allocated ID.

## Trigger condition

The remote createStream result requests a nonzero stream ID that already exists locally after conversion to the supported stream-ID width.

## Explanation

The local stream cannot be created for that response, so connection processing fails.

## Possible causes

- The remote createStream result requests a nonzero stream ID that already exists locally after conversion to the supported stream-ID width.

## What to check

1. Compare returned stream IDs with earlier createStream results on the same connection.

## Recommended action

Have the remote endpoint assign an unused stream ID.
