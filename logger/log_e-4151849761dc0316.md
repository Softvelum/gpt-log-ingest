# Advertising content waiting set was not found

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-4151849761dc0316

## Log pattern

```text
[WrkT::RemAdsCoO] key='%s' p=%p not found
```

## Parameters

- Argument 1 — Resource identifier: Text identifying the advertising content.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::RemAdsCoO] key='example-item' p=0x1000 not found
```

## Short description

Advertising content waiting set was not found.

## Trigger condition

Removing a notification subscription finds no set for the advertising content.

## Explanation

No waiting set is changed. The shared cache/stream pattern identifies either a cache key or a stream name according to the operation.

## Possible causes

- The requested resource has no registered waiting-session set.

## What to check

1. Compare subscription registration and removal for the same resource.
