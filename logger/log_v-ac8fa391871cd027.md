# Explicit DVR cleanup found an archive that is not ready

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_v
Log level: verbose
Documentation ID: log_v-ac8fa391871cd027

## Log pattern

```text
skipped deleting not ready dvr archive='%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skipped deleting not ready dvr archive='live/camera'
```

## Short description

Explicit DVR cleanup found an archive that is not ready.

## Trigger condition

A locked or temporarily unavailable-style cleanup request finds an archive not ready.

## Explanation

The cleanup operation returns false without starting deletion.

## Possible causes

- A locked or temporarily unavailable-style cleanup request finds an archive not ready.

## What to check

1. Wait for loading or the other archive operation to finish before retrying.

## Recommended action

Wait for loading or the other archive operation to finish before retrying.
