# MPEG-TS playlist stream information is unavailable

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-6f757b16c5208088

## Log pattern

```text
failed to find mpegts stream info, file %s
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find mpegts stream info, file /media/program.mp4
```

## Short description

MPEG-TS playlist stream information is unavailable.

## Trigger condition

Discovering codec information after opening MPEG-TS input fails.

## Explanation

The media reader returns failure before selecting tracks.

## Possible causes

- Discovering codec information after opening MPEG-TS input fails.

## What to check

1. Check that the transport stream contains readable audio/video stream information.

## Recommended action

Check that the transport stream contains readable audio/video stream information.
