# Initial video keyframe does not fit after advertising

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-223cfc8b0661da07

## Log pattern

```text
cannot write initial mpeg2ts keyframe, frame_size=%u
```

## Parameters

- Argument 1 — Frame bytes: Unsigned size of the media frame in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot write initial mpeg2ts keyframe, frame_size=8192
```

## Short description

Initial video keyframe does not fit after advertising.

## Trigger condition

Writing the initial MPEG-TS keyframe for the trailing stream section raises a buffer-size exception.

## Explanation

The remainder request is marked failed before publishing the post-advertisement chunk.

## Possible causes

- Writing the initial MPEG-TS keyframe for the trailing stream section raises a buffer-size exception.

## What to check

1. Check the transmuxing buffer limit and the source keyframe size.

## Recommended action

Check the transmuxing buffer limit and the source keyframe size.
