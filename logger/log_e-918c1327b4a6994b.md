# Advertising HLS encryption failed

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-918c1327b4a6994b

## Log pattern

```text
failed to encrypt ads chunk key='%s'
```

## Parameters

- Argument 1 — Cache key: Text identifying the affected media item in the cache.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to encrypt ads chunk key='/app/stream/ad_1.ts'
```

## Short description

Advertising HLS encryption failed.

## Trigger condition

Preparing encryption for an MPEG-TS, audio, or fragmented MP4 advertising chunk returns failure.

## Explanation

The chunk is not copied to a ready cache item; request cleanup cancels the pending item.

## Possible causes

- Preparing encryption for an MPEG-TS, audio, or fragmented MP4 advertising chunk returns failure.

## What to check

1. Check the application DRM settings and preceding key or encryption errors.

## Recommended action

Check the application DRM settings and preceding key or encryption errors.
