# Playlist synchronization worker stopped

Product: Nimble Streamer
Component: Server playlists
Logging function: log_d
Log level: debug
Documentation ID: log_d-261e009989f06adb

## Log pattern

```text
ServerPlaylistSyncThread stopped
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerPlaylistSyncThread stopped
```

## Short description

Playlist synchronization worker stopped.

## Trigger condition

The synchronization loop exits after a stop request.

## Explanation

All playlist workers are stopped and joined; download observers and retained content references are released.

## Possible causes

- The synchronization loop exits after a stop request.
