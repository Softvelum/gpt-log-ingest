# Video encoder input aspect ratio changed

Product: Nimble Streamer
Component: Video encoder input stability
Logging function: log_e
Log level: error
Documentation ID: log_e-13d8f63692cc88b8

## Log pattern

```text
failed to change sar from %d/%d to %d/%d on the fly for [%s]
```

## Parameters

- Argument 1 — Old numerator: Old numerator, integer ratio component; no unit.
- Argument 2 — Old denominator: Old denominator, integer ratio component; no unit.
- Argument 3 — New numerator: New numerator, integer ratio component; no unit.
- Argument 4 — New denominator: New denominator, integer ratio component; no unit.
- Argument 5 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to change sar from 1/1 to 4/3 on the fly for [live/camera]
```

## Short description

Video encoder input aspect ratio changed.

## Trigger condition

Preserving input sample aspect ratio is active, and a later frame has a different ratio in the FFmpeg or native Quick Sync encoder.

## Explanation

The frame is rejected instead of reconfiguring the session.

## Possible causes

- The source or filter changes pixel aspect ratio.

## What to check

1. Compare the reported fractions and upstream aspect-ratio settings.

## Recommended action

Keep the ratio stable or restart encoding after the change.
