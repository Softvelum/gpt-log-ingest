# Quick Sync could not read video sequence header

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-8606304c3d1e6afa

## Log pattern

```text
failed to process seq header, status=%d
```

## Parameters

- Argument 1 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to process seq header, status=-3
```

## Short description

Quick Sync could not read video sequence header.

## Trigger condition

The media runtime returns a nonzero status while parsing the prepared sequence header or initial VP8/VP9 packet.

## Explanation

Decoder initialization fails before output surfaces are allocated.

## Possible causes

- The supplied codec configuration or first packet is not accepted by the selected decoder.

## What to check

1. Check input codec configuration and the reported media status; for VP8 or VP9 inspect the initial packet.

## Recommended action

Provide valid supported video headers or choose a decoder that accepts the input.
