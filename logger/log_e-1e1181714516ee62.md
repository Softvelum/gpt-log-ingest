# Cache fragment released twice

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-1e1181714516ee62

## Log pattern

```text
releasing fragment=%u with ref_count_=0 key='%s'
```

## Parameters

- Argument 1 — fragment: Zero-based fragment index.
- Argument 2 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
releasing fragment=0 with ref_count_=0 key='movie'
```

## Short description

Cache fragment released twice.

## Trigger condition

A fragment release finds its reference count already zero.

## Explanation

The cache reports the invalid release and leaves the count unchanged.

## Possible causes

- A release arrived without a matching active fragment reference.

## What to check

1. Compare fragment acquisition, release, and unmapping messages.

## Recommended action

Investigate ownership of the named fragment.
