failed to generate a new session id

Illustrative examples; these are not captured server logs.

## Short description

No unused session identifier found.

## Trigger condition

One hundred candidate session identifiers collide with existing sessions.

## Explanation

The newly allocated session record is deleted and registration returns an invalid identifier.

## Possible causes

- The identifier search repeatedly encountered existing sessions.

## What to check

1. Check the preceding collision messages and session restoration activity.

## Recommended action

Investigate session identifier allocation before expecting new registrations to succeed.
