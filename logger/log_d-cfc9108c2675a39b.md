# UDP input read would block on Windows

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_d
Log level: debug
Documentation ID: log_d-cfc9108c2675a39b

## Log pattern

```text
failed to recv from s=%d WSAEWOULDBLOCK
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to recv from s=42 WSAEWOULDBLOCK
```

## Short description

UDP input read would block on Windows.

## Trigger condition

A receive call returns the Windows would-block error.

## Explanation

The receiver returns success and waits for later readable data.

## Possible causes

- A receive call returns the Windows would-block error.

## What to check

1. Check whether normal traffic resumes before treating this transient event as a fault.

## Recommended action

No action is needed for an isolated would-block event.
