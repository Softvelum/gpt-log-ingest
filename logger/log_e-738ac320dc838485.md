# Playlist AAC configuration was rejected

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-738ac320dc838485

## Log pattern

```text
ServerBlockProcessor: failed to set aac header for vod file url=[%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: failed to set aac header for vod file url=[/media/program.mp4]
```

## Short description

Playlist AAC configuration was rejected.

## Trigger condition

A changed AAC configuration from the source file cannot initialize the output stream.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- A changed AAC configuration from the source file cannot initialize the output stream.

## What to check

1. Check the source AAC configuration and prior codec errors.

## Recommended action

Check the source AAC configuration and prior codec errors.
