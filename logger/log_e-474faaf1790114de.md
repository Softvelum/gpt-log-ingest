# AJA capture stopped because the input format changed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-474faaf1790114de

## Log pattern

```text
capture stopped device=%s/%d reason='input video format changed' old_format='%s' new_format='%s'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.
- Argument 3 — Old format: Runtime description of the initially detected input format.
- Argument 4 — New format: Runtime description of the latest detected input format.

## Log examples

Illustrative examples; these are not captured server logs.

```text
capture stopped device=0/0 reason='input video format changed' old_format='1080p25' new_format='1080p30'
```

## Short description

AJA capture stopped because the input format changed.

## Trigger condition

The currently detected input format differs from the format used to initialize capture.

## Explanation

The capture quit flag is set before transferring the new frame, and the loop exits. The new format can also represent loss of recognizable input.

## Possible causes

- The currently detected input format differs from the format used to initialize capture.

## What to check

1. Check the old and newly detected input formats and any source format change.

## Recommended action

Reinitialize capture for the current supported input format.
