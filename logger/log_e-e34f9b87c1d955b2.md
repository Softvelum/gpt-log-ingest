# SDI video decoder opening failed

Product: Nimble Streamer
Component: SDI device input
Logging function: log_e
Log level: error
Documentation ID: log_e-e34f9b87c1d955b2

## Log pattern

```text
failed to open video decoder params for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open video decoder params for [live/camera]
```

## Short description

SDI video decoder opening failed.

## Trigger condition

Opening the device video decoder returns a nonzero result.

## Explanation

The current device decoding operation returns failure.

## Possible causes

- The decoder rejects the supplied device video configuration.

## What to check

1. Check the device video format and accompanying FFmpeg diagnostics.

## Recommended action

Use a supported device format and retry the input.
