# DASH advertisement marker format is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-6a2b4278f28e6198

## Log pattern

```text
invalid dash_ad_marker_format parameter value: %s
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid dash_ad_marker_format parameter value: 0
```

## Short description

DASH advertisement marker format is invalid.

## Trigger condition

While reading configuration, the DASH advertisement marker format is neither bin nor xml.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires bin for encoded binary markers or xml for XML markers.

## Recommended action

Correct the value to bin for encoded binary markers or xml for XML markers and reload configuration.
