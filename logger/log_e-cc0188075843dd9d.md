# Windows file view unmap failed

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-cc0188075843dd9d

## Log pattern

```text
UnmapViewOfFile failed error=%d
```

## Parameters

- Argument 1 — Error: Windows error code, printed in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
UnmapViewOfFile failed error=487
```

## Short description

Windows file view unmap failed.

## Trigger condition

Releasing a previously mapped Windows file view fails during cleanup.

## Explanation

Cleanup continues with mapping and file handles even though view release was not confirmed.

## Possible causes

- Releasing a previously mapped Windows file view fails during cleanup.

## What to check

1. Inspect the Windows error during media-file cleanup.
