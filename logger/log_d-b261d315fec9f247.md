# DVR extra-data segment removal started

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-b261d315fec9f247

## Log pattern

```text
[DvrA::RemES] p=%u st=%llu f='%s' t=%d
```

## Parameters

- Argument 1 — Period: Unsigned recording period identifier.
- Argument 2 — Media start: 64-bit media start timestamp in the segment track timescale.
- Argument 3 — Storage file: Text naming the recorded media storage file.
- Argument 4 — Segment type: Integer recorded-segment category: 2 video, 3 audio, 6 DVB subtitle, 7 KLV, 8 WebVTT.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[DvrA::RemES] p=1 st=90000 f='/data/dvr/live/camera/1700000000000.dat' t=3
```

## Short description

DVR extra-data segment removal started.

## Trigger condition

An extra-data entry is selected for deletion.

## Explanation

Its type is checked before database and file references are removed.

## Possible causes

- An extra-data entry is selected for deletion.
