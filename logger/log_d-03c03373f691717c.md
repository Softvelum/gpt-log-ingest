# DRM provider does not protect the requested protocols

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-03c03373f691717c

## Log pattern

```text
[drm] app='%s' stream='%s' proto=%u is not protected with key server type=%u
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Protocol mask: Unsigned mask of enabled streaming protocols.
- Argument 4 — Provider type: Unsigned numeric DRM-provider identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] app='live' stream='camera' proto=0 is not protected with key server type=3
```

## Short description

DRM provider does not protect the requested protocols.

## Trigger condition

The registered protocol mask has no supported combination with the configured provider.

## Explanation

External key registration returns without requesting keys.

## Possible causes

- The registered protocol mask has no supported combination with the configured provider.

## What to check

1. Match the output protocol to a supported protection mode.

## Recommended action

Match the output protocol to a supported protection mode.
