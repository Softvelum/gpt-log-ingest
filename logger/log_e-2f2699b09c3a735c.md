# Whole-item response arrived in an unexpected cache state

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_e
Log level: error
Documentation ID: log_e-2f2699b09c3a735c

## Log pattern

```text
cache item key='%s' state=%d is not kNotReady
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — state: Cache state: 0 empty, 1 downloading, 2 fragmented, 3 ready, or 4 marked for removal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item key='https://media.example/movie.mp4' state=2 is not kNotReady
```

## Short description

Whole-item response arrived in an unexpected cache state.

## Trigger condition

A nonfragmented GET response reaches completion while its cache item is not empty.

## Explanation

The ordinary ready transition is skipped. A downloading item is canceled if that state is encountered; the reference and active request are then released.

## Possible causes

- The completed whole-item request encountered an unexpected item state.

## What to check

1. Compare prior state changes and concurrent requests for the key.

## Recommended action

Investigate cache item lifecycle ordering.
