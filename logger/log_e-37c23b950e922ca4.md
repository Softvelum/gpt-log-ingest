# VAAPI derived image is unusable

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-37c23b950e922ca4

## Log pattern

```text
vaDeriveImage can't be used

```

## Log examples

Illustrative examples; these are not captured server logs.

```text
vaDeriveImage can't be used

```

## Short description

VAAPI derived image is unusable.

## Trigger condition

Deriving a surface image succeeds but returns an invalid image or buffer identifier.

## Explanation

Frame encoding fails before the image can be mapped.

## Possible causes

- The driver did not supply usable identifiers for direct surface-image access.

## What to check

1. Check driver support for deriving images from the selected surface format.

## Recommended action

Use a compatible VA driver or another encoder backend.
