# Playlist response ready for the client

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-0264fb3d5947cb6a

## Log pattern

```text
client s=%d response (playlist):
%s%s
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.
- Argument 2 — Response headers: Text of the assembled HTTP response headers.
- Argument 3 — Separate body: Text body stored separately when applicable; may be empty.

## Short description

Playlist response ready for the client.

## Trigger condition

A rewritten playlist response is assembled with HTTP 200 headers.

## Explanation

Client sending begins; a short GET body may be included in the header buffer, a large one uses a separate buffer, and HEAD omits the body.

## Possible causes

- A rewritten playlist response is assembled with HTTP 200 headers.
