# Listening port is configured for conflicting security modes

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-dcf2443940253cbc

## Log pattern

```text
port=%s can not be used for both plain and SSL connections
```

## Parameters

- Argument 1 — Port: The conflicting port token as text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
port=8081 can not be used for both plain and SSL connections
```

## Short description

Listening port is configured for conflicting security modes.

## Trigger condition

A TLS listening-port token is also present in the plain-port list.

## Explanation

Listener configuration exits the process with a failure status before creating sockets for that configuration.

## Possible causes

- The same port text appears in the plain and TLS lists.

## What to check

1. Compare the plain and TLS listening-port lists.

## Recommended action

Assign distinct ports to plain and TLS listeners.
