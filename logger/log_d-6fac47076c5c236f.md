# HTTP/3 observed cache item updated

Product: Nimble Streamer
Component: HTTP/2 and HTTP/3 request handling
Logging function: log_d
Log level: debug
Documentation ID: log_d-6fac47076c5c236f

## Log pattern

```text
[H3C::OnCIU] key='%s' st=%d (%p s=%d)
```

## Parameters

- Argument 1 — Cache key: Requested cache-item key, text; identifies the origin resource.
- Argument 2 — Cache state: Cache state code, integer: 0 newly allocated/not ready, 1 downloading, 2 fragmented, 3 fully ready, 4 marked for removal.
- Argument 3 — Connection identity: In-process connection object address, pointer displayed in hexadecimal; useful only for correlating this process lifetime.
- Argument 4 — Connection identifier: HTTP/3 session index, integer; this value is not a socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[H3C::OnCIU] key='https://origin.example/movie.mp4' st=3 (0x12340000 s=12)
```

## Short description

HTTP/3 observed cache item updated.

## Trigger condition

A cache update is matched to an observed request stream that still has a pending request and a corresponding cache item.

## Explanation

The item state controls whether the request keeps waiting, resumes downloading/fragment delivery, sends completed content, or receives an error after removal. This diagnostic is emitted before that action.
