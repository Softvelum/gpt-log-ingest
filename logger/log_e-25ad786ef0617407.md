# Could not create the DVR repackaging worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-25ad786ef0617407

## Log pattern

```text
failed to create dvr transmuxer thread %d
```

## Parameters

- Argument 1 — Worker index: Zero-based index of the worker whose creation failed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create dvr transmuxer thread 0
```

## Short description

Could not create the DVR repackaging worker.

## Trigger condition

A configured DVR repackaging worker is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the DVR repackaging worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed DVR repackaging worker.
