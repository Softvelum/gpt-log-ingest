# API list entry has the wrong JSON type

Product: Nimble Streamer
Component: Advertising and Zixi API responses
Logging function: log_e
Log level: error
Documentation ID: log_e-c12e9ac8e6e85753

## Log pattern

```text
invalid content type=%d
```

## Parameters

- Argument 1 — JSON type: Integer JSON type code of the unexpected value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid content type=6
```

## Short description

API list entry has the wrong JSON type.

## Trigger condition

An advertising content entry, Zixi stream entry, or Zixi output entry is not a JSON object.

## Explanation

The malformed entry is skipped; remaining entries continue to be processed.

## Possible causes

- An advertising content entry, Zixi stream entry, or Zixi output entry is not a JSON object.

## What to check

1. Return objects in the advertising contents or Zixi streams and outputs arrays.

## Recommended action

Return objects in the advertising contents or Zixi streams and outputs arrays.
