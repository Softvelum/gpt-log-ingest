# Cache metadata file opened

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-6ce69454a28f775b

## Log pattern

```text
created mf='%s'
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

Cache metadata file opened.

## Trigger condition

The metadata file is successfully opened for writing.

## Explanation

Item details still need to be serialized, written, and closed, so this message alone does not prove metadata was saved.
