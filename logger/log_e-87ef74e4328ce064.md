# DVR HEVC configuration cannot be assembled

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-87ef74e4328ce064

## Log pattern

```text
[VM] buildHEVCDecoderConfigurationRecord failed for [%s]
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[VM] buildHEVCDecoderConfigurationRecord failed for [live/camera]
```

## Short description

DVR HEVC configuration cannot be assembled.

## Trigger condition

The HEVC decoder configuration cannot be built from VPS, SPS, and PPS data within its output buffer.

## Explanation

Video initialization fails.

## Possible causes

- The HEVC decoder configuration cannot be built from VPS, SPS, and PPS data within its output buffer.

## What to check

1. Check HEVC parameter-set validity and size.

## Recommended action

Check HEVC parameter-set validity and size.
