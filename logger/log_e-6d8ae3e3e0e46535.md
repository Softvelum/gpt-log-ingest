# SLDP Play exceeds its selection capacity

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-6d8ae3e3e0e46535

## Log pattern

```text
viewer issues too many streams
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
viewer issues too many streams
```

## Short description

SLDP Play exceeds its selection capacity.

## Trigger condition

A Play entry requires a new playback selection while all four selection slots are occupied.

## Explanation

This extra entry is ignored after logging. Already accepted selections remain, and the command can still succeed.

## Possible causes

- A Play entry requires a new playback selection while all four selection slots are occupied.

## What to check

1. Count distinct source/offset selections and duration-limited selections in the request.

## Recommended action

Cancel unused selections or keep the request within four selection slots.
