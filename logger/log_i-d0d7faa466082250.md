# HLS encryption uses the default DRM key

Product: Nimble Streamer
Component: DRM key management
Logging function: log_i
Log level: info
Documentation ID: log_i-d0d7faa466082250

## Log pattern

```text
using default DRM key for stream '%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
using default DRM key for stream 'live/camera'
```

## Short description

HLS encryption uses the default DRM key.

## Trigger condition

A VCAS key is unavailable, fallback is enabled, and a default key exists.

## Explanation

The default key is copied for this HLS operation.

## Possible causes

- A VCAS key is unavailable, fallback is enabled, and a default key exists.

## What to check

1. Check VCAS failures if use of the fallback key was unexpected.

## Recommended action

Check VCAS failures if use of the fallback key was unexpected.
