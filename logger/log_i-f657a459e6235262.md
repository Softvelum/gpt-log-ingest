# Process signal received

Product: Nimble Streamer
Component: Process signals and exception diagnostics
Logging function: log_i
Log level: info
Documentation ID: log_i-f657a459e6235262

## Log pattern

```text
signal handler: %s (%d)
```

## Parameters

- Argument 1 — Signal description: Operating system description of the signal, text.
- Argument 2 — Signal: Operating system signal number, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
signal handler: Interrupt (2)
```

## Short description

Process signal received.

## Trigger condition

On non-Windows platforms, the signal handler receives a termination signal or enters its default signal branch.

## Explanation

Interrupt requests stop the server. On non-Windows systems, termination and user signal 1 also stop it; other signals enter stack-trace reporting. The log-reopen signal is handled without this message.

## Possible causes

- An operating system signal was delivered to the process.

## What to check

1. Identify the signal and whether shutdown was requested intentionally.

## Recommended action

Investigate an unexpected signal; allow an intentional stop request to complete.
