# Whisper model context creation failed

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-739a98e1fcc969d8

## Log pattern

```text
failed to create whisper ctx model='%s' use_gpu=%d gpu_device=%d
```

## Parameters

- Argument 1 — Model: Configured Whisper model file path.
- Argument 2 — GPU enabled: Boolean GPU preference, printed as 0 or 1.
- Argument 3 — GPU device: Configured GPU device number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create whisper ctx model='/data/models/speech.bin' use_gpu=1 gpu_device=0
```

## Short description

Whisper model context creation failed.

## Trigger condition

The Whisper library cannot initialize a model context from the configured file and device settings.

## Explanation

Audio transcription fails before the audio decoder is used.

## Possible causes

- The Whisper library cannot initialize a model context from the configured file and device settings.

## What to check

1. Check model availability and library diagnostics for the requested GPU settings.
