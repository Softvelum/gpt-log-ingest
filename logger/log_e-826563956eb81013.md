# Unavailable Icecast advertisement skipped

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-826563956eb81013

## Log pattern

```text
skip advertising content error id=%s uri=%s
```

## Parameters

- Argument 1 — Content ID: Text identifying the advertising content.
- Argument 2 — Content URI: Text giving the original advertising content location.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip advertising content error id=ad-01 uri=https://media.example/ad.mp4
```

## Short description

Unavailable Icecast advertisement skipped.

## Trigger condition

A scheduled advertisement is not ready, cannot be waited for, and its error policy is skip.

## Explanation

The pending advertisement entry is removed and selection continues with the next entry.

## Possible causes

- A scheduled advertisement is not ready, cannot be waited for, and its error policy is skip.

## What to check

1. Check why this content is unavailable; verify that skipping is the intended rule policy.

## Recommended action

Check why this content is unavailable; verify that skipping is the intended rule policy.
