# Socket event has no active session

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_e
Log level: error
Documentation ID: log_e-8f57fe7989886421

## Log pattern

```text
invalid fd=%d event=%d received from selector
```

## Parameters

- Argument 1 — Socket: Integer socket descriptor.
- Argument 2 — Event mask: Decimal bit mask from the event selector.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid fd=12 event=1 received from selector
```

## Short description

Socket event has no active session.

## Trigger condition

A still-valid descriptor has no active session in an HTTP or advertising-download worker; the HTTP worker also excludes valid HTTP/3 events.

## Explanation

The descriptor is removed from event monitoring. This branch does not explicitly close it.

## Possible causes

- A valid event descriptor has no owning active session.

## What to check

1. Compare the descriptor with preceding session creation and deletion events.
