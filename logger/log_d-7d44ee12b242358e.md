# DRM key notification consumer registered

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-7d44ee12b242358e

## Log pattern

```text
[drm] added key observer for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] added key observer for 'live/camera'
```

## Short description

DRM key notification consumer registered.

## Trigger condition

A nonnull listener is added for the application or stream.

## Explanation

The consumer can be notified when its pending key operation succeeds or fails.

## Possible causes

- A nonnull listener is added for the application or stream.
