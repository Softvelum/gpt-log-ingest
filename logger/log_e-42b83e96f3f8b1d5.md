# Common-encryption segment parameters failed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-42b83e96f3f8b1d5

## Log pattern

```text
EncryptCencChunk failed to encrypt segment for [%s/%s] cenc_required=%d
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Encryption required: Integer boolean showing whether CENC was required: 0 false, 1 true.

## Log examples

Illustrative examples; these are not captured server logs.

```text
EncryptCencChunk failed to encrypt segment for [live/camera] cenc_required=1
```

## Short description

Common-encryption segment parameters failed.

## Trigger condition

Media-segment parameter lookup reports failure or does not mark CENC required.

## Explanation

The segment encryption operation returns failure.

## Possible causes

- Media-segment parameter lookup reports failure or does not mark CENC required.

## What to check

1. Check preceding license and key-availability errors.

## Recommended action

Check preceding license and key-availability errors.
