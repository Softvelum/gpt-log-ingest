# SVT-HEVC library is unavailable

Product: Nimble Streamer
Component: HEVC encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-99f09c5f4055b5b8

## Log pattern

```text
libsvthevc is unavailable
```

## Parameters

Shared by ordinary output encoder selection and HEVC black-segment generation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
libsvthevc is unavailable
```

## Short description

SVT-HEVC library is unavailable.

## Trigger condition

A build with SVT-HEVC integration attempts to create a normal encoder or a generated black-video segment while the library-availability flag is false.

## Explanation

Normal encoder creation fails, or black-segment creation returns no segment.

## Possible causes

- The optional SVT-HEVC library did not load successfully.

## What to check

1. Check preceding SVT-HEVC library-loading diagnostics and whether black-frame generation or an output encoder requested it.

## Recommended action

Restore the compatible library or select an available encoder where configurable.
