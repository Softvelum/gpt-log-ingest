# AJA output video buffer size is negative

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-023b8665e56d9e77

## Log pattern

```text
Bad output video buffer size for device '%s': video=%d
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Configured value: Signed integer count of buffered video frames.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Bad output video buffer size for device '0': video=-1
```

## Short description

AJA output video buffer size is negative.

## Trigger condition

The configured video buffer size is below zero.

## Explanation

Output parameter validation returns failure. A value of zero is not rejected by this check.

## Possible causes

- The configured video buffer size is below zero.

## What to check

1. Check the video buffer size setting.

## Recommended action

Use a nonnegative video buffer size.
