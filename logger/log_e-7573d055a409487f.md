# Inactive RTMP pull receiver removed

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_e
Log level: error
Documentation ID: log_e-7573d055a409487f

## Log pattern

```text
inactive rtmp socket removed [%d], url=%s
```

## Parameters

- Argument 1 — socket: Receiver socket descriptor.
- Argument 2 — URL: Current pulled stream URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
inactive rtmp socket removed [12], url=rtmp://media.example/live/camera
```

## Short description

Inactive RTMP pull receiver removed.

## Trigger condition

The periodic RTMP inactivity check finds a normal receiver in the shut-down state.

## Explanation

The receiver and its identifier mapping are removed, and the live-pull settings marker is cleared to request synchronization. Probe receivers use a separate cleanup path.

## Possible causes

- The receiver is shut down when periodic inactivity handling runs.

## What to check

1. Check earlier input, timeout, and connection diagnostics for the URL.

## Recommended action

Resolve the origin availability problem if repeated reconnect attempts occur.
