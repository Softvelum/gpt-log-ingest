# NDI media conversion libraries could not be initialized

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-ae83291f328e86c4

## Log pattern

```text
failed to load transcoder libs, ndi_name=%s
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load transcoder libs, ndi_name=Camera
```

## Short description

NDI media conversion libraries could not be initialized.

## Trigger condition

A non-listing NDI mode fails to initialize its media-processing libraries.

## Explanation

Library initialization stops before NDI loading or sender/receiver creation. Source-list mode skips this media-library initialization.

## Possible causes

- A non-listing NDI mode fails to initialize its media-processing libraries.

## What to check

1. Check the media-processing libraries needed by the selected NDI mode.
