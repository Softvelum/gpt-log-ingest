# RTSP request line is malformed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-48b5253b4c978242

## Log pattern

```text
unable to parse request line for [%s]: %s
```

## Parameters

- Argument 1 — Stream identity: Application and stream label used by the RTSP parser.
- Argument 2 — Request line: Received line without its terminating newline.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unable to parse request line for [live/camera]: PLAY
```

## Short description

RTSP request line is malformed.

## Trigger condition

A complete line does not match a method, URI, and RTSP/1.0 request-line structure.

## Explanation

The parser resets to its interleaved-data state and returns a parse failure.

## Possible causes

- A complete line does not match a method, URI, and RTSP/1.0 request-line structure.

## What to check

1. Check the request line sent by the client.

## Recommended action

Send a complete RTSP/1.0 request line.
