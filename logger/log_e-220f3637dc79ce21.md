# Whisper library loading failed

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-220f3637dc79ce21

## Log pattern

```text
LoadWhisperLibraries exception what()='%s'
```

## Parameters

- Argument 1 — Error: Exception description from the dynamic library loader.

## Log examples

Illustrative examples; these are not captured server logs.

```text
LoadWhisperLibraries exception what()='Whisper library unavailable'
```

## Short description

Whisper library loading failed.

## Trigger condition

Loading the Whisper library or resolving required entry points throws an exception.

## Explanation

The partial library handle is closed and Whisper library initialization fails. This path requires Whisper support.

## Possible causes

- Loading the Whisper library or resolving required entry points throws an exception.

## What to check

1. Read the exception text for the library loading failure.
