# NDI SEI-timecode sender thread could not start

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-ab4f0562281460ff

## Log pattern

```text
failed to start ndi sender thread, ndi_name="%s"
```

## Parameters

- Argument 1 — NDI name: Requested or resolved NDI source name identifying the affected input or output.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start ndi sender thread, ndi_name="HOST (Output)"
```

## Short description

NDI SEI-timecode sender thread could not start.

## Trigger condition

The SEI-timecode output worker creation operation returns false after the NDI sender has been created.

## Explanation

Sender initialization returns failure; no successfully initialized scheduled sender is returned.

## Possible causes

- The SEI-timecode output worker creation operation returns false after the NDI sender has been created.

## What to check

1. Check the SEI-timecode sender thread initialization.
