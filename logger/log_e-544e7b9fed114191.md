# RTMP playback stops on an advertising load error

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-544e7b9fed114191

## Log pattern

```text
s=%d, stop on advertising content error %s
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.
- Argument 2 — Content URI: Configured URI of the selected advertising media item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
s=42, stop on advertising content error https://media.example/ad.mp4
```

## Short description

RTMP playback stops on an advertising load error.

## Trigger condition

Unready content cannot be waited for and is not configured to skip, or a reader cannot be created for an audio/video or audio-only advertising item.

## Explanation

The media send operation fails and the caller shuts down playback.

## Possible causes

- Unready content cannot be waited for and is not configured to skip, or a reader cannot be created for an audio/video or audio-only advertising item.

## What to check

1. Check content readiness, reader/format errors, and the advertisement error policy.

## Recommended action

Provide a readable advertising item or correct its intended error policy.
