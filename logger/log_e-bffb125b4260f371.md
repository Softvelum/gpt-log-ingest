# AJA output signal routing failed

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-bffb125b4260f371

## Log pattern

```text
Output routing failed on '%s' channel '%s', failures=%u
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel name: Human-readable channel description returned by the AJA runtime.
- Argument 3 — Failed connections: Unsigned count of failed routing connections; one or two depending on the route.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Output routing failed on 'AJA device' channel 'Channel 1', failures=1
```

## Short description

AJA output signal routing failed.

## Trigger condition

One or more required card routing connections report failure.

## Explanation

RGB output attempts two connections through the color converter; non-RGB output attempts one direct connection. The failure count is returned as unsuccessful routing, preventing normal sender startup.

## Possible causes

- One or more required card routing connections report failure.

## What to check

1. Check the selected channel and its frame-buffer-to-SDI routing support.
