# DVR ID3 metadata append failed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-30bff33ed38833a5

## Log pattern

```text
failed to save id3_info to file='%s'
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded media storage file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to save id3_info to file='/data/dvr/live/camera/1700000000000.dat'
```

## Short description

DVR ID3 metadata append failed.

## Trigger condition

An audio segment has been written, but appending changed ID3 metadata fails.

## Explanation

Segment addition returns failure before its database record is written.

## Possible causes

- An audio segment has been written, but appending changed ID3 metadata fails.

## What to check

1. Check storage-write errors and available disk space.

## Recommended action

Check storage-write errors and available disk space.
