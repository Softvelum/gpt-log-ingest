# Transport stream publishing stops

Product: Nimble Streamer
Component: MPEG-TS stream registration and parsing
Logging function: log_v
Log level: verbose
Documentation ID: log_v-d361ba167026d4ec

## Log pattern

```text
stopped publishing stream='%s/%s' %s
```

## Parameters

- Argument 1 — Application: Source application.
- Argument 2 — Stream: Source stream.
- Argument 3 — Publishing context: Output destination and mode description, including SRT peer/group information where applicable.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stopped publishing stream='live/camera' to 'srt://192.0.2.20:5000' mode='push'
```

## Short description

Transport stream publishing stops.

## Trigger condition

A stream iterator with recorded publishing context and a live source buffer is destroyed.

## Explanation

This stream association is being removed; the line alone does not identify the reason or establish that every output has stopped.

## Possible causes

- A stream iterator with recorded publishing context and a live source buffer is destroyed.

## What to check

1. Match the application, stream, and destination/mode context with expected output lifecycle changes.

## Recommended action

No action is needed for expected publishing lifecycle changes.
