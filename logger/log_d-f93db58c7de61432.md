# Initial SRT group member state

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_d
Log level: debug
Documentation ID: log_d-f93db58c7de61432

## Log pattern

```text
srt group=%d sock=%d state=%s
```

## Parameters

- Argument 1 — Group: SRT group socket identifier.
- Argument 2 — Member: SRT member socket identifier.
- Argument 3 — State: Textual SRT socket state.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt group=1073741924 sock=101 state=connecting
```

## Short description

Initial SRT group member state.

## Trigger condition

After initiating a group connection, the library returns details for each group member.

## Explanation

The debug message records the member state at that point; connecting is not the same as connected.

## Possible causes

- After initiating a group connection, the library returns details for each group member.

## What to check

1. Check whether each configured member progresses to connected.
