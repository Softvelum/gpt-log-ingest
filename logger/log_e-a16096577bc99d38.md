# DVR replacement fragment does not fit

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_e
Log level: error
Documentation ID: log_e-a16096577bc99d38

## Log pattern

```text
failed to extend segment from %d to %d
```

## Parameters

- Argument 1 — Original bytes: Original allocated segment size in bytes.
- Argument 2 — Replacement bytes: Generated replacement fragment size in bytes, excluding the extra eight-byte header.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to extend segment from 1000 to 998
```

## Short description

DVR replacement fragment does not fit.

## Trigger condition

The replacement fragment plus its required eight-byte free-space header exceeds the original segment size.

## Explanation

The original segment is not rewritten by this operation.

## Possible causes

- The replacement fragment plus its required eight-byte free-space header exceeds the original segment size.

## What to check

1. Check the preceding blackout or mute parameters and replacement segment size.

## Recommended action

Check the preceding blackout or mute parameters and replacement segment size.
