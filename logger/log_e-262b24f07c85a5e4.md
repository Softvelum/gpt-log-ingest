# Could not create the MPEG-TS input worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error

## Log examples

Illustrative examples; these are not captured server logs.

## Short description

Could not create the MPEG-TS input worker.

## Trigger condition

One of the configured MPEG-TS input workers is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the MPEG-TS input worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed MPEG-TS input worker.
