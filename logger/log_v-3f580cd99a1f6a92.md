# Disk cache loading paused between batches

Product: Nimble Streamer
Component: Media data cache
Logging function: log_v
Log level: verbose
Documentation ID: log_v-3f580cd99a1f6a92

## Log pattern

```text
Interrupted loading cache, %llu item(s), disk cache size is %llu bytes
```

## Parameters

- Argument 1 — items: Current number of registered cache items.
- Argument 2 — disk bytes: Total cache capacity currently accounted for on disk, in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Interrupted loading cache, 100 item(s), disk cache size is 104857600 bytes
```

## Short description

Disk cache loading paused between batches.

## Trigger condition

The current loading batch ends before all protocol directories are scanned.

## Explanation

This is a scheduled pause, not necessarily an error. The saved traversal continues on a later loading call.
