# CUDA context cache fill started

Product: Nimble Streamer
Component: NVIDIA device contexts
Logging function: log_i
Log level: info
Documentation ID: log_i-099ca26b778e9b15

## Log pattern

```text
cache %d cuda ctx, gpu=%d, flag=%d...
```

## Parameters

- Argument 1 — Requested contexts: Number of contexts requested for this batch, integer contexts.
- Argument 2 — GPU: Zero-based CUDA device index, integer; no unit.
- Argument 3 — Flags: CUDA context creation flags, integer bit mask printed in decimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache 2 cuda ctx, gpu=0, flag=0...
```

## Short description

CUDA context cache fill started.

## Trigger condition

A cache initialization batch begins for a GPU and context-creation flag combination.

## Explanation

The requested number of context creations will be attempted; individual failures do not stop the batch.
