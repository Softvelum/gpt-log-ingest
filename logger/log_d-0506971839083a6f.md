# Windows version query failed

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_d
Log level: debug
Documentation ID: log_d-0506971839083a6f

## Log pattern

```text
GetVersionExW() failed errno=%d
```

## Parameters

- Argument 1 — Windows error: Windows last-error code, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
GetVersionExW() failed errno=5
```

## Short description

Windows version query failed.

## Trigger condition

The preferred Windows version query is unavailable or fails, and the compatibility version query also fails.

## Explanation

The operating system name falls back to Windows without a version.

## Possible causes

- Windows rejected the version query.

## What to check

1. Check the Windows error code if accurate version reporting is needed.

## Recommended action

Investigate the version-query failure when version reporting matters.
