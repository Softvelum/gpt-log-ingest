# Keyframe frame-count interval is invalid

Product: Nimble Streamer
Component: Transcoding output
Logging function: log_e
Log level: error
Documentation ID: log_e-0e4785b908a7de03

## Log pattern

```text
invalid key frame boundary for frame count interval alignment [%s/%s]
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid key frame boundary for frame count interval alignment [live/encoded]
```

## Short description

Keyframe frame-count interval is invalid.

## Trigger condition

Frame-count keyframe alignment is selected with a boundary less than one.

## Explanation

The current video-frame operation fails and the worker stops.

## Possible causes

- The configured keyframe interval is zero or negative.

## What to check

1. Check the frame-count keyframe boundary.

## Recommended action

Set a positive interval in frames.
