# Playlist cache notification has no matching request

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-2811d784dfac3746

## Log pattern

```text
cache item not found key=%s
```

## Parameters

- Argument 1 — Content location: Text identifying a local media file or a remote cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cache item not found key=/media/program.mp4
```

## Short description

Playlist cache notification has no matching request.

## Trigger condition

A cache notification refers to a key absent from the playlist download request set.

## Explanation

The notification is ignored.

## Possible causes

- A cache notification refers to a key absent from the playlist download request set.

## What to check

1. Check whether the content request was removed during a playlist update.

## Recommended action

Check whether the content request was removed during a playlist update.
