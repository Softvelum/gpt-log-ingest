# Widevine key installed

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-a890c92367f98e84

## Log pattern

```text
[drm] added Widevine key for '%s' cpi=%u type='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Crypto-period index: Unsigned index of the requested or selected key rotation period.
- Argument 3 — Key type: Text classifying the Widevine media key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] added Widevine key for 'live/camera' cpi=120 type='HD'
```

## Short description

Widevine key installed.

## Trigger condition

A successful Widevine response key matches a stored crypto-period index and media-key type.

## Explanation

The key, key ID, and protection header are stored and its failed state clears.

## Possible causes

- A successful Widevine response key matches a stored crypto-period index and media-key type.
