# Advertising grouped request interval is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-52fbb4859b989443

## Log pattern

```text
invalid parameter value: %s. should be >= 10 && <= 200
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 10 && <= 200
```

## Short description

Advertising grouped request interval is invalid.

## Trigger condition

While reading configuration, the grouped advertising session-rules request interval is outside 10 through 200.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires an interval from 10 through 200.

## Recommended action

Correct the value to an interval from 10 through 200 and reload configuration.
