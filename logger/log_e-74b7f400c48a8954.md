# WHIP publication aborted

Product: Nimble Streamer
Component: WHIP publishing helper
Logging function: log_e
Log level: error
Documentation ID: log_e-74b7f400c48a8954

## Log pattern

```text
WHIP session aborted by publish framework or explicitly deleted session=%d stream=[%s/%s]
```

## Parameters

- Argument 1 — Session identifier: WebRTC helper session identifier, unsigned 32-bit integer displayed in decimal; no unit.
- Argument 2 — Application: Application name, text.
- Argument 3 — Stream: Stream name, text.

The log text identifies authorization-framework denial or explicit deletion as the intended sources of the abort flag.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WHIP session aborted by publish framework or explicitly deleted session=7 stream=[live/camera]
```

## Short description

WHIP publication aborted.

## Trigger condition

A WHIP media socket is ready to read but its session has already been marked aborted.

## Explanation

Media processing stops; the caller removes the active session and publishing authorization record and closes its media socket.
