# SDI video decoder allocation failed

Product: Nimble Streamer
Component: SDI device input
Logging function: log_e
Log level: error
Documentation ID: log_e-d0305c23b409002d

## Log pattern

```text
failed to create video decoder for [%s]
```

## Parameters

- Argument 1 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create video decoder for [live/camera]
```

## Short description

SDI video decoder allocation failed.

## Trigger condition

Allocating the device video decoder context returns no context.

## Explanation

The current device decoding operation returns failure.

## Possible causes

- Decoder context allocation fails.

## What to check

1. Check memory availability while the device video decoder starts.

## Recommended action

Restore available memory and retry the input.
