# Windows UDP output send fails

Product: Nimble Streamer
Component: MPEG-TS transport input and output
Logging function: log_e
Log level: error
Documentation ID: log_e-9d972301ff98186f

## Log pattern

```text
failed to send s=%d '%s:%d' ws_err=%d
```

## Parameters

- Argument 1 — Socket: Numeric socket descriptor.
- Argument 2 — Destination: Configured destination IP address.
- Argument 3 — Port: Configured destination port.
- Argument 4 — Windows error: Windows socket error code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send s=42 '192.0.2.20:5000' ws_err=10051
```

## Short description

Windows UDP output send fails.

## Trigger condition

A UDP send fails with a Windows socket error other than would-block.

## Explanation

The send operation returns failure and the sending loop transitions to shutdown.

## Possible causes

- A UDP send fails with a Windows socket error other than would-block.

## What to check

1. Check the Windows socket error and configured destination.

## Recommended action

Resolve the reported output socket failure.
