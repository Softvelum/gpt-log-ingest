# Scenario process stopped before connecting

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_e
Log level: error
Documentation ID: log_e-31b0642766d94892

## Log pattern

```text
remove remote transcoder id=%s, process stopped
```

## Parameters

- Argument 1 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remove remote transcoder id=scenario1, process stopped
```

## Short description

Scenario process stopped before connecting.

## Trigger condition

An unconnected scenario child is no longer running when the parent checks it.

## Explanation

The controller is removed and cleaned up; audio and video synchronization is invalidated so the required scenario can be created again.

## Possible causes

- The scenario process exits before establishing its parent connection.

## What to check

1. Check child process diagnostics preceding the exit.

## Recommended action

Correct the child startup failure.
