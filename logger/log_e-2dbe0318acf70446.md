# RTSP publishing URL authorization failed

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-2dbe0318acf70446

## Log pattern

```text
url auth failed, url=%s client=%d
```

## Parameters

- Argument 1 — URL: RTSP stream or track URL for the request.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

The URL is logged as supplied and can include authorization query parameters.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url auth failed, url=rtsp://192.0.2.1/live/camera client=25
```

## Short description

RTSP publishing URL authorization failed.

## Trigger condition

Publishing-signature processing reports failure, or the supplied URL login/password text does not match the application credentials.

## Explanation

Signature failure sends a forbidden response and execution continues into subsequent authorization logic. A credential mismatch sends a new Digest challenge and returns immediately. The message therefore covers two different response paths.

## Possible causes

- Publishing-signature processing reports failure, or the supplied URL login/password text does not match the application credentials.

## What to check

1. Check whether the URL used a publishing signature or direct RTSP credentials, then verify that authorization data.

## Recommended action

Provide authorization data accepted for the publishing application.
