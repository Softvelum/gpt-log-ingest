# DVR audio message is truncated

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-4d462bbe171808f9

## Log pattern

```text
[AM] wrong message size %d stream='%s'
```

## Parameters

- Argument 1 — Message bytes: Number of bytes in the supplied media message.
- Argument 2 — Stream: Text naming the application and stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] wrong message size 1 stream='live/camera'
```

## Short description

DVR audio message is truncated.

## Trigger condition

The audio message is empty, its AAC configuration lacks two payload bytes, or its AC3/EAC3 payload is no larger than its RTMP header.

## Explanation

The current recording pass returns failure.

## Possible causes

- The audio message is empty, its AAC configuration lacks two payload bytes, or its AC3/EAC3 payload is no larger than its RTMP header.

## What to check

1. Check incoming audio packet size and complete codec headers.

## Recommended action

Check incoming audio packet size and complete codec headers.
