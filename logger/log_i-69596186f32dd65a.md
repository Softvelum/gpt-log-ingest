# Delayed pull task source is dead

Product: Nimble Streamer
Component: Live input and publishing workers
Logging function: log_i
Log level: info
Documentation ID: log_i-69596186f32dd65a

## Log pattern

```text
live pull task for %s/%s is dead
```

## Parameters

- Argument 1 — application: Application of the delayed pull task.
- Argument 2 — stream: Stream of the delayed pull task.

## Log examples

Illustrative examples; these are not captured server logs.

```text
live pull task for live/camera is dead
```

## Short description

Delayed pull task source is dead.

## Trigger condition

Settings synchronization finds a delayed pull task whose live stream is marked dead.

## Explanation

Its indexes are removed and recreation is attempted using the current matching settings; an unused task preserves its previous idle start time.
