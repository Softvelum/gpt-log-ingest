# New geolocation database could not be installed

Product: Nimble Streamer
Component: IP geolocation
Logging function: log_e
Log level: error
Documentation ID: log_e-6544130eaa45cdf1

## Log pattern

```text
failed to move '%s' to '%s'
```

## Parameters

- Argument 1 — Replacement path: Text path of the proposed database file.
- Argument 2 — Cache path: Text destination path for the cached database.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to move '/tmp/country.mmdb' to '/var/cache/nimble/GeoLite2-Country.mmdb'
```

## Short description

New geolocation database could not be installed.

## Trigger condition

A replacement database passes verification but moving it to the cached database path fails.

## Explanation

The temporary replacement is removed and the cached database is reopened. The update returns the result of reopening the cache.

## Possible causes

- Moving the verified database into the cache failed.

## What to check

1. Check the replacement and destination paths and the associated filesystem error.
