# DVR time-bucket directory removal failed

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_e
Log level: error
Documentation ID: log_e-e162975e33f332e9

## Log pattern

```text
failed to remove dvr archive dir='%s' ec.value()=%d ec.message()='%s'
```

## Parameters

- Argument 1 — Archive directory: Text giving the archive or time-bucket directory.
- Argument 2 — Filesystem error: Integer filesystem error code.
- Argument 3 — Error message: Text describing the reported filesystem failure.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to remove dvr archive dir='/data/dvr/live/camera/1700000000000' ec.value()=13 ec.message()='Permission denied'
```

## Short description

DVR time-bucket directory removal failed.

## Trigger condition

Recursive directory removal removes nothing or reports a filesystem error.

## Explanation

Cleanup returns failure and the directory is not confirmed removed.

## Possible causes

- Recursive directory removal removes nothing or reports a filesystem error.

## What to check

1. Check directory permissions, open-file use, and the reported filesystem error.

## Recommended action

Check directory permissions, open-file use, and the reported filesystem error.
