# SDI input pixel format is unsupported

Product: Nimble Streamer
Component: SDI device input
Logging function: log_e
Log level: error
Documentation ID: log_e-e57530178b6e0d67

## Log pattern

```text
unsupported frame format [%d] for [%s]
```

## Parameters

- Argument 1 — Pixel format: FFmpeg pixel-format identifier, integer; no unit.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported frame format [0] for [live/camera]
```

## Short description

SDI input pixel format is unsupported.

## Trigger condition

An opened device reports a video pixel format other than packed UYVY422.

## Explanation

Input creation fails before the device stream is ready.

## Possible causes

- The device supplies a pixel format other than the supported UYVY422 format.

## What to check

1. Check the device video mode and the reported pixel-format identifier.

## Recommended action

Configure the input device to deliver UYVY422 video.
