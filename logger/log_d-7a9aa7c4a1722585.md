# VCAS key set is missing

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-7a9aa7c4a1722585

## Log pattern

```text
no keys found for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
no keys found for 'live/camera'
```

## Short description

VCAS key set is missing.

## Trigger condition

HLS encryption finds no key set for the application or stream.

## Explanation

The HLS operation fails unless fallback to the configured default key is permitted; with fallback permitted, default-key selection is attempted.

## Possible causes

- HLS encryption finds no key set for the application or stream.

## What to check

1. Check key registration and key-server errors; verify the intended default-key fallback setting.

## Recommended action

Check key registration and key-server errors; verify the intended default-key fallback setting.
