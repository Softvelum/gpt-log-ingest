## Short description

Cannot allocate OCR instance.

## Trigger condition

Tesseract does not return a new OCR instance for a language not already active.

## Explanation

Processing of the subtitle message fails; no language decoder is installed.

## Possible causes

- Tesseract does not return a new OCR instance for a language not already active.

## What to check

1. Check Tesseract availability and surrounding allocation diagnostics.
