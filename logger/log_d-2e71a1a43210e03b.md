# Local media or DVR file opened

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-2e71a1a43210e03b

## Log pattern

```text
opened file='%s' fd=%d
```

## Parameters

- Argument 1 — Filename: Text filesystem path of the local media or DVR archive file.
- Argument 2 — File descriptor: Integer descriptor of the newly opened file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
opened file='/media/movie.mp4' fd=23
```

## Short description

Local media or DVR file opened.

## Trigger condition

The requested local media or DVR archive file opens successfully for reading.

## Explanation

The descriptor is recorded before file metadata, DVR headers, or requested ranges are validated.

## Possible causes

- The requested local media or DVR archive file opens successfully for reading.
