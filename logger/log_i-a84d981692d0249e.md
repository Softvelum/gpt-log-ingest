## Short description

Server cleanup completed.

## Trigger condition

Server execution has returned and listener, DVR and library cleanup has reached its end.

## Explanation

The message follows closure of server listeners, removal of the configured process-ID file and library cleanup. It can also follow an early return from the startup run sequence; it does not identify why execution ended.
