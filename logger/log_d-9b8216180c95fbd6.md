# RTP connection created

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-9b8216180c95fbd6

## Log pattern

```text
rtp open, s=%d
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
rtp open, s=25
```

## Short description

RTP connection created.

## Trigger condition

The RTP connection object is constructed.

## Explanation

The connection reports itself to its parent RTSP input and queues an initial twelve-byte RTP packet. This records creation, not proof that remote media has arrived.

## Possible causes

- Normal creation of a RTP connection.
