# VAAPI encoded output unmapping failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-cb644e6b4d0982e4

## Log pattern

```text
%p failed to unmap output buffer, 0x%x
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to unmap output buffer, 0x1
```

## Short description

VAAPI encoded output unmapping failed.

## Trigger condition

Unmapping the coded-output buffer after successful packet delivery returns a non-success status.

## Explanation

Frame writing returns failure even though the packet has already been delivered; the frame counter is not advanced.

## Possible causes

- The driver cannot complete access to the coded-output buffer.

## What to check

1. Check the VA status, preceding device errors, and whether the encoder context remains usable.

## Recommended action

Resolve the VA driver or device failure and restart the affected encoder.
