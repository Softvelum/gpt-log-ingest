# Invalid Whisper audio configuration

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-21d9151b5cd9381d

## Log pattern

```text
invalid audio config for [%s] lang=%s
```

## Parameters

- Argument 1 — Stream: Application and stream name.
- Argument 2 — Language: Configured language identifier for this transcription process; it may differ from the effective detected language.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid audio config for [live/news] lang=en
```

## Short description

Invalid Whisper audio configuration.

## Trigger condition

The audio codec is unknown, a time-base component is zero, or the model path is empty.

## Explanation

The configuration message returns failure and is not installed.

## Possible causes

- The audio codec is unknown, a time-base component is zero, or the model path is empty.

## What to check

1. Check codec identification, audio timescale, and the model path.

## Recommended action

Supply complete valid audio and model settings.
