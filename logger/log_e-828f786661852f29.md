# DVR video-only video payload send failed

Product: Nimble Streamer
Component: DVR export
Logging function: log_e
Log level: error
Documentation ID: log_e-828f786661852f29

## Log pattern

```text
failed to send video segment period=%d start_time=%lld offset=%d size=%d stream=%s utc_start=%lld utc_end=%lld
```

## Parameters

- Argument 1 — Recording period: Integer identifier of the continuous recording period.
- Argument 2 — Segment start: 64-bit segment start timestamp in that track's media timescale.
- Argument 3 — Media offset: Byte offset of selected samples within the mapped segment.
- Argument 4 — Media bytes: Number of media sample bytes selected for transmission.
- Argument 5 — Stream: Text naming the application and stream.
- Argument 6 — UTC start: 64-bit requested UTC start in seconds since the Unix epoch; zero leaves this bound unspecified.
- Argument 7 — UTC end: 64-bit requested UTC end in seconds since the Unix epoch; zero leaves this bound unspecified.

The byte offset and byte count are 64-bit values supplied to 32-bit integer conversions.

## Log examples

No sound example is given because both offset and size arguments mismatch their printf conversions.

## Short description

DVR video-only video payload send failed.

## Trigger condition

Sending selected video sample bytes returns failure.

## Explanation

The export socket is shut down.

## Possible causes

- Sending selected video sample bytes returns failure.
