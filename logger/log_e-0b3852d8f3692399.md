# Panel proxy address is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-0b3852d8f3692399

## Log pattern

```text
invalid parameter value: '%s'
```

## Parameters

- Argument 1 — Proxy: Original panel proxy text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: ':80'
```

## Short description

Panel proxy address is invalid.

## Trigger condition

Splitting the panel proxy setting fails because the string is empty or has no host before its port separator.

## Explanation

Configuration processing fails. The proxy parser otherwise uses port 80 when no usable port is supplied.

## Possible causes

- The proxy setting is empty or lacks a host.

## What to check

1. Check the proxy hostname and optional port.

## Recommended action

Provide a nonempty proxy host and optional port.
