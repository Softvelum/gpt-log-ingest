# External redirect has no location

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-61a1348fad850d1a

## Log pattern

```text
url='%s' request failed status=%hu (empty location)
```

## Parameters

- Argument 1 — URL: Original external request URL, retained even when following a redirect.
- Argument 2 — status: HTTP response status code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
url='https://media.example/movie.mp4' request failed status=302 (empty location)
```

## Short description

External redirect has no location.

## Trigger condition

The first supported redirect response has an empty location.

## Explanation

The old connection is closed and the requester receives a failure callback instead of following the redirect.

## Possible causes

- The first supported redirect response has an empty location.

## What to check

1. Inspect the origin redirect chain and location headers.

## Recommended action

Use a valid target reachable within one redirect.
