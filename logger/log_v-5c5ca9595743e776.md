# Remote fragment request queued

Product: Nimble Streamer
Component: Remote media cache requests
Logging function: log_v
Log level: verbose
Documentation ID: log_v-5c5ca9595743e776

## Log pattern

```text
enqueued request for item key='%s' fi=%u queue_size=%u
```

## Parameters

- Argument 1 — key: Cache key, also used as the remote request URL.
- Argument 2 — fragment: Zero-based fragment index.
- Argument 3 — queue size: Number of requests queued for this URL after insertion.

Both fragment index and queue size use platform-sized values with 32-bit unsigned conversions.

## Log examples

No portable example is provided for the argument-width mismatches.

## Short description

Remote fragment request queued.

## Trigger condition

A different request is already active for the item and the queue is below its limit.

## Explanation

The new fragment request is appended and will wait for the active request to finish.
