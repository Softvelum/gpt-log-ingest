# Playlist HTTP response received

Product: Nimble Streamer
Component: Server playlists
Logging function: log_d
Log level: debug
Documentation ID: log_d-7594366668821e0f

## Log pattern

```text
ServerPlaylistSyncThread::OnRequestProcessed url='%s' status=%d body_len=%d
```

## Parameters

- Argument 1 — Request URL: Text identifying the playlist or block request.
- Argument 2 — HTTP status: Integer HTTP response status.
- Argument 3 — Body bytes: Integer response body length in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerPlaylistSyncThread::OnRequestProcessed url='https://api.example/playlist' status=200 body_len=1024
```

## Short description

Playlist HTTP response received.

## Trigger condition

The HTTP request callback receives a response for playlist synchronization or block definitions.

## Explanation

Expected block bodies are retained; a main response wakes synchronization. Unrecognized URLs produce an additional error.

## Possible causes

- The HTTP request callback receives a response for playlist synchronization or block definitions.
