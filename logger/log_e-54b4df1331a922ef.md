# Cannot observe a VOD packaging dependency

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-54b4df1331a922ef

## Log pattern

```text
DataCache::AddObserver failed for cache_key='%s'
```

## Parameters

- Argument 1 — Dependency cache key: Text key of the source item or initialization segment whose updates were needed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DataCache::AddObserver failed for cache_key='/vod/movie.mp4'
```

## Short description

Cannot observe a VOD packaging dependency.

## Trigger condition

The worker records a postponed output request but cannot register for changes to its input or required initialization segment.

## Explanation

The helper reports failure and its caller cancels the output. The stored postponed-request entry is not removed by this failure branch.

## Possible causes

- The worker records a postponed output request but cannot register for changes to its input or required initialization segment.

## What to check

1. Check that the dependency item still exists and inspect nearby cache removal or observer-registration events.

## Recommended action

Check that the dependency item still exists and inspect nearby cache removal or observer-registration events.
