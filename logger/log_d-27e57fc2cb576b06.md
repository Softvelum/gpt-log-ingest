# Synchronization response status is unsuccessful

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-27e57fc2cb576b06

## Log pattern

```text
sync status is not success ("%s"), discarding rules
```

## Parameters

- Argument 1 — status: Panel-provided synchronization status string.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync status is not success ("error"), discarding rules
```

## Short description

Synchronization response status is unsuccessful.

## Trigger condition

An ordinary synchronization response status is neither success nor unknown.

## Explanation

Processing returns early and requests a full statistics report for the next interaction. The handler returns true to keep panel communication active; it does not signal a transport failure.
