# DVR time-bucket directory contains an unexpected file

Product: Nimble Streamer
Component: DVR archive storage
Logging function: log_v
Log level: verbose
Documentation ID: log_v-2c2d47dde974808a

## Log pattern

```text
skip deleting dvr archive dir='%s' because of unexpected file='%s'
```

## Parameters

- Argument 1 — Archive directory: Text giving the archive or time-bucket directory.
- Argument 2 — Unexpected entry: Text naming the unexpected directory entry.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip deleting dvr archive dir='/data/dvr/live/camera/1700000000000' because of unexpected file='notes.txt'
```

## Short description

DVR time-bucket directory contains an unexpected file.

## Trigger condition

Directory cleanup finds an entry other than the segment database.

## Explanation

The directory is preserved.

## Possible causes

- Directory cleanup finds an entry other than the segment database.

## What to check

1. Inspect the unexpected entry before deciding whether the time-bucket directory can be removed.

## Recommended action

Inspect the unexpected entry before deciding whether the time-bucket directory can be removed.
