# CPIX key count is incompatible

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-5ad29019ac2263c5

## Log pattern

```text
%s keys received=%llu expected=%llu
```

## Parameters

- Argument 1 — Provider: Text naming the DRM provider.
- Argument 2 — Received keys: Unsigned count of parsed keys.
- Argument 3 — Stored slots: Unsigned count of currently stored key slots.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Widevine keys received=2 expected=1
```

## Short description

CPIX key count is incompatible.

## Trigger condition

The provider response parses but either the received key count or the stored key-slot count is not exactly one.

## Explanation

No key is installed and waiting consumers are not notified by this branch.

## Possible causes

- The provider response parses but either the received key count or the stored key-slot count is not exactly one.

## What to check

1. Configure the provider to return one key and check that the stream has one matching key slot.

## Recommended action

Configure the provider to return one key and check that the stream has one matching key slot.
