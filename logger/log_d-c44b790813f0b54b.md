# Configured audio packet is unavailable

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-c44b790813f0b54b

## Log pattern

```text
updateAvailable failed to find audio_pid=%d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable failed to find audio_pid=256
```

## Short description

Configured audio packet is unavailable.

## Trigger condition

The matching input availability map does not contain the explicitly configured audio packet identifier.

## Explanation

Audio codec initialization, timestamps, AAC header state, and the audio frame buffer are reset. The selected identifier and type are cleared. Availability processing continues for other media.
