# RTMP HEVC parameter sets are rejected

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-75dd0c7a4094623c

## Log pattern

```text
[VM] set_video_codec_hevc
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

RTMP HEVC parameter sets are rejected.

## Trigger condition

Installing HEVC parameter sets extracted from a legacy sequence header fails.

## Explanation

The video handler fails and connection processing stops.

## Possible causes

- Installing HEVC parameter sets extracted from a legacy sequence header fails.

## What to check

1. Check the extracted HEVC parameter sets and accompanying codec errors.

## Recommended action

Correct the HEVC sequence header at the encoder.
