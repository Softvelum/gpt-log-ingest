# DVR export archive is not ready

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-4136546aa367c2a1

## Log pattern

```text
failed to get dvr segments for '%s' state=%d
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Archive state: Integer describing the current archive loading/readiness state.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get dvr segments for 'live/camera' state=1
```

## Short description

DVR export archive is not ready.

## Trigger condition

A registered archive is not in its ready state when download segments are requested.

## Explanation

Segment lookup fails.

## Possible causes

- A registered archive is not in its ready state when download segments are requested.

## What to check

1. Wait for archive loading to finish and inspect archive-load failures.

## Recommended action

Wait for archive loading to finish and inspect archive-load failures.
