# Internal resource request received

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-b812200a42a57703

## Log pattern

```text
WorkerThread::RequestExternalResource url='%s' requestor=%p
```

## Parameters

- Argument 1 — URL: Requested resource URL as text.
- Argument 2 — Request recipient: Address of the component waiting for the HTTP request result.

## Log examples

Illustrative examples; these are not captured server logs.

```text
WorkerThread::RequestExternalResource url='https://origin.example/media' requestor=0x2000
```

## Short description

Internal resource request received.

## Trigger condition

A component asks the worker to request an external resource.

## Explanation

The worker validates its request-processing setup, URL and result recipient before building and queuing an HTTP request.
