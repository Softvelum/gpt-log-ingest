# SLDP advertising state is invalid

Product: Nimble Streamer
Component: SLDP playback and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-0d486174416526c6

## Log pattern

```text
s=%d, video_sn=%d, audio_sn=%d unknown ad_state=%d
```

## Parameters

- Argument 1 — Socket: Connection descriptor reported by the playback transport.
- Argument 2 — Video number: Client-assigned video stream number for this playback selection, or its default value when no video is selected.
- Argument 3 — Audio number: Client-assigned audio stream number for this playback selection, or its default value when no audio is selected.
- Argument 4 — State: Numeric advertising-state value that matches no supported phase.

## Log examples

No reachable illustrative value is established: every declared advertising phase is handled and normal transitions use those phases.

## Short description

SLDP advertising state is invalid.

## Trigger condition

The playback selection reaches a state outside all defined advertising phases.

## Explanation

The sender fails and the playback connection is closed. Normal transitions assign only handled phases.

## Possible causes

- The playback selection reaches a state outside all defined advertising phases.

## What to check

1. Check preceding advertising transitions and callback events.

## Recommended action

Report the unexpected internal state to support.
