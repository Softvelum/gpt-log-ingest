# Audio source structure could not be processed

Product: Nimble Streamer
Component: VOD transmuxing
Logging function: log_e
Log level: error
Documentation ID: log_e-5e1e01d54eb73735

## Log pattern

```text
failed to load file structure for %s
```

## Parameters

- Argument 1 — Audio source: Text local audio path or remote source cache key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load file structure for /media/audio.mp3
```

## Short description

Audio source structure could not be processed.

## Trigger condition

An audio-loader exception escapes MP3 or AAC playlist or chunk generation.

## Explanation

The requested output cache item is canceled with a transmuxing-failure reason and released. Any local input mapping is also closed.

## Possible causes

- An audio-loader exception escapes MP3 or AAC playlist or chunk generation.

## What to check

1. Check MP3/AAC validity, complete source download, and audio-loader errors preceding this message.

## Recommended action

Check MP3/AAC validity, complete source download, and audio-loader errors preceding this message.
