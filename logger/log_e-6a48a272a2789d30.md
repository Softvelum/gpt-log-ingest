# VAAPI cannot write multiple coded picture buffers

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error

## Log pattern

```text
alternative CPB specifications not supported
```

## Log examples

Illustrative examples; these are not captured server logs.


## Short description

VAAPI cannot write multiple coded picture buffers.

## Trigger condition

The H.264 NAL buffering parameters specify more than one coded picture buffer.

## Explanation

The H.264 parameter-set writer returns failure and encoder initialization cannot complete.

## Possible causes

- The requested H.264 metadata is outside this native parameter-set writer support.

## What to check

1. Check the requested multiple coded picture buffers and chosen encoder backend.

## Recommended action

Use settings supported by this encoder or select another H.264 encoder.
