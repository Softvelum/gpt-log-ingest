# DRM key rotation interval is invalid

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-5b2925468cd53924

## Log pattern

```text
invalid key rotation interval value=%s (must be >= 30)
```

## Parameters

- Argument 1 — Interval text: Configured key rotation interval text in seconds.

Zero is accepted even though the original message only states the minimum nonzero interval.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid key rotation interval value=10 (must be >= 30)
```

## Short description

DRM key rotation interval is invalid.

## Trigger condition

The parsed rotation interval is nonzero and less than 30 seconds.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The parsed rotation interval is nonzero and less than 30 seconds.

## What to check

1. Use zero to disable rotation or at least 30 seconds.

## Recommended action

Use zero to disable rotation or at least 30 seconds.
