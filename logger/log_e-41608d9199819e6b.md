# VCAS rejected key retrieval

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-41608d9199819e6b

## Log pattern

```text
VCAS GetKey failed url='%s' code='%s' message='%s'
```

## Parameters

- Argument 1 — Key-server URL: Text giving the configured or requested key-server URL.
- Argument 2 — Provider status: Text containing the provider status code.
- Argument 3 — Provider message: Text explaining the provider status.

## Log examples

Illustrative examples; these are not captured server logs.

```text
VCAS GetKey failed url='https://keys.example/key' code='ERROR' message='asset unavailable'
```

## Short description

VCAS rejected key retrieval.

## Trigger condition

The parsed VCAS key retrieval response has a status other than OK.

## Explanation

The key is not updated from this response.

## Possible causes

- The parsed VCAS key retrieval response has a status other than OK.

## What to check

1. Correct the problem reported in the VCAS status and message.

## Recommended action

Correct the problem reported in the VCAS status and message.
