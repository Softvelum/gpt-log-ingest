# Recovered-statistics response has invalid JSON

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-f3e8b1394a3be775

## Log pattern

```text
error parsing json[recovered]='%s'
```

## Parameters

- Argument 1 — response\_body: The unparseable response body.

## Log examples

Illustrative examples; these are not captured server logs.

```text
error parsing json[recovered]='invalid'
```

## Short description

Recovered-statistics response has invalid JSON.

## Trigger condition

Parsing a nonempty recovered-statistics response produces no JSON value.

## Explanation

The handler deliberately returns permission to continue panel interaction. In the successful-transport caller, that return also allows pending recovered statistics to be reset; this message does not guarantee the panel accepted their contents.

## Possible causes

- The nonempty response cannot be parsed as JSON.

## What to check

1. Check the response content and panel endpoint.

## Recommended action

Correct the invalid panel response.
