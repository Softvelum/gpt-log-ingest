# Rules file save started

Product: Nimble Streamer
Component: Server configuration
Logging function: log_d
Log level: debug
Documentation ID: log_d-796fed6a71287d56

## Log pattern

```text
saving file: %s
```

## Parameters

- Argument 1 — File: Requested file path, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
saving file: /var/lib/nimble/example.xml
```

## Short description

Rules file save started.

## Trigger condition

The rules-file writing operation begins before opening the file.

## Explanation

The destination will be opened with truncation, then a managed-file notice and rules text will be written. This message does not confirm success.
