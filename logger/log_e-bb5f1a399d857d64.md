# Audio filter input could not be created

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-bb5f1a399d857d64

## Log pattern

```text
failed to create abuffer, filter=%s, stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create abuffer, filter=[in]anull[out], stream=live/camera
```

## Short description

Audio filter input could not be created.

## Trigger condition

Creating the audio-buffer source with the input rate, format, layout, and time base fails.

## Explanation

Input setup fails and the frame is not processed.

## Possible causes

- FFmpeg rejected the audio source configuration.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
