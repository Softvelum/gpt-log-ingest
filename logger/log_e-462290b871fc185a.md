# AJA reader connection message could not be queued

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-462290b871fc185a

## Log pattern

```text
failed to write connection message to AJA reader id=%llu name='%s' endpoint=%s:%d
```

## Parameters

- Argument 1 — Session ID: Positive unsigned 64-bit identifier for the reader or writer session.
- Argument 2 — Session name: Configured AJA device and channel name.
- Argument 3 — Endpoint address: IP address of the internal media-session connection.
- Argument 4 — Endpoint port: Decimal TCP port of the internal media-session connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to write connection message to AJA reader id=1 name='0/0' endpoint=127.0.0.1:9000
```

## Short description

AJA reader connection message could not be queued.

## Trigger condition

The worker cannot serialize or buffer its initial success-status message before connecting to the media-session endpoint.

## Explanation

The worker cleans up, marks itself finished, and returns without attempting the connection.

## Possible causes

- The worker cannot serialize or buffer its initial success-status message before connecting to the media-session endpoint.

## What to check

1. Check the internal status-message buffering and session endpoint information.
