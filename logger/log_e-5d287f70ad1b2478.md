# Downloader sent count exceeds request length

Product: Nimble Streamer
Component: Background origin download
Logging function: log_e
Log level: error
Documentation ID: log_e-5d287f70ad1b2478

## Log pattern

```text
DownloaderSession::OnSockOut origin s=%d assertion failed (%d < %d)
```

## Parameters

- Argument 1 — socket: Origin socket descriptor.
- Argument 2 — request bytes: Prepared request length.
- Argument 3 — sent bytes: Accumulated sent count.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DownloaderSession::OnSockOut origin s=12 assertion failed (100 < 101)
```

## Short description

Downloader sent count exceeds request length.

## Trigger condition

The accumulated origin request bytes sent exceed the request buffer length.

## Explanation

The session is marked finished and will not continue sending the request.

## Possible causes

- Request transmission accounting exceeded the prepared buffer size.

## What to check

1. Compare preceding write-progress messages.

## Recommended action

Investigate inconsistent request byte accounting.
