# Rotating DRM leaves fixed initialization key fields empty

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-67fb4a736d9424fa

## Log pattern

```text
[drm] GetCencInitParams returned empty key/key_id/pssh for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] GetCencInitParams returned empty key/key_id/pssh for 'live/camera'
```

## Short description

Rotating DRM leaves fixed initialization key fields empty.

## Trigger condition

Common-encryption initialization succeeds with key rotation enabled.

## Explanation

Fixed key identifier and protection-header fields are left empty for per-period signaling.

## Possible causes

- Common-encryption initialization succeeds with key rotation enabled.
