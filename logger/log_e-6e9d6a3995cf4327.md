# DRMToday ticket response is empty

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-6e9d6a3995cf4327

## Log pattern

```text
[drm] DRMToday response processing get cas ticket failed for: '%s' %s
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — HTTP response details: Text containing the HTTP status and optional response body; empty when no response parser exists.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] DRMToday response processing get cas ticket failed for: 'live/camera' status=503 body='unavailable'
```

## Short description

DRMToday ticket response is empty.

## Trigger condition

The CAS-ticket response contains an empty body.

## Explanation

The requested keys are marked failed and waiting consumers are notified.

## Possible causes

- The CAS-ticket response contains an empty body.

## What to check

1. Check the ticket endpoint response and the preceding login result.

## Recommended action

Check the ticket endpoint response and the preceding login result.
