# VCAS HLS AES protection selected

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-a649445aee6f04e1

## Log pattern

```text
[drm] app='%s' stream='%s' is protected with VCAS (HLS AES)
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] app='live' stream='camera' is protected with VCAS (HLS AES)
```

## Short description

VCAS HLS AES protection selected.

## Trigger condition

The application uses VCAS HLS AES and stream registration includes HLS, MPEG-TS HLS, or fragmented-MP4 HLS.

## Explanation

Key registration continues; this message alone does not confirm that usable keys have arrived.

## Possible causes

- The application uses VCAS HLS AES and stream registration includes HLS, MPEG-TS HLS, or fragmented-MP4 HLS.
