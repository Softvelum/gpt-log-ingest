# Windows service status update failed

Product: Nimble Streamer
Component: Windows service
Logging function: log_e
Log level: error
Documentation ID: log_e-3944d92173d2044a

## Log pattern

```text
can't set service status=%d error=%d
```

## Parameters

- Argument 1 — Requested status: Numeric Windows service state being reported.
- Argument 2 — System error: Numeric Windows error from the failed status update.

## Log examples

Illustrative examples; these are not captured server logs.

```text
can't set service status=4 error=6
```

## Short description

Windows service status update failed.

## Trigger condition

A Windows service status change is submitted and the operating system rejects it.

## Explanation

The requested status is stored locally, but publishing that status fails. The helper then returns to the startup, stop-request, or shutdown sequence without an additional recovery step.

## Possible causes

- The service status update was rejected by the operating system.

## What to check

1. Compare the requested service state with the associated system error.
