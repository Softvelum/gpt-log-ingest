# Playlist block file could not be loaded

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-2ed0a4a09177d704

## Log pattern

```text
failed to load BlocksLocation file='%s'
```

## Parameters

- Argument 1 — Block file: Text naming the block-definition file.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load BlocksLocation file='/data/blocks.json'
```

## Short description

Playlist block file could not be loaded.

## Trigger condition

A task references a local block-definition location that cannot be read.

## Explanation

No blocks are added from that file; processing of the task response continues.

## Possible causes

- A task references a local block-definition location that cannot be read.

## What to check

1. Check that the referenced block-definition file exists and is readable.

## Recommended action

Check that the referenced block-definition file exists and is readable.
