# Scenario transcoder connection is ready

Product: Nimble Streamer
Component: Scenario transcoder processes
Logging function: log_i
Log level: info
Documentation ID: log_i-596f2077a8da104d

## Log pattern

```text
remote transcoder connected sock=%d scenario=%s
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Scenario: Transcoding scenario identifier, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
remote transcoder connected sock=12 scenario=scenario1
```

## Short description

Scenario transcoder connection is ready.

## Trigger condition

The known scenario controller successfully processes initial buffered input and enables its socket events.

## Explanation

The socket moves from the pending connection set into active scenario connections.
