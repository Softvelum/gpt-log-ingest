# SRT bonding member state changed

Product: Nimble Streamer
Component: SRT connections and session reporting
Logging function: log_d
Log level: debug
Documentation ID: log_d-b50698962973f335

## Log pattern

```text
srt group=%d sock=%d state=%s=>%s
```

## Parameters

- Argument 1 — Group: SRT group socket identifier.
- Argument 2 — Member: Current SRT member socket identifier.
- Argument 3 — Previous: Previously recorded socket-state name.
- Argument 4 — Current: Returned socket-state name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
srt group=1073741924 sock=101 state=connected=>broken
```

## Short description

SRT bonding member state changed.

## Trigger condition

After a grouped send, a returned member state differs from the previous stored state at that member position.

## Explanation

The old and current socket states are logged; this message alone does not stop the group.

## Possible causes

- After a grouped send, a returned member state differs from the previous stored state at that member position.

## What to check

1. Check whether a path moved from connected to broken and whether recovery follows.
