# External request URL cannot be split

Product: Nimble Streamer
Component: External HTTP requests
Logging function: log_e
Log level: error
Documentation ID: log_e-438a2a18535a9559

## Log pattern

```text
SplitUrl failed to split url='%s'
```

## Parameters

- Argument 1 — URL: Current peer URL being parsed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SplitUrl failed to split url='http://'
```

## Short description

External request URL cannot be split.

## Trigger condition

Initial or redirected URL parsing fails to extract protocol, host, and path.

## Explanation

A fatal request exception is thrown and startup cleanup reports the request as failed.

## Possible causes

- The supplied URL cannot be split into its required parts.

## What to check

1. Check the requested URL or redirect location.

## Recommended action

Correct the URL.
