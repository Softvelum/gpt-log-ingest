# Reported available cache fragment cannot be obtained

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-a289b26cc48eb826

## Log pattern

```text
failed to get available key='%s' fragment=%u
```

## Parameters

- Argument 1 — Cache key: Text identifying the requested media or playlist cache item.
- Argument 2 — Fragment index: Unsigned zero-based index of the requested cache fragment.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get available key='/live/camera/segment1.ts' fragment=1
```

## Short description

Reported available cache fragment cannot be obtained.

## Trigger condition

The remote VOD manager reports a fragment already available, but retrieving its fragment data returns no buffer.

## Explanation

HTTP/1 shuts down the client socket. HTTP/2 or HTTP/3 fails body preparation and attempts an internal-error stream reset.

## Possible causes

- The remote VOD manager reports a fragment already available, but retrieving its fragment data returns no buffer.

## What to check

1. Inspect fragment download, eviction, and cache update messages for this key and index; availability and buffer retrieval disagree.

## Recommended action

Inspect fragment download, eviction, and cache update messages for this key and index; availability and buffer retrieval disagree.
