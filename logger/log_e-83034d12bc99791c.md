# Configuration loading stopped at an invalid line

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-83034d12bc99791c

## Log pattern

```text
failed to load config file. invalid line %d: '%s'
```

## Parameters

- Argument 1 — Line number: One-based configuration file line number, integer.
- Argument 2 — Line: Complete rejected line text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load config file. invalid line 12: 'worker_threads=0'
```

## Short description

Configuration loading stopped at an invalid line.

## Trigger condition

A nonempty, noncomment configuration line cannot be parsed or its parameter processing returns failure.

## Explanation

Loading stops immediately and returns failure; preceding lines may already have changed configuration values.

## Possible causes

- The line has invalid syntax, an unsupported parameter, or an invalid value.

## What to check

1. Check the reported line and the preceding specific validation message.

## Recommended action

Correct the rejected line and reload the complete configuration.
