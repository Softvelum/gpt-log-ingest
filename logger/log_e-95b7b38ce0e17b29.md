# Prepackaged VOD file could not be loaded

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-95b7b38ce0e17b29

## Log pattern

```text
failed to load pre-transmuxed file='%s'
```

## Parameters

- Argument 1 — Media filename: Text filesystem path of the prepackaged file being loaded.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to load pre-transmuxed file='/media/movie/playlist.m3u8'
```

## Short description

Prepackaged VOD file could not be loaded.

## Trigger condition

Reading a local prepackaged DASH or HLS file into memory fails.

## Explanation

HTTP 500 is prepared instead of a playlist or packaged media response.

## Possible causes

- Reading a local prepackaged DASH or HLS file into memory fails.

## What to check

1. Verify that the requested packaged file exists and is readable, and inspect adjacent file I/O errors.

## Recommended action

Verify that the requested packaged file exists and is readable, and inspect adjacent file I/O errors.
