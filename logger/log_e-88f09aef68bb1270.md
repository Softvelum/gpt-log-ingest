## Short description

Could not create the constant-rate UDP output worker.

## Trigger condition

The constant-rate UDP worker is being created in a build that includes the non-Windows sender branch. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the constant-rate UDP output worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed constant-rate UDP output worker.
