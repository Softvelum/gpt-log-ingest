# DRMToday CPIX configuration identifier is missing

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-bffe774204430875

## Log pattern

```text
CPIX Id configuration must be provided for DRMToday (drmtoday_cpix_config_id)
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
CPIX Id configuration must be provided for DRMToday (drmtoday_cpix_config_id)
```

## Short description

DRMToday CPIX configuration identifier is missing.

## Trigger condition

The DRMToday CPIX configuration identifier is empty.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The DRMToday CPIX configuration identifier is empty.

## What to check

1. Provide the DRMToday CPIX configuration identifier.

## Recommended action

Provide the DRMToday CPIX configuration identifier.
