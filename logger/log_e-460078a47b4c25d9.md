# Invalid Icecast metadata request URL

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-460078a47b4c25d9

## Log pattern

```text
invalid icecast metadata url=%s, client=%d
```

## Parameters

- Argument 1 — URL: Received metadata update URL.
- Argument 2 — Socket: Numeric connection socket descriptor.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid icecast metadata url=/metadata?mount=live/radio, client=42
```

## Short description

Invalid Icecast metadata request URL.

## Trigger condition

A metadata-update GET URL does not begin with /admin/metadata?.

## Explanation

The connection is shut down before metadata processing.

## Possible causes

- A metadata-update GET URL does not begin with /admin/metadata?.

## What to check

1. Check the metadata-update endpoint.

## Recommended action

Use the expected metadata-update URL.
