# Cannot size Windows mapping file

Product: Nimble Streamer
Component: Media file access
Logging function: log_e
Log level: error
Documentation ID: log_e-c654a202505411f0

## Log pattern

```text
SetEndOfFile failed error=%d
```

## Parameters

- Argument 1 — Error: Windows error code, printed in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
SetEndOfFile failed error=112
```

## Short description

Cannot size Windows mapping file.

## Trigger condition

Moving the file pointer to the desired length or setting the file end fails while preparing a new writable mapping.

## Explanation

The file handle is closed and mapping stops. Despite the wording, the message can report either positioning or end-of-file failure.

## Possible causes

- Moving the file pointer to the desired length or setting the file end fails while preparing a new writable mapping.

## What to check

1. Check the Windows error and requested output file size.
