## Short description

AAC high bit rate live-stream setup failed.

## Trigger condition

The live-stream AAC configuration operation rejects the decoded SDP configuration.

## Explanation

AAC initialization returns failure. The downstream operation rejects an ended stream, fewer than two configuration bytes, or an explicit sample-frequency index of fifteen.

## Possible causes

- The live-stream AAC configuration operation rejects the decoded SDP configuration.

## What to check

1. Check the decoded AAC configuration and accompanying live-stream AAC errors.
