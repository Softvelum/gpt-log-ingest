# Advertising content observer removed

Product: Nimble Streamer
Component: HTTP media delivery
Logging function: log_d
Log level: debug
Documentation ID: log_d-0195bf45e840018b

## Log pattern

```text
[SndT::RemO] key='%s' p=%p
```

## Parameters

- Argument 1 — Content: Advertising content identifier.
- Argument 2 — Observer: Address identifying the consumer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[SndT::RemO] key='example-ad' p=0x12345000
```

## Short description

Advertising content observer removed.

## Trigger condition

An observer is removed from an existing advertising-content observer set.

## Explanation

The content ID and observer address identify the removal attempt. If the set becomes empty, the thread also unregisters its upstream observer.

## Possible causes

- An observer is removed from an existing advertising-content observer set.

## What to check

1. Check whether the corresponding advertising consumer ended.
