# Audio encoder input resubmission failed

Product: Nimble Streamer
Component: FFmpeg audio encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-c1f85c20843dca26

## Log pattern

```text
failed to send again audio frame to encoder: %s
```

## Parameters

- Argument 1 — Error text: Diagnostic description supplied by the operating system or library, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send again audio frame to encoder: operation failed
```

## Short description

Audio encoder input resubmission failed.

## Trigger condition

After draining packets, resubmitting the audio frame still returns a nonzero result.

## Explanation

Encoding reports failure; the failed packet is not sent to the output writer.

## Possible causes

- FFmpeg reported the included encoding error.

## What to check

1. Check the error text and the input audio settings.

## Recommended action

Resolve the specific FFmpeg encoding failure.
