# SRT publisher authentication token missing

Product: Nimble Streamer
Component: SRT publishing authentication
Logging function: log_e
Log level: error
Documentation ID: log_e-4df754f379009704

## Log pattern

```text
[srt_listen_callback] invalid streamid=[%s] either 'publishsign' or 'srtauth' must be specified ip=[%s]
```

## Parameters

- Argument 1 — Stream ID: Requested SRT stream identifier.
- Argument 2 — Peer: Publisher IP address.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[srt_listen_callback] invalid streamid=[live/news] either 'publishsign' or 'srtauth' must be specified ip=[192.0.2.20]
```

## Short description

SRT publisher authentication token missing.

## Trigger condition

Neither a publishing signature nor an SRT authentication identifier is supplied and the application is not in signature-free mode.

## Explanation

The listener rejects the publisher before loading per-user SRT settings.

## Possible causes

- Neither a publishing signature nor an SRT authentication identifier is supplied and the application is not in signature-free mode.

## What to check

1. Check the publisher stream-ID authentication parameters.

## Recommended action

Supply the authentication parameter required by the application.
