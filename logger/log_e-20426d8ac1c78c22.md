# DVR recording archive could not be created

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-20426d8ac1c78c22

## Log pattern

```text
failed to create dvr archive for stream='%s/%s'
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create dvr archive for stream='live/camera'
```

## Short description

DVR recording archive could not be created.

## Trigger condition

A recording context needs an archive but archive creation returns no archive because matching settings are unavailable.

## Explanation

Recording context creation is skipped for this stream during this synchronization.

## Possible causes

- A recording context needs an archive but archive creation returns no archive because matching settings are unavailable.

## What to check

1. Check that stream-specific or application DVR settings still exist.

## Recommended action

Check that stream-specific or application DVR settings still exist.
