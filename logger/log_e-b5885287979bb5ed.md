# RTMP metadata artist name cannot be decoded

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-b5885287979bb5ed

## Log pattern

```text
cannot process AMF. get artist(%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
cannot process AMF. get artist(live/camera)
```

## Short description

RTMP metadata artist name cannot be decoded.

## Trigger condition

The artist metadata field cannot be read as an AMF string.

## Explanation

Further field decoding stops. The original metadata has already been stored; the handler still attempts to build audio metadata and apply the values decoded so far. This log alone does not shut down the connection.

## Possible causes

- The artist metadata field cannot be read as an AMF string.

## What to check

1. Check the artist field type, its length, and whether the metadata message is complete.

## Recommended action

Correct the artist metadata encoding at the source.
