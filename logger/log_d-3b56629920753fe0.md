# Origin playlist returned an unsuccessful status

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-3b56629920753fe0

## Log pattern

```text
origin RESP code %hu, closing the client s=%d
```

## Parameters

- Argument 1 — HTTP status: Unsigned short origin HTTP status code.
- Argument 2 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
origin RESP code 404, closing the client s=18
```

## Short description

Origin playlist returned an unsuccessful status.

## Trigger condition

A nonempty origin response enters playlist handling with a status other than 200 or 206.

## Explanation

Any reserved playlist cache item is canceled; status 412 is passed to the client, while other statuses use the default shutdown response.

## Possible causes

- A nonempty origin response enters playlist handling with a status other than 200 or 206.

## What to check

1. Check the origin URL and returned HTTP status, including access restrictions or a missing playlist.

## Recommended action

Check the origin URL and returned HTTP status, including access restrictions or a missing playlist.
