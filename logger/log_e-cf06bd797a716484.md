# Downloader output arrived in an unexpected state

Product: Nimble Streamer
Component: Background origin download
Logging function: log_e
Log level: error
Documentation ID: log_e-cf06bd797a716484

## Log pattern

```text
DownloaderSession(%p) unexpected kEventOut for s=%d (state=%d)
```

## Parameters

- Argument 1 — address: Downloader session memory address.
- Argument 2 — socket: Origin socket descriptor.
- Argument 3 — state: Numeric downloader session state.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DownloaderSession(0x1000) unexpected kEventOut for s=12 (state=5)
```

## Short description

Downloader output arrived in an unexpected state.

## Trigger condition

The logical output handler runs outside its accepted connection, request, or response-header states.

## Explanation

The session is marked finished; later destruction closes its socket and finalizes or cancels the cache item.

## Possible causes

- The event direction does not fit the current downloader state.

## What to check

1. Compare preceding state, request, and socket event messages.

## Recommended action

Investigate unexpected downloader event ordering.
