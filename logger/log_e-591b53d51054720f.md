## Short description

SRT output bonding unavailable.

## Trigger condition

Bonded output is configured but required bonding entry points are unavailable.

## Explanation

Group connection setup fails.

## Possible causes

- Bonded output is configured but required bonding entry points are unavailable.

## What to check

1. Check the loaded library for bonding support.

## Recommended action

Install an SRT library with group support to use this output mode.
