# HLS AES key length is not sixteen bytes

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_e
Log level: error
Documentation ID: log_e-193ad2f558094f79

## Log pattern

```text
invalid encryption key length=%d, uri=%s, hls camera s=%d
```

## Parameters

- Argument 1 — key\_bytes: Downloaded key length in bytes, supplied as an unsigned 32-bit value.
- Argument 2 — key\_uri: Current key request URL.
- Argument 3 — socket: Origin connection socket descriptor.

The unsigned 32-bit byte count is supplied to signed %d. Values within the signed range can be represented, but this is not a fully matching conversion.

## Log examples

No portable full example is supplied because of the signed conversion used for the unsigned length.

## Short description

HLS AES key length is not sixteen bytes.

## Trigger condition

A downloaded encryption key has a body size other than 16 bytes.

## Explanation

The key is not inserted in the local cache. The caller requests shutdown and returns, for both chunked and fixed-length responses.

## Possible causes

- The key endpoint did not return exactly 16 bytes.

## What to check

1. Check the key response body length and whether an error page was returned.

## Recommended action

Return the expected 16-byte AES key from the key endpoint.
