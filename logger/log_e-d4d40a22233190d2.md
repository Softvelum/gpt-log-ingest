# Audio transcription processing failed

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-d4d40a22233190d2

## Log pattern

```text
failed to transcribe audio stream='%s'
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to transcribe audio stream='live/news'
```

## Short description

Audio transcription processing failed.

## Trigger condition

The active stream cannot decode or buffer the received audio for transcription.

## Explanation

Processing of the current incoming audio message fails. The log does not identify which decoder or buffering step failed.

## Possible causes

- The active stream cannot decode or buffer the received audio for transcription.

## What to check

1. Check the audio format and nearby buffer or decoder diagnostics.
