# Quick Sync decoder hardware display unavailable

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-60f1adf8a37a8851

## Log pattern

```text
%p no hw found
```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 no hw found
```

## Short description

Quick Sync decoder hardware display unavailable.

## Trigger condition

On Linux, a hardware decoder implementation was selected but opening and initializing a VA display fails.

## Explanation

Decoder session setup returns failure.

## Possible causes

- No suitable accessible render device or usable VA display could be initialized.

## What to check

1. Check preceding VA device diagnostics, render-device access, and the installed video driver.

## Recommended action

Restore device access or a compatible driver, then restart decoding.
