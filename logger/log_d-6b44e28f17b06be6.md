# Session timer registered

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-6b44e28f17b06be6

## Log pattern

```text
added timer id=%d, current_time=%d, timeout=%d
```

## Parameters

- Argument 1 — Timer identifier: Signed 64-bit identifier.
- Argument 2 — Current time: Wall-clock time in seconds since the system epoch, stored in the platform time type.
- Argument 3 — Timeout: Signed duration in seconds.

The timer identifier is 64-bit and the wall-clock value may be wider than int, while both conversions expect int.

## Log examples

A reliable example is omitted because the timer identifier and time conversions can have incompatible argument widths.

## Short description

Session timer registered.

## Trigger condition

A new session timer identifier and its expiration time have been stored.

## Explanation

Expiration is scheduled at the current wall-clock time plus the requested number of seconds. The saved timer is later removed when delivered or cancelled.
