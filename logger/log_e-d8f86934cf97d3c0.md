# Preserved captions could not be attached to video

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-d8f86934cf97d3c0

## Log pattern

```text
av_frame_new_side_data failed filter='%s', stream=%s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.
- Argument 2 — Stream: Input stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
av_frame_new_side_data failed filter='[in]null[out]', stream=live/camera
```

## Short description

Preserved captions could not be attached to video.

## Trigger condition

Allocating output caption side data fails while preserved captions are pending.

## Explanation

The caption buffer is reset and the video frame continues without those preserved captions.

## Possible causes

- The output side-data allocation failed.

## What to check

1. Check caption preservation settings, accumulated caption size, and allocation diagnostics.

## Recommended action

Resolve the caption storage failure if caption preservation is required.
