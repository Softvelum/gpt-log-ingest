# AJA playback could not start after preroll

Product: Nimble Streamer
Component: AJA capture and playback
Logging function: log_e
Log level: error
Documentation ID: log_e-879dd447689d7272

## Log pattern

```text
playback failed device=%s/%d reason='AutoCirculate start failed'
```

## Parameters

- Argument 1 — Device: Configured AJA device selector or display name, as indicated by the message.
- Argument 2 — Channel: Numeric AJA channel identifier used by the device API; it is not converted to a one-based display number.

## Log examples

Illustrative examples; these are not captured server logs.

```text
playback failed device=0/0 reason='AutoCirculate start failed'
```

## Short description

AJA playback could not start after preroll.

## Trigger condition

Enough initial frames have transferred to meet the preroll target, but starting output circulation returns failure.

## Explanation

Transfer processing returns failure; the playback-started flag is not set. The target is between one and three frames according to device capacity.

## Possible causes

- Enough initial frames have transferred to meet the preroll target, but starting output circulation returns failure.

## What to check

1. Check device circulation startup after the initial frame transfers.
