# Quick Sync decoder synchronization failed

Product: Nimble Streamer
Component: Intel Quick Sync
Logging function: log_e
Log level: error
Documentation ID: log_e-2331b573c3d0497a

## Log pattern

```text
%p failed to sync decoder %d

```

## Parameters

- Argument 1 — Session: Quick Sync session handle, pointer printed in hexadecimal.
- Argument 2 — Status: Signed integer status returned by the Intel media runtime; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to sync decoder -3

```

## Short description

Quick Sync decoder synchronization failed.

## Trigger condition

Waiting for decoded output returns a nonzero status other than the in-progress status that is retried.

## Explanation

The operation fails before decoded pixels are copied to an output frame.

## Possible causes

- The asynchronous decode operation cannot complete successfully.

## What to check

1. Check the status and device health; each synchronization call waits up to 1000 milliseconds and in-progress results are retried.

## Recommended action

Resolve the media runtime or device fault and restart the decoder.
