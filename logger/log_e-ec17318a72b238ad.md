# VAAPI picture end failed

Product: Nimble Streamer
Component: VAAPI video encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-ec17318a72b238ad

## Log pattern

```text
%p failed to end picture, 0x%x %s
```

## Parameters

- Argument 1 — Encoder: Encoder instance address, pointer printed in hexadecimal.
- Argument 2 — VA status: VAAPI status code, integer printed in hexadecimal; no unit.
- Argument 3 — Status description: VA driver text describing the status.

## Log examples

Illustrative examples; these are not captured server logs.

```text
0x12340000 failed to end picture, 0x1 operation failed
```

## Short description

VAAPI picture end failed.

## Trigger condition

The VA driver returns a non-success status while finishing picture submission.

## Explanation

Frame encoding fails before surface synchronization and packet delivery.

## Possible causes

- The VA driver rejects the current picture operation or its encoding parameters.

## What to check

1. Check the status description, active codec parameters, and preceding device errors.

## Recommended action

Correct unsupported encoding parameters or restore the device and restart encoding.
