# Could not create the live input pull worker

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error

## Short description

Could not create the live input pull worker.

## Trigger condition

One of the configured live input pull workers is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the live input pull worker failed.

## What to check

1. Inspect the preceding thread resource error for the failed live input pull worker.
