# Video filter output support is unavailable

Product: Nimble Streamer
Component: Audio and video filtering
Logging function: log_e
Log level: error
Documentation ID: log_e-a254c4429b22b629

## Log pattern

```text
failed to get buffersink definition, filter graph: %s
```

## Parameters

- Argument 1 — Filter: Complete configured video filter expression, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to get buffersink definition, filter graph: [in]null[out]
```

## Short description

Video filter output support is unavailable.

## Trigger condition

FFmpeg cannot find the video-buffer sink filter.

## Explanation

Video filter initialization fails.

## Possible causes

- The loaded library lacks the required video sink filter.

## What to check

1. Check the affected filter expression, its input/output labels, and accompanying FFmpeg diagnostics.

## Recommended action

Correct the reported filter setup or frame-processing failure.
