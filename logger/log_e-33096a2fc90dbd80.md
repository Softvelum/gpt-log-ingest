# Cached file open failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-33096a2fc90dbd80

## Log pattern

```text
DataCache::RequestItem key='%s' failed to open '%s' errno=%d
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — file: Filesystem path of the cache data or metadata file being handled.
- Argument 3 — error: Operating system error number reported for the failed operation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DataCache::RequestItem key='movie' failed to open '/var/cache/nimble/movie' errno=2
```

## Short description

Cached file open failed.

## Trigger condition

Opening an existing non-Windows cache file for reading and writing fails.

## Explanation

The new reference is released and the recorded item is removed; the lookup returns a miss.

## Possible causes

- The file is missing or the operating system denies access.

## What to check

1. Check the reported error and cache-file availability.

## Recommended action

Restore cache directory access; the removed item must be cached again.
