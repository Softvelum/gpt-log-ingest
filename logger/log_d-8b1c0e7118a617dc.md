# Empty DRM key slot created for configured content

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-8b1c0e7118a617dc

## Log pattern

```text
[drm] created empty key for '%s' with content_id '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Content identifier: Text identifying the configured DRM asset.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] created empty key for 'live/camera' with content_id 'asset-01'
```

## Short description

Empty DRM key slot created for configured content.

## Trigger condition

A supported CPIX-based stream has no keys and a content identifier is provided in its settings.

## Explanation

A single placeholder key is created before requesting the provider key.

## Possible causes

- A supported CPIX-based stream has no keys and a content identifier is provided in its settings.
