# Fragmented LATM RTP audio is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-5cd72647a42a79c9

## Log pattern

```text
mp4a-latm: fragmented latm is unsupported
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
mp4a-latm: fragmented latm is unsupported
```

## Short description

Fragmented LATM RTP audio is unsupported.

## Trigger condition

A LATM RTP packet arrives without its marker flag set.

## Explanation

The LATM input reports a stream failure before processing the audio-multiplex element.

## Possible causes

- A LATM RTP packet arrives without its marker flag set.

## What to check

1. Check whether the source fragments LATM audio across RTP packets.

## Recommended action

Send complete LATM audio elements using the supported packetization.
