# Invalid transcription audio configuration ignored

Product: Nimble Streamer
Component: Live speech transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-978ade7053e21a15

## Log pattern

```text
invalid audio config for [%s]
```

## Parameters

- Argument 1 — Stream: Configured stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid audio config for [live/news]
```

## Short description

Invalid transcription audio configuration ignored.

## Trigger condition

An audio configuration lacks a stream name, service URL, API key, valid codec, or nonzero time-base components.

## Explanation

The configuration message is ignored without replacing the stored stream configuration.

## Possible causes

- An audio configuration lacks a stream name, service URL, API key, valid codec, or nonzero time-base components.

## What to check

1. Check the stream identity, service URL and key, codec, and audio timescale.

## Recommended action

Supply a complete valid audio configuration.
