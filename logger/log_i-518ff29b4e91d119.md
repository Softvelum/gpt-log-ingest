# Shared hardware-device cache reference released

Product: Nimble Streamer
Component: Shared hardware devices
Logging function: log_i
Log level: info
Documentation ID: log_i-518ff29b4e91d119

## Log pattern

```text
released shared hw device ctx=%p type=%d dev=%s
```

## Parameters

- Argument 1 — Context: FFmpeg hardware device reference address, pointer printed in hexadecimal.
- Argument 2 — Device type: FFmpeg hardware-device type identifier, integer; no unit.
- Argument 3 — Device: Hardware device name or device node, text; VAAPI with no explicit name first attempts Intel render-device discovery.

## Log examples

Illustrative examples; these are not captured server logs.

```text
released shared hw device ctx=0x12340000 type=3 dev=/dev/dri/renderD128
```

## Short description

Shared hardware-device cache reference released.

## Trigger condition

Global hardware-context release visits this cached device.

## Explanation

The cached reference is released and its map entry removed; remaining caller references can keep the device alive.
