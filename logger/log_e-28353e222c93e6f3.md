# SDI audio frame submission failed

Product: Nimble Streamer
Component: SDI device output
Logging function: log_e
Log level: error
Documentation ID: log_e-28353e222c93e6f3

## Log pattern

```text
failed to send audio frame to converter for [%s]
```

## Parameters

- Argument 1 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to send audio frame to converter for [live/camera]
```

## Short description

SDI audio frame submission failed.

## Trigger condition

Sending a audio frame to the output encoder returns a negative result.

## Explanation

The current output frame operation returns failure.

## Possible causes

- The output encoder cannot accept the audio frame.

## What to check

1. Check the source audio frame format and preceding FFmpeg diagnostics.

## Recommended action

Correct the source media or restart the output.
