# Playlist subtitle packet was rejected

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-91294ee1947c42e6

## Log pattern

```text
ServerBlockProcessor: processWebVTTSubtitle failed for vod file [%s],stream=[%s/%s]
```

## Parameters

- Argument 1 — Source media: Text identifying the source media file or URI.
- Argument 2 — Application: Text naming the application.
- Argument 3 — Stream: Text naming the stream.

## Log examples

Illustrative examples; these are not captured server logs.

```text
ServerBlockProcessor: processWebVTTSubtitle failed for vod file [/media/program.mp4],stream=[live/camera]
```

## Short description

Playlist subtitle packet was rejected.

## Trigger condition

Submitting a configured WebVTT subtitle packet to the output stream fails.

## Explanation

The block processor becomes failed and returns immediately; the playlist worker subsequently stops.

## Possible causes

- Submitting a configured WebVTT subtitle packet to the output stream fails.

## What to check

1. Check the subtitle text, language settings, timing, and preceding subtitle errors.

## Recommended action

Check the subtitle text, language settings, timing, and preceding subtitle errors.
