# RTSP media socket created

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_d
Log level: debug
Documentation ID: log_d-d577b310ee69a925

## Log pattern

```text
socket s=%d created
```

## Parameters

- Argument 1 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
socket s=26 created
```

## Short description

RTSP media socket created.

## Trigger condition

The operating system successfully creates an IPv4 socket for RTSP media setup.

## Explanation

Nonblocking mode and local binding are attempted afterward, so this message does not establish that the socket is bound or connected.

## Possible causes

- Normal creation of a UDP media or control socket.
