# Origin input paused for a full circular buffer

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d


## Parameters

- Argument 1 — Origin socket: Integer identifying the local origin socket.

## Short description

Origin input paused for a full circular buffer.

## Trigger condition

The circular pass-through buffer has no free contiguous space for another read.

## Explanation

Origin input monitoring is disabled until client output makes space; this is flow control rather than an allocation failure.

## Possible causes

- The circular pass-through buffer has no free contiguous space for another read.
