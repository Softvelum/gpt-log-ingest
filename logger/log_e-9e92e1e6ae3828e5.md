# Stream-check redirect limit reached

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-9e92e1e6ae3828e5

## Log pattern

```text
max steps reached for %s task.last location=%s
```

## Parameters

- Argument 1 — task: Panel-supplied stream-check task identifier.
- Argument 2 — location: Redirect location that would have been followed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
max steps reached for check-a task.last location=https://media.example/next
```

## Short description

Stream-check redirect limit reached.

## Trigger condition

An HTTP or RTSP redirect arrives after at least five prior follow-up steps.

## Explanation

The task shuts down without following the latest redirect.

## Possible causes

- The check followed too many redirects or playlist transitions.

## What to check

1. Inspect the redirect chain and final location.

## Recommended action

Use a URL that reaches the stream within the allowed number of steps.
