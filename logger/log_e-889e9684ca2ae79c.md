# FLAC frame rejected by live stream

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-889e9684ca2ae79c

## Log pattern

```text
icecast stream failed to process FLAC audio message %s
```

## Parameters

- Argument 1 — URL: Configured source URL; it can be empty for an incoming publisher.

## Log examples

Illustrative examples; these are not captured server logs.

```text
icecast stream failed to process FLAC audio message http://radio.example.net/live
```

## Short description

FLAC frame rejected by live stream.

## Trigger condition

An extracted FLAC frame cannot be accepted by the live-stream audio processing path.

## Explanation

Ogg frame processing fails and the ingest caller shuts down the session.

## Possible causes

- An extracted FLAC frame cannot be accepted by the live-stream audio processing path.

## What to check

1. Check preceding live-stream FLAC diagnostics and the source frame format.
