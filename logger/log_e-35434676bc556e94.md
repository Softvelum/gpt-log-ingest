# Unsupported Whisper option skipped

Product: Nimble Streamer
Component: Whisper transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-35434676bc556e94

## Log pattern

```text
skip unsupported whisper_full_params key='%s'
```

## Parameters

- Argument 1 — Option: Rejected detailed recognition option name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
skip unsupported whisper_full_params key='unknown_option'
```

## Short description

Unsupported Whisper option skipped.

## Trigger condition

A supplied detailed recognition option is not one of the accepted option names.

## Explanation

Only that option is ignored; supported options continue to be applied.

## Possible causes

- A supplied detailed recognition option is not one of the accepted option names.

## What to check

1. Check the option spelling. Accepted options cover thread count, temperature, best-of sampling, temperature increment, entropy threshold, log-probability threshold, and no-speech threshold.

## Recommended action

Remove or correct the unsupported option.
