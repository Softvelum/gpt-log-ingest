# TLS private key does not match certificate

Product: Nimble Streamer
Component: TLS certificate management
Logging function: log_e
Log level: error
Documentation ID: log_e-2607b50468362d4d

## Log pattern

```text
private key does not match the certificate public key e='%s'
```

## Parameters

- Argument 1 — Error: TLS library error description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
private key does not match the certificate public key e='key values mismatch'
```

## Short description

TLS private key does not match certificate.

## Trigger condition

The TLS library rejects the certificate and private-key pairing.

## Explanation

Creating this certificate context fails, preventing the pending context set from being installed. The check applies to ordinary TLS and supported HTTP/3 contexts.

## Possible causes

- The TLS library rejects the certificate and private-key pairing.

## What to check

1. Compare the certificate and configured private key.

## Recommended action

Configure the private key corresponding to the certificate.
