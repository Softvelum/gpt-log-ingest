# Pay-per-view API domain is invalid

Product: Nimble Streamer
Component: Pay-per-view API synchronization
Logging function: log_e
Log level: error
Documentation ID: log_e-47d4190185b38ccc

## Log pattern

```text
PPV Api sync failed handler's domain invalid
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
PPV Api sync failed handler's domain invalid
```

## Short description

Pay-per-view API domain is invalid.

## Trigger condition

Parsing the configured API URL leaves an empty domain.

## Explanation

Any previously applied deny list is cleared. The thread continues after its synchronization delay.

## Possible causes

- The API URL does not produce a usable domain.

## What to check

1. Check the configured API URL and connection diagnostics.

## Recommended action

Correct the API address or connection problem.
