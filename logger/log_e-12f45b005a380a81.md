# RTMP connect objectEncoding cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-12f45b005a380a81

## Log pattern

```text
failed to read objectEncoding
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to read objectEncoding
```

## Short description

RTMP connect objectEncoding cannot be decoded.

## Trigger condition

The connect request cannot supply its objectEncoding as an AMF number.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The connect request cannot supply its objectEncoding as an AMF number.

## What to check

1. Inspect the objectEncoding field and AMF framing in the incoming connect command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
