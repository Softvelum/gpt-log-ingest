# Advertising rule is not a JSON object

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-6085cd39b28940af

## Log pattern

```text
invalid rule type=%d
```

## Parameters

- Argument 1 — JSON type: Integer JSON type code of the unexpected value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid rule type=6
```

## Short description

Advertising rule is not a JSON object.

## Trigger condition

An element of the advertising rules array is not an object.

## Explanation

That rule is skipped while the remaining rules are parsed.

## Possible causes

- An element of the advertising rules array is not an object.

## What to check

1. Return an object for each element of the rules array.

## Recommended action

Return an object for each element of the rules array.
