# Transcription requires the Addenda license

Product: Nimble Streamer
Component: Live stream registration and transcription
Logging function: log_e
Log level: error
Documentation ID: log_e-3a252969790eacaa

## Log pattern

```text
Addenda license is required for Transcriber to process '%s'
```

## Parameters

- Argument 1 — stream: Application and stream name joined by a slash.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Addenda license is required for Transcriber to process 'live/camera'
```

## Short description

Transcription requires the Addenda license.

## Trigger condition

Audio-to-WebVTT transcription is enabled for a stream, but Addenda is not enabled in a build supporting transcription.

## Explanation

Transcriber initialization is skipped. Live stream registration still continues with no transcriber request queue assigned by this branch.

## Possible causes

- Transcription was requested without an enabled Addenda license.

## What to check

1. Check Addenda license state and whether transcription is intended for this stream.

## Recommended action

Enable the required license or disable transcription for this stream.
