# Client output enabled after origin input

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-e8d70dc7e1256a85

## Log pattern

```text
data available for client s=%d, enabling kEventOut
```

## Parameters

- Argument 1 — Client socket: Integer identifying the local client socket.

## Log examples

Illustrative examples; these are not captured server logs.

```text
data available for client s=18, enabling kEventOut
```

## Short description

Client output enabled after origin input.

## Trigger condition

A positive origin-body read provides data while client writable-event monitoring is disabled.

## Explanation

The client socket is enabled for output from the circular pass-through response buffer.

## Possible causes

- A positive origin-body read provides data while client writable-event monitoring is disabled.
