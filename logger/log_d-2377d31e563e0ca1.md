# Explicit video packet changed media type

Product: Nimble Streamer
Component: MPEG-TS live stream selection
Logging function: log_d
Log level: debug
Documentation ID: log_d-2377d31e563e0ca1

## Log pattern

```text
updateAvailable video type changed for video_pid=%d from %d to %d
```

## Parameters

- Argument 1 — packet\_id: MPEG-TS packet identifier printed as a decimal integer.
- Argument 2 — previous\_type: Previously selected stream-type code in decimal.
- Argument 3 — new\_type: New advertised stream-type code in decimal.

## Log examples

Illustrative examples; these are not captured server logs.

```text
updateAvailable video type changed for video_pid=256 from 27 to 36
```

## Short description

Explicit video packet changed media type.

## Trigger condition

An explicitly configured video packet identifier is present, but its new type differs from the previous nonzero type.

## Explanation

Video codec initialization, timestamps, parameter sets, and frame assembly buffers are reset. The same configured identifier remains selected and its advertised type is updated.
