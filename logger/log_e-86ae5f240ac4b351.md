# WebRTC helper listener bind failed

Product: Nimble Streamer
Component: WebRTC helper connection
Logging function: log_e
Log level: error
Documentation ID: log_e-86ae5f240ac4b351

## Log pattern

```text
failed to bind to ephemeral port s=%d errno=%d '%s'
```

## Parameters

- Argument 1 — Socket: Socket descriptor, integer; no unit.
- Argument 2 — Operating system error: C runtime errno value immediately after the failed operation, integer; no unit.
- Argument 3 — Error text: Diagnostic description supplied by the operating system or library, text.

Both occurrences concern a local helper TCP listener: one accepts WHIP publishing connections and the other WHEP playback connections.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to bind to ephemeral port s=12 errno=5 'operation failed'
```

## Short description

WebRTC helper listener bind failed.

## Trigger condition

Binding the IPv4 TCP listener for either the WHIP or WHEP helper fails.

## Explanation

The listener socket is closed and initialization fails. The message says ephemeral even when an explicit helper port was configured.

## Possible causes

- The chosen address/port is unavailable, already bound, or rejected by the operating system.

## What to check

1. Use the reported operating system error to check the selected helper interface and port.

## Recommended action

Correct the listener address or port conflict and restart the affected WebRTC service.
