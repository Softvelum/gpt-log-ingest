# Maximum decode interval is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-9250b722861e8c5d

## Log pattern

```text
invalid parameter value: %s. should be >= 1 && <=30
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. 

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0. should be >= 1 && <=30
```

## Short description

Maximum decode interval is invalid.

## Trigger condition

While reading configuration, the transcoder maximum decode interval is outside 1 through 30.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires a decode interval from 1 through 30.

## Recommended action

Correct the value to a decode interval from 1 through 30 and reload configuration.
