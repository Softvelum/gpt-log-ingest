# MPEG-TS table or clock interval is invalid

Product: Nimble Streamer
Component: Server configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-55a461ef49b4a351

## Log pattern

```text
invalid parameter value: %s (should be >= 10 && <= 5000)
```

## Parameters

- Argument 1 — Value: Original configuration value, text before numeric conversion; the applicable units depend on the named setting.

The value is logged as its original text. Several settings share this pattern; identify the setting from the rejected configuration line.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid parameter value: 0 (should be >= 10 && <= 5000)
```

## Short description

MPEG-TS table or clock interval is invalid.

## Trigger condition

While reading configuration, the SDT, PAT/PMT, or PCR repetition interval is outside 10 through 5000 milliseconds.

## Explanation

Configuration processing reports failure and the file loader stops at this line.

## Possible causes

- A configured value violates the setting-specific range or accepted choices.

## What to check

1. Check the setting on the rejected configuration line; it requires 10 through 5000 milliseconds.

## Recommended action

Correct the value to 10 through 5000 milliseconds and reload configuration.
