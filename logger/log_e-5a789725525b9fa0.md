# CPIX content key cannot be decrypted

Product: Nimble Streamer
Component: KeyOS DRM
Logging function: log_e
Log level: error
Documentation ID: log_e-5a789725525b9fa0

## Log pattern

```text
failed to decrypt content key for CPIX response
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to decrypt content key for CPIX response
```

## Short description

CPIX content key cannot be decrypted.

## Trigger condition

RSA document-key decryption fails, the decoded IV-and-ciphertext is not 48 bytes, or AES decryption fails to produce a 16-byte key.

## Explanation

The KeyOS response is rejected without installing the key.

## Possible causes

- RSA document-key decryption fails, the decoded IV-and-ciphertext is not 48 bytes, or AES decryption fails to produce a 16-byte key.

## What to check

1. Check the partner RSA key and the encrypted document/content-key payloads.

## Recommended action

Check the partner RSA key and the encrypted document/content-key payloads.
