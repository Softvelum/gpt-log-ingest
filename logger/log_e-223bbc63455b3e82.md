# Teletext decoder unavailable

Product: Nimble Streamer
Component: Caption and subtitle handling
Logging function: log_e
Log level: error
Documentation ID: log_e-223bbc63455b3e82

## Log pattern

```text
failed to find AV_CODEC_ID_DVB_TELETEXT decoder
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to find AV_CODEC_ID_DVB_TELETEXT decoder
```

## Short description

Teletext decoder unavailable.

## Trigger condition

The media library cannot find a DVB teletext decoder.

## Explanation

Initialization fails and a remembered unavailable-decoder flag suppresses further decoding attempts on this decoder instance.

## Possible causes

- The media library cannot find a DVB teletext decoder.

## What to check

1. Check that the loaded media library includes DVB teletext decoding.
