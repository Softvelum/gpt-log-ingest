# RIST sender transport startup failed

Product: Nimble Streamer
Component: RIST media integration
Logging function: log_e
Log level: error
Documentation ID: log_e-69d0b96284385bab

## Log pattern

```text
failed to start rist sender, id=%s
```

## Parameters

- Argument 1 — Connection ID: Configured identifier for the RIST child-process connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to start rist sender, id=rist-sender
```

## Short description

RIST sender transport startup failed.

## Trigger condition

The RIST library returns a nonzero result from transport startup.

## Explanation

The context and peer exist, but sender initialization returns failure.

## Possible causes

- The RIST library returns a nonzero result from transport startup.

## What to check

1. Check the RIST runtime diagnostics for transport startup using this connection ID.
