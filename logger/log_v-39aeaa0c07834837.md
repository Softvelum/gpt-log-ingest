# Remote media fragment requested

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_v
Log level: verbose
Documentation ID: log_v-39aeaa0c07834837

## Log pattern

```text
req fr=%u key='%s'
```

## Parameters

- Argument 1 — Fragment index: Unsigned zero-based cache fragment index.
- Argument 2 — Cache key: Text identifying the requested media or playlist cache item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
req fr=1 key='/live/camera/segment1.ts'
```

## Short description

Remote media fragment requested.

## Trigger condition

The first requested range fragment or next response fragment is unavailable in the local cache.

## Explanation

The session registers for cache updates and requests the fragment; it sends immediately if it became available or waits if queued.

## Possible causes

- The first requested range fragment or next response fragment is unavailable in the local cache.
