# Memory cache buffer allocation failed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-d0c1f38e1744b53d

## Log pattern

```text
failed to allocate cache item data key='%s' size=%llu cache_size=%llu
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — requested bytes: Requested buffer size in bytes.
- Argument 3 — RAM bytes: Total cache capacity currently allocated in memory, in bytes.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to allocate cache item data key='movie' size=4096 cache_size=8192
```

## Short description

Memory cache buffer allocation failed.

## Trigger condition

The memory allocation for an otherwise selected RAM cache item returns no buffer.

## Explanation

Cache allocation returns failure without adding the requested bytes to the RAM total.

## Possible causes

- The process could not allocate the requested memory.

## What to check

1. Check requested size and process memory availability.

## Recommended action

Address memory pressure before retrying the media request.
