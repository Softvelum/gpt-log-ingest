# DVR recording period advanced

Product: Nimble Streamer
Component: DVR archive maintenance
Logging function: log_d
Log level: debug
Documentation ID: log_d-4afc3624f761965a

## Log pattern

```text
reset period for dvr archive stream='%s/%s' current_period=%u storage_format=%u
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Period: Unsigned recording period identifier.
- Argument 4 — Storage version: Unsigned active archive-storage version.

## Log examples

Illustrative examples; these are not captured server logs.

```text
reset period for dvr archive stream='live/camera' current_period=1 storage_format=2
```

## Short description

DVR recording period advanced.

## Trigger condition

A recording reset increments the archive period.

## Explanation

A pending storage-version change is applied so later recording can begin a new storage bucket.

## Possible causes

- A recording reset increments the archive period.

## What to check

1. Check preceding timestamp, loading, or settings-change messages if the new period was unexpected.

## Recommended action

Check preceding timestamp, loading, or settings-change messages if the new period was unexpected.
