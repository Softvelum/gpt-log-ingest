# DVR AV1 initialization exceeds its buffer

Product: Nimble Streamer
Component: DVR recording
Logging function: log_e
Log level: error
Documentation ID: log_e-8992d0b98a1a22e4

## Log pattern

```text
DvrContext::ProcessAv1SequenceHeader failed to generate init segment. av1_config_record_size=%d
```

## Parameters

- Argument 1 — Codec data bytes: Size in bytes of the AV1 configuration record.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DvrContext::ProcessAv1SequenceHeader failed to generate init segment. av1_config_record_size=65536
```

## Short description

DVR AV1 initialization exceeds its buffer.

## Trigger condition

The calculated MP4 initialization size is greater than the fixed initialization buffer.

## Explanation

The recording initialization returns failure.

## Possible causes

- The calculated MP4 initialization size is greater than the fixed initialization buffer.

## What to check

1. Check unusually large codec configuration data.

## Recommended action

Check unusually large codec configuration data.
