# RTMP playback enters pause

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_d
Log level: debug
Documentation ID: log_d-7df8209c5c3b571d

## Log pattern

```text
stream paused, client: %d
```

## Parameters

- Argument 1 — Socket: Operating-system socket descriptor for the affected connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream paused, client: 42
```

## Short description

RTMP playback enters pause.

## Trigger condition

The connection pause flag is set while the sender is not yet in its paused state.

## Explanation

Media and metadata positions are reset and output events are disabled. The connection is retained for a later resume.

## Possible causes

- The connection pause flag is set while the sender is not yet in its paused state.

## What to check

1. Check the playback control sequence that requested pause.

## Recommended action

No action is required for an expected pause.
