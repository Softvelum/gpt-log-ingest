# DRM encryption scheme is unsupported

Product: Nimble Streamer
Component: DRM configuration
Logging function: log_e
Log level: error
Documentation ID: log_e-194a3e66762f3fd9

## Log pattern

```text
unknown encryption scheme type at %s:%u '%s' (must be 'cbcs' or 'cenc')
```

## Parameters

- Argument 1 — Settings file: Text naming the DRM settings file.
- Argument 2 — Settings line: Unsigned line number within the settings file.
- Argument 3 — Encryption scheme: Text containing the requested encryption scheme.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown encryption scheme type at /etc/nimble/drm.conf:12 'other' (must be 'cbcs' or 'cenc')
```

## Short description

DRM encryption scheme is unsupported.

## Trigger condition

The configured CENC scheme is neither cbcs nor cenc, ignoring letter case.

## Explanation

The new DRM settings are rejected; an earlier successfully loaded settings set is retained by the file reload path.

## Possible causes

- The configured CENC scheme is neither cbcs nor cenc, ignoring letter case.

## What to check

1. Select cbcs or cenc.

## Recommended action

Select cbcs or cenc.
