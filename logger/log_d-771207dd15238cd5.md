# Panel request enters retry delay

Product: Nimble Streamer
Component: WMSPanel synchronization
Logging function: log_d
Log level: debug
Documentation ID: log_d-771207dd15238cd5

## Log pattern

```text
sync request retry=%d
```

## Parameters

- Argument 1 — attempt\_index: Zero-based attempt index, 0 through 2.

## Log examples

Illustrative examples; these are not captured server logs.

```text
sync request retry=0
```

## Short description

Panel request enters retry delay.

## Trigger condition

An ordinary panel connection fails or the connected request returns a non-success transport result.

## Explanation

The printed index is the zero-based current attempt, from 0 through 2. A 30-second delay follows. After all three attempts, a full report is requested, statistics are saved, and the selected panel endpoint advances.
