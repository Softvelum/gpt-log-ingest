# HLS input waiting for new segments

Product: Nimble Streamer
Component: HLS and MPEG-TS HTTP input
Logging function: log_d
Log level: debug
Documentation ID: log_d-59423b56269b9760

## Log pattern

```text
waiting for chunks url='%s' wakeup_in=%u
```

## Parameters

- Argument 1 — url: Current origin URL.
- Argument 2 — delay\_seconds: Delay until the next wakeup in seconds, normally one through four.

## Log examples

Illustrative examples; these are not captured server logs.

```text
waiting for chunks url='https://origin.example/live.m3u8' wakeup_in=2
```

## Short description

HLS input waiting for new segments.

## Trigger condition

The HLS input schedules a delay while refreshing playlists without new chunks to request.

## Explanation

The delay is one second for target duration one; otherwise it uses half the target duration, capped at four seconds. A reusable connection is left open without events; otherwise shutdown is requested while preserving the planned wakeup.
