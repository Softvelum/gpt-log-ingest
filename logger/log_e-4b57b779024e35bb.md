# Icecast cue duration is not a valid number

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_e
Log level: error
Documentation ID: log_e-4b57b779024e35bb

## Log pattern

```text
scte35 injection rule failed to convert duration '%s' to long e='%s'
```

## Parameters

- Argument 1 — Duration: Captured duration text before applying the rule time-unit multiplier.
- Argument 2 — Error: Numeric-conversion exception description.

## Log examples

Illustrative examples; these are not captured server logs.

```text
scte35 injection rule failed to convert duration 'abc' to long e='stol'
```

## Short description

Icecast cue duration is not a valid number.

## Trigger condition

Converting the first regular-expression capture from an out-with-duration rule to a signed long throws an exception.

## Explanation

No splice cue is returned for this metadata match.

## Possible causes

- Converting the first regular-expression capture from an out-with-duration rule to a signed long throws an exception.

## What to check

1. Check the captured duration text and rule expression.

## Recommended action

Make the first captured group a duration accepted as a signed integer.
