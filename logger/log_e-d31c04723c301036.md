# Cannot disable SRT address reuse

Product: Nimble Streamer
Component: SRT transport
Logging function: log_e
Log level: error
Documentation ID: log_e-d31c04723c301036

## Log pattern

```text
failed to disable reuseaddr mode s=%d
```

## Parameters

- Argument 1 — Socket: SRT socket or group identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to disable reuseaddr mode s=100
```

## Short description

Cannot disable SRT address reuse.

## Trigger condition

For an SRT version older than 1.4.4, or one without version reporting, disabling address reuse fails before binding.

## Explanation

Binding is still attempted. The compatibility setting avoids reusing an existing UDP socket solely because its port matches.

## Possible causes

- For an SRT version older than 1.4.4, or one without version reporting, disabling address reuse fails before binding.

## What to check

1. Check the loaded SRT version and subsequent bind result.
