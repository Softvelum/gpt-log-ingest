# Origin playlist response allocation failed

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_e
Log level: error
Documentation ID: log_e-1d8ee9869907d6cd

## Log pattern

```text
failed to reallocate origin response buffer size=%d
```

## Parameters

- Argument 1 — Response bytes: Integer requested response capacity in bytes, excluding the extra terminating byte.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to reallocate origin response buffer size=131072
```

## Short description

Origin playlist response allocation failed.

## Trigger condition

A larger origin playlist response buffer cannot be allocated.

## Explanation

HTTP 500 is prepared and playlist processing stops.

## Possible causes

- A larger origin playlist response buffer cannot be allocated.

## What to check

1. Check process memory availability and whether the origin playlist size is expected.

## Recommended action

Check process memory availability and whether the origin playlist size is expected.
