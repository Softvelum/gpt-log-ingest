# RTMP deleteStream command-object placeholder cannot be decoded

Product: Nimble Streamer
Component: RTMP command handling
Logging function: log_e
Log level: error
Documentation ID: log_e-684b186930703b2f

## Log pattern

```text
failed to process null for deleteStream command
```

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

RTMP deleteStream command-object placeholder cannot be decoded.

## Trigger condition

The deleteStream request cannot supply its command-object placeholder as an AMF null value.

## Explanation

The command is rejected and connection processing fails at this field. Truncated data or an unexpected AMF type can cause the read to fail.

## Possible causes

- The deleteStream request cannot supply its command-object placeholder as an AMF null value.

## What to check

1. Inspect the command-object placeholder field and AMF framing in the incoming deleteStream command.

## Recommended action

Correct the peer command encoding and ensure the full command reaches the server.
