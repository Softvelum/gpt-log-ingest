# File could not be opened

Product: Nimble Streamer
Component: Operating system utilities
Logging function: log_e
Log level: error
Documentation ID: log_e-53b6bbdb34321d71

## Log pattern

```text
failed to open '%s'
```

## Parameters

- Argument 1 — File: Affected file path, text.

The same text covers output-file write/append modes and DRM settings read mode.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open '/var/lib/nimble/example.dat'
```

## Short description

File could not be opened.

## Trigger condition

Opening a file fails while replacing or appending binary data, or while reloading changed DRM settings.

## Explanation

The write, append, or DRM reload operation returns failure before processing file contents.

## Possible causes

- The requested file cannot be opened in the required mode.

## What to check

1. Check the path and write access for output files or read access for DRM settings.

## Recommended action

Restore access to the requested file.
