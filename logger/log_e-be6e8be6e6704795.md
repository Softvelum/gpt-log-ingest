# RTSP static audio payload type is unsupported

Product: Nimble Streamer
Component: RTSP input and RTP media
Logging function: log_e
Log level: error
Documentation ID: log_e-be6e8be6e6704795

## Log pattern

```text
unsupported audio codec fmt=%d stream url='%s'
```

## Parameters

- Argument 1 — Payload format: Integer SDP static payload format number.
- Argument 2 — Stream URL: RTSP input base URL identifying the affected source.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported audio codec fmt=18 stream url='rtsp://192.0.2.1/live'
```

## Short description

RTSP static audio payload type is unsupported.

## Trigger condition

The SDP audio encoding name is empty and its static payload format is not zero, eight, or fourteen.

## Explanation

Audio codec selection fails. The accepted unnamed static formats are G.711 mu-law, G.711 A-law, and MPEG audio.

## Possible causes

- The SDP audio encoding name is empty and its static payload format is not zero, eight, or fourteen.

## What to check

1. Check the audio payload type and whether SDP supplies an encoding name.

## Recommended action

Use a supported static format or advertise a supported named audio encoding.
