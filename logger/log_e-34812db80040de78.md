# Enhanced RTMP Opus media precedes its sequence header

Product: Nimble Streamer
Component: RTMP media input
Logging function: log_e
Log level: error
Documentation ID: log_e-34812db80040de78

## Log pattern

```text
[AM] opus data MUST follow opus sequence header for (%s)
```

## Parameters

- Argument 1 — Stream: Application and stream name associated with this RTMP message stream; it can be empty before association.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[AM] opus data MUST follow opus sequence header for (live/camera)
```

## Short description

Enhanced RTMP Opus media precedes its sequence header.

## Trigger condition

A Opus coded-audio packet arrives before enhanced audio initialization.

## Explanation

The packet is rejected and connection processing fails before audio delivery.

## Possible causes

- A Opus coded-audio packet arrives before enhanced audio initialization.

## What to check

1. Check whether a Opus sequence-start packet was sent and accepted before coded frames.

## Recommended action

Send the Opus sequence header before coded audio packets.
