# NDI sender slows down to rebuild buffering

Product: Nimble Streamer
Component: NDI media integration
Logging function: log_i
Log level: info
Documentation ID: log_i-316b14400db2cd6f

## Log pattern

```text
buffer delay=%lld, correction=%lld, slow down
```

## Parameters

- Argument 1 — Buffer delay: Current buffered stream duration in milliseconds.
- Argument 2 — Correction: Positive delay added to the pacing origin in milliseconds.

## Log examples

Illustrative examples; these are not captured server logs.

```text
buffer delay=300, correction=8, slow down
```

## Short description

NDI sender slows down to rebuild buffering.

## Trigger condition

Buffered delay is below the 500-millisecond target and the pacing correction rounds to a positive value.

## Explanation

The sender moves its pacing start time later, increasing the wait before output to let buffering grow. Corrections begin only when the deficit reaches the configured correction bands.

## Possible causes

- Buffered delay is below the 500-millisecond target and the pacing correction rounds to a positive value.

## What to check

1. Check the reported buffer delay relative to the 500-millisecond target.
