# Missing SMIL media download is being initialized

Product: Nimble Streamer
Component: HTTP client sessions
Logging function: log_d
Log level: debug
Documentation ID: log_d-e9f13f01b6e46140

## Log pattern

```text
InitializeNewCacheItem key='%s'
```

## Parameters

- Argument 1 — Required media key: Text identifying a missing VOD source referenced by the SMIL document.

## Log examples

## Short description

Missing SMIL media download is being initialized.

## Trigger condition

A remote SMIL request reserves a missing required VOD item and registers its observer.

## Explanation

The source item download is initialized; the playlist request waits until all required items are available.

## Possible causes

- A remote SMIL request reserves a missing required VOD item and registers its observer.
