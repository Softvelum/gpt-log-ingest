# VCAS key reference added

Product: Nimble Streamer
Component: DRM key management
Logging function: log_d
Log level: debug
Documentation ID: log_d-a702251e1f8f07bb

## Log pattern

```text
added key for '%s' url='%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.
- Argument 2 — Key-server URL: Text giving the configured or requested key-server URL.

## Log examples

Illustrative examples; these are not captured server logs.

```text
added key for 'live/camera' url='https://keys.example/key'
```

## Short description

VCAS key reference added.

## Trigger condition

A VCAS key URL is added or reused while creating an application key set.

## Explanation

The key reference is stored for the stream; downloading or creating the key follows.

## Possible causes

- A VCAS key URL is added or reused while creating an application key set.
