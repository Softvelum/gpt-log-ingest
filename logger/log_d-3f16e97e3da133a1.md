# Cache fragment marked available

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-3f16e97e3da133a1

## Log pattern

```text
CacheItem::SetFragmentAvailable key='%s' index=%u byte=%u bit=%u
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.
- Argument 2 — fragment: Zero-based fragment index.
- Argument 3 — byte: Zero-based byte in the availability bitmap.
- Argument 4 — bit: Zero-based bit within that byte.

## Log examples

Illustrative examples; these are not captured server logs.

```text
CacheItem::SetFragmentAvailable key='movie' index=9 byte=1 bit=1
```

## Short description

Cache fragment marked available.

## Trigger condition

A previously clear fragment availability bit is set.

## Explanation

The fragment timestamp is updated and waiting cache observers are notified.
