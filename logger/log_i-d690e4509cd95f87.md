# AJA output settings require a restart

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_i
Log level: info
Documentation ID: log_i-d690e4509cd95f87

## Log pattern

```text
aja encoder params changed. Restart encoder %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

## Log examples

Illustrative examples; these are not captured server logs.

```text
aja encoder params changed. Restart encoder live/encoded
```

## Short description

AJA output settings require a restart.

## Trigger condition

A decoded-video output update finds that the existing AJA writer parameters differ from the new settings.

## Explanation

The update deliberately fails, causing the encoder worker to stop and release the writer so the output can be recreated.

## Possible causes

- The configured AJA parameter map changed after the writer was created.

## What to check

1. Check the recent AJA output settings change and subsequent worker startup.

## Recommended action

Allow the output to restart with the new parameters; investigate repeated restarts if settings are stable.
