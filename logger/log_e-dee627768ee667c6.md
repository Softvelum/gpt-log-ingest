# Common-encryption key is unavailable

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-dee627768ee667c6

## Log pattern

```text
[drm] Widevine key for '%s/%s' is not available (%s)
```

## Parameters

- Argument 1 — Application: Text naming the application.
- Argument 2 — Stream: Text naming the stream.
- Argument 3 — Key availability: Text stating missing when no matching key exists or never updated when its slot has not received a usable key.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[drm] Widevine key for 'live/camera' is not available (never updated)
```

## Short description

Common-encryption key is unavailable.

## Trigger condition

A selected key is missing or has never been updated, either during initialization with error logging requested or during segment preparation without permitted clear fallback.

## Explanation

The initialization or segment request reports failure. The message also covers CPIX-based providers.

## Possible causes

- A selected key is missing or has never been updated, either during initialization with error logging requested or during segment preparation without permitted clear fallback.

## What to check

1. Check preceding key requests and provider responses; verify the required crypto period and media-key type.

## Recommended action

Check preceding key requests and provider responses; verify the required crypto period and media-key type.
