# Advertising server rejected the download

Product: Nimble Streamer
Component: Advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-0d74ac04445b67eb

## Log pattern

```text
failed to download %s, code=%d
```

## Parameters

- Argument 1 — Content URI: Text giving the original advertising content location.
- Argument 2 — HTTP status: Integer HTTP response status code.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to download https://media.example/ad.mp4, code=404
```

## Short description

Advertising server rejected the download.

## Trigger condition

The advertising origin returns a final HTTP status other than 200 or 206, after redirect handling.

## Explanation

The download session is marked finished without accepting the response body.

## Possible causes

- The advertising origin returns a final HTTP status other than 200 or 206, after redirect handling.

## What to check

1. Check that the content URI returns the intended media with HTTP 200 or 206.

## Recommended action

Check that the content URI returns the intended media with HTTP 200 or 206.
