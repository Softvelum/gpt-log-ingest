# Current DRM settings cannot be found

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-bf269332fe9f96d4

## Log pattern

```text
DRM settings not found for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
DRM settings not found for 'live/camera'
```

## Short description

Current DRM settings cannot be found.

## Trigger condition

DRMToday login, ticket, or key processing, or key garbage collection, cannot find settings for the key owner.

## Explanation

DRMToday processing stops; garbage collection instead skips this key set.

## Possible causes

- DRMToday login, ticket, or key processing, or key garbage collection, cannot find settings for the key owner.

## What to check

1. Check whether DRM settings were removed or changed while keys or requests remained active.

## Recommended action

Check whether DRM settings were removed or changed while keys or requests remained active.
