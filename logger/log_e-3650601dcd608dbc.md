# Encrypted URL initialization vector has the wrong decoded size

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-3650601dcd608dbc

## Log pattern

```text
BIO_read failed read_bytes=%d expected=%d
```

## Parameters

- Argument 1 — Decoded bytes: Base64 decode return value, signed integer byte count.
- Argument 2 — Required bytes: Cipher-required vector size in bytes, integer.

## Log examples

Illustrative examples; these are not captured server logs.

```text
BIO_read failed read_bytes=8 expected=16
```

## Short description

Encrypted URL initialization vector has the wrong decoded size.

## Trigger condition

Base64 decoding the initialization vector returns a size different from the cipher-required size.

## Explanation

URL validation returns failure without assigning a decrypted URL.

## Possible causes

- The vector is malformed or has the wrong decoded length.

## What to check

1. Check that all encrypted-link fields are complete and correctly encoded.

## Recommended action

Regenerate the complete encrypted link with matching fields.
