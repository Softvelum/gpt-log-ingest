# NVIDIA encoder API creation failed

Product: Nimble Streamer
Component: Transcoding library loading
Logging function: log_e
Log level: error
Documentation ID: log_e-2a16f5091eb13594

## Log pattern

```text
failed to create nvenc api instance(code=%d)
```

## Parameters

- Argument 1 — Status: NVIDIA encoder API status, integer; no unit.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to create nvenc api instance(code=15)
```

## Short description

NVIDIA encoder API creation failed.

## Trigger condition

Creating the NVIDIA encoder API function table returns a status other than success.

## Explanation

Loading the NVIDIA encoding library raises an exception; the enclosing loader closes the NVIDIA encoding and CUDA libraries and leaves NVIDIA encoding unavailable.

## Possible causes

- The driver API rejects creation of the requested encoder interface.

## What to check

1. Check the NVIDIA status and compatibility between the installed driver and encoder interface.

## Recommended action

Install compatible NVIDIA driver support before using NVIDIA encoding.
