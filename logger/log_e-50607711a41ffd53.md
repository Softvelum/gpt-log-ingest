# FLV response contains an invalid buffer

Product: Nimble Streamer
Component: Non-Windows progressive download modules
Logging function: log_e
Log level: error
Documentation ID: log_e-50607711a41ffd53

## Log pattern

```text
FlvModule::HandleRequest invalid buffer in chain
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
FlvModule::HandleRequest invalid buffer in chain
```

## Short description

FLV response contains an invalid buffer.

## Trigger condition

A chain entry has no buffer, or its file-backed buffer lacks a nonzero descriptor.

## Explanation

The FLV wrapper marks the chain invalid, clears response content length, and changes status 200 to 500. Other existing status values are retained.

## Possible causes

- A chain entry has no buffer, or its file-backed buffer lacks a nonzero descriptor.

## What to check

1. Check the module return result and selected local media file.

## Recommended action

Investigate the module output that violates the wrapper buffer requirements.
