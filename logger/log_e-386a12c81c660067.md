# DRM key notification has no consumer

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-386a12c81c660067

## Log pattern

```text
got null observer for '%s'
```

## Parameters

- Argument 1 — Key owner: Text identifying the application or application/stream whose keys are managed.

## Log examples

Illustrative examples; these are not captured server logs.

```text
got null observer for 'live/camera'
```

## Short description

DRM key notification has no consumer.

## Trigger condition

An attempt to register a key-availability listener supplies no listener.

## Explanation

No notification listener is added.

## Possible causes

- An attempt to register a key-availability listener supplies no listener.

## What to check

1. Check why the waiting media operation did not provide a key notification consumer.

## Recommended action

Check why the waiting media operation did not provide a key notification consumer.
