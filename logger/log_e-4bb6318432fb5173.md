# Scenario live-stream registration is a duplicate

Product: Nimble Streamer
Component: Scenario encoding
Logging function: log_e
Log level: error
Documentation ID: log_e-4bb6318432fb5173

## Log pattern

```text
stream already registered and not removable[%s], failed to register
```

## Parameters

- Argument 1 — Stream identity: Joined application and stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
stream already registered and not removable[live/camera], failed to register
```

## Short description

Scenario live-stream registration is a duplicate.

## Trigger condition

A stream with the same joined application/name already exists in the scenario encoder registry.

## Explanation

Registration returns an empty result and keeps the existing stream. This registry does not replace an existing entry during registration.

## Possible causes

- A stream with the same joined application/name already exists in the scenario encoder registry.

## What to check

1. Check whether two registrations target the same application and stream.

## Recommended action

Remove the earlier registration or use a distinct stream name before registering again.
