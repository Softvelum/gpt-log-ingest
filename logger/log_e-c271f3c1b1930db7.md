# RTSP server received an unsupported method

Product: Nimble Streamer
Component: RTSP connections and control
Logging function: log_e
Log level: error
Documentation ID: log_e-c271f3c1b1930db7

## Log pattern

```text
unsupported method %s from client: %d
```

## Parameters

- Argument 1 — Method: Request method text.
- Argument 2 — Socket: Integer operating-system socket descriptor identifying this connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unsupported method PAUSE from client: 25
```

## Short description

RTSP server received an unsupported method.

## Trigger condition

The request does not match the server operations handled in its current mode.

## Explanation

The server sends a not-implemented response. PLAY is handled here only in the corresponding receive mode.

## Possible causes

- The request does not match the server operations handled in its current mode.

## What to check

1. Check the request method and session mode.

## Recommended action

Use a method supported for the current session.
