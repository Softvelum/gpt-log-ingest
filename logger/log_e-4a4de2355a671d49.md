# HLS advertising playlist is not ready after waiting

Product: Nimble Streamer
Component: HLS and DASH packaging
Logging function: log_e
Log level: error
Documentation ID: log_e-4a4de2355a671d49

## Log pattern

```text
app=%s stream=%s stream_name=%s session=%lu failed to get playlist
```

## Parameters

- Argument 1 — Application: Application associated with the advertising playback session.
- Argument 2 — Stream: Stream associated with the advertising playback session.
- Argument 3 — Rendition: Specific stream name being processed for this session.
- Argument 4 — Session: Numeric playback session identifier.

## Log examples

Illustrative examples; these are not captured server logs.

```text
app=live stream=camera stream_name=live/camera session=123 failed to get playlist
```

## Short description

HLS advertising playlist is not ready after waiting.

## Trigger condition

Processing resumes from the playlist-wait phase with no playlist or a playlist whose state is not ready.

## Explanation

The advertising playlist update fails instead of inserting the requested advertisement.

## Possible causes

- Processing resumes from the playlist-wait phase with no playlist or a playlist whose state is not ready.

## What to check

1. Check playlist-generation completion and earlier advertising media errors.

## Recommended action

Resolve the failed or incomplete advertising playlist generation.
