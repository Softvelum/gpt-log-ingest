# Stream-check event processing threw an exception

Product: Nimble Streamer
Component: Linux stream availability checks
Logging function: log_e
Log level: error
Documentation ID: log_e-cb89f63825b962f5

## Log pattern

```text
unknown exception while processing session=%p(s=%d)
```

## Parameters

- Argument 1 — task address: Address of the task object whose handler failed.
- Argument 2 — socket: Socket descriptor for the stream-check connection.

## Log examples

Illustrative examples; these are not captured server logs.

```text
unknown exception while processing session=0x1000(s=12)
```

## Short description

Stream-check event processing threw an exception.

## Trigger condition

Any exception escapes a task socket-event handler.

## Explanation

The event loop catches it and requests task shutdown, then continues cleanup and remaining work. The message does not include an exception description.

## Possible causes

- Task event handling raised an exception.

## What to check

1. Correlate the task address and socket with preceding task diagnostics.

## Recommended action

Investigate the last task operation before the exception.
