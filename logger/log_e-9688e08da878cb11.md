## Short description

LATM stream configuration parsing failed.

## Trigger condition

An audio mux element supplies a new stream configuration that cannot be parsed or is unsupported.

## Explanation

Processing of the audio mux element returns failure before payload extraction.

## Possible causes

- An audio mux element supplies a new stream configuration that cannot be parsed or is unsupported.

## What to check

1. Check earlier LATM configuration diagnostics and whether the element is truncated.
