# Session begins waiting for advertising content

Product: Nimble Streamer
Component: HTTP request workers
Logging function: log_d
Log level: debug
Documentation ID: log_d-62a439ee6b4293e6

## Log pattern

```text
[WrkT::AddAdsCoO] content_id='%s' session=%p
```

## Parameters

- Argument 1 — Content identifier: Text identifying the observed resource.
- Argument 2 — Session: Connection-session address used for diagnostic correlation.

## Log examples

Illustrative examples; these are not captured server logs.

```text
[WrkT::AddAdsCoO] content_id='example-item' session=0x1000
```

## Short description

Session begins waiting for advertising content.

## Trigger condition

A session requests notification when advertising content loads.

## Explanation

An existing set is updated or the worker first subscribes to the advertising content manager. Registration can still fail after this message.
