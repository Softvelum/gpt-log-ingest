# URL verification digest finalization failed

Product: Nimble Streamer
Component: Encrypted playback URL validation
Logging function: log_e
Log level: error
Documentation ID: log_e-1cd41615da04e16e

## Log pattern

```text
EVP_DigestFinal_ex() failed
```

## Log examples

Illustrative examples; these are not captured server logs.

```text
EVP_DigestFinal_ex() failed
```

## Short description

URL verification digest finalization failed.

## Trigger condition

During encrypted-link validation, finalizing the calculated digest fails.

## Explanation

Validation returns failure and no URL is assigned.

## Possible causes

- The cryptographic library reports that the digest calculation could not produce its final result.

## What to check

1. Check matching encrypted-link data and session key, and available cryptographic library operations.

## Recommended action

Resolve the failed decryption or digest operation before accepting the link.
