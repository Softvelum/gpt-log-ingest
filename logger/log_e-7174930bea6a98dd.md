# RTMP or RTSP playback has no stream buffer

Product: Nimble Streamer
Component: RTMP output and advertising
Logging function: log_e
Log level: error
Documentation ID: log_e-7174930bea6a98dd

## Log pattern

```text
Stream Not Found %s %s
```

## Parameters

- Argument 1 — Application: Application requested by the playback session.
- Argument 2 — Stream: Requested stream name.

## Log examples

Illustrative examples; these are not captured server logs.

```text
Stream Not Found live camera
```

## Short description

RTMP or RTSP playback has no stream buffer.

## Trigger condition

RTMP output finds no stream buffer, or RTSP session setup cannot obtain one after requesting a delayed pull if available.

## Explanation

The playback attempt fails and the session is shut down.

## Possible causes

- RTMP output finds no stream buffer, or RTSP session setup cannot obtain one after requesting a delayed pull if available.

## What to check

1. Check the requested application and stream, active input, alias mapping, and any delayed-pull setup.

## Recommended action

Make the intended stream available before retrying playback.
