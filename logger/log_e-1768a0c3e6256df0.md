# Unexpected segment kind reached CENC encryption

Product: Nimble Streamer
Component: DRM key management
Logging function: log_e
Log level: error
Documentation ID: log_e-1768a0c3e6256df0

## Log pattern

```text
encryptCencChunk: unexpected segment type: %d
```

## Parameters

- Argument 1 — Segment kind: Integer identifying the unsupported segment category.

## Log examples

Illustrative examples; these are not captured server logs.

```text
encryptCencChunk: unexpected segment type: 0
```

## Short description

Unexpected segment kind reached CENC encryption.

## Trigger condition

The segment is neither an initialization segment nor a media segment.

## Explanation

Encryption returns failure.

## Possible causes

- The segment is neither an initialization segment nor a media segment.

## What to check

1. Check the media object type supplied for encryption and preserve surrounding output errors.

## Recommended action

Check the media object type supplied for encryption and preserve surrounding output errors.
