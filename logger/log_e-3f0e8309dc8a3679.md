# DVR subtitle language header is invalid

Product: Nimble Streamer
Component: DVR
Logging function: log_e
Log level: error
Documentation ID: log_e-3f0e8309dc8a3679

## Log pattern

```text
invalid lang_info format in .vtt segment file, stream=%s period=%d start_time=%lld
```

## Parameters

- Argument 1 — Stream: Text naming the application and stream.
- Argument 2 — Period: Integer identifying a continuous recording period.
- Argument 3 — Segment start: 64-bit media timestamp in 90000-Hz ticks.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid lang_info format in .vtt segment file, stream=live/camera period=1 start_time=90000
```

## Short description

DVR subtitle language header is invalid.

## Trigger condition

The stored language-header length reaches or exceeds the subtitle segment size.

## Explanation

This segment contributes no subtitle text; export continues with subsequent segments.

## Possible causes

- The stored language-header length reaches or exceeds the subtitle segment size.

## What to check

1. Check the affected recorded subtitle segment and its language metadata.

## Recommended action

Check the affected recorded subtitle segment and its language metadata.
