# Playlist block start date is invalid

Product: Nimble Streamer
Component: Server playlists
Logging function: log_e
Log level: error
Documentation ID: log_e-e533809a6fb5c29e

## Log pattern

```text
invalid start date %s
```

## Parameters

- Argument 1 — Block start: Text containing the rejected block timestamp.

## Log examples

Illustrative examples; these are not captured server logs.

```text
invalid start date invalid-date
```

## Short description

Playlist block start date is invalid.

## Trigger condition

Parsing a block start timestamp returns zero.

## Explanation

The block receives the epoch start time; this log does not itself discard the block.

## Possible causes

- Parsing a block start timestamp returns zero.

## What to check

1. Use a valid UTC start date in YYYY-MM-DD HH:MM:SS form.

## Recommended action

Use a valid UTC start date in YYYY-MM-DD HH:MM:SS form.
