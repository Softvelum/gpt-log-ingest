# Disk cache version marker cannot be written

Product: Nimble Streamer
Component: Media data cache
Logging function: log_e
Log level: error
Documentation ID: log_e-77daa87304d75df0

## Log pattern

```text
failed to open(write) cache version file: %s. Most probably this is permission issue
```

## Parameters

- Argument 1 — file: Filesystem path of the cache data or metadata file being handled.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to open(write) cache version file: /var/cache/nimble/version. Most probably this is permission issue
```

## Short description

Disk cache version marker cannot be written.

## Trigger condition

The version marker is missing or incompatible and cannot be opened for writing.

## Explanation

The compatibility check returns before cleaning stored cache files. Both marker creation and replacement use this message.

## Possible causes

- Creating or rewriting the version marker failed; permissions are one possible cause.

## What to check

1. Check write access to the marker and its parent directory.

## Recommended action

Restore access before expecting incompatible cache data to be cleared.
