# Cache lookup missed

Product: Nimble Streamer
Component: Media data cache
Logging function: log_d
Log level: debug
Documentation ID: log_d-69173d0b793f7f1d

## Log pattern

```text
not found key='%s'
```

## Parameters

- Argument 1 — key: Cache lookup key identifying the stored item.

## Log examples

Illustrative examples; these are not captured server logs.

```text
not found key='movie'
```

## Short description

Cache lookup missed.

## Trigger condition

No usable cached item is found, including after an allowed on-demand disk load.

## Explanation

The lookup returns no item. A cache miss alone is normal and does not establish an underlying error.
