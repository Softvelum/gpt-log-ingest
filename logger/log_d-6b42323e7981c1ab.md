# Audio component settings changed

Product: Nimble Streamer
Component: Transcoding output management
Logging function: log_d
Log level: debug
Documentation ID: log_d-6b42323e7981c1ab

## Log pattern

```text
audio encoder changed for %s/%s
```

## Parameters

- Argument 1 — Application: Output application name, text.
- Argument 2 — Stream: Output stream name, text.

With video following audio, some combined states also return to finding the first audio timestamp. Other accepted states retain their current scheduling state until subsequent processing.

## Log examples

Illustrative examples; these are not captured server logs.

```text
audio encoder changed for live/encoded
```

## Short description

Audio component settings changed.

## Trigger condition

Audio remains enabled and a settings update arrives in a supported existing-audio state.

## Explanation

The current audio encoder and codec selection are reset, then the updated source or encoder is configured.
