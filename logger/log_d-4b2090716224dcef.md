# Direct file-to-socket send failed

Product: Nimble Streamer
Component: Client and origin sockets
Logging function: log_d
Log level: debug
Documentation ID: log_d-4b2090716224dcef

## Log pattern

```text
failed to sendfile fd=%d to %s s=%d (errno=%d)
```

## Parameters

- Argument 1 — File descriptor: Integer descriptor of the source file.
- Argument 2 — Peer role: Text name identifying the socket role, such as client or origin.
- Argument 3 — Socket: Integer socket descriptor.
- Argument 4 — System error: Integer operating-system socket error value.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to sendfile fd=10 to client s=12 (errno=11)
```

## Short description

Direct file-to-socket send failed.

## Trigger condition

A non-Windows, non-TLS file send returns a negative result.

## Explanation

The system error is saved and the failure is returned. Each attempted transfer is limited to 128 KiB.

## Possible causes

- The direct file send operation returned an error.

## What to check

1. Inspect the input file, socket and system error; a temporary readiness condition is possible.
