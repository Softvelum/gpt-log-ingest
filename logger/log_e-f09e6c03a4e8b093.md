# DVR HLS encryption initialization cannot be read

Product: Nimble Streamer
Component: DVR playback conversion
Logging function: log_e
Log level: error
Documentation ID: log_e-f09e6c03a4e8b093

## Log pattern

```text
failed to open and map init segment f='%s' off=%llu size=%llu
```

## Parameters

- Argument 1 — Storage file: Text naming the recorded storage file.
- Argument 2 — Segment bytes: Unsigned 32-bit initialization size in bytes, despite the off label.
- Argument 3 — Segment offset: Unsigned 64-bit byte offset, despite the size label.

The offset and size labels are reversed by the supplied arguments, and the first numeric argument is 32-bit while its conversion requires 64-bit.

## Log examples

No sound example is given because the initialization-size argument is incompatible with its printf conversion.

## Short description

DVR HLS encryption initialization cannot be read.

## Trigger condition

The required recorded video initialization data cannot be opened for reading.

## Explanation

The cache item is canceled.

## Possible causes

- The required recorded video initialization data cannot be opened for reading.

## What to check

1. Check file availability, access, and the recorded segment index.

## Recommended action

Check file availability, access, and the recorded segment index.
