# Icecast publishing request cannot be parsed

Product: Nimble Streamer
Component: Icecast ingest and metadata
Logging function: log_d
Log level: debug
Documentation ID: log_d-ea59282fbdd58911

## Log pattern

```text
failed to parse icecast request:
%.*s
```

## Parameters

- Argument 1 — Length: Maximum number of request bytes to print; this precision argument is not printed separately.
- Argument 2 — Request: Request buffer, limited by the preceding byte length.

The asterisk precision consumes the first argument and limits the following string conversion.

## Log examples

Illustrative examples; these are not captured server logs.

```text
failed to parse icecast request:
BAD /live/radio HTTP/1.0


```

## Short description

Icecast publishing request cannot be parsed.

## Trigger condition

The incoming request method is unsupported, metadata GET requests are disabled, or HTTP request parsing fails.

## Explanation

The session is shut down. The displayed request can already have its legacy SOURCE and ICE syntax normalized for HTTP parsing.

## Possible causes

- The incoming request method is unsupported, metadata GET requests are disabled, or HTTP request parsing fails.

## What to check

1. Check the request method and request syntax.

## Recommended action

Send a supported publishing request, or enable metadata updates when using that endpoint.
