# Could not create the SRT input listener

Product: Nimble Streamer
Component: Server startup and services
Logging function: log_e
Log level: error
Documentation ID: log_e-9b3ed75631204fb5

## Log pattern

failed to create SrtListenCamera thread

## Log examples

Illustrative examples; these are not captured server logs.

```text

```

## Short description

Could not create the SRT input listener.

## Trigger condition

SRT support is compiled in, its library is available, and a configured input listener is being created. Thread creation reports failure.

## Explanation

The remaining server startup sequence is skipped and the server run routine returns failure. This path does not reach the normal worker-join sequence. The preceding thread resource error can provide the underlying reason.

## Possible causes

- Creation of the SRT input listener failed.

## What to check

1. Inspect the preceding thread resource error for the failed SRT input listener.
